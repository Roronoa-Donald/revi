Chapitre 3 — Algorithme du Simplexe & Tableaux

Module 3 ≈ 3 h 00 de travail Réservé B2 et plus
Mise en situation

Dès qu’un problème compte 3, 10 ou 100 variables de décision, la représentation graphique dans le plan devient strictement impossible. Comment explorer un polyèdre à 50 dimensions sans tester des milliards de combinaisons ? En 1947, George Dantzig invente une méthode révolutionnaire : partir d’un sommet initial évident, inspecter les arêtes adjacentes pour choisir celle qui augmente le plus vite le profit, et glisser vers le sommet voisin par un pivot matriciel. C’est le génie de l’algorithme du Simplexe.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. comprendre l’intuition géométrique et algébrique de la marche de sommet en sommet sur le polyèdre ;
  2. distinguer rigoureusement les variables de base (non nulles a priori) et les variables hors-base (fixées à zéro) ;
  3. dresser le tableau initial du simplexe à partir de la forme standard d’un programme linéaire ;
  4. appliquer le critère de Dantzig pour désigner la variable entrante (colonne pivot) ;
  5. appliquer le test du ratio minimum pour désigner la variable sortante (ligne pivot) et éviter de sortir du domaine réalisable ;
  6. exécuter un pivotage complet de Gauss-Jordan pour mettre à jour la base et les coûts réduits ;
  7. reconnaître sans hésiter la condition d’optimalité finale (tous les coûts réduits $\bar{c}_j \le 0$).

1. Le principe fondamental : Naviguer de sommet en sommet

L’algorithme du simplexe ne cherche pas au hasard. Il applique un principe d’ascension systématique :

La marche de Dantzig de sommet en sommet
Itération 0 — Sommet initial (Origine)

Base $s = b$, variables de décision hors-base $x_1 = x_2 = 0 \implies Z = 0$.

Itération 1 — Choix de la plus forte pente

Entrée de la variable au coût réduit $\bar{c}_k > 0$ le plus élevé, pivotage $\implies Z = 120$.

Itération 2 — Atteinte du sommet optimal

Nouvelle amélioration jusqu’à ce que tous les coûts réduits soient $\le 0 \implies Z^* = 160$ (Optimum prouvé).

Pourquoi le simplexe est-il si rapide ?

Bien que le nombre théorique de sommets puisse être exponentiel dans le pire des cas (Klee-Minty), en pratique industrielle l’algorithme du simplexe converge en un nombre d’itérations linéaire par rapport au nombre de contraintes (généralement entre $1.5 m$ et $3 m$ pivots, où $m$ est le nombre de lignes).

2. Base, Hors-Base & Solutions de Base Réalisables

Considérons un système de $m$ contraintes avec $n$ variables ($n > m$) sous forme standard $A x = b$ :

Définition d’une Solution de Base Réalisable (SBR)
  • On partitionne les $n$ variables en deux groupes :
    • $m$ variables de base ($x_B$) : associées à une sous-matrice carrée inversible $B$ de taille $m \times m$.
    • $n - m$ variables hors-base ($x_N$) : fixées arbitrairement à zéro ($x_N = 0$).
  • La valeur des variables de base est alors calculée par $x_B = B^{-1} b$.
  • Si $x_B \ge 0$, la solution de base est dite réalisable (SBR) : elle correspond exactement à un sommet du polyèdre géométrique !

3. Anatomie du Tableau du Simplexe

L’algorithme consigne tous les calculs dans un tableau matriciel structuré :

Basex1x2s1s2b (Solution)Ratio (b / a_col)
s1a11a1210b1b1 / a1k
s2a21a2201b2b2 / a2k
Δ (Coûts réduits)c1c200-Z (ou Z courant)—
Interprétation des coûts réduits (ligne Δ)

Le coût réduit $\bar{c}_j$ indique le gain marginal net obtenu sur la fonction objectif si l’on augmente la variable hors-base $x_j$ d’une unité :

  • Si $\bar{c}_j > 0$ : faire entrer $x_j$ dans la base va augmenter le profit $Z$.
  • Si tous les $\bar{c}_j \le 0$ : aucune variable ne peut augmenter le profit, la base courante est optimale.

4. L’Itération du Simplexe en 4 règles précises

Chaque itération du simplexe applique rigoureusement les quatre étapes suivantes :

Algorithme d’itération du simplexe en 4 étapes clés
1. Variable entrante (colonne pivot $k$)
$$k = \operatorname{argmax} \{ \bar{c}_j \mid \bar{c}_j > 0 \}$$

Si aucun $\bar{c}_j > 0$, la solution courante est optimale (STOP).

2. Variable sortante (ligne pivot $r$ — Test du ratio minimum)
$$r = \operatorname{argmin} \left\{ \theta_i = \frac{b_i}{a_{ik}} \;\middle|\; a_{ik} > 0 \right\}$$

Si tous les $a_{ik} \le 0$, le domaine est ouvert : le problème est non borné ($Z \to +\infty$).

3. Pivot de Gauss-Jordan

Le coefficient $p = a_{rk}$ est le pivot. On normalise la ligne du pivot : $L_r \leftarrow \frac{L_r}{p}$.

Pour chaque autre ligne $i ≠ r$ : $L_i \leftarrow L_i - a_{ik} L_r$ (élimination sur la colonne $k$).

Exercice 1 — Critère de Dantzig (Choix de la variable entrante)

Étude de cas Niveau 1 — Acquisition

Objectif : Identifier la variable hors-base entrante selon la règle du plus grand coût réduit.

Dans un problème de maximisation, la ligne d’indicateurs (coûts réduits $\bar{c}_j$) du tableau du simplexe guide l’amélioration de la solution :

  • Si tous les $\bar{c}_j \le 0$, la solution de base courante est optimale ;
  • Sinon, la variable entrante est celle qui possède le coût réduit le plus strictement positif $\max \bar{c}_j$ (règle de Dantzig). En cas d’égalité, on choisit l’indice le plus petit (règle de Bland pour éviter le cyclage).

Analysez les paramètres du problème pour chaque cas....
Si toutes les valeurs sont $\le 0$, Indiquez : OPTIMALITE_ATTEINTE.
Sinon, Indiquez : ENTRANTE: <nom_variable> COUT_REDUIT=<valeur à 2 décimales>.

Cas d’exemple
x1:4.0,x2:6.0,s1:0.0,s2:0.0
Résolution attendue
ENTRANTE: x2 COUT_REDUIT=6.00

x2 a le plus fort coût réduit positif (+6.0).

Deux indices, rédigés en mots
  1. Découpez par virgule puis chaque couple par deux-points.
  2. Cherche le maximum strictement positif. S’il n’y en a aucun, c’est optimal.

Exercice 2 — Règle du ratio minimum & variable sortante

Étude de cas Niveau 2 — Application

Objectif : Déterminer la variable de base sortante par le test du ratio minimum de Dantzig.

Une fois la colonne pivot $k$ choisie, la ligne sortante $r$ est déterminée par la règle du plus petit ratio strictement positif entre le second membre $b_i$ et l’élément de la colonne pivot $a_{ik}$ :
$$\theta = \min_{i \mid a_{ik} > 0} \left( \frac{b_i}{a_{ik}} \right)$$

Si aucun élément $a_{ik}$ n’est strictement positif ($a_{ik} \le 0$ pour toute la colonne), la solution est non bornée.

Analysez les paramètres du problème pour chaque cas...;a1k,a2k,....
Si aucun $a_{ik} > 0$, Indiquez : PROBLEME_NON_BORNE.
Sinon, Indiquez : SORTANTE: LIGNE_<numéro 1-indexé> MIN_RATIO=<theta à 2 décimales>.
(En cas d’égalité de ratio, choisis la ligne de plus petit indice pour briser l’équi-départ).

Cas d’exemple
18,42,24;2,3,4
Résolution attendue
SORTANTE: LIGNE_3 MIN_RATIO=6.00

Ratios : L1=18/2=9.0, L2=42/3=14.0, L3=24/4=6.0. Le minimum est en Ligne 3.

Deux indices, rédigés en mots
  1. Ignore les lignes où aik <= 0.
  2. Parcourez les ratios et retiens le minimum strictement positif.

Exercice 3 — Opération de pivotage de Gauss-Jordan

Étude de cas Niveau 3 — Raisonnement

Objectif : Effectuer un pivot complet de Gauss-Jordan sur une matrice de simplexe.

Le pivot de Gauss-Jordan sur l’élément de pivot $(r, c)$ d’une matrice $M$ s’effectue en deux étapes :

  1. Normaliser la ligne de pivot $r$ en divisant chaque coefficient par le pivot $p = M[r][c]$ ;
  2. Pour chaque autre ligne $i ≠ r$, éliminer le coefficient de la colonne $c$ en effectuant :
    $M[i][j] \leftarrow M[i][j] - M[i][c] \times M[r][j]$.

Analysez les paramètres du problème pour chaque cas...|L2_coeff1,L2_coeff2,...|...
où $r, c$ sont les indices 1-indexés du pivot (ligne $r$, colonne $c$).
Indiquez chaque ligne de la matrice résultante séparée par | avec les coefficients arrondis à 2 décimales séparés par des virgules :
<val11>,<val12>,... | <val21>,<val22>,....

Cas d’exemple
1,1;2,4,10|1,1,4
Résolution attendue
1.00,2.00,5.00 | 0.00,-1.00,-1.00

Pivot à la ligne 1, colonne 1 (valeur 2). L1 devient L1/2 = [1, 2, 5]. L2 devient L2 - 1*L1 = [0, -1, -1].

Deux indices, rédigés en mots
  1. Convertissez r et c en indices 0-indexés (r-1, c-1).
  2. Sauvegarde bien la ligne pivot normalisée avant de modifier les autres lignes.

6. QCM — niveau examen

Dans un tableau du simplexe en maximisation, à quel moment s’arrête l’algorithme avec la certitude d’avoir trouvé l’optimum ?

Si tous les coûts réduits sont $\le 0$, aucune variable hors-base ne peut améliorer la fonction objectif, la solution est optimale.

Selon le critère de Dantzig pour un problème MAX, quelle variable choisit-on pour entrer dans la base ?

La règle de Dantzig sélectionne la variable promettant le plus fort taux d’accroissement unitaire de la fonction objectif.

Pourquoi la règle du ratio minimum (b_i / a_ik) impose-t-elle de ne considérer que les coefficients a_ik strictement positifs (a_ik > 0) ?

Augmenter la variable entrante diminue les variables de base proportionnellement à $a_{ik}$. Si $a_{ik} > 0$, la variable de base s’annule à $b_i / a_{ik}$. Le ratio minimum garantit qu’aucune variable ne devient négative.

Que conclut l’algorithme du simplexe si, pour une variable entrante choisie, tous les coefficients de la colonne pivot sont négatifs ou nuls (a_ik ≤ 0) ?

Si aucun coefficient n’est positif, la variable entrante peut augmenter indéfiniment sans qu’aucune variable de base ne diminue : $Z \to +\infty$.

Quelle règle de brisure d’égalité (tie-breaking) permet de choisir la variable de plus petit indice pour éviter le phénomène de cyclage ?

La règle de Bland (Robert Bland, 1977) garantit formellement l’absence de bouclage infini en cas de dégénérescence.

Dans un problème standard avec m contraintes et n variables (n > m), combien de variables sont fixées à zéro (variables hors-base) dans une solution de base ?

Une base contient exactement $m$ variables. Les $n - m$ autres variables sont hors-base et ont pour valeur 0.

Après l’opération de pivot de Gauss-Jordan sur l’élément (r, c), que vaut l’élément de pivot lui-même et les autres coefficients de sa colonne ?

Le pivotage crée une colonne de la matrice identité : un 1 sur la ligne pivot $r$ et des 0 partout ailleurs.

Comment qualifie-t-on une solution de base réalisable dans laquelle au moins une variable de base a une valeur égale à zéro (b_i = 0) ?

La présence d’un zéro dans le vecteur de base caractérise la dégénérescence, où plus de $n$ hyperplans se coupent en un même sommet.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Calculer le ratio sur des coefficients négatifs ou nuls ($a_{ik} \le 0$), ce qui produit des ratios aberrants ou des divisions par zéro.
  • Oublier de mettre à jour la ligne de fonction objectif lors de l’élimination de Gauss-Jordan.
  • Pivoter sur un élément non nul mais sans diviser toute la ligne de pivot par la valeur du pivot pour obtenir un 1.
  • Déclarer l’optimalité alors qu’il subsiste au moins un coût réduit strictement positif dans la ligne $\Delta$.
  • Confondre le nom de la variable qui entre (en haut de la colonne pivot) et celui de la variable qui sort (à gauche de la ligne pivot).

8. Méthodologie de résolution

Protocole d’itération du Simplexe pas à pas
  1. Examiner la ligne des coûts réduits $\Delta$ : repérer le coefficient strictement positif le plus grand. Sa colonne est la colonne pivot $k$. Si aucun $\Delta_j > 0$, la solution est optimale.
  2. Pour chaque ligne $i$ ayant $a_{ik} > 0$, calculer le ratio $\theta_i = b_i / a_{ik}$. Identifier le ratio strictement positif le plus petit. Sa ligne est la ligne pivot $r$.
  3. Remplacer le nom de la variable de base sortante par celui de la variable entrante dans la colonne de gauche.
  4. Diviser tous les coefficients de la ligne $r$ par le pivot $p = a_{rk}$.
  5. Pour toutes les autres lignes $i ≠ r$ (y compris la ligne de fonction objectif), soustraire $a_{ik} \times L_r$ pour annuler le terme en colonne $k$.

9. Révision active

Résumé essentiel
  • Le Simplexe parcourt les sommets du polyèdre de proche en proche par pivotage matriciel.
  • Une Solution de Base Réalisable compte $m$ variables de base ($x_B \ge 0$) et $n - m$ variables hors-base ($x_N = 0$).
  • La variable entrante correspond au plus grand coût réduit $\bar{c}_j > 0$ (règle de Dantzig).
  • La variable sortante correspond au plus petit ratio $b_i / a_{ik}$ parmi les $a_{ik} > 0$ (règle du ratio minimum).
  • Le pivotage de Gauss-Jordan transforme la colonne pivot en colonne de la matrice identité ($1$ au pivot, $0$ ailleurs).

Checklist de maîtrise

  • Je sais identifier les variables en base et hors-base dans un tableau de simplexe.
  • Je sais sélectionner la variable entrante via la ligne des coûts réduits.
  • Je sais calculer les ratios et identifier la variable sortante sans diviser par un nombre négatif ou nul.
  • Je sais réaliser les opérations élémentaires de Gauss-Jordan pour mettre à jour le tableau.
  • Je reconnais les conditions d’arrêt : optimalité prouvée ou problème non borné.
