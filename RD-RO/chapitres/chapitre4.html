Chapitre 4 — Méthode des Deux Phases & Dualité Linéaire

Module 4 ≈ 2 h 50 de travail Réservé B2 et plus
Mise en situation

Lorsque toutes les contraintes sont de type $\le$ avec des seconds membres positifs, les variables d’écart forment immédiatement une base de départ triviale à l’origine ($s = b$). Mais dès qu’il existe des contraintes de type $\ge$ ou $=$, l’origine n’est pas réalisable et aucune base initiale n’apparaît spontanément. La méthode des Deux Phases permet de forcer l’accès à un premier sommet réalisable. Simultanément, la théorie de la dualité révèle que tout problème de production possède un jumeau économique qui calcule la valeur marginale exacte (le prix d’ombre) de chaque ressource rare de l’entreprise.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. comprendre pourquoi les contraintes $\ge$ et $=$ empêchent l’initialisation directe du simplexe ;
  2. introduire des variables artificielles ($a_i \ge 0$) et dérouler la Phase 1 pour tester la faisabilité du système ;
  3. enchaîner sur la Phase 2 pour déterminer la solution optimale réelle du problème d’origine ;
  4. construire systématiquement le programme dual à partir de n’importe quel programme primal canonique ;
  5. énoncer et exploiter les théorèmes faible et fort de la dualité pour borner et prouver l’optimalité ;
  6. appliquer le théorème des écarts complémentaires pour déduire la solution duale à partir de la solution primale ;
  7. donner l’interprétation managériale des variables duales comme prix d’ombre (shadow prices).

1. Le problème de l’initialisation : Pourquoi les variables artificielles ?

Si une contrainte est de type $\ge$, la mise sous forme standard donne :
$$a_1 x_1 + a_2 x_2 - e_1 = b_1 \quad (b_1 > 0)$$

Si l’on pose les variables de décision hors-base ($x_1 = 0, x_2 = 0$), on obtient :
$$-e_1 = b_1 \iff e_1 = -b_1 < 0$$

L’origine est irréalisable

Une variable d’excès ne peut pas être négative ($e_1 \ge 0$). L’origine $(0, 0)$ est en dehors du domaine de faisabilité. Il est donc impossible d’utiliser $e_1$ comme variable de base initiale !

La solution : on ajoute une variable artificielle fictive $a_1 \ge 0$ :
$$a_1 x_1 + a_2 x_2 - e_1 + a_1 = b_1$$
qui fournit le coefficient $+1$ nécessaire pour constituer la base identité de départ.

2. L’Algorithme des Deux Phases

Pour éliminer ces variables artificielles qui n’ont aucune existence physique réelle dans le problème, l’algorithme résout deux programmes linéaires consécutifs :

// PHASE 1 : Recherche d’une solution de base réalisable
Objectif   : MINIMISER la somme des variables artificielles : W = ∑ a_i
Résolution : On applique le simplexe classique sur ce critère artificiel.
Conclusion :
  - Si Min W > 0 : le problème d’origine est IRREALISABLE (domaine vide).
  - Si Min W = 0 : toutes les artificielles sont sorties de la base. On a trouvé
                   un premier sommet réalisable du problème d’origine !

// PHASE 2 : Optimisation du problème réel
- On supprime définitivement les colonnes des variables artificielles.
- On réinjecte la fonction objectif d’origine Z = ∑ cj * xj.
- On continue les itérations du simplexe jusqu’à l’optimum global Z*.

3. Théorie de la Dualité : Le Problème Miroir

À tout problème d’optimisation linéaire (appelé Primal) est intrinsèquement associé un autre problème linéaire (appelé Dual) qui contient exactement la même information sous un angle opposé :

CaractéristiqueProgramme PrimalProgramme Dual associé
ObjectifMAXIMISER $Z = c^T x$MINIMISER $W = b^T y$
Nombre de variables$n$ variables de décision $x_j$$m$ variables duales $y_i$
Nombre de contraintes$m$ contraintes de ressources$n$ contraintes duales
Matrice des coefficientsMatrice $A$ ($m \times n$)Matrice transposée $A^T$ ($n \times m$)
Coefficients économiquesVecteur coût $c$Seconds membres $b$

Règle d’or de transposition Primal-Dual

La $i$-ème contrainte primale correspond à la $i$-ème variable duale $y_i$.
La $j$-ème variable primale $x_j$ correspond à la $j$-ème contrainte duale.

4. Théorèmes fondamentaux & Prix d’Ombre

La relation mathématique entre primal et dual est régie par trois théorèmes d’une importance capitale :

Les trois grands théorèmes de la dualité
  • 1. Théorème faible de la dualité : pour toute solution réalisable $x$ du primal et toute solution réalisable $y$ du dual :
    $$Z(x) = c^T x \le b^T y = W(y)$$
    La valeur de tout plan primal réalisable est une borne inférieure pour le dual, et tout plan dual est un plafond pour le primal.
  • 2. Théorème fort de la dualité : si le primal admet une solution optimale finie $x^*$, alors le dual admet une solution optimale finie $y^*$ et :
    $$Z(x^*) = W(y^*)$$
    Le gap de dualité s’annule exactement à l’optimum !
  • 3. Théorème des écarts complémentaires (Karush-Kuhn-Tucker) : à l’optimum :
    $$y_i^* \times s_i^* = 0 \quad \text{et} \quad x_j^* \times e_j^* = 0$$
Interprétation managériale des Prix d’Ombre (Shadow Prices)

La variable duale $y_i^*$ représente le prix d’ombre (ou valeur marginale) de la ressource $i$ :

$$y_i^* = \frac{\partial Z^*}{\partial b_i}$$

C’est l’accroissement net du profit maximal $Z^*$ si l’entreprise parvient à acquérir une unité supplémentaire de la ressource $i$. Si la ressource est excédentaire ($s_i > 0$), son prix d’ombre est nul ($y_i = 0$) : payer pour en avoir plus ne rapporterait rien de plus !

Exercice 1 — Construction du problème Dual canonique

Python Niveau 1 — Acquisition

Objectif : Transposer un programme primal MAX en son programme dual MIN symétrique.

À tout programme primal sous forme canonique :
$$\text{MAX } Z = c_1 x_1 + c_2 x_2 \quad \text{sous } A x \le b, \quad x \ge 0$$correspond un programme dual associé :
$$\text{MIN } W = b_1 y_1 + b_2 y_2 \quad \text{sous } A^T y \ge c, \quad y \ge 0$$

Lit sur l’entrée standard une ligne au format c1,c2;a11,a12,b1;a21,a22,b2.
Génère et affiche le programme dual sur deux lignes :
Ligne 1 : MIN W=<b1>*y1 + <b2>*y2
Ligne 2 : CONTRAINTES: <a11>*y1 + <a21>*y2 >= <c1> | <a12>*y1 + <a22>*y2 >= <c2>.
(Les coefficients conservent leur format naturel).

Entrée du programme
3,5;1,2,6;3,1,9
Sortie attendue
MIN W=6*y1 + 9*y2
CONTRAINTES: 1*y1 + 3*y2 >= 3 | 2*y1 + 1*y2 >= 5

Objectif MIN W = 6*y1 + 9*y2. Transposée de [[1,2],[3,1]] = [[1,3],[2,1]].

Deux indices, rédigés en mots
  1. Remarque la transposition : la première contrainte duale utilise a11 et a21 (première colonne de A).
  2. La fonction objectif duale utilise les seconds membres b1 et b2 du primal.

Exercice 2 — Théorème fort de la dualité & Gap de dualité

Python Niveau 2 — Application

Objectif : Vérifier l’égalité des optimums primal et dual et calculer le gap de dualité.

D’après le théorème fort de la dualité, si le problème primal admet une solution optimale $x^*$, alors le problème dual admet une solution optimale $y^*$ telle que :
$$Z(x^*) = c^T x^* = b^T y^* = W(y^*)$$
Si les points testés ne sont pas encore optimaux, le théorème faible garantit que $Z(x) \le W(y)$, l’écart $W(y) - Z(x) \ge 0$ formant le gap de dualité.

Lit sur l’entrée standard une ligne au format c1,c2;x1,x2;b1,b2;y1,y2.
Calcule $Z = c_1 x_1 + c_2 x_2$, $W = b_1 y_1 + b_2 y_2$ et l’écart $gap = W - Z$.
Si $|gap| < 10^{-5}$, affiche :
OPTIMUM_ATTEINT Z=W=<valeur à 2 décimales> GAP=0.00.
Sinon, affiche :
NON_OPTIMAL Z=<Z à 2 décimales> W=<W à 2 décimales> GAP=<gap à 2 décimales>.

Entrée du programme
3,5;4,2;16,11;0.33,2.33
Sortie attendue
NON_OPTIMAL Z=22.00 W=30.91 GAP=8.91

Z = 3*4 + 5*2 = 22.0. W = 16*0.33 + 11*2.33 = 30.91. Gap de dualité = 8.91.

Deux indices, rédigés en mots
  1. Calcule z = c1*x1 + c2*x2 et w = b1*y1 + b2*y2.
  2. Si abs(w - z) < 1e-5, le gap est nul et l’optimum est prouvé.

Exercice 3 — Théorème des écarts complémentaires (Slackness)

Python Niveau 3 — Raisonnement

Objectif : Vérifier les conditions d’écarts complémentaires entre solutions primale et duale.

Le théorème des écarts complémentaires (Karush-Kuhn-Tucker) stipule qu’à l’optimum :

  • Pour toute contrainte de ressource $i$ : $y_i^* \times s_i^* = 0$.
    (Si une ressource est excédentaire $s_i > 0$, son prix d’ombre est nul $y_i = 0$ ; si $y_i > 0$, la ressource est saturée $s_i = 0$).
  • Pour toute variable de décision $j$ : $x_j^* \times e_j^* = 0$ (où $e_j$ est l’écart sur la contrainte duale).

Lit sur l’entrée standard une ligne au format :
s1,s2,...;y1,y2,... représentant les écarts primaux $s_i$ et les variables duales associées $y_i$.
Pour chaque couple $(s_i, y_i)$, vérifie si $s_i \times y_i = 0$ (avec tolérance $10^{-5}$).
Si toutes les conditions sont respectées, affiche :
COMPLEMENTARITE_VERIFIEE.
Sinon, liste les indices des contraintes en violation :
VIOLATION_CONTRAINTE_<i> (séparés par un espace).

Entrée du programme
0.0,4.5,0.0;1.2,0.0,3.5
Sortie attendue
COMPLEMENTARITE_VERIFIEE

C1: 0*1.2=0, C2: 4.5*0=0, C3: 0*3.5=0. Tout est nul.

Deux indices, rédigés en mots
  1. Découpe par ";" puis sépare les valeurs s et y.
  2. Une violation apparaît si abs(s * y) > 1e-5.

6. QCM — niveau examen

Pourquoi introduit-on des variables artificielles dans un problème de programmation linéaire ?

Les contraintes $\ge$ et $=$ ne fournissent pas de variable d’écart positive pour démarrer le simplexe ; les artificielles comblent ce manque.

Quel est l’objectif mathématique poursuivi lors de la Phase 1 de la méthode des Deux Phases ?

La Phase 1 cherche à faire tomber toutes les variables artificielles à zéro pour atteindre un premier sommet réalisable.

Que conclut-on si, à la fin de la Phase 1 du simplexe, la valeur minimale obtenue pour W est strictement positive (Min W > 0) ?

S’il est impossible d’annuler les variables artificielles, cela prouve qu’aucun point ne vérifie les contraintes réelles.

Si le programme primal est un MAX avec m contraintes et n variables, quelle est la structure de son programme dual canonique ?

La dualité inverse le sens d’optimisation (MAX devient MIN) et transpose les dimensions ($m$ contraintes deviennent $m$ variables, $n$ variables deviennent $n$ contraintes).

D’après le théorème fort de la dualité, que vaut la valeur optimale de la fonction objectif duale W(y*) par rapport à l’optimum primal Z(x*) ?

À l’optimum, le gap de dualité est nul : la valeur maximale du primal égale exactement la valeur minimale du dual.

Que stipule le théorème des écarts complémentaires si une ressource i est excédentaire à l’optimum (s_i* > 0) ?

L’orthogonalité impose $s_i^* \times y_i^* = 0$. Si une ressource n’est pas pleinement utilisée, disposer d’une unité supplémentaire n’apporte aucun gain marginal ($y_i^* = 0$).

Que représente concrètement pour un directeur d’usine le prix d’ombre (shadow price) d’une heure d’atelier de découpe ?

Le prix d’ombre mesure le surcroît de profit apporté par une unité marginale de ressource.

Si le programme primal est non borné (Z → +∞), que peut-on affirmer sur son programme dual d’après le théorème faible de la dualité ?

Puisque tout $y$ dual devrait être un plafond supérieur pour $Z$, si $Z \to +\infty$, aucun plafond fini ne peut exister, donc le dual est vide.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Oublier de changer le sens de l’optimisation lors du passage au dual (conserver MAX au lieu de MIN).
  • Conserver les colonnes des variables artificielles dans le tableau lors du passage de la Phase 1 à la Phase 2.
  • Croire qu’une variable duale nulle ($y_i = 0$) signifie que la ressource n’a aucune valeur pour l’entreprise, alors que cela signifie seulement qu’elle n’est pas saturée.
  • Transposer les coefficients sans transposer la matrice des contraintes ($A^T$).
  • Confondre le théorème faible ($Z \le W$) et le théorème fort ($Z^* = W^*$).

8. Méthodologie de résolution

Protocole de construction du Dual canonique
  1. S’assurer que le primal est sous forme canonique : MAX $Z = c^T x$ sous $A x \le b$ avec $x \ge 0$ (multiplier par $-1$ les contraintes $\ge$ si besoin).
  2. Poser l’objectif dual opposé : MIN $W = b^T y$ où les coefficients de $W$ sont les seconds membres $b$ du primal.
  3. Associer une variable duale $y_i \ge 0$ à chaque contrainte primale $i$.
  4. Construire les contraintes duales en transposant la matrice $A$ : la colonne $j$ de $A$ devient les coefficients de la contrainte duale $j$, et le second membre est le coût primal $c_j$.
  5. Poser les contraintes de signe duales : $y_i \ge 0$ pour chaque variable duale.

9. Révision active

Résumé essentiel
  • La Phase 1 minimise la somme des artificielles ($W = \sum a_i$) pour trouver une première solution réalisable sans biais.
  • Le Primal et le Dual sont deux faces de la même pièce : MAX $c^T x$ sous $A x \le b \iff$ MIN $b^T y$ sous $A^T y \ge c$.
  • Théorème fort : à l’optimum, $Z^* = c^T x^* = b^T y^* = W^*$ (gap de dualité nul).
  • Écarts complémentaires : $y_i^* \times s_i^* = 0$ (une ressource excédentaire a un prix d’ombre nul).
  • Le prix d’ombre $y_i^* = \frac{\partial Z^*}{\partial b_i}$ quantifie le gain marginal apporté par une unité de ressource supplémentaire.
