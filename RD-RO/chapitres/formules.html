Mémo synthétique de Recherche Opérationnelle

Toutes les formes matricielles, formules d’intersection, règles de pivotage, théorèmes de dualité, équations de transport et lois d’ordonnancement réunies sur une seule page de référence.

1. Forme Canonique & Forme Standard

// Forme Canonique (Primal MAX)
MAX Z = c1*x1 + c2*x2 + ... + cn*xn
sous :
  a_i1*x1 + a_i2*x2 + ... + a_in*xn ≤ b_i  (i = 1..m)
  x_j ≥ 0  (j = 1..n)

// Forme Standard
- Contrainte ≤ : ajouter variable d’écart s_i ≥ 0 → ∑ a_ij*x_j + s_i = b_i
- Contrainte ≥ : soustraire variable d’excès e_k ≥ 0 → ∑ a_kj*x_j - e_k = b_k
- Contrainte =  : contrainte stricte maintenue → ∑ a_lj*x_j = b_l

2. Géométrie & Règle de Cramer (2 variables)

// Intersection de deux droites frontières actives
L1 : a1 * x1 + b1 * x2 = c1
L2 : a2 * x1 + b2 * x2 = c2

Déterminant principal : Δ = a1 * b2 - a2 * b1
Si Δ ≠ 0 :
  x1 = (c1 * b2 - c2 * b1) / Δ
  x2 = (a1 * c2 - a2 * c1) / Δ
Si Δ = 0 : droites parallèles ou confondues.

3. Algorithme du Simplexe (Tableau de Dantzig)

// 1. Critère de Dantzig (Variable entrante)
k = argmax { Δj | Δj > 0 }  (coût réduit le plus strictement positif)
Arrêt optimal : ssi tous les Δj ≤ 0.

// 2. Règle du ratio minimum (Variable sortante)
θ = min { b_i / a_ik | a_ik > 0 }
La ligne r correspondant à θ sort de la base.
Arrêt non borné : ssi tous les a_ik ≤ 0 dans la colonne pivot.

// 3. Opération de pivot de Gauss-Jordan (sur pivot p = A[r][k])
Ligne pivot : Lr ← Lr / p
Autres lignes : Li ← Li - A[i][k] * Lr

4. Théorie de la Dualité & Prix d’Ombre

// Transposition Primal / Dual
PRIMAL (MAX)                 DUAL (MIN)
MAX Z = c^T * x      ↔      MIN W = b^T * y
sous A * x ≤ b              sous A^T * y ≥ c
avec x ≥ 0                   avec y ≥ 0

// Théorèmes fondamentaux
1. Théorème faible : Z(x) ≤ W(y) pour tous x et y réalisables.
2. Théorème fort   : à l’optimum, Z(x*) = W(y*) (gap nul).
3. Écarts complémentaires : y_i* * s_i* = 0  et  x_j* * e_j* = 0

// Prix d’ombre (Shadow price)
y_i* = ∂Z* / ∂b_i (gain marginal apporté par une unité de ressource i).

5. Problème de Transport & Méthode MODI

// Matrice équilibrée
∑_{i=1}^m O_i = ∑_{j=1}^n D_j  (sinon : ajouter une entité fictive à coût nul)

// Potentiels de lignes (u_i) et de colonnes (v_j)
Pour chaque cellule de base (occupée) : u_i + v_j = c_ij  (poser u_1 = 0)

// Évaluation des cellules vides
Δ_ij = c_ij - (u_i + v_j)
- Solution optimale ssi tous les Δ_ij ≥ 0.
- Si min Δ_ij < 0 : cycle du marchepied (stepping-stone) avec transfert θ.

6. Ordonnancement PERT / CPM & Ford-Fulkerson

// PERT / MPM (Calcul aller-retour)
Forward pass  : ES(j) = max_{p ∈ Pred(j)} (ES(p) + d_p),   EF(j) = ES(j) + d_j
Durée projet  : max EF(t)
Backward pass : LF(i) = min_{s ∈ Succ(i)} LS(s),           LS(i) = LF(i) - d_i
Marge Totale  : MT(i) = LF(i) - ES(i) - d_i = LS(i) - ES(i)
Marge Libre   : ML(i) = min_{s} ES(s) - ES(i) - d_i
Chemin critique : ensemble des tâches de marge totale nulle (MT = 0).

// Flots de Ford-Fulkerson
Capacité résiduelle : r(u, v) = c(u, v) - f(u, v)
Goulot d’étranglement d’une chaîne augmentante : Δ = min r(u, v)
Théorème Max-Flow Min-Cut : Valeur maximale du Flot = Capacité de la Coupe minimale.
