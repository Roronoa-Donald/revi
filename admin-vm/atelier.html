Atelier de code

Un éditeur dans la page, un vrai interpréteur PowerShell derrière. Écrivez un script d’administration, exécutez-le et lisez ce qu’il affiche : c’est ici qu’une règle du cours devient un script qui tourne.

Comment fonctionne l’atelier
  • Exécuter fait tourner votre script PowerShell tel quel, et affiche sa sortie, ses erreurs et son code de sortie.
  • Entrée du programme contient ce que lira [Console]::In.ReadLine(), une valeur par ligne.
  • Expliquer mon erreur demande au tuteur, quand il y a une erreur, pourquoi elle survient et par où chercher. Il explique en mots : il n’écrit jamais de code à votre place.
  • Le raccourci Ctrl + Entrée exécute le script sans quitter l’éditeur.
  • Votre code est conservé dans ce navigateur, par exercice et par cours.

PowerShell

Objectif : expérimenter sans conséquence. Reprenez un mécanisme du cours (condition, boucle, switch) et programmez-le sur des cas limites.

Le script proposé calcule combien de VM une mémoire peut accueillir. Modifiez-le, ajoute une condition, un switch, remplace tout le script par le mécanisme que vous voulez vérifier — un quorum, une surallocation de vCPU, un espace de volume.

Dans un vrai serveur, ce sera un script d’audit planifié : la structure — lire, traiter, afficher — reste exactement la même.

De la page au vrai serveur

La simulation a une limite assumée : rien n’est envoyé ni stocké durablement. Elle a une force : toute la logique se vérifie sans machine Windows. Quand le script affiche les bons résultats sur vos cas limites, le portage est mécanique.

Les trois erreurs que l’atelier révèle immédiatement
  • Comparaison avec == : PowerShell compare les chaînes avec -eq.
  • Division entière : sans [math]::Floor, le résultat peut être décimal.
  • Boucle infinie : un $i jamais incrémenté ne s’arrête pas.
Ce que fait l’atelier, côté technique
  • Votre code est envoyé à ce serveur, qui le transmet à un service d’exécution isolé : rien ne tourne sur votre machine.
  • La clé du service reste sur le serveur ; le navigateur ne la voit jamais.
  • Le nombre d’exécutions est limité par jour, pour tout le monde.

Ensuite

Les 6 chapitres contiennent chacun trois exercices corrigés dans la page. Ils sont la meilleure façon de vérifier que le mécanisme est vraiment acquis.
