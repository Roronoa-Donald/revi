Examen blanc n°1 — virtualisation et architecture

Sujet type examen — types de virtualisation, hyperviseurs, prérequis, plans.

Exercice 1/5 — Hyperviseurs

Distinguez un hyperviseur de type 1 et de type 2. Donnez un exemple de chacun et un contexte d’usage.

Corrigé
Type 1 (bare-metal) : s’installe directement sur le matériel, pour la production — ESXi, Proxmox VE.
Type 2 (hébergé) : s’installe sur un OS existant, pour les tests et la formation — VirtualBox, VMware Workstation.
Exercice 2/5 — Architecture

Un hyperviseur réunit deux plans. Lesquels, et à quoi sert chacun ?

Corrigé
Plan de données : exécution des VM et entrées/sorties. Plan de gestion : interface, API, rôles et audit.
Les confondre expose toute la plateforme.
Exercice 3/5 — Prérequis

Pourquoi la RAM est-elle plus critique que la CPU dans une plateforme virtualisée ?

Corrigé
Le CPU se partage dans le temps (vCPU), tandis que la RAM est non élastique : chaque VM en consomme une part fixe. C’est donc la RAM qui limite le nombre de VM hébergeables.
Exercice 4/5 — Types

Citez les quatre grands types de virtualisation et un exemple pour chacun.

Corrigé
Serveur (Proxmox/ESXi), poste/VDI (VMware Horizon), stockage (NAS/SAN, Ceph), réseau (VLAN, pfSense).

Examen blanc n°2 — stockage, réseau et clusters

Sujet orienté stockage, segmentation réseau et haute disponibilité.

Exercice 1/5 — Stockage

Expliquez LVM en trois notions et l’intérêt d’un volume logique.

Corrigé
PV (disque physique), VG (pool regroupant les PV), LV (volume logique).
Le LV devient le disque d’une VM et peut être agrandi sans réinstaller.
Exercice 2/5 — Sauvegarde

Quelle différence entre un snapshot et une sauvegarde ? Pourquoi un snapshot ne suffit-il pas ?

Corrigé
Le snapshot est local et rapide : il permet un retour en arrière immédiat.
La sauvegarde est une copie externe durable.
Le snapshot repose sur le même stockage : s’il disparaît, la VM aussi. Règle : 3 copies, 2 supports, 1 hors site.
Exercice 3/5 — Réseau

Une agence héberge un site web et un ERP interne. Proposez une segmentation et une règle de pare-feu.

Corrigé
Web en DMZ (VLAN 30), ERP en LAN (VLAN 20), utilisateurs en VLAN 10.
Pare-feu : LAN et DMZ uniquement sur le port 443. La base de données reste dans le LAN.
Exercice 4/5 — Cluster

À quoi servent le quorum et le fencing dans un cluster ?

Corrigé
Le quorum garantit la prise de décision (majorité des nœuds) ; le fencing isole un nœud instable pour éviter le « split brain ». Ensemble, ils rendent le failover fiable.
