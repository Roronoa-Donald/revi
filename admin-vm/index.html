Admin VM B2 — virtualisation, stockage, réseau et haute disponibilité

Administrer des machines virtuelles, c’est comprendre sur quoi elles reposent et comment elles se partagent. Six chapitres pour choisir un hyperviseur, vérifier ses prérequis, cycler une VM, structurer le stockage, cloisonner le réseau et administrer un cluster — chaque mécanisme étant prolongé par un script PowerShell.

Ce que tu sauras faire à la fin du cours
  • définir la virtualisation et choisir un hyperviseur adapté (type 1 / type 2) ;
  • vérifier les prérequis et distinguer plan de données et plan de gestion ;
  • cycler une VM : conception, provisioning, exploitation, retrait ;
  • structurer le stockage (LVM, NFS/iSCSI) et une stratégie de sauvegarde GFS ;
  • cloisonner le réseau (bridge, VLAN, DMZ, pare-feu) ;
  • administrer un cluster : ressources, quorum, migration, sauvegarde et sécurité.
Comment ce cours s’articule

Les sept modules historiques du cours Admin VM sont condensés en six chapitres, du plus conceptuel au plus opérationnel. Le chapitre 1 est en accès libre.

Chaque chapitre se termine par trois exercices de code en PowerShell : tu écris un script d’administration qui lit l’entrée standard et produit un résultat, puis tu le valides. L’atelier de code permet de manipuler librement.
