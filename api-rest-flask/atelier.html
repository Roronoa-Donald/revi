Atelier de code Python / API REST

Un éditeur Monaco intégré à la page, relié au moteur d’exécution Python. Écris ton script, exécute-le et observe immédiatement la sortie : l’outil idéal pour prototyper la logique de tes endpoints.

Comment fonctionne l’atelier
  • Exécuter fait tourner votre code Python 3 et affiche sa sortie standard et ses éventuelles erreurs.
  • Entrée du programme contient ce que sys.stdin recevra en entrée standard.
  • Expliquer mon erreur sollicite le tuteur IA pour comprendre l’origine d’un bug sans dévoiler la solution.
  • Le raccourci Ctrl + Entrée exécute le script directement depuis l’éditeur.
  • Vos modifications sont automatiquement sauvegardées dans votre navigateur.

De la logique algorithmique aux routes Flask

Le moteur d’exécution évalue la logique Python pure de vos endpoints (parsing JSON, validation de schémas, formatage de codes de statut). Cette logique se transpose à l’identique dans vos vues @app.route réelles sur vos serveurs.

Les erreurs courantes décelées par l’atelier
  • Oubli de gestion des clés absentes : privilégier dict.get() avec valeur par défaut plutôt que dict[cle] qui lève KeyError.
  • Conversions de types non protégées : encadrer int() ou float() dans un bloc try / except.
  • Guillemets JSON non conformes : se rappeler que JSON exige des guillemets doubles stricts.
Architecture technique du bac à sable
  • Votre script est envoyé de manière sécurisée au service d’exécution isolé sans dépendance locale.
  • Toutes les exécutions respectent les quotas de sécurité de la plateforme.
  • Le résultat s’affiche en temps réel dans la console intégrée sous l’éditeur.
