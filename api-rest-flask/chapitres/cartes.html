Module 1 — API Web & le protocole HTTP

QuestionQue signifie l’acronyme API ?
RéponseApplication Programming Interface (Interface de programmation d’application).
QuestionQuels sont les 4 composants d’une requête HTTP ?
RéponseLa ligne de requête (méthode + chemin + version), les en-têtes, la ligne vide et le corps (body).
QuestionÀ quoi sert l’en-tête Content-Type ?
RéponseÀ indiquer le type MIME des données envoyées dans le corps (ex. application/json).
QuestionQuelle est la différence entre Content-Type et Accept ?
RéponseContent-Type décrit le format des données envoyées ; Accept décrit le format attendu en réponse.
QuestionQuels guillemets sont obligatoires pour les chaînes et clés en JSON ?
RéponseLes guillemets doubles strictes ("...").
QuestionComment débute la Query String dans une URL ?
RéponsePar un point d’interrogation (?) suivi de couples clé=valeur séparés par des esperluettes (&).

Module 2 — Architecture REST & modélisation des ressources

QuestionQue signifie REST ?
RéponseRepresentational State Transfer (Transfert d’état représentationnel).
QuestionPourquoi les URI REST ne doivent-elles pas contenir de verbes ?
RéponseParce que l’URI identifie la ressource ciblée, tandis que le verbe HTTP exprime l’action réalisée.
QuestionQu’est-ce qu’une opération idempotente ?
RéponseUne opération dont l’exécution répétée plusieurs fois produit exactement le même effet qu’une seule exécution.
QuestionLe verbe POST est-il idempotent ?
RéponseNon : réexécuter une requête POST crée plusieurs ressources distinctes.
QuestionQuelle est la différence fondamentale entre PUT et PATCH ?
RéponsePUT remplace l’intégralité de la ressource, tandis que PATCH modifie uniquement les champs ciblés.
QuestionQuels sont les verbes HTTP considérés comme sûrs (safe) ?
RéponsePrincipalement GET, HEAD et OPTIONS, car ils n’altèrent pas les données du serveur.

Module 3 — Démarrage avec Flask & Routage

QuestionComment instancie-t-on une application Flask minimale ?
Réponseapp = Flask(__name__)
QuestionComment restreindre une route Flask aux méthodes POST et PUT ?
Réponse@app.route("/...", methods=["POST", "PUT"])
QuestionQue fait le convertisseur <int:id> si un texte est passé dans l’URL ?
RéponseFlask renvoie automatiquement une erreur 404 Not Found sans appeler la fonction.
QuestionComment lire un paramètre d’URL optionnel ?page=2 dans Flask ?
Réponsepage = request.args.get("page", 1, type=int)
QuestionQue renvoie request.get_json() si le client n’a pas envoyé de Content-Type: application/json ?
RéponseElle renvoie None (par défaut).
QuestionQuelle erreur HTTP est renvoyée si la méthode de la requête n’est pas dans methods ?
Réponse405 Method Not Allowed.

Module 4 — Codes d’état HTTP & réponses JSON

QuestionQuel statut HTTP indique qu’une ressource a été créée avec succès ?
Réponse201 Created.
QuestionQuel statut HTTP est idéal pour une suppression réussie sans données retournées ?
Réponse204 No Content.
QuestionQuelle est la différence entre 401 et 403 ?
Réponse401 signifie que l’identité du client n’est pas vérifiée (non connecté), 403 signifie qu’il est connecté mais n’a pas la permission requise.
QuestionQuel code de statut correspond à un email déjà présent en base lors d’une inscription ?
Réponse409 Conflict.
QuestionComment Flask permet-il de préciser un code de statut personnalisé ?
RéponseEn renvoyant un tuple (jsonify(...), code), par exemple return jsonify(data), 201.
QuestionQuel en-tête HTTP est automatiquement positionné par jsonify() ?
RéponseContent-Type: application/json.

Module 5 — Validation des données & gestion d’erreurs

QuestionQuelle fonction Flask interrompt immédiatement une requête avec un code HTTP ?
Réponseabort(code, description="...")
QuestionComment intercepter les erreurs 404 dans toute l’application Flask ?
Réponse@app.errorhandler(404) placé au-dessus d’une fonction renvoyant du JSON.
QuestionQu’est-ce que le principe de Whitelisting pour un payload JSON ?
RéponseNe conserver que les champs explicitement autorisés et ignorer toute clé inconnue ou sensible.
QuestionQuelle commande cURL envoie une requête POST avec un corps JSON ?
Réponsecurl -X POST -H "Content-Type: application/json" -d '{"clé":"valeur"}' <URL>
QuestionComment simuler une requête dans un test unitaire Flask sans lancer le serveur ?
Réponseclient = app.test_client() puis reponse = client.get("/...")
QuestionQuel code de statut est adapté lorsqu’un corps JSON est vide ou malformé ?
Réponse400 Bad Request.

Module 6 — Mini API complète & persistance

QuestionQuel est l’intérêt majeur d’un Blueprint dans Flask ?
RéponseDécouper l’application en modules fonctionnels indépendants et réutilisables.
QuestionComment définir un préfixe commun pour toutes les routes d’un Blueprint ?
RéponseEn passant url_prefix="/..." lors de l’instanciation du Blueprint.
QuestionPourquoi app.run(debug=True) est-il interdit en production ?
RéponseCar le débogueur interactif de Flask permet d’exécuter du code arbitraire sur le serveur.
QuestionQuel serveur WSGI est couramment utilisé en production avec Flask ?
RéponseGunicorn (Green Unicorn).
QuestionQu’est-ce qu’OpenAPI / Swagger ?
RéponseUne spécification universelle de description et de documentation interactive des API REST.
QuestionQue fait la méthode to_dict() sur un modèle SQLAlchemy ?
RéponseElle convertit l’objet modèle en dictionnaire Python prêt à être sérialisé en JSON par jsonify().
