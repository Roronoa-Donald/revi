Mémo syntaxe REST & Flask

Toutes les structures, méthodes et syntaxes indispensables de REST et Flask réunies sur une seule page. À garder ouvert pendant vos ateliers pratiques.

1. Protocole HTTP & En-têtes

// Requête HTTP type
POST /api/v1/articles HTTP/1.1
Host: api.monsite.fr
Content-Type: application/json
Accept: application/json

{"titre": "Guide", "prix": 29.9}

// En-têtes clés
Content-Type : format du corps envoyé (application/json)
Accept       : format souhaité en retour
Authorization: jeton d’accès (Bearer <token>)

2. Conception REST & Verbes canoniques

GET    /ressources       # Lister la collection (sûr, idempotent)
GET    /ressources/42    # Consulter l’élément 42 (sûr, idempotent)
POST   /ressources       # Créer un élément (non-sûr, NON-idempotent) -> 201 Created
PUT    /ressources/42    # Remplacer complètement l’élément 42 (idempotent) -> 200 OK
PATCH  /ressources/42    # Modifier partiellement l’élément 42 (non-sûr) -> 200 OK
DELETE /ressources/42    # Supprimer l’élément 42 (idempotent) -> 204 No Content

@app.route("/articles/<string:slug>")         # Chaîne standard sans slash

4. Inspection de la requête (request)

# Paramètres de Query String (?page=2&limit=10)
page = request.args.get("page", 1, type=int)

# En-têtes HTTP de la requête
token = request.headers.get("Authorization")

# Corps JSON parsé en dict / list Python
payload = request.get_json()  # Renvoie None si Content-Type non JSON

5. Codes d’état HTTP & Réponses JSON

# Réponse de succès standard (200 OK)
return jsonify(data), 200

# Création réussie avec en-tête de localisation (201 Created)
return jsonify(nouvel_objet), 201, {"Location": f"/items/{nouvel_objet['id']}"}

# Suppression réussie sans corps (204 No Content)
return "", 204

# Erreur standardisée
return jsonify({"code": 404, "error": "Not Found", "message": "Introuvable"}), 404

6. Validation, Gestion d’erreurs & Blueprints

# Interruption contrôlée avec abort
if not item:
    abort(404, description="Ressource absente")

# Gestionnaire d’erreur global unifié
@app.errorhandler(404)
def introuvable(err):
    return jsonify({"code": 404, "error": "Not Found", "message": getattr(err, "description", "")}), 404

# Modularité avec Blueprint
from flask import Blueprint
bp = Blueprint("api_v1", __name__, url_prefix="/api/v1")
app.register_blueprint(bp)
