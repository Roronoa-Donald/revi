Projet fil conducteur : La BookStore API REST complète

Ce projet intègre l’ensemble des notions du cours dans une API de production organisée en Blueprints modulaires.

Étape 1 : Conception des ressources & Endpoints

Définir le contrat d’API pour la ressource /livres :

  • GET /api/v1/livres : lister tous les livres avec filtres (?genre=roman&dispo=true).
  • GET /api/v1/livres/<int:id> : détail d’un livre spécifique (404 si absent).
  • POST /api/v1/livres : ajout d’un nouvel ouvrage avec validation du corps (201 Created).
  • PATCH /api/v1/livres/<int:id> : modification partielle (prix, disponibilité).
  • DELETE /api/v1/livres/<int:id> : suppression définitive (204 No Content).

Étape 3 : Validation défensive & Whitelisting

Filtrer les attributs et vérifier les types avant toute insertion :

CHAMPS_VALIDES = {"titre": str, "auteur": str, "prix": (int, float), "disponible": bool}

def valider_payload(data):
    for champ, t in CHAMPS_VALIDES.items():
        if champ not in data or not isinstance(data[champ], t):
            abort(400, description=f"Champ {champ} invalide ou manquant")
