Mémo synthétique d’Assembleur & Architecture Machine

Toutes les structures de registres, formules d’adressage, mnémoniques d’instructions, drapeaux EFLAGS et conventions d’appel réunies sur une seule page de référence.

1. Hiérarchie des registres x86_64

// Registre 64 bits RAX et son découpage hiérarchique
+---------------------------------------------------------------+
| RAX (64 bits)                                                 |
+-------------------------------+-------------------------------+
                                | EAX (32 bits)                 |
                                +---------------+---------------+
                                                | AX (16 bits)  |
                                                +-------+-------+
                                                | AH(8) | AL(8) |
                                                +-------+-------+

// Rôles conventionnels des registres généraux en x86 / x86_64 :
- RAX / EAX : Accumulateur principal, valeur de retour des fonctions
- RBX / EBX : Registre de base pour l’adressage mémoire (préservé par l’appelé)
- RCX / ECX : Compteur pour les boucles (LOOP) et décalages (CL pour SHL/SHR)
- RDX / EDX : Registre de données, opérande auxiliaire (multiplication/division)
- RSI / ESI : Source Index pour les copies de chaînes (Source)
- RDI / EDI : Destination Index pour les copies de chaînes (Destination, 1er arg x64)
- RSP / ESP : Pointeur du sommet de la pile (Stack Pointer)
- RBP / EBP : Pointeur de base du cadre d’activation (Frame / Base Pointer)
- RIP / EIP : Pointeur de la prochaine instruction à exécuter (Instruction Pointer)

2. Registre d’état EFLAGS

// Les 4 drapeaux essentiels testés par les sauts conditionnels :
- ZF (Zero Flag)     : ZF = 1 si le résultat de l’opération est nul (0), sinon ZF = 0
- CF (Carry Flag)    : CF = 1 en cas de retenue/emprunt non signé (> 255 ou A < B)
- SF (Sign Flag)     : SF = 1 si le bit de poids fort vaut 1 (résultat signé négatif)
- OF (Overflow Flag) : OF = 1 si un débordement arithmétique signé se produit (-128..+127)

// Règle d’Overflow en addition signée : A + B
Deux opérandes de même signe produisent un résultat de signe opposé.

3. Modes d’adressage complet x86

// Formule de calcul d’adresse effective (Load Effective Address) :
Adresse = Base + (Index × Scale) + Déplacement

- Base        : n’importe quel registre général (ex. RBX, RBP)
- Index       : n’importe quel registre général sauf RSP
- Scale       : facteur d’échelle valant 1, 2, 4 ou 8 (taille des éléments)
- Déplacement : constante immédiate sur 8 ou 32 bits

Exemples :
MOV EAX, [EBX]                   ; Adressage indirect simple
MOV EAX, [EBX + 8]               ; Base + déplacement constant
MOV EAX, [EBX + ECX*4]           ; Base + index × échelle (tableau d’entiers 32 bits)
LEA EAX, [EBX + ECX*4 + 16]      ; Calcule l’adresse sans toucher à la mémoire !

6. Convention d’appel cdecl (Pile 32 bits)

// 1. Prologue standard de fonction :
push ebp             ; Sauvegarde l’ancien cadre de pile
mov  ebp, esp        ; Établit le nouveau cadre de référence fixe
sub  esp, 16         ; Alloue 16 octets pour les variables locales

// 2. Accès aux données via EBP :
- Paramètre 1 : [ebp + 8]
- Paramètre 2 : [ebp + 12]
- Variable locale 1 : [ebp - 4]
- Variable locale 2 : [ebp - 8]

// 3. Épilogue standard & Retour :
mov  eax, [ebp - 4]  ; Place la valeur de retour dans EAX
mov  esp, ebp        ; Libère les variables locales
pop  ebp             ; Restaure le cadre de pile de l’appelant
ret                  ; Dépile l’adresse de retour et saute
