Le métier d’administrateur

definition : gestion des programmes donnant acces a la

  machine et a ses peripheriques dans un parc



taches (CALMS) : Comptes / Assistance / Logiciels /

  Materiel / Securite (+ maintenance 1er niveau)

qualites : technicite / rigueur / bon sens

types : poste de travail / serveurs / reseau



outils Windows : Gestionnaire des taches /

  Gestion de l ordinateur (utilisateurs, evenements,

  services, stockage) / Analyseur de performance /

  Gestionnaire de securite

L’administrateur est en première ligne : c’est lui qu’on appelle… et qu’on incrimine.

Windows Server 2012 R2 : éditions et installation

chronologie : 1985 Win 1.0 / annees 90 NT /

  2003 1er Windows Server / 2008-2012-2016-2019-2022



editions 2012 : Foundation 15 u, sans VM, 1 CPU,

  physique / Essential 25 u, 2 CPU / Standard 2 VM /

  Datacenter VM illimitees

options : Server Core (moins de surface d attaque)

  ou interface graphique (bascule possible, DISM)

requis : 3,1 GHz 64 bits / RAM 2 Go (8 conseilles) /

  60 Go disque / Gigabit Ethernet

session : SAM locale machine\user / domaine

  NETBIOS\login ou login@domaine

Standard et Datacenter ont les mêmes fonctions : seule la licence VM les distingue.

Configuration initiale du serveur

gestionnaire de serveur : tableau de bord (roles,

  groupes de serveurs) / serveur local (nom, pare-feu,

  IP, bureau a distance) / outils / notifications



pare-feu : 3 profils a traiter (domaine, prive, public)

  netsh advfirewall set allprofiles state off

  Set-NetFirewallProfile -Profile Domain,Public,Private

    -Enabled False

nom : netdom renamecomputer ACTUEL /NewName:NOUVEAU

  puis shutdown /r

IP : New-NetIPAddress -InterfaceIndex 12 -IPAddress

  192.168.1.203 -PrefixLength 24 -DefaultGateway ...

  (ifIndex par Get-NetAdapter ; ActiveStore applique,

  PersistentStore conserve apres reboot)

activation : slmgr.vbs /ipk CLE puis /ato (ou sconfig 11)

distant : bureau a distance, Enable-PSRemoting -Force

Un profil de pare-feu oublié = une panne qui n’apparaît que sur ce réseau.

Active Directory : notions

hierarchie : domaine ⊂ arbre ⊂ foret

domaine : entite logique (objets + strategies)

succursales : cdp.org racine, paris.cdp.org et

  lome.cdp.org = domaines enfants

arbre : domaines a espace de nom contigu

foret : regroupement d arbres independants

renommage d un domaine : possible mais tres lourd

  (PC, utilisateurs, services, logiciels)

Le nom du domaine se choisit une fois, une fois pour toutes.

Installer un contrôleur de domaine

1. role : Gerer → Ajouter des roles → AD DS

   (binaires installes, PAS encore configure)

2. promotion : bandeau jaune → Promouvoir ce serveur

   → Ajouter une nouvelle foret → nom du domaine

3. niveau fonctionnel : le plus haut (2012 R2)

4. mot de passe DSRM (restauration AD) : solide

5. avertissement DNS : AD DS exige le DNS

6. dossiers : base NTDS.DIT / journaux / SYSVOL

   (scripts de connexion, GPO, replication)

7. verification des prerequis → redemarrage OBLIGATOIRE

PowerShell : Install-WindowsFeature AD-Domain-Services

  puis Install-ADDSForest

Où sont les GPO ? Dans SYSVOL — question d’examen classique.

Gérer les objets AD DS

console : Utilisateurs et ordinateurs AD

ordre : UO (rangement) → groupes → utilisateurs

utilisateur : formulaire + UPN (iziti@ntic.ma)

  + option « doit changer le mot de passe »

  + onglet Compte : horaires d acces

groupes : securite (droits) / distribution (diffusion)

  etendue : Globale (cas courant du support)

jointure domaine : DNS du client = DNS du domaine,

  puis changement d appartenance, puis reboot

profil itinerant : profil synchronise sur le serveur,

  suit l utilisateur de poste en poste

PowerShell : New-ADUser / Set-ADUser / Get-ADUser

Droits aux groupes, jamais aux utilisateurs isolés : la règle d’or.

Erreurs fréquentes à éviter

  • Confondre Standard (2 VM) et Datacenter (VM illimitées).
  • Oublier un profil du pare-feu (domaine, privé, public).
  • Ajouter une IP sans supprimer l’ancienne (Remove-NetIPAddress).
  • Confondre ActiveStore (applique) et PersistentStore (conserve).
  • S’arrêter après l’installation du rôle AD DS : la promotion reste à faire.
  • Nom de domaine irréel : le renommage coûte très cher.
  • Mot de passe DSRM bâclé : c’est la clé de secours de l’AD.
  • Donner des droits à des utilisateurs au lieu de groupes.
  • Joindre un poste au domaine sans corriger son DNS.
  • Oublier le redémarrage obligatoire après la promotion.
