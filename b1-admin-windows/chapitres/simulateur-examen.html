Simulateur d’examen

Deux sujets blancs chronométrés, dans l’esprit de l’épreuve (durée 2 h, /20). Fais-les sans regarder les corrigés, puis corrige-toi sévèrement.

Chronomètre d’examen — 2 h

Lance le chrono quand tu commences un sujet. Ne consulte le corrigé qu’à la fin. Réserve 15 min de relecture : familles de tâches, éditions, commandes de configuration, hiérarchie AD, étapes de promotion, objets du domaine.

Examen blanc n°1

Sujet type épreuve — métier, éditions, configuration initiale.

Exercice 1/5 — Métier

Définir l’administration système. Citer les familles de tâches, les trois qualités et les trois types d’administration.

Corrigé
Gestion de l’ensemble des programmes permettant d’accéder à une machine et d’utiliser ses périphériques dans un parc. Tâches : comptes, assistance, logiciels, matériel, sécurité (+ maintenance de premier niveau). Qualités : technicité, rigueur, bon sens. Types : poste, serveurs, réseau.
Exercice 2/5 — Éditions

Une TPE de 12 utilisateurs sans virtualisation, puis une entreprise prévoyant 10 VM : quelle édition pour chacun ? Justifier.

Corrigé
TPE : Foundation (15 utilisateurs max, sans virtualisation, machine physique). 10 VM : Datacenter (VM illimitées) — Standard couvrirait seulement 2 VM par licence.
Exercice 3/5 — Session

Écrire les trois syntaxes d’ouverture de session et dire ce qu’est la SAM.

Corrigé
Locale : machine\utilisateur (base SAM). Domaine : NETBIOS\login ou login@domaine. La SAM (Security Account Manager) est la base de données des comptes locaux, composant du registre.
Exercice 4/5 — Configuration

Citer les commandes : pare-feu sur les trois profils (netsh et PowerShell), renommage, IP statique 192.168.1.203/24 sur l’ifIndex 12.

Corrigé
netsh advfirewall set allprofiles state off ; Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled False ; netdom renamecomputer ACTUEL /NewName:NOUVEAU puis shutdown /r ; New-NetIPAddress -InterfaceIndex 12 -IPAddress 192.168.1.203 -PrefixLength 24 (+ passerelle), vérification ipconfig /all.

Examen blanc n°2 — variante

Sujet orienté Active Directory : notions, installation, objets.

Exercice 1/5 — Notions

Définir domaine, arbre, forêt. Construire l’arborescence de cdp.org avec deux succursales (Paris, Lomé).

Corrigé
Domaine : entité logique hébergeant objets et stratégies. Arbre : domaines à espace de nom contigu. Forêt : regroupement d’arbres indépendants. Arborescence : racine cdp.org, enfants paris.cdp.org et lome.cdp.org.
Exercice 2/5 — Installation

Dérouler les étapes de l’installation d’un contrôleur de domaine, de l’ajout du rôle au redémarrage.

Corrigé
Rôle AD DS (binaires) → bandeau jaune → Promouvoir → Ajouter une nouvelle forêt + nom réel du domaine → niveau fonctionnel le plus haut (2012 R2) → mot de passe DSRM → avertissement DNS accepté → dossiers NTDS.DIT / journaux / SYSVOL → vérification des prérequis → redémarrage obligatoire.
Exercice 3/5 — Dossiers

Où sont stockées la base AD, les journaux, les GPO et les scripts de connexion ?

Corrigé
Base = NTDS.DIT (dossier « base de données ») ; journaux = dossier dédié, lus par l’Observateur d’événements ; GPO et scripts de connexion = SYSVOL (avec les fichiers de réplication).
Exercice 4/5 — Objets

Créer l’utilisateur iziti dans l’unité TRI : deux formes de session, option de mot de passe à activer. Quel groupe pour donner des droits ?

Corrigé
Console Utilisateurs et ordinateurs AD → clic droit sur TRI → Nouveau → Utilisateur. Sessions : iziti@ntic.ma (UPN) ou NTIC\iziti. Option : « doit changer le mot de passe à la prochaine ouverture ». Droits : à donner à un groupe de sécurité (pas à l’utilisateur), étendue Globale.

QCM final — toutes notions

L’édition limitée à 25 utilisateurs :

Essential : 25 u, 2 CPU, sans virtualisation.

L’édition qui couvre 2 VM :

Standard = 2 VM par licence ; Datacenter = illimité.

La SAM contient…

Security Account Manager : base des comptes locaux (registre).

Le pare-feu a…

Toute manipulation doit couvrir les trois profils.

L’index d’une carte réseau s’obtient par…

Colonne ifIndex de Get-NetAdapter ou Get-NetIPInterface.

Une forêt est…

Domaine ⊂ arbre ⊂ forêt.

La promotion en contrôleur de domaine se lance…

Rôle d’abord (binaires), promotion ensuite, redémarrage obligatoire à la fin.

La base de l’AD s’appelle…

NTDS.DIT ; SYSVOL porte scripts et GPO.

Les GPO vivent dans…

SYSVOL : scripts de connexion, GPO, réplication.

Un groupe de sécurité sert à…

Les groupes de distribution servent à la diffusion.
