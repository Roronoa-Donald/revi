Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque chapitre, puis un projet final qui met le domaine en service de bout en bout. Les scripts sont en Bash, comme à l’atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n lignes « tache famille » (comptes/logiciels/materiel/securite) et valide chaque classement, puis le compteur.
  2. Lit n lignes « edition limite » (u15/u25/vm2/vmillimite) et valide chaque édition, puis le compteur.
  3. Lit n lignes « action onglet » du Gestionnaire de serveur et valide, puis le compteur d’erreurs.
  4. Lit n lignes « poste ram disque » et dit si le poste tient la configuration requise (2 Go, 60 Go), puis le compteur.

read -r n
e=0
for ((k=0; k<n; k++)); do

  case "$tache" in

    panne|remplacement|ajout) attendu="materiel" ;;
    sauvegardes|acces) attendu="securite" ;;

done

Application

Application
  1. Lit 3 lignes « profil etat » (domaine/prive/public) et compte les profils encore actifs du pare-feu.
  2. Lit n lignes « contexte identite machine » et forme la syntaxe de session (locale, NETBIOS, UPN).
  3. Lit n lignes « objet uo » et compte les objets de chaque unité d’organisation dans l’ordre d’apparition.
  4. Lit n lignes « utilisateur identifiant changement » et classe UPN/domaine plus compteur d’init-mdp.

Raisonnement

  2. Lit n lignes « info statut » et signale les informations AD requises manquantes, puis le verdict.
  3. Lit n lignes « domaine niveau longueur » et contrôle niveau fonctionnel + mot de passe DSRM.

Projet intégrateur — « la mise en service d’un domaine »

Cahier des charges

Le script reçoit le journal de mise en service. D’abord n lignes machine config où config est une suite de lettres sans espace — f = pare-feu traité sur les trois profils, i = IP statique validée, a = activation faite, d = DNS pointé vers le domaine, le tiret - = étape non faite. Puis m lignes objet classe (utilisateur/ordinateur/groupe) à créer dans le domaine. Il affiche pour chaque machine machine : prete si les quatre lettres sont présentes, sinon machine : a corriger (manque X) avec la première lettre manquante dans l’ordre f, i, a, d ; pour chaque objet objet : classe-valide si la classe est l’une des trois attendues, sinon objet : classe-inconnue ; enfin le verdict : domaine en service si toutes les machines sont prêtes ET qu’il y a au moins un utilisateur, domaine a finir si les machines sont prêtes sans utilisateur, domaine bloque sinon.

Fonctionnalités attendues
  1. Lire les deux blocs sans mélanger machines et objets.
  2. Auditer chaque machine : première étape manquante dans l’ordre f, i, a, d.
  3. Valider les classes d’objets et repérer le premier utilisateur.
  4. Verdict final au format exact du cahier des charges.

Contraintes : parsing lettre à lettre, premier manque dans l’ordre, bilan après lecture complète.

Grille d’auto-évaluation du projet (sur 100)
Lecture des deux blocs et parsing correct 20
Audit des machines (premier manque) 20
Validation des objets et détection d’un utilisateur 20
Verdict global conforme 20
Rapport lisible et formats exacts 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
read -r n
toutes_ok=1
for ((k=0; k<n; k++)); do
  read -r machine config
  f=0 ; i=0 ; a=0 ; d=0
  if [ "$config" != "-" ]; then
    for ((j=0; j<${#config}; j++)); do
      lettre=${config:$j:1}
      case "$lettre" in
        f) f=1 ;;
        i) i=1 ;;
        a) a=1 ;;
        d) d=1 ;;
      esac
    done
  fi
  if [ "$f" = "1" ] && [ "$i" = "1" ] && [ "$a" = "1" ] && [ "$d" = "1" ]; then
    echo "$machine : prete"
  elif [ "$f" = "0" ]; then
    echo "$machine : a corriger (manque f)" ; toutes_ok=0
  elif [ "$i" = "0" ]; then
    echo "$machine : a corriger (manque i)" ; toutes_ok=0
  elif [ "$a" = "0" ]; then
    echo "$machine : a corriger (manque a)" ; toutes_ok=0
  else
    echo "$machine : a corriger (manque d)" ; toutes_ok=0
  fi
done
read -r m
objets_ok=1
a_un_utilisateur=0
for ((k=0; k<m; k++)); do
  read -r objet classe
  case "$classe" in
    utilisateur)
      echo "$objet : classe-valide"
      a_un_utilisateur=1
      ;;
    ordinateur|groupe)
      echo "$objet : classe-valide"
      ;;
    *)
      echo "$objet : classe-inconnue"
      objets_ok=0
      ;;
  esac
done
if [ "$toutes_ok" = "1" ] && [ "$a_un_utilisateur" = "1" ]; then
  echo "verdict : domaine en service"
elif [ "$toutes_ok" = "1" ]; then
  echo "verdict : domaine a finir"
else
  echo "verdict : domaine bloque"
fi
