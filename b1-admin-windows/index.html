Administration Windows : de Windows Server à Active Directory

Administrer Windows, c’est une suite d’actes précis : comprendre le métier d’administrateur, choisir la bonne édition de Windows Server 2012 R2, mettre le serveur d’aplomb (pare-feu, nom, IP, activation, accès distant), puis bâtir l’annuaire d’entreprise — installer AD DS, promouvoir un contrôleur de domaine, peupler le domaine d’unités d’organisation, d’utilisateurs et de groupes. Six chapitres pour ancrer chaque geste : chacun est d’abord programmé et vérifié dans l’atelier, puis rejoué tel quel sur les cas du support.

Ce que tu sauras faire à la fin du cours
  • classer les tâches de l’administrateur et nommer ses outils Windows ;
  • choisir l’édition de Windows Server 2012 adaptée : Foundation à Datacenter ;
  • mettre un serveur d’aplomb : pare-feu (3 profils), nom, IP statique, activation, accès distant ;
  • construire le vocabulaire AD DS : domaine, arbre, forêt, sous-domaines ;
  • installer un contrôleur de domaine : rôle AD DS, promotion, NTDS.DIT et SYSVOL ;
  • peupler le domaine : unités d’organisation, utilisateurs (UPN), groupes.
Comment ce cours s’articule

Les supports « Base de l’Administration Windows » (Dr Abasse KPEGOUNI) déroulent le parcours du débutant : le métier d’administrateur système, le système lui-même (Windows Server 2012 R2 et ses éditions), sa configuration initiale, puis l’annuaire d’entreprise — Active Directory : notions, installation du contrôleur de domaine, gestion des objets. Ce cours en garde l’esprit et fait appliquer chaque règle en Bash : familles de tâches, limites des éditions, syntaxes de session, profils du pare-feu, validation d’IPv4, arborescences de domaines, matrice des informations AD, cycle des comptes et des groupes.

Chaque chapitre se termine par trois exercices de code : tu écris vraiment le script, il est réellement exécuté, puis corrigé par des tests que tu ne vois pas. La logique écrite ici se rejoue telle quelle aux travaux pratiques sur Windows Server 2012 R2.
