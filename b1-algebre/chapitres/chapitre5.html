Chapitre 5 — Familles libres, génératrices, bases et rang

Module 5 ≈ 3 h de travail Réservé B1 et plus
Mise en situation

Tu disposes d’un jeu de trois vecteurs dans le plan : l’un d’eux est forcément de trop. Pourquoi ? Parce que le plan est de dimension 2. Distinguer les vecteurs qui apportent une vraie information de ceux qui sont « déjà contenus » dans les autres, c’est l’objet de ce chapitre — et c’est aussi ce que fait un algorithme de compression quand il élimine les données redondantes.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. reconnaître une famille génératrice d’un espace vectoriel ;
  2. démontrer qu’une famille est libre ou liée ;
  3. définir une base et calculer la dimension d’un espace ;
  4. calculer le rang d’une famille de vecteurs et d’une matrice.

1. Familles génératrices

Définition. Une famille (v₁, …, vₚ) de vecteurs de E est génératrice de E si tout vecteur de E s’écrit comme combinaison linéaire de la famille : pour tout u ∈ E, il existe des réels a₁, …, aₚ tels que

u = a₁·v₁ + a₂·v₂ + … + aₚ·vₚ

Les coefficients a₁, …, aₚ sont les coordonnées de u dans la famille. Trouver ces coordonnées est exactement résoudre un système linéaire — la méthode de Gauss du chapitre 3 sert donc directement ici.

Exemple décisif

Dans ℝ³, la famille canonique e₁ = (1,0,0), e₂ = (0,1,0), e₃ = (0,0,1) est génératrice : (x, y, z) = x·e₁ + y·e₂ + z·e₃. Les coordonnées sont exactement les composantes du vecteur.

En revanche la famille (1,0,0), (0,1,0) n’engendre que le plan z = 0 : elle n’est pas génératrice de ℝ³.

2. Familles libres et familles liées

Définition. Une famille (v₁, …, vₚ) est libre (ou les vecteurs sont linéairement indépendants) si la seule combinaison linéaire nulle est celle dont tous les coefficients sont nuls :

$\\sum_{k=1}^p a_k v_k = 0 \\implies a_1 = a_2 = \\dots = a_p = 0$

Dans le cas contraire, la famille est liée : il existe des coefficients non tous nuls qui donnent le vecteur nul, autrement dit un vecteur de la famille est combinaison linéaire des autres.

Comment tester ? On écrit l’équation a₁·v₁ + … + aₚ·vₚ = 0, on obtient un système homogène, et on l’échelonne :

  • une seule solution, la solution nulle → la famille est libre ;
  • une infinité de solutions → la famille est liée.
Piège — « aucun vecteur n’est un multiple d’un autre »

Cette vérification rapide ne suffit que pour deux vecteurs. Avec trois vecteurs, une famille peut être liée sans qu’aucun ne soit multiple d’un autre : c’est le cas de (1,0,0), (0,1,0), (1,1,0), où le troisième est la somme des deux premiers. Au-delà de deux vecteurs, il faut échelonner.

Mnémotechnique — « libre = zéro seul »

Libre se retient en une phrase : « pour annuler, on est obligé de tout mettre à zéro ». Liée, c’est l’inverse : « on peut annuler sans tout mettre à zéro » — donc un vecteur est de trop.

3. Bases et dimension

Définition. Une base de E est une famille qui est à la fois libre et génératrice de E.

Une base cumule les deux avantages : être génératrice garantit que tout vecteur s’écrit dans la base ; être libre garantit que cette écriture est unique. C’est cette unicité qui rend les coordonnées exploitables.

Théorème (dimension). Dans un espace vectoriel admettant une base, toutes les bases ont le même nombre d’éléments. Ce nombre est la dimension de E, notée dim E.

dim ℝ² = 2        dim ℝ³ = 3        dim ℝⁿ = n
dim Mm,n(ℝ) = m × n          dim ℝn[X] = n + 1

La base canonique de ℝⁿ est formée des vecteurs à une seule composante égale à 1. Pour les matrices m × n, la base canonique est l’ensemble des matrices Eij n’ayant qu’un 1 en position (i, j).

Un repère, c’est une base

Tu connais déjà des bases sans les nommer : donner la position d’un point par « 3 mètres à droite, 2 mètres en avant » revient à écrire ses coordonnées dans la base des deux directions du sol. Une base est un repère, et la dimension est le nombre de directions indépendantes nécessaires.

4. Rang d’une famille et d’une matrice

Définition. Le rang d’une famille de vecteurs est le nombre maximal de vecteurs linéairement indépendants qu’on peut en extraire. C’est aussi la dimension du sous-espace engendré.

Pour une matrice A, le rang est défini de deux façons équivalentes :

  • le rang des lignes (dimension de l’espace engendré par les lignes) ;
  • le rang des colonnes (dimension de l’espace engendré par les colonnes).

Un théorème fondamental affirme que ces deux nombres sont toujours égaux : on peut donc parler simplement du rang de A.

Calcul pratique. On échelonne la matrice et on compte les lignes non nulles — c’est-à-dire les pivots :

rang(A) = nombre de pivots après échelonnement

Pour A carrée d’ordre n :
   A inversible  ⇔  rang(A) = n  ⇔  det(A) ≠ 0
Exemple
M = [ 1  2  3 ]
    [ 2  4  6 ]      L2 = 2·L1  →  disparaît
    [ 1  0  1 ]

Après élimination il reste 2 lignes indépendantes :
rang(M) = 2.  Les lignes de M engendrent un plan de ℝ³.

Exercice 1 — Rang d’une matrice

Étude de cas Niveau 3 — Raisonnement

Objectif : Échelonner une matrice et compter ses pivots.

Dans cette étude, on considère une ligne m n (dimensions), puis m lignes de n entiers. Affichez le rang de la matrice.

Cas d’exemple
3 3
1 2 3
2 4 6
1 0 1
Résolution attendue
2

La deuxième ligne est le double de la première : il reste 2 pivots.

Deux indices, rédigés en mots
  1. Le rang est le nombre de lignes non nulles une fois la matrice échelonnée par la méthode du pivot.
  2. À chaque colonne, cherche un coefficient non nul à partir de la ligne courante : c’est un pivot, et il en « consomme » une.

Exercice 2 — Famille libre ou liée ?

Étude de cas Niveau 3 — Raisonnement

Objectif : Comparer le rang d’une famille au nombre de ses vecteurs.

Dans cette étude, on considère deux entiers d (dimension) et p (nombre de vecteurs), puis p lignes de d entiers. Indiquez libre si la famille est linéairement indépendante, sinon liee.

Cas d’exemple
3 3
1 0 0
0 1 0
0 0 1
Résolution attendue
libre

Les trois vecteurs de la base canonique sont indépendants.

Deux indices, rédigés en mots
  1. Une famille de p vecteurs est libre quand le rang de la matrice qu’ils forment vaut exactement p.
  2. Si le rang est strictement inférieur à p, au moins un vecteur est combinaison des autres : la famille est liée.

Exercice 3 — Est-ce une base de ℝ³ ?

Étude de cas Niveau 4 — Examen

Objectif : Utiliser le déterminant pour décider si trois vecteurs forment une base.

Dans cette étude, on considère trois lignes de trois entiers : trois vecteurs de ℝ³. Indiquez base s’ils forment une base de ℝ³, sinon pas une base.

Cas d’exemple
1 0 0
0 1 0
0 0 1
Résolution attendue
base

La base canonique de ℝ³.

Deux indices, rédigés en mots
  1. Trois vecteurs de ℝ³ forment une base si et seulement s’ils sont libres.
  2. Avec trois vecteurs de ℝ³, liberté et déterminant non nul sont équivalents : c’est le calcul le plus rapide.

6. QCM — niveau examen

Une famille est génératrice de E lorsque…

C’est la définition : l’espace engendré est E tout entier.

Une famille est libre lorsque…

L’indépendance linéaire : l’équation n’a que la solution nulle.

Une base est une famille…

Les deux propriétés ensemble, ce qui rend les coordonnées uniques.

Que vaut dim M2,3(ℝ) ?

La dimension est le nombre de coefficients : 2 × 3 = 6.

Comment calcule-t-on le rang d’une matrice ?

Le rang est le nombre de pivots après échelonnement.

Pour A carrée d’ordre n, rang(A) = n équivaut à…

rang = n ⇔ det ≠ 0 ⇔ A inversible.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Confondre libre et génératrice : ce sont deux propriétés indépendantes.
  • Test « pas de multiple » appliqué à plus de deux vecteurs.
  • Conclusion sur une famille vide ou contenant 0 : toute famille contenant le vecteur nul est liée.
  • Rang calculé sur la matrice non échelonnée : il faut compter les pivots, pas les lignes.
  • Dimension confondue avec le nombre de vecteurs d’une famille : seule une base a autant d’éléments que la dimension.

8. Méthodologie de résolution

Étudier une famille de vecteurs
  1. Ranger les vecteurs en colonnes dans une matrice.
  2. Échelonner par la méthode du pivot.
  3. Compter les pivots : c’est le rang, donc la dimension de l’espace engendré.
  4. Comparer au nombre de vecteurs : égalité ⇒ famille libre ; strictement inférieur ⇒ famille liée.
  5. Conclure sur la base : libre avec rang = dim E ⇒ la famille est une base de E.

9. Révision active

Résumé essentiel
  • Génératrice : tout vecteur de E est combinaison linéaire de la famille ; les coefficients sont les coordonnées.
  • Libre : la seule combinaison linéaire nulle a tous ses coefficients nuls ; sinon la famille est liée.
  • Base = famille libre et génératrice ; les coordonnées y sont uniques.
  • Toutes les bases d’un espace ont le même cardinal : la dimension.
  • Rang = nombre de pivots après échelonnement = dimension du sous-espace engendré.

Checklist de maîtrise

  • Je distingue clairement famille libre et famille génératrice.
  • Je teste la liberté par échelonnement, pas par intuition.
  • Je donne la dimension de ℝⁿ, de Mm,n et de ℝn[X].
  • Je calcule un rang et j’en déduis l’inversibilité d’une matrice carrée.
