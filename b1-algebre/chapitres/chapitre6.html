Chapitre 6 — Déterminants, applications linéaires et valeurs propres

Module 6 ≈ 3 h 30 de travail Réservé B1 et plus
Mise en situation

Un logiciel de vision par ordinateur fait pivoter une image : géométriquement, c’est une transformation du plan. Cette transformation est une application linéaire, elle se code par une matrice, et deux questions se posent immédiatement : garde-t-elle l’information (déterminant non nul) et existe-t-il des directions qu’elle ne fait que dilater (valeurs propres) ? Ce dernier chapitre répond à ces deux questions.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. calculer un déterminant 2 × 2 et 3 × 3 par développement ;
  2. appliquer les propriétés du déterminant ;
  3. définir une application linéaire et déterminer noyau et image ;
  4. calculer les valeurs propres d’une matrice 2 × 2.

1. Le déterminant : définition et calcul

Définition. Le déterminant est un nombre associé à toute matrice carrée. On le note det(A) ou |A|. Il mesure en quelque sorte le « volume » du parallélépipède construit sur les lignes de A — et lorsqu’il est nul, ce volume est plat : les lignes sont dépendantes.

Ordre 2. La formule est directe :

     [ a  b ]
det  [ c  d ]  =  a·d − b·c

Ordre 3. On développe selon la première ligne, en alternant les signes + − + :

     [ a  b  c ]
det  [ d  e  f ]  =  a(e·i − f·h) − b(d·i − f·g) + c(d·h − e·g)
     [ g  h  i ]
Mnémotechnique — la règle de Sarrus (ordre 3) et les signes

Pour une matrice 3 × 3, la règle de Sarrus évite le développement : on recopie les deux premières colonnes à droite, puis on additionne les trois diagonales « descendantes » et on retranche les trois « montantes ».

Et pour ne jamais se tromper sur les signes du développement : « + − + » le long de la première ligne, comme les cases d’un échiquier.

2. Applications linéaires

Définition. Soient E et F deux espaces vectoriels. Une application f : E → F est linéaire si elle respecte les deux lois :

f(u + v) = f(u) + f(v)          (additivité)
f(k · u) = k · f(u)              (homogénéité)

Les deux se résument en une seule condition :
f(k·u + v) = k·f(u) + f(v)

Conséquence immédiate : une application linéaire envoie toujours le vecteur nul sur le vecteur nul, f(0) = 0. C’est le premier contrôle à faire : si f(0) ≠ 0, l’application n’est pas linéaire.

Noyau et image. Deux sous-espaces décrivent complètement une application linéaire :

ker f = { u ∈ E | f(u) = 0 }        sous-espace de E
Im f  = { f(u) | u ∈ E }            sous-espace de F

Théorème du rang :   dim(ker f) + dim(Im f) = dim E

L’injectivité se lit sur le noyau : f est injective si et seulement si ker f = {0}.

La matrice associée

Toute application linéaire de ℝⁿ dans ℝᵖ s’écrit f(X) = A·X, où A est la matrice p × n dont les colonnes sont les images des vecteurs de la base canonique.

Exemple : f(x, y, z) = (x + y, y + z) a pour matrice [[1, 1, 0], [0, 1, 1]] — une matrice 2 × 3, conforme au passage de ℝ³ dans ℝ².

3. Valeurs propres et vecteurs propres

Définition. Soit A une matrice carrée. Un réel λ est une valeur propre de A s’il existe un vecteur X ≠ 0 tel que

A · X = λ · X

Le vecteur X est alors un vecteur propre associé à λ. Géométriquement, dans la direction de X, la transformation A se réduit à une homothétie de rapport λ : elle ne change pas la direction, seulement la longueur (et éventuellement le sens).

Comment les trouver ? L’équation s’écrit (A − λ·I)·X = 0. Comme on cherche X ≠ 0, cette équation n’a de solution non nulle que si la matrice A − λ·I est non inversible :

det(A − λ·I) = 0        ← polynôme caractéristique

Pour une matrice 2 × 2, ce déterminant est un polynôme du second degré : on le résout avec le discriminant.

Exemple complet. A = [[4, 1], [2, 3]] :

det(A − λI) = (4 − λ)(3 − λ) − 1·2 = λ² − 7λ + 10 = 0
Δ = 49 − 40 = 9     ⇒     λ = (7 ± 3)/2

Valeurs propres :  λ₁ = 5      λ₂ = 2
Pourquoi cela compte en informatique

Les valeurs propres servent à mesurer la stabilité d’un système, à comprimer des images (l’analyse en composantes principales ne garde que les grandes valeurs propres), à classer les pages du Web (l’algorithme PageRank cherche un vecteur propre) et à étudier la convergence d’un algorithme itératif. C’est l’outil de réduction d’une matrice.

Piège — oublier que X ≠ 0

Le vecteur nul vérifie A·0 = λ·0 pour n’importe quel λ : il n’est donc jamais un vecteur propre. Un vecteur propre est par définition non nul — sinon la notion n’aurait aucun sens.

Exercice 2 — Valeurs propres d’une matrice 2 × 2

Python Niveau 4 — Examen

Objectif : Résoudre le polynôme caractéristique λ² − s·λ + p = 0.

Le programme reçoit deux lignes de deux entiers (une matrice 2 × 2). Affichez ses valeurs propres réelles, la plus petite puis la plus grande, chacune arrondie à deux décimales. S’il n’y a pas de valeur propre réelle, affichez pas de valeur propre reelle.

Entrée du programme
4 1
2 3
Sortie attendue
2.00
5.00

s = 7, p = 10 : λ² − 7λ + 10 = 0 donne 2 et 5.

Deux indices, rédigés en mots
  1. Le polynôme caractéristique s’écrit λ² − s·λ + p = 0, où s est la trace et p le déterminant.
  2. Le discriminant Δ = s² − 4p décide : négatif, pas de racine réelle ; sinon les racines sont (s ± √Δ)/2.

5. QCM — niveau examen

Que vaut det [[a, b], [c, d]] ?

Le produit de la diagonale moins le produit de l’anti-diagonale.

Que devient le déterminant si l’on échange deux lignes ?

L’échange de deux lignes inverse le signe du déterminant.

Que vaut det(A · B) ?

Le déterminant est multiplicatif.

Une application linéaire vérifie nécessairement…

Test rapide : si f(0) ≠ 0, l’application n’est pas linéaire.

Une application linéaire est injective si et seulement si…

ker f = {0} ⇔ f injective.

Comment trouve-t-on les valeurs propres de A ?

Les valeurs propres sont les racines du polynôme caractéristique.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Signes du développement : alterner + − + sur la ligne de développement.
  • Confondre det(A) = 0 et A = 0 : une matrice non nulle peut être singulière.
  • Oublier det(k·A) = kⁿ·det(A) et écrire simplement k·det(A).
  • Tester la linéarité sur un exemple au lieu de la formule générale.
  • Vecteur propre nul : accepter X = 0, qui n’est jamais un vecteur propre.

7. Méthodologie de résolution

Étudier une application linéaire donnée par sa matrice
  1. Vérifier la linéarité avec f(k·u + v) = k·f(u) + f(v), ou contrôler f(0) = 0.
  2. Écrire la matrice dont les colonnes sont les images des vecteurs de la base canonique.
  3. Déterminer le noyau en résolvant A·X = 0 par échelonnement.
  4. Calculer le rang : il donne dim(Im f), et le théorème du rang donne dim(ker f).
  5. Conclure : injective si le noyau est réduit à {0}, surjective si le rang égale la dimension d’arrivée.

8. Révision active

Résumé essentiel
  • det 2 × 2 : ad − bc ; det 3 × 3 : développement + − + ou règle de Sarrus.
  • det(A·B) = det(A)·det(B), det(tA) = det(A), det(k·A) = kⁿ·det(A).
  • Une application linéaire respecte addition et multiplication scalaire, et vérifie f(0) = 0.
  • ker f = {u | f(u) = 0}, Im f = {f(u)}, et dim ker f + dim Im f = dim E.
  • Les valeurs propres annulent det(A − λI) = 0 ; le vecteur propre associé n’est jamais nul.
