Mémo des formules

Définitions, formules et méthodes du cours sur une page. À garder ouvert pendant les exercices et l’atelier.

Matrice et vocabulaire

A = (aij)  avec i = ligne, j = colonne
A est de taille m × n : m lignes, n colonnes
matrice carrée : m = n        matrice nulle : tous les aij = 0
matrice identité In : 1 sur la diagonale, 0 ailleurs
diagonale : les aii     trace : tr(A) = a11 + a22 + … + ann

Attention : le produit matriciel n’est pas commutatif — en général A·B ≠ B·A. Mais il est associatif : (A·B)·C = A·(B·C).

Propriétés de la transposée et de la trace

t(A + B) = tA + tB
t(A · B) = tB · tA        (l’ordre s’inverse)
t(tA) = A
tr(A + B) = tr(A) + tr(B)     tr(A · B) = tr(B · A)     tr(tA) = tr(A)

Une matrice est symétrique si tA = A, antisymétrique si tA = −A.

Inverse d’une matrice

A inversible  ⇔  il existe B telle que A · B = B · A = I
A est inversible  ⇔  det(A) ≠ 0

2 × 2 :   A = [a b ; c d]      det(A) = ad − bc
          A⁻¹ = 1/det(A) · [ d  −b ; −c  a ]

(A · B)⁻¹ = B⁻¹ · A⁻¹        (tA)⁻¹ = t(A⁻¹)

Méthode de Gauss (pivot)

Pour résoudre A·X = B ou inverser A, on écrit la matrice augmentée et on applique trois opérations élémentaires, sans changer l’ensemble des solutions :

1. échanger deux lignes                        L_i ↔ L_j
2. multiplier une ligne par k ≠ 0              L_i ← k · L_i
3. ajouter à une ligne un multiple d’une autre L_i ← L_i + k · L_j

Système   : [ A | B ]  →  forme échelonnée  →  remontée
Inverse   : [ A | I ]  →  [ I | A⁻¹ ]

Espace vectoriel et sous-espace

(E, +, ·) est un espace vectoriel sur ℝ si :
  (E, +) est un groupe commutatif
  1 · u = u
  k · (u + v) = k·u + k·v
  (k + k′) · u = k·u + k′·u
  k · (k′ · u) = (k · k′) · u

F ⊂ E est un sous-espace vectoriel si :
  F ≠ ∅ ;  ∀u,v ∈ F, u + v ∈ F ;  ∀k ∈ ℝ, ∀u ∈ F, k·u ∈ F
  (equivalent court : ∀u,v ∈ F, ∀k ∈ ℝ, k·u + v ∈ F)

Familles libres, génératrices, bases, rang

Famille génératrice : tout vecteur de E s’écrit comme combinaison linéaire de la famille
Famille libre       : a₁v₁ + … + aₚvₚ = 0  ⇒  a₁ = … = aₚ = 0
Base                : famille libre ET génératrice (dimension = nombre de vecteurs)
Rang                : nombre maximal de vecteurs linéairement indépendants

rang(A) = nombre de pivots après échelonnement = nombre de lignes non nulles
A carrée est inversible  ⇔  rang(A) = n  ⇔  det(A) ≠ 0

Déterminant

2 × 2 : det [a b ; c d] = ad − bc
3 × 3 : det A = a(ei − fh) − b(di − fg) + c(dh − eg)     (développement 1re ligne)

det(A · B) = det(A) · det(B)      det(tA) = det(A)
det(k · A) = kⁿ · det(A)          (A de taille n × n)
Échanger deux lignes change le signe ; ajouter k·L_j à L_i ne change rien.

Applications linéaires et valeurs propres

f : E → F est linéaire  ⇔  f(u + v) = f(u) + f(v)  et  f(k·u) = k·f(u)
  ⇔  f(k·u + v) = k·f(u) + f(v)
noyau  : ker f = { u ∈ E | f(u) = 0 }        image : Im f = { f(u) | u ∈ E }

λ est valeur propre de A  ⇔  A·X = λ·X avec X ≠ 0
  ⇔  det(A − λ·I) = 0        (polynôme caractéristique)
Le vecteur X ≠ 0 associé est un vecteur propre.

Erreurs fréquentes à éviter

  • Ajouter deux matrices de dimensions différentes.
  • Calculer A·B sans vérifier que colonnes(A) = lignes(B).
  • Croire que A·B = B·A : c’est faux dès la dimension 2.
  • Oublier de diviser par det(A) dans la formule de l’inverse 2×2.
  • Conclure qu’une famille est libre parce qu’aucun vecteur n’est un multiple d’un autre.
  • Confondre « det(A) = 0 » (non inversible) et « A = 0 ».
