Examen blanc n°1

Sujet type — calcul et méthode, d’après les évaluations B1.

Exercice 1/4 — Calcul matriciel

Soit A = [2 1 ; 3 4] et B = [1 0 ; 2 1]. Calcule A·B, B·A, tr(A) et det(A).

Corrigé
A·B = [4 1 ; 11 4]. B·A = [2 1 ; 7 6]. tr(A) = 6. det(A) = 2·4 − 1·3 = 5. On vérifie au passage que A·B ≠ B·A : le produit n’est pas commutatif.
Exercice 2/5 — Inverse

A = [1 2 ; 3 4]. Montre que A est inversible et calcule A⁻¹.

Corrigé
det(A) = 1·4 − 2·3 = −2 ≠ 0, donc A est inversible. A⁻¹ = 1/(−2) · [4 −2 ; −3 1] = [−2 1 ; 1.5 −0.5]. Vérification : A · A⁻¹ = I.
Exercice 3/6 — Système de Gauss

Résous par la méthode de Gauss : x + y + z = 6 ; 2x − y + z = 3 ; x + 2y − z = 2.

Corrigé
Matrice augmentée [1 1 1 | 6 ; 2 −1 1 | 3 ; 1 2 −1 | 2]. L2 ← L2 − 2L1 : [0 −3 −1 | −9]. L3 ← L3 − L1 : [0 1 −2 | −4]. L2 ↔ L3 : [0 1 −2 | −4] puis [0 −3 −1 | −9]. L3 ← L3 + 3L2 : [0 0 −7 | −21]. Donc z = 3, y − 2z = −4 ⇒ y = 2, puis x + 2 + 3 = 6 ⇒ x = 1. Solution : (x, y, z) = (1, 2, 3).
Exercice 4/5 — Déterminant

Calcule le déterminant de C = [1 2 3 ; 0 1 4 ; 5 6 0] et dis si C est inversible.

Corrigé
Développement selon la 1re ligne : 1·(1·0 − 4·6) − 2·(0·0 − 4·5) + 3·(0·6 − 1·5) = 1·(−24) − 2·(−20) + 3·(−5) = −24 + 40 − 15 = 1. det(C) = 1 ≠ 0, donc C est inversible et rang(C) = 3.

Examen blanc n°2 — variante

Sujet orienté espaces vectoriels et applications linéaires.

Exercice 1/5 — Famille libre

Dans ℝ³, la famille {u = (1, 2, 3), v = (0, 1, 4), w = (1, 3, 7)} est-elle libre ?

Corrigé
On cherche a, b, c tels que a·u + b·v + c·w = 0 : a + c = 0 ; 2a + b + 3c = 0 ; 3a + 4b + 7c = 0. La 1re équation donne c = −a. En reportant : b + 3c + 2a = b + c + 2a − 2c = … la 3e devient 3a + 4b − 7a = 0 ⇒ b = a. La 2e : 2a + a − 3a = 0, toujours vraie. Il existe donc des solutions non nulles (par exemple a = b = 1, c = −1) : w = u + v, la famille est liée.
Exercice 2/5 — Rang

M = [1 2 3 ; 2 4 6 ; 1 0 1]. Détermine le rang de M.

Corrigé
L2 = 2·L1, donc L2 disparaît. Il reste [1 2 3 ; 1 0 1]. L2 ← L2 − L1 : [0 −2 −2], non nulle. Deux pivots ⇒ rang(M) = 2. Conclusion : les lignes de M engendrent un plan dans ℝ³.
Exercice 3/5 — Application linéaire

Soit f(x, y, z) = (x + y, y + z). Montre que f est linéaire et donne sa matrice.

Corrigé
f(u + v) = f(u) + f(v) et f(k·u) = k·f(u) se vérifient composante par composante : chaque coordonnée de sortie est une somme de coordonnées d’entrée, sans terme constant. Matrice associée dans les bases canoniques : [1 1 0 ; 0 1 1], de taille 2 × 3.
Exercice 4/5 — Valeurs propres

Trouve les valeurs propres de A = [4 1 ; 2 3].

Corrigé
det(A − λI) = (4 − λ)(3 − λ) − 2 = λ² − 7λ + 10 = 0. Discriminant : 49 − 40 = 9, donc λ = (7 ± 3)/2 : λ₁ = 5 et λ₂ = 2.

QCM final — toutes notions

Quand le produit A·B existe-t-il ?

La taille du produit est (lignes de A) × (colonnes de B).

Le produit matriciel est-il commutatif ?

A·B ≠ B·A en général, même pour des matrices carrées.

Que vaut t(A·B) ?

La transposée d’un produit inverse l’ordre des facteurs.

À quelle condition une matrice carrée est-elle inversible ?

det(A) ≠ 0 ⇔ A inversible ⇔ rang(A) = n.

Que fait l’opération L2 ← L2 − 2L1 sur la matrice augmentée ?

Les opérations élémentaires sur les lignes conservent l’ensemble des solutions.

Une famille est libre lorsque…

C’est la définition : l’indépendance linéaire.

Que vaut le rang d’une matrice de déterminant non nul (n × n) ?

det ≠ 0 ⇒ les n lignes sont indépendantes ⇒ rang = n.

Combien de valeurs propres possède une matrice 2 × 2 sur ℝ (comptées avec multiplicité) ?

Le polynôme caractéristique est de degré 2.

Que vaut det(k · A) pour A de taille n × n ?

Chaque ligne est multipliée par k : n lignes, donc kⁿ.

Le noyau de f est…

ker f = { u | f(u) = 0 } : c’est un sous-espace de l’espace de départ.
