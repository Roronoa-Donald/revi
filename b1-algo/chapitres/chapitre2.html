Chapitre 2 — Variables, types et affectation

Module 2 ≈ 2 h de travail B1 et plus
Mise en situation

On te confie deux dossiers physiques à échanger entre deux tiroirs. Impossible de les échanger sans une troisième case pour poser l'un des deux. Les variables se comportent exactement ainsi : l'échange passe toujours par une variable temporaire.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. Déclarer une variable avec le bon type (entier, réel, chaîne, booléen) ;
  2. prédire le résultat d'une affectation, y compris x ← x + 1 ;
  3. utiliser div et mod (Python : // et %) ;
  4. échanger le contenu de deux variables.

1. La variable : un nom, un type, une valeur

Définition. Une variable est un emplacement mémoire nommé qui contient une valeur de son type. Le type est déclaré avant l'usage en Pascal ; il est déduit de la valeur en Python.

Pseudo-code
Variable age : Entier
Variable moyenne : Réel
Variable nom : Chaîne
Variable admis : Booléen
var
  age: integer;
  moyenne: real;
  nom: string;
  admis: boolean;
begin
  age := 20;
  moyenne := 13.5;
end.
age = 20
moyenne = 13.5
nom = "Ali"
admis = True

2. L'affectation

Définition. L'affectation (← en pseudo-code, := en Pascal, = en Python) calcule l'expression de droite puis range le résultat dans la variable de gauche. L'ancienne valeur est écrasée.

Pseudo-code
x ← 5
x ← x + 1   // x vaut maintenant 6
x := 5;
x := x + 1;   (* x vaut 6 *)
x = 5
x += 1        # x vaut 6
Niveau 1 — Intuition

x ← x + 1 ne veut pas dire « x est égal à x + 1 » (impossible !) : la flèche est un ordre. « Prends la valeur actuelle de x, ajoute 1, range le résultat dans x ». Toujours lire la droite d'abord.

3. div et mod

Définition. Pour deux entiers a et b : a div b donne le quotient entier de la division, a mod b le reste.

OpérationPseudo-codePascalPython
Division entièredivdiv//
Restemodmod%
17 div 5 = 3    (* 3 × 5 = 15, reste 2 *)
17 mod 5 = 2
L'identité à retenir

Pour tout a et b ≠ 0 : a = (a div b) × b + (a mod b). Cette identité sert à vérifier un découpage (heures/minutes, billets/reste, boîtes/pièces) et revient dans presque tous les sujets.

4. Échanger deux variables

Pseudo-code
temp ← a
a ← b
b ← temp
temp := a;
a := b;
b := temp;
a, b = b, a        # affectation simultanée
# ou, façon manuelle :
temp = a
a = b
b = temp
Piège — l'échange sans case temporaire

Écrire a ← b puis b ← a perd la valeur initiale de a : après la première affectation, les deux variables contiennent la valeur de b. La variable temporaire est obligatoire (sauf affectation simultanée en Python).

Exercice 1 — Permuter deux valeurs

Python Niveau 2 — Application

Objectif : Échanger le contenu de deux variables.

Le programme reçoit deux entiers, chacun sur une ligne. Échangez leurs valeurs : la première valeur lue doit être affichée en second et la seconde en premier, séparées par une espace.

Entrée du programme
3
8
Sortie attendue
8 3

Les deux valeurs ont été permutées.

Deux indices, rédigés en mots
  1. Un échange a besoin d’une case temporaire, ou d’une écriture qui affecte les deux variables en une seule fois.
  2. Attention à l’ordre : ce qui est demandé, c’est b puis a à l’affichage.

Exercice 2 — Moyenne pondérée

Python Niveau 2 — Application

Objectif : Calculer une moyenne pondérée sans perdre les décimales.

Le programme reçoit une note de contrôle continu (sur 20, entier) et une note d’examen (sur 20, entier). La moyenne pondérée vaut 40 % du contrôle continu plus 60 % de l’examen. Affichez-la avec deux décimales.

Entrée du programme
12
15
Sortie attendue
13.80

0,4 × 12 + 0,6 × 15 = 13,80.

Deux indices, rédigés en mots
  1. Pour que la division soit décimale, au moins un opérande doit être un nombre à virgule.
  2. L’arrondi se fait au moment de l’affichage : le format des f-strings fixe le nombre de décimales.

Exercice 3 — Somme des chiffres

Python Niveau 3 — Raisonnement

Objectif : Décomposer un entier chiffre par chiffre.

Le programme reçoit un entier positif. Affichez la somme de ses chiffres.

Entrée du programme
4729
Sortie attendue
22

4 + 7 + 2 + 9 = 22.

Deux indices, rédigés en mots
  1. Un nombre peut se parcourir caractère par caractère une fois converti en texte.
  2. Chaque morceau doit redevenir un entier pour entrer dans une somme.

6. QCM — niveau examen

Que fait x ← x + 1 ?

La droite est calculée puis rangée dans x.

Que vaut 17 mod 5 ?

17 = 3 × 5 + 2 : le reste est 2.

Que vaut 17 div 5 ?

Le quotient entier est 3.

En Pascal, quel symbole compare deux valeurs ?

:= affecte ; = compare (Pascal n'a pas de ==).

Pourquoi une variable temporaire pour échanger ?

Sans elle, la valeur initiale est écrasée avant d'être recopiée.

Quel type pour une note avec décimales ?

Une valeur décimale exige le type réel (real/float).

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Échanger sans variable temporaire.
  • Confondre div et / (division réelle).
  • Utiliser une variable non initialisée.
  • Confondre = et := en Pascal.
  • Mélanger les types : ranger du texte dans un entier.

8. Méthodologie de résolution

Choisir ses variables
  1. Une variable par donnée du problème, avec un nom explicite.
  2. Un type par nature de valeur : compte → entier, mesure → réel.
  3. Initialiser avant toute lecture.
  4. Vérifier chaque affectation avec une table de trace.

9. Révision active

Résumé essentiel
  • Variable = nom + type + valeur ; le type fixe les opérations permises.
  • Affectation : toujours calculer la droite, puis ranger à gauche.
  • div/mod (Python : ///%) : quotient et reste entiers.
  • Identité : a = (a div b) × b + (a mod b).
  • Échange = trois affectations avec temporaire.

Checklist de maîtrise

  • Je déclare chaque variable avec le bon type.
  • Je prédis le résultat de toute affectation.
  • Je découpe une valeur avec div et mod.
  • J'échange deux variables sans perdre de valeur.
