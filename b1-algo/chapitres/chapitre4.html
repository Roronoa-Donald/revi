Chapitre 4 — Boucles : Pour

Module 4 ≈ 2 h 30 de travail B1 et plus
Mise en situation

Afficher la table de 7 : dix lignes. Écrire dix instructions « Écrire » ? Absurde. La boucle Pour répète un bloc un nombre de fois connu à l'avance : c'est la structure du compteur.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. Écrire une boucle Pour avec les bonnes bornes ;
  2. traduire en Pascal for...to...do et for...downto...do ;
  3. expliquer la différence de convention entre Pascal (borne incluse) et Python (range borne exclue) ;
  4. utiliser un accumulateur dans une boucle.

1. La boucle Pour : un compteur borné

Définition. La boucle Pour exécute son corps pour chaque valeur d'un compteur compris entre une borne de début et une borne de fin, avec un pas de 1 (ou −1 avec downto).

Pseudo-code
Pour i de 1 à 5 Faire
  Écrire i
FinPour
for i := 1 to 5 do
  writeln(i);
for i in range(1, 6):
    print(i)
1 2 3 4 5
La différence de borne Pascal / Python

En Pascal, la borne de fin est incluse : for i := 1 to 10 va jusqu'à 10. En Python, range(fin) exclut la fin : pour aller jusqu'à 10, il faut écrire range(1, 11). C'est LA source d'erreur n°1 des exercices.

ObjectifPascalPython
i de 1 à 10for i := 1 to 10 dofor i in range(1, 11)
i de 10 à 1 (inverse)for i := 10 downto 1 dofor i in range(10, 0, -1)
n tours à partir de 0for i := 0 to n-1 dofor i in range(n)

2. L'accumulateur

Définition. Un accumulateur est une variable qui se met à jour à chaque tour pour construire un résultat : une somme (initialisée à 0) ou un produit (initialisé à 1).

Pseudo-code — somme 1..n
Lire n
S ← 0
Pour i de 1 à n Faire
  S ← S + i
FinPour
Écrire S
n = int(input())

somme = 0
for i in range(1, n + 1):
    somme += i

print(somme)
Deux pièges classiques
  • Initialisation dans la boucle : S ← 0 écrit à l'intérieur du Pour remet le compteur à zéro à chaque tour ; le résultat est faussé (souvent la dernière valeur seule).
  • Élément neutre du produit : un produit s'initialise à 1. Multiplier par 0 efface tout ; la convention 0! = 1 en découle naturellement.

3. Boucles imbriquées

Une boucle dans une boucle : le corps complet de la boucle interne s'exécute pour chaque tour de la boucle externe. Deux boucles de 3 tours exécutent donc 9 itérations.

# Tables de 1 à 3
for table in range(1, 4):
    for i in range(1, 11):
        print(table, "x", i, "=", table * i)

Exercice 1 — Table de multiplication

Python Niveau 2 — Application

Objectif : Écrire une boucle compteur avec la bonne borne.

Le programme reçoit un entier n. Affichez sa table de multiplication de 1 à 10, une ligne par produit, sous la forme n x i = r.

Entrée du programme
3
Sortie attendue
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30

Dix lignes, de 1 à 10.

Deux indices, rédigés en mots
  1. La borne de fin d’un parcours n’est jamais atteinte : pour aller jusqu’à 10 inclus, il faut dépasser d’un.
  2. Chaque tour affiche sa ligne ; le produit se calcule dans le tour.

Exercice 2 — Somme des entiers de 1 à n

Python Niveau 3 — Raisonnement

Objectif : Accumuler un résultat dans une boucle Pour.

Le programme reçoit un entier n. Affichez la somme 1 + 2 + … + n en utilisant une boucle, sans sum().

Entrée du programme
10
Sortie attendue
55

1 + 2 + … + 10 = 55.

Deux indices, rédigés en mots
  1. Un accumulateur s’initialise avant la boucle : initialisé dedans, il repart de zéro à chaque tour.
  2. La borne de fin doit dépasser n d’une unité pour que n soit inclus.

Exercice 3 — Factorielle

Python Niveau 4 — Examen

Objectif : Accumuler un produit et respecter l’élément neutre.

Le programme reçoit un entier n (0 ≤ n ≤ 20). Affichez sa factorielle : le produit 1 × 2 × … × n, avec la convention 1 pour n = 0. Une boucle est attendue.

Entrée du programme
5
Sortie attendue
120

1 × 2 × 3 × 4 × 5 = 120.

Deux indices, rédigés en mots
  1. Un produit s’accumule comme une somme, mais l’élément neutre n’est pas zéro : multiplier par zéro effacerait tout.
  2. Pour n = 0, la boucle ne s’exécute pas : la valeur initiale de l’accumulateur est déjà le bon résultat.

5. QCM — niveau examen

Quand utiliser une boucle Pour ?

Pour = compteur borné ; TantQue = condition.

for i := 1 to 5 (Pascal) exécute combien de fois ?

La borne de fin est incluse en Pascal : 1, 2, 3, 4, 5.

Comment aller de 1 à 10 en Python ?

range exclut sa borne de fin : il faut dépasser 10 d'une unité.

Comment initialiser un accumulateur de produit ?

1 est l'élément neutre de la multiplication.

Que fait Pascal for i := 5 downto 1 do ?

downto est la boucle inverse.

Deux boucles imbriquées de 4 et 3 tours exécutent le corps interne…

4 × 3 = 12 : le corps interne tourne pour chaque combinaison.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Borne exclue : range(1, n) oublie n en Python.
  • Initialisation dans la boucle : l'accumulateur repart de zéro.
  • Produit initialisé à 0 : résultat toujours nul.
  • Modifier le compteur dans le corps du Pour : interdit, il est géré par la boucle.
  • Mélanger les conventions Pascal (incluse) et Python (exclue).

7. Méthodologie de résolution

Écrire une boucle Pour
  1. Identifier le compteur et ses bornes exactes.
  2. Choisir la convention du langage et ajuster la borne.
  3. Initialiser les accumulateurs avant la boucle.
  4. Écrire le corps : une responsabilité par tour.
  5. Vérifier avec la table de trace sur 2 ou 3 tours.

8. Révision active

Résumé essentiel
  • Pour = compteur entre deux bornes, nombre de tours connu.
  • Pascal : borne incluse ; Python : range exclut la fin.
  • downto (ou pas −1) pour compter à rebours.
  • Somme → 0 ; produit → 1, initialisés avant la boucle.
  • Imbrication : le corps interne s'exécute pour chaque tour externe.

Checklist de maîtrise

  • Je fixe les bornes sans erreur de ±1.
  • Je traduis Pour ↔ for Pascal ↔ range Python.
  • J'initialise mes accumulateurs au bon endroit.
  • Je prédis le nombre de tours d'une imbrication.
