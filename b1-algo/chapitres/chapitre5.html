Chapitre 5 — Boucles : TantQue et Répéter

Module 5 ≈ 2 h 30 de travail B1 et plus
Mise en situation

Demandez un nombre à un utilisateur jusqu'à ce qu'il donne une valeur valide. Combien d'essais faudra-t-il ? On n'en sait rien : c'est le cas de la boucle à condition, TantQue ou Répéter, quand le nombre de tours est inconnu à l'avance.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. Écrire une boucle TantQue (while) avec une condition d'arrêt correcte ;
  2. distinguer TantQue (test avant) et Répéter...Jusqu'à (test après) ;
  3. éviter les boucles infinies ;
  4. traduire un algorithme à condition d'arrêt (seuil, Syracuse) en programme.

1. La boucle TantQue

Définition. La boucle TantQue répète son corps tant que sa condition reste vraie. La condition est testée avant chaque tour : si elle est fausse dès le départ, le corps ne s'exécute jamais (zéro tour possible).

Pseudo-code
TantQue somme < seuil Faire
  terme ← terme + 1
  somme ← somme + terme
FinTantQue
while somme < seuil do
begin
  terme := terme + 1;
  somme := somme + terme;
end;
while somme < seuil:
    terme += 1
    somme += terme

2. La boucle Répéter...Jusqu'à

Définition. Répéter exécute son corps au moins une fois, puis recommence jusqu'à ce que la condition devienne vraie. Le test est en fin de boucle, et la logique est inversée : on répète jusqu'à ce que la condition d'arrêt soit vraie.

Pseudo-code
Répéter
  Écrire "Entrez 1 pour continuer"
  Lire choix
Jusqu'à choix = 1
repeat
  write('Entrez 1 pour continuer : ');
  readln(choix);
until choix = 1;
while True:
    choix = int(input("Entrez 1 pour continuer : "))
    if choix == 1:
        break

Python n'a pas d'équivalent direct : on combine while et break.

Niveau 1 — Intuition

TantQue ressemble à un agent qui regarde avant d'agir : s'il voit un mur dès le départ, il ne bouge pas. Répéter...Jusqu'à ressemble à quelqu'un qui agit d'abord et regarde ensuite : il avance au moins un pas, puis vérifie s'il peut s'arrêter.

3. La boucle infinie : l'ennemi n°1

Une boucle TantQue s'arrête seulement si sa condition devient fausse. Trois causes classiques de boucle infinie :

  • Le compteur n'avance pas : i ← i + 1 oublié dans le corps ;
  • La condition ne peut jamais devenir fausse : on teste une variable jamais modifiée ;
  • Le sens du test est inversé : < au lieu de <= près d'une borne.
La règle des trois points

Toute boucle TantQue correcte précise : (1) l'initialisation des variables testées, (2) la condition d'arrêt, (3) l'instruction qui fait progresser vers l'arrêt. Si l'un des trois manque, la boucle est suspecte. Mais une impression de progrès ne suffit pas : il faut aussi montrer que l'arrêt sera atteint en un nombre fini de tours.

Par exemple, si un compteur est un entier positif ou nul, qu'il diminue strictement de 1 à chaque tour et que la boucle continue seulement tant qu'il est supérieur à 0, il atteint 0 après un nombre fini de tours :

compteur = 3
while compteur > 0:
    compteur -= 1
print(compteur)

À l'inverse, dans le modèle mathématique exact, si x est un réel strictement positif, le diviser par deux à chaque tour le rapproche de zéro sans jamais atteindre zéro : TantQue x > 0 ne s'arrête pas.

4. Exemple complet : la conjecture de Syracuse

L'entrée attendue est un entier strictement positif : avec 0, la valeur resterait 0. L'exemple refuse donc les valeurs nulles ou négatives. L'atteinte de 1 n'est pas démontrée pour tous les entiers positifs : c'est une conjecture, et la fin du calcul n'est pas garantie pour toute entrée admissible.

Pseudo-code
Lire valeur
Si valeur ≤ 0 Alors
  Écrire "La valeur doit être strictement positive."
Sinon
  étapes ← 0
  TantQue valeur ≠ 1 Faire
    Si valeur mod 2 = 0 Alors valeur ← valeur div 2
    Sinon valeur ← 3 × valeur + 1
    étapes ← étapes + 1
  FinTantQue
  Écrire étapes
FinSi
valeur = int(input())

if valeur <= 0:
    print("La valeur doit être strictement positive.")
else:
    etapes = 0
    while valeur != 1:
        if valeur % 2 == 0:
            valeur //= 2
        else:
            valeur = 3 * valeur + 1
        etapes += 1

    print(etapes)

On ne sait pas combien d'étapes seront nécessaires : c'est exactement le cas du TantQue. La valeur peut augmenter ou diminuer à chaque tour, et la condition d'arrêt est l'atteinte de 1.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute le code et la validation fait tourner des jeux de tests indépendants : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire le code de la solution — c’est le principe de l’exercice.

Exercice 1 — Somme jusqu’au seuil

Pseudo-code Niveau 3 — Raisonnement

Objectif : Écrire une boucle TantQue dont la condition dépend d’un accumulateur.

Le programme reçoit un entier seuil. Ajoutez les entiers naturels successifs (1, 2, 3, …) tant que la somme est strictement inférieure au seuil, puis affichez la somme obtenue et le nombre de termes ajoutés, séparés par une espace.

Entrée du programme
10
Sortie attendue
10 4

1 + 2 + 3 + 4 = 10 : la somme atteint exactement le seuil et s’arrête.

Trois indices, rédigés en mots
  1. La condition de poursuite porte sur l’état courant de la somme, pas sur un compteur de tours.
  2. Suivez deux variables : la somme reconstituée et le dernier terme ajouté ; le nombre de termes se déduit du dernier terme.
  3. Étapes : somme = 0, terme = 0 ; TantQue somme < seuil Faire : terme = terme + 1, somme = somme + terme ; à la sortie, afficher somme et terme.

Exercice 2 — Compter les chiffres

Pseudo-code Niveau 3 — Raisonnement

Objectif : Répéter une réduction jusqu’à la condition d’arrêt.

Le programme reçoit un entier positif. Affichez son nombre de chiffres, obtenu par divisions entières successives (sans convertir en texte).

Entrée du programme
4729
Sortie attendue
4

Quatre chiffres : 4729 → 472 → 47 → 4 → 0.

Trois indices, rédigés en mots
  1. Chaque division entière par dix retire un chiffre : compter les divisions revient à compter les chiffres.
  2. Le cas particulier de zéro doit donner un chiffre : un compteur initialisé à un et une boucle qui s’exécute seulement au-delà de zéro le gèrent.
  3. Étapes : chiffres = 1 ; TantQue nombre >= 10 Faire : nombre = nombre DIV 10, chiffres = chiffres + 1 ; afficher chiffres.

Exercice 3 — Conjecture de Syracuse

Pseudo-code Niveau 4 — Examen

Objectif : Écrire une boucle dont on ne connaît pas le nombre de tours à l’avance.

Le programme reçoit un entier strictement positif. Appliquez la suite de Syracuse : tant que la valeur n’est pas 1, divisez-la par 2 si elle est paire, sinon remplacez-la par 3 × valeur + 1. Comptez et affichez le nombre d’étapes nécessaires.

Entrée du programme
6
Sortie attendue
8

6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1 : huit étapes.

Trois indices, rédigés en mots
  1. La parité se teste par le reste de la division par deux.
  2. La boucle continue tant que la valeur diffère de un : c’est la condition d’arrêt, pas une borne connue d’avance.
  3. Étapes : etapes = 0 ; TantQue valeur <> 1 Faire : Si reste nul Alors valeur = valeur / 2 Sinon valeur = 3 × valeur + 1 ; etapes = etapes + 1 ; afficher etapes.

6. QCM — niveau examen

Combien de tours au minimum pour un TantQue dont la condition est fausse dès le début ?

Le test est avant le corps : zéro tour possible.

Quelle boucle garantit au moins une exécution ?

Son test est en fin de boucle.

Cause classique de boucle infinie ?

Si la condition reste vraie et qu'aucune autre instruction ne quitte la boucle, l'exécution ne s'arrête pas.

Répéter...Jusqu'à : quand s'arrête-t-elle ?

« Jusqu'à » exprime la condition d'arrêt, vraie en fin.

Pour une « saisie jusqu'à valeur valide », quelle boucle ?

Le nombre de tours dépend de l'utilisateur : condition d'arrêt.

Pour tout compteur entier ≥ 0, quelle mise à jour garantit l'arrêt de la boucle TantQue compteur > 0, sans autre sortie ?

Un compteur entier positif diminué de 1 atteint 0. S'il augmente ou reste inchangé, le test reste vrai lorsqu'il est positif au départ.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Boucle infinie : compteur non avancé ou condition figée.
  • Confondre les deux logiques : TantQue continue si vrai ; Répéter s'arrête si vrai.
  • Initialisation oubliée : tester une variable jamais renseignée.
  • Test de bord : < au lieu de <=, un tour de trop ou de moins.
  • Répéter là où un Pour suffit : un compteur borné appelle un Pour.

8. Méthodologie de résolution

Écrire une boucle à condition
  1. Choisir la structure : Pour si compteur borné, TantQue sinon.
  2. Initialiser toutes les variables testées.
  3. Écrire la condition d'arrêt dans le bon sens (continue ou stoppe).
  4. Faire progresser explicitement vers l'arrêt dans le corps.
  5. Dérouler un exemple : la boucle s'arrête-t-elle vraiment ?

9. Révision active

Résumé essentiel
  • TantQue : test avant, 0 tour possible, continue si vrai.
  • Répéter...Jusqu'à : test après, au moins 1 tour, stoppe si vrai.
  • Terminaison = initialisation + condition + progression.
  • Syracuse, seuils, saisies valides : le domaine du TantQue.
  • Pour quand le nombre de tours est connu.

Checklist de maîtrise

  • Je choisis entre Pour, TantQue et Répéter.
  • Ma condition d'arrêt finit par devenir fausse (ou vraie).
  • Je n'écris jamais de boucle infinie.
  • Je traduis un algorithme à condition d'arrêt en programme.
