Chapitre 5 — Boucles : TantQue et Répéter

Module 5 ≈ 2 h 30 de travail B1 et plus
Mise en situation

Demande un nombre à un utilisateur jusqu'à ce qu'il donne une valeur valide. Combien d'essais faudra-t-il ? On n'en sait rien : c'est le cas de la boucle à condition, TantQue ou Répéter, quand le nombre de tours est inconnu à l'avance.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. Écrire une boucle TantQue (while) avec une condition d'arrêt correcte ;
  2. distinguer TantQue (test avant) et Répéter...Jusqu'à (test après) ;
  3. éviter les boucles infinies ;
  4. traduire un algorithme à condition d'arrêt (seuil, Syracuse) en programme.

1. La boucle TantQue

Définition. La boucle TantQue répète son corps tant que sa condition reste vraie. La condition est testée avant chaque tour : si elle est fausse dès le départ, le corps ne s'exécute jamais (zéro tour possible).

Pseudo-code
TantQue somme < seuil Faire
  terme ← terme + 1
  somme ← somme + terme
FinTantQue
while somme < seuil do
begin
  terme := terme + 1;
  somme := somme + terme;
end;
while somme < seuil:
    terme += 1
    somme += terme

2. La boucle Répéter...Jusqu'à

Définition. Répéter exécute son corps au moins une fois, puis recommence jusqu'à ce que la condition devienne vraie. Le test est en fin de boucle, et la logique est inversée : on répète jusqu'à ce que la condition d'arrêt soit vraie.

Pseudo-code
Répéter
  Écrire "Entrez 1 pour continuer"
  Lire choix
Jusqu'à choix = 1
repeat
  write('Entrez 1 pour continuer : ');
  readln(choix);
until choix = 1;
while True:
    choix = int(input("Entrez 1 pour continuer : "))
    if choix == 1:
        break

Python n'a pas d'équivalent direct : on combine while et break.

Niveau 1 — Intuition

TantQue ressemble à un agent qui regarde avant d'agir : s'il voit un mur dès le départ, il ne bouge pas. Répéter...Jusqu'à ressemble à quelqu'un qui agit d'abord et regarde ensuite : il avance au moins un pas, puis vérifie s'il peut s'arrêter.

3. La boucle infinie : l'ennemi n°1

Une boucle TantQue s'arrête seulement si sa condition devient fausse. Trois causes classiques de boucle infinie :

  • Le compteur n'avance pas : i ← i + 1 oublié dans le corps ;
  • La condition ne peut jamais devenir fausse : on teste une variable jamais modifiée ;
  • Le sens du test est inversé : < au lieu de <= près d'une borne.
La règle des trois points

Toute boucle TantQue correcte précise : (1) l'initialisation des variables testées, (2) la condition d'arrêt, (3) l'instruction qui fait progresser vers l'arrêt. Si l'un des trois manque, la boucle est suspecte.

4. Exemple complet : la conjecture de Syracuse

Pseudo-code
Lire valeur
étapes ← 0
TantQue valeur ≠ 1 Faire
  Si valeur mod 2 = 0 Alors valeur ← valeur div 2
  Sinon valeur ← 3 × valeur + 1
  étapes ← étapes + 1
FinTantQue
Écrire étapes
valeur = int(input())

etapes = 0
while valeur != 1:
    if valeur % 2 == 0:
        valeur //= 2
    else:
        valeur = 3 * valeur + 1
    etapes += 1

print(etapes)

On ne sait pas combien d'étapes seront nécessaires : c'est exactement le cas du TantQue. La valeur diminue (ou varie) à chaque tour, et la condition d'arrêt est l'atteinte de 1.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Somme jusqu’au seuil

Python Niveau 3 — Raisonnement

Objectif : Écrire une boucle TantQue dont la condition dépend d’un accumulateur.

Le programme reçoit un entier seuil. Ajoutez les entiers naturels successifs (1, 2, 3, …) tant que la somme est strictement inférieure au seuil, puis affichez la somme obtenue et le nombre de termes ajoutés, séparés par une espace.

Entrée du programme
10
Sortie attendue
10 4

1 + 2 + 3 + 4 = 10 : quatre termes pour atteindre le seuil.

Deux indices, rédigés en mots
  1. Le test de la boucle porte sur la somme, pas sur le compteur : on continue tant qu’il reste de la marge sous le seuil.
  2. Deux variables évoluent ensemble : la somme et le nombre de termes ajoutés.

Exercice 2 — Compter les chiffres

Python Niveau 3 — Raisonnement

Objectif : Répéter une réduction jusqu’à la condition d’arrêt.

Le programme reçoit un entier positif. Affichez son nombre de chiffres, obtenu par divisions entières successives (sans convertir en texte).

Entrée du programme
4729
Sortie attendue
4

Quatre chiffres.

Deux indices, rédigés en mots
  1. Une division entière par 10 supprime le dernier chiffre : répétez-la jusqu’à ce que le nombre soit épuisé.
  2. Le cas particulier zéro compte pour un chiffre : traitez-le avant la boucle ou choisissez une boucle qui s’exécute au moins une fois.

Exercice 3 — Conjecture de Syracuse

Python Niveau 4 — Examen

Objectif : Écrire une boucle dont on ne connaît pas le nombre de tours à l’avance.

Le programme reçoit un entier strictement positif. Appliquez la suite de Syracuse : tant que la valeur n’est pas 1, divisez-la par 2 si elle est paire, sinon remplacez-la par 3 × valeur + 1. Comptez et affichez le nombre d’étapes nécessaires.

Entrée du programme
6
Sortie attendue
8

6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1 : huit étapes.

Deux indices, rédigés en mots
  1. La condition d’arrêt est l’atteinte de 1 : la boucle tourne tant que ce n’est pas le cas.
  2. Deux transformations coexistent selon la parité ; une seule s’applique par étape, et chaque transformation compte pour une étape.

6. QCM — niveau examen

Combien de tours au minimum pour un TantQue dont la condition est fausse dès le début ?

Le test est avant le corps : zéro tour possible.

Quelle boucle garantit au moins une exécution ?

Son test est en fin de boucle.

Cause classique de boucle infinie ?

Sans progression, la condition reste vraie pour toujours.

Répéter...Jusqu'à : quand s'arrête-t-elle ?

« Jusqu'à » exprime la condition d'arrêt, vraie en fin.

Pour une « saisie jusqu'à valeur valide », quelle boucle ?

Le nombre de tours dépend de l'utilisateur : condition d'arrêt.

Que faut-il vérifier en priorité sur un TantQue ?

C'est la garantie de terminaison.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Boucle infinie : compteur non avancé ou condition figée.
  • Confondre les deux logiques : TantQue continue si vrai ; Répéter s'arrête si vrai.
  • Initialisation oubliée : tester une variable jamais renseignée.
  • Test de bord : < au lieu de <=, un tour de trop ou de moins.
  • Répéter là où un Pour suffit : un compteur borné appelle un Pour.

8. Méthodologie de résolution

Écrire une boucle à condition
  1. Choisir la structure : Pour si compteur borné, TantQue sinon.
  2. Initialiser toutes les variables testées.
  3. Écrire la condition d'arrêt dans le bon sens (continue ou stoppe).
  4. Faire progresser explicitement vers l'arrêt dans le corps.
  5. Dérouler un exemple : la boucle s'arrête-t-elle vraiment ?

9. Révision active

Résumé essentiel
  • TantQue : test avant, 0 tour possible, continue si vrai.
  • Répéter...Jusqu'à : test après, au moins 1 tour, stoppe si vrai.
  • Terminaison = initialisation + condition + progression.
  • Syracuse, seuils, saisies valides : le domaine du TantQue.
  • Pour quand le nombre de tours est connu.

Checklist de maîtrise

  • Je choisis entre Pour, TantQue et Répéter.
  • Ma condition d'arrêt finit par devenir fausse (ou vraie).
  • Je n'écris jamais de boucle infinie.
  • Je traduis un algorithme à condition d'arrêt en programme.
