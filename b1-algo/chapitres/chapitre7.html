Chapitre 7 — Fonctions et procédures

Module 7 ≈ 3 h de travail B1 et plus
Mise en situation

Dans un programme qui gère des notes, le calcul de moyenne revient dix fois. Le recopier dix fois, c'est corriger dix endroits le jour où le barème change. La fonction isole un calcul sous un nom et le réutilise partout : c'est la brique de la décomposition.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. Distinguer fonction (renvoie une valeur) et procédure (n'en renvoie pas) ;
  2. déclarer paramètres et valeur de retour en pseudo-code et Pascal ;
  3. faire renvoyer plusieurs valeurs par une fonction ;
  4. décomposer un problème en fonctions à responsabilité unique.

1. Fonction ou procédure ?

Définition. Une fonction calcule et renvoie une valeur à l'appelant. Une procédure exécute des actions (afficher, remplir un tableau) sans rien renvoyer.

Pseudo-code
Fonction carre(n : Entier) : Entier
  Retourner n × n
FinFonction

Procédure AfficherLigne(n : Entier)
  Pour i de 1 à n Faire
    Écrire "-" (sans saut de ligne)
  FinPour
  Écrire ""  // saut de ligne
FinProcédure
function carre(n: integer): integer;
begin
  carre := n * n;
end;

procedure AfficherLigne(n: integer);
var i: integer;
begin
  for i := 1 to n do
    write('-');
  writeln;
end;
def carre(n):
    return n * n

def afficher_ligne(n):
    print("-" * n)

En Pascal, la valeur de retour est rangée dans une variable portant le nom de la fonction ; en Python, elle part avec return.

Piège — print n'est pas return

Une fonction qui affiche son résultat mais ne le renvoie pas renvoie en réalité None : l'appelant ne peut rien en faire. Renvoyer et afficher sont deux actes différents : la fonction renvoie, le programme principal affiche.

2. Paramètres et portée

Définition. Les paramètres sont les entrées locales de la fonction. Une variable déclarée dans une fonction n'existe que dans cette fonction : c'est sa portée.

TypePortée
Variable localeDans la fonction où elle est définie ; en Python, une boucle ne crée pas de portée distincte.
ParamètreComme une locale de la fonction.
Variable globaleDéclarée hors fonction : visible partout, à éviter.

En Python, un paramètre est un nom local associé à l'objet transmis, sans copie automatique. Une réaffectation du nom local ne remplace pas l'objet de l'appelant ; une modification en place d'une liste partagée est visible par l'appelant.

def remplacer(liste):
    liste = [99]

def ajouter(liste):
    liste.append(2)

notes = [1]
remplacer(notes)
print(notes)
ajouter(notes)
print(notes)

Le premier affichage est [1] : seul le nom local a été réaffecté. Le second est [1, 2] : append a modifié la liste partagée.

Pourquoi éviter les globales

Une fonction qui lit ou modifie une variable globale dépend d'un état extérieur invisible : elle devient plus difficile à tester isolément et se réutilise mal. Pour la rendre autonome, privilégiez les paramètres et les valeurs de retour ; une modification de liste reçue reste possible et doit être explicite.

3. Renvoyer plusieurs valeurs

Une fonction ne renvoie qu'une seule chose. Pour deux résultats (moyenne et maximum, par exemple), on les regroupe dans un couple :

def calcul_statistiques(notes):
    # ... un seul parcours : total et maximum
    return moyenne, maximum   # un couple

moy, maxi = calcul_statistiques(notes)

En Pascal, on emploie un enregistrement ou des paramètres variables (var) ; la notion est reprise au module 8 avec les structures.

4. Décomposer un problème

La bonne question : « quelles sont les responsabilités de mon programme ? » Chacune devient une fonction d'une seule responsabilité, testable séparément.

def somme(t):
    total = 0
    for valeur in t:
        total += valeur
    return total

def moyenne(t):
    if not t:
        return 0.0
    return somme(t) / len(t)   # réutilisation

moyenne appelle somme : une fonction bien découpée se réutilise dans les autres.

Exercice 1 — Une fonction qui renvoie une valeur

Pseudo-code Niveau 3 — Raisonnement

Objectif : Distinguer Retourner de Afficher dans une fonction.

Complétez la fonction carre pour qu’elle renvoie le carré de son argument (sans rien afficher). Le programme principal lit un entier, appelle la fonction et affiche le résultat sous la forme Carre : <valeur>.

Entrée du programme
7
Sortie attendue
Carre : 49

Le carré de sept vaut quarante-neuf.

Trois indices, rédigés en mots
  1. Une fonction qui renvoie une valeur utilise l’instruction de retour ; l’affichage appartient au programme appelant.
  2. Le carré d’un nombre est son produit par lui-même.
  3. Étapes : dans la fonction, Retourner x × x ; le principal se contente d’afficher l’étiquette et le résultat de l’appel.

Exercice 2 — calcul_statistiques — sujet d’examen

Pseudo-code Niveau 4 — Examen

Objectif : Faire renvoyer deux résultats par une même fonction.

Écrivez calcul_statistiques(notes), une fonction qui reçoit un tableau de notes et renvoie deux résultats : la moyenne (division réelle) et le maximum, calculés en un seul parcours. Le programme principal lit un entier n ≥ 1, puis n notes, et affiche la moyenne avec deux décimales suivie du maximum, séparés par une espace. L’atelier ne renvoie qu’une valeur par Retourner : choisissez comment combiner les deux résultats (par exemple mémoriser le maximum dans une variable globale).

Entrée du programme
5
12
15
14

18
Sortie attendue
13.60 18

Moyenne 13.60 et maximum 18.

Trois indices, rédigés en mots
  1. Un seul parcours met à jour trois choses : le total des notes, le record courant, et le nombre de notes déjà vues.
  2. Le record se mémorise dans la variable globale pendant que la fonction renvoie la moyenne : le principal affiche ensuite les deux résultats.

Exercice 3 — Fonction booléenne et réutilisation

Pseudo-code Niveau 4 — Examen

Objectif : Écrire une fonction de test et l’appeler depuis une autre.

Écrivez est_premier(n) qui renvoie VRAI ou FAUX, puis compte_premiers(limite) qui renvoie combien de nombres premiers existent entre 2 et limite inclus. Le programme lit la limite et affiche le compte.

Entrée du programme
10
Sortie attendue
4

2, 3, 5 et 7 sont premiers : quatre nombres.

Trois indices, rédigés en mots
  1. Un nombre premier n’admet aucun diviseur autre que un et lui-même : testez les candidats diviseurs à partir de deux.
  2. La fonction de comptage réutilise la fonction de test pour chaque valeur de l’intervalle : c’est la composition des fonctions.
  3. Étapes : est_premier : Si n < 2 Alors FAUX ; Pour d De 2 A n-1 : Si n MOD d = 0 Alors Retourner FAUX ; Retourner VRAI. compte_premiers : compteur = 0 ; Pour v De 2 A limite : Si est_premier(v) Alors compteur + 1 ; Retourner compteur.

6. QCM — niveau examen

Quelle est la différence fonction / procédure ?

C'est la seule différence de contrat.

Que renvoie une fonction sans return ?

Afficher n'est pas renvoyer.

Portée d'une variable déclarée dans une fonction ?

C'est une variable locale.

Comment une fonction renvoie-t-elle explicitement un résultat à l'appelant ?

Le retour transmet une valeur ; afficher ou stocker dans une globale ne constitue pas un retour. Une fonction peut aussi modifier une liste reçue, sans que ce soit une valeur renvoyée.

Une fonction reçoit une liste et ajoute un élément avec append. Que voit l'appelant ?

La liste n'est pas copiée automatiquement : append la modifie en place. Cela ne réaffecte pas les noms de l'appelant.

Pourquoi éviter les variables globales ?

Paramètres et retour rendent la fonction autonome.

Une fonction bien découpée a…

Une responsabilité = un test facile = une réutilisation possible.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • print au lieu de return : l'appelant reçoit None.
  • Oublier le return dans une branche de la fonction.
  • Confondre réaffectation locale et modification d'un objet partagé : réaffecter un nom ne modifie pas la liste, mais append la modifie en place.
  • Globale là où un paramètre suffit.
  • Une fonction qui fait tout : lecture, calcul, affichage mélangés.

8. Méthodologie de résolution

Concevoir une fonction
  1. Nommer par un verbe d'action : calculer_moyenne, est_premier.
  2. Lister les entrées : ce sont les paramètres.
  3. Déterminer la sortie : le type renvoyé (ou procédure).
  4. Écrire le corps : une seule responsabilité.
  5. Tester depuis le programme principal sur des cas limites.

9. Révision active

Résumé essentiel
  • Fonction = renvoie une valeur ; procédure = agit sans retour.
  • return transmet le résultat ; print ne fait qu'afficher.
  • Portée locale : une variable n'existe que dans sa fonction.
  • Plusieurs résultats → un couple (ou un enregistrement).
  • Décomposition = fonctions à responsabilité unique, réutilisables.

Checklist de maîtrise

  • Je distingue fonction et procédure sans hésiter.
  • Je renvoie mes résultats par return, pas par print.
  • Je limite la portée de mes variables.
  • Je découpe un problème en fonctions testables.
