Chapitre 7 — Fonctions et procédures

Module 7 ≈ 3 h de travail B1 et plus
Mise en situation

Dans un programme qui gère des notes, le calcul de moyenne revient dix fois. Le recopier dix fois, c'est corriger dix endroits le jour où le barème change. La fonction isole un calcul sous un nom et le réutilise partout : c'est la brique de la décomposition.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. Distinguer fonction (renvoie une valeur) et procédure (n'en renvoie pas) ;
  2. déclarer paramètres et valeur de retour en pseudo-code et Pascal ;
  3. faire renvoyer plusieurs valeurs par une fonction ;
  4. décomposer un problème en fonctions à responsabilité unique.

1. Fonction ou procédure ?

Définition. Une fonction calcule et renvoie une valeur à l'appelant. Une procédure exécute des actions (afficher, remplir un tableau) sans rien renvoyer.

Pseudo-code
Fonction carre(n : Entier) : Entier
  Retourner n × n
FinFonction

Procédure AfficherLigne(n : Entier)
  Pour i de 1 à n Faire
    Écrire "-" (sans saut de ligne)
  FinPour
  Écrire ""  // saut de ligne
FinProcédure
function carre(n: integer): integer;
begin
  carre := n * n;
end;

procedure AfficherLigne(n: integer);
var i: integer;
begin
  for i := 1 to n do
    write('-');
  writeln;
end;
def carre(n):
    return n * n

def afficher_ligne(n):
    print("-" * n)

En Pascal, la valeur de retour est rangée dans une variable portant le nom de la fonction ; en Python, elle part avec return.

Piège — print n'est pas return

Une fonction qui affiche son résultat mais ne le renvoie pas renvoie en réalité None : l'appelant ne peut rien en faire. Renvoyer et afficher sont deux actes différents : la fonction renvoie, le programme principal affiche.

2. Paramètres et portée

Définition. Les paramètres sont les entrées locales de la fonction. Une variable déclarée dans une fonction n'existe que dans cette fonction : c'est sa portée.

TypePortée
Variable localeSeulement dans la fonction (ou le bloc) où elle est déclarée.
ParamètreComme une locale de la fonction.
Variable globaleDéclarée hors fonction : visible partout, à éviter.
Pourquoi éviter les globales

Une fonction qui lit ou modifie une variable globale dépend d'un état extérieur invisible : elle devient impossible à tester isolément et se réutilise mal. La règle du cours : toute information entre par les paramètres, toute information sort par la valeur de retour.

3. Renvoyer plusieurs valeurs

Une fonction ne renvoie qu'une seule chose. Pour deux résultats (moyenne et maximum, par exemple), on les regroupe dans un couple :

def calcul_statistiques(notes):
    # ... un seul parcours : total et maximum
    return moyenne, maximum   # un couple

moy, maxi = calcul_statistiques(notes)

En Pascal, on emploie un enregistrement ou des paramètres variables (var) ; la notion est reprise au module 8 avec les structures.

4. Décomposer un problème

La bonne question : « quelles sont les responsabilités de mon programme ? » Chacune devient une fonction d'une seule responsabilité, testable séparément.

def somme(t):
    total = 0
    for valeur in t:
        total += valeur
    return total

def moyenne(t):
    if not t:
        return 0.0
    return somme(t) / len(t)   # réutilisation

moyenne appelle somme : une fonction bien découpée se réutilise dans les autres.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute le code et la validation fait tourner des jeux de tests indépendants : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire le code de la solution — c’est le principe de l’exercice.

Exercice 1 — Une fonction qui renvoie une valeur

Python Niveau 3 — Raisonnement

Objectif : Distinguer return de print dans une fonction.

Complétez la fonction carre pour qu’elle renvoie le carré de son argument. Le programme lit un entier, appelle la fonction et affiche le résultat sous la forme Carre : <valeur>.

Entrée du programme
7
Sortie attendue
Carre : 49

7² = 49.

Deux indices, rédigés en mots
  1. Une fonction qui affiche mais ne renvoie rien produit None : c’est le signe qu’un print a remplacé le return.
  2. Le mot-clé de retour est suivi de l’expression à renvoyer à l’appelant.

Exercice 2 — calcul_statistiques — sujet d’examen

Python Niveau 4 — Examen

Objectif : Faire renvoyer plusieurs valeurs par une fonction.

Écrivez calcul_statistiques(liste_notes) qui renvoie le couple (moyenne, maximum) en un seul parcours, sans sum() ni max(). Le programme lit un entier n, puis n notes, et affiche la moyenne avec deux décimales suivie du maximum, séparés par une espace.

Entrée du programme
5
12
15
14
9
18
Sortie attendue
13.60 18

Moyenne 13.60 et maximum 18.

Deux indices, rédigés en mots
  1. Une fonction ne renvoie qu’une seule chose : pour en faire passer deux, groupez-les dans un couple séparé par une virgule.
  2. Le maximum se cherche en mémorisant un candidat, puis en le remplaçant dès qu’un élément le dépasse.

Exercice 3 — Fonction booléenne et réutilisation

Python Niveau 4 — Examen

Objectif : Écrire une fonction de test et l’appeler depuis une autre.

Écrivez est_premier(n) qui renvoie True ou False, puis compte_premiers(limite) qui renvoie combien de nombres premiers existent entre 2 et limite inclus. Le programme lit la limite et affiche le compte.

Entrée du programme
10
Sortie attendue
4

2, 3, 5 et 7 sont premiers : quatre au total.

Deux indices, rédigés en mots
  1. Un nombre premier n’a aucun diviseur autre que 1 et lui-même : dès qu’un diviseur est trouvé, le verdict est rendu.
  2. La fonction de comptage n’a pas à refaire le travail : elle appelle la fonction de test pour chaque candidat.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • print au lieu de return : l'appelant reçoit None.
  • Oublier le return dans une branche de la fonction.
  • Modifier un paramètre en croyant modifier l'appelant (copie).
  • Globale là où un paramètre suffit.
  • Une fonction qui fait tout : lecture, calcul, affichage mélangés.

8. Méthodologie de résolution

Concevoir une fonction
  1. Nommer par un verbe d'action : calculer_moyenne, est_premier.
  2. Lister les entrées : ce sont les paramètres.
  3. Déterminer la sortie : le type renvoyé (ou procédure).
  4. Écrire le corps : une seule responsabilité.
  5. Tester depuis le programme principal sur des cas limites.

9. Révision active

Résumé essentiel
  • Fonction = renvoie une valeur ; procédure = agit sans retour.
  • return transmet le résultat ; print ne fait qu'afficher.
  • Portée locale : une variable n'existe que dans sa fonction.
  • Plusieurs résultats → un couple (ou un enregistrement).
  • Décomposition = fonctions à responsabilité unique, réutilisables.

Checklist de maîtrise

  • Je distingue fonction et procédure sans hésiter.
  • Je renvoie mes résultats par return, pas par print.
  • Je limite la portée de mes variables.
  • Je découpe un problème en fonctions testables.
