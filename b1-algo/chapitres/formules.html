Mémo — pseudo-code, Pascal et Python

Les mêmes constructions dans les trois écritures du cours. À garder ouvert pendant les exercices.

Variables et affectation

Pseudo-code
Variable x : Entier
x ← 5
var x : integer;
x := 5;
x = 5

Pascal distingue := (affectation) et = (comparaison). Python utilise = pour les deux.

Entrées / sorties

Pseudo-code

writeln('x = ', x);

Test alternatif

Pseudo-code
Si note ≥ 10 Alors
  Écrire "Admis"
Sinon
  Écrire "Ajourné"
FinSi
if note >= 10 then
  writeln('Admis')
else
  writeln('Ajourné');
if note >= 10:
    print("Admis")
else:
    print("Ajourné")

Cascade : Si...Alors Sinon Si...Alors Sinon (pseudo-code), else if (Pascal : else if), elif (Python). En Pascal, pas de point-virgule avant else.

Selon (choix multiple)

Pseudo-code
Selon jour Faire
  1 : Écrire "Lundi"
  6, 7 : Écrire "Week-end"
  Sinon Écrire "Autre"
FinSelon
case jour of
  1: writeln('Lundi');
  6, 7: writeln('Week-end');
  else writeln('Autre');
end;

Boucle Pour

Pseudo-code
Pour i de 1 à 10 Faire
  Écrire i
FinPour
for i := 1 to 10 do
  writeln(i);
for i in range(1, 11):
    print(i)

En Pascal, la borne de fin est incluse. En Python, range(fin) exclut la fin : pour aller jusqu'à 10, écrire range(1, 11).

Boucle TantQue

Pseudo-code
TantQue somme < seuil Faire
  i ← i + 1
  somme ← somme + i
FinTantQue
while somme < seuil do
begin
  i := i + 1;
  somme := somme + i;
end;
while somme < seuil:
    i += 1
    somme += i

Répéter...Jusqu'à

Pseudo-code
Répéter
  Lire choix
Jusqu'à choix = 1
repeat
  readln(choix);
until choix = 1;

Pas d'équivalent direct en Python : utiliser une boucle avec break.

Tableaux

Pseudo-code
Tableau t[10] : Entiers
t[0] ← 5
var t : array[1..10] of integer;
t[1] := 5;
t = [0] * 10
t[0] = 5

Attention : les indices commencent à 0 en Python, et peuvent commencer à 1 en Pascal selon la déclaration.

Fonctions

Pseudo-code
Fonction carre(n : Entier) : Entier
  Retourner n × n
FinFonction
function carre(n: integer): integer;
begin
  carre := n * n;
end;
def carre(n):
    return n * n

Trames d'algorithmes classiques

# Somme 1..n
somme = 0
for i in range(1, n + 1):
    somme += i

# Maximum d'un tableau
maximum = tableau[0]
for valeur in tableau:
    if valeur > maximum:
        maximum = valeur

# Recherche séquentielle
trouve = -1
for i in range(n):
    if tableau[i] == cible:
        trouve = i
        break

# Tri par sélection
for debut in range(n - 1):
    indice_min = debut
    for i in range(debut + 1, n):
        if tableau[i] < tableau[indice_min]:
            indice_min = i
    tableau[debut], tableau[indice_min] = tableau[indice_min], tableau[debut]

Erreurs fréquentes à éviter

  • Confondre = (comparaison) et ←/:= (affectation).
  • Initialiser l'accumulateur dans la boucle.
  • Oublier d'avancer le compteur dans un TantQue (boucle infinie).
  • Confondre borne incluse (Pascal) et borne exclue (Python range).
  • Initialiser le maximum à zéro avec des valeurs négatives.
  • Oublier le point-virgule ou en mettre un avant else en Pascal.
