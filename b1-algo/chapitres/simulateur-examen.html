Exercice 1/4 — Analyse d'algorithme

Soit l'algorithme suivant :

Pseudo-code
S ← 0
Pour i de 1 à 4 Faire
  S ← S + i × i
FinPour
Écrire S

(a) (2 pts) Trace l'exécution (valeur de S après chaque tour). (b) (1 pt) Que vaut S à la fin ? (c) (1 pt) Que calcule cet algorithme en général ?

Corrigé
(a) i=1 : S=1 ; i=2 : S=5 ; i=3 : S=14 ; i=4 : S=30. (b) S = 30. (c) La somme des carrés des entiers de 1 à 4 : 1² + 2² + 3² + 4².
Exercice 2/5 — Écriture d'algorithme

Écris un algorithme en pseudo-code puis son équivalent Pascal qui lit un entier n et affiche la somme des entiers impairs de 1 à n.

Corrigé
Pseudo-code
Lire n
S ← 0
Pour i de 1 à n Faire
  Si i mod 2 = 1 Alors S ← S + i
FinPour
Écrire S
program somme_impairs;
var n, i, s: integer;
begin
  readln(n);
  s := 0;
  for i := 1 to n do
    if i mod 2 = 1 then
      s := s + i;
  writeln(s);
end.
Exercice 3/4 — Tableau

Écris un algorithme qui lit n puis n entiers dans un tableau, puis affiche la moyenne, la plus grande et la plus petite valeur.

Corrigé
n = int(input())
t = [int(input()) for i in range(n)]

somme = 0
maximum = t[0]
minimum = t[0]
for valeur in t:
    somme += valeur
    if valeur > maximum:
        maximum = valeur
    if valeur < minimum:
        minimum = valeur

print(somme / n)
print(maximum)
print(minimum)
Initialiser max et min au premier élément (pas à zéro) : sinon des valeurs négatives faussent le résultat.
Exercice 4/3 — Boucle TantQue

Écris un algorithme qui lit un entier strictement positif et affiche combien de fois on peut le diviser par 2 avant qu'il ne devienne impair ou égal à 1.

Corrigé
valeur = int(input())
compte = 0
while valeur % 2 == 0 and valeur > 1:
    valeur //= 2
    compte += 1
print(compte)
Exemple : 40 → 20 → 10 → 5 (impair) : trois divisions.
Exercice 5/4 — Fonction

Écris une fonction factorielle(n) (itérative) puis un programme principal qui lit n et affiche sa factorielle.

Corrigé
def factorielle(n):
    produit = 1
    for i in range(1, n + 1):
        produit *= i
    return produit

n = int(input())
print(factorielle(n))
L'accumulateur vaut 1 (élément neutre du produit) : la convention 0! = 1 est respectée.

Examen blanc n°2 — variante

Exercice 1/4 — Traduction Pascal

Traduis en Pascal : « Lire deux entiers a et b ; afficher le plus grand sans utiliser de fonction max ».

Corrigé
program plus_grand;
var a, b: integer;
begin
  readln(a, b);
  if a > b then
    writeln(a)
  else
    writeln(b);
end.
Exercice 2/4 — Matrice

Écris un algorithme qui lit une matrice carrée 3×3 et affiche la somme de sa diagonale principale.

Corrigé
m = [[int(v) for v in input().split()] for i in range(3)]
somme = 0
for i in range(3):
    somme += m[i][i]
print(somme)

Exercice 4/4 — Récursivité

Écris une fonction récursive somme(n) qui renvoie 1 + 2 + … + n (n ≥ 0), puis explique le cas de base.

Corrigé
def somme(n):
    if n == 0:
        return 0
    return n + somme(n - 1)
Le cas de base est n = 0 : il répond sans appel récursif et garantit l'arrêt.

QCM final — toutes notions

Que fait l'affectation x ← x + 1 ?

La droite est calculée avec l'ancienne valeur, puis rangée dans x.

Quelle structure choisir pour un nombre de tours connu à l'avance ?

La boucle Pour est un compteur borné.

Quelle boucle s'exécute au moins une fois ?

Le test est en fin de boucle : le corps s'exécute d'abord.

Que vaut 17 div 5 ? Et 17 mod 5 ?

17 = 3 × 5 + 2 : quotient 3, reste 2.

Dans une cascade Si/Sinon Si, quelle branche s'exécute ?

Dès qu'une condition est satisfaite, les suivantes sont ignorées.

Où doit s'initialiser un accumulateur ?

Initialisé dans la boucle, il repart de zéro à chaque tour.

Quel est le dernier indice d'un tableau de n éléments (indexé à partir de 0) ?

Les indices vont de 0 à n − 1.

Que renvoie une fonction sans return ?

Afficher n'est pas renvoyer : sans return, la valeur est None.

Condition de validité de la recherche dichotomique ?

Sans tri, éliminer la moitié du tableau n'a aucun sens.

Qu'est-ce qui garantit l'arrêt d'une fonction récursive ?

Le cas de base répond sans rappel : chaque appel se rapproche de lui.
