Chapitre 4 — Pronunciation and fluency techniques

Module 4 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

Leo a le vocabulaire et la structure, mais en appel il n'est pas compris : « tink » pour think, l'h muet, un débit robot sans pauses. La prononciation ne se corrige pas par la lecture — elle se travaille son par son, mot par mot, groupe de souffle par groupe de souffle.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. produire les sons /θ/ (think) et /ð/ (the) avec la langue entre les dents ;
  2. prononcer le h aspiré (hello, have, help) sans le taire ;
  3. classer les -ed endings en /t/, /d/ et /ɪd/ ;
  4. couper la phrase en thought groups pour sonner naturel.

1. Les cinq sons problématiques

Le support liste les cinq difficultés des francophones : le /θ/ de think, three, deadline (ni « tink » ni « sink ») ; le /ð/ de the, this, that ; le /h/ de hello, have, help (pas silencieux !) ; le e final souvent muet (make, time, note) ; et les terminaisons -ed en /t/, /d/ ou /ɪd/.

Le /θ/ — the tongue sandwich : la langue entre les dents, souffler. Mots à répéter : think, thanks, three, month, deadline, both. Exercice du support : « Thank you for the thoughtful thing » cinq fois. Le /h/ — don't be silent : expirer fort, pas « 'ello » mais « hello » — « How have you been ? Happy to help ! » en accentuant chaque H.

Les -ed endings se prononcent de trois façons : /t/ après son sourd (walked, laughed, missed), /d/ après son voisé (called, loved, changed), /ɪd/ après T ou D (wanted, needed, started). Exercice : trier fixed, ended, deployed, tested, used.

Mnémotechnique — « la langue entre les dents, l'h qui souffle, le -ed à trois voix »

/θ/ et /ð/ = langue entre les dents (sandwich). /h/ = souffle audible. -ed = /t/ après sourd, /d/ après voisé, /ɪd/ après T ou D. Trois réflexes qui débloquent 80 % de l'intelligibilité.

2. Accent, pauses et fluidité

L'accent de mot change le sens : REcord (nom, un fichier) contre reCORD (verbe, enregistrer) ; PREsent (cadeau) contre preSENT (montrer). Exercice du support : CONduct/conDUCT, OBject/obJECT.

L'accent de phrase met en relief le mot important : « I didn't delete the file » change de sens selon le mot accentué (quelqu'un d'autre l'a fait ; je le nie fortement ; j'ai fait autre chose ; j'ai supprimé autre chose).

Les thought groups coupent la phrase aux frontières naturelles : « We need to finish by Friday (pause) so let's work hard ». Le linking soude les mots : « get on » devient « Ge-ton », « not at all » devient « No-ta-tall », « an apple » devient « A-napple » — la phrase coule d'un seul tenant : « What are you waiting for ? ».

L'intonation monte pour les questions oui/non (« Are you coming ? ↗ ») et descend pour les déclarations et questions WH (« Where are you going ? ↘ »). Le recording lab du support fait écouter sa propre voix : est-ce que je perds les H ? Est-ce que je pause ? Mon accent est-il juste ?

Confusions d'examen
  • « Tink » pour think : le /θ/ exige la langue entre les dents, pas un t ni un s.
  • « 'ello » pour hello : le /h/ se souffle, il ne se tait pas.
  • Tous les -ed ne se prononcent pas pareil : wanted (/ɪd/) et walked (/t/) diffèrent.
  • Débit continu sans pauses : la fluidité n'est pas la vitesse, c'est le rythme.

3. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — The three -ed endings

Bash Niveau 1 — Acquisition

Objectif : Classer les verbes au prétérit selon la prononciation du -ed : /t/, /d/ ou /ɪd/.

Le script lit n lignes « verbe son » : son vaut t (walked), d (played) ou id (wanted). Pour chaque ligne il affiche verbe : /X/ où X est t, d ou ɪd. Il termine par trois lignes de comptage dans cet ordre : son-t : X, son-d : X, son-id : X.

Entrée du programme
3
walked t
played d
wanted id
Sortie attendue
walked : /t/
played : /d/
wanted : /ɪd/
son-t : 1
son-d : 1
son-id : 1
Deux indices, rédigés en mots
  1. Un case à trois sons : t, d, id.
  2. Les trois totaux sortent après la boucle, dans l'ordre demandé.

Exercice 2 — Word stress pairs

Bash Niveau 2 — Application

Objectif : Distinguer les paires d'accentuation : REcord (nom) / reCORD (verbe) — le sens change avec l'accent.

Le script lit n lignes « mot classe » : classe vaut noun ou verb. Pour chaque ligne il affiche mot : forme, où forme vaut REcord (noun) ou reCORD (verb). Il termine par noms : X/n.

Entrée du programme
4
record noun
record verb
present noun
present verb
Sortie attendue
record : REcord
record : reCORD
present : PREsent
present : preSENT
noms : 2/4
Deux indices, rédigés en mots
  1. Un if sur la classe suffit : noun et verb sont les deux seules valeurs.
  2. Comptez seulement les noms (accent en tête).

Exercice 3 — Thought groups and pausing

Bash Niveau 3 — Raisonnement

Objectif : Simuler les groupes de souffle : couper la phrase aux bons endroits pour ne plus sonner comme un robot.

Le script lit n lignes « position groupe » : position est un entier et groupe vaut pause ou run. Le script mesure la longueur des séquences consecutives de run séparées par des pause : une séquence de plus de 4 mots sonne robot. Pour chaque ligne il affiche position groupe : compteur où compteur est la longueur de la séquence courante de run (0 si pause). Final : sequences robot : X (nombre de séquences de run de longueur strictement supérieure à 4).

Entrée du programme
5
1 run
2 run
3 pause
4 run
5 pause
Sortie attendue
1 run : compteur 1
2 run : compteur 2
3 pause : compteur 0
4 run : compteur 1
5 pause : compteur 0
sequences robot : 0
Deux indices, rédigés en mots
  1. run incrémente le compteur courant ; pause clôture la séquence : si courant > 4, robots++ puis courant = 0.
  2. Ne pas oublier la dernière séquence si elle se termine sans pause finale.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Prononcer think comme tink ou sink : la langue doit être entre les dents.
  • Taquer le h de hello, have, help : il se souffle.
  • Dire tous les -ed en /ɪd/ : trois prononciations existent selon le son final.
  • Lire ses notes à voix robot : accentuer le mot-clé et respirer par groupes.

6. Méthodologie de résolution

Méthode — travailler un son en quatre gestes
  1. Isoler le son : écouter, répéter dix fois (drill du support).
  2. Le replacer dans des mots fréquents : think, three, month, deadline.
  3. Le replacer dans une phrase complète avec linking et pauses.
  4. S'enregistrer et s'auto-corriger : H perdus ? Pauses ? Accent ?

7. Révision active

Résumé essentiel
  • Cinq sons difficiles : /θ/, /ð/, /h/, e final muet, -ed à trois voix.
  • /θ/ et /ð/ : langue entre les dents ; /h/ : souffle audible.
  • -ed : /t/ après sourd, /d/ après voisé, /ɪd/ après T ou D.
  • Accent de mot (REcord/reCORD) et de phrase, thought groups, linking, intonation ↗/↘.

Checklist de maîtrise

  • Je sais produire /θ/ dans cinq mots sans y penser.
  • Je sais trier dix verbes en -ed selon leur son.
  • Je sais accentuer REcord/reCORD et PREsent/preSENT.
  • Je sais couper une phrase en thought groups et la lire en fluide.

Les 8 notions à connaître absolument

  1. /θ/ (think) : langue entre les dents, souffle.
  2. /ð/ (the) : même position, son voisé.
  3. /h/ (hello) : h aspiré, jamais muet.
  4. -ed /t/ : après son sourd (walked).
  5. -ed /ɪd/ : après T ou D (wanted).
  6. Word stress : REcord (nom) vs reCORD (verbe).
  7. Thought groups : pauses aux frontières naturelles.
  8. Intonation ↗/↘ : montante oui/non, descendante ailleurs.

8. Test de maîtrise

Comment t'auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lis ton pourcentage :

< 50 % — reprennez les cinq sons, un par un, avec les drills.
50–69 % — refaites le tri des -ed et les paires d'accent.
70–89 % — bon niveau, ciblez linking et intonation.
≥ 95 % — niveau de maîtrise recherché.
