Chapitre 6 — Professional grammar and assessment

Mise en situation

Le test final approche. Leo relit ses emails : « Me want finish work soon yes », « You send file yesterday ? » — phrases télégraphiques sans sujet, sans verbe conjugué, sans politesse. La grammaire professionnelle, c'est la politesse rendue syntaxique : sujet + verbe conjugué + formule. Puis le verdict : admis ou entraînement.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. transformer les phrases télégraphiques en requêtes polies complètes ;
  2. corriger les accords sujet-verbe (singular/plural) ;
  3. réutiliser le vocabulaire des sessions précédentes en contexte ;
  4. s'auto-évaluer sur les quatre compétences du module.

1. Requêtes polies et accords

Le tableau « bad business English » du support se corrige avec trois ingrédients : un sujet, un verbe conjugué, une formule polie. « Me want finish work soon yes » → « I want to finish work soon » ; « You send file yesterday ? » → « Did you send the file yesterday ? » ; « Server crash. Fix now ! » → « The server crashed. Could we please fix it now ? » ; « Client call. You talk. Not me. » → « The client is calling. Can you talk to them ? I cannot. »

L'accord sujet-verbe complete : le sujet singulier prend le verbe avec -s (the server works), le sujet pluriel sans -s (the servers work). Une erreur d'accord dans un email client passe pour de la négligence : la relecture n'est pas optionnelle.

Les formules de politesse structurent la requête : « Could you please… », « Would you be able to… », « I would appreciate it if you could… ». Le refus poli : « I cannot », puis une alternative — jamais un sec « no ».

Mnémotechnique — « S-V-P : sujet, verbe, politesse »

Toute requête professionnelle se construit en trois temps : sujet explicite, verbe conjugué, formule de politesse. S-V-P comme « s'il vous plaît » — justement.

2. L'évaluation finale

Le bilan du support résume le parcours de Leo : session 1 (vocabulaire), session 2 (emails), session 3 (présentations), session 4 (prononciation). L'évaluation finale couvre les quatre compétences : vocabulary, email writing, oral presentation, pronunciation — chacune notée, moyennée, comparée au seuil de passage.

La moyenne se calcule : somme des scores divisée par le nombre de compétences. Le verdict suit : admis (moyenne ≥ seuil) ou entraînement (retour aux exercices ciblés de la compétence la plus faible). Et la conclusion du support vaut programme : « You passed. But fluency is a habit, not a destination. »

Confusions d'examen
  • Phrase sans sujet : « Me want… » n'existe pas en anglais professionnel — I want to…
  • Verbe non conjugué : « You send file yesterday ? » → Did you send… ?
  • Refus sec : « Not me » heurte ; « I cannot, but… » garde la relation.
  • Moyenne sans pondération : chaque compétence compte autant dans le calcul du verdict.

3. Études de cas & applications pratiques

Ces trois études de cas se réalisent directement dans la page. Complétez chaque grille d’analyse à partir des données du cas, puis lancez la validation pour vérifier vos réponses critère par critère.

La validation compare vos réponses aux attendus des cas affichés ; elle ne vérifie pas votre capacité à traiter toutes les situations.

En cas d’hésitation, le bouton Obtenir une aide formative générale fournit un conseil identique pour toutes les grilles, sans transmettre de réponse attendue ni utiliser le tuteur IA.

Exercice 1 — S-V-P : les phrases télégraphiques de Leo

Étude de cas Formative Niveau 1 — Acquisition

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Transformer des phrases télégraphiques en requêtes polies : sujet, verbe conjugué, politesse.

Énoncé. Le test final approche. Leo relit ses anciens messages et retrouve quatre phrases télégraphiques (« bad business English »). La méthode du cours : S-V-P — un sujet (Subject), un verbe conjugué (Verb), une formule de politesse (Politeness).

N°Phrase de LeoCorrection visée
1« Me want finish work soon yes »« I want to finish work soon. »
2« You send file yesterday ? »« ___ you send the file yesterday ? »
3« Server crash. Fix now ! »« The server ___ last night. Could we please fix it now ? »
4« Client call. You talk. Not me. »« The client is calling. Can you talk to them ? I cannot. »
  1. Phrase 1 : quel sujet correct remplace « Me » ? (un seul mot)
  2. Phrase 2 : quel auxiliaire complète « ___ you send the file yesterday ? » ?
  3. Phrase 3 : quelle forme conjuguée du verbe crash complète « The server ___ last night » ?
  4. Dans la méthode S-V-P, que signifie le P ? Répondez par un mot (la politesse).
  5. « ___ you please review the attached report ? » : quel modal poli complète la requête du cours ?

Répondez en anglais, par un mot.

Cas d’exemple
Phrases de Nina :
1) « Want meeting tomorrow yes » → « I would like to have a meeting tomorrow. »
2) « You received my email yesterday ? » → « Did you receive my email yesterday ? »

Analyse :
1) Dans « Want meeting », il manque le sujet (I) et le verbe conjugué (would like).
2) Dans « You received... ? », l'auxiliaire did porte le temps : « Did you receive... ? »
Trois indices, rédigés en mots
  1. Toute requête professionnelle se construit en trois temps : sujet explicite, verbe conjugué, formule de politesse.
  2. Au past simple interrogatif, un auxiliaire porte le temps et le verbe reste à sa base : c'est lui qui manque à la phrase 2.
  3. Pour la phrase 3, conjuguez crash au passé ; pour la question 5, le modal du cours s'emploie avec please.

Exercice 2 — L'accord sujet-verbe dans le rapport mensuel

Étude de cas Formative Niveau 2 — Application

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Corriger les accords sujet-verbe : le singulier prend le -s, le pluriel le verbe nu.

Énoncé. Fin du mois : Leo relit son rapport mensuel avant l'envoi au client. Quatre accords sujet-verbe sont faux. Le rapport :

N°Phrase du rapport
1« The server work fine. »
2« The servers works fine. »
3« The report need an update. »
4« The clients wants a demo. »

Rappel du cours : le sujet singulier prend le verbe avec -s (the server works) ; le sujet pluriel prend le verbe sans -s (the servers work). Une erreur d'accord dans un email client passe pour de la négligence.

  1. Phrase 1 : quelle est la forme correcte du verbe « work » ?
  2. Phrase 2 : quelle est la forme correcte du verbe ?
  3. Phrase 3 : quelle est la forme correcte du verbe « need » ?
  4. Phrase 4 : quelle est la forme correcte du verbe « want » ?
  5. Quel type de sujet prend le verbe sans le -s : le singulier ou le pluriel ?

Répondez en anglais, par une forme verbale (question 5 : singulier ou pluriel).

Cas d’exemple
Rapport du parc d'imprimantes :
1) « The printer need ink. » → le sujet the printer est singulier : needs.
2) « The printers needs ink. » → le sujet the printers est pluriel : need.
Trois indices, rédigés en mots
  1. Comptez le sujet : un seul élément (server, report) ou plusieurs (servers, clients) ?
  2. La règle du cours est régulière : singulier → verbe en -s ; pluriel → verbe nu. Le -s passe du sujet au verbe.
  3. Relisez chaque correction à voix haute : the server works, the servers work — l'oreille confirme l'accord.

Exercice 3 — The final assessment

Étude de cas Formative Niveau 3 — Raisonnement

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Évaluer le parcours complet (le test final du support) : quatre compétences notées, verdict de passage.

L’analyse porte sur d'abord seuil (score minimal, entier). Puis il lit n lignes « competence score » (score entier). Pour chaque situation, indiquez competence : score X. Final : moyenne : M (moyenne entière arrondie vers le bas) et verdict : admis si M ≥ seuil, verdict : entrainement sinon. Si n = 0, afficher moyenne : 0.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Écrire des phrases télégraphiques : sujet, verbe conjugué, politesse sont obligatoires.
  • Oublier le -s du verbe au singulier (the server work).
  • Refuser sans alternative : le « I cannot, but… » préserve la relation.
  • Calculer la moyenne en oubliant une compétence : les quatre comptent.

6. Méthodologie de résolution

Méthode — corriger une phrase en trois gestes
  1. Ajouter le sujet explicite (I, you, the server…).
  2. Conjuguer le verbe (did you send… ; the server crashed…).
  3. Ajouter la formule polie (Could we please… ; I would appreciate it if…).
  4. Relire l'accord sujet-verbe avant l'envoi.

7. Révision active

Résumé essentiel
  • S-V-P : sujet + verbe conjugué + politesse — la grammaire de la requête professionnelle.
  • Accord : singulier → verbe en -s ; pluriel → verbe nu.
  • Refus poli : I cannot + alternative.
  • Évaluation finale : quatre compétences notées, moyenne comparée au seuil, verdict admis/entraînement.

Checklist de maîtrise

  • Je sais corriger les cinq phrases « bad business English » du support.
  • Je sais accorder dix paires sujet-verbe.
  • Je sais formuler une requête et un refus polis.
  • Je sais calculer ma moyenne et lire mon verdict.

Les 8 notions à connaître absolument

  1. Sujet explicite : I, you, the server — jamais omis.
  2. Verbe conjugué : did you send, the server crashed.
  3. Could you please… : requête polie standard.
  4. I would appreciate it if… : requête formelle client.
  5. Accord : singulier -s, pluriel sans -s.
  6. Refus poli : I cannot + alternative.
  7. Moyenne : somme des scores / nombre de compétences.
  8. Verdict : admis (≥ seuil) ou entraînement.

8. Test de maîtrise

Comment vous auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lisez votre pourcentage :

< 50 % — reprenez le tableau bad business English et ses corrections.
50–69 % — refaites les accords sujet-verbe et les requêtes polies.
70–94 % — bon niveau, ciblez l'évaluation complète des quatre compétences.
≥ 95 % — niveau de maîtrise recherché.
