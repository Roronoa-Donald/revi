Chapitre 6 — Professional grammar and assessment

Module 6 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

Le test final approche. Leo relit ses emails : « Me want finish work soon yes », « You send file yesterday ? » — phrases télégraphiques sans sujet, sans verbe conjugué, sans politesse. La grammaire professionnelle, c'est la politesse rendue syntaxique : sujet + verbe conjugué + formule. Puis le verdict : admis ou entraînement.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. transformer les phrases télégraphiques en requêtes polies complètes ;
  2. corriger les accords sujet-verbe (singular/plural) ;
  3. réutiliser le vocabulaire des sessions précédentes en contexte ;
  4. s'auto-évaluer sur les quatre compétences du module.

1. Requêtes polies et accords

Le tableau « bad business English » du support se corrige avec trois ingrédients : un sujet, un verbe conjugué, une formule polie. « Me want finish work soon yes » → « I want to finish work soon » ; « You send file yesterday ? » → « Did you send the file yesterday ? » ; « Server crash. Fix now ! » → « The server crashed. Could we please fix it now ? » ; « Client call. You talk. Not me. » → « The client is calling. Can you talk to them ? I cannot. »

L'accord sujet-verbe complete : le sujet singulier prend le verbe avec -s (the server works), le sujet pluriel sans -s (the servers work). Une erreur d'accord dans un email client passe pour de la négligence : la relecture n'est pas optionnelle.

Les formules de politesse structurent la requête : « Could you please… », « Would you be able to… », « I would appreciate it if you could… ». Le refus poli : « I cannot », puis une alternative — jamais un sec « no ».

Mnémotechnique — « S-V-P : sujet, verbe, politesse »

Toute requête professionnelle se construit en trois temps : sujet explicite, verbe conjugué, formule de politesse. S-V-P comme « s'il vous plaît » — justement.

2. L'évaluation finale

Le bilan du support résume le parcours de Leo : session 1 (vocabulaire), session 2 (emails), session 3 (présentations), session 4 (prononciation). L'évaluation finale couvre les quatre compétences : vocabulary, email writing, oral presentation, pronunciation — chacune notée, moyennée, comparée au seuil de passage.

La moyenne se calcule : somme des scores divisée par le nombre de compétences. Le verdict suit : admis (moyenne ≥ seuil) ou entraînement (retour aux exercices ciblés de la compétence la plus faible). Et la conclusion du support vaut programme : « You passed. But fluency is a habit, not a destination. »

Confusions d'examen
  • Phrase sans sujet : « Me want… » n'existe pas en anglais professionnel — I want to…
  • Verbe non conjugué : « You send file yesterday ? » → Did you send… ?
  • Refus sec : « Not me » heurte ; « I cannot, but… » garde la relation.
  • Moyenne sans pondération : chaque compétence compte autant dans le calcul du verdict.

3. Études de cas & applications pratiques

Ces trois études de cas se réalisent directement dans la page. Complétez chaque grille d’analyse à partir des données du cas, puis lancez la validation pour vérifier vos réponses critère par critère.

En cas d’hésitation, le bouton Expliquer mon erreur sollicite le tuteur pédagogique pour vous guider dans l’application de la méthodologie sans donner directement la solution.

Exercice 1 — Polite requests

Étude de cas Niveau 1 — Acquisition

Objectif : Corriger les phrases télégraphiques en requêtes polies : sujet + verbe conjugué + formule.

Pour chaque situation proposée : problème vaut sujet (sujet manquant), verbe (verbe non conjugué) ou politesse (formule polie absente). Une phrase correcte vaut aucun. Pour chaque situation, indiquez phrase : probleme ou phrase : correcte. Final : phrases correctes : X/n.

p2 aucun
p3 politesse
Résolution attendue

p2 : correcte

phrases correctes : 1/3
Deux indices, rédigés en mots
  1. Seule la valeur aucun donne « correcte » : sujet, verbe et politesse sont des défauts.
  2. Le compteur suit exactement les phrases correctes.

Exercice 2 — Subject verb agreement

Étude de cas Niveau 2 — Application

Objectif : Vérifier l'accord sujet-verbe : la phrase est correcte quand le verbe correspond au sujet.

Pour chaque situation proposée : accord vaut ok (accord correct), singular (sujet singulier, verbe pluriel) ou plural (sujet pluriel, verbe singulier). Pour chaque situation, indiquez phrase : verdict où verdict vaut correcte (ok) ou accorder (à corriger). Final : erreurs : X et taux : Y/n avec Y = nombre de phrases correctes.

Cas d’exemple
4
p1 ok
p2 singular
p3 plural
p4 ok
Résolution attendue
p1 : correcte
p2 : accorder
p3 : accorder
p4 : correcte
erreurs : 2
taux : 2/4
Deux indices, rédigés en mots
  1. Seul ok donne « correcte » : singular et plural sont des erreurs d'accord.
  2. Deux compteurs suffisent : erreurs, et le taux se déduit (n - erreurs).

Objectif : Évaluer le parcours complet (le test final du support) : quatre compétences notées, verdict de passage.

Final : moyenne : M (moyenne entière arrondie vers le bas) et verdict : admis si M ≥ seuil, verdict : entrainement sinon. Si n = 0, afficher moyenne : 0.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Écrire des phrases télégraphiques : sujet, verbe conjugué, politesse sont obligatoires.
  • Oublier le -s du verbe au singulier (the server work).
  • Refuser sans alternative : le « I cannot, but… » préserve la relation.
  • Calculer la moyenne en oubliant une compétence : les quatre comptent.

6. Méthodologie de résolution

Méthode — corriger une phrase en trois gestes
  1. Ajouter le sujet explicite (I, you, the server…).
  2. Conjuguer le verbe (did you send… ; the server crashed…).
  3. Ajouter la formule polie (Could we please… ; I would appreciate it if…).
  4. Relire l'accord sujet-verbe avant l'envoi.

7. Révision active

Résumé essentiel
  • S-V-P : sujet + verbe conjugué + politesse — la grammaire de la requête professionnelle.
  • Accord : singulier → verbe en -s ; pluriel → verbe nu.
  • Refus poli : I cannot + alternative.
  • Évaluation finale : quatre compétences notées, moyenne comparée au seuil, verdict admis/entraînement.

Checklist de maîtrise

  • Je sais corriger les cinq phrases « bad business English » du support.
  • Je sais accorder dix paires sujet-verbe.
  • Je sais formuler une requête et un refus polis.
  • Je sais calculer ma moyenne et lire mon verdict.

Les 8 notions à connaître absolument

  1. Sujet explicite : I, you, the server — jamais omis.
  2. Verbe conjugué : did you send, the server crashed.
  3. Could you please… : requête polie standard.
  4. I would appreciate it if… : requête formelle client.
  5. Accord : singulier -s, pluriel sans -s.
  6. Refus poli : I cannot + alternative.
  7. Moyenne : somme des scores / nombre de compétences.
  8. Verdict : admis (≥ seuil) ou entraînement.

8. Test de maîtrise

Comment t'auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lis ton pourcentage :

< 50 % — reprenez le tableau bad business English et ses corrections.
50–69 % — refaites les accords sujet-verbe et les requêtes polies.
70–89 % — bon niveau, ciblez l'évaluation complète des quatre compétences.
≥ 95 % — niveau de maîtrise recherché.
