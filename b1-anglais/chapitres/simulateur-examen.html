Simulateur d'examen

Deux sujets blancs chronométrés, dans l'esprit de l'épreuve (durée 2 h, /20). Fais-les sans regarder les corrigés, puis corrige-toi sévèrement.

Chronomètre d'examen — 2 h

Lance le chrono quand tu commences un sujet. Ne consulte le corrigé qu'à la fin. Réserve 15 min de relecture : registres cohérents, CLEAR complet, transitions présentes, accords vérifiés.

120:00

Examen blanc n°1

Sujet type épreuve — vocabulaire, emails, méthode CLEAR.

Exercice 1/5 — Vocabulaire

Définir en anglais simple puis employer dans une phrase : deadline, stakeholder, sprint, UAT. Distinguer client et customer sur un exemple d'entreprise.

Corrigé
Deadline : the final date to finish work (« The deadline is Friday »). Stakeholder : a person interested in the project (« All stakeholders must review the contract »). Sprint : a short work period (1–4 weeks) in Agile (« We will add a search bar this sprint »). UAT : User Acceptance Testing, final testing by real users (« The client approved the software after UAT »). Client : Mrs. Rivera, who buys a maintenance contract every year (long-term relationship) ; customer : the person who bought one laptop in 2024 and never came back.
Exercice 2/5 — Faux amis

Corriger les trois phrases : « Actually, I am working currently » (voulue : « en fait, je travaille actuellement ») ; « Eventually we will see » (voulue : « éventuellement, nous verrons ») ; « I bought a book at the library ».

Corrigé
« In fact, I am working currently » (actually = en fait, pas actuellement). « Possibly we will see » ou « We may see later » (eventually = finalement ; éventuellement = possibly/possibly speaking). « I bought a book at the bookshop » (library = bibliothèque ; bookshop = librairie).
Exercice 3/5 — CLEAR

Réécrire l'email catastrophe « Yo team, gonna need that thing by tomorrow. k thx. » au format complet : subject line, salutation, corps CLEAR, closing, signature.

Corrigé
Subject : Report Deadline – Action Needed by Tomorrow. Dear team, — (C) The report deadline is tomorrow. — (L) The final version must be shared by 5 PM. — (E) I need everyone's section by 10 AM. — (A) Please send your section to me before 10 AM. — (R) Thank you for your efforts. Best regards, [Name], IT Team Lead.
Exercice 4/5 — Ton

Choisir salutation, ton et closing pour : (a) un CEO rencontré pour la première fois ; (b) une collègue de longue date ; (c) un client fidèle depuis trois ans. Justifier.

Corrigé
(a) Formel : « Dear Mr./Ms. [Nom], » + « Sincerely, » — nouveau contact, respect maximal. (b) Semi-formel : « Hello Sarah, » + « Best regards, » — collègue régulier. (c) Semi-formel à formel : « Hello Mrs. Dialou, » + « Kind regards, » — client fidèle : chaleureux mais professionnel.

Examen blanc n°2 — variante

Sujet orienté présentation, prononciation, grammaire.

Exercice 1/5 — Structure

Bâtir le squelette d'une présentation de 2 minutes sur « the server was down this morning » : hook, roadmap, deux transitions de body, closing avec call to action.

Corrigé
Hook : « Have you ever arrived at work and found every screen frozen ? » Roadmap : « Today I'll explain what happened, what we did, and what you should do. » Body : « First, the main server crashed at 7 AM. » … « Next, we rebooted the system and restored the backup. » Closing : « To summarize, we had a crash, we fixed it with a reboot, and now everything works. Please restart your computers tonight. »
Exercice 2/5 — Grandma Rule

Traduire en anglais simple, niveau grand-mère : « The deployment failed because of a CI/CD pipeline configuration mismatch. »

Corrigé
Niveau professionnel simple : « The software release did not work because our automatic delivery system had a settings problem. » Niveau grand-mère : « The computer system got confused and couldn't finish the job. » La méthode : deployment → software release ; failed → did not work ; CI/CD pipeline → automatic delivery system ; configuration mismatch → settings problem.
Exercice 3/5 — Prononciation

Classer par son : fixed, ended, walked, tested, deployed. Puis expliquer la prononciation de think et hello à un francophone.

Corrigé
/t/ : fixed (k sourd), walked (k sourd). /d/ : deployed (d voisé). /ɪd/ : ended, tested (terminaison T/D). think : le /θ/ se produit avec la langue entre les dents en soufflant — ni « tink » ni « sink ». hello : le /h/ s'aspire fortement, il n'est jamais muet (« 'ello » est une faute).
Exercice 4/5 — Grammaire

Corriger au format S-V-P : « Me want finish work soon yes » ; « You send file yesterday ? » ; « Server crash. Fix now ! » ; « Client call. You talk. Not me. »

Corrigé
« I want to finish work soon. » — « Did you send the file yesterday ? » — « The server crashed. Could we please fix it now ? » — « The client is calling. Can you talk to them ? I cannot. » Trois ingrédients à chaque fois : sujet explicite, verbe conjugué, formule polie.

QCM final — toutes notions

A deadline is…

Et ce n'est pas un happy word.

A client has…

Customer = achat ponctuel.

« Actually » means…

Faux ami : actuellement = currently.

Dans CLEAR, l'Action est…

Expectation = what I need ; Action = what they do.

Salutation formelle pour un CEO ?

Formel : Dear + nom ; jamais Yo.

Le closing contient…

Résumé puis action précise demandée à l'auditeur.

Le /θ/ de think se produit…

The tongue sandwich — ni « tink » ni « sink ».

L'-ed de « wanted » vaut…

Après T ou D : /ɪd/.

Devant un client on dit…

Les reductions restent en registre casual.

« Could we please fix it now ? » illustre…

Sujet + verbe conjugué + formule polie.
