Chapitre 4 — Circuits logiques combinatoires

Module 4 ≈ 2 h 30 de travail Réservé B1 et plus
Mise en situation

Un processeur entier se réduit à des transistors câblés en portes logiques. Tout circuit combinatoire — dont la sortie ne dépend que des entrées présentes — se décrit par une table de vérité, se traduit en équation, puis se simplifie : ce chapitre déroule cette chaîne jusqu'aux blocs que le TP câble (additionneur, décodeur, multiplexeur).

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. donner la table de vérité et le symbole des huit portes ;
  2. appliquer les règles d'algèbre de Boole pour simplifier une expression ;
  3. synthétiser un circuit depuis sa table de vérité (mintermes, SOMME de produits) ;
  4. simplifier par Karnaugh avec la règle des bulles ;
  5. décrire additionneur, comparateur, décodeur et multiplexeur.

1. Les huit portes logiques

La NOT inverse (0→1, 1→0). La AND donne 1 si toutes les entrées valent 1 ; la NAND est sa négation. La OR donne 1 si au moins une entrée vaut 1 ; la NOR est sa négation. La XOR (OU exclusif) donne 1 si les entrées diffèrent — son équation : S = a·b̄ + ā·b — et la NXOR (équivalence) donne 1 si elles sont égales. Sur les symboles, la négation se marque par une bulle sur la sortie (NOT, NAND, NOR, NXOR).

Règles d'algèbre de Boole à connaître : a+0=a, a+1=1, a+a=a, a+ā=1 ; a·0=0, a·1=a, a·a=a, a·ā=0 ; involution (ā)̄=a ; De Morgan : (a·b)̄ = ā+b̄ et (a+b)̄ = ā·b̄ — la barre se coupe et le produit devient somme.

Mnémotechnique — « AND exige tout, OR se contente d'un, XOR aime la différence »

Trois portes, trois caractères : l'exigeant, le tolérant, celui qui compare. Les trois autres portent juste une bulle de négation.

2. Synthèse depuis une table de vérité

Marche du support : 1) dresser la table de vérité (2^k lignes pour k entrées) ; 2) pour chaque ligne où la sortie vaut 1, écrire le minterme — produit des variables, complémentées quand elles valent 0 ; 3) faire la SOMME des produits ; 4) simplifier. La table définit le comportement : le circuit s'en déduit mécaniquement.

Simplification algébrique : factoriser et appliquer Boole. Exemple type : S = ab + ab̄ = a(b + b̄) = a·1 = a. Une variable et son complément se neutralisent dans une somme ; un terme redondant disparaît (a + ab = a).

Confusions d'examen
  • Karnaugh : une variable toujours à 0 dans le bloc → complémentée ; toujours à 1 → non complémentée ; qui change → disparaît.
  • Les groupes font 1, 2, 4, 8 cases — jamais 3 ni 6 ; les bords se recollent.
  • De Morgan : couper la barre change ET en OU (et inversement).
  • NXOR donne 1 sur les entrées égales : c'est l'équivalence, pas la différence.

3. Karnaugh et les blocs combinatoires

Le Karnaugh place la table dans une grille où deux cases voisines ne diffèrent que d'une variable : on regroupe en rectangles de 1, 2, 4, 8 cases (y compris en recollant les bords), puis on lit chaque groupe — variable constante à 0 → complémentée, constante à 1 → directe, qui change → éliminée. L'ordre de remplissage suit le code Gray : 00, 01, 11, 10.

Les blocs du support : l'additionneur complet 1 bit calcule somme S = a ⊕ b ⊕ r (r = retenue entrante) et retenue sortante r₁ = ab + r(a ⊕ b) ; le comparateur sort a>b, a=b, a<b ; le décodeur 2 vers 4 active une sortie par combinaison d'adresse ; le multiplexeur aiguille une des 2^k entrées vers la sortie selon k bits de sélection — son inverse, le démultiplexeur, redistribue une entrée vers 2^k sorties.

Vérifier en Bash
  • L'additionneur de l'atelier : total = a + b + r ; S = total mod 2, retenue = total divisé par 2.
  • Le décodeur : une adresse 2 bits allume une sortie parmi 4 (un seul 1 dans le mot).
  • Les portes s'écrivent avec les opérateurs du shell : && (ET), || (OU), != (différence, XOR).

4. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

Exercice 1 — Portes logiques de base

Bash Niveau 1 — Acquisition

Objectif : Retrouver la sortie des huit portes : NOT, AND, NAND, OR, NOR, XOR, NXOR.

Le script lit n lignes « a b porte » : a et b valent 0 ou 1 et porte est un code parmi and, or, xor, nand, nor ou xnor. Rappel du support : AND donne 1 si les deux entrées valent 1, OR si au moins une vaut 1, XOR si elles diffèrent ; NAND, NOR et NXOR sont les négations des trois premières. Pour chaque ligne il affiche a b : porte=X, puis le bilan bilan : n portes.

Entrée du programme
3
1 1 and
1 0 or
1 0 xor
Sortie attendue
1 1 : and=1
1 0 : or=1
1 0 : xor=1
bilan : 3 portes
Deux indices, rédigés en mots
  1. Un case sur la porte : and donne 1 si a et b valent 1, or si au moins un vaut 1, xor si a diffère de b.
  2. Nand, nor et xnor sont le contraire de and, or et xor.

Exercice 2 — Additionneur complet 1 bit

Bash Niveau 2 — Application

Objectif : Simuler l'additionneur : somme et retenue sortante à partir de a, b et de la retenue entrante.

Le script lit n lignes « a b c » où a, b sont les deux bits à additionner et c la retenue entrante. Rappel du support : la somme vaut 1 quand le nombre de bits à 1 est impair, la retenue sortante vaut 1 dès que deux entrées au moins valent 1. Pour chaque ligne il affiche a + b + c : somme=X retenue=Y, puis le bilan additions : n.

Entrée du programme
3
0 0 0
1 0 0
1 1 1
Sortie attendue
0 + 0 + 0 : somme=0 retenue=0
1 + 0 + 0 : somme=1 retenue=0
1 + 1 + 1 : somme=1 retenue=1
additions : 3
Deux indices, rédigés en mots
  1. Fais le total $((a + b + c)) : la somme est son reste modulo 2, la retenue son quotient par 2.
  2. Vérifie avec la table : 1+1+1 donne somme 1 et retenue 1.

Exercice 3 — Decodeur 2 vers 4

Bash Niveau 3 — Raisonnement

Objectif : Activer une seule sortie parmi quatre selon les deux bits d'entrée.

Le script lit n lignes « a b » : a est le bit de poids faible et b le bit de poids fort d'une adresse de 2 bits. Le décodeur du support active une seule sortie : Y0 quand l'adresse vaut 00, Y1 pour 01, Y2 pour 10 et Y3 pour 11 (a et b lus dans cet ordre : a d'abord, b ensuite). Pour chaque ligne il affiche a b : Y3Y2Y1Y0 = XXXX où XXXX est le mot de sortie, puis le bilan decodages : n.

Entrée du programme
3
0 0
1 0
1 1
Sortie attendue
0 0 : Y3Y2Y1Y0 = 0001
1 0 : Y3Y2Y1Y0 = 0010
1 1 : Y3Y2Y1Y0 = 1000
decodages : 3
Deux indices, rédigés en mots
  1. L'indice de la sortie active vaut 2 fois b plus a.
  2. Un if imbrique ou un case sur les deux bits donne le mot de 4 caractères.

5. QCM — niveau examen

La porte AND donne 1 si…

AND = produit logique : tout à 1.

La XOR donne 1 si les entrées…

OU exclusif : les entrées diffèrent. NXOR = équivalence.

(a·b)̄ vaut…

De Morgan : la barre se coupe, le produit devient somme.

a + ab simplifie en…

Absorption : a(1+b) = a.

Un groupe Karnaugh de 3 cases est…

Groupes de 1, 2, 4, 8… puissances de 2 seulement.

Dans un groupe où la variable vaut toujours 0, elle est…

Règle des bulles du support : toujours 0 → complémentée.

La somme d'un additionneur complet vaut…

XOR des trois entrées, retenue entrante comprise.

Un multiplexeur à 4 entrées nécessite…

2^k entrées : k bits de sélection, ici k = 2.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Confondre XOR (différence) et NXOR (équivalence).
  • Oublier que NAND et NOR nient leur porte de base : sorties opposées.
  • Faire des groupes Karnaugh de 3 cases ou oublier le recollement des bords.
  • Oublier la retenue entrante dans l'additionneur complet.

7. Méthodologie de résolution

Méthode — synthétiser un circuit en quatre gestes
  1. Dresser la table de vérité : une ligne par combinaison des entrées.
  2. Écrire un minterme par sortie à 1 (variable complémentée si elle vaut 0).
  3. Simplifier : algèbre de Boole, puis Karnaugh avec groupes de puissances de 2.
  4. Dessiner le circuit : portes AND sur les mintermes, OR pour la somme.

8. Révision active

Résumé essentiel
  • Huit portes : NOT, AND, NAND, OR, NOR, XOR, NXOR — bulle = négation.
  • Boole : a+ā=1, a·ā=0, absorption, De Morgan.
  • Synthèse : table de vérité → mintermes → somme de produits → simplification.
  • Karnaugh : groupes de puissances de 2 ; additionneur, comparateur, décodeur, multiplexeur.

Checklist de maîtrise

  • Je donne tables et symboles des huit portes.
  • J'applique De Morgan et l'absorption sans erreur.
  • Je synthétise une fonction depuis sa table de vérité.
  • Je simplifie par Karnaugh et je connais les blocs usuels.

Les 8 notions à connaître absolument

  1. Porte : circuit élémentaire à une fonction logique (NOT, AND, OR…).
  2. XOR : 1 si les entrées diffèrent ; NXOR : 1 si égales.
  3. De Morgan : (a·b)̄ = ā+b̄ ; (a+b)̄ = ā·b̄.
  4. Minterme : produit des variables pour une ligne de table où la sortie vaut 1.
  5. Karnaugh : grille de simplification par groupements adjacents.
  6. Additionneur complet : S = a ⊕ b ⊕ r ; retenue = ab + r(a ⊕ b).
  7. Décodeur : active une sortie par combinaison des entrées d'adresse.
  8. Multiplexeur : aiguille 2^k entrées vers une sortie selon k bits.
