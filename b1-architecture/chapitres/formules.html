Mémo Architecture & circuits

Les règles du cours sur une page, dans l'ordre d'une configuration. À garder ouvert pendant les exercices et l'atelier.

Le système informatique et les unités

systeme informatique : hardware / software / donnees / utilisateurs

generations : lampe -> transistor -> circuit integre ->

  microprocesseur -> reseau et cloud



capacites : 1 octet = 8 bits ; 1 Ko = 1024 octets

  1 Mo = 1024 Ko ; 1 Go = 1024 Mo ; 1 To = 1024 Go

debits : MBps (octets/s) = 8 x Mbps (bits/s)

mesures : frequence Hz (cycles/s) / puissance W / latence ms

Puissances de 2 pour les capacités, facteur 8 entre octets et bits.

Numération : les quatre conversions

unites : bit (0/1) / quartet (4 bits) / octet (8 bits)

  MSB = poids fort (gauche) / LSB = poids faible (droite)



decimal -> binaire : divisions successives, restes lus de BAS EN HAUT

  (13 -> 1101) OU soustraction des puissances de 2

binaire -> decimal : somme des poids (1011 = 8+0+2+1 = 11)

binaire -> octal : groupement par 3 bits depuis la DROITE

binaire -> hexa : groupement par 4 bits depuis la DROITE

  A=10 B=11 C=12 D=13 E=14 F=15

fractionnaire : poids negatifs a droite (2^-1, 2^-2...)

  -> multiplier par 2, garder les parties entieres

codes : BCD (quartet par chiffre decimal) / ASCII (7 bits, A=65)

Trois bits font l'octal, quatre bits font l'hexa : les groupements partent de la droite.

Nombres signés et arithmétique

signe + valeur absolue : MSB = signe (0 = +, 1 = -)

  defaut : DEUX zeros (0000 et 1000)

complement a 1 : inverser TOUS les bits (0101 -> 1010)

complement a 2 : complement a 1 + 1 (0101 -> 1010 -> 1011)

  methode directe : recopier jusqu'au 1er 1 compris, inverser le reste

  avantages : UN SEUL zero ; soustraction = addition du complement



addition : 1+1 = 0 retenue 1 ; 1+1+1 = 1 retenue 1

soustraction : additionner le complement a 2

decalage gauche de k bits = x 2^k ; droite = division entiere

debordement : le bit sortant du mot (carry) doit etre signale

Le complément à 2 a gagné : un seul zéro et un seul additionneur.

Portes logiques et algèbre de Boole

NOT : inverse        AND : tout a 1        OR : au moins un a 1

NAND = non-AND       NOR = non-OR

XOR : 1 si ENTREES DIFFERENTES    NXOR : 1 si ENTREES EGALES

  bulle sur le symbole = negation



boole : a+0=a / a+1=1 / a+a=a / a+a'=1

  a.0=0 / a.1=a / a.a=a / a.a'=0

  a + ab = a (absorption)      (a')' = a

De Morgan : (ab)' = a' + b'   (a+b)' = a' . b'



synthese : table -> mintermes (0 = complemente) -> somme de produits

karnaugh : groupes de 1/2/4/8, bords recolles ;

  var toujours a 0 -> complements / a 1 -> directe / change -> eliminee

XOR aime la différence, NXOR l'équivalence : ne pas les échanger.

Blocs combinatoires et séquentiels

additionneur complet : S = a XOR b XOR r

  retenue sortante = ab + r(a XOR b)

comparateur : a>b / a=b / a4 : une sortie active par adresse (Y3Y2Y1Y0)

multiplexeur : 2^k entrees -> 1 sortie selon k bits de selection



RS : S met a 1 / R met a 0 / RS=00 memoire / RS=11 INTERDIT

D : recopie D sur Q au FRONT d'horloge

JK : 00 memoire / 10 set / 01 reset / 11 BASCULE (toggle)

  set/reset asynchrones : hors horloge, immediat

registre a decalage : n bascules D en serie, serie <-> parallele

compteur modulo 2^n : 0 ... 2^n-1 puis 0 ; valeur = (depart + i) mod n

R=S=1 est interdit ; J=K=1 est le mode bascule qui fait les compteurs.

Architecture PC et périphériques

von Neumann : UAL (calcule) / unite de controle (orchestre) /

  memoire (RAM volatile + ROM/disque permanents) / E/S

  programme stocke dans la MEME memoire que les donnees



carte mere : socket (CPU) / DIMM (RAM) / SATA (disques) /

  PCIe (cartes, GPU x16) / M.2 (SSD NVMe) / chipset /

  BIOS-UEFI (demarrage) / pile CMOS (heure, reglages)

alimentation : 12 V / 5 V / 3,3 V

CPU : 4 criteres = frequence GHz / coeurs / cache / socket



peripheriques : entree (clavier, souris, scanner) /

  sortie (ecran, imprimante, HP) /

  entree-sortie (tactile, modem, cle USB, carte reseau)

video : HDMI / VGA / DVI / DisplayPort

qualifier : multimedia >= 2000 MHz et 4096 Mo /

  bureautique >= 1000 MHz et 2048 Mo / sinon basique

L'UAL calcule, le contrôle commande, la mémoire se souvient, les E/S parlent.

Erreurs fréquentes à éviter

  • Croire que 1 Ko = 1000 octets : c'est 1024 (puissances de 2).
  • Confondre Mbps (bits) et Mo/s (octets) : facteur 8.
  • Lire les restes des divisions successives de haut en bas : c'est de bas en haut.
  • Grouper les bits depuis la gauche : les groupements partent de la droite.
  • Oublier le +1 du complément à 2 après l'inversion.
  • Confondre XOR (différence) et NXOR (équivalence).
  • Faire un groupe Karnaugh de 3 cases : puissances de 2 seulement.
  • Appliquer R=S=1 à la JK : c'est J=K=1 qui bascule, et R=S=1 qui est interdit.
  • Placer le disque dur dans la mémoire volatile : il est permanent.
  • Choisir un CPU sans vérifier la compatibilité socket.
