Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque chapitre, puis un projet final qui qualifie un poste de bout en bout. Les scripts sont en Bash, comme à l'atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n lignes « composant categorie » (materiel/logiciel) et valide chaque classement, puis le compteur d'erreurs.
  2. Lit n lignes « valeur unite » (ko/mo/go) et affiche la taille en Mo, puis le total de conversions.
  3. Lit n lignes « binaire » et affiche le décimal, puis le total.
  4. Lit n lignes « unite sens » (mo/mbps) et convertit avec le facteur 8.
Corrections
read -r n
e=0
for ((k=0; k<n; k++)); do
  read -r composant categorie
  case "$composant" in
    clavier|processeur|ram|disque|ecran) attendu="materiel" ;;
    linux|word|navigateur|antivirus) attendu="logiciel" ;;
  esac
  if [ "$categorie" = "$attendu" ]; then
    echo "$composant : OK"
  else
    echo "$composant : KO ($attendu attendu)"
    e=$((e + 1))
  fi
done
echo "erreurs : $e/$n"

read -r n
for ((k=0; k<n; k++)); do
  read -r valeur unite
  case "$unite" in
    ko) mo=$((valeur / 1024)) ;;
    mo) mo=$valeur ;;
    go) mo=$((valeur * 1024)) ;;
  esac
  echo "$valeur $unite : $mo mo"
done
echo "conversions : $n"

read -r n
for ((k=0; k<n; k++)); do
  read -r binaire
  decimal=$((2#$binaire))
  echo "$binaire : decimal=$decimal"
done
echo "conversions : $n"

read -r n
for ((k=0; k<n; k++)); do
  read -r valeur unite
  case "$unite" in
    mo) converti=$((valeur * 8)) ; cible="mbps" ;;
    mbps) converti=$((valeur / 8)) ; cible="mos" ;;
  esac
  echo "$valeur $unite : $converti $cible"
done
echo "conversions : $n"

Application

Application
  1. Lit n lignes « binaire » (4 bits) et affiche le complément à 1 puis le complément à 2 de chaque mot.
  2. Lit n lignes « a b » (deux binaires de 4 bits) et pose l'addition avec les retenues, puis affiche la somme.
  3. Lit n lignes « a b porte » (and/or/xor/nand/nor/xnor) et affiche la sortie de la porte.
  4. Lit n lignes « a b c » (bits + retenue entrante) et affiche somme et retenue sortante de l'additionneur complet.
Corrections
read -r n
for ((k=0; k<n; k++)); do
  read -r binaire
  c1=$(printf '%s' "$binaire" | tr '01' '10')
  v=$((2#$binaire))
  c2=$(( (16 - v) % 16 ))
  tmp=$c2 ; res=""
  for ((j=0; j<4; j++)); do
    reste=$((tmp % 2)) ; tmp=$((tmp / 2)) ; res="$reste$res"
  done
  echo "$binaire : c1=$c1 c2=$res"
done
echo "complements : $n"

read -r n
for ((k=0; k<n; k++)); do
  read -r a b
  total=$(( (2#$a) + (2#$b) ))
  tmp=$total ; somme=""
  if [ "$tmp" -eq 0 ]; then somme="0" ; fi
  while [ "$tmp" -gt 0 ]; do
    reste=$((tmp % 2)) ; tmp=$((tmp / 2)) ; somme="$reste$somme"
  done
  echo "$a + $b : somme=$somme"
done
echo "additions : $n"

read -r n
for ((k=0; k<n; k++)); do
  read -r a b porte
  case "$porte" in
    and)  if [ "$a" -eq 1 ] && [ "$b" -eq 1 ]; then r=1; else r=0; fi ;;
    or)   if [ "$a" -eq 1 ] || [ "$b" -eq 1 ]; then r=1; else r=0; fi ;;
    xor)  if [ "$a" -ne "$b" ]; then r=1; else r=0; fi ;;
    nand) if [ "$a" -eq 1 ] && [ "$b" -eq 1 ]; then r=0; else r=1; fi ;;
    nor)  if [ "$a" -eq 1 ] || [ "$b" -eq 1 ]; then r=0; else r=1; fi ;;
    xnor) if [ "$a" -eq "$b" ]; then r=1; else r=0; fi ;;
  esac
  echo "$a $b : $porte=$r"
done
echo "portes : $n"

read -r n
for ((k=0; k<n; k++)); do
  read -r a b c
  total=$((a + b + c))
  somme=$((total % 2))
  retenue=$((total / 2))
  echo "$a + $b + $c : somme=$somme retenue=$retenue"
done
echo "additions : $n"

Raisonnement

Raisonnement
  1. Lit n lignes « hexa » et enchaîne hexa vers décimal puis octal (série de révision du support).
  2. Lit n lignes « a b » (adresse 2 bits, a d'abord) et affiche le mot du décodeur Y3Y2Y1Y0.
  3. Lit n puis n lignes « j k » et déroule une bascule JK initialisée à 0, front par front, puis l'état final.
  4. Lit n, la valeur de départ, puis simule un compteur modulo 8 et compte ses retours à zéro.
Corrections
read -r n
for ((k=0; k<n; k++)); do
  read -r hexa
  decimal=$((16#$hexa))
  octal=$(printf '%o' "$decimal")
  echo "$hexa : octal=$octal"
done
echo "conversions : $n"

read -r n
for ((k=0; k<n; k++)); do
  read -r a b
  if [ "$a" -eq 0 ] && [ "$b" -eq 0 ]; then code="0001"
  elif [ "$a" -eq 1 ] && [ "$b" -eq 0 ]; then code="0010"
  elif [ "$a" -eq 0 ] && [ "$b" -eq 1 ]; then code="0100"
  else code="1000" ; fi
  echo "$a $b : Y3Y2Y1Y0 = $code"
done
echo "decodages : $n"

read -r n
q=0
for ((i=1; i<=n; i++)); do
  read -r j k
  if [ "$j" -eq 0 ] && [ "$k" -eq 0 ]; then q=$q
  elif [ "$j" -eq 1 ] && [ "$k" -eq 0 ]; then q=1
  elif [ "$j" -eq 0 ] && [ "$k" -eq 1 ]; then q=0
  else
    if [ "$q" -eq 0 ]; then q=1; else q=0; fi
  fi
  echo "front $i : Q=$q"
done
echo "etat final : Q=$q"

read -r n
read -r depart
total=$((depart + n))
retours=$((total / 8))
for ((i=1; i<=n; i++)); do
  valeur=$(( (depart + i) % 8 ))
  echo "front $i : compteur=$valeur"
done
echo "retours : $retours"

Projet intégrateur — « la fiche de qualification d'un poste »

Cahier des charges

Le script reçoit le journal d'un parc de postes : d'abord n lignes poste configs où configs est une suite de lettres sans espace — c = CPU au moins 2000 MHz, r = RAM au moins 4096 Mo, d = disque SSD, p = périphérique entrée-sortie présent, le tiret - = poste vierge. Puis m lignes frequence memoire à profiler (multimédia si ≥ 2000 MHz et ≥ 4096 Mo, bureautique si ≥ 1000 MHz et ≥ 2048 Mo, sinon basique). Il affiche pour chaque poste poste : multimedia si les quatre configs sont présentes, sinon poste : echec (manque X) avec la première lettre manquante dans l'ordre c, r, d, p ; pour chaque ligne de profilage frequence memoire : profil ; enfin le verdict : parc pret si tous les postes sont configurés, intervention requise sinon.

Fonctionnalités attendues
  1. Lire les deux blocs sans mélanger postes et profilages.
  2. Analyser chaque suite de configs lettre à lettre.
  3. Profiler chaque machine selon les deux seuils (test du plus exigeant d'abord).
  4. Compter les échecs avec le premier manque dans l'ordre.
  5. Verdict final au format exact du cahier des charges.

Contraintes : parsing lettre à lettre, première lettre manquante, bilan après lecture complète.

Grille d'auto-évaluation du projet (sur 100)
Lecture des deux blocs et parsing correct 20
Analyse des configs (premier manque) 20
Profilage selon les seuils 20
Verdict global conforme 20
Rapport lisible et formats exacts 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
read -r n
tous_ok=1
for ((k=0; k<n; k++)); do
  read -r poste configs
  c=0 ; r=0 ; d=0 ; p=0
  if [ "$configs" != "-" ]; then
    for ((j=0; j<${#configs}; j++)); do
      lettre=${configs:$j:1}
      case "$lettre" in
        c) c=1 ;;
        r) r=1 ;;
        d) d=1 ;;
        p) p=1 ;;
      esac
    done
  fi
  if [ "$c" = "1" ] && [ "$r" = "1" ] && [ "$d" = "1" ] && [ "$p" = "1" ]; then
    echo "$poste : multimedia"
  elif [ "$c" = "0" ]; then
    echo "$poste : echec (manque c)" ; tous_ok=0
  elif [ "$r" = "0" ]; then
    echo "$poste : echec (manque r)" ; tous_ok=0
  elif [ "$d" = "0" ]; then
    echo "$poste : echec (manque d)" ; tous_ok=0
  else
    echo "$poste : echec (manque p)" ; tous_ok=0
  fi
done
read -r m
for ((k=0; k<m; k++)); do
  read -r frequence memoire
  if [ "$frequence" -ge 2000 ] && [ "$memoire" -ge 4096 ]; then profil="multimedia"
  elif [ "$frequence" -ge 1000 ] && [ "$memoire" -ge 2048 ]; then profil="bureautique"
  else profil="basique" ; fi
  echo "$frequence $memoire : $profil"
done
if [ "$tous_ok" = "1" ]; then
  echo "verdict : parc pret"
else
  echo "verdict : intervention requise"
fi
Cette solution combine parsing lettre à lettre, profilage à deux seuils, comptage du premier manque et verdict global — les chapitres 1, 5 et 6 en un seul script.
