Exercices supplémentaires & cas pratiques

De la pratique graduée pour consolider chaque module, puis un dossier d’ingénierie matérielle et d’architecture des ordinateurs.

Entraînement rapide (acquisition)

Échauffement
  1. Convertir un nombre entre les bases binaire (base 2), hexadécimale (base 16) et décimale (base 10).
  2. Calculer l’espace d’adressage direct permis par un bus d’adresses de 32 bits et de 64 bits.
  3. Identifier les registres fondamentaux du modèle de Von Neumann (PC, IR, MAR, MBR, Accumulateur).
  4. Décrire les trois phases du cycle d’instruction (Fetch, Decode, Execute).
Corrections & calculs d’architecture

1. Conversions : $1101_2 = 8 + 4 + 1 = 13_{10} = ext{D}_{16}$ ; $0x2A = 2 imes 16 + 10 = 42_{10} = 00101010_2$.

2. Espace d’adressage : $2^{32} ext{ octets} = 4 ext{ Go}$ ; $2^{64} ext{ octets} approx 18{,}4 ext{ Exaoctets}$.

3. Registres : PC (Program Counter pointe l’instruction suivante), IR (Instruction Register contient le code opération en cours), MAR/MBR interfacent la mémoire centrale.

4. Cycle machine : Fetch (chargement depuis RAM), Decode (décodage du code opération par l’unité de contrôle), Execute (calcul ALU ou transfert registre).

Application

Application
  1. Calculer le temps d’accès effectif moyen (AMAT) d’une hiérarchie mémoire avec cache L1 ($95%$ de hit rate).
  2. Distinguer les architectures RISC (instructions simples à cycle unique) et CISC (instructions complexes multi-cycles).
  3. Représenter un nombre réel en virgule flottante simple précision norme IEEE 754 (signe, exposant biaisé, mantisse).
  4. Calculer le débit maximal d’un bus PCI-Express selon sa génération et son nombre de lignes (lanes).
Corrections & calculs d’architecture

1. AMAT : $AMAT = T_{hit} + (1 - H) imes T_{miss} = 1 ext{ ns} + 0{,}05 imes 50 ext{ ns} = 3{,}5 ext{ ns}$.

2. RISC vs CISC : RISC (ARM, RISC-V : format fixe, exécution pipeline optimisée) vs CISC (x86-64 : rétrocompatibilité, micro-opérations internes).

3. IEEE 754 32 bits : 1 bit de signe, 8 bits d’exposant (biais de 127), 23 bits de mantisse normalisée ($1.M$).

4. Débit PCIe : PCIe 4.0 délivre $approx 2 ext{ Go/s}$ par ligne ; un port x16 offre donc un débit théorique de $32 ext{ Go/s}$ bidirectionnel.

Raisonnement

Raisonnement
  1. Analyser les aléas de pipeline processeur (structurels, de données RAW/WAR/WAW, et de contrôle lors de branchements).
  2. Dimensionner la hiérarchie de stockage d’un serveur de base de données (NVMe, SSD SATA, RAM et caches CPU).
  3. Comparer les mécanismes de cohérence de cache (protocole MESI) dans un processeur multi-cœurs.
  4. Évaluer l’impact de la loi d’Amdahl sur le gain de performance d’une parallélisation à N cœurs.
Corrections & calculs d’architecture

1. Aléas de pipeline : Données (résolu par forwarding/bypassing ou insertion de bulles) ; Contrôle (résolu par prédiction de branchement statique/dynamique).

2. Dimensionnement stockage : Priorité à la RAM pour le buffer pool, NVMe PCIe en RAID 10 pour le journal WAL (faible latence d’écriture synchrone).

3. Protocole MESI : Modified (modifié en cache local), Exclusive (propre, non partagé), Shared (partagé en lecture), Invalid (invalide, rechargement requis).

4. Loi d’Amdahl : $S = rac{1}{(1 - P) + rac{P}{N}}$ où $P$ est la fraction parallélisable : la partie séquentielle $(1-P)$ borne strictement l’accélération maximale.

Dossier de synthèse — Architecture Matérielle & Dimensionnement Serveur

Cahier des charges du Dossier

Ce dossier d’ingénierie consiste à concevoir et justifier l’architecture matérielle complète d’un serveur d’entreprise haute densité : choix des processeurs (cœurs, fréquences, cache L3), dimensionnement des canaux mémoire NUMA, contrôleurs de stockage et interfaces d’entrées/sorties.

Compétences d’architecture évaluées
  1. Analyse de charge : Profilage CPU-bound, Memory-bound ou I/O-bound.
  2. Topologie NUMA : Répartition symétrique des barrettes de RAM par canal pour maximiser la bande passante.
  3. Tolérance aux pannes : Mémoire ECC registered, alimentations redondantes et RAID matériel.
  4. Bilan thermique & énergétique : Calcul de TDP global et dimensionnement de la dissipation.
