Chapitre 1 — Word : l'interface et la saisie

Module 1 ≈ 2 h de travail Accès libre
Mise en situation

Le support d'AHADJI Katé Kékéli ouvre le traitement de texte par son ruban : des onglets (Accueil, Insertion, Mise en page, Références, Publipostage, Révision, Affichage) subdivisés en groupes. Savoir où vivre chaque commande — et enregistrer avant de fermer — est la première compétence du secrétariat.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. situer les groupes dans leurs onglets : Presse-papiers et Police (Accueil), Tableaux (Insertion), Zoom (Affichage) ;
  2. retrouver les cinq modes d'affichage et leur usage ;
  3. lire la barre d'état : numéros de page, langue, zoom, statistiques ;
  4. sélectionner au clavier (Shift, F8, Ctrl+A) et à la souris (double-clic, Ctrl+clic) ;
  5. enregistrer par les trois méthodes du support, y compris à la fermeture.

1. Le ruban : onglets et groupes

MS Word sert à saisir, modifier, mettre en forme, ouvrir et sauvegarder un document. Son ruban comporte des onglets subdivisés en groupes : l'onglet Accueil regroupe Presse-papiers, Police, Paragraphe, Style et Modification ; Insertion rassemble Pages, Tableaux, Illustrations, Liens, En-tête et pied, Texte, Symbole ; Mise en page tient Thèmes, Mise en page, Arrière-plan de page, Paragraphe et Organiser ; Références porte la table des matières, les notes de bas de page, les citations et légendes ; Publipostage gère la fusion ; Révision couvre vérification, commentaires, suivi et protection ; Affichage propose les modes d'affichage, le zoom, la fenêtre et les macros.

Mnémotechnique — « Accueil des habitudes, Insertion des objets, Affichage des vues »

La commande quotidienne vit dans Accueil, ce qu'on ajoute au document dans Insertion, ce qui change la façon de voir dans Affichage.

2. Modes d'affichage et barre d'état

Cinq modes d'affichage : Page (actif par défaut, le plus utilisé, montre les quatre marges de 2,5 cm), Lecture plein écran (le ruban disparaît), Web (pour créer des pages HTML), Plan (l'enchaînement des titres d'un long document) et Brouillon (défilement rapide, images masquées).

La barre d'état, juste sous le document, est entièrement configurable (clic droit) : numéro de page, langue, zoom, et l'option Statistiques qui compte les mots « approximativement » — tout caractère précédé et suivi d'un espace compte pour un mot : « il répond : 8 » est compté pour 6 mots, et « Ah ! » en vaut deux.

Confusions d'examen
  • Le mode Page est le mode par défaut ; Web sert au HTML, pas à la lecture.
  • Les marges par défaut font 2,5 cm des quatre côtés.
  • Le compteur de mots est approximatif : les signes isolés comptent pour des mots.
  • ESC sort du mode de sélection F8 ; Ctrl+A sélectionne tout le document.

3. Sélectionner et enregistrer

Pour modifier une portion de texte, il faut d'abord la sélectionner : au clavier — Shift + flèches, F8 successifs (mot, phrase, paragraphe, section, document), Ctrl+A — ou à la souris — double-clic sur un mot, Ctrl+clic dans une phrase, triple-clic (ou double-clic dans la marge) sur un paragraphe, clic dans la marge pour une ligne.

Enregistrer est la chose la plus importante, sinon tout est perdu à la fermeture. Premier enregistrement : bouton Office, Enregistrer sous, nom, dossier, valider. Ensuite : Ctrl+S ou la disquette de la barre d'accès rapide, régulièrement. À la fermeture sans sauvegarde, Word propose Oui (enregistre les modifications depuis la dernière sauvegarde), Non (elles sont perdues) ou Annuler (on reste dans Word).

4. Études de cas & applications pratiques

Ces trois études de cas se réalisent directement dans la page. Compléter chaque grille d’analyse à partir des données du cas, puis lancer la validation pour vérifier les réponses critère par critère.

En cas d’hésitation, le bouton Expliquer mon erreur sollicite le tuteur pédagogique pour guider l’application de la méthodologie sans donner directement la solution.

Exercice 1 — Onglets et groupes

Étude de cas Niveau 1 — Acquisition

Objectif : Retrouver l'organisation du ruban : chaque groupe appartient à un onglet précis.

Pour chaque situation proposée : onglet est un code de accueil, insertion, miseenpage, revision ou affichage. Pour chaque situation, indiquez groupe : OK si le groupe appartient bien à cet onglet, sinon groupe : ERREUR. Concluez par conformes : X/n.

Cas d’exemple
3
police accueil
tableaux insertion
zoom revision
Résolution attendue
police : OK
tableaux : OK
zoom : ERREUR
conformes : 2/3
Deux indices, rédigés en mots
  1. Un case sur le groupe donne l'onglet attendu ; compare-le à l'onglet saisi.
  2. Le bilan sort une seule fois, après la boucle.

Exercice 2 — Les cinq modes d'affichage

Étude de cas Niveau 1 — Acquisition

Objectif : Retrouver la définition de chaque mode d'affichage du document.

Pour chaque situation proposée : mode est un code parmi page, pleinecran, web, plan ou brouillon et Question un code parmi defaut, ruban, html, titres ou rapide. Indiquez mode : OUI quand le couple est juste, mode : NON sinon, puis justes : X/n.

Cas d’exemple
2
page defaut
web titres
Résolution attendue
page : OUI
web : NON
justes : 1/2
Deux indices, rédigés en mots
  1. Chaque mode a une seule réponse juste : page-defaut, pleinecran-ruban, web-html, plan-titres, brouillon-rapide.
  2. Un case sur le mode donne la réponse attendue ; une comparaison suffit.

Exercice 3 — Sélectionner sans la souris

Étude de cas Niveau 2 — Application

Objectif : Associer chaque geste de sélection à sa portée : mot, phrase, paragraphe, document.

Pour chaque situation proposée : geste est un code parmi doubleclic, ctrlclic, tripleclic ou ctrla et cible un code parmi mot, phrase, paragraphe ou document. Indiquez geste : cible si le couple est juste, sinon geste : AUTRE, puis justes : X/n.

Cas d’exemple
2
doubleclic mot
ctrla phrase
Résolution attendue
doubleclic : mot
ctrla : AUTRE
justes : 1/2
Deux indices, rédigés en mots
  1. Les quatre gestes du support : doubleclic-mot, ctrlclic-phrase, tripleclic-paragraphe, ctrla-document.
  2. Comparez la cible annoncée à la cible attendue du geste.

Sélectionner une phrase à la souris :

Ctrl + clic dans la phrase ; double-clic = mot ; triple-clic = paragraphe.

Sélectionner tout le document :

Ctrl+A ; F8 successifs vont jusqu'à la section.

« Ah ! » est compté par les Statistiques comme…

Tout caractère précédé d'un espace, sans caractère suivant, compte pour un mot.

À la fermeture, « Annuler » signifie…

Oui enregistre, Non ferme sans enregistrer, Annuler reste dans le document.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Chercher le groupe Tableaux dans Accueil : il vit dans Insertion.
  • Confondre mode Web (HTML) et mode Page (par défaut).
  • Oublier Ctrl+S en cours de travail : à la fermeture, Non perd tout.
  • Croire que le compteur de mots est exact : il est approximatif.

7. Méthodologie de résolution

Méthode — se repérer dans Word en trois gestes
  1. Nommer la commande, deviner l'onglet : habitudes (Accueil), objets (Insertion), vues (Affichage).
  2. Choisir le mode d'affichage selon la tâche : Page pour la mise en page, Plan pour structurer.
  3. Enregistrer par réflexe : Ctrl+S dès qu'un paragraphe est stable.

8. Révision active

Résumé essentiel
  • Le ruban organise les commandes en onglets et groupes.
  • Cinq modes d'affichage : Page, Lecture plein écran, Web, Plan, Brouillon.
  • La barre d'état affiche page, langue, zoom et statistiques approximatives.
  • Sélectionner avant de mettre en forme ; enregistrer avant de fermer.

Checklist de maîtrise

  • Je sais classer dix groupes dans leurs onglets.
  • Je sais retrouver les cinq modes d'affichage et leur usage.
  • Je sais sélectionner mot, phrase, paragraphe et document.
  • Je sais dérouler les trois méthodes d'enregistrement.

Les 8 notions à connaître absolument

  1. Ruban : bandeau d'onglets subdivisés en groupes.
  2. Onglet Accueil : Presse-papiers, Police, Paragraphe, Style, Modification.
  3. Onglet Insertion : Pages, Tableaux, Illustrations, Liens, En-tête et pied, Texte, Symbole.
  4. Mode Page : affichage par défaut, marges visibles (2,5 cm).
  5. Barre d'état : page, langue, zoom, statistiques.
  6. F8 : sélection croissante (mot, phrase, paragraphe, section, document).
  7. Ctrl+A : sélection de tout le document.
  8. Enregistrer sous : premier enregistrement — nom, disque, dossier.
