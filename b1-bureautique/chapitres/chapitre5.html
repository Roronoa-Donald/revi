Chapitre 5 — Excel : conditionnelles et compteurs conditionnels

Module 5 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

Le responsable commercial du support calcule une commission à paliers : 10 % si CA < 10000, 15 % si 10000 <= CA < 50000, 20 % si CA >= 50000. C'est le cas d'école de la fonction SI imbriquée — structuré ici par paliers successifs, puis complété par les compteurs conditionnels NB.SI, SOMME.SI et MOYENNE.SI.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. écrire SI(Test; Valeur_si_vrai; Valeur_si_faux) ;
  2. imbriquer des SI pour traiter plusieurs paliers, du plus strict au plus large ;
  3. compter, sommer et moyenner sous condition : NB.SI, SOMME.SI, MOYENNE.SI ;
  4. classer une valeur avec RANG.
  5. tester une condition par études de cas avec if/elif/else.

1. SI et SI imbriqué

SI(Test; Valeur_si_Test_vrai; Valeur_si_Test_faux) renvoie un résultat selon qu'une expression logique est vraie ou fausse : c'est la formule conditionnelle la plus utilisée. L'imbrication place un SI dans un SI : =SI(Test1;valeur1;SI(Test2;valeur2;valeur_fausse)).

La commission du support illustre le schéma : un SI principal teste le premier palier, le sinon en teste un second, et la dernière branche recueille le reste — du palier le plus strict au plus large. Dans une grille d’analyse, le même raisonnement s'évalue palier par palier : le programme teste 50000, puis 10000, sinon applique le taux de base.

Mnémotechnique — « SI imbriqué : tester du plus grand au plus petit »

Si on teste d'abord CA >= 50000, les branches suivantes n'ont plus besoin de vérifier la borne haute : l'ordre fait le travail.

2. NB.SI, SOMME.SI, MOYENNE.SI et RANG

NB.SI(plage;critère) détermine le nombre de cellules non vides répondant à la condition ; SOMME.SI(plage;critère;plage_somme) additionne les cellules spécifiées selon le critère ; MOYENNE.SI(plage;critère;plage_moyenne) en fait la moyenne. Le critère peut être une valeur ou une comparaison.

RANG(nombre;référence;ordre) renvoie le rang d'un nombre dans une liste : sa taille relative aux autres valeurs — l'ordre (croissant ou décroissant) décide si la plus grande valeur prend le rang 1.

Confusions d'examen
  • Un SI imbriqué se lit de l'extérieur vers l'intérieur : le premier test gagne.
  • NB.SI compte ; SOMME.SI additionne ; MOYENNE.SI moyenne — trois usages d'un même critère.
  • RANG a besoin d'un ordre : sans lui, la convention par défaut s'applique.
  • Les bornes du palier : 10000 tombe dans le palier 15 %, pas 10 % (CA >= 10000).

3. Études de cas & applications pratiques

Ces trois études de cas se réalisent directement dans la page. Compléter chaque grille d’analyse à partir des données du cas, puis lancer la validation pour vérifier les réponses critère par critère.

En cas d’hésitation, le bouton Expliquer mon erreur sollicite le tuteur pédagogique pour guider l’application de la méthodologie sans donner directement la solution.

Exercice 1 — La fonction SI

Étude de cas Niveau 2 — Application

Objectif : Transposer la commission du support : appliquez la logique conditionnelle SI d'Excel palier par palier.

L’analyse porte sur d'abord n, puis n lignes « agent ca » (chiffre d'affaires entier). Commission du support : 10% si CA < 10000, 15% si 10000 <= CA < 50000, 20% si CA >= 50000. Pour chaque agent Indiquez agent : X% ; Concluez par commission moyenne : P% (moyenne entière des taux).

Cas d’exemple
3
ana 5000
ben 20000
cleo 60000
Résolution attendue
ana : 10%
ben : 15%
cleo : 20%
commission moyenne : 15%
Deux indices, rédigés en mots
  1. Testez d'abord le plus grand seuil : >= 50000, puis >= 10000, sinon 10.
  2. Cumule les taux pour la moyenne entière.

Exercice 2 — Gauche, droite, STXT

Étude de cas Niveau 2 — Application

Objectif : Reproduire les fonctions de texte sur des chaînes : Gauche, Droite et STXT.

L’analyse porte sur d'abord n, puis n lignes « chaine op a b » où op est un code parmi gauche, droite ou stxt : pour gauche et droite, a est le nombre de caractères (b vaut 0) ; pour stxt, a est la position de départ (1 = première lettre) et b le nombre de caractères. Indiquez le résultat de chaque opération : Gauche extrait les a premiers caractères, Droite les a derniers, STXT extrait b caractères à partir de la position a.

Cas d’exemple
3
informatique gauche 3 0
informatique droite 5 0
informatique stxt 2 3
Résolution attendue
inf
tique
nfo
Deux indices, rédigés en mots
  1. La fonction GAUCHE(texte; n) extrait les n premiers caractères depuis le début de la chaîne.
  2. La fonction DROITE(texte; n) extrait les n derniers caractères, et STXT(texte; départ; longueur) extrait une sous-chaîne intermédiaire.

Exercice 3 — Le SI imbriqué

Étude de cas Niveau 3 — Raisonnement

Objectif : Reproduire la fonction SI imbriquée : mention selon la note, avec messages composés.

L’analyse porte sur d'abord n, puis n lignes « eleve note ». Il applique la fonction SI imbriquée du support : note >= 16 → eleve : tres bien ; note >= 14 → eleve : bien ; note >= 10 → eleve : passe ; sinon eleve : rattrapage. Concluez par recales : X (notes sous 10).

Cas d’exemple

ben 14
cleo 10

Résolution attendue
ana : tres bien
ben : bien
cleo : passe
dan : rattrapage
recales : 1
Deux indices, rédigés en mots
  1. Le SI imbriqué teste du plus strict au plus large : 16, 14, 10, sinon rattrapage.
  2. Compte un recale pour chaque note strictement sous 10.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Tester le palier bas d'abord : tout tombe dans 10 %.
  • Oublier la troisième partie de SOMME.SI : la plage à sommer.
  • Confondre NB.SI (compter) et SOMME.SI (additionner).
  • Donner à RANG une référence sans ordre voulu.

6. Méthodologie de résolution

Méthode — poser une condition en trois gestes
  1. Écrire le test le plus restrictif en premier.
  2. Emboîter les SI (ou elif) jusqu'au cas par défaut.
  3. Vérifier les bornes : 10000 et 50000 changent de palier.

7. Révision active

Résumé essentiel
  • SI(Test;V;F) : la formule conditionnelle de base.
  • SI imbriqué : paliers du plus strict au plus large.
  • NB.SI compte, SOMME.SI additionne, MOYENNE.SI moyenne — sous critère.
  • RANG : la position relative d'une valeur dans une liste.

Checklist de maîtrise

  • Je sais écrire un SI simple et lire un SI imbriqué.
  • Je sais calculer la commission du support aux bornes.
  • Je sais choisir entre NB.SI, SOMME.SI et MOYENNE.SI.
  • Je sais interpréter un RANG.

Les 8 notions à connaître absolument

  1. SI : formule conditionnelle — test, valeur vraie, valeur fausse.
  2. SI imbriqué : un SI dans un SI, paliers successifs.
  3. NB.SI : compter les cellules répondant au critère.
  4. SOMME.SI : additionner la plage_somme selon le critère.
  5. MOYENNE.SI : moyenne de la plage_moyenne selon le critère.
  6. RANG : position relative d'un nombre dans une liste.
  7. Critère : valeur ou comparaison testée.
  8. Commission : 10 / 15 / 20 % selon le CA (cas du support).

Comment vous auto-évaluer

≥ 95 % — niveau de maîtrise recherché.
