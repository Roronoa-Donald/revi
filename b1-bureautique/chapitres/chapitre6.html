Chapitre 6 — PowerPoint : la présentation

Module 6 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

PowerPoint est un programme de présentation assistée par ordinateur : des diapositives qui affichent texte, images, tableaux, graphiques, son ou vidéo — projetées en diaporama, à passage automatique (après un délai) ou manuel. Le support en détaille l'écran, les modes et la construction.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. décrire l'écran : bouton Office, barre d'accès rapide, volet Plan/Diapositives, commentaires ;
  2. retrouver les quatre modes d'affichage et leur vocation ;
  3. créer une présentation vierge ou à partir d'un modèle ;
  4. appliquer un thème et adapter les couleurs ;
  5. construire un diaporama cohérent : titre, contenus, conclusion — et le chronométrer.

1. L'écran et les modes d'affichage

L'écran de PowerPoint : le bouton Office remplace le menu Fichier des versions antérieures ; la barre d'accès rapide affiche les commandes ; la barre de titre donne application et document ; les onglets regroupent les commandes ; le ruban porte les outils de conception ; le volet Plan/Diapositives (à gauche) facilite la navigation ; le volet Commentaires enregistre des remarques diapositive par diapositive ; la fenêtre Diapositives (centre) est l'espace de travail ; les modes d'affichage et le zoom ferment l'écran en bas.

Quatre modes : Normal (une diapositive à la fois, édition du contenu), Trieuse de diapositives (miniatures de toutes les diapositives : vue globale, réorganisation, masquage, transitions, minutage du diaporama automatique), Diaporama (la présentation visualisée sur l'écran ou projetée ; passage automatique après un délai ou manuel ; animations, effets sonores et transitions possibles) et Page de commentaire (diapositive en haut, commentaires en dessous — imprimé, ce document sert de guide au présentateur ou de support distribué à l'assistance).

Mnémotechnique — « Normal édite, la Trieuse organise, le Diaporama projette, la Page commente »

Un verbe par mode : écrire, réorganiser, présenter, annoter.

2. Créer, thématiser, diffuser

Une série de diapositives constitue une présentation — imprimable, affichable en diaporama ou diffusable sur Intranet/Internet. Création : bouton Office, Nouveau, document vierge ; ou un modèle (document prédéfini avec styles, à télécharger depuis Office Online — connexion requise) : il installe des diapositives d'exemple à remplacer. Le bouton Ouvrir et réparer secourt un document corrompu (déconnexion USB, panne de courant).

Les thèmes se choisissent à l'onglet Création ; leur survol affiche un aperçu avant clic. Les couleurs s'adaptent par le menu déroulant Couleurs du groupe Thèmes — le support recommande de ne pas s'arrêter aux couleurs du modèle : elles se changent. L'enregistrement suit les mêmes règles que Word : Enregistrer sous pour la première fois, disquette ensuite.

Confusions d'examen
  • La Trieuse affiche des miniatures ; le mode Normal, une seule diapositive.
  • Le passage automatique se règle par un délai, le manuel par un clic.
  • La page de commentaire sert au présentateur ou à l'assistance, pas au public sur écran.
  • Le bouton Office remplace le menu Fichier — l'option réparer est dans Ouvrir.

3. Études de cas & applications pratiques

Ces trois études de cas se réalisent directement dans la page. Complétez chaque grille d’analyse à partir des données du cas, puis lancez la validation pour vérifier vos réponses critère par critère.

En cas d’hésitation, le bouton Expliquer mon erreur sollicite le tuteur pédagogique pour vous guider dans l’application de la méthodologie sans donner directement la solution.

Exercice 1 — Les modes d'affichage

Étude de cas Niveau 1 — Acquisition

Objectif : Retrouver la vocation de chaque mode d'affichage de PowerPoint.

Pour chaque situation proposée : mode est un code parmi normal, trieuse, diaporama ou commentaire et usage un code parmi edition, vueglobale, projection ou notes. Indiquez mode : OUI si le couple est juste, sinon mode : NON, puis justes : X/n.

Cas d’exemple
2
normal edition
diaporama edition
Résolution attendue
normal : OUI
diaporama : NON
justes : 1/2
Deux indices, rédigés en mots
  1. Les quatre couples : normal-edition, trieuse-vueglobale, diaporama-projection, commentaire-notes.
  2. Un case sur le mode donne l'usage attendu.

Exercice 2 — Composer le diaporama

Étude de cas Niveau 2 — Application

Objectif : Valider la construction d'une présentation : chaque diapositive a un rôle et une place.

Pour chaque situation proposée : type est un code parmi titre, contenu, graphique ou conclusion. Présentation conforme : la diapositive 1 est un titre, la dernière une conclusion, les autres un contenu ou un graphique. Pour chaque diapositive Indiquez diapo : conforme ou diapo : a revoir ; Concluez par presentation : conforme si TOUTES les diapositives sont conformes, presentation : a revoir dès qu'une seule faute.

Cas d’exemple
3
d1 titre
d2 contenu
d3 conclusion
Résolution attendue
d1 : conforme
d2 : conforme
d3 : conforme
presentation : conforme
Deux indices, rédigés en mots
  1. Le numéro de la diapositive est le compteur i : 1 = titre, n = conclusion, entre les deux contenu ou graphique.
  2. Une seule diapositive fautive invalide toute la présentation.

Exercice 3 — Le minutage du diaporama

Étude de cas Niveau 3 — Raisonnement

Objectif : Simuler le minutage automatique : chaque diapositive s'affiche selon sa durée annoncée.

L’analyse porte sur d'abord n, puis n lignes « diapo duree » (durée entière en secondes). Le diaporama avance automatiquement : Indiquez diapo : Xs pour chaque diapositive, puis total : T et moyenne : M (division entière). Une durée à 0 bloque la présentation : dans ce cas le cas affiche diapo : duree nulle à sa place, total : -1 et moyenne : -1.

Cas d’exemple
3
d1 10
d2 20
d3 30
Résolution attendue
d1 : 10s
d2 : 20s
d3 : 30s
total : 60
moyenne : 20
Deux indices, rédigés en mots
  1. Dès qu'une durée vaut 0, pose bloque=1 sans jamais la remettre à 0 : le bilan passe à -1.
  2. La moyenne entière ne se calcule que si rien ne bloque.

Normal : édition, volet Plan/Diapositives à gauche.

Les deux existent, réglés dans le diaporama.

La page de commentaire associe…

Diapositive en haut, commentaires dessous — guide ou support distribué.

Le bouton Office remplace…

Nouveau, Ouvrir, Enregistrer, Enregistrer sous, Quitter.

À télécharger (connexion requise), puis à personnaliser.

Adapter les couleurs d'un thème :

Groupe Thèmes ; le survol donne l'aperçu.

« Ouvrir et réparer » sert en cas de…

Panne, déconnexion USB, extinction brutale : la flèche à droite d'Ouvrir.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Réorganiser les diapositives en mode Normal : la Trieuse est faite pour ça.
  • Oublier de régler le minutage pour un diaporama automatique.
  • Prendre la page de commentaire pour un affichage public.
  • Garder les couleurs d'un modèle sans les adapter : le support invite à les changer.

6. Méthodologie de résolution

Méthode — monter une présentation en trois gestes
  1. Partir d'un vierge ou d'un modèle ; remplacer les diapositives d'exemple.
  2. Thème et couleurs : onglet Création, aperçu au survol, adaptation des couleurs.
  3. Répéter en Trieuse (ordre, transitions, minutage) avant le mode Diaporama.

7. Révision active

Résumé essentiel
  • PowerPoint : présentation assistée par ordinateur — diapositives multimédias.
  • Quatre modes : Normal, Trieuse, Diaporama, Page de commentaire.
  • Modèles et thèmes : styles prédéfinis, couleurs adaptables.
  • Diaporama : passage automatique (délai) ou manuel.

Checklist de maîtrise

  • Je sais nommer les zones de l'écran de PowerPoint.
  • Je sais choisir le bon mode d'affichage par tâche.
  • Je sais créer une présentation depuis un modèle.
  • Je sais régler ordre, transitions et minutage.

Les 8 notions à connaître absolument

  1. Diapositive : page de la présentation (texte, images, son, vidéo).
  2. Mode Normal : édition, une diapositive à la fois.
  3. Mode Trieuse : miniatures, réorganisation, transitions, minutage.
  4. Mode Diaporama : projection, passage automatique ou manuel.
  5. Page de commentaire : notes par diapositive, pour le présentateur.
  6. Modèle : document prédéfini avec styles, à personnaliser.
  7. Thème : habillage global, couleurs adaptables (onglet Création).
  8. Ouvrir et réparer : secours des documents corrompus.

8. Test de maîtrise

Comment t'auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lis ton pourcentage :

< 50 % — relis les quatre modes d'affichage.
50–69 % — refais la carte écran/modes du support.
70–89 % — bon niveau, cible modèles, thèmes et minutage.
≥ 95 % — niveau de maîtrise recherché.
