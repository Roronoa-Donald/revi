Mémo bureautique

Les règles du cours sur une page, dans l'ordre d'une journée de travail. À garder ouvert pendant les exercices et l'atelier.

Word : interface et saisie

onglets : Accueil (Presse-papiers, Police, Paragraphe, Style)

          Insertion (Pages, Tableaux, Illustrations, Liens, Symbole)

          Mise en page / References / Publipostage / Revision / Affichage

modes   : Page (defaut) / Lecture plein ecran / Web (HTML)

          Plan (titres) / Brouillon (rapide, images masquees)

barre d'etat : page, langue, zoom, statistiques (mots APPROXIMATIFS)

selection : doubleclic=mot  ctrlclic=phrase  tripleclic=paragraphe

            ctrla=tout   F8=croissante (ESC sort)

enregistrer : 1er fois Enregistrer sous / Ctrl+S regulierement

              fermeture : Oui enregistre, Non perd, Annuler reste

Sélectionner avant de mettre en forme — et enregistrer avant de fermer.

Word : mise en forme et mise en page

alignements : gauche (marge gauche) / droite (marge droite)

              centrer (milieu) / justifier (LES DEUX bords)

paragraphe : interligne (entre lignes), Avant/Apres (autour)

              retrait (decale d'une tabulation), taquets (regle)

page       : marges 2,5 cm / orientation portrait (longueur)

              ou paysage (largeur) / numeros de page (Insertion)

impression : imprimante par defaut -> apercu -> Ctrl+P

Seul le justifié aligne les deux bords : le défaut des rapports officiels.

Excel : la feuille de calcul

classeur = fichier ; feuilles : clic droit (renommer, inserer,

          deplacer ou copier, supprimer)

barres   : acces rapide / titre / FORMULE (contenu) / etat (options)

onglets  : 7 par defaut + un temporaire pour les objets

alignement par defaut : TEXTE a gauche, CHIFFRES a droite

insertion : ligne au-DESSUS, colonne a GAUCHE

formats  : Nombre (2 dec) / Pourcentage / Texte (litteral) / Date

La barre de formule voit le contenu ; la barre d'état, les options.

Excel : formules et fonctions

formule : commence TOUJOURS par = (sinon texte aligne a gauche)

operateurs : + - * / % ^   comparaison = > < >= <= <>

             & concatene   : plage   ; union   espace intersection

statistiques : =SOMME(A2:A10) =MOYENNE(A2:A10) =MAX =MIN

compteurs : NB (nombres) != NBVAL (non vides)

texte     : =Gauche(B1;3)=INF  =Droite(B1;5)=tique

            =STXT(B1;2;3)=nfo (position 1 = premiere lettre)

conditions : NB.SI (compte) / SOMME.SI (additionne) / MOYENNE.SI

Sans le signe =, la formule reste du texte : le tableur le signale par l'alignement.

Excel : la fonction SI

=SI(Test; Valeur_si_vrai; Valeur_si_faux)

imbrication : du palier le PLUS STRICT au plus large



commission (support) :

  CA >= 50000 -> 20%   (test 1)

  CA >= 10000 -> 15%   (test 2)

  sinon       -> 10%   (cas par defaut)



bash : if / elif / else — meme ordre, memes bornes

RANG(nombre;reference;ordre) : position relative dans la liste

Tester le grand seuil d'abord : l'ordre des tests fait le travail.

PowerPoint : la présentation

ecran : bouton Office (remplace Fichier) / ruban / volet Plan

        Diapositives / volet Commentaires / zoom

modes : Normal (edite) / Trieuse (organise, transitions, minutage)

        Diaporama (projette) / Page de commentaire (annote)

passage : automatique (delai) ou manuel

creation : bouton Office > Nouveau > vierge OU modele (styles)

theme    : onglet Creation, couleurs adaptables (groupe Themes)

secours  : Ouvrir et reparer (document corrompu)

Répéter en mode Trieuse avant de projeter : ordre, transitions, minutage.

Erreurs fréquentes à éviter

  • Mettre en forme sans sélectionner : rien ne change.
  • Chercher le groupe Tableaux dans Accueil : il vit dans Insertion.
  • Croire que le compteur de mots de Word est exact : il est approximatif.
  • Imprimer sans passer par l'aperçu avant impression.
  • Insérer une colonne à droite : elle s'insère à GAUCHE de la sélection.
  • Écrire SOMME(A2:A10) sans le signe = : du texte, pas une formule.
  • Confondre NB (nombres) et NBVAL (non vides).
  • Tester le palier bas de la commission en premier.
  • Compter les positions de STXT à partir de zéro : la première lettre est la position 1.
  • Réorganiser les diapositives en mode Normal : la Trieuse est faite pour ça.
