Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque séance, puis un projet final qui outille le secrétariat entier. Les scripts sont en Bash, comme à l'atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n lignes « groupe onglet » et valide le classement Word, puis le compteur Accueil.
  2. Lit n lignes « alignement bord » et valide les quatre alignements, puis le compteur justifie.
  3. Lit n lignes « valeur type » (texte/nombre) et aligne comme Excel, puis les deux compteurs.
  4. Lit n lignes « mode usage » de PowerPoint et valide les couples, puis le compteur diaporama.
Corrections
read -r n
ok=0
for ((k=0; k<n; k++)); do
  read -r groupe onglet
  case "$groupe" in
    police|paragraphe|styles) attendu="accueil" ;;
    tableaux|symbole) attendu="insertion" ;;
    zoom|macros) attendu="affichage" ;;
  esac
  if [ "$onglet" = "$attendu" ]; then
    echo "$groupe : OK" ; ok=$((ok + 1))
  else
    echo "$groupe : ERREUR"
  fi
done
echo "accueil confirmes : $ok/$n"

read -r n
just=0
for ((k=0; k<n; k++)); do
  read -r alignement bord
  case "$alignement" in
    gauche) attendu="gauche" ;;
    droite) attendu="droite" ;;
    centre) attendu="centre" ;;
    justifie) attendu="lesdeux" ;;
  esac
  if [ "$bord" = "$attendu" ]; then
    echo "$alignement : OUI"
    if [ "$alignement" = "justifie" ]; then just=$((just + 1)) ; fi
  else
    echo "$alignement : NON"
  fi
done
echo "justifies : $just"

read -r n
t=0 ; c=0
for ((k=0; k<n; k++)); do
  read -r valeur type
  if [ "$type" = "texte" ]; then
    echo "$valeur : aligne a gauche" ; t=$((t + 1))
  else
    echo "$valeur : aligne a droite" ; c=$((c + 1))
  fi
done
echo "textes : $t / chiffres : $c"

read -r n
d=0
for ((k=0; k<n; k++)); do
  read -r mode usage
  case "$mode" in
    normal) attendu="edition" ;;
    trieuse) attendu="vueglobale" ;;
    diaporama) attendu="projection" ;;
    commentaire) attendu="notes" ;;
  esac
  if [ "$usage" = "$attendu" ]; then
    echo "$mode : OUI"
    if [ "$mode" = "diaporama" ]; then d=$((d + 1)) ; fi
  else
    echo "$mode : NON"
  fi
done
echo "diaporama confirmes : $d"

Application

Application
  1. Lit n notes puis calcule SOMME, MOYENNE, MAX et MIN au format des formules Excel.
  2. Lit n cellules « contenu type » (nombre/texte/vide) et sort NB, NBVAL et le nombre de vides.
  3. Lit n lignes « chaine op a b » et reproduit Gauche, Droite et STXT (position 1 = première lettre).
  4. Lit n lignes « plage resultat » (somme/moyenne/max/min + valeur) et valide chaque formule.
Corrections
read -r n
somme=0 ; max=0 ; min=999999
for ((k=0; k<n; k++)); do
  read -r note
  somme=$((somme + note))
  [ "$note" -gt "$max" ] && max=$note
  [ "$note" -lt "$min" ] && min=$note
done
echo "=SOMME(...) -> $somme"
echo "=MOYENNE(...) -> $((somme / n))"
echo "=MAX(...) -> $max"
echo "=MIN(...) -> $min"

read -r n
nb=0 ; nbval=0 ; vides=0
for ((k=0; k<n; k++)); do
  read -r contenu type
  if [ "$type" = "vide" ]; then vides=$((vides + 1))
  else
    nbval=$((nbval + 1))
    [ "$type" = "nombre" ] && nb=$((nb + 1))
  fi
done
echo "NB : $nb / NBVAL : $nbval / vides : $vides"

read -r n
for ((k=0; k<n; k++)); do
  read -r chaine op a b
  case "$op" in
    gauche) echo "\${chaine:0:a}" ;;
    droite) echo "\${chaine: -a}" ;;
    stxt) echo "\${chaine:a-1:b}" ;;
  esac
done

read -r n
ok=0
for ((k=0; k<n; k++)); do
  read -r plage resultat
  case "$resultat" in
    somme|moyenne|max|min) echo "$plage : formule valide ($resultat)" ; ok=$((ok + 1)) ;;
    *) echo "$plage : il manque le signe =" ;;
  esac
done
echo "validees : $ok/$n"

Raisonnement

Raisonnement
  1. Lit n lignes « agent ca » et applique la commission à paliers du support (10/15/20 %), verdict de masse salariale compris.
  2. Lit n lignes « eleve note » et applique le SI imbriqué des mentions, puis le taux de réussite.
  3. Lit n lignes « valeur critere » et répond pour NB.SI, SOMME.SI et MOYENNE.SI simulés.
  4. Lit n lignes « diapo duree » et simule le minutage du diaporama, alerte si le total dépasse la durée impartie.
Corrections
read -r n
tot=0 ; masse=0
for ((k=0; k<n; k++)); do
  read -r agent ca
  if [ "$ca" -ge 50000 ]; then taux=20
  elif [ "$ca" -ge 10000 ]; then taux=15
  else taux=10
  fi
  echo "$agent : $taux%"
  tot=$((tot + taux))
  masse=$((masse + ca * taux / 100))
done
echo "taux moyen : $((tot / n))%"
echo "masse : $masse"

read -r n
recus=0
for ((k=0; k<n; k++)); do
  read -r eleve note
  if [ "$note" -ge 16 ]; then m="tres bien"
  elif [ "$note" -ge 14 ]; then m="bien"
  elif [ "$note" -ge 10 ]; then m="passe"
  else m="rattrapage"
  fi
  echo "$eleve : $m"
  [ "$note" -ge 10 ] && recus=$((recus + 1))
done
echo "taux de reussite : $((recus * 100 / n))%"

read -r n
compte=0 ; somme=0
for ((k=0; k<n; k++)); do
  read -r valeur critere
  if [ "$critere" = "retenu" ]; then
    echo "$valeur : compte" ; compte=$((compte + 1)) ; somme=$((somme + valeur))
  else
    echo "$valeur : ecarte"
  fi
done
echo "NB.SI : $compte"
echo "SOMME.SI : $somme"
if [ "$compte" -gt 0 ]; then echo "MOYENNE.SI : $((somme / compte))" ; else echo "MOYENNE.SI : erreur division zero" ; fi

read -r n
impartie=0 ; total=0
for ((k=0; k<n; k++)); do
  read -r diapo duree
  if [ "$k" = "0" ]; then impartie=$duree ; continue ; fi
  echo "$diapo : \${duree}s"
  total=$((total + duree))
done
echo "total : $total / impartie : $impartie"
if [ "$total" -le "$impartie" ]; then
  echo "diaporama : dans les temps"
else
  echo "diaporama : depasse de $((total - impartie))s"
fi

Projet intégrateur — « le classeur de bord du secrétariat »

Cahier des charges

Le script reçoit le journal du secrétariat : d'abord n_docs documents au format doc genre où genre vaut lettre, rapport ou tableau, chaque document devant respecter son orientation (lettre et rapport : portrait, tableau : paysage). Puis n_ventes ventes au format vendeur ca ; chaque vendeur reçoit la commission à paliers du support (10 / 15 / 20 %). Le script affiche pour chaque document doc : conforme ou doc : orientation a revoir, pour chaque vente vendeur : X%, puis le bilan : dossiers conformes : X/n, commission moyenne : Y% (division entière) et le verdict secreariat prete si tous les documents sont conformes, revision requise sinon.

Fonctionnalités attendues
  1. Lire les deux blocs sans mélanger documents et ventes.
  2. Valider chaque orientation selon le genre du document.
  3. Calculer la commission à paliers du plus strict au plus large.
  4. Agréger les deux bilans : conformité et taux moyen.
  5. Verdict final au format exact du cahier des charges.

Contraintes : arithmétique entière (bash refuse les décimales), ordre des tests de paliers, bilan après lecture complète.

Grille d'auto-évaluation du projet (sur 100)
Lecture des deux blocs et parsing correct 20
Validation des orientations 20
Commission à paliers correcte 20
Bilans agrégés (conformes, moyenne) 20
Verdict final conforme 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
read -r n_docs
conformes=0
tout_ok=1
for ((k=0; k<n_docs; k++)); do
  read -r doc genre
  case "$genre" in
    lettre|rapport) attendu="portrait" ;;
    tableau) attendu="paysage" ;;
  esac
  read -r orientation
  if [ "$orientation" = "$attendu" ]; then
    echo "$doc : conforme"
    conformes=$((conformes + 1))
  else
    echo "$doc : orientation a revoir"
    tout_ok=0
  fi
done
read -r n_ventes
tot=0
for ((k=0; k<n_ventes; k++)); do
  read -r vendeur ca
  if [ "$ca" -ge 50000 ]; then taux=20
  elif [ "$ca" -ge 10000 ]; then taux=15
  else taux=10
  fi
  echo "$vendeur : $taux%"
  tot=$((tot + taux))
done
echo "dossiers conformes : $conformes/$n_docs"
echo "commission moyenne : $((tot / n_ventes))%"
if [ "$tout_ok" = "1" ]; then
  echo "verdict : secreariat prete"
else
  echo "verdict : revision requise"
fi
Cette solution combine validation d'orientation, commission à paliers, agrégation et verdict global — les chapitres 2, 5 et 6 en un seul script.
