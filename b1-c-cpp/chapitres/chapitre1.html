Chapitre 1 — Premier programme : structure et compilation

Module 1 ≈ 2 h de travail Gratuit
Mise en situation

Vous viens d'être recruté comme stagiaire IT. Votre première mission : écrire un petit programme qui demande un prénom à l'utilisateur et affiche « Bonjour, <prénom> ! ». Vous n’avez jamais touché au langage C. Ce chapitre te donne exactement ce qu'il faut : compiler et exécuter un programme, comprendre sa structure, afficher du texte avec printf et lire une valeur avec scanf.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. Compiler et exécuter un programme avec gcc ;
  2. reconnaître la structure d'un fichier C (#include, main, return) ;
  3. afficher du texte et des valeurs avec printf ;
  4. lire une entrée avec scanf et son symbole d'adresse ;
  5. lire un premier message d'erreur du compilateur et le corriger.

1. Du texte au programme : ce que fait le compilateur

Définition. Le langage C est un langage compilé : vous écrivez un fichier source .c, un programme appelé compilateur le traduit en instructions machine, et vous exécutez le résultat. Rien ne tourne tant que la traduction n'a pas réussi.

ÉtapeCe qui se passe
PréprocesseurTraite les #include : le contenu des en-têtes est inséré avant compilation.
CompilationLe code C est traduit en assembleur puis en code objet.
Édition de liensLe code objet est relié aux bibliothèques ; on obtient un exécutable.
Niveau 1 — Intuition

Un langage compilé ressemble à un livre qu'on traduit entièrement avant de le lire : la traduction peut échouer (erreur de compilation), et c'est justement elle qui prévient des fautes. Un langage interprété, lui, lit à voix haute et découvre le problème au moment où il arrive.

Niveau 2 — Technique

La commande gcc main.c -o prog applique les trois étapes et produit un fichier exécutable prog. On le lance avec ./prog. Le compilateur gcc traite le C ; g++ traite le C++ (il accepte aussi du C, mais avec les conventions C++).

1.1 Compiler et exécuter

gcc main.c -o prog      /* compile et relie */
./prog                  /* exécute le programme */
gcc --version           /* vérifie la version installée */
Méthode — « gcc introuvable »

1. Vérifiez l'installation : gcc --version. 2. Si la commande manque, installe une chaîne de compilation (GCC/MinGW selon le système). 3. Si la compilation échoue, lis toujours la première erreur : les suivantes en découlent souvent.

2. Structure d'un programme C

Définition. Un programme C minimal comporte une directive d'inclusion, une fonction main, et une valeur de retour. L'exécution commence toujours par main.

#include <stdio.h>       /* déclare printf/scanf */

int main(void) {         /* point d'entrée du programme */
    printf("Bonjour !\n");
    return 0;            /* 0 = succès */
}
ÉlémentRôle
#include <stdio.h>Déclare les fonctions d'entrées/sorties avant de les utiliser.
int main(void)Fonction principale ; int = elle renvoie un entier.
{ … }Délimite le bloc d'instructions.
return 0;Termine le programme en signalant un succès.
;Termine chaque instruction : l'oublier arrête la compilation.
Piège — le point-virgule et la casse

C distingue les majuscules et les minuscules : Main n'est pas main, et Printf n'est pas printf. Chaque instruction se termine par un point-virgule ; les directives #include, elles, n'en ont pas.

3. Afficher : printf

Définition. printf affiche un texte dans lequel des formats sont remplacés par les valeurs fournies à la suite.

printf("Bonjour\n");                 /* texte simple */
printf("Somme : %d\n", a + b);      /* un entier */
printf("Prix : %.2f euro\n", prix);  /* deux décimales */
printf("%s a %d ans\n", nom, age);  /* deux valeurs */
FormatAffiche
%dUn entier
%f, %.2fUn décimal (avec 2 décimales si précisé)
%cUn caractère
%sUne chaîne de caractères
\nUn retour à la ligne
Somme : 7 Prix : 12.50 euro

4. Lire : scanf et le symbole &

Définition. scanf lit une valeur sur l'entrée standard et la range dans une variable. Pour qu'elle puisse la modifier, elle a besoin de l'adresse de cette variable, d'où le symbole & placé devant son nom.

int age;
scanf("%d", &age);          /* lit un entier */

double prix;
scanf("%lf", &prix);        /* lit un décimal (double) */

char nom[50];
scanf("%49s", nom);         /* lit un mot : pas de & (déjà une adresse) */
Piège classique — l'oubli du &

Écrire scanf("%d", age) au lieu de scanf("%d", &age) compile parfois, mais plante à l'exécution : scanf écrit à une adresse invalide. Une chaîne de caractères, en revanche, est déjà une adresse : on ne met pas de & devant.

5. Lire un message du compilateur

Le premier réflexe devant une compilation qui échoue n'est pas de tout réécrire, mais de lire le message. Le compilateur indique toujours le fichier, la ligne et la nature du problème.

main.c:3:12: error: 'printf' undeclared
main.c:5:9:  warning: implicit declaration of function 'scanf'
  • « undeclared » : la fonction est utilisée sans que sa déclaration ait été incluse — il manque souvent un #include.
  • « expected ';' » : une instruction précédente n'est pas terminée.
  • « unterminated » : un guillemet ou un commentaire est resté ouvert.

6. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute le code et la validation fait tourner des jeux de tests indépendants : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire le code de la solution — c’est le principe de l’exercice.

Exercice 1 — Premier affichage personnalisé

C Niveau 1 — Acquisition

Objectif : Lire un mot sur l’entrée standard et l’insérer dans une phrase affichée par printf.

Le programme reçoit un prénom (un seul mot) sur l’entrée standard. Affichez la phrase Bonjour, <prénom> !.

L’exemple affiché doit vraiment venir de la lecture : une phrase écrite en dur ne passera pas les tests cachés.

Entrée du programme
Monde
Sortie attendue
Bonjour, Monde !

Le prénom lu est inséré dans la phrase.

Deux indices, rédigés en mots
  1. Le message de sortie est affiché par une fonction de la bibliothèque d’entrées/sorties : elle reçoit un texte à trous et les valeurs à y insérer.
  2. Un texte se place dans un tableau de caractères et se désigne sans le symbole d’adresse : c’est la seule variable que l’on ne fait pas précéder d’un « & ».

Exercice 2 — Somme de deux nombres

C Niveau 1 — Acquisition

Objectif : Lire deux entiers et calculer leur somme avec printf.

Le programme reçoit deux entiers séparés par un espace. Affichez leur somme sous la forme Somme : <valeur>.

Entrée du programme
3 4
Sortie attendue
Somme : 7

3 + 4 = 7.

Deux indices, rédigés en mots
  1. Le calcul se fait entre la lecture et l’affichage : rangez le résultat dans une variable avant de l’afficher, ou calculez-le directement dans l’appel d’affichage.
  2. Le format d’affichage d’un entier est « %d » dans les deux cas — lecture comme écriture.

Exercice 3 — Deux valeurs dans une phrase

C Niveau 2 — Application

Objectif : Lire une chaîne et un entier, puis les placer dans un même affichage.

Le programme reçoit un nom (un mot) puis un âge, séparés par un espace. Affichez Nom : <nom>, age : <age>.

Entrée du programme
Monde 30
Sortie attendue
Nom : Monde, age : 30

Le nom et l’âge lus sont affichés.

Deux indices, rédigés en mots
  1. L’ordre des valeurs passées à l’affichage doit suivre l’ordre des trous du texte : d’abord le texte du nom, puis l’entier.
  2. Deux trous de types différents cohabitent dans une même phrase : « %s » pour le nom, « %d » pour l’âge.

7. QCM — niveau examen

L'exécution commence toujours par main.

Que fait #include <stdio.h> ?

L'en-tête apporte les déclarations de printf et scanf.

8. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Point-virgule oublié : « expected ';' before … ».
  • Mauvaise casse : Main, Printf, Scanf n'existent pas.
  • & oublié dans un scanf scalaire.
  • & en trop devant un tableau de caractères.
  • Guillemet non fermé : « missing terminating " character ».
  • #include manquant : fonction « undeclared ».

9. Méthodologie de résolution

Quand vous voyez un énoncé « entrée calcul sortie »
  1. Écrire le squelette : #include, main, return 0;.
  2. Déclarer une variable par entrée attendue, avec son type.
  3. Lire chaque entrée avec le bon format, sans oublier &.
  4. Afficher exactement le texte demandé (majuscules, espaces, ponctuation).
  5. Compiler et tester avec un jeu de valeurs simple.

10. Révision active

Résumé essentiel
  • Compilé : gcc main.c -o prog puis ./prog.
  • Structure : #include, int main(void), bloc, return 0;.
  • printf : texte à trous, formats %d, %.2f, %c, %s.
  • scanf : toujours l'adresse d'une variable scalaire (&), jamais pour une chaîne.
  • \n termine une ligne ; ; termine une instruction.

Checklist de maîtrise

  • Je compile et exécute un fichier sans aide.
  • Je reconnais chacune des parties de main.
  • Je choisis le bon format d'affichage pour chaque type.
  • Je n'oublie jamais & dans un scanf scalaire.
  • Je lis une erreur de compilation et je la corrige.
