Chapitre 2 — Variables, types et opérateurs

Module 2 ≈ 2 h 30 de travail B1 et plus
Mise en situation

Le service informatique doit calculer la moyenne d'un étudiant : deux notes entières et une note décimale. Ton programme affiche 3 au lieu de 3.5. Pourquoi ? Parce qu'en C, le type des nombres décide du résultat des opérations. Ce chapitre te donne les règles exactes.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. Déclarer une variable avec le bon type (int, float, double, char) ;
  2. prédire la taille d'un type avec sizeof ;
  3. utiliser les opérateurs arithmétiques et expliquer la division entière ;
  4. convertir une valeur explicitement par transtypage ;
  5. choisir le bon format de lecture/affichage pour chaque type.

1. Une variable : un nom, un type, une case mémoire

Définition. Une variable est un emplacement mémoire nommé, dont le type fixe la taille et l'interprétation des bits stockés. Contrairement à Python, le type est déclaré à l'avance et ne change plus.

int nombre_utilisateurs = 150;      /* entier */
double prix_ttc = 12.5;             /* décimal */
char service = 'A';                 /* un caractère */
char nom[50] = "GestionStock";      /* chaîne */
TypeTaille (typique)Plage / usageFormat
char1 octetUn caractère ou un petit entier (−128 à 127)%c
int4 octetsEntiers courants%d
long8 octetsGrands entiers%ld
float4 octetsDécimaux (précision simple)%f
double8 octetsDécimaux (précision double)%lf / %.2f
Niveau 1 — Intuition

Choisir un type, c'est choisir la taille de la boîte. Un char est une petite boîte, un double une grande. Mettre une grande valeur dans une boîte trop petite, c'est le débordement : la valeur est tronquée sans avertissement.

Niveau 2 — Technique

sizeof(type) donne la taille en octets sur la plateforme courante. Un int n'a pas une taille garantie par la norme : elle dépend du système. Pour un code portable, préférer les types à largeur fixe (int32_t, uint8_t) de stdint.h.

2. Déclarer et affecter

int a;             /* déclaration : valeur indéterminée */
a = 10;            /* affectation */
int b = 3;         /* déclaration + initialisation */
const int TVA = 20; /* constante : non modifiable */
Piège — la variable non initialisée

Une variable locale déclarée sans valeur contient ce qui restait dans la mémoire (« valeur indéterminée »). L'utiliser produit un résultat imprévisible : initialise toujours avant de lire.

3. Opérateurs arithmétiques

OpérateurSignificationExemple

La règle d'or : / entre entiers tronque

Si les deux opérandes sont des entiers, / effectue une division entière : 7 / 2 vaut 3. Pour obtenir 3.5, il faut qu'au moins un opérande soit décimal : 7 / 2.0 ou (double)7 / 2. Le reste % n'a de sens que sur des entiers.

int a = 7, b = 2;
printf("%d\n", a / b);            /* 3 */
printf("%.1f\n", (double)a / b);  /* 3.5 */
printf("%d\n", a % b);            /* 1 */

4. Transtypage (conversion explicite)

Définition. Le transtypage force la conversion d'une valeur d'un type vers un autre. Il s'écrit en plaçant le type cible entre parenthèses devant la valeur.

double prix = 12.99;
int arrondi_bas = (int)prix;    /* 12 : troncature, pas arrondi */
int total = (int)(prix + 0.5);  /* arrondi vers le haut */

int notes = 36, eleves = 5;
double moyenne = (double)notes / eleves;   /* 7.2 */
Piège — troncature et promotion

Le transtypage vers un entier tronque et n'arrondit pas : (int)9.99 vaut 9. Si une expression mélange entiers et décimaux, les entiers sont promus en décimaux avant l'opération, mais la promotion ne s'applique pas rétroactivement : 1 / 2 * 2.0 vaut 0.0, pas 1.

5. Lire et afficher selon le type

int n;
scanf("%d", &n);              /* entier */

double d;
scanf("%lf", &d);             /* décimal (double) */

printf("Entier : %d\n", n);
printf("Decimal : %.2f\n", d);
printf("Taille d'un int : %zu octets\n", sizeof(int));

6. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

Exercice 1 — Conversion Celsius vers Fahrenheit

C Niveau 2 — Application

Objectif : Utiliser un type décimal et un arrondi d’affichage.

Le programme reçoit une température en degrés Celsius (nombre décimal). Affichez sa valeur en Fahrenheit sur la forme F = <valeur>, avec exactement deux décimales.

Formule : F = C × 9/5 + 32.

Entrée du programme
25
Sortie attendue
F = 77.00

25 °C correspondent à 77 °F.

Deux indices, rédigés en mots
  1. Une division entre deux entiers donne un résultat entier : pour conserver les décimales, les opérandes doivent être des nombres décimaux.
  2. Le format décimal de lecture d’un double est « %lf » ; à l’affichage, on peut fixer le nombre de décimales entre le « % » et le « f ».

Exercice 2 — Aire et périmètre d’un rectangle

C Niveau 2 — Application

Objectif : Enchaîner plusieurs calculs et plusieurs affichages.

Le programme reçoit la largeur puis la hauteur d’un rectangle (entiers). Affichez l’aire sur une ligne puis le périmètre sur la suivante, comme dans l’exemple.

Entrée du programme
2 7
Sortie attendue
Aire : 14
Perimetre : 18

Aire 2×7 = 14 ; périmètre 2×(2+7) = 18.

Deux indices, rédigés en mots
  1. L’aire est le produit des deux dimensions ; le périmètre additionne deux fois chaque côté.
  2. Chaque information demandée occupe sa propre ligne : deux appels d’affichage, chacun terminé par un passage à la ligne.

Exercice 3 — Moyenne de trois notes

C Niveau 3 — Raisonnement

Objectif : Éviter la division entière dans un calcul de moyenne.

Le programme reçoit trois notes entières. Affichez leur moyenne sous la forme Moyenne : <valeur>, avec deux décimales.

Entrée du programme
12 15 9
Sortie attendue
Moyenne : 12.00

12 + 15 + 9 = 36 ; 36 / 3 = 12.00.

Deux indices, rédigés en mots
  1. La somme de trois entiers est un entier : c’est la division qui doit se faire en décimal, sans quoi la partie fractionnaire disparaît.
  2. Pour un résultat décimal, l’un des deux nombres divisés doit être un nombre à virgule.

7. QCM — niveau examen

Que vaut 9 / 4 entre deux int ?

Division entière : la partie décimale est tronquée.

Que vaut 17 % 5 ?

17 = 3 × 5 + 2, le reste est 2.

Quel format lit un double avec scanf ?

En lecture, un double se lit avec %lf.

Que vaut (int)9.99 ?

Le transtypage tronque, il n'arrondit pas.

Combien d'octets occupe typiquement un double ?

Le double est la précision double : 8 octets.

Que vaut 1 / 2 * 2.0 ?

1 / 2 est calculé en entier (0) avant la multiplication par 2.0.

8. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Moyenne entière : diviser deux int et attendre un décimal.
  • Mauvais format : %d pour un double, ou oublier %lf à la lecture.
  • Variable non initialisée : résultat imprévisible.
  • Troncature involontaire : affecter un décimal à un int.
  • Confondre = et == dans une condition (chapitre 3).

9. Méthodologie de résolution

Choisir le type d'un résultat
  1. Compter (effectif, index, identifiant) → int.
  2. Mesurer (moyenne, prix, pourcentage) → double.
  3. Un caractère unique → char.
  4. Un texte → tableau de char.
  5. Avant toute division d'entiers qui doit être décimale : transtyper un opérande en double.

10. Révision active

Résumé essentiel
  • Types de base : char (1 o), int (4 o), double (8 o) — voir sizeof.
  • / entre entiers tronque ; % donne le reste.
  • Transtypage : (double)a / b pour une division décimale.
  • Lecture double : %lf ; affichage : %.2f.
  • Une variable non initialisée n'a pas de valeur prévisible.

Checklist de maîtrise

  • Je choisis le bon type pour chaque donnée.
  • Je prédis le résultat d'une division entière.
  • Je convertis explicitement avant une division décimale.
  • J'associe chaque type à son format.
  • J'initialise toute variable avant de la lire.
