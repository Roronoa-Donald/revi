Chapitre 3 — Conditions et boucles

Module 3 ≈ 2 h 30 de travail B1 et plus
Mise en situation

Un programme qui ne fait que lire et calculer une fois n'est pas très utile. Pour traiter une classe de trente étudiants, décider qui est admis, répéter un calcul, il faut deux outils : la condition pour choisir, la boucle pour répéter. Ce chapitre les met en place.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. Écrire une condition avec if, else if, else ;
  2. comparer plusieurs valeurs constantes avec switch ;
  3. écrire une boucle for, while et do-while ;
  4. choisir la bonne boucle selon le nombre d'itérations ;
  5. contrôler une boucle avec break et continue.

1. Expressions booléennes

Définition. En C, il n'existe pas de type booléen d'origine : une condition est un entier. Zéro vaut faux, tout entier non nul vaut vrai.

OpérateurSensExemple
==égal àa == 5
!=différent dea != 0
<, >inférieur, supérieura < b
<=, >=inférieur ou égal, supérieur ou égala >= 10
&&et logiquea > 0 && a < 10
||ou logiquea == 0 || b == 0
!négation!trouve
Piège — = contre ==

if (a = 5) affecte 5 à a puis teste ce 5 : la condition est toujours vraie ! La comparaison s'écrit ==. C'est l'erreur la plus fréquente en début de C.

2. La condition if

int note;
scanf("%d", &note);

if (note >= 10) {
    printf("Admis\n");
} else if (note >= 8) {
    printf("Rattrapage\n");
} else {
    printf("Ajourne\n");
}

L'ordre des tests compte : on va du cas le plus exigeant au plus permissif. Dès qu'une branche est satisfaite, les suivantes sont ignorées.

Niveau 1 — Intuition

Un if est un carrefour : la voiture (l'exécution) prend la première sortie dont le panneau correspond. Une cascade de else if est une succession de péages sur la même route : on s'arrête au premier qui s'ouvre.

3. Le choix multiple : switch

Définition. switch compare une même expression à plusieurs valeurs constantes. Il remplace une longue cascade de else if quand toutes les comparaisons portent sur la même variable.

int jour;
scanf("%d", &jour);

switch (jour) {
    case 1: printf("Lundi\n"); break;
    case 2: printf("Mardi\n"); break;
    case 6:
    case 7: printf("Week-end\n"); break;
    default: printf("Autre jour\n");
}
Piège — le break oublié

Sans break, l'exécution « tombe » dans les cas suivants et affiche plusieurs messages. C'est parfois voulu (regrouper deux cas), mais le plus souvent c'est un bug.

4. Les boucles

Définition. Une boucle répète un bloc tant qu'une condition est vraie, ou un nombre de fois connu à l'avance.

BoucleQuand l'utiliser
forNombre d'itérations connu (parcourir 1..n, un tableau).
whileRépéter tant qu'une condition tient, nombre inconnu à l'avance.
do-whileComme while, mais le corps s'exécute au moins une fois.
for (int i = 1; i <= 10; i++) {
    printf("%d ", i);
}

int n = 0, somme = 0;
while (somme < 100) {
    n++;
    somme += n;
}

int choix;
do {
    printf("Entrez 1 pour continuer : ");
    scanf("%d", &choix);
} while (choix != 1);
Anatomie d'un for

Trois parties séparées par des points-virgules : initialisation (une fois), condition (testée avant chaque tour), incrément (après chaque tour). for (i = 0; i < n; i++) parcourt exactement les indices 0 à n − 1 d'un tableau.

4.1 Contrôler une boucle

for (int i = 0; i < 10; i++) {
    if (i == 5) break;      /* sort immédiatement de la boucle */
    if (i % 2 == 0) continue; /* passe au tour suivant */
    printf("%d ", i);
}

5. Accumuler dans une boucle

Le motif le plus fréquent de tout le cours : déclarer un accumulateur avant la boucle, l'initialiser à l'élément neutre (0 pour une somme, 1 pour un produit), puis le faire grandir à chaque tour.

int n, total = 0;
scanf("%d", &n);
for (int i = 1; i <= n; i++) {
    total += i;
}
printf("Somme : %d\n", total);

6. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute le code et la validation fait tourner des jeux de tests indépendants : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire le code de la solution — c’est le principe de l’exercice.

Exercice 1 — Plus grand de trois nombres

C Niveau 2 — Application

Objectif : Comparer des valeurs avec des conditions successives.

Le programme reçoit trois entiers. Affichez le plus grand sous la forme Max : <valeur>.

Entrée du programme
4 8 2
Sortie attendue
Max : 8

8 est le plus grand.

Deux indices, rédigés en mots
  1. On peut garder un « candidat » et le remplacer chaque fois qu’une autre valeur le dépasse : deux comparaisons suffisent pour trois nombres.
  2. Attention aux valeurs négatives : initialiser le candidat au premier nombre évite de le fixer à zéro par erreur.

Exercice 2 — Table de multiplication

C Niveau 3 — Raisonnement

Objectif : Écrire une boucle compteur et l’afficher ligne par ligne.

Le programme reçoit un entier n. Affichez sa table de multiplication de 1 à 10, une ligne par produit, sous la forme n x i = r.

Entrée du programme
3
Sortie attendue
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30

Dix lignes, de 1 à 10.

Deux indices, rédigés en mots
  1. Un compteur qui va de 1 à 10 inclus se pilote par une boucle : veillez à ce que la borne de fin soit bien atteinte.
  2. Chaque tour de boucle affiche sa ligne et se termine par un passage à la ligne ; le produit se calcule à l’intérieur du tour.

Exercice 3 — Somme des entiers de 1 à n

C Niveau 3 — Raisonnement

Objectif : Accumuler un résultat dans une boucle.

Le programme reçoit un entier n. Affichez la somme 1 + 2 + … + n sous la forme Somme : <valeur>.

Entrée du programme
10
Sortie attendue
Somme : 55

1 + 2 + … + 10 = 55.

Deux indices, rédigés en mots
  1. Un accumulateur se déclare et s’initialise avant la boucle, puis grandit à chaque tour.
  2. La borne de fin d’une boucle compteur est incluse si la condition utilise « <= » : pour aller jusqu’à n, c’est cette forme qu’il faut.

7. QCM — niveau examen

Quelle est la différence entre = et == ?

Confondre les deux rend une condition toujours vraie.

for (i = 0; i < 5; i++) exécute le corps combien de fois ?

i prend les valeurs 0, 1, 2, 3, 4 : cinq tours.

Quelle boucle garantit au moins une exécution du corps ?

Le test est évalué après le corps dans do-while.

Que fait continue dans une boucle ?

continue saute le reste du corps ; break sort.

Que se passe-t-il si un case de switch n'a pas de break ?

C'est le « fall-through », volontaire ou non.

Où initialiser un accumulateur de somme ?

Initialisé dans la boucle, il repart de zéro à chaque tour.

8. Erreurs classiques — récapitulatif

À reconnaître en examen
  • = au lieu de == dans une condition.
  • break oublié dans un switch.
  • Boucle infinie : la condition ne devient jamais fausse (oublier d'incrémenter).
  • Hors des limites : for (i = 0; i <= n; i++) parcourt n + 1 éléments.
  • Ordre des conditions : tester >= 8 avant >= 10.

9. Méthodologie de résolution

Condition ou boucle ?
  1. Décider parmi des cas → if / else if / else (ou switch si même variable).
  2. Répéter un nombre connu de fois → for.
  3. Répéter jusqu'à une condition (saisie valide, seuil atteint) → while.
  4. Au moins une fois puis condition → do-while.
  5. Ajouter un accumulateur avant la boucle, l'incrémenter dedans, l'afficher après.

10. Révision active

Résumé essentiel
  • 0 = faux, non nul = vrai ; comparaison ==, affectation =.
  • if / else if / else : du plus exigeant au plus permissif.
  • switch : même variable, plusieurs case, break obligatoire.
  • for (n tours), while (condition), do-while (au moins une fois).
  • break sort, continue saute au tour suivant.

Checklist de maîtrise

  • Je n'écris jamais = à la place de ==.
  • Je choisis la boucle adaptée au problème.
  • J'initialise mes accumulateurs avant la boucle.
  • Je place un break dans chaque case.
  • Je prédis le nombre de tours d'une boucle.

Les 8 notions à connaître absolument

  2. == vs =
  3. cascade else if
  4. switch et break
  5. for et ses trois parties
  6. while vs do-while
  7. break/continue
