Chapitre 4 — Tableaux et chaînes de caractères

Module 4 ≈ 3 h de travail B1 et plus
Mise en situation

Trente notes à traiter : trente variables ? Impossible à maintenir. Il faut une collection de valeurs partageant un nom : le tableau. Et puisqu'un texte n'est jamais qu'une suite de caractères, le tableau est aussi la brique des chaînes de caractères en C.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. Déclarer et initialiser un tableau d'entiers ;
  2. parcourir un tableau et calculer somme, moyenne, min, max ;
  3. respecter les bornes d'un tableau (de 0 à n − 1) ;
  4. déclarer et manipuler une chaîne de caractères ;
  5. utiliser les fonctions de string.h et ctype.h.

1. Le tableau : une collection indexée

Définition. Un tableau est une suite de cases contiguës, toutes du même type, désignées par un indice qui commence à 0.

int notes[5] = {10, 12, 14, 9, 15};   /* indices 0 à 4 */
notes[0] = 20;                        /* modifier une case */
printf("%d\n", notes[4]);             /* 15 : dernière case */
printf("%zu\n", sizeof(notes) / sizeof(notes[0]));  /* 5 : nombre de cases */
ÉcritureSens
int t[5];Déclare un tableau de 5 cases (valeurs indéterminées).
int t[5] = {1, 2};Les cases non listées valent 0.
t[0]Première case.
t[n - 1]Dernière case d'un tableau de n cases.
t[n]Hors des limites : comportement indéfini.
Piège — l'indice n n'existe pas

C ne vérifie pas les bornes. Écrire dans t[5] pour un tableau de 5 cases (indices 0 à 4) corrompt la mémoire voisine sans message d'erreur. Toute la vigilance porte sur la borne des boucles : for (int i = 0; i < n; i++).

Niveau 1 — Intuition

Un tableau est une rangée de casiers numérotés. Le premier porte le numéro 0, comme les étages d'un immeuble qui commenceraient au rez-de-chaussée. Demander le casier « numéro 5 » dans une rangée qui s'arrête au numéro 4, c'est s'adresser au casier d'à côté.

2. Parcourir un tableau

int n;
scanf("%d", &n);
int t[100];
for (int i = 0; i < n; i++) {
    scanf("%d", &t[i]);
}

int somme = 0, maximum = t[0];
for (int i = 0; i < n; i++) {
    somme += t[i];
    if (t[i] > maximum) {
        maximum = t[i];
    }
}
printf("Somme : %d\n", somme);
printf("Max : %d\n", maximum);

Initialiser le maximum au premier élément et non à 0 évite l'erreur classique d'un maximum figé sur des valeurs négatives.

3. Chaînes de caractères

Définition. Une chaîne de caractères en C est un tableau de char terminé par le caractère nul '\0'. Sa longueur utile est celle des caractères avant ce terminateur.

char mot[20] = "bonjour";   /* b o n j o u r \0 */
printf("%s\n", mot);        /* affiche bonjour */
printf("%c\n", mot[0]);     /* b */
mot[0] = 'B';               /* Bonjour */
FonctionRôle
strlen(s)Longueur (nombre de caractères avant '\0')
strcpy(dest, src)Copier une chaîne
strcmp(a, b)Comparer : 0 si égales
strcat(a, b)Concaténer (ajouter b à la fin de a)
toupper(c), tolower(c)Changer la casse (dans ctype.h)
#include <string.h>
#include <ctype.h>

int compter_voyelles(const char mot[]) {
    int compte = 0;
    for (int i = 0; mot[i] != '\0'; i++) {
        char c = tolower((unsigned char)mot[i]);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u' || c == 'y') {
            compte++;
        }
    }
    return compte;
}
Attention à la place du terminateur

Une chaîne de n caractères occupe n + 1 cases : il faut toujours réserver la place du '\0'. char mot[5] = "salut"; est une erreur : la chaîne fait 5 caractères et a besoin de 6 cases.

4. Recherche dans un tableau

int chercher(int t[], int n, int valeur) {
    for (int i = 0; i < n; i++) {
        if (t[i] == valeur) {
            return i;      /* trouvé à l'indice i */
        }
    }
    return -1;             /* convention : absent */
}

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute le code et la validation fait tourner des jeux de tests indépendants : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

Exercice 1 — Somme et maximum d’un tableau

C Niveau 3 — Raisonnement

Objectif : Lire un tableau puis le parcourir une fois pour deux résultats.

Le programme reçoit un entier n, puis n entiers. Affichez la somme sur une ligne puis le maximum sur la suivante.

Entrée du programme
5
12 15 14 9 18
Sortie attendue
Somme : 68
Max : 18

Somme 68 ; maximum 18.

Deux indices, rédigés en mots
  1. Comptez à partir de zéro : un tableau de n cases est indexé de 0 à n − 1.
  2. Le maximum ne se devine pas : partez du premier élément et remplacez le candidat dès qu’un élément le dépasse.

Exercice 2 — Compter les voyelles d’un mot

C Niveau 3 — Raisonnement

Objectif : Parcourir une chaîne de caractères caractère par caractère.

Le programme reçoit un mot (un seul mot, sans espace). Affichez le nombre de voyelles qu’il contient, sous la forme Voyelles : <n>. Les voyelles sont a e i o u y, majuscules comme minuscules.

Entrée du programme
python
Sortie attendue
Voyelles : 2

y et o sont des voyelles.

Deux indices, rédigés en mots
  1. Une chaîne se termine par un caractère de fin : c’est lui qui indique au parcours quand s’arrêter, pas la taille du tableau.
  2. Pour ignorer la casse, ramenez chaque caractère en minuscule avant de le comparer à la liste des voyelles.

Exercice 3 — Afficher un tableau à l’envers

C Niveau 4 — Examen

Objectif : Parcourir un tableau dans le sens inverse sans séparateur superflu.

Le programme reçoit un entier n, puis n entiers. Affichez-les dans l’ordre inverse, séparés par une espace, sur une seule ligne.

Entrée du programme
5
10 20 30 40 50
Sortie attendue
50 40 30 20 10

L’ordre est inversé.

Deux indices, rédigés en mots
  1. Le parcours à l’envers commence au dernier indice valide — n − 1 — et décroît jusqu’à zéro inclus.
  2. Pour éviter une espace parasite après la dernière valeur, ne placez le séparateur qu’entre deux valeurs.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Dépassement de borne : for (i = 0; i <= n; i++) ou t[n].
  • Chaîne trop courte : oublier la case du '\0'.
  • Maximum initialisé à 0 sur des valeurs négatives.
  • strcmp comparé à 1 : la comparaison se fait à 0.
  • %s avec un char au lieu d'un char[].

8. Méthodologie de résolution

Traiter un tableau
  1. Écrire la borne : i < n, jamais i <= n.
  2. Lire les cases avec scanf("%d", &t[i]).
  3. Parcourir une seule fois si possible : accumulateurs dans la même boucle.
  4. Initialiser min/max au premier élément.
  5. Vérifier un cas limite : tableau d'un seul élément, valeurs négatives.

9. Révision active

Résumé essentiel
  • Indices de 0 à n − 1 ; pas de contrôle de borne en C.
  • Taille d'un tableau = constante connue à la compilation.
  • Une chaîne est un char[] terminé par '\0'.
  • string.h : strlen, strcpy, strcmp, strcat.
  • Parcours de chaîne : for (i = 0; mot[i] != '\0'; i++).

Checklist de maîtrise

  • J'écris toujours i < n et jamais i <= n.
  • Je réserve une case pour le terminateur d'une chaîne.
  • J'initialise min/max au premier élément.
  • J'utilise les bonnes fonctions de string.h.
  • Je parcours une chaîne jusqu'au '\0'.
