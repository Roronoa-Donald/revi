Chapitre 6 — Pointeurs et mémoire

Module 6 ≈ 3 h de travail B1 et plus
Mise en situation

Tu veux qu'une fonction échange deux valeurs : impossible avec le passage par valeur vu au chapitre 5. La solution passe par l'adresse des variables. Le pointeur est l'outil qui donne au langage C sa puissance — et sa réputation de difficulté. Ce chapitre le démystifie pas à pas.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. Expliquer ce qu'est une adresse mémoire ;
  2. utiliser & (adresse) et * (déréférencement) ;
  3. écrire une fonction qui modifie ses arguments (passage par adresse) ;
  4. parcourir un tableau par arithmétique des pointeurs ;
  5. distinguer un tableau de son adresse de première case.

1. Adresse et pointeur

Définition. Chaque variable occupe une ou plusieurs cases mémoire, repérées par une adresse. Un pointeur est une variable dont la valeur est une adresse.

int x = 5;
int *p = &x;         /* p contient l'adresse de x */

printf("%d\n", x);   /* 5 : la valeur */
printf("%p\n", (void *)&x);  /* l'adresse de x */
printf("%d\n", *p);  /* 5 : la valeur pointée */

*p = 7;              /* écrit dans x via l'adresse */
printf("%d\n", x);   /* 7 */
ÉcritureSens
int *p;Déclare un pointeur vers un int.
&xDonne l'adresse de la variable x.
*pAccède à la valeur située à l'adresse contenue dans p.
p = NULL;Pointeur qui ne vise rien : à tester avant usage.
Niveau 1 — Intuition

Une variable est une maison. &x donne son adresse postale ; p est le facteur qui la connaît ; *p est l'action d'ouvrir la boîte aux lettres à cette adresse, que ce soit pour lire ou pour y déposer quelque chose.

Niveau 2 — Technique

Un pointeur a lui-même un type (int *, double *…) qui indique le type de la donnée pointée. Ce type détermine de combien d'octets le pointeur avance quand on l'incrémente.

2. Passage par adresse

Passer l'adresse d'une variable permet à la fonction de modifier la variable d'origine. C'est le mécanisme utilisé par scanf.

void echange(int *a, int *b) {
    int temporaire = *a;
    *a = *b;
    *b = temporaire;
}

int main(void) {
    int x = 1, y = 2;
    echange(&x, &y);
    printf("x = %d, y = %d\n", x, y);   /* x = 2, y = 1 */
    return 0;
}
Piège — la permutation sans case temporaire

Écrire *a = *b; *b = *a; perd la valeur initiale de *a : après la première affectation, les deux pointent vers la même valeur. La case temporaire est indispensable.

3. Pointeurs et tableaux

Définition. Le nom d'un tableau s'utilise comme l'adresse de sa première case : t équivaut à &t[0]. On peut donc parcourir un tableau par un pointeur.

int t[4] = {10, 20, 30, 40};
int *p = t;             /* même chose que &t[0] */

printf("%d\n", *p);     /* 10 */
p++;                    /* case suivante */
printf("%d\n", *p);     /* 20 */

int somme = 0;
for (int i = 0; i < 4; i++) {
    somme += *(t + i);  /* équivaut à t[i] */
}
t[i] est une écriture de *(t + i)

L'indice n'est qu'une notation plus lisible. Savoir cela aide à comprendre pourquoi t[i] et i[t] sont rigoureusement équivalents — même si le second n'est jamais écrit.

4. Paramètres de sortie

void min_max(int t[], int n, int *mini, int *maxi) {
    *mini = t[0];
    *maxi = t[0];
    for (int i = 1; i < n; i++) {
        if (t[i] < *mini) *mini = t[i];
        if (t[i] > *maxi) *maxi = t[i];
    }
}

int main(void) {
    int t[5] = {12, 4, 19, 7, 15};
    int petit, grand;
    min_max(t, 5, &petit, &grand);
    printf("min = %d, max = %d\n", petit, grand);
    return 0;
}

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Échanger deux valeurs par pointeurs

C Niveau 3 — Raisonnement

Objectif : Modifier les variables de l’appelant par l’intermédiaire d’adresses.

Complétez la fonction echanger qui permute les valeurs pointées par ses deux paramètres. Le programme lit deux entiers, les échange, puis affiche a = <valeur>, b = <valeur>.

Entrée du programme
10 20
Sortie attendue
a = 20, b = 10

Les deux valeurs ont été permutées.

Deux indices, rédigés en mots
  1. Une permutation réelle a besoin d’une troisième case : on y met l’une des deux valeurs avant de la remplacer, sinon elle est perdue.
  2. Un paramètre de type pointeur ne contient pas une valeur mais une adresse : pour atteindre la valeur visée, il faut déréférencer.

Exercice 2 — Deux résultats par paramètres de sortie

C Niveau 4 — Examen

Objectif : Faire produire plusieurs valeurs à une fonction sans rien renvoyer.

Complétez somme_produit qui place dans les cases pointées par s et p la somme et le produit de ses deux premiers paramètres. Le programme affiche la somme puis le produit.

Entrée du programme
2 9
Sortie attendue
Somme : 11
Produit : 18

Somme 11 ; produit 18.

Deux indices, rédigés en mots
  1. Le rôle de la fonction est d’écrire à l’adresse reçue : c’est une affectation à travers le pointeur, pas un retour.
  2. Les deux paramètres de sortie sont distincts : l’ordre dans lequel vous les remplissez n’a pas d’importance, mais chacun doit recevoir le bon calcul.

Exercice 3 — Parcourir un tableau par pointeur

C Niveau 4 — Examen

Objectif : Utiliser l’arithmétique des pointeurs pour avancer dans un tableau.

Complétez le parcours pour additionner les cases du tableau à l’aide d’un pointeur : le nom d’un tableau désigne l’adresse de sa première case, et l’incrémenter avance d’une case. Affichez Somme : <valeur>.

Entrée du programme
5
1 1 1 1 1
Sortie attendue
Somme : 5

Cinq cases valant 1.

Deux indices, rédigés en mots
  1. Le pointeur commence sur la première case ; après chaque ajout, il faut le faire avancer d’une case.
  2. Le déréférencement donne la valeur contenue dans la case visée : c’est cette valeur qui entre dans l’accumulateur.

6. QCM — niveau examen

Que contient un pointeur ?

Un pointeur stocke une adresse.

Que fait &x ?

& est l'opérateur d'adresse.

Que fait *p = 10; ?

Le déréférencement accède à la valeur située à l'adresse.

Que vaut (double)a / b pour a = 9 et b = 2 ?

Le transtypage de a en double rend la division décimale.

Que vaut t seul dans une expression, pour int t[3] ?

Le nom d'un tableau « dégénère » en pointeur vers sa première case.

De combien avance p++ pour un int *p ?

L'incrément se fait en unités du type pointé.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Déréférencer un pointeur non initialisé : comportement indéfini.
  • Oublier & à l'appel d'une fonction attendant un pointeur.
  • Confondre p et *p dans les messages d'erreur.
  • Permutation sans variable temporaire.
  • Pointeur après la fin du tableau : p++ au-delà de la dernière case.

8. Méthodologie de résolution

Faut-il un pointeur ?
  1. La fonction doit-elle modifier l'argument ? → passer son adresse (*).
  2. Le paramètre est-il un tableau ? → il est déjà une adresse, pas de &.
  3. Plusieurs résultats ? → paramètres de sortie par pointeurs.
  4. Simple valeur en entrée ? → passage par valeur suffit.
  5. Tester le pointeur contre NULL avant de le déréférencer.

9. Révision active

Résumé essentiel
  • Un pointeur stocke une adresse ; & la donne, * accède à la valeur.
  • Passage par adresse : la fonction modifie la variable d'origine.
  • t équivaut à &t[0] ; t[i] équivaut à *(t + i).
  • p++ avance d'une case du type pointé.
  • Toujours tester NULL avant de déréférencer.

Checklist de maîtrise

  • J'écris une fonction qui modifie ses arguments.
  • Je parcours un tableau par pointeur.
  • Je n'incrémente pas un pointeur au-delà du tableau.
  • Je ne déréférence jamais un pointeur non initialisé.
