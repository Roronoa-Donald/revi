Chapitre 7 — Structures et fichiers

Module 7 ≈ 3 h de travail B1 et plus
Mise en situation

Un étudiant, c'est un nom et des notes. Gérer trois tableaux parallèles (noms, notes…) devient vite ingérable. La structure regroupe des données hétérogènes sous un même type. Et pour survivre à la fermeture du programme, ces données doivent pouvoir être écrites dans un fichier.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. Déclarer une structure et accéder à ses champs ;
  2. utiliser typedef pour alléger l'écriture ;
  3. passer une structure à une fonction ;
  4. ouvrir, écrire et lire un fichier avec fopen/fprintf/fscanf ;
  5. toujours tester le retour de fopen et fermer le fichier.

1. Déclarer une structure

Définition. Une structure est un type composé : elle regroupe plusieurs variables nommées (champs) sous un même nom de type.

struct Point {
    int x;
    int y;
};

struct Point p = {3, 4};
printf("(%d, %d)\n", p.x, p.y);   /* (3, 4) */
p.x = 10;                         /* modifier un champ */
ÉcritureSens
struct Point p;Déclare une variable de type struct Point.
p.xAccède au champ x (opérateur point).
p->xAccède à x via un pointeur vers la structure (flèche).
{3, 4}Initialise les champs dans l'ordre de déclaration.
Niveau 1 — Intuition

Une structure est une fiche cartonnée : elle a plusieurs cases (les champs), chacune étiquetée. On range la fiche entière d'un bloc, mais on remplit chaque case séparément en la nommant.

2. typedef : donner un nom court

typedef struct {
    char nom[50];
    double note;
} Etudiant;

Etudiant e = {"Ali", 15.5};
printf("%s : %.2f\n", e.nom, e.note);

typedef crée un synonyme : on écrit Etudiant au lieu de struct Etudiant partout. C'est la convention la plus courante en C moderne.

3. Structures et fonctions

Une structure se passe en paramètre et se renvoie comme n'importe quel type. Par valeur, la fonction reçoit une copie complète de la structure.

typedef struct {
    int largeur;
    int hauteur;
} Rectangle;

int aire(Rectangle r) {
    return r.largeur * r.hauteur;
}

int main(void) {
    Rectangle rect = {6, 7};
    printf("Aire : %d\n", aire(rect));   /* 42 */
    return 0;
}

4. Lire et écrire un fichier

Définition. Un fichier est ouvert par fopen, qui renvoie un pointeur de type FILE *, ou NULL en cas d'échec. Il faut toujours tester ce retour, puis fermer avec fclose.

#include <stdio.h>

int main(void) {
    FILE *f = fopen("notes.txt", "w");
    if (f == NULL) {
        printf("Ouverture impossible.\n");
        return 1;
    }
    fprintf(f, "Ali 15\n");
    fprintf(f, "Sara 18\n");
    fclose(f);

    f = fopen("notes.txt", "r");
    if (f == NULL) return 1;
    char nom[50];
    int note;
    while (fscanf(f, "%49s %d", nom, &note) == 2) {
        printf("%s : %d\n", nom, note);
    }
    fclose(f);
    return 0;
}
ModeEffet
"r"Lire ; échoue si le fichier n'existe pas.
"w"Écrire ; crée ou écrase le fichier.
"a"Ajouter à la fin, sans effacer.
"r+"Lire et écrire le fichier existant.
Piège — le mode "w" efface

Ouvrir en "w" un fichier existant le vide immédiatement. Pour conserver le contenu et ajouter des lignes, c'est "a" qu'il faut. Et toujours fermer avec fclose : sinon les dernières écritures peuvent ne jamais atteindre le disque.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Structurer un point

C Niveau 4 — Examen

Objectif : Déclarer une structure et accéder à ses champs.

Complétez le programme pour stocker deux coordonnées dans une structure Point et les afficher sous la forme Point(x, y).

Entrée du programme
2 7
Sortie attendue
Point(2, 7)

Coordonnées x = 2 et y = 7.

Deux indices, rédigés en mots
  1. Un champ de structure s’atteint en écrivant le nom de la variable, un point, puis le nom du champ.
  2. Les deux champs sont lus sur une seule ligne : la lecture les sépare, l’affichage doit les recomposer dans l’ordre demandé.

Exercice 2 — Fiche d’un étudiant

C Niveau 4 — Examen

Objectif : Combiner une chaîne et un décimal dans une même structure.

Complétez le programme pour lire un nom et une note, les ranger dans une structure Etudiant, puis afficher le nom et la note avec deux décimales, comme dans l’exemple.

Entrée du programme
Marie 18.25
Sortie attendue
Nom : Marie
Note : 18.25

Nom et note affichés sur deux lignes.

Deux indices, rédigés en mots
  1. Un champ de type tableau de caractères n’a pas besoin du symbole d’adresse dans la lecture : il est déjà une adresse.
  2. La note est un décimal : son affichage doit fixer le nombre de décimales pour être identique quelle que soit la valeur.

Exercice 3 — Structure passée à une fonction

C Niveau 4 — Examen

Objectif : Passer une structure en paramètre et calculer à partir de ses champs.

Complétez la fonction aire qui reçoit un rectangle et renvoie le produit de sa largeur par sa hauteur. Le programme lit les deux dimensions et affiche Aire : <valeur>.

Entrée du programme
6 7
Sortie attendue
Aire : 42

6 × 7 = 42.

Deux indices, rédigés en mots
  1. Le paramètre est une copie complète de la structure : ses champs s’atteignent avec le point, exactement comme dans le programme principal.
  2. La fonction doit renvoyer la valeur ; l’affichage, lui, reste à la charge de l’appelant.

6. QCM — niveau examen

Comment accéder au champ x d'une structure p ?

Le point s'utilise sur une structure ; la flèche sur un pointeur.

À quoi sert typedef ?

Il évite d'écrire struct à chaque fois.

Que renvoie fopen en cas d'échec ?

L'échec se teste en comparant à NULL.

Quel mode ajoute sans effacer ?

"a" = append.

Quelle fonction ferme un fichier ?

fclose(f); libère le fichier et vide les tampons.

Comment accéder au champ note via un pointeur p vers une structure ?

La flèche combine le déréférencement et l'accès au champ.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • fopen non testé : utiliser un NULL fait planter le programme.
  • fclose oublié : écritures perdues.
  • Mode "w" au lieu de "a" : données écrasées.
  • Confondre . et ->.
  • Chaîne trop courte dans une structure : le nom est tronqué.

8. Méthodologie de résolution

Modéliser avec une structure
  1. Repérer l'entité : étudiant, article, point.
  2. Lister ses attributs et leur type.
  3. Déclarer la structure (avec typedef).
  4. Écrire des fonctions qui prennent la structure en paramètre.
  5. Persister dans un fichier si les données doivent survivre.

9. Révision active

Résumé essentiel
  • Une structure regroupe des champs de types différents.
  • p.champ (valeur) ; p->champ (pointeur).
  • typedef allège l'écriture.
  • fopen renvoie FILE * ou NULL ; toujours tester et fclose.
  • Modes : r lire, w écraser, a ajouter.

Checklist de maîtrise

  • Je déclare et initialise une structure.
  • Je distingue le point de la flèche.
  • Je teste le retour de fopen.
  • Je choisis le bon mode d'ouverture.
  • Je ferme toujours le fichier.
