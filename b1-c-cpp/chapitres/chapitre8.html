Chapitre 8 — Introduction au C++

Module 8 ≈ 3 h de travail B1 et plus
Mise en situation

Le langage C vous a donné le contrôle de la mémoire et de la performance, au prix d'une écriture parfois verbeuse. Le C++ garde cette performance mais ajoute des outils de haut niveau : flux d'entrées/sorties, classes, conteneurs. Ce chapitre vous en donne les bases, en réutilisant tout ce que vous savez déjà.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. Compiler en C++ avec g++ ;
  2. utiliser cout et cin à la place de printf/scanf ;
  3. déclarer une classe avec attributs et méthodes ;
  4. utiliser un vector à la place d'un tableau statique ;
  5. allouer et libérer de la mémoire dynamique avec new/delete.

1. Passer du C au C++

Définition. Le C++ est un langage compilé, dérivé du C, qui ajoute la programmation orientée objet et une bibliothèque standard riche. La compilation se fait avec g++.

g++ main.cpp -o prog
./prog

Niveau 1 — Intuition

Les flux cout et cin ressemblent à des tubes : les << et >> indiquent le sens de circulation des données. Plus besoin de préciser le type : le compilateur le déduit de chaque valeur.

2. Les flux cout et cin

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    cout << "Carre : " << n * n << endl;
    return 0;
}

endl insère un retour à la ligne et vide le tampon de sortie. using namespace std; évite d'écrire std::cout à chaque fois.

3. Les classes

Définition. Une classe regroupe des attributs (les données) et des méthodes (les fonctions qui agissent sur ces données). Elle étend l'idée de structure.

class Rectangle {
public:
    int largeur;
    int hauteur;

    int aire() const {
        return largeur * hauteur;
    }
};

int main() {
    Rectangle r;
    r.largeur = 6;
    r.hauteur = 7;
    cout << "Aire : " << r.aire() << endl;   // 42
    return 0;
}
Mot-cléSens
classDéclare une classe ; accès privé par défaut.
public:Les membres qui suivent sont accessibles de l'extérieur.
const (méthode)La méthode ne modifie pas l'objet.
Différence structure / classe

Dans une struct, les membres sont publics par défaut ; dans une class, privés. C'est la seule vraie différence de départ. On écrit public: pour exposer ce qui doit l'être.

4. Conteneurs et mémoire dynamique

#include <vector>
using namespace std;

vector<int> valeurs(5);         // 5 cases, taille connue à l'exécution
valeurs.push_back(42);          // ajoute une case
cout << valeurs.size() << endl;  // nombre de cases

int *p = new int[10];           // allocation dynamique
delete[] p;                     // libération obligatoire
Piège — new sans delete

Toute mémoire allouée par new doit être libérée par delete (ou delete[] pour un tableau). L'oublier provoque une fuite mémoire ; libérer deux fois provoque un plantage. Un vector s'en charge tout seul : c'est à préférer.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute le code et la validation fait tourner des jeux de tests indépendants : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire le code de la solution — c’est le principe de l’exercice.

Exercice 1 — Entrées/sorties C++

C++ Niveau 4 — Examen

Objectif : Utiliser les flux cin/cout à la place de scanf/printf.

En C++, l’affichage ne passe plus par une fonction à format mais par un flux. Complétez le programme pour lire un entier et afficher Carre : <valeur>.

Entrée du programme
7
Sortie attendue
Carre : 49

7² = 49.

Deux indices, rédigés en mots
  1. L’opérateur d’insertion dans un flux s’enchaîne : on peut écrire un texte, puis une valeur, dans le même ordre qu’on veut les voir apparaître.
  2. Le passage à la ligne a son propre symbole en C++ : il s’insère dans le flux après la valeur.

Exercice 2 — Première classe C++

C++ Niveau 4 — Examen

Objectif : Regrouper des données et un comportement dans une classe.

Complétez la méthode aire de la classe Rectangle pour qu’elle renvoie le produit de ses deux attributs. Le programme lit largeur et hauteur puis affiche Aire : <valeur>.

Entrée du programme
6 7
Sortie attendue
Aire : 42

6 × 7 = 42.

Deux indices, rédigés en mots
  1. À l’intérieur d’une méthode, les attributs de l’objet sont accessibles directement par leur nom.
  2. La méthode est déclarée const : elle promet de ne pas modifier l’objet, elle ne peut donc que lire les attributs et renvoyer un résultat.

Exercice 3 — Conteneur dynamique

C++ Niveau 5 — Challenge

Objectif : Utiliser un conteneur de la bibliothèque standard à la place d’un tableau figé.

Complétez le parcours pour additionner les valeurs d’un vector. Le programme lit un entier n, puis n valeurs, et affiche Somme : <valeur>.

Entrée du programme
5
2 4 6 8 10
Sortie attendue
Somme : 30

2+4+6+8+10 = 30.

Deux indices, rédigés en mots
  1. Un conteneur connaît sa taille : il se parcourt sans avoir à mémoriser n une seconde fois.
  2. La forme moderne de parcours donne directement chaque valeur, sans passer par un indice.

6. QCM — niveau examen

Quelle commande compile un fichier C++ ?

g++ est le compilateur C++.

Quel flux utilise-t-on pour afficher en C++ ?

cout est le flux de sortie standard.

Que fait le mot-clé public: dans une classe ?

Par défaut, les membres d'une classe sont privés ; public: les ouvre.

Quel conteneur remplace un tableau de taille dynamique ?

Le vector connaît sa taille et grandit tout seul.

Quelle instruction libère un tableau alloué par new int[10] ?

Pour un tableau alloué par new[], la libération se fait par delete[].

Que signifie int aire() const ?

const en fin de signature promet de ne pas modifier l'objet.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • #include <iostream> oublié : cout non déclaré.
  • ; après la classe : la déclaration class {...} se termine par un point-virgule.
  • new sans delete : fuite mémoire.
  • delete au lieu de delete[] pour un tableau.
  • Confondre << (sortie) et >> (entrée).

8. Méthodologie de résolution

Du C au C++ sans se perdre
  1. Remplacer #include <stdio.h> par #include <iostream>.
  2. Remplacer printf par cout << … et scanf par cin >> ….
  3. Regrouper données et fonctions dans une classe.
  4. Préférer vector à un tableau dynamique.
  5. Compiler avec g++ et lire les erreurs.

9. Révision active

Résumé essentiel
  • Compilation : g++ main.cpp -o prog.
  • Flux : cout << …, cin >> …, endl.
  • Classe : attributs + méthodes, public: pour exposer.
  • vector : tableau dynamique qui connaît sa taille.
  • new/delete : toujours appariés.
