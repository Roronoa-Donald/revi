Mémo syntaxe — C & C++ B1

Toute la syntaxe du cours, regroupée par thème. À garder ouvert pendant les exercices.

Structure d'un programme C

#include <stdio.h>        /* déclare printf/scanf */

int main(void) {          /* point d'entrée */
    int x;
    scanf("%d", &x);
    printf("x = %d\n", x);
    return 0;            /* 0 = succès */
}

Compilation : gcc main.c -o prog puis exécution ./prog. Pour le C++ : g++ main.cpp -o prog.

Tableaux et chaînes

int notes[5] = {10, 12, 14, 9, 15};   /* indices 0 à 4 */

char mot[20] = "bonjour";           /* finit par '\0' */

string.h : strlen, strcpy, strcmp, strcat. ctype.h : toupper, tolower, isdigit.

Fonctions

}

Pointeurs

int x = 5;
int *p = &x;      /* p contient l'adresse de x */
*p = 7;           /* modifie x via l'adresse */

void echange(int *a, int *b) {
    int tmp = *a; *a = *b; *b = tmp;
}
echange(&x, &y);  /* passer les adresses */

int t[3] = {1, 2, 3};
int *q = t;        /* t == &t[0] */
q++;              /* case suivante */

Structures et fichiers

struct Point { int x; int y; };

printf("%d\n", p.x);

typedef struct { int largeur; int hauteur; } Rectangle;
Rectangle r = {6, 7};

FILE *f = fopen("donnees.txt", "r");
if (f == NULL) { printf("erreur"); }
fprintf(f, "%d\n", 42);
fclose(f);

Modes : r (lire), w (écrire, écrase), a (ajouter), r+ (lire et écrire).

C++ — l'essentiel

#include <iostream>
#include <vector>
using namespace std;

class Rectangle {
public:
    int largeur, hauteur;
    int aire() const { return largeur * hauteur; }
};

int main() {
    int n;
    cin >> n;                          /* lire */
    cout << "n = " << n << endl;        /* écrire */

    vector<int> v(n);
    for (int x : v) cout << x;
    return 0;
}

Erreurs fréquentes à éviter

  • Oublier & dans scanf (sauf pour une chaîne).
  • Diviser deux entiers et attendre un résultat décimal.
  • Dépasser les bornes d'un tableau (t[n] au lieu de t[n-1]).
  • Oublier de terminer une chaîne par '\0' ou de réserver la place pour lui.
  • Oublier break dans un switch.
  • Utiliser un pointeur non initialisé ou libérer deux fois avec delete.
