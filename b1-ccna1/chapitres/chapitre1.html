Chapitre 1 — Généralités et composantes des réseaux

Module 1 ≈ 2 h de travail Accès libre
Mise en situation

Un réseau informatique est un ensemble de matériels reliés entre eux par des supports de transport et échangeant des informations sous forme de données numériques — des bits. Deux ordinateurs connectés forment déjà un réseau minimal. Avant de configurer quoi que ce soit, il faut nommer chaque boîte et chaque câble : c'est le terrain de ce chapitre.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. définir réseau et mise en réseau (networking) ;
  2. placer chaque composante : terminal, routeur, switch L2 et L3, pont, concentrateur, pare-feu, IDS/IPS ;
  3. distinguer les cinq types de paires torsadées (UTP, FTP, STP, SFTP, SSTP) ;
  4. choisir la catégorie de câble selon le débit : cat 5e (1 Gbit/s), cat 6a (10 Gbit/s) ;
  5. expliquer le principe de la fibre optique : réfraction, cœur, revêtement.

1. Les composantes du réseau

Le périphérique terminal (PC, imprimante, serveur) envoie et reçoit des données. Le routeur relie des réseaux distincts et choisit les chemins — c'est la couche réseau. Le commutateur de couche 2 (switch L2) commute les trames dans un même LAN ; le commutateur de couche 3 (switch L3) ajoute le routage entre VLAN. Les générations anciennes survivent dans le vocabulaire : ponts (ancêtres du switch), concentrateurs (hubs, qui répètent les bits sans les comprendre).

La sécurité s'ajoute en couches : le pare-feu filtre le trafic selon des règles ; l'IDS (détection d'intrusion) surveille et alerte, en coupure ou sur un hôte, en temps réel ou a posteriori ; l'IPS (prévention d'intrusion) va plus loin et bloque le comportement malicieux — c'est « la prochaine étape dans l'évolution de l'IDS ».

Mnémotechnique — « le hub répète, le switch comprend, le routeur décide, l'IPS bloque »

Quatre boîtes, quatre degrés d'intelligence : la hiérarchie du réseau en une phrase.

2. Paires torsadées : types et catégories

La paire torsadée — deux conducteurs enroulés en hélice pour minimiser les interférences électromagnétiques — est le support le plus répandu. Cinq types : UTP (non blindée, téléphonie et réseaux domestiques), FTP (écrantée : une feuille d'aluminium autour de l'ensemble des paires), STP (blindée : chaque paire entourée de sa couche conductrice, réseaux Token-Ring), SFTP (écrantée ET blindée, double écran commun), SSTP (super blindée : STP plus un écran commun sous la gaine).

Les catégories (ANSI/TIA/EIA-568B) : cat 1 et 2 abandonnées (téléphonie, Token Ring 4 Mbit/s), cat 3 (16 MHz, téléphonie et 100BASE-T), cat 4 (20 MHz, vite remplacée), cat 5 (100 MHz), cat 5e (125 MHz, jusqu'à 1 Gbit/s), cat 6 (250 MHz), cat 6a (500 MHz, 10 Gbit/s, compatible PoE/PoE+), cat 7 (600 MHz, 10 Gbit/s sur 100 m, blindage individuel et collectif).

Confusions d'examen
  • FTP = écran commun (feuille d'aluminium) ; STP = blindage par paire : deux blindages différents.
  • Cat 5e porte le gigabit ; le 10 Gigabit exige cat 6a ou 7.
  • Le hub (couche 1) ne cible personne ; le switch L2 transfère selon la MAC.
  • L'IDS alerte ; l'IPS bloque : la différence est dans l'action.

3. La fibre optique

La fibre optique — fil de verre ou de plastique très fin — conduit la lumière et sert aux transmissions terrestres et océaniques. Principe : un laser (ou une DEL) transforme le signal électrique en lumière, la fibre la propage, une cellule photoélectrique la reconvertit en signal électrique. Physique : la réfraction — un faisceau qui frappe en biais la surface entre deux milieux se partage en partie réfléchie et partie réfractée ; l'indice de réfraction divise la vitesse de la lumière dans le vide (299 792 km/s) par celle dans le matériau (55 à 60 % dans le verre).

L'atténuation — affaiblissement du signal (loi de Beer-Lambert, Ps = Pe·e^(-αL)) — est extrêmement faible : environ 0,2 dB/km vers 1550 nm, avec réamplification périodique par amplificateurs optiques sur les longues distances.

4. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Quel équipement pour quel rôle

Bash Niveau 1 — Acquisition

Objectif : Classer les composantes du réseau : terminal, routeur, commutateurs L2/L3, concentrateur, pare-feu.

Le script lit n lignes « equipement role » : role est un code parmi terminal, routeur, switchl2, switchl3, hub ou parefeu. Pour chaque ligne il affiche equipement : OK quand le rôle annoncé correspond à l'équipement — PC et imprimante sont des terminaux, le routeur relie les réseaux, le switch L2 commute sur un LAN, le switch L3 route entre VLAN, le hub répéter bêtement, le pare-feu filtre — sinon equipement : ERREUR. Il termine par roles corrects : X/n.

Entrée du programme
3
pc terminal
sw1 switchl2
hub switchl3
Sortie attendue
pc : OK
sw1 : OK
hub : ERREUR
roles corrects : 2/3
Deux indices, rédigés en mots
  1. Un case sur l'équipement donne le rôle attendu ; compare-le au rôle saisi.
  2. Le bilan sort une seule fois, après la boucle.

Exercice 2 — Câble droit ou câble croisé

Bash Niveau 1 — Acquisition

Objectif : Appliquer la règle du brochage : câble droit entre appareils différents, croisé entre appareils similaires.

Le script lit n lignes « liaisontype typeannonce » : liaisontype est un code parmi pc-switch, pc-pc, switch-switch, pc-routeur ou routeur-routeur et typeannonce un code parmi droit ou croise. Règle du support : un câble droit relie deux appareils différents (pc-switch, pc-routeur), un câble croisé relie deux appareils similaires (pc-pc, switch-switch, routeur-routeur). Pour chaque ligne il affiche liaison : conforme ou liaison : a revoir, puis conformes : X/n.

Entrée du programme
3
pc-switch droit
switch-switch droit
pc-pc croise
Sortie attendue
pc-switch : conforme
switch-switch : a revoir
pc-pc : conforme
conformes : 2/3
Deux indices, rédigés en mots
  1. Deux appareils différents → droit ; deux appareils similaires → croisé.
  2. Un case sur la liaison donne le brochage attendu.

Exercice 3 — Choisir la catégorie du câble

Bash Niveau 2 — Application

Objectif : Conseiller la catégorie de paires torsadées selon le débit visé.

Le script lit d'abord n, puis n lignes « site debit » où debit est un code parmi 100m, 1g ou 10g. Règle du support : la catégorie 5e porte le gigabit, la catégorie 6a porte le 10 Gigabit ; en dessous, la catégorie 3 couvre le Fast Ethernet 100 Mbit/s. Pour chaque site il affiche site : cat5e, site : cat6a ou site : cat3, puis cat6a posees : X (nombre de câbles 10G).

Entrée du programme
3
bureau 1g
salle 10g
reception 100m
Sortie attendue
bureau : cat5e
salle : cat6a
reception : cat3
cat6a posees : 1
Deux indices, rédigés en mots
  1. 1g → cat5e ; 10g → cat6a ; 100m → cat3.
  2. Compte les cat6a posées pour le bilan.

5. QCM — niveau examen

Deux ordinateurs connectés constituent…

Définition du support : deux ordinateurs connectés forment à eux seuls un réseau minimal.

Le commutateur de couche 3 sait…

Le switch L3 ajoute le routage à la commutation L2.

L'IPS se distingue de l'IDS car il…

L'IPS répond aux menaces détectées : c'est la prévention.

La paire STP est blindée…

STP : chaque paire entourée de sa couche conductrice (Token-Ring).

La feuille d'aluminium autour de TOUTES les paires désigne…

FTP (F/UTP) : écran général entre gaine et groupement de paires.

Le 10 Gigabit exige au minimum…

Cat 6a : 500 MHz, 10 Gbit/s, compatible PoE/PoE+.

Dans la fibre, la lumière est reconvertie par…

Laser → fibre → cellule photoélectrique : le cycle électrique-lumière-électrique.

L'atténuation minimale de la silice est vers…

Proche infrarouge : ~0,2 dB/km, réamplification périodique au-delà.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Donner un rôle de routage au switch L2 : il commute, il ne route pas.
  • Confondre FTP (écran commun) et STP (blindage par paire).
  • Poser du cat 3 pour du gigabit : cat 5e minimum.
  • Attendre d'un hub qu'il cible le destinataire : il répète tout à tous.

7. Méthodologie de résolution

Méthode — identifier un équipement en trois gestes
  1. Regarder la couche : bits (hub, 1), trames (switch L2, 2), paquets (routeur, 3).
  2. Vérifier le média : paires torsadées (catégorie selon débit) ou fibre (distance, sécurité).
  3. Penser sécurité : pare-feu (filtre), IDS (alerte), IPS (bloque).

8. Révision active

Résumé essentiel
  • Réseau : matériels reliés par des supports, échange de données numériques.
  • Hub répète (couche 1), switch L2 commute, switch L3 route, routeur relie les réseaux.
  • Cinq types de paires torsadées ; catégories de cat 3 (16 MHz) à cat 7 (600 MHz).
  • Fibre : réfraction, atténuation ~0,2 dB/km, multimode et monomode.

Checklist de maîtrise

  • Je sais classer les composantes et leurs couches.
  • Je sais distinguer les cinq types de paires torsadées.
  • Je sais conseiller une catégorie de câble selon le débit.
  • Je sais expliquer le fonctionnement de la fibre optique.

Les 8 notions à connaître absolument

  1. Réseau : ensemble d'ordinateurs et périphériques interconnectés pour échanger.
  2. Switch L3 : commutation + routage entre VLAN.
  3. IDS / IPS : détection (alerte) / prévention (blocage) d'intrusion.
  4. UTP / FTP / STP / SFTP / SSTP : les cinq types de paires torsadées.
  5. Cat 5e : 125 MHz, jusqu'à 1 Gbit/s.
  6. Cat 6a : 500 MHz, 10 Gbit/s.
  7. Réfraction : changement de direction entre deux milieux.
  8. Atténuation : affaiblissement exponentiel (Beer-Lambert).

9. Test de maîtrise

Comment t'auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lis ton pourcentage :

< 50 % — relis les composantes et le tableau des catégories.
