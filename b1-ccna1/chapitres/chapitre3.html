Chapitre 3 — Les réseaux locaux Ethernet

Module 3 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

Ethernet — la famille de normes IEEE 802.3 — régit les réseaux locaux filaires : câblage, connecteurs, règles de protocole. Le support décompose la liaison UTP, les brochages droit et croisé, la trame 802.3 champ par champ, puis le chemin d'une trame en duplex intégral.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. décrire un LAN SOHO (un commutateur, ou un routeur sans fil unique) et un LAN d'entreprise (un switch par étage) ;
  2. décomposer la liaison Ethernet : câble, connecteurs RJ-45, ports ;
  3. appliquer le brochage : câble droit (appareils différents), câble croisé (appareils similaires) ;
  4. citer les champs de la trame 802.3 avec leurs tailles ;
  5. dérouler le chemin d'une trame PC1 → SW1 → SW2 → PC2.

1. SOHO, entreprise et liaisons UTP

Le LAN SOHO (Small Office Home Office) : un commutateur LAN Ethernet pour tous les nœuds (PC, imprimante, routeur vers l'Internet) ; dans la réalité, un seul appareil « routeur sans fil » remplit les trois rôles (routeur, commutateur, point d'accès). Le LAN d'entreprise reproduit ce schéma à plus grande échelle : un commutateur et un point d'accès par étage, dans la salle technique. Les normes sans fil commencent par 802.11 ; les normes Ethernet par 802.3, de 10 Mbit/s à 400 Gbit/s.

La liaison Ethernet = câble + connecteurs RJ-45 + ports. 10BASE-T et 100BASE-T utilisent deux paires ; 1000BASE-T en exige quatre. Les cartes réseau émettent sur les broches 1 et 2 et reçoivent sur 3 et 6 ; les commutateurs font le contraire. D'où deux brochages : le câble droit (broche à broche, entre appareils différents — PC vers switch) et le câble croisé (paires croisées 1-2/3-6, entre appareils similaires — deux commutateurs). Le gigabit transmet et reçoit simultanément sur chaque paire (broches 4-5 et 7-8 ajoutées).

Mnémotechnique — « droit entre différents, croisé entre copains »

PC-switch : droit. Switch-switch, PC-PC : croisé. Le gigabit transmet dans les deux sens sur les quatre paires.

2. La trame 802.3 et le duplex intégral

La trame Ethernet (802.3) : préambule (7 octets, synchronisation), SFD (1 octet, annonce l'adresse MAC de destination), MAC destination (6), MAC source (6), type (2 — IPv4 ou IPv6), données et pad (46 à 1500 octets), FCS (4 — détection d'erreurs par la carte réceptrice). Les données portent un paquet L3, avec un pad si la charge est inférieure à 46 octets.

En duplex intégral (réseaux modernes à commutateurs), chaque liaison permet l'émission et la réception simultanées — plus simple et plus rapide que le semi-duplex exigé par les anciens concentrateurs. Le chemin : PC1 construit et envoie la trame (sa MAC en source, celle de PC2 en destination) ; SW1 relaie de G0/1 vers SW2 ; SW2 livre de F0/2 vers PC2 ; PC2 reconnaît sa MAC et traite.

Confusions d'examen
  • MAC destination et source : 6 octets chacune ; type : 2 ; FCS : 4.
  • Les données font de 46 à 1500 octets : le pad comble le minimum.
  • Le câble croisé relie deux appareils SIMILAIRES, pas deux appareils quelconques.
  • Duplex intégral = émission et réception simultanées, possible grâce aux commutateurs.

3. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Trame Ethernet : compter les octets

Bash Niveau 1 — Acquisition

Objectif : Valider la taille des champs d'une trame Ethernet 802.3 (en-tête, données, FCS).

Le script lit d'abord n, puis n lignes « champ octets » où octets est la taille annoncée. Champs du support : préambule 7, SFD 1, MAC destination 6, MAC source 6, type 2, données 46 à 1500, FCS 4. Pour chaque ligne il affiche champ : OK quand la taille annoncée est juste, sinon champ : KO (attendu X). Il termine par champs justes : X/n.

Entrée du programme
3
destination 6
type 4
fcs 4
Sortie attendue
destination : OK
type : KO (attendu 2)
fcs : OK
champs justes : 2/3
Deux indices, rédigés en mots
  1. Préambule 7, SFD 1, destination 6, source 6, type 2, FCS 4 ; données entre 46 et 1500.
  2. En cas d'erreur, affiche la taille attendue entre parenthèses.

Exercice 2 — SOHO ou entreprise

Bash Niveau 2 — Application

Objectif : Distinguer le réseau local SOHO du réseau local d'entreprise selon l'équipement décrit.

Le script lit n lignes « reseau usage » : usage est un code parmi soho ou entreprise. Réseau SOHO : un seul commutateur pour tous les postes, ou un « routeur sans fil » unique qui fait tout. Réseau d'entreprise : un commutateur par étage dans la salle technique, point d'accès par étage. Pour chaque ligne il affiche reseau : conforme ou reseau : a revoir, puis conformes : X/n.

Entrée du programme
2
domicile soho
etage1 soho
Sortie attendue
domicile : conforme
etage1 : a revoir
conformes : 1/2
Deux indices, rédigés en mots
  1. Un seul appareil qui fait tout → SOHO ; un commutateur par étage → entreprise.
  2. Un case par usage donne la famille attendue.

Exercice 3 — Duplex intégral : le chemin de la trame

Bash Niveau 2 — Application

Objectif : Reproduire le chemin d'une trame Ethernet dans un LAN moderne à commutateurs (duplex intégral).

Le script lit n lignes « etape action » : etape est un code parmi pc1, sw1, sw2 ou pc2 et action un code parmi construit, relais, livre ou reconnait. Chemin du support : PC1 construit et envoie la trame, SW1 relaie de G0/1 vers SW2, SW2 livre de F0/2 vers PC2, PC2 reconnaît sa MAC et traite. Pour chaque ligne il affiche etape : OUI quand le couple est juste, sinon etape : NON, puis justes : X/n.

Entrée du programme
4
pc1 construit
sw1 relais
sw2 livre
pc2 livre
Sortie attendue
pc1 : OUI
sw1 : OUI
sw2 : OUI
pc2 : NON
justes : 3/4
Deux indices, rédigés en mots
  1. Les quatre couples : pc1-construit, sw1-relais, sw2-livre, pc2-reconnait.
  2. Le bilan sort après la boucle.

4. QCM — niveau examen

Les normes Ethernet commencent par…

IEEE 802.3 ; 802.11 désigne le sans-fil.

Un LAN SOHO typique d'aujourd'hui utilise…

Un seul appareil remplit routeur, commutateur et point d'accès.

Les cartes réseau émettent sur les broches…

Émission 1-2, réception 3-6 ; les commutateurs font l'inverse.

Entre deux commutateurs, on utilise…

Appareils similaires : paires croisées 1-2/3-6.

1000BASE-T utilise…

Quatre paires, transmission simultanée sur chaque paire.

La MAC de destination fait…

Comme la MAC source : 6 octets.

Le champ données de la trame 802.3 fait…

Minimum 46 (pad sinon), maximum 1500.

Le FCS sert à…

4 octets, vérifiés par la carte réceptrice.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Relier deux commutateurs par un câble droit : brochage croisé exigé.
  • Oublier le pad quand les données sont sous 46 octets.
  • Confondre SFD (1 octet) et préambule (7 octets).
  • Imaginer du semi-duplex derrière des commutateurs modernes : c'est le règne des hubs.

6. Méthodologie de résolution

Méthode — dérouler une trame en trois gestes
  1. Lire la MAC destination : 6 octets, c'est le destinataire voulu.
  2. Suivre les relais : chaque commutateur reçoit et retransmet vers l'interface suivante.
  3. Vérifier au bout : le destinataire reconnaît sa MAC et traite la trame (FCS juste).

7. Révision active

Résumé essentiel
  • Ethernet = IEEE 802.3, de 10 Mbit/s à 400 Gbit/s ; sans-fil = 802.11.
  • Câble droit entre différents, croisé entre similaires ; gigabit sur 4 paires.
  • Trame : préambule 7, SFD 1, MAC 6+6, type 2, données 46-1500, FCS 4.
  • Duplex intégral : émission et réception simultanées sur chaque liaison.

Checklist de maîtrise

  • Je sais décrire SOHO et entreprise.
  • Je sais choisir droit ou croisé pour cinq liaisons.
  • Je sais citer les champs de la trame avec leurs tailles.
  • Je sais dérouler le chemin PC1 → SW1 → SW2 → PC2.

Les 8 notions à connaître absolument

  1. IEEE 802.3 : la famille de normes Ethernet filaire.
  2. SOHO : Small Office Home Office — petit LAN, souvent un seul appareil.
  3. Câble droit : broche à broche, entre appareils différents.
  4. Câble croisé : paires croisées, entre appareils similaires.
  5. RJ-45 : connecteur à 8 positions (broches).
  6. Trame 802.3 : préambule, SFD, MAC dest/src, type, données, FCS.
  7. FCS : 4 octets de détection d'erreurs.
  8. Duplex intégral : émission et réception simultanées.

Comment t'auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lis ton pourcentage :

< 50 % — relis les brochages et le format de trame.
