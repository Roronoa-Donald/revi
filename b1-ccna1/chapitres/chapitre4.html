Chapitre 4 — Fondamentaux des WAN et du routage IP

Mise en situation

Le WAN est l'interconnexion de plusieurs LAN — par ligne louée (HDLC, PPP) ou par Ethernet WAN (EoMPLS). Le routage IP y achemine les paquets de bout en bout : chaque routeur désencapsule, consulte sa table et réencapsule. Lors du transfert IPv4, le TTL diminue et la somme de contrôle de l'en-tête est actualisée.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. décrire le WAN de lignes louées et le WAN Ethernet (EoMPLS) ;
  2. dérouler les quatre étapes du routage interne d'un routeur ;
  3. comparer des adresses IPv4 et leurs masques pour identifier les sous-réseaux ;
  4. décrire l'en-tête IPv4, sa taille et les champs modifiés lors du routage ;
  5. décrire l'apprentissage des routes par protocole de routage (connectées, annonces, métrique).

1. Les WAN : lignes louées et Ethernet

Le WAN de lignes louées : une liaison permanente louée à un opérateur, dont les détails de liaison de données utilisent HDLC (ou PPP). Le routeur y encapsule le paquet IP dans une trame HDLC. L'Ethernet WAN (EoMPLS — Ethernet over MPLS) est « plus d'actualité » : le WAN se comporte comme un gigantesque switch Ethernet entre les sites.

La logique de routage interne, pour chaque trame qui arrive sur une interface : 1. vérifier le FCS de la trame (erreur → jeter) ; 2. supprimer l'ancien en-tête et la fin de liaison de données, laissant le paquet IP ; 3. comparer l'IP de destination à la table de routage (meilleure route → interface sortante et saut suivant) ; 4. encapsuler le paquet dans un nouvel en-tête approprié à l'interface sortante et transmettre.

À chaque saut, la trame change et le TTL IPv4 diminue

La trame est adaptée à la liaison sortante. Les adresses IP source et destination restent généralement les mêmes en l'absence de traduction d'adresses ou de tunnel.

2. Sous-réseaux, en-tête IP et protocoles de routage

Un sous-réseau est un ensemble d'adresses défini par un préfixe et un masque. Le même segment physique peut porter plusieurs sous-réseaux : comparez les adresses et leur masque, pas seulement la présence d'un routeur. Par exemple, 192.0.2.1/24 et 192.0.3.1/24 ont des préfixes différents, même si elles sont reliées au même commutateur.

L'en-tête IPv4 mesure 20 octets au minimum et jusqu'à 60 octets avec des options ; les adresses source et destination ont chacune 32 bits. Lorsqu'un routeur transmet un paquet, son TTL diminue d'au moins une unité et la somme de contrôle de l'en-tête est recalculée. Sans NAT ni tunnel, les adresses IP restent généralement identiques.

Références : RFC 791, IPv4, RFC 1122, réseaux logiques multiples et RFC 1812, routeurs IPv4, consultées le 30 octobre 2026.

Les protocoles de routage apprennent les routes en trois étapes : chaque routeur ajoute d'abord ses routes connectées ; chaque protocole annonce les routes de sa table à ses voisins (mises à jour de routage) ; après apprentissage, la meilleure route — selon une métrique — entre dans la table. Les hôtes, eux, connaissent leur routeur par défaut : destination de tout paquet hors du sous-réseau local. ARP apprend dynamiquement la MAC de liaison de données d'un hôte IP du LAN.

Confusions d'examen
  • Le FCS est vérifié AVANT la désencapsulation : trame fautive = trame jetée.
  • Un segment commun ne prouve pas que les adresses partagent le même préfixe IP.
  • Le TTL et la somme de contrôle IPv4 changent lors du transfert par un routeur.
  • EoMPLS est un WAN Ethernet : plus d'actualité que HDLC.

Exercice 1 — Comparer des sous-réseaux IPv4

Étude de cas Formative Niveau 1 — Acquisition

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Comparer les préfixes calculés à partir de deux adresses et d'un masque commun.

Pour chaque ligne « nom adresse1 adresse2 /p », les deux adresses utilisent le même préfixe /p. Calculez leur adresse réseau respective ; un segment physique commun ne suffit pas à décider. Indiquez nom : meme reseau si les préfixes sont identiques ou nom : reseaux differents sinon. Terminez par identiques : X/n. Les adresses /31 du dernier cas représentent les deux extrémités d'une liaison point-à-point compatible.

Cas d’exemple
2
meme 192.0.2.1 192.0.2.2 /24
autre 192.0.2.1 192.0.3.1 /24
Deux indices, rédigés en mots
  1. Appliquez le masque à chaque adresse pour obtenir son préfixe réseau.
  2. Comparez les deux préfixes calculés avant de compter les cas identiques.

Exercice 2 — Les quatre étapes du routage

Étude de cas Formative Niveau 2 — Application

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Dérouler la logique interne du routeur : FCS, désencapsulation, table de routage, réencapsulation.

Analysez chaque ligne proposée « etape action » : etape est un numéro de 1 à 4 et action un code parmi fcs, desencapsule, table ou encapsule. Les quatre étapes du support : 1 vérifier le FCS (jeter si erreur), 2 supprimer l'ancien en-tête de liaison de données, 3 chercher la meilleure route pour l'IP de destination, 4 encapsuler dans un nouvel en-tête et transmettre. Pour chaque ligne, indiquez etape N : OUI quand le couple est juste, sinon etape N : NON, puis justes : X/n.

Cas d’exemple
3
1 fcs
2 desencapsule
4 encapsule
Deux indices, rédigés en mots
  1. 1-fcs, 2-desencapsule, 3-table, 4-encapsule : l'ordre du support.
  2. Le numéro affiché est celui de l'étape.

4. QCM — niveau examen

Le WAN de lignes louées utilise comme protocole de liaison…

HDLC (ou PPP) ; EoMPLS est le WAN Ethernet, plus récent.

Première étape du routage interne :

FCS d'abord : trame erronée jetée.

Deux adresses sont sur le même segment : comment comparer leurs sous-réseaux ?

Un segment peut porter plusieurs préfixes ; la MAC seule ne détermine pas le sous-réseau IP.

L'en-tête IPv4 fait…

Le minimum est 20 octets ; des options peuvent porter la taille à 60 octets.

Pendant le routage IPv4, que devient l'en-tête du paquet transmis ?

La trame change, et le routeur actualise aussi des champs de l'en-tête IPv4.

La « meilleure route » est choisie selon…

Métrique : le critère de choix entre plusieurs routes.

Un hôte envoie les paquets distants à…

Logique de transfert de l'hôte : envoyer au routeur par défaut.

ARP sert à…

Résolution d'adresse : IP → MAC sur le segment local.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Chercher la route avant de vérifier le FCS.
  • Encapsuler sans désencapsuler : le vieux cabeau de liaison doit partir.
  • Supposer qu'un segment physique unique impose un préfixe IP unique.
  • Confondre route connectée (apprentissage automatique) et route apprise (annonce).

6. Méthodologie de résolution

Méthode — suivre un paquet en trois gestes
  1. Repérer le sous-réseau de destination : même groupe ou saut vers le routeur par défaut.
  2. À chaque routeur : FCS, désencapsulation, table, réencapsulation.
  3. Vérifier le TTL et la somme de contrôle IPv4 ; sans NAT ni tunnel, les adresses IP restent généralement identiques.

7. Révision active

Résumé essentiel
  • WAN : lignes louées (HDLC, PPP) ou Ethernet WAN (EoMPLS).
  • Routage interne : FCS → désencapsulation → table → réencapsulation.
  • Sous-réseaux : comparer les adresses et les masques, même sur un segment commun.
  • Protocoles de routage : routes connectées, annonces aux voisins, métrique.

Checklist de maîtrise

  • Je sais dérouler les quatre étapes du routage dans l'ordre.
  • Je sais comparer deux préfixes de sous-réseau.
  • Je sais expliquer la taille de l'en-tête IPv4 et ses champs modifiés.
  • Je sais décrire l'apprentissage d'une route par protocole de routage.

Les 8 notions à connaître absolument

  1. HDLC : protocole de liaison des lignes louées.
  2. EoMPLS : Ethernet WAN, le plus d'actualité.
  3. Table de routage : sous-réseau → interface sortante + saut suivant.
  4. Métrique : critère de choix de la meilleure route.
  5. Route connectée : ajoutée sans protocole de routage.
  6. En-tête IPv4 : 20 à 60 octets ; TTL et somme de contrôle sont actualisés au routage.
  7. Routeur par défaut : destination des paquets hors du sous-réseau.
  8. ARP : apprend la MAC d'un hôte IP du LAN.

8. Test de maîtrise

Comment vous auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lisez votre pourcentage :

≥ 95 % — niveau de maîtrise recherché.
