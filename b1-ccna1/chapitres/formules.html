Mémo CCNA 1

Les règles du cours sur une page, dans l'ordre d'un déploiement. À garder ouvert pendant les exercices et l'atelier.

Les composantes et les câbles

roles : hub repete (L1) / switch L2 commute (L2) /

        switch L3 route entre VLAN / routeur relie les reseaux

securite : pare-feu filtre / IDS alerte / IPS bloque



paires torsadees : UTP (rien) / FTP (ecran commun) /

  STP (blindage par paire) / SFTP (double) / SSTP (super)

categories : 100BASE-T4 historique : cat 3 ; 100BASE-TX : cat 5

  cat 5e (1 G) ; 10GBASE-T Cisco : cat 6 UTP 55 m, cat 6a 100 m

fibre : laser -> lumiere -> cellule photoelectrique

  attenuation ~0,2 dB/km vers 1550 nm (Beer-Lambert)

Quatre boîtes, quatre degrés d'intelligence : hub, switch, switch L3, routeur.

Les modèles TCP/IP et OSI

TCP/IP 4 : acces reseau / internet / transport / application

TCP/IP 5 (actualite) : la PHYSIQUE est separee



OSI 7 -> 1 : application (services) / presentation (codage)

  session (RPC, NetBIOS) / transport (segments, ports)

  reseau (paquets, IP, routeurs) / liaison (trames, switch)

  physique (bits, cables, hub)



unites : bits (1) / trame (2) / paquet (3) / segment (4)

L'unité de données trahit la couche : l'examen la demande dans les deux sens.

Ethernet : liaisons et trame 802.3

normes : IEEE 802.3 (Ethernet, 10 Mb/s a 400 Gb/s)

  IEEE 802.11 (sans-fil) / SOHO : un appareil fait tout

  entreprise : un switch + un AP par etage



brochage : NIC emet 1-2, recoit 3-6 ; switch fait l'inverse

  sans Auto-MDIX : MDI / MDI-X = droit ; memes types = croise

  PC et routeur MDI classiques : croise

  1000BASE-T : 4 paires, simultane



trame 802.3 : preamble 7 / SFD 1 / MAC dest 6 / MAC src 6 /

  type 2 / donnees 46-1500 / FCS 4 (erreurs)

duplex integral : emission et reception simultanees

Droit entre différents, croisé entre copains : le brochage suit les rôles.

WAN et routage IP

WAN : lignes louees (HDLC, PPP) OU Ethernet WAN (EoMPLS)



routage interne, 4 etapes :

  1. FCS (erreur -> trame jetee)

  2. desencapsulation (l'en-tete de liaison part)

  3. table de routage (meilleure route -> interface + saut)

  4. reencapsulation + transmission



sous-reseaux : comparer les adresses et les masques

  un meme segment peut porter plusieurs préfixes IP

en-tete IPv4 : 20 a 60 octets ; TTL et somme de controle actualises

protocoles de routage : connectees -> annonces -> metrique

hote : paquet distant -> routeur par defaut ; ARP -> MAC

La trame change à chaque saut. Lors du transfert IPv4, le TTL diminue et la somme de contrôle est actualisée ; sans NAT ni tunnel, les adresses IP restent généralement les mêmes.

La CLI Cisco

acces : console (physique) / Telnet (CLAIR, labo) / SSH (chiffre)



modes : user EXEC (regarder, reload REFUSEE)

  -> enable (privilgie, configure terminal)

  -> config globale (s'applique a l'Entree !)

  -> sous-modes : line con 0, line vty 0 15, interface ...

  exit redescend d'un cran



memoires : RAM (running-config) / NVRAM (startup-config)

  flash (IOS) / ROM (bootstrap)

sauvegarde : copy running-config startup-config

repartir de zero : erase startup-config puis reload

User regarde, enable ose, configure change — et on sauvegarde avant de partir.

Sécuriser et adresser le commutateur

mots de passe simples : (line) password + login

mode enable : enable secret (global)

utilisateurs locaux : username nom secret mdp + login local



SSH : hostname / ip domain-name / crypto key generate rsa

  (IOS XE 17.10 : RSA >= 2048 bits) / ip ssh version 2 /

  authentification : mot de passe ou cle publique selon configuration

  transport input ssh (interdit Telnet)



IPv4 de gestion : interface vlan 1 (SVI) -> ip address ->

  no shutdown -> ip default-gateway -> (fac.) ip name-server

ou : ip address dhcp



confort : logging synchronous / exec-timeout m s

  (0 0 : délai EXEC d'inactivité désactivé)

  / no ip domain-lookup (pas d'attente DNS)

Sans ip default-gateway, le commutateur ne parle pas hors de son sous-réseau.

Erreurs fréquentes à éviter

  • Confondre FTP (écran commun) et STP (blindage par paire).
  • Confondre 100BASE-T4 sur cat 3 avec 100BASE-TX sur cat 5 ; vérifier la portée et le matériel pour 10GBASE-T.
  • Placer « physique » dans le modèle TCP/IP à 4 couches.
  • Confondre segment (4), paquet (3) et trame (2).
  • Choisir un câble d'après les noms des appareils sans vérifier MDI/MDI-X et Auto-MDIX.
  • Chercher la route avant de vérifier le FCS.
  • Croire que l'en-tête IPv4 reste entièrement intact : le TTL et la somme de contrôle changent au routage.
  • Utiliser Telnet en production : tout passe en clair.
  • Modifier la configuration sans copy running-config startup-config.
  • Activer SSH sans crypto key generate rsa : pas de clés, pas de SSH.
