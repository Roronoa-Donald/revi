Examen blanc n°1

Sujet type épreuve — composantes, câbles, modèles, Ethernet.

Exercice 1/5 — Composantes et sécurité

Décrire le rôle du switch L2, du switch L3, du routeur et du hub. Quelle différence entre IDS et IPS ? Entrez pare-feu et IDS ?

Corrigé
Hub (couche 1) : répète les bits sans cibler. Switch L2 : commute les trames dans un LAN. Switch L3 : commutation PLUS routage entre VLAN. Routeur : relie des réseaux distincts. IDS détecte et alerte (en coupure ou sur hôte, temps réel ou a posteriori) ; IPS bloque les menaces. Le pare-feu filtre selon des règles ; l'IDS complète en détectant ce qu'il ne peut pas attraper.
Exercice 2/5 — Câblage

Classer : un câble avec feuille d'aluminium autour de toutes les paires ; un câble à blindage par paire ; un câble sans blindage. Quel câble pour 1 Gbit/s ? Pour 10 Gbit/s ? Où l'atténuation de la fibre est-elle minimale ?

Corrigé
FTP (écran commun), STP (blindage par paire, Token-Ring), UTP (téléphonie, domestique). 1 Gbit/s : cat 5e (125 MHz). 10 Gbit/s : cat 6a (500 MHz) ou cat 7. Fibre : minimum d'atténuation vers 1550 nm (~0,2 dB/km), réamplification périodique au-delà.
Exercice 3/5 — Modèles

Ranger : ASCII ; RPC ; ports TCP ; trame ; bits. Combien de couches a le modèle TCP/IP d'actualité ? Que devient le segment en couche 3 ?

Corrigé
ASCII : couche 6 (présentation) ; RPC : couche 5 (session) ; ports : couche 4 (transport) ; trame : couche 2 ; bits : couche 1. Le modèle d'actualité est TCP/IP à 5 couches (physique séparée). En couche 3, le segment devient un paquet.
Exercice 4/5 — Ethernet

Choisir le brochage : PC vers commutateur ; deux commutateurs ; deux PC. Donner les tailles des champs de la trame 802.3. Que fait le pad ?

Corrigé
PC-switch : câble droit (appareils différents) ; switch-switch et PC-PC : câble croisé (appareils similaires). Trame : préambule 7, SFD 1, MAC destination 6, MAC source 6, type 2, données 46-1500, FCS 4. Le pad comble les données quand la charge est inférieure à 46 octets.

Examen blanc n°2 — variante

Sujet orienté WAN, routage, CLI et configuration.

Exercice 1/5 — WAN et routage

Nommer le protocole de liaison des lignes louées et celui du WAN Ethernet. Dérouler les quatre étapes du routage interne. Que se passe-t-il si le FCS détecte une erreur ?

Corrigé
Lignes louées : HDLC (ou PPP) ; WAN Ethernet : EoMPLS (plus d'actualité). Étapes : 1 vérifier le FCS, 2 désencapsuler (l'ancien en-tête de liaison part), 3 chercher la meilleure route (table de routage), 4 réencapsuler et transmettre. FCS en erreur : la trame est jetée — le routage ne commence pas.
Exercice 2/5 — Sous-réseaux

Deux adresses sans routeur entre elles ? Deux adresses séparées par un routeur ? Que contient l'entrée de la table de routage ? Que fait ARP ?

Corrigé
Sans routeur : même groupe (sous-réseau). Séparées par au moins un routeur : groupes différents. L'entrée de table liste le sous-réseau, l'interface sortante et éventuellement l'adresse du saut suivant. ARP apprend dynamiquement la MAC d'un hôte IP du LAN avant l'envoi.
Exercice 3/5 — CLI Cisco

Classer console, Telnet et SSH selon le support. Pourquoi reload est-elle refusée en mode user ? Placer running-config, startup-config, IOS et bootstrap dans les quatre mémoires. Quelle commande sauvegarde la configuration ?

Corrigé
Console : physique (câble dédié) ; Telnet : clair (dangereux en production) ; SSH : chiffré. reload est une commande puissante : réservée au mode enable. running-config : RAM ; startup-config : NVRAM ; IOS : flash ; bootstrap : ROM. Sauvegarde : copy running-config startup-config.
Exercice 4/5 — Configuration du commutateur

Dérouler la sécurisation complète (mots de passe, utilisateurs locaux, SSH), puis la configuration IPv4 de gestion. À quoi servent logging synchronous et exec-timeout 0 0 ?

Corrigé
Sécurisation : enable secret (global) ; password + login en line con 0 et line vty 0 15 ; ou username nom secret mdp + login local ; SSH : hostname, ip domain-name, crypto key generate rsa (≥ 768 bits), ip ssh version 2, transport input ssh. IPv4 : interface vlan 1, ip address, no shutdown, ip default-gateway, (facultatif) ip name-server. logging synchronous : les syslog attendent la fin de la sortie ; exec-timeout 0 0 : jamais déconnecté — pour le laboratoire.

QCM final — toutes notions

Le commutateur de couche 3 sait…

Commutation L2 PLUS routage entre VLAN.

L'IPS se distingue de l'IDS car il…

Prévention : il répond aux menaces détectées.

Le 10 Gigabit exige au minimum…

Cat 6a : 500 MHz, 10 Gbit/s.

Le modèle TCP/IP d'actualité compte…

La couche physique est séparée de l'accès réseau.

Le segment devient un paquet en couche…

Réseau : adressage logique et routage.

Entre deux PC, le brochage est…

Appareils similaires : paires croisées.

Le champ données de la trame 802.3 fait…

Pad si la charge est sous 46 octets.

Première étape du routage interne :

Trame erronée = trame jetée.

La startup-config est stockée en…

RAM : running-config ; flash : IOS.

La clé SSH se génère par…

Avec hostname et ip domain-name configurés avant.
