Exercices supplémentaires & cas pratiques CCNA 1

De la pratique graduée pour consolider chaque module, puis un dossier de configuration et de sécurisation d’infrastructures Cisco IOS.

Entraînement rapide (acquisition)

Échauffement
  1. Identifier les modes de commandes Cisco IOS (User EXEC, Privileged EXEC, Global Configuration).
  2. Sécuriser l’accès console et les lignes VTY avec mot de passe et chiffrement de service.
  3. Configurer l’interface de gestion SVI (Switch Virtual Interface VLAN 1) sur un commutateur Cisco.
  4. Sauvegarder la configuration active (running-config) dans la mémoire non volatile (startup-config).
Corrections & commandes Cisco IOS

1. Modes IOS : Switch> (User) → enable → Switch# (Privileged) → configure terminal → Switch(config)# (Global).

2. Sécurisation : line console 0 / password / login ; service password-encryption ; enable secret pour le mot de passe privilégié.

3. SVI Management : interface vlan 1 / ip address [IP] [MASQUE] / no shutdown ; ip default-gateway [IP_ROUTEUR].

4. Sauvegarde : copy running-config startup-config (ou write memory) pour persister les réglages en NVRAM.

Application

Application
  1. Calculer les blocs d’adresses VLSM et allouer les adresses de début, de fin et de broadcast.
  2. Distinguer les topologies réseau Ethernet en transmission Half-Duplex (CSMA/CD) et Full-Duplex.
  3. Interpréter les champs d’en-tête d’un paquet IPv4 (TTL, Protocole, Checksum, Adresses source et destination).
  4. Vérifier la connectivité de bout en bout avec les utilitaires ping et traceroute.
Corrections & commandes Cisco IOS

1. VLSM Cisco : Attribution des sous-réseaux contigus aux interfaces de routeurs et liaisons point-à-point en /30 ou /31.

2. Duplex : En Full-Duplex sur commutateur, le domaine de collision est restreint à chaque port physique et CSMA/CD est désactivé.

3. En-tête IPv4 : TTL décrémenté à chaque saut de routeur (évite les boucles infinies) ; champ Protocole 6 pour TCP, 17 pour UDP.

4. Diagnostics : Ping valide la joignabilité ICMP ; traceroute exploite l’expiration progressive du TTL pour cartographier le chemin.

Raisonnement

Raisonnement
  1. Concevoir le schéma d’adressage IPv4 et IPv6 d’un campus d’entreprise comportant plusieurs départements.
  2. Déployer SSH version 2 pour remplacer Telnet sur l’accès distant d’administration des commutateurs.
  3. Configurer la sécurité des ports (Port Security) sur un commutateur pour bloquer les adresses MAC non autorisées.
  4. Résoudre un incident de mauvaise configuration de passerelle ou de masque de sous-réseau.
Corrections & commandes Cisco IOS

1. Double pile : Coexistence native IPv4 (RFC 1918 + NAT) et IPv6 (adresses Global Unicast GUA et Link-Local fe80::).

2. SSHv2 : ip domain-name → crypto key generate rsa → ip ssh version 2 → transport input ssh sur les lignes VTY.

3. Port Security : switchport port-security → maximum 1 → mac-address sticky → violation shutdown.

4. Dépannage : Vérification de show ip interface brief et show arp pour confirmer la cohérence de la table de routage locale.

Dossier de synthèse — Déploiement & Sécurisation Réseau Cisco CCNA

Cahier des charges du Dossier

Ce dossier d’infrastructure Cisco consiste à élaborer l’architecture réseau d’une succursale d’entreprise : topologie commutée redondante, adressage VLSM, passerelles de premier saut et sécurisation des accès administratifs.

Compétences CCNA évaluées
  1. Configuration IOS : Rigueur syntaxique et respect des standards de nommage Cisco.
  2. Adressage hiérarchique : Découpage VLSM rationnel et allocation des sous-réseaux.
  3. Durcissement des équipements : Bannière légale, chiffrement fort, désactivation des services inutiles.
  4. Validation fonctionnelle : Cahier de tests de connectivité et capture de tables d’adresses.
