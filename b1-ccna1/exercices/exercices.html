Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque chapitre, puis un projet final qui qualifie un commutateur de bout en bout. Les scripts sont en Bash, comme à l'atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n lignes « equipement couche » (1/2/3) et valide hub, switch, routeur, puis le compteur couche 2.
  2. Lit n lignes « unite couche » (bits/trame/paquet/segment) et valide le classement, puis le compteur trame.
  3. Lit n lignes « liaison brochage » (droit/croise) et valide selon la règle, puis le compteur croise.
  4. Lit n lignes « memoire contenu » (ram/nvram/flash/rom) et valide le placement, puis le compteur d'erreurs.
Corrections
read -r n
l2=0
for ((k=0; k<n; k++)); do
  read -r equipement couche
  case "$equipement" in
    hub) attendu=1 ;;
    switch) attendu=2 ;;
    routeur) attendu=3 ;;
  esac
  if [ "$couche" = "$attendu" ]; then
    echo "$equipement : OK"
    [ "$equipement" = "switch" ] && l2=$((l2 + 1))
  else
    echo "$equipement : KO (couche $attendu)"
  fi
done
echo "switch en couche 2 : $l2"

Application

Application
  1. Lit n lignes « champ octets » et valide les tailles de la trame 802.3, bornes 46-1500 comprises.
  2. Lit n lignes « etape action » (1 à 4 : fcs/desencapsule/table/encapsule) et valide l'ordre du routage.
  3. Lit n lignes « commande mode » (enable/configure/exit) et valide l'escalade des modes.
  4. Lit n lignes « protection commande » et valide la correspondance des sécurisations.
Corrections
read -r n
ok=0
for ((k=0; k<n; k++)); do
  read -r champ octets
  case "$champ" in
    preamble) attendu=7 ;;
    sfd) attendu=1 ;;
    mac) attendu=6 ;;
    type) attendu=2 ;;
    fcs) attendu=4 ;;
    donnees)
      if [ "$octets" -ge 46 ] && [ "$octets" -le 1500 ]; then
        echo "$champ : OK" ; ok=$((ok + 1))
      else
        echo "$champ : KO (46-1500)"
      fi
      continue ;;
  esac
  if [ "$octets" = "$attendu" ]; then
    echo "$champ : OK" ; ok=$((ok + 1))
  else
    echo "$champ : KO ($attendu attendu)"
  fi
done
echo "champs justes : $ok/$n"

Raisonnement

Raisonnement
  1. Lit n lignes « adresse voisine » (routeur entre les deux ou pas) et tranche même groupe ou groupes différents.
  2. Lit n lignes « site debit » et conseille la catégorie de câble, puis le budget cat6a.
  3. Lit n lignes « session reglages » (suite s/t/d) et juge le confort de console, premier motif manquant.
  4. Lit « seuil n » puis n lignes « switch score » et rend le verdict de qualification (moyenne entière).
Corrections
read -r n
ok=0
for ((k=0; k<n; k++)); do
  read -r adresse voisin
  if [ "$voisin" = "aucun" ]; then verdict="memegroupe" ; else verdict="groupesdifferents" ; fi
  read -r annonce
  if [ "$annonce" = "$verdict" ]; then
    echo "$adresse : conforme" ; ok=$((ok + 1))
  else

  fi
done

read -r n
budget=0
for ((k=0; k<n; k++)); do
  read -r site debit
  case "$debit" in
    1g) echo "$site : cat5e" ;;
    10g) echo "$site : cat6a" ; budget=$((budget + 1)) ;;
    100m) echo "$site : cat3" ;;
  esac
done
echo "budget cat6a : $budget"

read -r n
fluides=0
for ((k=0; k<n; k++)); do
  read -r session reglages
  s=0 ; t=0 ; d=0
  for ((j=0; j<${#reglages}; j++)); do
    c=${reglages:$j:1}
    case "$c" in
      s) s=1 ;;
      t) t=1 ;;
      d) d=1 ;;
    esac
  done
  if [ "$s" = "1" ] && [ "$t" = "1" ] && [ "$d" = "1" ]; then
    echo "$session : fluide" ; fluides=$((fluides + 1))
  elif [ "$s" = "0" ]; then echo "$session : gene (motif syslog)"
  elif [ "$t" = "0" ]; then echo "$session : gene (motif timeout)"
  else echo "$session : gene (motif dns)"
  fi
done
echo "sessions fluides : $fluides/$n"

read -r seuil
read -r n
somme=0
for ((k=0; k<n; k++)); do
  read -r switch score
  echo "$switch : score $score"
  somme=$((somme + score))
done
if [ "$n" -gt 0 ]; then moyenne=$((somme / n)) ; else moyenne=0 ; fi
if [ "$moyenne" -ge "$seuil" ]; then echo "verdict : qualifie" ; else echo "verdict : formation requise" ; fi

Projet intégrateur — « la qualification du commutateur »

Cahier des charges

Le script reçoit le journal de qualification d'un parc de commutateurs : d'abord n_switch commutateurs au format switch protections où protections est une suite de lettres sans espace — e = enable secret présent, l = login local, s = SSH (crypto key), i = IPv4 de gestion (SVI + default-gateway), le tiret - = commutateur vierge. Puis n_cables câbles au format liaison brochage (droit/croise). Il affiche pour chaque commutateur switch : securise si les quatre protections sont présentes, sinon switch : echec (manque X) avec la première lettre manquante dans l'ordre e, l, s, i ; pour chaque câble liaison : conforme ou liaison : a revoir ; enfin le verdict : parc qualifie si tous les commutateurs sont sécurisés et tous les câbles conformes, intervention requise sinon.

Fonctionnalités attendues
  1. Lire les deux blocs sans mélanger commutateurs et câbles.
  2. Analyser chaque suite de protections lettre à lettre.
  3. Valider chaque câble selon la règle droit/croisé.
  4. Compter les échecs avec le premier manque dans l'ordre.
  5. Verdict final au format exact du cahier des charges.

Contraintes : parsing lettre à lettre, première lettre manquante, bilan après lecture complète.

Grille d'auto-évaluation du projet (sur 100)
Lecture des deux blocs et parsing correct 20
Analyse des protections (premier manque) 20
Validation des câbles 20
Verdict global conforme 20
Rapport lisible et formats exacts 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
read -r n_switch
tous_ok=1
for ((k=0; k<n_switch; k++)); do
  read -r switch protections
  e=0 ; l=0 ; s=0 ; i=0
  if [ "$protections" != "-" ]; then
    for ((j=0; j<${#protections}; j++)); do
      c=${protections:$j:1}
      case "$c" in
        e) e=1 ;;
        l) l=1 ;;
        s) s=1 ;;
        i) i=1 ;;
      esac
    done
  fi
  if [ "$e" = "1" ] && [ "$l" = "1" ] && [ "$s" = "1" ] && [ "$i" = "1" ]; then
    echo "$switch : securise"
  elif [ "$e" = "0" ]; then
    echo "$switch : echec (manque e)" ; tous_ok=0
  elif [ "$l" = "0" ]; then
    echo "$switch : echec (manque l)" ; tous_ok=0
  elif [ "$s" = "0" ]; then
    echo "$switch : echec (manque s)" ; tous_ok=0
  else
    echo "$switch : echec (manque i)" ; tous_ok=0
  fi
done
read -r n_cables
cables_ok=1
for ((k=0; k<n_cables; k++)); do
  read -r liaison brochage
  case "$liaison" in
    pc-switch|pc-routeur) attendu="droit" ;;
    pc-pc|switch-switch|routeur-routeur) attendu="croise" ;;
  esac
  if [ "$brochage" = "$attendu" ]; then
    echo "$liaison : conforme"
  else
    echo "$liaison : a revoir" ; cables_ok=0
  fi
done
if [ "$tous_ok" = "1" ] && [ "$cables_ok" = "1" ]; then
  echo "verdict : parc qualifie"
else
  echo "verdict : intervention requise"
fi
