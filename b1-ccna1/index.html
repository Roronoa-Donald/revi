CCNA 1 — réseaux, Ethernet, routage et CLI Cisco

Le CCNA 1 n'est pas du vocabulaire à réciter : c'est une discipline — choisir le bon câble (droit ou croisé), la bonne catégorie (cat 5e, cat 6a), placer la bonne unité dans la bonne couche, dérouler les quatre étapes du routage, escalader les modes de la CLI, sécuriser un commutateur. Six chapitres pour ancrer chaque mécanisme. Chacun est d'abord programmé et vérifié dans l'atelier, puis rejoué tel quel sur les exemples du support.

Ce que tu sauras faire à la fin du cours
  • nommer les composantes du réseau et leurs couches : hub, switch L2/L3, routeur, pare-feu, IDS/IPS ;
  • choisir le câble : type de paire torsadée (UTP à SSTP), catégorie selon le débit, fibre optique ;
  • ranger les unités de données dans les modèles OSI (7 couches) et TCP/IP (4 et 5 couches) ;
  • brocher un lien Ethernet : câble droit ou croisé, champs de la trame 802.3, duplex intégral ;
  • dérouler le routage IP : FCS, désencapsulation, table de routage, réencapsulation ;
  • prendre la main en CLI : modes, mémoires, sécurisation, SSH, IPv4 de gestion.
Comment ce cours s'articule

Le support « B1-IT : CCNA 1 » (Essowaba AHOULOUMI, d'après le programme CCNA 200-301) déroule six chapitres : généralités, modèles, Ethernet LAN, WAN et routage, CLI, configuration du commutateur. Ce cours en garde l'esprit et fait manipuler chaque règle en Bash : un script qui reproduit l'analyse exacte du support — brochages, couches, étapes de routage, escalade des modes — exécuté dans la page.

Chaque chapitre se termine par trois exercices de code : tu écris vraiment le script, il est réellement exécuté, puis corrigé par des tests que tu ne vois pas. La logique écrite ici se rejoue telle quelle sur les commandes et configurations du support (CLI, SSH, SVI).

Programme du cours

1Généralités et composantes des réseaux
Qu'est-ce qu'un réseau ? Les composantes : terminaux, routeur, commutateurs L2/L3, ponts, concentrateurs, pare-feu, IDS/IPS ; câblage paires torsadées (types et catégories) et fibre optique. 2Les modèles TCP/IP et OSI
Le modèle TCP/IP à 4 couches et à 5 couches (d'actualité) ; le modèle OSI en 7 couches, de la physique à l'application ; les unités de données par couche. 3Les réseaux locaux Ethernet
Ethernet (IEEE 802.3) ; réseaux SOHO et d'entreprise ; liaisons UTP : câble droit et croisé, brochages 10/100/1000BASE-T ; la trame 802.3 ; envoi en duplex intégral. 4Fondamentaux des WAN et du routage IP
WAN de lignes louées (HDLC) et Ethernet WAN (EoMPLS) ; la logique de routage en quatre étapes ; règles des sous-réseaux ; l'en-tête IP ; comment les protocoles de routage apprennent les routes. 5L'interface en ligne de commande
Trois accès : console, Telnet, SSH ; modes user et enable ; mode de configuration et sous-modes ; les quatre mémoires ; running-config et startup-config, copie et effacement. 6Configuration de base du commutateur
Mots de passe console et vty, enable secret, utilisateurs locaux, SSH (hostname, ip domain-name, crypto key) ; IPv4 de gestion (SVI, ip address, no shutdown, ip default-gateway) ; commandes de confort.
