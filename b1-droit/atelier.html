Atelier de scripts

Un éditeur dans la page, un vrai interpréteur Bash derrière. Écris un script, exécute-le et lis ce qu'il affiche : c'est ici qu'une norme devient un contrôle automatisé.

Comment fonctionne l'atelier
  • Exécuter fait tourner votre script Bash tel quel et affiche sa sortie, ses erreurs et son code de sortie.
  • Entrée du programme contient ce que read lira, une valeur par ligne.
  • Expliquer mon erreur demande au tuteur, quand il y a une erreur, pourquoi elle survient et par où chercher. Il explique en mots : il n'écrit jamais de code à votre place.
  • Le raccourci Ctrl + Entrée exécute le script sans quitter l'éditeur.
  • Votre code est conservé dans ce navigateur, par exercice et par cours.

Bash

Objectif : expérimenter sans conséquence. Prends un mécanisme de droit (jour franc, registre des abrogations, routing des dossiers), programme-le et teste-le sur des cas limites.

Le script proposé vérifie la hiérarchie : chaque norme doit être de rang inférieur ou égal à la précédente. Ajoute les blocs (constitutionnalité, conventionnalité, légalité, réglementaire), un compteur de violations, ou remplace tout le script par le mécanisme que tu veux vérifier.

Dans un vrai contentieux, ce sera le contrôle de constitutionnalité ou de conventionnalité : la structure du script — lire, comparer, rapporter — reste exactement la même.

De la page au vrai contentieux

La simulation a une limite assumée : aucun dossier réel n'est instruit et aucun texte officiel n'est modifié. Elle a une force : toute la logique se vérifie sans risque — on peut rejouer un contrôle de normes autant de fois que nécessaire. Quand le script reproduit les bons réflexes — lire le texte, identifier son rang, comparer, rapporter — le passage au raisonnement juridique écrit est mécanique.

Les trois erreurs que l'atelier révèle immédiatement
  • Ordre des lectures inversé : le script lit le texte avant le niveau, ou oublie la ligne d'entête.
  • Cas partiels : le case ne couvre qu'un niveau de norme et juge les autres par un défaut silencieux (rang 0).
  • Bilan dans la boucle : le verdict d'ensemble s'affiche à chaque norme au lieu d'une seule fois, après.
Ce que fait l'atelier, côté technique
  • Votre code est envoyé à ce serveur, qui le transmet à un service d'exécution isolé : rien ne tourne sur votre machine, et aucun accès au système n'est possible.
  • La clé du service reste sur le serveur ; le navigateur ne la voit jamais.
  • Le nombre d'exécutions est limité par jour, pour tout le monde. L'atelier n'exécute donc que sur un clic.

Ensuite

Les 6 chapitres contiennent chacun trois exercices Bash corrigés automatiquement dans la page. Une fois l'atelier apprivoisé, ils sont la meilleure façon de vérifier que le mécanisme juridique est vraiment acquis.
