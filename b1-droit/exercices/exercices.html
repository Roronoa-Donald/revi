Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque module, puis un projet final qui outille un greffe numérique. Les scripts sont en Bash, comme à l'atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n énoncés « o/s » et affiche regle ou prerogative, puis les deux compteurs.
  2. Lit n normes « niveau texte » (const, trait, loi, regl) et affiche leur bloc (constitutionnalite, conventionalite, legalite, reglementaire).
  3. Lit n situations « nom situation » (naissance, vivant, deces) et affiche titulaire ou eteinte.
  4. Lit n juridictions « degre » (1, 2, 3) et affiche la juridiction correspondante.
Corrections
read -r n
regles=0
for ((k=0; k<n; k++)); do
  read -r type libelle
  if [ "$type" = "o" ]; then
    echo "$libelle : regle"
    regles=$((regles + 1))
  else
    echo "$libelle : prerogative"
  fi
done
echo "regles : $regles"

    trait) echo "$texte : conventionalite" ;;
    loi) echo "$texte : legalite" ;;
    regl) echo "$texte : reglementaire" ;;
  esac
done

  read -r nom situation
  if [ "$situation" = "deces" ]; then
    echo "$nom : eteinte"
  else
    echo "$nom : titulaire"
  fi
done

  read -r degre
  case "$degre" in
    1) echo "TPI" ;;
    2) echo "Cour d Appel" ;;
    3) echo "Cour Supreme" ;;
  esac
done

Application

Application
  1. Calcule des dates de vigueur : lit n lois « nom jour_parution » et applique le jour franc (parution + 1), en rejetant les parutions nulles.
  2. Registre d'abrogations : lit n événements « texte disposition » et affiche maintenue / abrogee expresse / abrogee tacite / deja abrogee.
  3. Double degré : lit n actes « acte affaire » et vérifie la recevabilité des appels (un jugement préalable, pas déjà appelé).
  4. Validité des contrats : lit n contrats et ses quatre conditions, affiche valide ou le nombre de conditions manquantes.
Corrections
read -r n
valides=0
for ((k=0; k<n; k++)); do
  read -r nom jour
  if [ "$jour" -gt 0 ]; then
    echo "$nom : vigueur au jour $((jour + 1))"
    valides=$((valides + 1))
  else
    echo "$nom : parution invalide"
  fi
done
echo "lois : $valides/$n"

read -r n
declare -A etat
for ((k=0; k<n; k++)); do
  read -r texte disposition
  statut="${etat[$texte]:-}"
  if [ "$statut" != "" ]; then
    echo "$texte : deja abrogee"
  elif [ "$disposition" = "abroge" ]; then
    etat[$texte]=e ; echo "$texte : abrogee expresse"
  elif [ "$disposition" = "incompatible" ]; then
    etat[$texte]=t ; echo "$texte : abrogee tacite"
  else
    echo "$texte : maintenue"
  fi
done

read -r n
declare -A juges
declare -A appeles
for ((k=0; k<n; k++)); do
  read -r acte affaire
  if [ "$acte" = "jugement" ]; then
    juges[$affaire]=1 ; echo "jugement $affaire : rendu"
  elif [ -n "${juges[$affaire]:-}" ] && [ -z "${appeles[$affaire]:-}" ]; then
    appeles[$affaire]=1 ; echo "appel $affaire : recevable"
  else
    echo "appel $affaire : irrecevable"
  fi
done

read -r n
valides=0
for ((k=0; k<n; k++)); do
  read -r contrat c1 c2 c3 c4
  ko=0
  for cond in "$c1" "$c2" "$c3" "$c4"; do
    [ "$cond" = "ko" ] && ko=$((ko + 1))
  done
  if [ "$ko" = "0" ]; then echo "$contrat : valide" ; valides=$((valides + 1))
  else echo "$contrat : $ko manquantes"; fi
done
echo "valides : $valides/$n"

Raisonnement

Raisonnement
  1. Statue dans le temps : lit « vigueur n » puis n situations « nom naissance fin » et applique non-rétroactivité et effet immédiat.
  2. Distingue absence et disparition : lit n personnes « nom jours_sans_nouvelles corps_trouve » et affiche absence, disparition ou vivant.
  3. Litige complet : lit « seuil n » puis n litiges « nom montant cause » et applique le régime du chapitre 6 (dispense, dommages, exequatur).
  4. Audit de la pyramide : lit n normes et affiche le bloc de chaque norme, puis le nombre de violations hiérarchiques.
Corrections

nouvelles=0
for ((k=0; k<n; k++)); do

  else

read -r n
for ((k=0; k<n; k++)); do
  read -r nom jours corps
  if [ "$corps" = "introuvable" ] && [ "$jours" -ge 1 ]; then
    echo "$nom : disparition"
  elif [ "$jours" -ge 1825 ]; then
    echo "$nom : absence (5 ans)"
  else
    echo "$nom : vivant"
  fi
done

read -r seuil
read -r n
total=0
for ((k=0; k<n; k++)); do
  read -r nom montant cause
  if [ "$cause" = "forcemajeure" ]; then echo "$nom : dispense"
  elif [ "$cause" = "delictuel" ]; then echo "$nom : dommages" ; total=$((total + montant))
  elif [ "$montant" -ge "$seuil" ]; then echo "$nom : dommages" ; total=$((total + montant))
  else echo "$nom : exequatur"; fi
done
echo "total : $total"

Projet intégrateur — « greffe numérique »

Cahier des charges

Le script reçoit le journal d'un greffe : d'abord n_normes normes au format niveau texte (const, trait, loi, regl), puis n_dossiers dossiers au format degre affaire (1, 2, 3). Il contrôle la pyramide (chaque norme conforme à la précédente), route chaque dossier vers sa juridiction, signale les appels sans jugement préalable (doublons de degré 2 sans degré 1 pour la même affaire), et produit le bilan : normes conformes, violations, répartition des dossiers par juridiction.

Fonctionnalités attendues
  1. Lire les deux blocs dans l'ordre : normes d'abord, dossiers ensuite.
  2. Contrôler la hiérarchie des normes avec drapeau de rupture.
  3. Router chaque dossier vers TPI, Cour d'Appel ou Cour Suprême.
  4. Contrôler
    5.  la recevabilité des appels (jugement préalable exigé).
  5. Bilan : conformes, violations, compteurs par juridiction, formats exacts.

Contraintes : tableaux associatifs pour les jugements et appels, drapeau de rupture de la pyramide, aucun bilan dans la boucle.

Grille d'auto-évaluation du projet (sur 100)
Lecture des deux blocs sans mélange 20
Contrôle de la pyramide conforme 20
Routage des dossiers exact 20
Recevabilité des appels correcte 20
Bilan final lisible et complet 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

read -r n_normes
rang_actuel=4
conformes=0
violations=0
for ((k=0; k<n_normes; k++)); do
  read -r niveau texte
  case "$niveau" in
    const) rang=4 ;;
    trait) rang=3 ;;
    loi) rang=2 ;;
    regl) rang=1 ;;
    *) rang=0 ;;
  esac
  if [ "$rang" -le "$rang_actuel" ] && [ "$rang" -gt 0 ]; then
    echo "$texte : conforme"
    rang_actuel=$rang
    conformes=$((conformes + 1))
  else
    echo "$texte : viole la hierarchie"
    violations=$((violations + 1))
  fi
done
read -r n_dossiers
declare -A juges
declare -A appeles
tpi=0 ; ca=0 ; cs=0
for ((k=0; k<n_dossiers; k++)); do
  read -r degre affaire
  case "$degre" in
    1) juges[$affaire]=1 ; echo "$affaire : TPI" ; tpi=$((tpi + 1)) ;;
    2) if [ -n "${juges[$affaire]:-}" ] && [ -z "${appeles[$affaire]:-}" ]; then
         appeles[$affaire]=1 ; echo "$affaire : Cour d Appel" ; ca=$((ca + 1))
       else echo "$affaire : appel irrecevable"; fi ;;
    3) echo "$affaire : Cour Supreme" ; cs=$((cs + 1)) ;;
  esac
done
echo "normes conformes : $conformes"
echo "violations : $violations"
echo "TPI : $tpi / CA : $ca / CS : $cs"
Cette solution combine contrôle de la pyramide avec drapeau de rupture, routage par degré et recevabilité des appels — les chapitres 2, 3 et 5 en un seul script.
