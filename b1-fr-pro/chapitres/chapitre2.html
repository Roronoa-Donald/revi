Chapitre 2 — Les registres de langue

Module 2 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

« Je caille », dit l'un ; « j'ai très froid », dit l'autre ; « j'étais mort de froid », conclut le troisième. Même idée, trois niveaux. Le support fixe la règle : l'usage détermine les connotations sociales — soutenu (recherché), courant (standard), familier (relâché) — et le professionnel sait passer de l'un à l'autre sans y penser.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. caractériser les trois niveaux : familier, courant, soutenu ;
  2. ranger un mot dans son registre à partir de trios connus (bouffer, manger, se sustenter) ;
  3. repérer les marques du familier : syntaxe relâchée, « ne » supprimé, argot ;
  4. remplacer les verbes passe-partout (donner, faire, avoir) par des verbes précis.

1. Trois niveaux, trois usages

Le niveau familier est celui de l'oral quotidien : lexique argotique, syntaxe relâchée — ruptures, répétitions, suppression du « ne » (« il s'marrait »). Le niveau courant est l'usage standard, celui de la presse et du journal télévisé : lexique usuel, syntaxe respectée sans recherche, subjonctif admis, passé simple exclu. Le niveau soutenu — parfois noté « littér. » dans les dictionnaires, mais pas propre à la littérature — vise le lexique précis, les figures de style, les inversions : « il riait aux éclats ».

\n

Le support déroule les trios : cailler / avoir très froid / être mort de froid ; bouffer / manger / se sustenter ; zyeuter / regarder / considérer ; rosser / battre / (soutenu : maltraiter) ; roupiller / dormir / s'assoupir ; la gadoue / la boue / la vase ; une bagnole / une voiture / une automobile ; le boulot / le travail / le labeur ; un mec / un homme / un monsieur ; il a cassé sa pipe / il est mort / il a trépassé.

\n
Mnémotechnique — « le trio monte d'un cran à chaque ligne »

Familier = imagé et sonore (casser la croûte) ; courant = neutre et partagé (manger) ; soutenu = précis et rare (se restaurer). Si un mot fait rire, il est familier ; s'il fait hésiter, il est soutenu.

2. Traquer les mots passe-partout

« Pour aller plus loin », le support déclare la guerre aux expressions passe-partout : donner, faire, avoir — des verbes valables partout, donc précis nulle part. Remplacer « donner » : attacher de l'importance, prodiguer des conseils, accorder sa confiance ou un délai, procurer un stage, indiquer l'heure, distribuer des cartes, causer du souci.

\n

Remplacer « faire » : procéder à une enquête, commettre une erreur, confectionner un bijou, intenter un procès, effectuer un travail, exécuter un croquis, établir une liste, feindre de se fâcher, exercer un métier.

\n

Remplacer « avoir » : détenir les clés, souffrir d'un handicap, obtenir un résultat, éprouver un sentiment, rencontrer des difficultés, faire preuve de courage, ressentir de la sympathie, subir une opération, compter mille habitants.

\n
Confusions d'examen
    \n
  • Le familier n'est pas interdit : il est « à sa place » — entre amis, jamais en clientèle.
    • \n
  • Le soutenu n'est pas littéraire : un rapport peut dire « se sustenter » comme « demeurer ».
    • \n
  • Le « ne » supprimé (« je sais pas ») marque le familier autant que le lexique.
    • \n
  • Faire preuve de courage, pas « avoir du courage » : le passe-partout s'entend immédiatement.
    • \n

3. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Familier, courant, soutenu

Bash Niveau 1 — Acquisition

Objectif : Ranger chaque mot dans son niveau de langue : cailler, avoir très froid, être mort de froid.

Le script lit n lignes « mot registre » : registre vaut fam (familier), cour (courant) ou sout (soutenu). Pour chaque ligne il affiche mot : niveau, où niveau vaut familier, courant ou soutenu. Il termine par trois lignes de comptage dans cet ordre : familier : X, courant : Y, soutenu : Z.

Entrée du programme
3
bouffer fam
manger cour
sustenter sout
Sortie attendue
bouffer : familier
manger : courant
sustenter : soutenu
familier : 1
courant : 1
soutenu : 1
Deux indices, rédigés en mots
  1. Un case à trois registres : fam, cour, sout.
  2. Les trois totaux sortent après la boucle, dans l'ordre familier, courant, soutenu.

Exercice 2 — Le trio des trois registres

Bash Niveau 2 — Application

Objectif : Vérifier qu'une notion est couverte par les trois niveaux : bouffer, manger, se sustenter.

Le script lit n lignes « mot notion registre » : notion vaut manger, regarder ou dormir ; registre vaut fam, cour ou sout. Pour chaque ligne il affiche mot : niveau (familier, courant ou soutenu). Il termine par une ligne par notion, dans l'ordre manger, regarder, dormir : notion : complete (les trois registres vus), notion : partielle (au moins un) ou notion : absente. Puis trios : X/3.

Entrée du programme
6
bouffer manger fam
manger manger cour
sustenter manger sout
zyeuter regarder fam
regarder regarder cour
considere regarder sout
Sortie attendue
bouffer : familier
manger : courant
sustenter : soutenu
zyeuter : familier
regarder : courant
considere : soutenu
manger : complete
regarder : complete
dormir : absente
trios : 2/3
Deux indices, rédigés en mots
  1. Trois tableaux associatifs : vf[notion]=1 pour fam, vc pour cour, vs pour sout.
  2. Une notion est complete seulement si les trois tableaux la connaissent ; partielle si un seul au moins.

Exercice 3 — Verbes passe-partout

Bash Niveau 3 — Raisonnement

Objectif : Traquer donner, faire et avoir au profit de verbes précis : prodiguer, commettre, détenir.

Le script lit n lignes « mot verbe » : verbe vaut donner, faire ou avoir (passe-partout à remplacer) ou precis (verbe précis déjà employé). Pour chaque ligne il affiche mot : verbe passe-partout (donner) (ou faire, ou avoir) ou mot : precise. Il termine par passe-partout : X/n, puis texte : a enrichir si les passe-partout sont strictement majoritaires, texte : acceptable sinon.

Entrée du programme
4
prodiguer precis
conseils donner
enquete faire
detient precis
Sortie attendue
prodiguer : precise
conseils : verbe passe-partout (donner)
enquete : verbe passe-partout (faire)
detient : precise
passe-partout : 2/4
texte : acceptable
Deux indices, rédigés en mots
  1. Un case à quatre valeurs : donner, faire, avoir, tout le reste tombant dans precis.
  2. Strictement majoritaires : le double du compteur doit dépasser n.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Écrire « bouffer » dans un rapport : le lexique familier discrédite le propos.
  • Confondre soutenu et pédant : le soutenu précise, il ne complique pas.
  • Oublier la syntaxe du familier : le « ne » supprimé fait autant signe que « gonzesse ».
  • Laisser « faire » et « avoir » faire tout le travail : commettre, effectuer, éprouver, détenir.

6. Méthodologie de résolution

Méthode — choisir le mot juste en trois gestes
  1. Identifier la situation : amis (familier), service (courant), rapport ou courrier (soutenu possible).
  2. Consulter le trio : chaque notion connue a ses trois étages — bouffer, manger, se sustenter.
  3. Chasser les passe-partout : remplacer donner, faire, avoir par le verbe qui dit l'action.

7. Révision active

Résumé essentiel
  • Trois niveaux : familier (oral relâché), courant (standard de la presse), soutenu (précis, recherché).
  • Les trios du support : cailler / avoir très froid / être mort de froid ; bouffer / manger / se sustenter.
  • Marques du familier : argot, ruptures, suppression du « ne ».
  • Passe-partout à remplacer : prodiguer, commettre, détenir, éprouver, compter…

Checklist de maîtrise

  • Je sais définir les trois niveaux de langue en une phrase chacun.
  • Je sais ranger dix mots dans leur registre sans dictionnaire.
  • Je sais compléter un trio (familier, courant, soutenu) pour une notion donnée.
  • Je sais remplacer « donner / faire / avoir » par cinq verbes précis.

Les 8 notions à connaître absolument

  1. Familier : oral quotidien, argot, syntaxe relâchée (cailler, boulot, zyeuter).
  2. Courant : usage standard, presse et télévision (manger, regarder, travail).
  3. Soutenu : lexique précis, figures, inversions (se sustenter, considérer, labeur).
  4. Trio : trois mots d'une même notion, un par registre.
  5. Ne supprimé : « je sais pas » — marque grammaticale du familier.
  6. Prodiguer : remplacer « donner » (des conseils).
  7. Commettre : remplacer « faire » (une erreur).
  8. Compter : remplacer « avoir » (des habitants).

8. Test de maîtrise

Comment t'auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lis ton pourcentage :

< 50 % — relis les tableaux comparatifs du support et refais les trios.
