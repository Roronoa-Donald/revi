Chapitre 4 — Pléonasmes, barbarismes, solécismes

Module 4 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

« Au jour d'aujourd'hui », « un problème pécunier », « si je pourrais » : trois fautes, trois familles. Le support les isole une à une — l'excès de mots, le mot déformé, la construction qui dérape — parce qu'on ne corrige bien que ce qu'on sait nommer.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. définir et repérer le pléonasme (périssologie) ;
  2. définir et corriger le barbarisme (mot forgé, impropres ou déformés) ;
  3. définir et corriger le solécisme (constructions fautives : se rappeler de, pallier à) ;
  4. appliquer la règle du « si » d'hypothèse : jamais de conditionnel derrière un si.

1. Le pléonasme : un mot de trop

Le mot vient du grec pleonasmós, « excès, surcharge » : le pléonasme est une répétition inutile, un double emploi. En didactique, on parle de périssologie. Exemple du support : « vos projets d'avenir » — projets exprime déjà l'avenir ; on dit « vos projets ».

Les classiques : allumer la lumière (une lampe), l'apparence extérieure (aux apparences), commémorer un souvenir (un évènement), comparer ensemble, la première priorité (la priorité), un hasard imprévu, divulguer publiquement, la panacée universelle, répéter la même chose deux fois, à l'unanimité de tous les présents (à l'unanimité).

Et la longue liste : au jour d'aujourd'hui (aujourd'hui), cela s'avère vrai (cela s'avère), voire même (voire / et même), un tri sélectif (un tri), incessamment sous peu (incessamment), moi personnellement (moi, ou personnellement), nous relayer tour à tour, découvrir pour la première fois, mais par contre, et puis (et / puis), un mauvais cauchemar, comme par exemple.

Mnémotechnique — « un mot de trop, toujours identifiable »

Cherchez l'information déjà portée par un mot : « d'avenir » dans projets, « lumière » dans allumer, « extérieure » dans apparence. Le pléonasme se coupe, il ne se reformule pas.

2. Le barbarisme : le mot déformé

Le barbarisme est une faute de langue : mots forgés (qui n'existent pas), mots impropres (mal employés) ou tournures étrangères. En Grèce antique, le barbare « déformait la langue de la cité ».

Le corrigé type : pécuniers → pécuniaires (de pecunia, argent), maline → maligne, bénine → bénigne, nous disons, vous disez → vous dites, empruntes → empreintes, dilemne → dilemme.

Les « mots à risque » : en liste → en lice, contreverses → controverses, en définitif → en définitive, marche de manœuvre → marge de manœuvre, rabattent les oreilles → rebattent les oreilles, recouvert la liberté → recouvré (recouvrer la vue, la santé, la liberté), rénuméré → rémunéré, je vous saurai gré → je vous serai gré (savoir gré), indemmes → indemnes, en dilettant → en dilettante.

3. Le solécisme : la construction qui dérape

Le solécisme est une faute de syntaxe : il pèche contre les constructions, les règles d'accord, l'emploi des modes. Étymologie : les colons de Soloi, en Cilicie, parlaient un grec incorrect.

Les dix du support : je me rappelle de → je me rappelle (on se souvient de, on se rappelle) ; pallier à → pallier (transitif direct, comme enfreindre) ; téléphoner les clients → téléphoner aux clients (COI) ; enfreindre aux règles → enfreindre les règles ; après que + subjonctif → après que + indicatif (le fait s'est produit) ; d'ici demain → d'ici à demain ; nous avons débuté la réunion → commencé (on ne débute pas quelque chose) ; malgré qu'il soit → bien qu'il soit ; le véhicule au directeur → le véhicule du directeur ; ils se sont divorcés → ils ont divorcé (verbe non pronominal).

La règle du « si » d'hypothèse retient tout : après « si », jamais de conditionnel — « si je pouvais, j'enverrais ». L'astuce du support : « les si n'aiment pas les rais » (poissons-scies et raies).

Confusions d'examen
  • Pléonasme ≠ barbarisme : l'un est un excès de mots, l'autre un mot faux.
  • Se rappeler prend un complément direct — exception : se rappeler de toi, d'elle, d'avoir fait.
  • Après que + indicatif (le fait s'est produit) ; avant que + subjonctif (il ne s'est pas encore produit).
  • Un si d'hypothèse interdit le conditionnel : « si je pouvais », jamais « si je pourrais ».

4. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Repérer les pléonasmes

Bash Niveau 1 — Acquisition

Objectif : Signaler le double emploi : allumer la lumière, au jour d'aujourd'hui, assez suffisantes.

Le script lit n lignes « expression type » : type vaut pleonasme (double emploi) ou bon (tour correct). Pour chaque ligne il affiche expression : pleonasme (un mot de trop) ou expression : correcte. Il termine par pleonasmes : X/n.

Entrée du programme
3
lumiere pleonasme
cauchemar bon
unanimite pleonasme
Sortie attendue
lumiere : pleonasme (un mot de trop)
cauchemar : correcte
unanimite : pleonasme (un mot de trop)
pleonasmes : 2/3
Deux indices, rédigés en mots
  1. Seule la valeur pleonasme déclenche le signalement.
  2. Le compteur suit exactement les lignes signalées.

Exercice 2 — Corriger les barbarismes

Bash Niveau 2 — Application

Objectif : Rendre à chaque mot sa vraie forme : pécuniaire, maligne, dilemme, empreintes.

Le script lit n mots, un par ligne, sans autre champ. Chaque mot est soit un barbarisme connu, soit une forme correcte. Les barbarismes connus du cours : pecuniers, maline, benine, disez, empruntes, dilemne, contreverse, renumere, rabattent, indemmes, dilettant, definitif. Pour chaque mot le script affiche mot : forme_corrigee (par exemple maline : maligne) ou mot : correct si le mot est bien formé. Il termine par barbarismes : X/n.

Entrée du programme
4
pecuniers
maline
dilemme
contreverse
Sortie attendue
pecuniers : pecuniaires
maline : maligne
dilemme : correct
contreverse : controverse
barbarismes : 3/4
Deux indices, rédigés en mots
  1. Un case sur le mot lui-même : chaque barbarisme connu donne sa forme corrigée.
  2. Le cas par défaut (*) approuve ; il n'incrémente pas le compteur.

Exercice 3 — La construction des verbes

Bash Niveau 3 — Raisonnement

Objectif : Éviter le solécisme : on pallie quelque chose, on se rappelle quelque chose, on téléphone à quelqu'un.

Le script lit n lignes « verbe construction » : verbe vaut rappeler, pallier ou enfreindre (ces trois verbes exigent un complément direct) ou telephoner (qui exige un complément en à) ; construction vaut direct ou a. Pour chaque ligne il affiche verbe : construction correcte ou verbe : construction fautive. Il termine par solecismes : X/n.

Entrée du programme
4
rappeler direct
pallier a
telephoner a
enfreindre a
Sortie attendue
rappeler : construction correcte
pallier : construction fautive
telephoner : construction correcte
enfreindre : construction fautive
solecismes : 2/4
Deux indices, rédigés en mots
  1. Le case sur le verbe pose la construction attendue (direct ou a) ; un simple test compare ensuite.
  2. Le compteur suit exactement les constructions fautives.

5. QCM — niveau examen

Un pléonasme est…

Double emploi : « projets d'avenir », « allumer la lumière ».

La périssologie désigne…

Le nom didactique du pléonasme.

La correction de « pécuniers » est…

De pecunia, argent : pécuniaire, au féminin comme au masculin.

« Un dilemne » s'écrit…

Dilemme, deux m.

« Pallier à cet incident » : la correction est…

Pallier est transitif direct : on pallie quelque chose.

« Je me rappelle de mon enfance » : la correction est…

On se rappelle quelque chose ; on se souvient de quelque chose.

Après « après que », on emploie…

Le fait s'est produit : indicatif. Avant que : subjonctif.

« Si je pourrais obtenir… » : la correction est…

Jamais de conditionnel après un si d'hypothèse.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Corriger « allumer la lumière » en « allumer la lampe » seulement à l'écrit : le pléonasme se dit aussi.
  • Inventer « dilemne », « contreverse », « rénuméré » : barbarismes classiques des copies.
  • Écrire « malgré que » : bien que + subjonctif, ou malgré + nom.
  • Mettre un conditionnel après « si » : les si n'aiment pas les rais.

7. Méthodologie de résolution

Méthode — nommer la faute en trois gestes
  1. Compter les mots : une information double = pléonasme, on coupe.
  2. Contrôler la forme : mot inexistant ou déformé = barbarisme, on restitue la vraie forme.
  3. Vérifier la construction : préposition en trop ou manquante = solécisme, on réaccorde le verbe.

8. Révision active

Résumé essentiel
  • Pléonasme : répétition inutile (périssologie) — projets d'avenir, au jour d'aujourd'hui.
  • Barbarisme : mot forgé, impropre ou déformé — pécuniaire, maligne, dilemme, empreintes.
  • Solécisme : faute de syntaxe — pallier, se rappeler, enfreindre (direct) ; téléphoner à.
  • Si d'hypothèse : indicatif, jamais de conditionnel.

Checklist de maîtrise

  • Je sais définir les trois familles en une phrase chacune.
  • Je sais corriger dix pléonasmes courants.
  • Je sais restituer dix barbarismes (pécuniaire, dilemme, empreintes…).
  • Je sais réaccorder les verbes piégés : rappeler, pallier, enfreindre, téléphoner.

Les 8 notions à connaître absolument

  1. Pléonasme : double emploi — allumer une lampe, la priorité, l'unanimité.
  2. Périssologie : nom didactique de la répétition inutile.
  3. Barbarisme : mots forgés, impropres, tournures étrangères.
  4. Pécuniaire : qui concerne l'argent — jamais « pécunier ».
  5. Dilemme : deux m — jamais « dilemne ».
  6. Empreintes : digitales — jamais « empruntes ».
  7. Solécisme : faute de construction ou d'accord.
  8. Si d'hypothèse : pas de conditionnel derrière « si ».

9. Test de maîtrise

Comment t'auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lis ton pourcentage :

< 50 % — refais les trois listes du support, une famille à la fois.
50–69 % — refais les dix pléonasmes et les dix solécismes.
70–89 % — bon niveau, traque les barbarismes dans tes mails.
≥ 95 % — niveau de maîtrise recherché.
