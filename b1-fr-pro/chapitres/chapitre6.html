Chapitre 6 — Grammaire professionnelle

Module 6 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

« J'ai étudié », « je suis parti », « nous sommes allés » : le passé composé raconte le parcours dans une lettre de motivation. Encore faut-il choisir le bon auxiliaire et accorder le participe — le dernier chapitre outille la phrase parfaite.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. former le passé composé : avoir ou être au présent + participe passé ;
  2. connaître la liste des verbes conjugués avec être ;
  3. accorder le participe passé avec être comme un adjectif ;
  4. gérer l'accord avec « vous » : quatre cas, du groupe mixte à la politesse singulière.

1. Avoir ou être

Le passé composé = avoir ou être au présent + participe passé. Le choix dépend du verbe et de son emploi, pas simplement d'une idée de mouvement : « Elle est partie en vacances », mais « Elle a marché deux heures ». On dit aussi « J'ai acheté un livre » et « Il a parlé de son film ».

Dans ces emplois, partir, venir, arriver et tomber se conjuguent avec être. Les verbes pronominaux utilisent également être : « Elle s'est couchée » ; le verbe non pronominal peut se construire autrement : « Elle a couché l'enfant ».

Certains verbes changent d'auxiliaire selon leur construction : « Elle est sortie du bureau » mais « Elle a sorti le dossier » ; « Je suis monté au premier étage » mais « J'ai monté les bagages ».

Mnémotechnique — « la maison d'être »

La maison aide à retenir des emplois avec être, par exemple « elle est partie » et « elle est sortie ». Elle ne comprend pas tous les verbes de mouvement : « elle a marché ». Vérifie le verbe et la phrase complète.

Pour approfondir : Académie française — choix de l'auxiliaire (consulté le 30 octobre 2026).

2. Participes et accords

Les participes courants du support, par famille : -é (allé, entré, travaillé) ; -u (eu, connu, entendu, reçu, venu, vécu, voulu) ; -it (dit, écrit, fait) ; -i (dormi, fini, parti, sorti) ; -is (acquis, appris, compris, mis, pris, soumis) ; -ert (découvert, ouvert, offert).

Avec être et un verbe non pronominal, le participe s'accorde comme un adjectif, en genre et en nombre : il est allé, elle est allée, ils sont allés, elles sont allées. « Julie dit : je suis allée » — le « je » représente Julie. « Djamel et Malika : nous sommes allés » — groupe mixte, masculin pluriel.

Pour un verbe pronominal, l'accord demande une analyse supplémentaire : « Elle s'est lavée », mais « Elle s'est lavé les mains ».

Vous : quatre cas — groupe d'hommes ou mixte : « Vous êtes sortis » ; groupe féminin : « Vous êtes sorties » ; politesse envers un homme : « Vous êtes sorti » ; politesse envers une femme : « Vous êtes sortie ». Identifier l'antécédent avant d'accorder.

Confusions d'examen
  • « Elle a parti » : fautif — partir prend être : « Elle est partie ».
  • « Ils se sont divorcés » : fautif — divorcer n'est pas pronominal : « Ils ont divorcé ».
  • « Vous êtes sorties » adressé à un homme : fautif — identifier l'antécédent réel.
  • « J'ai monté au premier étage » sans COD : fautif — « Je suis monté » (intransitif).

3. Études de cas & applications pratiques

Ces trois études de cas se réalisent directement dans la page. Complétez chaque grille d’analyse à partir des données du cas, puis lancez la validation pour vérifier vos réponses critère par critère.

La validation compare vos réponses aux attendus des cas affichés ; elle ne vérifie pas votre capacité à traiter toutes les situations.

En cas d’hésitation, le bouton Obtenir une aide formative générale fournit un conseil identique pour toutes les grilles, sans transmettre de réponse attendue ni utiliser le tuteur IA.

Exercice 1 — Avoir ou être

Étude de cas Formative Niveau 1 — Acquisition

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Choisir l'auxiliaire du passé composé en tenant compte du verbe et de la phrase.

Chaque code désigne une phrase précise dont l'auxiliaire est à vérifier : partir (« elle … partie »), marcher (« elle … marché »), venir (« elle … venue »), acheter (« elle … acheté un livre »), sortir_bureau (« elle … sortie du bureau »), sortir_dossier (« elle … sorti le dossier »), monter_etage (« elle … montée à l'étage »), monter_bagages (« elle … monté les bagages »), se_coucher (« elle s'… couchée ») et coucher_enfant (« elle … couché l'enfant »). L'auxiliaire proposé est avoir ou etre.

Pour chaque ligne, indiquez code : auxiliaire correct ou code : auxiliaire fautif, puis erreurs : X/n. Le mouvement ne suffit pas à déterminer l'auxiliaire.

Cas d’exemple
4
partir etre
marcher avoir
sortir_bureau avoir
sortir_dossier avoir
Deux indices, rédigés en mots
  1. Lisez la phrase correspondant à chaque code : « elle est sortie du bureau », mais « elle a sorti le dossier ».
  2. Le compteur suit exactement les auxiliaires fautifs.

Exercice 2 — Accorder le participe passé

Étude de cas Formative Niveau 2 — Application

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Faire accorder le participe passé avec être comme un adjectif : allé, allée, allés, allées.

Pour chaque situation proposée : famille vaut aller (participe masculin alle) ou sortir (participe masculin sorti) ; forme est le participe proposé (sans accents codés) ; sujet vaut il, elle, ils ou elles. Le participe attendu est la forme masculine suivie de rien (il), e (elle), s (ils) ou es (elles). Pour chaque situation, indiquez forme : conforme ou forme : accord fautif (attendu X). Concluez par accords : X/n.

Cas d’exemple
4
aller allee elle
aller alle il
sortir sorties elles
sortir sortie ils
Deux indices, rédigés en mots
  1. Deux case : le premier donne la forme masculine (alle ou sorti), le second le marqueur du sujet (vide, e, s, es).
  2. La forme attendue se concatène : attendu="$radical$terminaison".

Exercice 3 — L'évaluation finale du cours

Étude de cas Formative Niveau 3 — Raisonnement

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Noter les cinq compétences du français professionnel et rendre le verdict : admis ou reprise.

L’analyse porte sur d'abord seuil (score minimal, entier). Puis il lit n lignes « competence score » (score entier) parmi communication, registres, orthographe, lettre, grammaire. Pour chaque situation, indiquez competence : score X. Concluez par moyenne : M (moyenne entière arrondie vers le bas) et verdict : admis si M ≥ seuil, verdict : reprise sinon. Si n = 0, afficher moyenne : 0.

4. QCM — niveau examen

Le passé composé se forme avec…

Auxiliaire au présent, puis participe passé.

« Elle est partie » et « elle a marché » : que conclure ?

Le mouvement seul ne détermine pas l'auxiliaire : on examine le verbe et son emploi.

« J'ai monté les bagages » : monter prend…

COD présent : avoir. Sans COD : « je suis monté ».

Le participe de « écrire » est…

Famille -it : dit, écrit, fait.

Le participe de « prendre » est…

Famille -is : acquis, appris, compris, mis, pris, soumis.

Dans « elles sont allées », le participe s'accorde…

Avec être et le verbe non pronominal aller, le participe s'accorde avec le sujet : allées.

« Vous » de politesse adressé à une femme : « Vous êtes… »

Politesse + femme : féminin singulier.

Djamel et Malika disent : « Nous sommes… »

Groupe mixte : masculin pluriel.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Conjuguer « entrer » avec avoir sans COD : « je suis entré », pas « j'ai entré ».
  • Oublier l'accord après être : « elles sont allé » est fautif.
  • Accorder « vous » au hasard : quatre cas à trier (groupe mixte, femmes, homme, femme).
  • Confondre monter avec COD (avoir) et monter intransitif (être).

6. Méthodologie de résolution

Méthode — accorder le passé composé en trois gestes
  1. Choisir l'auxiliaire selon le verbe et la construction : « elle est sortie », mais « elle a sorti le dossier ».
  2. Identifier l'antécédent du sujet, surtout pour je, tu, nous, vous.
  3. Accorder avec être selon le sujet pour un verbe non pronominal ; examiner les pronominaux séparément.

7. Révision active

Résumé essentiel
  • Passé composé : avoir ou être au présent + participe passé.
  • Le mouvement ne suffit pas : « elle est partie », mais « elle a marché ». Les pronominaux emploient être.
  • Participes par familles : -é, -u, -it, -i, -is, -ert.
  • Avec être et un verbe non pronominal, accord avec le sujet ; les pronominaux demandent une analyse supplémentaire.

Checklist de maîtrise

  • Je sais réciter la liste des verbes conjugués avec être.
  • Je sais classer vingt participes passés par famille de terminaison.
  • Je sais accorder le participe après être avec les quatre sujets types.
  • Je sais choisir la forme de « vous êtes sorti(e)(s) » sur les quatre cas.

Les 8 notions à connaître absolument

  1. Passé composé : auxiliaire au présent + participe passé.
  2. Maison d'être : aller, venir, partir, arriver, entrer, sortir, monter, descendre…
  3. Selon la construction : « elle est sortie », mais « elle a sorti le dossier ».
  4. Pronominaux : toujours être (se coucher, se lever, se souvenir).
  5. Familles de participes : -é, -u, -it, -i, -is, -ert.
  6. Accord avec être : avec le sujet pour un verbe non pronominal ; les pronominaux demandent une analyse supplémentaire.
  7. Vous masculin pluriel : groupe d'hommes ou mixte — « vous êtes sortis ».
  8. Vous de politesse : accord selon la personne visée — sorti / sortie.

8. Test de maîtrise

Comment vous auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lisez votre pourcentage :

< 50 % — relisez la maison d'être et les familles de participes.
50–69 % — refaites le tableau d'accords du support (allé, allée, allés, allées).
70–94 % — bon niveau, accorde les « vous » sans hésiter.
≥ 95 % — niveau de maîtrise recherché.
