Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque séance, puis un projet final qui outille le service entier. Les scripts sont en Bash, comme à l'atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n lignes « element canal » (mot/voix/corps) et affiche verbal, para-verbal ou non-verbal, puis le compteur para-verbal.
  2. Lit n lignes « mot registre » (fam/cour/sout) et affiche le niveau, puis les trois compteurs.
  3. Lit n lignes « mot casse » (ok/maj/sing) et statue sur la date, puis le compteur de fautes.
  4. Lit n lignes « expression type » (pleonasme/bon) et signale les double emplois.
Corrections
read -r n
pv=0
for ((k=0; k<n; k++)); do
  read -r element canal
  case "$canal" in
    mot) echo "$element : verbal" ;;
    voix) echo "$element : para-verbal" ; pv=$((pv + 1)) ;;
    corps) echo "$element : non-verbal" ;;
  esac
done
echo "para-verbal : $pv/$n"

read -r n
fam=0 ; cour=0 ; sout=0
for ((k=0; k<n; k++)); do
  read -r mot registre
  case "$registre" in
    fam) echo "$mot : familier" ; fam=$((fam + 1)) ;;
    cour) echo "$mot : courant" ; cour=$((cour + 1)) ;;
    sout) echo "$mot : soutenu" ; sout=$((sout + 1)) ;;
  esac
done
echo "fam : $fam / cour : $cour / sout : $sout"

read -r n
fautes=0
for ((k=0; k<n; k++)); do
  read -r mot casse
  case "$casse" in
    ok) echo "$mot : correct" ;;
    maj) echo "$mot : majuscule a enlever" ; fautes=$((fautes + 1)) ;;
    sing) echo "$mot : mettre au pluriel" ; fautes=$((fautes + 1)) ;;
  esac
done
echo "fautes : $fautes/$n"

read -r n
pl=0
for ((k=0; k<n; k++)); do
  read -r expression type
  if [ "$type" = "pleonasme" ]; then
    echo "$expression : pleonasme" ; pl=$((pl + 1))
  else
    echo "$expression : correcte"
  fi
done
echo "pleonasmes : $pl/$n"

Application

Application
  1. Lit n lignes « phrase regle » (ok/invariable/accord/veillez/facons) et nomme la correction de chaque piège du courrier.
  2. Lit n mots, un par ligne, et corrige les barbarismes connus (pecuniers, dilemne, empruntes…) à coups de case.
  3. Lit n lignes « verbe construction » (rappeler/pallier/telephoner/enfreindre + direct/a) et juge la construction.
  4. Lit n lignes « formule type » (appel/politesse) et valide madame, madamemonsieur, cordialement, salutations…
Corrections
read -r n
corrections=0
for ((k=0; k<n; k++)); do
  read -r phrase regle
  case "$regle" in
    ok|invariable) echo "$phrase : correcte" ;;
    accord) echo "$phrase : a corriger : accord" ; corrections=$((corrections + 1)) ;;
    veillez) echo "$phrase : a corriger : veuillez" ; corrections=$((corrections + 1)) ;;
    facons) echo "$phrase : a corriger : singulier" ; corrections=$((corrections + 1)) ;;
  esac
done
echo "corrections : $corrections/$n"

read -r n
ba=0
for ((k=0; k<n; k++)); do
  read -r mot
  case "$mot" in
    pecuniers) echo "$mot : pecuniaires" ; ba=$((ba + 1)) ;;
    dilemne) echo "$mot : dilemme" ; ba=$((ba + 1)) ;;
    empruntes) echo "$mot : empreintes" ; ba=$((ba + 1)) ;;
    *) echo "$mot : correct" ;;
  esac
done
echo "barbarismes : $ba/$n"

read -r n
s=0
for ((k=0; k<n; k++)); do
  read -r verbe construction
  case "$verbe" in
    rappeler|pallier|enfreindre) attendu="direct" ;;
    telephoner) attendu="a" ;;
  esac
  if [ "$construction" = "$attendu" ]; then
    echo "$verbe : correct"
  else
    echo "$verbe : fautif" ; s=$((s + 1))
  fi
done
echo "solecismes : $s/$n"

read -r n
valides=0
for ((k=0; k<n; k++)); do
  read -r formule type
  case "$formule" in
    madame|monsieur|madamemonsieur) famille="appel" ;;
    cordialement|salutations|bienavous) famille="politesse" ;;
    *) famille="inconnue" ;;
  esac
  if [ "$famille" = "$type" ]; then
    echo "$formule : valide" ; valides=$((valides + 1))
  else
    echo "$formule : inadaptee"
  fi
done
echo "valides : $valides/$n"

Raisonnement

Raisonnement
  1. Lit n lignes « argument famille » (raison/emotion/confiance) et vérifie l'équilibre logos-pathos-éthos d'un discours.
  2. Lit n lignes « element ordre » (neuf blocs de la lettre) et valide la place de chaque bloc, verdict final compris.
  3. Lit n lignes « paragraphe contenu » et contrôle le corps de la lettre : entreprise (p1), compétences (p2), motivations (p3).
  4. Lit « seuil n » puis n lignes « competence score » et rend le verdict de l'évaluation finale (moyenne entière).
Corrections
read -r n
declare -A vues
for ((k=0; k<n; k++)); do
  read -r argument famille
  case "$famille" in
    raison) echo "$argument : logos" ; vues[logos]=1 ;;
    emotion) echo "$argument : pathos" ; vues[pathos]=1 ;;
    confiance) echo "$argument : ethos" ; vues[ethos]=1 ;;
  esac
done
if [ -n "${vues[logos]:-}" ] && [ -n "${vues[pathos]:-}" ] && [ -n "${vues[ethos]:-}" ]; then
  echo "discours : equilibre"
else
  echo "discours : incomplet"
fi

read -r n
valide=1
for ((k=0; k<n; k++)); do
  read -r element ordre
  case "$element" in
    coordonnees) attendu=1 ;;
    destinataire) attendu=2 ;;
    date) attendu=3 ;;
    objet) attendu=4 ;;
    appel) attendu=5 ;;
    corps) attendu=6 ;;
    rendezvous) attendu=7 ;;
    politesse) attendu=8 ;;
    signature) attendu=9 ;;
  esac
  if [ "$ordre" = "$attendu" ]; then
    echo "$element : bloc $attendu"
  else
    echo "$element : hors place" ; valide=0
  fi
done
if [ "$valide" = "1" ]; then echo "lettre valide" ; else echo "lettre a revoir"; fi

read -r n
declare -A conformes
rompu=0
for ((k=0; k<n; k++)); do
  read -r paragraphe contenu
  case "$paragraphe" in
    p1) attendu="entreprise" ;;
    p2) attendu="competences" ;;
    p3) attendu="personnel" ;;
  esac
  if [ "$contenu" = "$attendu" ]; then
    echo "$paragraphe : conforme" ; conformes[$paragraphe]=1
  else
    echo "$paragraphe : hors sujet" ; rompu=1
  fi
done
compte=0
for p in p1 p2 p3; do
  [ -n "${conformes[$p]:-}" ] && compte=$((compte + 1))
done
echo "paragraphes : $compte/3"

read -r seuil
read -r n
somme=0
for ((k=0; k<n; k++)); do
  read -r competence score
  echo "$competence : score $score"
  somme=$((somme + score))
done
if [ "$n" -gt 0 ]; then moyenne=$((somme / n)) ; else moyenne=0 ; fi
if [ "$moyenne" -ge "$seuil" ]; then echo "verdict : admis" ; else echo "verdict : reprise"; fi

Projet intégrateur — « l'audit de courriers du service »

Cahier des charges

Le script reçoit le journal de relecture du service : d'abord n_courriers courriers au format auteur fautes où fautes est une suite de lettres sans espace — a = article superflu, m = majuscule de jour ou de mois, x = abréviation anglaise « Mr », et le tiret - = courrier propre (par exemple am- = courrier fautif). Puis n_mots mots au format mot type (pleonasme/barbarisme/bon). Il produit le rapport d'audit : pour chaque auteur, nombre de courriers propres et fautifs ; puis les corrections lexicales (chaque pléonasme → couper : mot, chaque barbarisme → corriger : mot) ; enfin le verdict global : service prete si tous les courriers sont propres et zéro pléonasme ni barbarisme, relecture requise sinon.

Fonctionnalités attendues
  1. Lire les deux blocs sans mélanger courriers et mots.
  2. Analyser chaque suite de fautes lettre à lettre : propre seulement si tout est un tiret.
  3. Agréger par auteur avec des tableaux associatifs.
  4. Corriger le lexique : pléonasmes coupés, barbarismes nommés.
  5. Verdict final au format exact du cahier des charges.

Contraintes : parsing lettre à lettre des suites de fautes, declare -A par auteur, bilan après lecture complète.

Grille d'auto-évaluation du projet (sur 100)
Lecture des deux blocs et parsing des fautes 20
Agrégation par auteur correcte 20
Corrections lexicales (couper, corriger) 20
Verdict global conforme 20
Rapport lisible et formats exacts 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
read -r n_courriers
declare -A propres
declare -A fautifs
tout_propres=1
for ((k=0; k<n_courriers; k++)); do
  read -r auteur fautes
  propre=1
  for ((j=0; j<${#fautes}; j++)); do
    c=${fautes:$j:1}
    if [ "$c" != "-" ]; then
      propre=0
    fi
  done
  if [ "$propre" = "1" ]; then
    propres[$auteur]=$(( ${propres[$auteur]:-0} + 1 ))
  else
    fautifs[$auteur]=$(( ${fautifs[$auteur]:-0} + 1 ))
    tout_propres=0
  fi
done
read -r n_mots
pl=0
ba=0
for ((k=0; k<n_mots; k++)); do
  read -r mot type
  if [ "$type" = "pleonasme" ]; then
    echo "couper : $mot"
    pl=$((pl + 1))
  elif [ "$type" = "barbarisme" ]; then
    echo "corriger : $mot"
    ba=$((ba + 1))
  fi
done
for auteur in "${!propres[@]}"; do
  echo "$auteur : ${propres[$auteur]} propres / ${fautifs[$auteur]:-0} fautifs"
done
if [ "$tout_propres" = "1" ] && [ "$pl" = "0" ] && [ "$ba" = "0" ]; then
  echo "verdict : service prete"
else
  echo "verdict : relecture requise"
fi
Cette solution combine parsing lettre à lettre, agrégation par auteur, corrections lexicales et verdict global — les chapitres 3, 4 et 5 en un seul script.
