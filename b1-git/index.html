Git B1 — versionner, brancher, collaborer

Git garde trois espaces — copie de travail, index, dépôt — et des commandes qui déplacent le travail de l'un vers l'autre. Six chapitres pour comprendre ces trajets : initialiser, committer, annuler, brancher, fusionner, pousser. Chaque mécanisme est d'abord programmé et vérifié dans l'atelier, puis rejoué tel quel dans un vrai terminal avec les vraies commandes.

Ce que tu sauras faire à la fin du cours
  • créer un dépôt, configurer ton identité et lire git status ;
  • sélectionner tes commits : add, .gitignore, reset HEAD, messages nets ;
  • annuler proprement : reset soft/mixed/hard, revert, git diff ;
  • travailler en branches et fusionner (fast-forward, --no-ff, conflits) ;
  • synchroniser avec un distant : clone, push, pull, fetch, rejets ;
  • remiser avec stash, livrer une archive et publier avec GitHub Pages.
Comment ce cours s'articule

Les supports du cours déroulent les commandes au quotidien (aide-mémoire GitHub, vade-mecum « Travailler avec Git au quotidien ») et cinq TP : premier dépôt, binôme sur GitHub, branches, publication, conflit guidé. Ce cours en garde le plan et fait manipuler chaque mécanisme en Bash : un script qui reproduit l'effet exact des commandes Git, exécuté dans la page.

Chaque chapitre se termine par trois exercices de code : tu écris vraiment le script, il est réellement exécuté, puis corrigé par des tests que tu ne vois pas. La logique écrite ici se rejoue telle quelle dans un vrai terminal.

Programme du cours

1Créer un dépôt : init, config, status
Qu'est-ce que le versionnage, git init et .git, configurer son identité, lire git status. 2Index et commits : add, reset, commit
git add et ses options, exclure avec .gitignore, retirer de l'index, écrire des messages de commit. 3Historique et annulations : log, reset, revert
Lire git log, revenir en arrière avec reset (soft, mixed, hard), annuler avec trace via revert. 4Branches : isoler, fusionner, supprimer
Créer et basculer (checkout -b), lister les branches, fusionner avec merge, fast-forward et conflits. 5Dépôt distant : clone, push, pull, fetch
origin et les liens distants, pousser ses commits, récupérer avec pull (fetch + merge), gérer un rejet. 6Stash, gitignore et publication
Remiser avec stash, filtrer avec .gitignore, archiver avec git archive, publier avec GitHub Pages.
