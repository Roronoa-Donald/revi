Module 1 — Le système GNU/Linux : histoire, licence, architecture

QuestionQui a créé UNIX, quand et où ?
RéponseKen Thompson et Dennis Ritchie, en 1969, aux laboratoires Bell (AT&T) ; réécrit en C en 1973.
QuestionLes quatre libertés du logiciel libre ?
Réponse0 : utiliser ; 1 : étudier et adapter ; 2 : redistribuer ; 3 : améliorer et diffuser.
QuestionQue garantit le copyleft de la GPL ?
RéponseToute redistribution, modifiée ou non, se fait sous les mêmes conditions ; code source et libertés sont inséparables.
QuestionQu’est-ce qu’une distribution Linux ?
RéponseUn assemblage complet (noyau, utilitaires, commandes, applications) qui forme un système installable : Debian, RedHat, Slackware…

Module 2 — Arborescence et système de fichiers

QuestionRôle de /etc, /home, /tmp, /var, /root ?
RéponseConfiguration du système ; répertoires des utilisateurs ; temporaires effacés au reboot ; journaux et spools variables ; maison du super-utilisateur.
QuestionQue veut dire « tout est fichier » ?
RéponseDonnées, périphériques, partitions, processus, répertoires : tout est représenté par un fichier dans l’arborescence.
QuestionDifférence ext2 / ext3 / ext4 ?
Réponseext2 : historique, non journalisé. ext3 : journalisé, convertible depuis ext2. ext4 : évolution optimisée et rétrocompatible d’ext3.
QuestionQue font mount, umount, df, du ?
Réponsemount greffe un FS sur un point de l’arbre ; umount le détache ; df affiche l’occupation des partitions montées ; du l’espace pris par une arborescence.

Module 3 — Commandes de base : trouver, manipuler, chercher

QuestionSyntaxe d’une commande Unix ?
RéponseCOMMANDE OPTIONS ARGUMENTS — ex. ls -a /home : lister /home en incluant les fichiers cachés.
Questiontouch, cp, mv, rm : rôles ?
Réponsetouch : créer (ou dater) un fichier ; cp : copier ; mv : renommer/déplacer ; rm : supprimer (-rf irréversible).
Question> et >> avec echo ?
Réponse> écrase le contenu du fichier ; >> ajoute (suffixe) à la fin.
QuestionComment fonctionne ln -s ?
RéponseIl crée un lien symbolique, raccourci qui n’est pas stocké physiquement : il reflète toujours le contenu courant de la source.
QuestionSyntaxe et critères de find ?
Réponsefind répertoire critères ; -name, -type, -size, -ctime/-atime/-mtime, -user, -group, -perm.

Module 4 — Installer Debian 12

QuestionQu’est-ce que netinst ?
RéponseUne image légère de Debian : système de base installé localement, paquets restants téléchargés depuis les dépôts réseau.
QuestionSchéma de partitionnement typique d’un TP Debian ?
Réponse/ (racine, ext4), swap (≈ deux fois la RAM), /home séparé pour survivre à une réinstallation.
QuestionOù déclare-t-on les dépôts ?
RéponseDans /etc/apt/sources.list : adresse du dépôt, version (bookworm), composantes (main, contrib, non-free).
Questionapt update vs apt upgrade ?
Réponseupdate rafraîchit la liste des paquets disponibles ; upgrade applique les mises à jour des paquets déjà installés.

Module 5 — Utilisateurs, groupes et fichiers de comptes

QuestionLes sept champs de /etc/passwd ?
Réponselogin : mot-de-passe : UID : GID : info-utilisateur : répertoire-principal : shell.
QuestionÉtats du champ mot-de-passe ?
Réponse* : authentification impossible ; !! : compte désactivé ; x ou ! : mot de passe dans /etc/shadow ; vide : pas de mot de passe.
QuestionOù sont les mots de passe chiffrés ?
RéponseDans /etc/shadow, lisible uniquement par l’administrateur ; /etc/passwd reste lisible pour la correspondance login/UID.
Questionusermod -d /home/toto -m tutu fait quoi ?
RéponseChange la maison de tutu en /home/toto, en recopiant l’ancien contenu et en ajustant les droits.
QuestionRôle de whoami, who, users, w ?
Réponsewhoami : identité courante ; who, users, w : la liste des utilisateurs connectés.

Module 6 — Droits d’accès et scripts shell (TP)

QuestionQue signifient les dix caractères de ls -l ?
RéponseLe type (- fichier, d répertoire) puis trois triplets rwx : propriétaire (u), groupe (g), autres (o).
QuestionConversion octal : rwx, r-x, rw-, --- ?
Réponser=4, w=2, x=1 par triplet : 7, 5, 6, 0 — rwxr-x--- vaut donc 750.
Questionchmod ug=rwx vs chmod ug+x ?
Réponse= fixe exactement la classe (le reste disparaît) ; + ajoute un droit sans toucher aux autres.
QuestionRôles de chown et chgrp ?
Réponsechown change le propriétaire (et le groupe avec utilisateur:groupe) ; chgrp change seulement le groupe ; -R rend les deux récursifs.
QuestionPremière ligne obligatoire d’un script Bash ?
Réponse#!/bin/bash : le shebang, qui désigne l’interpréteur.
