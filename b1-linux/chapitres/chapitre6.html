Chapitre 6 — Droits d’accès et scripts shell (TP)

Module 6 ≈ 3 h de travail Réservé B1 et plus
Mise en situation

Dernière ligne droite du TP : comprendre qui peut lire, écrire, exécuter — et pourquoi. Les droits d’accès se lisent sur la sortie de ls -l, se calculent en octal, se modifient avec chmod, chown et chgrp. Puis on assemble tout le semestre dans un script shell : shebang, lecture, boucle, rapport.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. lire une chaîne de droits -rwxr-x--- classe par classe (propriétaire, groupe, autres) ;
  2. convertir entre notation symbolique et octale et inversement ;
  3. modifier droits et propriétés avec chmod (symbolique et octal), chown et chgrp ;
  4. écrire un script shell : shebang, lecture d’entrée, boucle et rapport conditionnel.

1. Lire les droits : trois triplets rwx

Sur la sortie de ls -l, chaque ligne commence par dix caractères : le type, puis neuf droits en trois triplets — propriétaire (u), groupe (g), autres (o) :

- r w x r - x r - -
│  │  │  └── autres (o)      : lecture et… rien, pas d’exécution
│  │  └── groupe (g)         : r-x, lire et exécuter
│  └── propriétaire (u)      : rwx, tout
└── type : - fichier, d répertoire

Chaque position vaut une lettre ou un tiret : r (read, 4), w (write, 2), x (execute, 1). La conversion octale additionne par triplet : rwx = 4+2+1 = 7, r-x = 5, --- = 0. Ainsi rwxr-x--- se note 750.

Mnémotechnique — « u go, o stop »

Trois classes dans l’ordre u, g, o — le propriétaire, son groupe, puis le reste du monde. Lire de gauche à droite, toujours trois caractères par classe, jamais un de plus. Le tiret à la place d’une lettre = droit absent.

2. chmod : symbolique et octal

chmod modifie les droits, dans les deux notations du TP :

NotationExempleEffet
symboliquechmod o-r totoretire la lecture aux autres
symboliquechmod ug=rwx dossierfixe exactement rwx pour u et g
octalechmod 770 totorwxrwx--- : tout pour u et g, rien aux autres

La forme symbolique combine classe (u, g, o, a = toutes), action (+ ajouter, - retirer, = fixer exactement) et lettres (r, w, x). Les classes se cumulent : ug+x touche le propriétaire et le groupe, go+w le groupe et les autres. L’option -R rend l’opération récursive : chmod -R ug=rwx dossier applique les mêmes droits au dossier et à tout son contenu.

Piège — = n’ajoute pas

+ ajoute un droit, - en retire un, mais = fixe la classe exactement : tout droit non mentionné disparaît. ug=rwx et ug+wx ne donnent pas le même résultat si le groupe avait déjà r. Les exercices de l’atelier testent les deux.

3. chown et chgrp : changer de propriétaire

Chaque fichier a un propriétaire et un groupe propriétaire, visibles dans ls -l. Le TP les fait manipuler :

chown tpsysteme toto           transfère toto à l’utilisateur tpsysteme
chown -R tpsysteme dossier     récursif : dossier et tout son contenu
chown tpsysteme:root dossier   propriétaire ET groupe en une commande
chgrp tpsysteme toto           change seulement le groupe propriétaire
chgrp -R tpsysteme dossier     récursif, groupe seulement

Après chaque série, le TP fait revérifier avec ls -l et ls -Rl : la preuve se lit sur la sortie, pas dans la tête. Un fichier créé par root appartient à root — tant que chown ne dit pas le contraire, les droits restent ceux de la création.

Le fil du TP2 en résumé

Créer deux utilisateurs, créer toto, lire ses propriétaires avec ls -l, transférer avec chown, jouer chgrp et chown -R sur un dossier complet, puis chmod o-r, chmod 770, chmod -R ug=rwx. Toute la matière du chapitre en une séance de TP.

4. Écrire ses premiers scripts Bash

Un script shell est un fichier texte contenant des commandes. Sa première ligne est le shebang : #!/bin/bash — elle indique quel interpréteur exécuter le fichier. S’ajoutent ensuite les lectures d’entrée (read), les variables, les tests (if, case), les boucles (for, while read).

#!/bin/bash
read -r n
ok=0
for ((i=0; i<n; i++)); do
  read -r niveau
  if [ "$niveau" = "OK" ]; then ok=$((ok + 1)); fi
done
echo "ok : $ok"
[ "$ok" -ge 1 ] && echo "surveillance" || echo "nominal"

Les mêmes réflexes qu’en Python dans ce cours : lire les entrées dans l’ordre de l’énoncé, initialiser les compteurs avant la boucle, afficher le bilan après. Les tests comparent la sortie exactement : un espace de trop dans echo "ok : $ok" est une faute.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

Exercice 1 — Le shebang et la syntaxe

Bash Niveau 1 — Acquisition

Objectif : Écrire un script avec shebang correct, lire des arguments et répéter une sortie.

Le script lit une ligne : un mot. Il affiche trois lignes : script : $0 est le nom du script — littéralement, sans substituer — puis le mot reçu, puis fin. Objectif : s'assurer que le squelette, le shebang #!/bin/bash et la lecture simple sont en place.

Entrée du programme
bonjour
Sortie attendue
script : $0 est le nom du script
bonjour
fin

La sortie attendue, sans substitution de $0.

Deux indices, rédigés en mots
  1. Trois echo suffisent ; le deuxième affiche la variable $mot.
  2. La première ligne est un texte littéral : $0 s'écrit tel quel dans une chaîne simple, non substituée.

Bash Niveau 2 — Application

Objectif : Traiter un flux de niveaux d'alerte et produire un rapport conditionnel.

Le script lit n lignes : des niveaux OK, WARN ou CRIT. Il affiche un rapport de quatre lignes : OK : K, WARN : W, CRIT : C, puis le verdict : alarme si C ≥ 1, surveillance si W ≥ 1 (et C = 0), nominal sinon.

Une seule alerte critique suffit à déclencher l'alarme.

  1. Trois compteurs initialisés à 0, un case sur "$niveau" pour incrémenter le bon.
  2. Le verdict se décide par ordre de gravité : CRIT d'abord, puis WARN, sinon nominal.

6. QCM — niveau examen

Dans -rwxr-x---, que peut faire le groupe ?

Le triplet du groupe est r-x : lecture et exécution, pas d’écriture.

Que vaut rwxr-x--- en octal ?

rwx=7, r-x=5, ---=0 : 750.

Que fait chmod o-r toto ?

o = autres (others), - = retirer, r = lecture.

Que fixe chmod 770 toto ?

7=rwx pour u, 7=rwx pour g, 0=--- pour o.

Quelle différence entre ug=rwx et ug+x ?

Avec =, tout droit non listé disparaît ; + ne fait qu’ajouter au droit existant.

Que fait chown tpsysteme:root dossier ?

La syntaxe utilisateur:groupe change les deux à la fois.

À quoi sert l’option -R de chmod ou chown ?

-R descend dans l’arborescence : dossier, sous-dossiers, fichiers.

Que fait chgrp tpsysteme toto ?

chgrp (change group) ne touche que le groupe ; chown change le propriétaire.

À quoi sert la ligne #!/bin/bash ?

Le shebang désigne l’interpréteur : bash ici.

Où initialiser un compteur utilisé dans une boucle Bash ?

Avant, sinon il repart à zéro à chaque tour ; le bilan s’affiche après la boucle.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Lire quatre caractères pour un triplet : trois par classe, toujours.
  • Additionner 7+5+0 : l’octal se calcule par triplet, pas en additionnant les classes.
  • Confondre + et = : = remplace toute la classe, + ajoute un droit.
  • chown et chgrp intervertis : chown change le propriétaire, chgrp le groupe.
  • Bilan affiché dans la boucle : le rapport s’écrit après, avec les compteurs finaux.

8. Méthodologie de résolution

Résoudre un exercice de droits
  1. Séparer les dix caractères : type puis trois triplets u, g, o.
  2. Convertir triplet par triplet : r=4, w=2, x=1, tiret=0.
  3. Traduire l’opération : + ajoute, - retire, = fixe exactement ; -R pour la récursion.
  4. Choisir la commande : chmod pour les droits, chown le propriétaire, chgrp le groupe.
  5. Vérifier sur ls -l : la preuve est dans la sortie, jamais dans l’intuition.

9. Révision active

Résumé essentiel
  • Dix caractères : un type (- ou d) puis neuf droits en triplets u, g, o.
  • r=4, w=2, x=1 : rwx=7, r-x=5, rw-=6, ---=0 ; rwxr-x--- = 750.
  • chmod symbolique (u/g/o/a + ou - ou =, lettres rwx) ou octal (770) ; -R rend l’opération récursive.
  • chown change le propriétaire (utilisateur:groupe en une fois), chgrp le groupe ; ls -l et ls -Rl vérifient.
  • Un script Bash commence par #!/bin/bash : read, boucles, tests, puis le bilan après la boucle.

Checklist de maîtrise

  • Je lis une chaîne de droits et je décris ce que chaque classe peut faire.
  • Je convertis symbolique → octal et octal → symbolique sans erreur.
  • J’applique chmod, chown, chgrp avec récursion quand il faut.
  • J’écris un script avec shebang, lectures ordonnées, boucle et bilan final.
