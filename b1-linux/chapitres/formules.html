Mémo de l’administrateur

Arborescence, commandes, comptes, droits et squelettes de scripts du cours sur une page. À garder ouvert pendant les exercices et l’atelier.

L’arborescence en une image

/          racine : origine de tout

etc        configuration (à sauvegarder)      home   répertoires des utilisateurs

tmp        temporaires, vidés au reboot        var    journaux des démons, spools

root       maison du super-utilisateur         dev    fichiers des périphériques

usr        applications, manuels, librairies   bin/sbin  binaires essentiels

boot       noyau et démarrage                  proc   arborescence virtuelle du noyau

Tout chemin absolu commence par / ; /root n’est pas /.

Commandes de base

où suis-je        pwd            changer      cd chemin

lister            ls [-a cachés]  créer rep   mkdir

créer fichier     touch           copier      cp source cible

renommer/déplacer mv              supprimer   rm (danger : -f, -rf)

afficher          cat, more, head, tail        manuel      man cmd

écrire            echo "x" > f (écrase) ; echo "x" >> f (ajoute)

Syntaxe immuable : COMMANDE OPTIONS ARGUMENTS — ls -a /home.

find : chercher

find répertoire critères

  -name "motif"      nom (ex. "fich*")     -type f | d   fichier | répertoire

  -size +10M         taille                -user login   propriétaire

  -ctime, -atime, -mtime                  -group, -perm

Ex. du TP : find /tmp -name "fich*" ; find /tmp -type f.

Comptes et groupes

/etc/passwd  login:mot-de-passe:UID:GID:info:maison:shell

             * = authentification impossible ; !! = désactivé

             x/! = mot de passe dans shadow ; vide = sans mot de passe

/etc/shadow  mots de passe chiffrés (root seul)

/etc/group   groupe:*:GID:utilisateurs

commandes    useradd, userdel [-r], usermod, passwd, groupadd, groupdel

qui          whoami (moi) ; who, users, w (connectés)

UID          root = 0 ; < 1000 = système ; ≥ 1000 = humains

usermod -d /home/toto -m tutu change la maison et recopie le contenu.

Droits d’accès

-rwxr-x---     type(-,d) + u:rwx  g:r-x  o:---

poids          r=4  w=2  x=1  →  rwx=7  r-x=5  rw-=6  ---=0

octal          rwxr-x--- = 750 ; rw-r--r-- = 644 ; 770 = rwxrwx---

chmod          symbolique (u/g/o/a + - = lettres) ou octal ; -R récursif

chown          propriétaire (utilisateur:groupe en une fois) ; chgrp groupe

vérifier       ls -l, ls -Rl

+ ajoute, - retire, = fixe exactement : ug=rwx efface ce qui dépassait rwx.

Squelette d’un script Bash

#!/bin/bash

read -r n                    # premier : le compteur d’entrées

compteur=0                   # initialisation AVANT la boucle

for ((i=0; i<n; i++)); do

  read -r valeur             # une lecture par ligne d’entrée

  if [ "$valeur" = "OK" ]; then compteur=$((compteur + 1)); fi

done

echo "compteur : $compteur"  # bilan APRÈS la boucle

Découper par champs : IFS=":" read -r login uid gid shell <<< "$ligne".

Erreurs fréquentes à éviter

  • Confondre / (racine) et /root (maison de root).
  • Mettre les journaux dans /etc au lieu de /var.
  • Un seul chevron > qui écrase un fichier de configuration.
  • Additionner les classes au lieu de convertir triplet par triplet (750, pas 12).
  • Confondre chown (propriétaire) et chgrp (groupe).
  • Lire le seuil après n, ou oublier le \n final sur l’entrée du dernier read.
