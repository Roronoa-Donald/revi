Simulateur d’examen

Deux sujets blancs chronométrés, dans l’esprit de l’examen (durée 2 h, /20). Réalisez-les sans regarder les corrigés, puis corrigez-vous sévèrement.

Chronomètre d’examen — 2 h

Lancez le chrono quand vous commencez un sujet. Ne consultez le corrigé qu’à la fin. Réservez 15 min de relecture : champs de passwd, triplets de droits, ordre des lectures du script.

120:00

Examen blanc n°1

Sujet type examen — système de fichiers, comptes et droits.

Exercice 1/5 — Arborescence

Où stocke-t-on les configurations système, les journaux des démons, les répertoires personnels et les fichiers temporaires ? Que faut-il sauvegarder en plus de /etc et que peut-il arriver à /tmp ?

Corrigé
Configurations : /etc. Sauvegarder aussi les données personnelles et applicatives, puis tester la restauration. Journaux : /var. Répertoires personnels : /home (root : /root). Fichiers temporaires : /tmp, dont la conservation n’est pas garantie.
Exercice 2/5 — /etc/passwd

Décomposer la ligne caroline:x:1002:1000:Caroline TP:/home/caroline:/bin/bash, champ par champ. Que signifie x ? Dans une simulation classant comme humains les UID à partir de 1000, comment classer ce compte ?

Corrigé
login=caroline ; x renvoie au vérificateur dans /etc/shadow ; UID=1002 ; GID=1000 ; info=Caroline TP ; maison=/home/caroline ; shell=/bin/bash.
Dans cette simulation, 1002 est classé humain. Sur une machine réelle, les plages sont configurables et l’UID seul ne prouve pas la nature du compte.
Exercice 3/5 — Droits

Un fichier porte les droits rw-r-----. Donner sa notation octale, puis les commandes qui (a) retirent la lecture aux autres, (b) fixent exactement rwx au propriétaire, (c) lui donnent les droits 770. Que fait chacune ?

Corrigé
rw- = 6, r-- = 4, --- = 0 → 640.
(a) déjà aucune lecture aux autres : rien à faire ; sinon chmod o-r f.
(b) chmod u=rwx f — le = fixe la classe exactement.
(c) chmod 770 f → rwxrwx--- : tout pour u et g, rien aux autres.
Exercice 4/5 — Script

Écrire le script qui lit n puis n lignes « type nom », compte fichiers et répertoires, et affiche les deux comptes. Que se passe-t-il si l’entrée ne finit pas par un retour à la ligne ?

Corrigé
Boucle for ((i=0; i<n; i++)) avec read -r type nom, compteurs initialisés avant, bilan affiché après. Sans retour à la ligne final, read atteint la fin de fichier et renvoie un statut non nul ; les caractères déjà lus peuvent néanmoins être affectés aux variables. Une boucle qui ne traite que les lectures réussies peut alors ignorer cette dernière ligne.

Examen blanc n°2 — variante

Sujet orienté histoire du système, installation Debian et administration.

Exercice 1/5 — Histoire

Situer 1969, 1973, 1984, 1991 dans l’histoire d’UNIX et de Linux, avec un nom et un fait par date. Réciter les quatre libertés.

Corrigé
1969 : Thompson et Ritchie créent UNIX aux Bell Labs. 1973 : réécriture en C (version 4, portabilité). 1984 : Stallman lance le projet GNU. 1991 : Torvalds publie le noyau Linux ; le noyau passe sous licence GPL en 1992.
Libertés 0-1-2-3 : utiliser, étudier/adapter, redistribuer, améliorer/diffuser.
Exercice 2/5 — Partitionnement

Proposer un schéma de partitionnement pour un TP Debian 12 (disque 80 Go, RAM 4 Go), en distinguant systèmes de fichiers montés et espace swap. Justifier le swap et la séparation de /home.

Corrigé
/dev/sda1 ≈ 30 Go ext4 sur / ; /dev/sda2 ≈ 8 Go de swap dans cet exemple ; /dev/sda3 le reste ext4 sur /home. La taille du swap dépend des besoins.
Le swap est activé, pas monté comme ext4 ; /home séparé peut être conservé si l’installateur ne le reformate pas. Garder une sauvegarde. Vérification : df -h et swapon --show.
Exercice 3/5 — Administration

Dérouler le cycle complet : créer tpsysteme et userVoisin, créer le groupe projet2026, y rattacher les deux comptes, renommer tpsysteme en tp2026, puis supprimer userVoisin avec sa maison. Quelles vérifications après chaque étape ?

Corrigé
useradd tpsysteme, useradd userVoisin ; groupadd projet2026 ; usermod -aG projet2026 tpsysteme (idem userVoisin) — vérifier dans /etc/group.
usermod -l tp2026 tpsysteme (utilisateur délogué). userdel -r userVoisin — le -r supprime la maison. Contrôles : /etc/passwd, /etc/group.
Exercice 4/5 — find et liens

Dans /tmp on a créé fichier1, fichier2, testfichier1, et un lien symbolique raccourci vers fichier1. Écrire : la commande qui trouve les éléments commençant par « fich », celle qui trouve tous les fichiers, et ce que voit cat raccourci après echo "maj" >> fichier1.

Corrigé
find /tmp -name "fich*" → fichier1, fichier2. find /tmp -type f → les trois fichiers.
Le lien symbolique reflète sa source : après l’ajout, cat raccourci affiche le contenu mis à jour de fichier1 (le lien n’est pas un fichier stocké).

QCM final — toutes notions

Que contient /var ?

/var : fichiers variables — journaux, spools de mail, d’impression, de cron.

root possède quel UID ?

root = UID 0 ; les autres plages dépendent de la configuration.

Que signifie un champ commençant par ! dans /etc/shadow ?

Le mot de passe est verrouillé ; d’autres moyens d’authentification peuvent rester autorisés.

Que fait echo "x" >> f ?

Deux chevrons ajoutent (suffixent) ; un seul écrase.

rwxr-x--- en octal ?

rwx=7, r-x=5, ---=0 : 750, triplet par triplet.

chmod ug=rwx : effet sur les autres classes ?

= fixe exactement les classes visées ; les autres classes ne bougent pas.

Que fait chown -R tpsysteme dossier ?

-R rend le changement récursif : dossier, sous-dossiers, fichiers.

groupdel échoue quand…

Impossible de supprimer un groupe qui sert de groupe principal.

Première ligne d’un script Bash ?

Le shebang désigne l’interpréteur.

Sans retour à la ligne final sur l’entrée, que devient le dernier read ?

read renvoie un statut non nul à la fin de fichier, mais peut affecter aux variables les caractères déjà lus. Une boucle qui exige un statut nul peut ignorer cette dernière ligne.
