Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque module, puis un projet final qui gère un parc système complet. Les scripts sont en Bash, comme à l’atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Affichez « Bienvenue sur Linux » puis la valeur lue sur l’entrée.
  2. Lit n et affiche n fois « ligne ok » avec le numéro de chaque ligne.
  3. Lit n puis n mots et compte ceux qui valent « root ».
  4. Lit deux entiers et affiche leur somme et leur produit.
Corrections
read -r nom
echo "Bienvenue sur Linux"
echo "Salut, $nom"

read -r n
for ((i=1; i<=n; i++)); do
  echo "ligne $i ok"
done

read -r n
compte=0
for ((i=0; i<n; i++)); do
  read -r mot
  [ "$mot" = "root" ] && compte=$((compte + 1))
done
echo "root : $compte"

read -r a
read -r b
echo "somme : $((a + b))"
echo "produit : $((a * b))"

Application

Application
  1. Convertit une chaîne de neuf droits (sans le type) en notation octale.
  2. Lit n lignes « login uid » et affiche les logins dont l’UID est supérieur ou égal à 1000.
  3. Lit un seuil en octets, puis n lignes « nom taille », et liste les fichiers au-dessus du seuil.
  4. Simule chmod : lit « droits modif » et applique une action + ou - sur une classe u, g ou o.
Corrections
read -r n
for ((i=0; i<n; i++)); do
  read -r droits
  octal=""
  for debut in 0 3 6; do
    v=0
    [ "${droits:$debut:1}" = "r" ] && v=$((v + 4))
    [ "${droits:$((debut + 1)):1}" = "w" ] && v=$((v + 2))
    [ "${droits:$((debut + 2)):1}" = "x" ] && v=$((v + 1))
    octal="$octal$v"
  done
  echo "$octal"
done

read -r n
for ((i=0; i<n; i++)); do
  read -r login uid
  [ "$uid" -ge 1000 ] && echo "$login"
done

read -r seuil
read -r n
for ((i=0; i<n; i++)); do
  read -r nom taille
  [ "$taille" -gt "$seuil" ] && echo "$nom $taille"
done

read -r n
for ((i=0; i<n; i++)); do
  read -r droits modif
  classe="${modif:0:1}"
  action="${modif:1:1}"
  lettre="${modif:2:1}"
  case "$classe" in
    u) debut=0 ;;
    g) debut=3 ;;
    o) debut=6 ;;
  esac
  for ((k=debut; k<debut + 3; k++)); do
    [ "${droits:$k:1}" = "$lettre" ] || [ "$action" = "+" ] || continue
    if [ "$action" = "+" ]; then droits="${droits:0:$k}$lettre${droits:$((k + 1))}"
    else droits="${droits:0:$k}-${droits:$((k + 1))}"; fi
  done
  echo "$droits"
done

Raisonnement

Raisonnement
  1. Suit une chaîne de liens symboliques jusqu’au fichier final et détecte les liens cassés.
  2. Simule /etc/passwd : ajoute des comptes avec UID automatique à partir de 1000, répond aux ls.
  3. Produit un rapport de parc : comptage par type, budget total et article le plus cher.
  4. Convertit une chaîne complète de dix caractères (type + droits) en ligne « nom : -drwxr-x--- ».
Corrections
read -r n
declare -A liens
for ((i=0; i<n; i++)); do
  read -r cible source
  liens["$source"]="$cible"
done
read -r depart
courant="$depart"
etapes=0
while [ -n "${liens[$courant]:-}" ] && [ "$etapes" -lt 10 ]; do
  courant="${liens[$courant]}"
  etapes=$((etapes + 1))
done
echo "$courant"

read -r n
logins=()
uids=()
uid_suivant=1000
for ((i=0; i<n; i++)); do
  read -r op login
  if [ "$op" = "useradd" ]; then
    deja=0
    for l in "${logins[@]}"; do [ "$l" = "$login" ] && deja=1; done
    if [ "$deja" = "1" ]; then echo "existe"
    else logins+=("$login"); uids+=("$uid_suivant"); uid_suivant=$((uid_suivant + 1)); fi
  elif [ "$op" = "ls" ]; then
    for idx in "${!logins[@]}"; do
      echo "${logins[$idx]}:x:${uids[$idx]}:${uids[$idx]}:/home/${logins[$idx]}:/bin/bash"
    done
  fi
done

read -r n
total=0
max_prix=-1
max_nom=""

Projet intégrateur — « gestion du parc système »

Cahier des charges

On te confie l’inventaire d’un parc. Le script lit n, puis n lignes au format type nom droits — type vaut fichier ou repertoire, droits sont neuf caractères type rwxr-x---. Il produit un rapport : effectifs par type, liste des répertoires, la notation octale de chaque entrée, et une recommandation de sécurité (une entrée dont les autres ont le droit d’écriture est « à risque »).

Fonctionnalités attendues
  1. Lire les entrées dans l’ordre : n d’abord, puis les lignes, une par une.
  2. Compter par type et mémoriser les répertoires dans l’ordre d’entrée.
  3. Convertir les droits en octal triplet par triplet (r=4, w=2, x=1).
  4. Détecter le risque : le caractère 8 (autres, écriture) vaut w.
  5. Formater : libellés exacts, « type : K », une ligne par entrée.
  6. Gérer le cas limite n = 0 (rapport vide mais propre).

Contraintes : pas de tableaux associatifs pour les effectifs (quatre variables nommées), noms explicites, bilan après la boucle.

Grille d’auto-évaluation du projet (sur 100)
< 50 % — Lecture ordonnée et gestion de n = 0 20
50–69 % — Effectifs par type corrects 20
70–94 % — Détection des entrées à risque 20
≥ 95 % — Lisibilité, noms, formats 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
read -r n
fichiers=0
repertoires=0
rep_noms=()
a_risque=0
for ((i=0; i<n; i++)); do
  read -r type nom droits
  if [ "$type" = "fichier" ]; then
    fichiers=$((fichiers + 1))
  else
    repertoires=$((repertoires + 1))
    rep_noms+=("$nom")
  fi
  octal=""
  for debut in 0 3 6; do
    v=0
    [ "${droits:$debut:1}" = "r" ] && v=$((v + 4))
    [ "${droits:$((debut + 1)):1}" = "w" ] && v=$((v + 2))
    [ "${droits:$((debut + 2)):1}" = "x" ] && v=$((v + 1))
    octal="$octal$v"
  done
  echo "$nom : $type $octal"
  if [ "${droits:8:1}" = "w" ]; then
    a_risque=$((a_risque + 1))
    echo "  a risque : ecriture possible pour les autres"
  fi
done
echo "fichiers : $fichiers"
echo "repertoires : $repertoires"
for nom in "${rep_noms[@]}"; do echo "repertoire : $nom"; done
echo "a risque : $a_risque"
Cette solution combine lecture ordonnée, comptage par variables nommées, conversion octale, mémorisation ordonnée et détection de risque — l’essentiel des six modules en un seul rapport.
