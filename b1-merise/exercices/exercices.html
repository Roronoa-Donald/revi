Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque module, puis un projet final qui déroule la chaîne complète d'analyse. Les scripts sont en Bash, comme à l'atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n valeurs « d » ou « i » suivies d'un libellé et affiche donnée ou information, puis les deux compteurs.
  2. Lit n modèles (MCD, MLD, MPD, MCT, MOT, MOpT) et affiche leur niveau (conceptuel, logique, physique).
  3. Lit n propriétés « nom nature » (el, co, ca) et affiche conservee ou ecartee, puis le total retenu.
  4. Lit n couples « min max » et affiche la cardinalité en toutes lettres (au plus une, exactement une, zero ou plusieurs, au moins une).
Corrections
read -r n
donnees=0
infos=0
for ((k=0; k<n; k++)); do
  read -r type libelle
  if [ "$type" = "d" ]; then
    echo "$libelle : donnee"
    donnees=$((donnees + 1))
  else
    echo "$libelle : information"
    infos=$((infos + 1))
  fi
done
echo "donnees : $donnees / informations : $infos"

read -r n
for ((k=0; k<n; k++)); do
  read -r modele
  case "$modele" in
    MCD|MCT) echo "$modele : conceptuel" ;;
    MLD|MOT) echo "$modele : logique" ;;
    MPD|MOpT) echo "$modele : physique" ;;
  esac
done

read -r n
retenues=0
for ((k=0; k<n; k++)); do
  read -r nom nature
  if [ "$nature" = "ca" ]; then
    echo "$nom : ecartee"
  else
    echo "$nom : conservee"
    retenues=$((retenues + 1))
  fi
done
echo "retenu : $retenues"

read -r n
for ((k=0; k<n; k++)); do
  read -r min max
  if [ "$min" = "0" ] && [ "$max" = "1" ]; then echo "au plus une"
  elif [ "$min" = "1" ] && [ "$max" = "1" ]; then echo "exactement une"
  elif [ "$min" = "0" ] && [ "$max" = "n" ]; then echo "zero ou plusieurs"
  else echo "au moins une"; fi
done

Application

Application
  1. Valide un dictionnaire : lit n propriétés « nom type » et refuse les types inconnus (hors el/co/ca), puis liste le dictionnaire validé.
  2. Détecte les DF dont la source est vide ou égale à la cible (A → A est interdite), et compte les DF exploitables.
  3. Traduit les cardinalités en règle de passage : lit « nature cardinalite » (entite/assoc + max) et affiche table, table ou # migre.
  4. Vérifie un schéma : lit n lignes « table champ role » et refuse un # vers une table sans clé primaire déclarée.

Raisonnement

Raisonnement
  1. Reconstruit les DF par transitivité : lit n DF « A B » et affiche les DF déduites A → C quand B → C existe (une passe).
  2. Classe les violations : lit n lignes « forme attribut » (1fn/2fn/3fn + nom) et compte les violations par forme.
  3. Compare deux schémas : lit n tables « nom nb_attributs » par schéma (2 blocs) et affiche lequel est le plus décomposé et de combien.
  4. Simule une décomposition : lit n attributs de LIGNE_CDE marqués cle/ref/dep et affiche les deux tables résultantes.

read -r n
v1=0 ; v2=0 ; v3=0
for ((k=0; k<n; k++)); do
  read -r forme attribut
  case "$forme" in
    1fn) v1=$((v1 + 1)) ; echo "1FN violee par $attribut" ;;
    2fn) v2=$((v2 + 1)) ; echo "2FN violee par $attribut" ;;
    3fn) v3=$((v3 + 1)) ; echo "3FN violee par $attribut" ;;
  esac
done
echo "violations : $v1 / $v2 / $v3"

read -r na
somme_a=0 ; tables_a=0
for ((k=0; k<na; k++)); do
  read -r nom attrs
  somme_a=$((somme_a + attrs))
  tables_a=$((tables_a + 1))
done
read -r nb
somme_b=0 ; tables_b=0
for ((k=0; k<nb; k++)); do
  read -r nom attrs
  somme_b=$((somme_b + attrs))
  tables_b=$((tables_b + 1))
done
if [ "$tables_a" -gt "$tables_b" ]; then
  echo "schema A plus decompose (+$((tables_a - tables_b)) tables)"
else
  echo "schema B plus decompose (+$((tables_b - tables_a)) tables)"
fi

read -r n
table1=""
table2=""
for ((k=0; k<n; k++)); do
  read -r attribut role
  if [ "$role" = "ref" ] || [ "$role" = "dep" ]; then
    table1="$table1 $attribut"
  else
    table2="$table2 $attribut"
  fi
done
echo "PRODUIT :$table1"
echo "LIGNE_CDE :$table2"

Projet intégrateur — « chaîne d'analyse complète »

Cahier des charges

Le script reçoit le journal d'une mission d'analyse : d'abord n_regles règles de gestion au format source cible (chaque source détermine sa cible), puis n_docs propriétés relevées sur les documents au format nom nature (el, co, ca). Il produit le rapport d'analyse : propriétés retenues (el et co) et écartées (ca), DF élémentaires dédoublonnées, identifiant candidat (source qui détermine le plus de cibles), et verdict de couverture : « complet » si toute propriété retenue est cible d'au moins une DF ou identifiant, « a completer » sinon.

Fonctionnalités attendues
  1. Lire les deux blocs dans l'ordre, sans mélanger règles et propriétés.
  2. Filtrer les propriétés par nature et compter chaque décision.
  3. Dédoublonner les DF et compter les cibles par source (tableaux associatifs).
  4. Désigner
    5.  l'identifiant candidat au maximum de cibles.
  5. Conclure : couverture des propriétés retenues, verdict final.

Contraintes : un seul passage d'affichage par bloc, bilan après lecture complète, formats exacts du cahier des charges.

Grille d'auto-évaluation du projet (sur 100)
Lecture des deux blocs et filtrage des natures 20
DF dédoublonnées et comptage par source 20
Identifiant candidat correct 20
Verdict de couverture conforme 20
Rapport lisible et formats exacts 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
read -r n_regles
declare -A cibles_par_source
declare -A comptes
declare -A vues_df
sources=()
for ((k=0; k<n_regles; k++)); do
  read -r source cible
  if [ -z "${vues_df[$source|$cible]:-}" ]; then
    vues_df[$source|$cible]=1
    if [ -z "${comptes[$source]:-}" ]; then
      comptes[$source]=0
      sources+=("$source")
    fi
    comptes[$source]=$(( ${comptes[$source]} + 1 ))
  fi
done
read -r n_docs
retenues=0
ecartees=0
declare -A retenus
for ((k=0; k<n_docs; k++)); do
  read -r nom nature
  if [ "$nature" = "ca" ]; then
    echo "ecartee : $nom (calculee)"
    ecartees=$((ecartees + 1))
  else
    echo "retenue : $nom"
    retenus[$nom]=1
    retenues=$((retenues + 1))
  fi
done
max=0
identifiant=""
for s in "${sources[@]}"; do
  if [ "${comptes[$s]}" -gt "$max" ]; then
    max="${comptes[$s]}"
    identifiant="$s"
  fi
done
echo "identifiant candidat : $identifiant ($max cibles)"
couvertes=1
for p in "${!retenus[@]}"; do
  if [ -z "${cibles_par_source[$p]:-}" ] && [ "$p" != "$identifiant" ]; then
    couvertes=0
  fi
done
if [ "$couvertes" = "1" ]; then
  echo "verdict : complet"
else
  echo "verdict : a completer"
fi
Cette solution combine lecture en deux blocs, filtrage des natures, dédoublonnage des DF, élection de l'identifiant et verdict de couverture — les chapitres 3, 4 et 5 en un seul script.
