Modélisation (MERISE) B1 — analyser, modéliser, normaliser

MERISE sépare ce qui est enregistré (les données) de ce qui est fait (les traitements), et avance par niveaux : quoi (conceptuel), comment organiser (logique), comment réaliser (physique). Six chapitres pour passer du discours du client au schéma relationnel normalisé. Chaque mécanisme est d'abord programmé et vérifié dans l'atelier, puis rejoué tel quel sur les applications du support.

Ce que tu sauras faire à la fin du cours
  • distinguer donnée, information et connaissance, et situer les trois sous-systèmes de l'entreprise ;
  • placer les six modèles MERISE (MCD, MLD, MPD, MCT, MOT, MOpT) sur leurs trois niveaux ;
  • construire un dictionnaire de données et extraire les dépendances fonctionnelles ;
  • dessiner un MCD : entités, associations, cardinalités, identifiants ;
  • passer du MCD au MLD relationnel avec clés primaires et étrangères ;
  • vérifier et corriger un schéma avec les formes normales 1FN, 2FN, 3FN.
Comment ce cours s'articule

Le support déroule la méthode en sept thèmes : le système d'information, la méthode MERISE, le dictionnaire de données, le MCD, le MLD et le relationnel, la normalisation, le MCT. Ce cours en garde l'ordre et fait manipuler chaque mécanisme en Bash : un script qui reproduit l'analyse exacte de l'analyste, exécuté dans la page.

Chaque chapitre se termine par trois exercices de code : tu écris vraiment le script, il est réellement exécuté, puis corrigé par des tests que tu ne vois pas. La logique écrite ici se rejoue telle quelle sur les applications du support (facture TogoMall, contre-exemples des formes normales).

Programme du cours

1Le système d'information et l'entreprise
Donnée, information, connaissance ; l'entreprise en trois sous-systèmes ; les domaines de l'information. 2La méthode MERISE : niveaux et étapes
Double démarche par niveaux et par étapes ; les modèles MCD/MLD/MPD et MCT/MOT/MOpT ; données contre traitements. 3Dictionnaire de données et dépendances fonctionnelles
Recenser les propriétés (élémentaires, composées, calculées) ; écrire les règles de gestion ; construire la matrice des DF. 4Le modèle conceptuel des données (MCD)
Entités, associations, cardinalités ; le formalisme entité-association ; l'application facture. 5Le modèle logique des données (MLD relationnel)
Attributs, tables, clés primaires et étrangères ; les règles de passage du MCD au MLD ; intégrité référentielle. 6La normalisation du MLD : 1FN, 2FN, 3FN
Anomalies d'une base non normalisée ; formes normales 1FN, 2FN, 3FN ; dépendances partielles et transitives.
