Atelier de code PHP

Un éditeur dans la page, un vrai interpréteur PHP derrière. Écrivez un script, donnez-lui son entrée, exécutez-le et lisez ce qu’il affiche. C’est ici qu’un cours devient un réflexe.

Comment fonctionne l’atelier
  • Exécuter fait tourner votre code PHP tel quel et affiche sa sortie, ses erreurs et son code de sortie.
  • Entrée du programme contient ce que fgets(STDIN) lira, une valeur par ligne.
  • Expliquer mon erreur demande au tuteur, quand il y a une erreur, pourquoi elle survient et par où chercher. Il explique en mots : il n’écrit jamais de code à votre place.
  • Le raccourci Ctrl + Entrée exécute le script sans quitter l’éditeur.
  • Votre code est conservé dans ce navigateur, par exercice et par cours : vous le retrouvez à la prochaine visite.

Du formulaire à la base de données

PHP vit dans un écosystème : un formulaire HTML envoie des données, le script les valide, les enregistre dans MySQL via PDO, puis génère la page. L'atelier travaille le cœur de cette chaîne — la logique du script — avec des entrées qui simulent ce que le formulaire aurait envoyé. La structure de données que vous manipulez ici (tableau associatif nom → valeur) est exactement celle que PDO vous rendra sous forme de lignes.

Les trois erreurs que l’atelier révèle immédiatement
  • Variable oubliée ou mal orthographiée : PHP prévient « Undefined variable » ou « Undefined array key » — le nom du tableau et la clé fautive sont dans le message.
  • Comparaison de types : la valeur lue est une chaîne ; comparez-la telle quelle ou convertissez-la, mais ne mélangez pas les deux.
  • Saut de ligne non retiré : fgets garde le retour à la ligne ; sans trim, la comparaison échoue sans bruit.
Ce que fait l’atelier, côté technique
  • Votre code est envoyé à ce serveur, qui le transmet à un service d’exécution sandboxé : rien ne tourne sur votre machine, et aucun accès au système n’est possible.
  • La clé du service reste sur le serveur ; le navigateur ne la voit jamais.
  • Le nombre d’exécutions est limité par jour, pour tout le monde. Exécuter à chaque frappe épuiserait ce quota : l’atelier n’exécute que sur un clic.
