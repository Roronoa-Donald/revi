Module 1 — Premiers pas

QuestionQuelle balise ouvre un bloc de code PHP ?
Réponse<?php — le code qui suit est interprété comme du PHP.
QuestionComment reconnaît-on une variable PHP ?
RéponseElle commence toujours par $ : $nom, $total.
QuestionQue lit fgets(STDIN) ?
RéponseUne ligne de l'entrée standard, saut de ligne compris : on la nettoie avec trim().
QuestionDifférence entre echo et return ?
Réponseecho affiche ; return transmet la valeur à l'appelant.
QuestionComment affecter une valeur à une variable en PHP ?
RéponseAvec = valeur;. Les variables débutent par $ et sont créées à leur première affectation.
QuestionQu'est-ce que l'interpolation de variables en PHP ?
RéponseDans une chaîne entre guillemets doubles "Bonjour ", les variables sont directement remplacées par leur valeur.

Module 2 — Types et chaînes

QuestionComment convertir une chaîne en entier ?
RéponseAvec le cast (int) : (int)"42" vaut 42.
QuestionConcaténer deux chaînes en PHP ?
RéponseAvec le point : "Bonjour " . $nom. Dans les guillemets doubles, les variables sont interpolées.
QuestionDivision entière et reste en PHP ?
Réponseintdiv($a, $b) pour le quotient entier, $a % $b pour le reste.
QuestionFormater un nombre à deux décimales ?
Réponsenumber_format($x, 2, '.', '') : deux décimales, point décimal, sans séparateur.
QuestionQuels sont les quatre types scalaires fondamentaux en PHP ?
Réponseint (entier), float (décimal), string (chaîne de caractères) et bool (booléen true/false).
QuestionComment obtenir le reste de la division entière en PHP ?
RéponseAvec l'opérateur modulo % (ex. 17 % 5 vaut 2).
QuestionQuel opérateur permet de concaténer deux chaînes en PHP ?
RéponseLe point . (ex. = . " " . ;).
QuestionQuelle fonction retourne la longueur en octets d'une chaîne en PHP ?
Réponsestrlen(). Pour les caractères multi-octets UTF-8, on privilégie mb_strlen().
QuestionDifférence entre explode() et implode() en PHP ?
Réponseexplode(, ) découpe une chaîne en tableau ; implode(, ) rassemble un tableau en chaîne.

Module 3 — Conditions

QuestionStructure complète du test alternatif PHP ?
Réponseif (...) { } elseif (...) { } else { } — un seul mot « elseif ».
QuestionDans une cascade, quelle branche s'exécute ?
RéponseLa première condition satisfaite ; les suivantes sont ignorées : ordonne du plus exigeant au plus général.
QuestionET et OU logiques en PHP ?
Réponse&& (et and) pour le ET ; || (et or) pour le OU.
QuestionDifférence entre == et === ?
Réponse== compare les valeurs après conversion ; === exige valeur ET type identiques.
QuestionQuels sont les opérateurs usuels de comparaison en PHP ?
Réponse<, >, <=, >=, == (égalité après conversion) et === (égalité stricte).
QuestionQue fait l'opérateur de négation logique ! en PHP ?
RéponseIl inverse la valeur de vérité booléenne : !true vaut false et !false vaut true.
QuestionPourquoi privilégier l'égalité stricte === plutôt que == en PHP ?
Réponse=== vérifie à la fois la valeur et le type, évitant les conversions implicites piégeuses de ==.
QuestionComment s'écrit une condition ternaire concise en PHP ?
Réponse = ( >= 10) ? "Admis" : "Ajourné";.

Module 4 — Boucles

QuestionLes trois parties d'une boucle for ?
RéponseInitialisation ; condition de poursuite ; pas. for ($i = 1; $i <= $n; $i++).
QuestionCompter à rebours en PHP ?
RéponsePas négatif : for ($i = $n; $i >= 1; $i--).
QuestionOù initialiser un accumulateur ?
RéponseAvant la boucle ; initialisé dedans, il repart de sa valeur initiale à chaque tour.
QuestionQuand utiliser while plutôt que for ?
RéponseQuand le nombre de tours est inconnu à l'avance (validation de saisie, recherche).
QuestionÀ quelle valeur initialiser un accumulateur pour un produit dans une boucle ?
RéponseÀ 1 (élément neutre multiplicatif) : initialiser à 0 annulerait tout le produit.
QuestionQuelle erreur produit une boucle infinie avec while ?
RéponseOublier de modifier ou d'incrémenter la variable testée dans la condition de maintien.
QuestionComment fonctionnent des boucles imbriquées en PHP ?
RéponseÀ chaque tour de la boucle externe, la boucle interne effectue toutes ses itérations (ex. 4 tours externes × 3 internes = 12 itérations).

Module 5 — Tableaux indexés

QuestionComment ajouter un élément à un tableau ?
Réponse$tab[] = $valeur; — l'indice numérique est attribué automatiquement.
QuestionPremier indice d'un tableau PHP ?
Réponse0 : un tableau de n éléments va de l'indice 0 à l'indice n − 1.
QuestionQue renvoie array_search quand la valeur est absente ?
Réponsefalse : à tester avec === false avant d'utiliser le résultat.
QuestionJoindre les éléments d'un tableau en une chaîne ?
Réponseimplode(' ', $tab) — le séparateur en premier argument.
QuestionQu'est-ce qu'un tableau indexé numériquement en PHP ?
RéponseUne liste de valeurs indexées à partir de 0 ; [] = ; insère au prochain indice entier libre.
QuestionComment obtenir le nombre d'éléments présents dans un tableau PHP ?
RéponseAvec la fonction native count().
QuestionQuelles fonctions natives calculent la somme et le maximum d'un tableau ?
Réponsearray_sum() pour la somme et max() pour la valeur maximale.
QuestionQuel est le principe du tri par sélection sur un tableau ?
RéponseRechercher le minimum de la fraction non triée et l'échanger avec la case du premier indice disponible.

Module 6 — Fonctions

QuestionDéclarer une fonction PHP ?
Réponsefunction nom($param) { ... return $valeur; } — le nom ne porte pas de $.
QuestionRenvoyer plusieurs valeurs ?
RéponseUn tableau : return [$a, $b];, reçu par décomposition [$x, $y] = f();.
QuestionPortée d'une variable déclarée dans une fonction ?
RéponseLocale à la fonction : toute information entre par les paramètres et sort par le return.
QuestionQue se passe-t-il sans return ?
RéponseLa fonction renvoie null : l'appelant ne peut rien exploiter.
QuestionComment renvoyer plusieurs valeurs distinctes depuis une fonction PHP ?
RéponseEn retournant un tableau return [, ];, déballé par l'appelant via [, ] = f();.
QuestionPourquoi factoriser les calculs répétitifs dans des fonctions en PHP ?
RéponsePour respecter le principe DRY (Don't Repeat Yourself), faciliter la maintenance et isoler les responsabilités.

Module 7 — Tableaux associatifs

QuestionDéclarer un tableau associatif ?
Réponse['cle' => valeur, 'autre' => valeur] — la flèche relie la clé à sa valeur.
QuestionParcourir clé et valeur ensemble ?
Réponseforeach ($tab as $cle => $valeur).
QuestionTester l'existence d'une clé ?
Réponseisset($tab[$cle]) — indispensable avant d'incrémenter un compteur.
QuestionÀ quoi servent les tableaux associatifs côté PDO ?
RéponseChaque ligne de résultat arrive sous forme colonne → valeur : c'est le même outil.
QuestionComment comptabiliser les occurrences d'éléments dans un tableau associatif ?
RéponsePour chaque valeur : [] = ([] ?? 0) + 1;.
QuestionComment combiner deux tableaux en PHP ?
RéponseAvec array_merge(, ) ou l'opérateur de décomposition [..., ...].

Module 8 — Formulaires, sessions et PDO

QuestionPourquoi les requêtes préparées ?
RéponseLa valeur passe par un paramètre, jamais concaténée au SQL : les injections deviennent impossibles.
QuestionQue fait $stmt->execute([$v]) ?
RéponseElle exécute la requête préparée en remplaçant le ? par la valeur fournie.
QuestionComment PDO présente-t-il chaque ligne de résultat ?
RéponseUn tableau associatif colonne → valeur, parcouru avec foreach.
QuestionÀ quoi sert htmlspecialchars avant d'afficher ?
RéponseÀ neutraliser le HTML d'une donnée externe : la protection contre les injections XSS.
QuestionQuel est le rôle de la superglobale en PHP ?
RéponseContenir les données transmises par le client HTTP via un formulaire soumis en méthode POST.
QuestionPourquoi doit-on appeler session_start() au début d'une page PHP ?
RéponsePour démarrer ou reprendre la session utilisateur et accéder aux données persistantes de .
QuestionQu'est-ce que le DSN lors de l'instanciation de l'objet PDO ?
RéponseLa chaîne de connexion (Data Source Name) indiquant le pilote, l'hôte et la base (ex. mysql:host=localhost;dbname=ecole).
QuestionComment parcourir les enregistrements renvoyés par une requête préparée PDO ?
RéponseEn appelant ->fetchAll(PDO::FETCH_ASSOC) et en itérant avec une boucle foreach.
