Module 1 — Premiers pas

QuestionQuelle balise ouvre un bloc de code PHP ?
Réponse<?php — le code qui suit est interprété comme du PHP.
QuestionComment reconnaît-on une variable PHP ?
RéponseElle commence toujours par $ : $nom, $total.
QuestionQue lit fgets(STDIN) ?
RéponseUne ligne de l'entrée standard, saut de ligne compris : on la nettoie avec trim().
QuestionDifférence entre echo et return ?
Réponseecho affiche ; return transmet la valeur à l'appelant.
QuestionQu’est-ce que « affectation » ?
RéponseDéfinition. Une variable est un nom qui désigne une valeur en mémoire. En PHP, tout nom de variable commence par $ , on ne la déclare pas à l'avance : sa première affectation la crée.
QuestionQu’est-ce que « interpolation » ?
RéponseEntrez guillemets doubles, une variable est remplacée par sa valeur : c’est l’interpolation.

Module 2 — Types et chaînes

QuestionComment convertir une chaîne en entier ?
RéponseAvec le cast (int) : (int)"42" vaut 42.
QuestionConcaténer deux chaînes en PHP ?
RéponseAvec le point : "Bonjour " . $nom. Dans les guillemets doubles, les variables sont interpolées.
QuestionDivision entière et reste en PHP ?
Réponseintdiv($a, $b) pour le quotient entier, $a % $b pour le reste.
QuestionFormater un nombre à deux décimales ?
Réponsenumber_format($x, 2, '.', '') : deux décimales, point décimal, sans séparateur.
QuestionQu’est-ce que « int / float / string / bool » ?
RéponseQuatre types de base : int, float, string, bool — conversions par cast.
QuestionQu’est-ce que « modulo % » ?
RéponseObjectif : Découper une quantité avec division entière et modulo.
QuestionQu’est-ce que « concaténation . » ?
Réponsemanipuler les chaînes : longueur, casse, découpage, concaténation.
QuestionQu’est-ce que « strlen » ?
Réponsestrlen compte les caractères de la chaîne.
QuestionQu’est-ce que « explode / implode » ?
Réponseexplode / implode : implode('-', [1, 2]) → "1-2"

Module 3 — Conditions

QuestionStructure complète du test alternatif PHP ?
Réponseif (...) { } elseif (...) { } else { } — un seul mot « elseif ».
QuestionDans une cascade, quelle branche s'exécute ?
RéponseLa première condition satisfaite ; les suivantes sont ignorées : ordonne du plus exigeant au plus général.
QuestionET et OU logiques en PHP ?
Réponse&& (et and) pour le ET ; || (et or) pour le OU.
QuestionDifférence entre == et === ?
Réponse== compare les valeurs après conversion ; === exige valeur ET type identiques.
QuestionQu’est-ce que « comparaisons » ?
Réponseif / else : exécuter selon une condition ; comparaisons avec <, >=, ===…
QuestionQu’est-ce que « ! » ?
Réponse! : PHP B1 › Sommaire › Chapitre 3
QuestionQu’est-ce que « == vs === » ?
Réponse== vs === : PHP B1 › Sommaire › Chapitre 3
QuestionQu’est-ce que « ternaire » ?
Réponseecho ($note >= 10 ? "Admis" : "Ajourne") . "\n"; — la condition ternaire renvoie l'une des deux valeurs selon le test. Pratique pour choisir un texte ou une valeur ; à éviter pour des blocs d'instructions longs.

Module 4 — Boucles

QuestionLes trois parties d'une boucle for ?
RéponseInitialisation ; condition de poursuite ; pas. for ($i = 1; $i <= $n; $i++).
QuestionCompter à rebours en PHP ?
RéponsePas négatif : for ($i = $n; $i >= 1; $i--).
QuestionOù initialiser un accumulateur ?
RéponseAvant la boucle ; initialisé dedans, il repart de sa valeur initiale à chaque tour.
QuestionQuand utiliser while plutôt que for ?
RéponseQuand le nombre de tours est inconnu à l'avance (validation de saisie, recherche).
QuestionQu’est-ce que « élément neutre » ?
RéponsePour un produit, l'élément neutre change : $produit = 1; — initialiser à zéro annulerait tout (0 × quoi que ce soit = 0). Chaque puissance de deux, par exemple, est le double de la précédente : une seule multiplication par tour.
QuestionQu’est-ce que « boucle infinie » ?
RéponseLes trois parties suivent la logique inverse : initialisation en haut, condition de borne basse, pas négatif. Oublier de retourner la condition ( >= au lieu de <= ) produit une boucle infinie.
QuestionQu’est-ce que « boucles imbriquées » ?
Réponseboucles imbriquées : imbriquer deux boucles et prédire le nombre total de tours.

Module 5 — Tableaux indexés

QuestionComment ajouter un élément à un tableau ?
Réponse$tab[] = $valeur; — l'indice numérique est attribué automatiquement.
QuestionPremier indice d'un tableau PHP ?
Réponse0 : un tableau de n éléments va de l'indice 0 à l'indice n − 1.
QuestionQue renvoie array_search quand la valeur est absente ?
Réponsefalse : à tester avec === false avant d'utiliser le résultat.
QuestionJoindre les éléments d'un tableau en une chaîne ?
Réponseimplode(' ', $tab) — le séparateur en premier argument.
QuestionQu’est-ce que « tableau indexé » ?
RéponseDéfinition. Un tableau indexé range des valeurs numérotées à partir de 0 . L'écriture $tab[] = valeur ajoute en fin de tableau en attribuant l'indice suivant automatiquement.
QuestionQu’est-ce que « count() » ?
Réponsearray_sum additionne tous les éléments d’un tableau ; count en donne la taille. Une boucle classique fait aussi l’affaire.
QuestionQu’est-ce que « array_sum / max » ?
Réponsearray_sum / max : calculer somme, moyenne et maximum en un parcours ;
QuestionQu’est-ce que « tri par sélection » ?
RéponsePHP propose sort() , mais les examens demandent d'implémenter le tri : le tri par sélection est le plus simple. À chaque tour, on cherche le minimum de la partie non triée et on l'échange avec la première position libre.

Module 6 — Fonctions

QuestionDéclarer une fonction PHP ?
Réponsefunction nom($param) { ... return $valeur; } — le nom ne porte pas de $.
QuestionRenvoyer plusieurs valeurs ?
RéponseUn tableau : return [$a, $b];, reçu par décomposition [$x, $y] = f();.
QuestionPortée d'une variable déclarée dans une fonction ?
RéponseLocale à la fonction : toute information entre par les paramètres et sort par le return.
QuestionQue se passe-t-il sans return ?
RéponseLa fonction renvoie null : l'appelant ne peut rien exploiter.
QuestionQu’est-ce que « tableau de retour » ?
Réponsetableau de retour : faire renvoyer plusieurs valeurs via un tableau ;
QuestionQu’est-ce que « réutilisation » ?
Réponseréutilisation : PHP B1 › Sommaire › Chapitre 6

Module 7 — Tableaux associatifs

QuestionDéclarer un tableau associatif ?
Réponse['cle' => valeur, 'autre' => valeur] — la flèche relie la clé à sa valeur.
QuestionParcourir clé et valeur ensemble ?
Réponseforeach ($tab as $cle => $valeur).
QuestionTester l'existence d'une clé ?
Réponseisset($tab[$cle]) — indispensable avant d'incrémenter un compteur.
QuestionÀ quoi servent les tableaux associatifs côté PDO ?
RéponseChaque ligne de résultat arrive sous forme colonne → valeur : c'est le même outil.
QuestionQu’est-ce que « compteur d'occurrences » ?
Réponseconstruire les schémas classiques : compteur d'occurrences, maximum par clé.
QuestionQu’est-ce que « fusion » ?
RéponseSchémas classiques : compteur d'occurrences, maximum par clé, fusion.

Module 8 — Formulaires, sessions et PDO

QuestionPourquoi les requêtes préparées ?
RéponseLa valeur passe par un paramètre, jamais concaténée au SQL : les injections deviennent impossibles.
QuestionQue fait $stmt->execute([$v]) ?
RéponseElle exécute la requête préparée en remplaçant le ? par la valeur fournie.
QuestionComment PDO présente-t-il chaque ligne de résultat ?
RéponseUn tableau associatif colonne → valeur, parcouru avec foreach.
QuestionÀ quoi sert htmlspecialchars avant d'afficher ?
RéponseÀ neutraliser le HTML d'une donnée externe : la protection contre les injections XSS.
QuestionQu’est-ce que « $_POST » ?
RéponseVoici la chaîne complète d'un site dynamique : un visiteur soumet un formulaire, PHP reçoit et valide les données, les enregistre dans MySQL, puis affiche les pages en reprenant les données de la session. Ce chapitre assemble tout le cours autour de trois outils : $_POST , $_SESS
QuestionQu’est-ce que « session_start » ?
RéponseHTTP oublie tout entre deux requêtes. La session donne au site une mémoire par visiteur : le panier, le login, le compteur de pages vues. Tout passe par le tableau $_SESSION , disponible après session_start() .
QuestionQu’est-ce que « PDO / DSN » ?
RéponsePDO / DSN : Voici la chaîne complète d'un site dynamique : un visiteur soumet un formulaire, PHP reçoit et valide les données, les enregistre dans MySQL, puis affiche les pages en reprenant les données de la session. Ce chapitre assemble tout le cours autour de trois outils : $_POST , $_SESS
QuestionQu’est-ce que « foreach sur résultats » ?
Réponseforeach sur résultats : exécuter SELECT et INSERT avec des requêtes préparées et parcourir les résultats.
