Chapitre 1 — Premiers pas en PHP

Module 1 ≈ 2 h 30 de travail Accès libre
Mise en situation

Un visiteur remplit un formulaire d'inscription : quelqu'un doit recevoir ses données, les vérifier et enregistrer son compte. Ce « quelqu'un », c'est un script PHP qui tourne sur le serveur. Avant les formulaires et les bases de données, il faut savoir écrire ce script — même minimal — et comprendre où il s'exécute.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. expliquer où s'exécute PHP et à quoi sert le mode CLI ;
  2. écrire le squelette d'un script avec sa balise d'ouverture ;
  3. déclarer des variables, afficher avec echo ;
  4. lire l'entrée standard avec fgets(STDIN) et trim().

1. PHP, où et comment il tourne

Définition. PHP (PHP: Hypertext Preprocessor) est un langage interprété conçu pour générer des pages Web côté serveur. Le navigateur ne reçoit jamais le code PHP : il en reçoit le résultat (du HTML), calculé sur le serveur.

ModeRôleExemple
Serveur Web (module / FPM)Répondre aux requêtes HTTP, générer des pagesUn site de boutique en ligne
CLI (ligne de commande)Exécuter un script dans le terminalUn script de maintenance, les TP du cours

Dans ce cours, les exercices tournent en CLI : le script lit ses données sur l'entrée standard et affiche son résultat dans la console. La logique est identique au mode Web — seuls l'entrée et la sortie changent de canal.

Le même PHP partout

Le fichier du script porte l'extension .php et l'interpréteur est invoqué avec php monscript.php. Les fonctions que tu apprends ici — variables, conditions, tableaux, fonctions — sont exactement celles d'un site en production.

2. Le squelette d'un script

Tout script PHP commence par la balise d'ouverture <?php. Le code qui suit est interprété ; le reste du fichier (hors balise) serait renvoyé tel quel. Un script purement PHP se termine sans balise de fermeture.

<?php

// ceci est du code PHP
echo "Premier script\n";
Premier script

echo envoie du texte vers la sortie. La séquence \n (dans des guillemets doubles) produit un saut de ligne : sans elle, tout s'empile sur une même ligne.

Piège — guillemets doubles ou simples

Dans des guillemets doubles, une variable est remplacée par sa valeur : echo "Bonjour $nom" affiche le nom. Dans des guillemets simples, rien n'est interpolé : echo 'Bonjour $nom' affiche littéralement « Bonjour $nom ».

3. Variables : le dollar obligatoire

Définition. Une variable est un nom qui désigne une valeur en mémoire. En PHP, tout nom de variable commence par $, on ne la déclare pas à l'avance : sa première affectation la crée.

$article = "Clavier";
$prix = 29;
$total = $prix * 3;

echo "$article : $total EUR\n";
Clavier : 87 EUR

À droite du =, une expression est calculée ; le résultat est rangé dans la variable à gauche. Le point-virgule termine chaque instruction — l'oublier est l'erreur de syntaxe la plus fréquente.

4. Lire l'entrée standard

En CLI, le script reçoit ses données sur l'entrée standard (STDIN). La fonction fgets(STDIN) lit une ligne, saut de ligne compris : on la nettoie avec trim(), puis on la convertit en entier avec (int) quand on attend un nombre.

Trame de lecture
$texte = trim(fgets(STDIN));  // une ligne, sans \n
$nombre = (int)trim(fgets(STDIN));  // converti en entier
$nom = trim(fgets(STDIN));
$age = (int)trim(fgets(STDIN));

echo "$nom a $age ans\n";

Chaque appel à fgets lit la ligne suivante : l'ordre des lectures doit suivre l'ordre des données. Dans les exercices de ce cours, une valeur = une ligne.

Intuition

Un script en trois temps : lire les données, calculer, puis afficher. Toute la suite du cours approfondit l'un de ces trois temps, jamais autre chose.

5. Premier programme complet

Un client achète 3 articles à 12 EUR. Le programme lit le prix unitaire et la quantité, puis affiche le total :

<?php
$prix = (int)trim(fgets(STDIN));
$quantite = (int)trim(fgets(STDIN));

$total = $prix * $quantite;
echo "Total : $total EUR\n";
Total : 36 EUR

6. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Bonjour la promotion

PHP Niveau 1 — Acquisition

Objectif : Lire une entrée sur STDIN et afficher avec echo.

Le programme reçoit un prénom (sans espace) sur l’entrée standard. Affichez Bonjour <prénom> ! suivi d’un saut de ligne.

Entrée du programme
Alice
Sortie attendue
Bonjour Alice !

Le prénom est inséré dans le message.

Deux indices, rédigés en mots
  1. fgets(STDIN) lit une ligne du clavier ou du tube d’entrée ; trim retire le saut de ligne qui l’accompagne.
  2. Entre guillemets doubles, une variable est remplacée par sa valeur : c’est l’interpolation.

  2. Deux echo, chacun terminé par le saut de ligne.

Exercice 3 — Total de commande

PHP Niveau 2 — Application

Objectif : Calculer à partir des entrées puis afficher le résultat.

Le programme reçoit le prix unitaire d’un article (entier), puis la quantité commandée (entier). Affichez Total : <prix × quantité> EUR.

Deux indices, rédigés en mots
  1. Le total d’une commande est le produit du prix par la quantité.

7. QCM — niveau examen

Quelle balise ouvre un bloc de code PHP ?

Tout code PHP suit la balise <?php.

Comment reconnaît-on une variable en PHP ?

$nom, $total : le dollar préfixe toute variable.

Que lit fgets(STDIN) ?

Une ligne par appel : d'où le trim qui suit.

Pourquoi trim() après fgets ?

Le \n final ferait échouer les comparaisons.

Que fait (int) devant une expression ?

C'est un cast : (int)"42" vaut l'entier 42.

Que produit echo 'Total : $total' (guillemets simples) ?

Pas d'interpolation entre guillemets simples.

8. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Point-virgule oublié : l'erreur est signalée à la ligne suivante, pas à la fautive.
  • $ oublié : nom = "A" n'est pas une affectation PHP.
  • trim oublié : la comparaison de la valeur lue échoue sans bruit.
  • Ordre des lectures inversé : chaque fgets consomme la ligne suivante.
  • \n manquant : les affichages s'empilent sur une seule ligne.

9. Méthodologie de résolution

Écrire un premier script
  1. Lister les données d'entrée : une ligne par valeur, dans l'ordre de l'énoncé.
  2. Choisir les variables : noms explicites ($prix, pas $x).
  3. Écrire le calcul dans une variable intermédiaire si besoin.
  4. Afficher exactement le format demandé (texte, espaces, sauts de ligne).
  5. Tester avec l'exemple de l'énoncé, puis une valeur limite.

10. Révision active

Résumé essentiel
  • PHP tourne côté serveur ; en CLI, le script lit STDIN et écrit dans la console.
  • Tout script commence par <?php ; chaque instruction finit par ;.
  • Une variable commence par $ et naît de sa première affectation.
  • echo affiche ; l'interpolation n'a lieu qu'entre guillemets doubles.
  • Lire une entrée : trim(fgets(STDIN)), avec (int) si c'est un nombre.

Checklist de maîtrise

  • J'écris le squelette d'un script sans modèle.
  • Je lis une entrée proprement (trim, cast).
  • Je choisis guillemets doubles ou simples en connaissance de cause.
  • Je trace un petit programme instruction par instruction.
