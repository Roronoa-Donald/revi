Chapitre 2 — Types, opérateurs et chaînes

Module 2 ≈ 3 h de travail B1 et plus
Mise en situation

Un panier contient 3 articles à 19.99 EUR. Le total affiché est « 59 EUR » au lieu de « 59.97 EUR », et une référence tapée « CLAVIER » ne correspond plus au produit « clavier ». Derrière ces deux bugs : des types mal gérés. Ce chapitre fixe les règles de conversion, de calcul et de manipulation du texte.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. citer les quatre types de base et convertir avec les casts ;
  2. calculer avec les opérateurs arithmétiques, dont intdiv et % ;
  3. formater un nombre à deux décimales avec number_format ;
  4. manipuler les chaînes : longueur, casse, découpage, concaténation.

1. Les quatre types de base

Définition. Le type d'une valeur détermine les opérations qui ont du sens dessus. PHP déduit le type à l'affectation (typage dynamique) : c'est au programmeur de rester cohérent.

TypeExemplesUsages typiques
int (entier)42, -7, 0Quantités, comptages, indices
float (flottant)19.99, -0.5Prix, moyennes, mesures
string (chaîne)"PHP", 'a'Noms, messages, saisies
bool (booléen)true, falseRésultats de tests, drapeaux

La conversion se demande explicitement par un cast : (int)"42" vaut 42, (int)"3.9" vaut 3 (troncature), (string)42 vaut "42", (float)"2" vaut 2.0.

Piège — tout ce qui arrive est une chaîne

fgets(STDIN) renvoie une chaîne. Calculer dessus sans cast produit des résultats imprévisibles : PHP peut convertir à la volée, mais pas toujours dans le sens attendu. La règle du cours : convertir à la lecture, une fois pour toutes.

2. Opérateurs arithmétiques

OpérationPHPExempleRésultat

Division entièreintdiv(a, b)intdiv(10, 4)2

La division PHP avec / est décimale dès que le résultat n'est pas rond : 10 / 2 donne l'entier 5, mais 10 / 4 donne le flottant 2.5. Pour un quotient entier, employer intdiv(). L'identité classique relie les trois : a = b × intdiv(a, b) + a % b.

À quoi sert le modulo ?

Dire si un nombre est pair ($n % 2 == 0), extraire les unités d'un montant, répartir des personnes en groupes de taille fixe, faire tourner un compteur circulaire : le reste de division est partout. En PHP, % sur des entiers se comporte comme en mathématiques pour les valeurs positives.

3. Formater un nombre

Les moyennes et les prix exigent un nombre fixé de décimales. number_format($x, 2, '.', '') renvoie une chaîne : deux décimales, point décimal, aucun séparateur de milliers — le format attendu par les sorties de ce cours et par les corrections automatiques.

$moyenne = (12 + 15 + 14) / 3;
echo number_format($moyenne, 2, '.', '') . "\n";   // 13.67

$prix = 2.5;
echo number_format($prix, 2, '.', '') . "\n";      // 2.50

4. Les chaînes : l'outil de tous les jours

Définition. Une chaîne est une suite de caractères. PHP fournit des dizaines de fonctions natives ; le cours en fixe un socle :

FonctionRôleExemple

substr($s, $d, $l)Extrairesubstr("PHP", 0, 2) → "PH"

La concaténation utilise le point : "Bonjour " . $nom. L'interpolation dans les guillemets doubles la remplace quand le texte est simple ; le point reste indispensable autour des appels de fonctions.

Chaîne immuable

Aucune fonction de chaîne ne modifie l'original : strtoupper($mot) renvoie une copie. Pour conserver le résultat, le ranger : $mot = strtoupper($mot);.

6. QCM — niveau examen

Que vaut (int)"3.9" ?

Le cast en int tronque : seule la partie entière reste.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Calcul sur chaîne non convertie : toujours caster à la lecture.
  • Confondre / et intdiv() : 10 / 4 vaut 2.5, pas 2.
  • Format au mauvais endroit : number_format s'applique à l'affichage, pas au calcul.
  • Ignorer le retour d'une fonction de chaîne : strtoupper($mot) seul ne change rien.
  • explode avec le mauvais séparateur : vérifier l'espace exact de l'énoncé.

8. Méthodologie de résolution

Calculer et afficher proprement
  1. Convertir toutes les entrées numériques dès la lecture : (int) ou (float).
  2. Calculer avec le bon opérateur : intdiv pour partager, % pour le reste, / pour la moyenne.
  3. Formater à l'affichage : number_format pour les décimales.
  4. Assembler le message : interpolation simple, point autour des fonctions.
  5. Vérifier le format attendu caractère par caractère (espaces, points, sauts de ligne).

9. Révision active

Résumé essentiel
  • Quatre types de base : int, float, string, bool — conversions par cast.
  • / est décimal ; intdiv() et % donnent quotient entier et reste.
  • number_format fixe décimales et séparateurs au moment d'afficher.
  • Le point concatène ; les fonctions de chaîne renvoient des copies.
  • fgets renvoie une chaîne : convertir avant de calculer.

Checklist de maîtrise

  • Je convertis mes entrées au bon type sans y penser.
  • Je choisis entre /, intdiv et % selon le besoin.
  • Je formate une moyenne à deux décimales.
  • Je me sers du socle de fonctions de chaîne de mémoire.
