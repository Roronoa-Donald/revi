Chapitre 4 — Boucles

Module 4 ≈ 3 h de travail B1 et plus
Mise en situation

Afficher une table de multiplication, additionner cent notes, compter à rebours avant un lancement : répéter la même action vingt fois en la copiant-collant serait absurde. La boucle répète un bloc d'instructions autant de fois que nécessaire — c'est la deuxième structure de contrôle, et celle qui donne au programme sa puissance.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. écrire une boucle for avec ses trois parties, à pas positif ou négatif ;
  2. choisir while quand le nombre de tours est inconnu ;
  3. utiliser un accumulateur (somme, produit) initialisé au bon endroit ;
  4. imbriquer deux boucles et prédire le nombre total de tours.

1. La boucle for : trois parties

Définition. La boucle for rassemble sur une ligne tout ce qui gouverne la répétition : l'initialisation (une fois), la condition de poursuite (testée avant chaque tour), le pas (exécuté après chaque tour).

for ($i = 1; $i <= 5; $i++) {
    echo $i . "\n";
}

La boucle s'exécute donc tant que la condition est vraie : quand $i atteint 6, elle s'arrête sans afficher. Cinq tours pour $i = 1; $i <= 5.

Piège — la borne de fin

$i < 5 fait quatre tours (1, 2, 3, 4) ; $i <= 5 en fait cinq. L'énoncé « de 1 à 5 » se traduit par <= 5. Une borne fausse décale tout le résultat d'une unité : c'est l'erreur la plus fréquente sur les boucles.

2. Pas négatif : compter à rebours

Le pas peut diminuer la variable : la boucle descend tant que la condition de borne basse reste vraie.

for ($i = 3; $i >= 1; $i--) {
    echo $i . "\n";
}
echo "Decollage\n";
3 2 1 Decollage

Les trois parties suivent la logique inverse : initialisation en haut, condition de borne basse, pas négatif. Oublier de retourner la condition (>= au lieu de <=) produit une boucle infinie.

3. L'accumulateur

Définition. Un accumulateur est une variable qui se met à jour à chaque tour pour construire un résultat : une somme, un produit, un comptage.

$somme = 0;                    // élément neutre de l'addition
for ($i = 1; $i <= $n; $i++) {
    $somme += $i;
}
echo $somme . "\n";

Pour un produit, l'élément neutre change : $produit = 1; — initialiser à zéro annulerait tout (0 × quoi que ce soit = 0). Chaque puissance de deux, par exemple, est le double de la précédente : une seule multiplication par tour.

$puissance = 1;
for ($i = 1; $i <= $n; $i++) {
    $puissance *= 2;
    echo $puissance . "\n";
}
Où initialiser ?

Avant la boucle, toujours. Initialisée dans le corps, l'accumulateur repart de sa valeur initiale à chaque tour : la somme vaudrait n à la fin (le dernier terme seul), pas la somme des termes.

4. while : quand on ne sait pas combien de tours

La boucle while teste avant chaque tour et s'arrête quand la condition devient fausse. Elle convient quand le nombre d'itérations dépend des données, pas d'un compteur fixe.

$somme = 0;
while ($somme < $seuil) {
    $somme += $valeurSuivante;
}

Un while peut ne pas s'exécuter du tout (condition fausse dès le départ). Les trois règles d'une boucle while saine : une initialisation avant, une progression dans le corps vers l'arrêt, une condition qui finit par être fausse. Manquer la progression donne la boucle infinie : le programme tourne sans fin et doit être interrompu.

Boucles imbriquées

Une boucle dans une boucle multiplie les tours : 4 × 3 = 12 tours pour for externe de 4 et interne de 3. La boucle interne finit entièrement chaque tour de l'externe. C'est la structure de base du parcours des tableaux à deux dimensions (module 8 du cours d'algorithmique) et des affichages en grille.

Dans la boucle, il repart de zéro à chaque tour.

Multiplier par zéro efface tout : 1 est l'élément neutre.

Sans progression, la condition reste vraie indéfiniment.

Les tours se multiplient : 4 × 3 = 12.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Borne < au lieu de <= : un tour manquant, résultat décalé.
  • A accumulateur initialisé dans la boucle : seul le dernier terme reste.
  • Produit initialisé à 0 : résultat nul quelle que soit la donnée.
  • Pas négatif sans condition retournée : boucle infinie.
  • Compteur modifié dans le corps d'un for : double avancement imprévisible.

8. Méthodologie de résolution

Écrire une boucle juste
  1. Identifer le type : nombre de tours connu (for) ou dépendant des données (while).
  2. Poser la première et la dernière valeur du compteur, choisir la condition en conséquence.
  3. Initialiser les accumulateurs avant la boucle, avec le bon élément neutre.
  4. Tracer les deux premiers tours et le dernier à la main pour vérifier les bornes.
  5. Tester les cas limites : n = 0 (aucun tour), n = 1 (un seul tour).

9. Révision active

Résumé essentiel
  • for : initialisation ; condition de poursuite ; pas — sur une ligne.
  • « de 1 à n » se traduit $i <= $n ; « strictement avant » par <.
  • Pas négatif : initialisation haute, condition >=, $i--.
  • Accumulateur : initialisé avant la boucle, neutre de l'opération (0 somme, 1 produit).
  • while : nombre de tours inconnu ; trois règles pour garantir l'arrêt.

Checklist de maîtrise

  • J'écris une boucle for à pas positif et négatif sans modèle.
  • Je place mes accumulateurs et leurs valeurs neutres.
  • Je prédis le nombre de tours d'une boucle imbriquée.
  • Je diagnostique une boucle infinie avec les trois règles.
