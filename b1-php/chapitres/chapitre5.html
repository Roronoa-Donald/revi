Chapitre 5 — Tableaux indexés

Module 5 ≈ 3 h de travail B1 et plus
Mise en situation

Calculer la moyenne d'une classe, c'est additionner trente notes : on ne déclare pas trente variables. Un tableau range plusieurs valeurs sous un seul nom, numérotées par un indice — la structure de données de base de tous les programmes de ce cours, et le socle des résultats PDO du module 8.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. créer un tableau, y ajouter des éléments, accéder par indice ;
  2. parcourir un tableau avec foreach et avec for ;
  3. calculer somme, moyenne et maximum en un parcours ;
  4. rechercher une valeur et trier sans sort().

1. Créer et remplir un tableau

Définition. Un tableau indexé range des valeurs numérotées à partir de 0. L'écriture $tab[] = valeur ajoute en fin de tableau en attribuant l'indice suivant automatiquement.

$notes = [];              // tableau vide
$notes[] = 12;            // indice 0
$notes[] = 15;            // indice 1
$notes[] = 14;            // indice 2

echo $notes[1] . "\n";    // 15
echo count($notes) . "\n"; // 3 : le nombre d'éléments

Remplir depuis l'entrée standard suit toujours la même trame : lire n, puis boucler n fois.

$n = (int)trim(fgets(STDIN));
$notes = [];
for ($i = 0; $i < $n; $i++) {
    $notes[] = (int)trim(fgets(STDIN));
}
Piège — le dernier indice

Un tableau de n éléments va de l'indice 0 à l'indice n − 1. Boucler jusqu'à $i <= $n lit au-delà du dernier élément : PHP le signale par un avertissement « Undefined array key » et le calcul est faux.

2. Parcourir : foreach et for

Deux parcours cohabitent. foreach visite chaque valeur sans se soucier des indices — le choix par défaut. for donne l'indice, utile quand la position compte.

// parcours par valeur
foreach ($notes as $note) {
    echo $note . "\n";
}

// parcours par indice (positions numérotées à partir de 1)
for ($i = 0; $i < count($notes); $i++) {
    echo ($i + 1) . " : " . $notes[$i] . "\n";
}

3. Somme, moyenne et maximum en un parcours

Un seul parcours suffit à accumuler la somme et à traquer le maximum : partir du premier élément, puis remplacer le candidat dès qu'un élément le dépasse.

$somme = 0;
$maximum = $notes[0];
foreach ($notes as $note) {
    $somme += $note;
    if ($note > $maximum) {
        $maximum = $note;
    }
}
$moyenne = $somme / count($notes);
Pourquoi partir du premier élément ?

Initialiser le maximum à 0 échoue sur un tableau de valeurs négatives (le maximum resterait 0 alors qu'aucun élément ne l'atteint). Le premier élément est toujours un candidat valide. Les fonctions array_sum() et max() existent en PHP — mais savoir écrire le parcours à la main reste exigé : c'est le même schéma que tous les algorithmes du cours.

4. Rechercher une valeur

array_search($cible, $tableau, true) renvoie la clé de la première occurrence, ou false si la valeur est absente. Deux précautions : comparer le résultat avec === (l'indice 0 existe et se confondrait avec false), et convertir la clé en position si l'énoncé numérote à partir de 1.

$cle = array_search($cible, $notes, true);
if ($cle === false) {
    echo "absent\n";
} else {
    echo ($cle + 1) . "\n";
}

La recherche séquentielle à la main suit le même principe avec une boucle : parcourir depuis le début, s'arrêter à la première occurrence.

5. Trier sans sort()

PHP propose sort(), mais les examens demandent d'implémenter le tri : le tri par sélection est le plus simple. À chaque tour, on cherche le minimum de la partie non triée et on l'échange avec la première position libre.

for ($debut = 0; $debut < $n - 1; $debut++) {
    $indiceMin = $debut;
    for ($i = $debut + 1; $i < $n; $i++) {
        if ($tableau[$i] < $tableau[$indiceMin]) {
            $indiceMin = $i;
        }
    }
    // échange des deux éléments
    $temporaire = $tableau[$debut];
    $tableau[$debut] = $tableau[$indiceMin];
    $tableau[$indiceMin] = $temporaire;
}

La partie triée grandit depuis le début ; l'échange passe par une variable temporaire (ou l'affectation simultanée [$a, $b] = [$b, $a]). Afficher le tableau trié en une ligne : echo implode(' ', $tableau) . "\n";

Exercice 1 — Somme et moyenne des notes

PHP Niveau 3 — Raisonnement

Objectif : Remplir un tableau puis le parcourir.

Le programme reçoit un entier n, puis n notes entières (une par ligne). Affichez Somme : <total> puis Moyenne : <moyenne à deux décimales>.

Entrée du programme
4
12
15
14
19
Sortie attendue
Somme : 60
Moyenne : 15.00

Total 60, moyenne 60 / 4 = 15.00.

Deux indices, rédigés en mots
  1. array_sum additionne tous les éléments d’un tableau ; count en donne la taille. Une boucle classique fait aussi l’affaire.
  2. La moyenne doit rester décimale : formatez-la au moment de l’affichage.

Exercice 2 — Recherche dans un tableau

PHP Niveau 3 — Raisonnement

Objectif : Chercher une valeur et communiquer sa position.

Le programme reçoit un entier n, puis n entiers, puis une valeur cible. Affichez la position de la première occurrence de la cible (positions numérotées à partir de 1), ou absent.

Entrée du programme
5
10
20
30
20
50
20
Sortie attendue
2

La première occurrence de 20 est à la position 2.

Deux indices, rédigés en mots
  1. array_search renvoie la clé de la première occurrence, mais la numérotation du tableau commence à zéro.
  2. Quand la valeur ne figure pas, array_search renvoie false : prévoyez ce cas avant d’afficher.

Exercice 3 — Trier sans sort()

PHP Niveau 4 — Examen

Objectif : Implémenter un tri à la main, interdiction des fonctions de tri.

Le programme reçoit un entier n, puis n entiers. Triez-les par sélection (chercher le minimum de la partie non triée et l’échanger), sans sort(), usort() ni autre fonction de tri. Affichez les valeurs triées sur une ligne, séparées par des espaces.

Entrée du programme
5
5
2
8
1
9
Sortie attendue
1 2 5 8 9

Tri croissant complet.

Deux indices, rédigés en mots
  1. La partie triée grandit depuis le début : à chaque tour, repérez le minimum de ce qui reste et échangez-le avec la première position libre.
  2. Un échange en PHP passe par une variable temporaire (ou par list($a, $b) = [$b, $a]).

7. QCM — niveau examen

Quel est le premier indice d'un tableau PHP ?

Les indices numériques partent de 0.

L'indice vide attribue le prochain emplacement libre.

De 0 à n − 1 : boucler jusqu'à n sort du tableau.

La partie triée grandit depuis le début du tableau.

8. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Boucle jusqu'à n inclus : lecture au-delà du tableau, « Undefined array key ».
  • array_search comparé avec == : l'indice 0 se confond avec false.
  • Maximum initialisé à 0 : faux sur des valeurs négatives.
  • Échange sans temporaire : une valeur écrasée avant d'être déplacée.
  • foreach avec indice : foreach ne donne pas la position ; utiliser for.

9. Méthodologie de résolution

Travailler sur un tableau
  1. Lire n puis remplir dans une boucle stricte de n tours.
  2. Choisir le parcours : foreach pour les valeurs, for quand la position compte.
  3. Initialiser maximum/minimum au premier élément, jamais à 0.
  4. Tester les cas limites : un seul élément, valeurs égales, valeurs négatives.
  5. Afficher au format demandé : implode pour une ligne de valeurs séparées.
