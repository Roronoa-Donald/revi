Chapitre 6 — Fonctions

Module 6 ≈ 3 h de travail B1 et plus
Mise en situation

Dans un programme de gestion de notes, la moyenne se calcule à dix endroits différents. La recopier dix fois, c'est corriger dix endroits le jour où le barème change. La fonction isole un calcul sous un nom et le réutilise partout : c'est la brique de la décomposition, et le passage obligé vers un code maintenable.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. déclarer une fonction PHP avec ses paramètres ;
  2. renvoyer un résultat avec return et distinguer return de echo ;
  3. faire renvoyer plusieurs valeurs via un tableau ;
  4. décomposer un problème en fonctions à responsabilité unique.

1. Déclarer et appeler

Définition. Une fonction regroupe des instructions sous un nom, reçoit des données par ses paramètres et renvoie un résultat à son appelant. Le nom d'une fonction ne porte pas de $ — contrairement aux variables.

function carte($nom)
{
    return "Bienvenue $nom";
}

// appel : le nom, les arguments entre parenthèses
echo carte("Alice") . "\n";   // Bienvenue Alice

La déclaration exécute rien : le corps ne tourne que lors d'un appel. PHP n'exige pas de déclarer le type des paramètres en B1 ; les noms des paramètres sont des variables locales à la fonction.

2. return : transmettre, pas afficher

return transmet la valeur à l'appelant et termine immédiatement la fonction : aucune instruction après un return atteint ne s'exécute. C'est le canal officiel de sortie d'une fonction.

function ticket($age)
{
    if ($age < 12 || $age >= 65) {
        return 0;      // la fonction se termine ici
    }
    if ($age <= 17) {
        return 5;
    }
    return 8;
}

$prix = ticket(30);   // $prix vaut 8
Piège — echo n'est pas return

Une fonction qui affiche son résultat mais ne le renvoie pas renvoie en réalité null : l'appelant ne peut rien en faire — ni l'additionner, ni le comparer, ni l'embarquer dans un message. Renvoyer et afficher sont deux actes différents : la fonction renvoie, le programme principal affiche.

3. Renvoyer plusieurs valeurs

Une fonction ne renvoie qu'une seule chose. Pour deux résultats (moyenne et maximum, par exemple), on les regroupe dans un tableau, reçu côté appelant par décomposition :

function stats($notes)
{
    $somme = 0;
    $max = $notes[0];
    foreach ($notes as $note) {
        $somme += $note;
        if ($note > $max) {
            $max = $note;
        }
    }
    return [$somme / count($notes), $max];
}

[$moyenne, $maximum] = stats($notes);

Le couple est construit dans un seul parcours : la fonction garde sa responsabilité unique (« statistiques ») et l'appelant reçoit les deux valeurs en une instruction.

4. Portée des variables

TypePortée
Variable localeSeulement dans la fonction où elle est créée.
ParamètreComme une locale de la fonction.
Variable globaleDéclarée hors fonction : invisible dedans (en PHP), et à éviter.

En PHP, une fonction ne voit pas les variables extérieures : c'est une contrainte salutaire. La règle du cours : toute information entre par les paramètres, toute information sort par le return. Une fonction ainsi écrite se teste isolément et se réutilise partout.

Le paramètre reçoit une copie

Passer un entier ou une chaîne transmet une copie : modifier le paramètre dans la fonction ne change pas la variable de l'appelant. Pour renvoyer un résultat, utiliser return — pas une modification de paramètre.

5. Décomposer un problème

La bonne question : « quelles sont les responsabilités de mon programme ? » Chacune devient une fonction d'une seule responsabilité, testable séparément. Le programme principal se réduit alors à la lecture, aux appels et aux affichages.

function somme($t)
{
    $total = 0;
    foreach ($t as $v) {
        $total += $v;
    }
    return $total;
}

function moyenne($t)
{
    if (count($t) === 0) {
        return 0;
    }
    return somme($t) / count($t);   // réutilisation
}

moyenne appelle somme : une fonction bien découpée se réutilise dans les autres. C'est le critère de notation des projets : une fonction = une responsabilité = un test facile.

6. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

Exercice 1 — Une fonction de bienvenue

PHP Niveau 3 — Raisonnement

Objectif : Déclarer une fonction qui renvoie une valeur.

Écrivez une fonction carte($nom) qui renvoie le message Bienvenue <nom>. Le programme lit un nom, appelle la fonction et affiche son résultat.

Entrée du programme
Alice
Sortie attendue
Bienvenue Alice

La fonction assemble le message et le renvoie.

Deux indices, rédigés en mots
  1. Une fonction PHP se déclare avec function, son nom et ses paramètres entre parenthèses.
  2. return transmet la valeur à l’appelant : echo dans la fonction ne suffit pas, la valeur doit sortir.

Exercice 2 — Fonction tarif

PHP Niveau 4 — Examen

Objectif : Écrire une fonction à branches qui renvoie un calcul.

Écrivez une fonction ticket($age) qui renvoie le prix d’entrée : 0 si l’âge est inférieur à 12 ou à partir de 65, 5 entre 12 et 17 inclus, sinon 8. Le programme lit un âge et affiche le prix renvoyé.

Entrée du programme
12
Sortie attendue
5

Entre 12 et 17 : tarif à 5.

Deux indices, rédigés en mots
  1. La fonction contient la cascade de conditions ; le programme principal se limite à lire et afficher.
  2. Chaque branche renvoie son prix : dès que return s’exécute, la fonction se termine.

Entrée du programme

8. Erreurs classiques — récapitulatif

À reconnaître en examen
  • echo au lieu de return : l'appelant reçoit null.
  • Oublier le return dans une branche de la fonction.
  • $ au nom de la fonction : function $f() est une erreur de syntaxe.
  • Modifier un paramètre en croyant modifier l'appelant (copie).
  • Une fonction qui fait tout : lecture, calcul, affichage mélangés.

9. Méthodologie de résolution

Concevoir une fonction
  1. Nommer par un verbe d'action : calculerMoyenne, ticket.
  2. Lister les entrées : ce sont les paramètres.
  3. Déterminer la sortie : la valeur renvoyée.
  4. Écrire le corps : une seule responsabilité, sans lecture ni affichage.
  5. Tester depuis le programme principal sur des cas limites.

10. Révision active

Résumé essentiel
  • function nom($params) { ... return $valeur; } — le nom sans $.
  • return transmet et termine ; echo n'affiche que.
  • Plusieurs résultats : un tableau, reçu par décomposition.
  • Portée locale : entrées par paramètres, sorties par return.
  • Décomposition : fonctions à responsabilité unique, réutilisables entre elles.

Checklist de maîtrise

  • Je déclare une fonction avec return sans modèle.
  • Je distingue return et echo en toutes circonstances.
  • Je renvoie un couple de valeurs proprement.
  • Je découpe un problème en fonctions testables.
