Chapitre 7 — Tableaux associatifs

Module 7 ≈ 3 h de travail B1 et plus
Mise en situation

Un stock se décrit par des noms : « claviers : 12 », « souris : 8 ». Chercher la quantité par un numéro d'indice serait absurde — on la cherche par le nom. Le tableau associatif range des valeurs accessibles par une clé quelconque : c'est aussi la forme exacte sous laquelle PDO rend chaque ligne de résultat MySQL (colonne → valeur).

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. déclarer un tableau associatif et accéder à une valeur par sa clé ;
  2. parcourir clé et valeur ensemble avec foreach ;
  3. tester l'existence d'une clé avec isset() ;
  4. construire les schémas classiques : compteur d'occurrences, maximum par clé.

1. Clé → valeur

Définition. Un tableau associatif associe à chaque clé une valeur. La flèche => relie la clé à sa valeur ; la clé peut être une chaîne ou un entier.

$stock = [
    'claviers' => 12,
    'souris' => 8
];

$stock['ecrans'] = 5;          // ajout / modification
echo $stock['souris'] . "\n";  // 8
echo count($stock) . "\n";     // 3 : nombre de clés

Une écriture à une clé inexistante crée l'entrée ; une lecture d'une clé inexistante déclenche un avertissement « Undefined array key » et rend null. D'où le réflexe du chapitre : toujours tester avant de lire.

if (isset($stock[$ref])) {
    echo $stock[$ref] . "\n";
} else {
    echo "Reference inconnue\n";
}

2. Parcourir clé et valeur

Le foreach du chapitre 5 se complète : la forme $tab as $cle => $valeur donne les deux à chaque tour.

foreach ($stock as $nom => $quantite) {
    echo "$nom : $quantite\n";
}
claviers : 12 souris : 8 ecrans : 5

La forme simple foreach ($stock as $quantite) reste valable quand la clé n'intéresse pas — pour un total, par exemple.

3. Le schéma du compteur d'occurrences

Compter combien de fois chaque mot apparaît : le tableau associatif est l'outil naturel. La clé est le mot, la valeur son nombre d'apparitions.

$compteur = [];
foreach ($mots as $mot) {
    if (!isset($compteur[$mot])) {
        $compteur[$mot] = 0;    // première apparition
    }
    $compteur[$mot]++;
}

Le isset est indispensable : incrémenter une clé inexistante ($compteur[$mot]++ sur null) fonctionne en PHP mais déclenche un avertissement, et masque la logique. Créer la case à zéro explicitement documente l'intention.

Intuition : l'annuaire

Un tableau indexé est une étagère : on cherche par numéro de case. Un tableau associatif est un annuaire : on cherche par nom, et le nom donne la valeur directement — sans connaître une position.

4. Le maximum par clé

Chercher la référence la plus stockée, le mot le plus fréquent, la personne la plus âgée : même schéma — garder le meilleur couple (clé, valeur) vu jusqu'ici.

$refMax = '';
$max = 0;
foreach ($stock as $nom => $quantite) {
    if ($quantite > $max) {
        $max = $quantite;
        $refMax = $nom;
    }
}
echo "$refMax ($max)\n";

La comparaison stricte (>) garantit qu'en cas d'égalité, le premier atteint garde la place — comportement exigé par la plupart des énoncés.

5. Fusionner deux inventaires

Réunir deux stocks, deux commandes, deux comptages : parcourir le second et l'ajouter au premier, clé par clé.

function fusionner($a, $b)
{
    $total = $a;
    foreach ($b as $cle => $valeur) {
        if (!isset($total[$cle])) {
            $total[$cle] = 0;
        }
        $total[$cle] += $valeur;
    }
    return $total;
}

Les clés présentes des deux côtés s'additionnent ; les clés propres au second sont recopiées. Le tableau associatif fait le travail d'alignement tout seul : aucune position à gérer.

8. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Lire sans isset : « Undefined array key » et valeur null.
  • => écrit -> : -> appartient aux objets (module 8), => aux tableaux.
  • Compteur incrémenté sans case créée : avertissement à la première occurrence.
  • Maximum initialisé sans clé de référence : perdre la clé du meilleur élément.
  • foreach sans => quand la clé est nécessaire : impossible de la reconstituer.

9. Méthodologie de résolution

Travailler sur un tableau associatif
  1. Identifier la clé : nom, mot, référence — c'est elle qui structure le tableau.
  2. Créer les cases explicitement (isset ou initialisation) avant de les modifier.
  3. Parcourir avec la forme clé => valeur dès que la clé compte.
  4. Garder le meilleur couple (clé + valeur) pour tout problème de maximum.
  5. Tester avec des clés absentes, puis des valeurs égales.
