PDO : la trame complète

try {
    $pdo = new PDO('mysql:host=localhost;dbname=boutique;charset=utf8mb4', 'user', 'mdp', [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION
    ]);

    // SELECT avec requête préparée
    $stmt = $pdo->prepare('SELECT nom, note FROM etudiants WHERE promotion = ?');
    $stmt->execute(['B1']);
    foreach ($stmt as $ligne) {
        echo $ligne['nom'] . " : " . $ligne['note'] . "\n";
    }

    // INSERT préparé
    $stmt = $pdo->prepare('INSERT INTO etudiants (nom, note) VALUES (?, ?)');
    $stmt->execute([$nom, $note]);
} catch (PDOException $e) {
    echo "Erreur base : " . $e->getMessage() . "\n";
}

Erreurs fréquentes à éviter

  • Oublier trim() après fgets(STDIN) : la comparaison échoue sans bruit.
  • Oublier le $ d'une variable — ou en mettre un au nom de fonction.
  • Comparer avec == des valeurs de types différents : préférer ===.
  • Lire $tab[$cle] sans isset : « Undefined array key ».
  • Concaténer une donnée externe dans le SQL au lieu d'une requête préparée.
  • Afficher une donnée utilisateur sans htmlspecialchars.
