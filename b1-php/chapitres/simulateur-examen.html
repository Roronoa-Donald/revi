Exercice 1/4 — Lecture de code

Soit le script suivant :

<?php
$total = 0;
for ($i = 2; $i <= 5; $i++) {
    $total += $i * $i;
}
echo "Total : $total\n";

(a) (2 pts) Trace l'exécution (valeur de $total après chaque tour). (b) (1 pt) Que s'affiche-t-il ? (c) (1 pt) Que calcule ce script en général ?

Corrigé
(a) i=2 : 4 ; i=3 : 13 ; i=4 : 29 ; i=5 : 54. (b) Total : 54. (c) La somme des carrés des entiers de 2 à 5.
Exercice 2/5 — Écriture de script

Écris un script PHP qui lit un entier n, puis n notes (une par ligne), puis affiche la moyenne à deux décimales et la mention Admis (moyenne ≥ 10) ou Ajourne.

Corrigé
<?php
$n = (int)trim(fgets(STDIN));
$notes = [];
for ($i = 0; $i < $n; $i++) {
    $notes[] = (int)trim(fgets(STDIN));
}

$moyenne = array_sum($notes) / $n;
echo number_format($moyenne, 2, '.', '') . "\n";
echo ($moyenne >= 10 ? "Admis" : "Ajourne") . "\n";
Exercice 3/4 — Tableau associatif

Le programme reçoit n lignes article quantite. Affiche l'article le plus stocké et sa quantité (en cas d'égalité, le premier atteint gagne).

Corrigé
<?php
$n = (int)trim(fgets(STDIN));
$stock = [];
for ($i = 0; $i < $n; $i++) {
    $parts = explode(' ', trim(fgets(STDIN)));
    $stock[$parts[0]] = (int)$parts[1];
}

$refMax = '';
$max = 0;
foreach ($stock as $ref => $quantite) {
    if ($quantite > $max) {
        $max = $quantite;
        $refMax = $ref;
    }
}
echo "$refMax $max\n";
Exercice 4/3 — Fonction

Écris une fonction livraison($panier) qui renvoie 0 si le panier atteint 100 EUR ou plus, sinon 7. Le script lit le panier et affiche le total à payer.

Corrigé
<?php
function livraison($panier)
{
    if ($panier >= 100) {
        return 0;
    }
    return 7;
}

$panier = (int)trim(fgets(STDIN));
$total = $panier + livraison($panier);
echo "Total : $total EUR\n";
Exercice 5/4 — Validation

Un formulaire envoie un login et un mot de passe (POST). Écris la partie du script qui valide : login d'au moins 4 caractères, mot de passe d'au moins 8. Affiche OK ou Refuse.

Corrigé
<?php
$login = $_POST['login'] ?? '';
$motDePasse = $_POST['mdp'] ?? '';

if (strlen($login) >= 4 && strlen($motDePasse) >= 8) {
    echo "OK\n";
} else {
    echo "Refuse\n";
}
Les deux conditions doivent être vraies ensemble : ET logique.

Exercice 1/5 — PDO

Complète le script : connexion à la base boutique, puis requête préparée qui affiche les produits de la catégorie reçue en entrée (nom et prix de chaque ligne).

Corrigé
<?php
$categorie = trim(fgets(STDIN));

$pdo = new PDO('mysql:host=localhost;dbname=boutique;charset=utf8mb4', 'user', 'mdp', [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION
]);

$stmt = $pdo->prepare('SELECT nom, prix FROM produits WHERE categorie = ?');
$stmt->execute([$categorie]);

foreach ($stmt as $ligne) {
    echo $ligne['nom'] . " : " . $ligne['prix'] . " EUR\n";
}
La valeur passe par le ? : jamais concaténée au SQL.
Exercice 2/5 — Tableau associatif

Deux commandes arrivent sous forme de tableaux associatifs article => quantite. Écris la fonction fusionner($a, $b) qui renvoie le total par article.

Corrigé
<?php
function fusionner($a, $b)
{
    $total = $a;
    foreach ($b as $article => $quantite) {
        if (!isset($total[$article])) {
            $total[$article] = 0;
        }
        $total[$article] += $quantite;
    }
    return $total;
}

$c1 = ['clous' => 10, 'vis' => 5];
$c2 = ['vis' => 7, 'ecrous' => 3];
print_r(fusionner($c1, $c2));
// clous 10, vis 12, ecrous 3
Exercice 3/5 — Session

Écris le squelette d'un script qui, à chaque visite, ajoute 1 au compteur de visites de l'utilisateur et l'affiche.

Corrigé
<?php
session_start();

if (!isset($_SESSION['visites'])) {
    $_SESSION['visites'] = 0;
}
$_SESSION['visites']++;

echo "Visites : " . $_SESSION['visites'] . "\n";
Tester l'existence avant d'incrémenter : sinon « Undefined array key ».
Exercice 4/5 — Débogage

Ce script contient trois erreurs. Identifie-les et corrige-les :

<?php
$nom = fgets(STDIN);
if ($nom = "admin") {
    echo "Bienvenue $nom";
}
echo $MotDePasse;
Corrigé
  1. fgets sans trim : $nom garde le saut de ligne → trim(fgets(STDIN)).
  2. Affectation au lieu de comparaison : $nom = "admin" affecte et est toujours vrai → $nom === "admin".
  3. Nom de variable inexistant : $MotDePasse n'a jamais été définie (la casse compte) → « Undefined variable ».

QCM final — toutes notions

Comment reconnaît-on une variable en PHP ?

$nom, $total : le dollar préfixe toute variable.

Pourquoi trim(fgets(STDIN)) ?

Sans trim, la comparaison échoue à cause du \n final.

Que teste === en plus de == ?

=== exige même valeur et même type.

Dans une cascade if / elseif / else, quelle branche s'exécute ?

Dès qu'une condition est satisfaite, les suivantes sont ignorées.

Dernier indice d'un tableau de n éléments ?

Les indices vont de 0 à n − 1.

Que renvoie array_search si la valeur est absente ?

À tester avec === false avant d'utiliser le résultat.

Parcourir un tableau associatif avec clé et valeur ?

Le foreach associatif visite chaque couple clé → valeur.

Que renvoie une fonction PHP sans return ?

Sans return, la fonction ne transmet rien d'exploitable.

Pourquoi une requête préparée plutôt qu'une concaténation ?

La valeur passe par un paramètre : le SQL reste fixe.

À quoi sert htmlspecialchars() à l'affichage ?

Les données externes s'affichent comme du texte, jamais comme du HTML.
