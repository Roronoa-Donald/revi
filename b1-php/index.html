PHP — du script au site dynamique

Le langage qui fait tourner une large part du Web : syntaxe, formulaires, sessions et accès à MySQL avec PDO. Un parcours complet, progressif et pratique, conçu pour viser la maîtrise exigée aux évaluations.

Ce que tu sauras faire à la fin du cours
  • écrire un script PHP : variables, types, opérateurs, chaînes ;
  • structurer le code avec conditions, boucles et fonctions ;
  • manipuler tableaux indexés et tableaux associatifs (clé → valeur) ;
  • valider des données de formulaire et gérer des sessions ;
  • interroger MySQL avec PDO : connexion, requêtes préparées, parcours de résultats.
Comment ce cours s'articule

Le cours couvre PHP procedural jusqu'à l'accès à la base de données avec PDO (connexion MySQL, requêtes préparées, CRUD). Les exercices de code de chaque chapitre sont rédigés en PHP, dans la version CLI : tu écris du vrai PHP, le programme est réellement lancé puis corrigé par des tests cachés. Les derniers modules relient la logique du programme aux tables d'une base MySQL.
