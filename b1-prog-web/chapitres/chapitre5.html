Chapitre 5 — CSS : mise en page, flexbox et responsive

Module 5 ≈ 3 h 30 de travail Réservé B1 et plus
Mise en situation

Le contenu s’empile verticalement, et c’est normal : c’est le flux normal du document. Toute mise en page commence par une décision — sortir du flux ou le réorganiser. Flexbox range des éléments sur une ligne ou une colonne, la grille place des cellules dans un tableau virtuel, et les media queries changent les règles selon la largeur disponible.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. expliquer le flux normal et décider quand le quitter ;
  2. choisir entre flexbox et grille pour une mise en page donnée ;
  3. aligner et répartir des éléments avec flexbox ;
  4. construire une grille responsive à colonnes adaptatives ;
  5. écrire une interface lisible de 320 px à 1600 px de large.

1. Le flux normal et la décision de mise en page

Sans CSS de disposition, les éléments s’empilent dans l’ordre du document : les éléments de type bloc (div, p, h1) prennent toute la largeur et se placent l’un sous l’autre ; les éléments en ligne (a, span, strong) s’écoulent dans le texte. C’est le flux normal.

Deux familles de mise en page s’y ajoutent, et le choix se fait sur le besoin :

BesoinOutil
ranger des éléments sur une ligne, les espacer, les alignerflexbox
organiser un ensemble en lignes et colonnesgrille CSS
sortir un élément du flux pour le superposerposition
Intuition — une dimension ou deux ?

Si tu peux répondre à la question « qu’est-ce qui est rangé ? » par un alignement, c’est flexbox. Si tu dois dessiner des lignes et des colonnes, c’est une grille. Les deux se combinent : une grille de cartes dont chaque carte est elle-même une flexbox.

2. display et position

display décide du comportement de l’élément dans le flux. Les valeurs qui comptent :

ValeurEffet
blocktoute la largeur, sur sa propre ligne
inlines’écoule dans le texte ; width et height ignorés
inline-blockdans la ligne, mais dimensionnable
flexl’élément devient conteneur flex pour ses enfants
gridl’élément devient conteneur de grille
nonel’élément disparaît, il ne réserve aucune place

position répond à une autre question : que faire si l’élément doit sortir du flux ? relative le décale sans changer la place réservée ; absolute le sort du flux et le place par rapport à son ancêtre positionné le plus proche ; fixed le fixe par rapport à la fenêtre ; sticky le colle à un bord pendant le défilement.

Piège — absolute sans ancêtre positionné

Un élément en absolute se place par rapport à son ancêtre le plus proche qui porte une position. Si aucun n’en a, il se place par rapport à la page — et « la fenêtre » d’aujourd’hui n’est plus celle de demain. La règle : un parent position: relative dès qu’un enfant est en absolute.

3. Flexbox

Un conteneur flex range ses enfants sur un axe principal, dont l’orientation se choisit avec flex-direction. Deux axes sont concernés : le principal (row par défaut) et le transversal.

.barre {
  display: flex;
  flex-direction: row;      /* ou column */
  justify-content: space-between;   /* axe principal : répartition */
  align-items: center;              /* axe transversal : alignement */
  gap: 16px;                        /* espace entre les enfants */
  flex-wrap: wrap;                  /* passe à la ligne si nécessaire */
}

.carte { flex: 1 1 260px; }   /* grandir | rétrécir | base de 260px */

Le raccourci flex: 1 1 260px se lit : les cartes partagent l’espace disponible, peuvent se rétrécir, et souhaitent au moins 260 px. C’est la façon la plus simple d’obtenir des colonnes élastiques sans média query.

PropriétéAxeValeurs utiles
justify-contentprincipalflex-start, center, space-between, space-around
align-itemstransversalstretch, flex-start, center, baseline
gaples deuxune longueur
Mnémotechnique — « justify suit la direction, align la traverse »

En row : justify-content répartit horizontalement, align-items centre verticalement. En column, les deux rôles s’échangent — d’où l’intérêt de raisonner en axes plutôt qu’en horizontal/vertical.

4. Grille CSS

Une grille définit des colonnes et des lignes, puis laisse les enfants s’y placer. repeat() évite d’écrire dix fois la même largeur, et minmax() fixe des bornes.

.galerie {
  display: grid;
  grid-template-columns: repeat(3, 1fr);   /* trois colonnes égales */
  gap: 12px;
}

/* colonnes adaptatives : le nombre de colonnes suit la place disponible */
.auto {
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
}

.entete {
  grid-column: 1 / -1;         /* toute la largeur, de la première à la dernière ligne */
}

L’unité fr représente une fraction de l’espace restant : repeat(3, 1fr) partage la largeur en trois parts égales, quel que soit l’écran. grid-column: 1 / -1 fait couvrir toutes les colonnes à un élément — la façon la plus courte d’obtenir un en-tête pleine largeur.

auto-fit et auto-fill

auto-fit étire les colonnes existantes pour remplir la ligne ; auto-fill crée des colonnes vides supplémentaires. Pour une galerie de cartes, auto-fit est presque toujours le bon choix : il évite une bande vide à droite.

5. Responsive : media queries et approche mobile d’abord

Une media query applique un bloc de règles seulement si la condition est vraie. La condition la plus courante porte sur la largeur de la fenêtre.

/* base : mobile */
.grille { display: grid; gap: 16px; grid-template-columns: 1fr; }

/* tablette */
@media (min-width: 600px) {
  .grille { grid-template-columns: repeat(2, 1fr); }
}

/* bureau */
@media (min-width: 900px) {
  .grille { grid-template-columns: repeat(3, 1fr); }
}

Écrire d’abord le style mobile puis ajouter des règles par paliers croissants s’appelle travailler mobile first. Cette approche produit un CSS plus court et des interfaces utilisables depuis le plus petit écran.

PalierLargeurColonnes
téléphone< 600 px1
tablette600 – 899 px2
bureau≥ 900 px3
Piège — la balise viewport oubliée

Sans <meta name="viewport" content="width=device-width, initial-scale=1.0">, un téléphone affiche la page comme un écran de bureau réduit : la media query ne se déclenche jamais comme prévu, et le texte devient minuscule.

6. Design fluide : moins de paliers, plus de souplesse

Toutes les tailles n’ont pas besoin d’un palier. Trois fonctions permettent de décrire une adaptation continue :

  • clamp(minimum, idéal, maximum) : borne une valeur fluide — typiquement une taille de titre ;
  • minmax(minimum, maximum) : borne une piste de grille ;
  • min() et max() : choisissent la plus petite ou la plus grande de plusieurs valeurs.
h1 { font-size: clamp(1.6rem, 4vw, 2.8rem); }

/* une colonne de texte qui ne dépasse jamais 65 caractères environ */
.lecture { max-width: min(65ch, 100%); margin-inline: auto; }

.galerie { grid-template-columns: repeat(auto-fit, minmax(min(240px, 100%), 1fr)); }

Le dernier exemple est le plus utile : min(240px, 100%) empêche la grille de déborder sur un écran plus étroit que 240 px. C’est le détail qui distingue une grille qui « tient » d’une grille parfaite.

Méthode : du plus petit au plus grand

Construis la version étroite d’abord, vérifie-la à 320 px, puis élargis la fenêtre progressivement en corrigeant à chaque rupture visible. Un rendu n’est terminé que lorsqu’il se tient à toutes les largeurs entre 320 px et 1600 px, pas seulement aux trois paliers.

7. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Largeur des éléments d’un flex

JavaScript Niveau 2 — Application

Objectif : Calculer la place réellement disponible quand une flexbox partage son espace.

Le programme reçoit une ligne largeur_du_conteneur espacement nombre_d’éléments. Affichez la largeur de chaque élément, arrondie à deux décimales, sachant que les espacements séparent les éléments et que nombre − 1 espaces sont consommés.

Entrée du programme
1000 20 4
Sortie attendue
235.00

1000 − 60 = 940 ; 940/4 = 235.

Deux indices, rédigés en mots
  1. Pour 4 éléments, il y a 3 espaces : l’espace disponible est conteneur − (nombre − 1) × espacement.
  2. Divise ensuite par le nombre d’éléments, puis formate avec toFixed(2).

Exercice 3 — Position d’une cellule dans une grille

JavaScript Niveau 3 — Raisonnement

Objectif : Retrouver ligne et colonne d’un élément placé dans une grille à n colonnes.

Le programme reçoit une ligne colonnes position : le nombre de colonnes de la grille et le rang de l’élément (le premier élément est en position 1, dans la première ligne). Affichez ligne colonne, tous deux comptés à partir de 1.

Entrée du programme
3 7
Sortie attendue

Deux indices, rédigés en mots

8. QCM — niveau examen

Quel outil pour ranger des éléments sur une seule ligne, avec espacement ?

Flexbox travaille sur un axe : c’est son terrain.

Dans un conteneur flex en row, que règle justify-content ?

justify-content agit sur l’axe principal ; align-items sur le transversal.

Que signifie repeat(3, 1fr) ?

fr est une fraction de l’espace restant : trois parts égales.

Quelle écriture fait couvrir toutes les colonnes à un élément ?

De la première ligne de grille à la dernière : toute la largeur.

Que fait une media query (min-width: 600px) ?

min-width est une borne basse : la règle s’applique dès que la largeur atteint 600px.

À quoi sert clamp(1.6rem, 4vw, 2.8rem) ?

La taille suit 4vw mais reste comprise entre le minimum et le maximum.

9. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Choisir une grille pour un simple alignement : flexbox suffit et coûte moins de code.
  • position: absolute sans parent positionné : l’élément se place par rapport à la page.
  • Oublier flex-wrap : les enfants se compriment au lieu de passer à la ligne.
  • Media query sans viewport : le palier ne se déclenche pas comme prévu sur téléphone.
  • Tester seulement aux paliers : les largeurs intermédiaires (par exemple 700 px) cassent souvent.

10. Méthodologie de résolution

Construire une mise en page solide
  1. Pars du flux normal et ne le quitte que si le besoin est réel.
  2. Choisis flexbox pour un axe, la grille pour deux dimensions.
  3. Écris le style mobile d’abord, puis ajoute des paliers croissants.
  4. Utilise gap plutôt que des marges entre éléments.
  5. Vérifie en continu entre 320 px et 1600 px, pas seulement aux paliers.

11. Révision active

Résumé essentiel
  • Le flux normal empile les blocs et fait couler les éléments en ligne : c’est le point de départ.
  • display choisit le comportement (block, inline, flex, grid, none) ; position sort du flux.
  • Flexbox range sur un axe : direction, justify-content, align-items, gap, flex-wrap.
  • La grille organise deux dimensions : grid-template-columns, fr, gap, placement par lignes.
  • Les media queries appliquent des règles à partir d’une largeur : approche mobile first.
  • clamp(), minmax() et auto-fit rendent la mise en page fluide sans multiplier les paliers.

Checklist de maîtrise

  • Je choisis entre flexbox et grille en justifiant mon choix.
  • Je construis une galerie responsive sans media query grâce à auto-fit.
  • J’écris une interface mobile first avec deux paliers de media queries.
  • Je vérifie mon rendu à 320 px, 700 px et 1600 px.
