Niveau examen

  2. Deux feuilles de style se contredisent : a { color: red } dans la première, .menu a { color: blue } dans la seconde. Laquelle gagne, et que se passe-t-il si l’on ajoute !important à la première ?

  4. Écris un programme qui lit n lignes « nom note », puis affiche la moyenne et le nom du major.

Projet intégrateur — relevé de notes interactif

Le projet réunit les six chapitres : une page unique, autonome, qui présente un relevé de notes et permet d’ajouter une note. Aucune bibliothèque : HTML, CSS et JavaScript natifs.

Cahier des charges
  1. Structure : document valide, un h1, un header avec navigation, un main, un footer, hiérarchie de titres sans saut.
  2. Tableau de données : les notes sont dans un table avec caption et th scope.
  3. Formulaire : deux champs étiquetés (nom, note bornée 0–20 et obligatoire), validation native, puis validation JavaScript avec message explicite.
  4. Style : sélecteurs par classes (pas d’identifiant pour styler), box-sizing: border-box global, unités rem pour le texte.
  5. Mise en page : flexbox pour l’en-tête, grille auto-fit pour les cartes de synthèse, mobile first avec au moins deux paliers.
  6. Interaction : bouton d’ajout, preventDefault(), mise à jour du tableau et d’une moyenne, saisie affichée avec textContent.
  7. Accessibilité : contraste du texte ≥ 4,5:1, focus visible sur les boutons, alt sur les images.

/* app.js */
const notes = [{ nom: "Ada", note: 18 }, { nom: "Linus", note: 15 }];

const corps = document.querySelector("#corps");
const form = document.querySelector("#form");
const message = document.querySelector("#message");

function afficher() {
  corps.textContent = "";
  for (const ligne of notes) {
    const tr = document.createElement("tr");
    const nom = document.createElement("th");
    nom.scope = "row";
    nom.textContent = ligne.nom;
    const note = document.createElement("td");
    note.textContent = String(ligne.note);
    tr.append(nom, note);
    corps.append(tr);
  }
  const somme = notes.reduce((s, l) => s + l.note, 0);
  document.querySelector("#moyenne").textContent =
    notes.length ? (somme / notes.length).toFixed(2) : "—";
}

form.addEventListener("submit", evenement => {
  evenement.preventDefault();
  const nom = document.querySelector("#nom").value.trim();
  const note = Number(document.querySelector("#note").value);
  if (!nom || Number.isNaN(note) || note < 0 || note > 20) {
    message.textContent = "Nom attendu et note comprise entre 0 et 20.";
    return;
  }
  notes.push({ nom, note });
  message.textContent = "Note ajoutée.";
  form.reset();
  afficher();
});

afficher();

Deux règles gouvernent tout le projet : les données vivent dans un tableau JavaScript, et le DOM n’est qu’un affichage de ce tableau. Reconstruire l’affichage à partir des données (afficher()) évite les incohérences entre ce que l’on voit et ce que l’on calcule.
