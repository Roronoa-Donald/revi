Programmation Web — du HTML au JavaScript

Une page web se construit sur trois langages qui ne se remplacent pas : HTML pour le sens, CSS pour la présentation, JavaScript pour le comportement. Six chapitres pour les apprendre ensemble, en partant de ce qui se passe vraiment entre le clic sur une adresse et l’affichage du document — et en finissant par une page complète, interactive et accessible.

Ce que vous saurez faire à la fin du cours
  • expliquer ce qui se passe entre le clic sur une adresse et l’affichage de la page ;
  • écrire un document HTML structuré, sémantique et accessible ;
  • construire un formulaire complet, étiqueté, validé et protégé des injections ;
  • styliser une page avec des sélecteurs justes et un modèle de boîte maîtrisé ;
  • mettre en page en flexbox et en grille, du téléphone au grand écran ;
  • rendre une page interactive avec le DOM et les événements.
Comment ce cours s’articule

Chaque chapitre part d’une situation concrète (une page qui ne s’affiche pas, un style qui ne s’applique pas, un bouton qui ne réagit pas), pose les notions, montre le code exact, puis se termine par trois exercices de code en JavaScript : votre programme est réellement exécuté et corrigé par des tests que vous ne voyez pas.

Les exercices ne manipulent pas le DOM — il n’existe pas hors du navigateur. Ils portent sur ce qui se calcule : décomposer une URL, classer un code HTTP, lire un extrait HTML, valider et échapper une saisie, calculer une spécificité ou une largeur de boîte, placer une cellule de grille. C’est exactement la logique que vous réutiliserez ensuite dans la page.

Programme du cours

Parcours des 6 chapitres

  1. 1 Le Web : clients, serveurs, URL et HTTP Client et serveur, requête HTTP, anatomie d’une URL, méthodes, codes de statut, rôle de HTML, CSS et JavaScript. Chapitre
  2. 2 HTML : structure, sémantique et contenu Squelette d’un document, balises sémantiques, texte et listes, liens, images, tableaux de données, validation. Chapitre
  3. 3 Formulaires, validation et sécurité des entrées Structure d’un formulaire, types de champs, étiquettes, validation côté client, échappement et injection HTML. Chapitre
  4. 4 CSS : sélecteurs, cascade et modèle de boîte Règles et feuilles de style, sélecteurs, cascade et spécificité, héritage, modèle de boîte, unités. Chapitre
  5. 5 CSS : mise en page, flexbox et responsive Flux normal, display et position, flexbox, grille CSS, media queries et design fluide. Chapitre
  6. 6 JavaScript : le DOM et les événements Chargement du script, variables et fonctions, tableaux, sélection et modification du DOM, événements, sûreté. Chapitre

Aucune installation nécessaire

L’atelier exécute votre JavaScript sur un service isolé : rien ne tourne sur votre machine, aucun fichier n’est installé. La clé du service reste sur le serveur et n’est jamais transmise au navigateur.
