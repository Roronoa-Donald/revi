Module 1 — Cadrage du projet

QuestionLes cinq objectifs pédagogiques ?
RéponseInterface Tkinter, connexion PostgreSQL, opérations CRUD, gestion des exceptions, modules réutilisables.
QuestionLes quatre fichiers du projet ?
Réponsemain.py (interface), database.py (SQL), requirements.txt (dépendances), README.md (doc).
QuestionInstaller l'environnement sur Ubuntu ?
Réponseapt install python3-pip postgresql python3-tk, pip install psycopg2-binary, créer la base gestion_stock.
QuestionRôle de psycopg2 ?
RéponseLe pont entre Python et PostgreSQL : connecter, exécuter des requêtes, gérer les erreurs.
QuestionPourquoi séparer main.py et database.py ?
RéponseChanger l'écran sans toucher au SQL, tester la base sans fenêtre : modules réutilisables.

Module 2 — La base de données

QuestionLes cinq colonnes de la table produits ?
Réponseid SERIAL PRIMARY KEY, nom VARCHAR(100), categorie VARCHAR(50), quantite INTEGER, prix DECIMAL(10,2).
QuestionPourquoi commit après INSERT ?
RéponseSans validation, PostgreSQL annule la modification à la déconnexion : la ligne n'est pas écrite.
QuestionLes quatre requêtes CRUD ?
RéponseINSERT INTO, SELECT FROM (fetchall), UPDATE SET WHERE, DELETE WHERE — toutes paramétrées (%s).
QuestionPourquoi des requêtes paramétrées ?
RéponseLes valeurs sont échappées par psycopg2 : protection contre l'injection SQL.
QuestionQue fait connecter() en cas d'échec ?
RéponseElle attrape Error, affiche le problème et renvoie False : l'application ne plante pas.

Module 3 — L'interface Tkinter

QuestionL'enchaînement des écrans ?
RéponseConnexion PostgreSQL → destroy du frame → interface principale (formulaire, boutons, tableau).
QuestionLes quatre boîtes de dialogue ?
Réponseshowinfo (succès), showwarning (attention), showerror (échec), askyesno (confirmation oui/non).
QuestionQue valide ajouter_produit() avant l'insertion ?
RéponseChamps obligatoires non vides, puis int(quantite) et float(prix) dans un try — ValueError → showerror.
QuestionComment le Treeview suit-il la base ?
Réponseactualiser_tableau() efface les lignes puis les recharge depuis obtenir_tous_produits().
QuestionComment l'application se ferme-t-elle proprement ?
Réponseroot.protocol("WM_DELETE_WINDOW") appelle db.deconnecter() avant root.destroy().

Module 4 — Cycle de vie d'un produit

QuestionLes trois verbes de toute action ?
RéponseValider (champs, sélection), appeler la base, rafraîchir (effacer_champs + actualiser_tableau).
QuestionLe chemin complet de la suppression ?
RéponseSélection → askyesno → DELETE WHERE id → showinfo → rafraîchir ; non = rien.
QuestionRègle des mouvements de stock ?
RéponseEntrées cumulées ; sortie refusée si elle dépasse le disponible : le stock ne devient jamais négatif.
QuestionQue se passe-t-il si le produit n'existe plus ?
RéponseLe résultat est rapporté comme introuvable : ce n'est pas une suppression réussie.
QuestionPourquoi WHERE id=%s est-il vital ?
RéponseSans WHERE, UPDATE et DELETE s'appliquent à toute la table.

Module 5 — Logique métier du stock

QuestionLa cascade des trois états ?
Réponsestock = 0 → rupture ; stock < seuil → alerte ; sinon ok (stock égal au seuil : ok).
QuestionComment calculer la valeur totale ?
RéponseValeur de ligne = quantite × prix, accumulée dans un total initialisé à 0, affichée après la boucle.
QuestionLe motif du maximum ?
RéponseDeux variables (meilleur, valeur) à « rien »/0 ; mise à jour si strictement supérieur ; le premier gagne à égalité.
QuestionQue rapporte une recherche sans résultat ?
Réponsetrouves : 0 et un meilleur resté « - » : c'est un bilan valide, pas une erreur.
QuestionPourquoi les bilans sortent-ils après la boucle ?
RéponseSinon chaque ligne produit un sous-bilan : le rapport devient illisible et faux.

Module 6 — Fiabiliser et livrer

QuestionLes quatre pannes et leurs remèdes ?
RéponseConnexion → service PostgreSQL ; psycopg2 → pip install psycopg2-binary ; tkinter → apt install python3-tk ; Non-ASCII → en-tête coding utf-8.
QuestionLe format de l'export CSV ?
RéponseEn-tête nom;categorie;quantite;prix, une ligne par produit, bilan « lignes exportees : n » après.
QuestionQue contient le tableau de bord ?
RéponsePar produit stock et valeur, puis total en FCFA, nombre d'alertes, vitrine (plus grande valeur de ligne).
QuestionQuelles améliorations restent ouvertes ?
RéponseStatistiques graphiques (matplotlib) et authentification avec droits d'accès.
QuestionPourquoi l'en-tête CSV sort-il avant la boucle ?
RéponsePour apparaître même sur un catalogue vide, et une seule fois.
