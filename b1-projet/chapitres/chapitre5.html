Chapitre 5 — Logique métier du stock

Module 5 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

Au-delà du CRUD, le stock parle : quels produits passent sous leur seuil ? Que vaut le magasin entier ? Quels articles d'une catégorie proposer, et lequel mettre en vitrine ? Les améliorations du tutoriel deviennent ici des algorithmes — seuils, sommes, filtres et maximum.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. signaler chaque produit : rupture (stock 0), alerte (stock < seuil), ok ;
  2. calculer la valeur d'une ligne (quantite × prix) et la valeur totale du stock ;
  3. filtrer les produits d'une catégorie cible ;
  4. trouver le maximum : plus cher de la catégorie, plus grande valeur de ligne.

1. Alertes de seuil

L'amélioration 2 du tutoriel : « afficher un avertissement si quantité < seuil ». Trois états, évalués dans l'ordre : rupture — stock à 0, plus rien à vendre ; alerte — stock strictement sous le seuil, à recommander vite ; ok — au seuil ou au-dessus (un stock exactement égal au seuil n'alerte pas). Le bilan compte ruptures et alertes séparément : deux lignes qui pilotent les commandes.

Mnémotechnique — « zéro c'est rompu, sous le seuil c'est l'alerte »

Rupture = 0 ; alerte = 0 < stock < seuil ; ok = stock ≥ seuil. La cascade if / elif / else.

2. Valeur du stock

La valeur d'une ligne : quantite × prix. La valeur totale : la somme accumulée dans une variable initialisée à 0 avant la boucle, affichée une seule fois après. Ce motif — accumulateur hors boucle, affichage après — est le même que pour les compteurs des chapitres précédents. Attention au piège : afficher le total dans la boucle donne n sous-totaux, pas un total.

Confusions d'examen
  • Stock égal au seuil : ok, pas alerte (le test est strictement inférieur).
  • Le total s'affiche après la boucle : jamais dans la boucle.
  • Valeur de ligne = quantite × prix : ne pas additionner les prix seuls.
  • Deux compteurs (ruptures, alertes) : deux bilans distincts.

3. Recherche et maximum

La recherche par catégorie (amélioration 1) filtre les produits dont la catégorie égale la cible : afficher chaque correspondance, compter les trouvailles. Le maximum se cherche avec deux variables — meilleur et son prix — initialisées à « rien » et 0 : à chaque produit mieux placé (prix strictement supérieur), on met à jour les deux. À prix égal, le premier rencontré gagne : c'est le sens du test strict. Si rien n'est trouvé, le bilan le dit : trouves : 0, meilleur resté « - ».

Vérifier en Bash
  • La cascade : -eq 0 → rupture, -lt seuil → alerte, sinon ok.
  • La valeur : ligne = quantite * prix, total accumulé, affiché après.
  • Le filtre : comparer la catégorie à la cible, compteur trouves.

Exercice 1 — Alertes de stock bas

Bash Niveau 1 — Acquisition

Objectif : Signaler chaque produit sous son seuil d'alerte, comme l'amélioration 2 du tutoriel.

Le script lit n lignes « produit seuil stock ». Pour chaque ligne il affiche produit : rupture si stock vaut 0, produit : alerte si le stock est strictement inférieur au seuil (amélioration « avertir si quantité < seuil »), sinon produit : ok. Bilan : ruptures : R puis alertes : A (dans cet ordre, sur deux lignes).

souris 4 10
Sortie attendue

souris : ok
ruptures : 1
alertes : 1
Deux indices, rédigés en mots
  1. Trois cas dans l'ordre : stock -eq 0 → rupture ; stock -lt seuil → alerte ; sinon ok.
  2. Deux lignes de bilan à la fin : ruptures : R puis alertes : A.

Exercice 2 — Valeur totale du stock

Bash Niveau 2 — Application

Objectif : Calculer la valeur de chaque ligne (quantite × prix) puis la valeur totale.

Amélioration 2 du tutoriel : « calculer la valeur totale du stock ». Le script lit n lignes « produit quantite prix » (prix en FCFA, entier). Pour chaque ligne il affiche produit : X FCFA avec X = quantite × prix, puis la ligne totale valeur totale : T FCFA.

Entrée du programme
3
clavier 10 5000
souris 5 2500
ecran 2 45000
Sortie attendue
clavier : 50000 FCFA
souris : 12500 FCFA
ecran : 90000 FCFA
valeur totale : 152500 FCFA
Deux indices, rédigés en mots
  1. Ligne = quantite * prix ; affiche puis ajoute au total.
  2. La ligne totale sort une seule fois, après la boucle.

Exercice 3 — Recherche et tri du catalogue

Bash Niveau 3 — Raisonnement

Objectif : Chercher les produits d'une catégorie puis désigner le plus cher et le mieux stocké.

Améliorations 1 et 4 du tutoriel. Le script lit n lignes « produit categorie prix stock » puis une ligne cible (la catégorie recherchée). Pour chaque ligne de la catégorie cible il affiche produit : prix=X stock=Y ; à la fin il affiche plus cher : P (X FCFA) (produit de la cible au prix le plus élevé ; en cas d'égalité, le premier rencontré gagne), puis trouves : K.

Deux indices, rédigés en mots
  1. Lis d'abord les n lignes dans des tableaux, puis la cible, puis boucle sur les tableaux.
  2. Le max : si prix -gt meilleur_prix OU meilleur = -, mettre à jour meilleur et meilleur_prix.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Déclarer en alerte un stock égal au seuil : le test est strict.
  • Afficher le total à chaque ligne : sous-totaux, pas total.
  • Initialiser le maximum à un produit existant : le premier de la liste gagnerait à tort.
  • Oublier le compteur trouves : le bilan ne sait plus dire 0.

7. Méthodologie de résolution

Méthode — calculer un tableau de bord en trois gestes
  1. Initialiser hors boucle : total à 0, compteurs à 0, maximum à « rien ».
  2. Traiter chaque ligne : valeur, alertes, filtre, mise à jour du maximum.
  3. Afficher après la boucle : total, bilans séparés, vitrine.

8. Révision active

Résumé essentiel
  • Trois états : rupture (0), alerte (stock < seuil), ok (stock ≥ seuil).
  • Valeur de ligne = quantite × prix ; total accumulé, affiché après.
  • Recherche : filtre par catégorie, compteur de trouvailles.
  • Maximum : prix strictement supérieur, premier rencontré en cas d'égalité.

Checklist de maîtrise

  • Je classe un produit en rupture, alerte ou ok.
  • Je calcule valeur de ligne et valeur totale.
  • Je filtre une catégorie et je compte les trouvailles.
  • Je code une boucle de maximum sans biais d'initialisation.

Les 8 notions à connaître absolument

  1. Seuil : quantité minimale avant recommandation.
  2. Rupture : stock à 0.
  3. Valeur de ligne : quantite × prix.
  4. Accumulateur : total initialisé hors boucle.
  5. Filtre : sélection par catégorie égale à la cible.
  6. Boucle de maximum : meilleur + sa valeur, test strict.
  7. Bilan : compteurs affichés une seule fois, après.
  8. Vitrine : produit de plus grande valeur de ligne.

9. Test de maîtrise

Comment t'auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lis ton pourcentage :

< 50 % — relis la cascade rupture / alerte / ok.
50–69 % — refais le calcul de valeur totale.
70–89 % — cible la recherche et le maximum.
≥ 95 % — niveau de maîtrise recherché.
