Simulateur d'examen

Deux sujets blancs chronométrés, dans l'esprit de l'épreuve (durée 2 h, /20). Fais-les sans regarder les corrigés, puis corrige-toi sévèrement.

Chronomètre d'examen — 2 h

Lance le chrono quand tu commences un sujet. Ne consulte le corrigé qu'à la fin. Réserve 15 min de relecture : structure des fichiers, table produits, requêtes CRUD, messagebox, cascade de seuils, format CSV.

Examen blanc n°1

Sujet type épreuve — cadrage, base de données, interface.

Exercice 1/5 — Cadrage

Présenter le projet en deux phrases. Citer les cinq objectifs pédagogiques. Donner le rôle des quatre fichiers et la commande d'installation des dépendances.

Corrigé
Application complète de gestion de stock en Python avec interface Tkinter et base PostgreSQL. Objectifs : interface, connexion, CRUD, exceptions, modules. Fichiers : main.py (écran), database.py (SQL), requirements.txt (psycopg2-binary), README.md (doc). Installation : pip install -r requirements.txt.
Exercice 2/5 — Table produits

Écrire le CREATE TABLE complet. Pourquoi DECIMAL et non FLOAT pour le prix ? Que garantit IF NOT EXISTS ?

Corrigé
id SERIAL PRIMARY KEY, nom VARCHAR(100) NOT NULL, categorie VARCHAR(50), quantite INTEGER NOT NULL, prix DECIMAL(10,2) NOT NULL. DECIMAL(10,2) stocke deux décimales exactes, FLOAT arrondit en binaire. IF NOT EXISTS : le second lancement ne duplique pas la table.
Exercice 3/5 — CRUD

Écrire les quatre requêtes CRUD. Que font les %s ? Que se passe-t-il sans commit après un INSERT ?

Corrigé
INSERT INTO produits (nom, categorie, quantite, prix) VALUES (%s, %s, %s, %s) ; SELECT * FROM produits ORDER BY id ; UPDATE … SET … WHERE id=%s ; DELETE FROM produits WHERE id=%s. Les %s paramètrent et échappent : protection contre l'injection. Sans commit, l'écriture est annulée à la déconnexion.
Exercice 4/5 — Interface

Décrire l'enchaînement des deux écrans. Associer chaque situation à sa messagebox. Que valide ajouter_produit() avant l'insertion ?

Corrigé
Connexion → succès → creer_table, destroy, écran principal ; échec → showerror. showinfo : succès ; showwarning : champs manquants ; showerror : échec ; askyesno : suppression. Validation : champs non vides, int(quantite) et float(prix) dans un try — ValueError → showerror.

Examen blanc n°2 — variante

Sujet orienté cycle de vie, logique métier et livraison.

Exercice 1/5 — Cycle de vie

Dérouler le chemin complet de la suppression. Écrire la requête de modification. Que devient une sortie de stock supérieure au disponible ?

Corrigé
Sélection Treeview → askyesno → oui → DELETE FROM produits WHERE id=%s → showinfo → effacer_champs + actualiser_tableau ; non → rien. Modification : UPDATE produits SET … WHERE id=%s après sélection. Sortie excessive : refusée — le stock ne devient jamais négatif.
Exercice 2/5 — Alertes

Un seuil vaut 5 : classer les stocks 0, 3, 5 et 12. Pourquoi le test est-il strict ?

Corrigé
0 → rupture ; 3 → alerte (3 < 5) ; 5 → ok (égal au seuil) ; 12 → ok. Le test est strictement inférieur : atteindre le seuil suffit, l'alerte prévient avant de le passer.
Exercice 3/5 — Valeur et maximum

Calculer : 10 claviers à 5 000 FCFA et 2 écrans à 45 000 FCFA — valeurs de ligne et total. Comment coder la boucle du maximum sans biais ?

Corrigé
Claviers : 10 × 5 000 = 50 000 ; écrans : 2 × 45 000 = 90 000 ; total 140 000 FCFA. Maximum : deux variables (meilleur, valeur) initialisées à « rien »/0, mise à jour si strictement supérieur — le premier rencontré gagne à égalité ; affichage après la boucle.
Exercice 4/5 — Livraison

Associer les quatre pannes à leurs remèdes. Décrire le format de l'export CSV. Que contient le tableau de bord de soutenance ?

Corrigé
Connexion → service PostgreSQL ; psycopg2 → pip install psycopg2-binary ; tkinter → apt install python3-tk ; Non-ASCII → coding utf-8. CSV : en-tête nom;categorie;quantite;prix avant la boucle, une ligne par produit, bilan « lignes exportees ». Tableau de bord : total FCFA, alertes, vitrine (plus grande valeur de ligne).

QCM final — toutes notions

Le fichier qui contient l'interface :

main.py : fenêtre, formulaire, tableau.

La version minimale de Python :

Python 3.7 ou supérieur.

Le type du champ prix :

Deux décimales exactes, pas d'arrondi binaire.

id est une clé…

Auto-incrémentée et primaire.

La méthode qui lit toutes les lignes :

Après un SELECT.

Sans commit après INSERT…

PostgreSQL annule la transaction.

La confirmation avant suppression :

Dialogue oui/non obligatoire.

Un stock égal au seuil est…

L'alerte exige un stock strictement inférieur.

L'en-tête CSV se génère…

Une seule fois, même pour 0 produit.

La vitrine du tableau de bord se choisit sur…

quantite × prix, pas le prix seul.
