Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque chapitre, puis un projet final qui rejoue la soutenance de bout en bout. Les scripts sont en Bash, comme à l'atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n lignes « fichier role » (interface/database/deps/doc) et valide chaque rôle, puis le compteur d'erreurs.
  2. Lit n lignes « colonne type » et valide le schéma de la table produits, puis le compteur.
  3. Lit n lignes « situation boite » (showinfo/showwarning/showerror/askyesno) et valide chaque dialogue.
  4. Lit n lignes « produit quantite » et dit si l'ajout passe (entier positif), puis le compteur d'ajouts.
Corrections
read -r n
e=0
for ((k=0; k<n; k++)); do
  read -r fichier role
  case "$fichier" in
    main) attendu="interface" ;;
    database) attendu="database" ;;
    requirements) attendu="deps" ;;
    readme) attendu="doc" ;;
  esac
  if [ "$role" = "$attendu" ]; then
    echo "$fichier : OK"
  else
    echo "$fichier : KO ($attendu attendu)"
    e=$((e + 1))
  fi
done
echo "erreurs : $e/$n"

Application

Application
  1. Lit n lignes « service etat » (serveur/mdp/base) et réagit comme connecter() : premier défaut ou succès.
  2. Lit n lignes « operation sql » dans l'ordre du cycle CRUD et valide opération et requête à chaque étape.
  3. Lit n lignes « produit quantite prix » et affiche la valeur de chaque ligne puis la valeur totale.
  4. Lit n lignes « produit categorie quantite prix » et écrit le catalogue CSV avec en-tête et bilan.

Raisonnement

Raisonnement
  1. Lit n lignes « produit seuil stock » et classe chaque produit : rupture, alerte ou ok, puis les deux bilans.
  2. Lit n lignes « produit mouvement » et simule les mouvements : sorties refusées si le stock est insuffisant.
  3. Lit n lignes « produit motif » (confirme/annule/absent) et traite les suppressions avec les deux compteurs.
  4. Lit n lignes « produit quantite prix seuil » et produit le tableau de bord complet (total, alertes, vitrine).
Corrections
read -r n
r=0
a=0
for ((k=0; k<n; k++)); do
  read -r produit seuil stock
  if [ "$stock" -eq 0 ]; then
    echo "$produit : rupture"
    r=$((r + 1))
  elif [ "$stock" -lt "$seuil" ]; then
    echo "$produit : alerte"
    a=$((a + 1))
  else
    echo "$produit : ok"
  fi
done
echo "ruptures : $r"
echo "alertes : $a"

read -r n
declare -A stock
for ((i=0; i<n; i++)); do
  read -r produit mouvement
  actuel=\${stock[$produit]:-0}
  case "$mouvement" in
    -*)
      quantite=\${mouvement#-}
      if [ "$actuel" -lt "$quantite" ]; then
        echo "$produit : stock insuffisant"
      else
        stock[$produit]=$((actuel - quantite))
        echo "$produit : stock=\${stock[$produit]}"
      fi
      ;;
    *)
      stock[$produit]=$((actuel + mouvement))
      echo "$produit : stock=\${stock[$produit]}"
      ;;
  esac
done
echo "mouvements : $n"

read -r n
suppr=0
abs=0
for ((k=0; k<n; k++)); do
  read -r produit motif
  case "$motif" in
    confirme) echo "$produit : supprime" ; suppr=$((suppr + 1)) ;;
    annule) echo "$produit : conserve" ;;
    absent) echo "$produit : introuvable" ; abs=$((abs + 1)) ;;
  esac
done
echo "suppressions : $suppr"
echo "introuvables : $abs"

read -r n
total=0
alertes=0
vitrine="-"
vitrine_val=0
for ((k=0; k<n; k++)); do
  read -r produit quantite prix seuil
  valeur=$((quantite * prix))
  total=$((total + valeur))
  if [ "$quantite" -lt "$seuil" ]; then
    alertes=$((alertes + 1))
  fi
  if [ "$valeur" -gt "$vitrine_val" ]; then
    vitrine_val=$valeur
    vitrine=$produit
  fi
  echo "$produit : stock=$quantite valeur=$valeur"
done
echo "total : $total FCFA"
echo "alertes : $alertes"
echo "vitrine : $vitrine ($vitrine_val FCFA)"

Projet intégrateur — « la soutenance de bout en bout »

Cahier des charges

Le script reçoit le journal final du projet. D'abord n lignes vm config renommées produit config où config est une suite de lettres sans espace — v = validation implémentée, c = requêtes paramétrées (CRUD complet), g = boîtes de dialogue correctes, s = seuils d'alerte gérés, le tiret - = fonction non traitée. Puis m lignes produit quantite prix du stock à inventorier. Il affiche pour chaque produit produit : conforme si les quatre lettres sont présentes, sinon produit : a completer (manque X) avec la première lettre manquante dans l'ordre v, c, g, s ; pour chaque ligne du stock produit : quantite=X valeur=Y ; enfin le verdict : application prete si toutes les fonctions sont conformes ET que la valeur totale du stock dépasse 100 000 FCFA, application a enrichir si les fonctions sont conformes sans ce volume, application incomplete sinon.

Fonctionnalités attendues
  1. Lire les deux blocs sans mélanger fonctions et stock.
  2. Auditer chaque produit : première lettre manquante dans l'ordre v, c, g, s.
  3. Inventorier : quantité et valeur de chaque ligne du stock.
  4. Accumuler la valeur totale et la comparer au volume attendu.
  5. Verdict final au format exact du cahier des charges.

Contraintes : parsing lettre à lettre, premier manque dans l'ordre, bilan après lecture complète.

Grille d'auto-évaluation du projet (sur 100)
Lecture des deux blocs et parsing correct 20
Audit des fonctions (premier manque) 20
Inventaire et valeur totale 20
Verdict global conforme 20
Rapport lisible et formats exacts 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

read -r n
toutes_ok=1
for ((k=0; k<n; k++)); do
  read -r produit config
  v=0 ; c=0 ; g=0 ; s=0
  if [ "$config" != "-" ]; then
    for ((j=0; j<${#config}; j++)); do
      lettre=${config:$j:1}
      case "$lettre" in
        v) v=1 ;;
        c) c=1 ;;
        g) g=1 ;;
        s) s=1 ;;
      esac
    done
  fi
  if [ "$v" = "1" ] && [ "$c" = "1" ] && [ "$g" = "1" ] && [ "$s" = "1" ]; then
    echo "$produit : conforme"
  elif [ "$v" = "0" ]; then
    echo "$produit : a completer (manque v)" ; toutes_ok=0
  elif [ "$c" = "0" ]; then
    echo "$produit : a completer (manque c)" ; toutes_ok=0
  elif [ "$g" = "0" ]; then
    echo "$produit : a completer (manque g)" ; toutes_ok=0
  else
    echo "$produit : a completer (manque s)" ; toutes_ok=0
  fi
done
read -r m
total=0
for ((k=0; k<m; k++)); do
  read -r produit quantite prix
  valeur=$((quantite * prix))
  total=$((total + valeur))
  echo "$produit : quantite=$quantite valeur=$valeur"
done

if [ "$toutes_ok" = "1" ] && [ "$total" -gt 100000 ]; then
  echo "verdict : application prete"
elif [ "$toutes_ok" = "1" ]; then
  echo "verdict : application a enrichir"
else
  echo "verdict : application incomplete"
fi
