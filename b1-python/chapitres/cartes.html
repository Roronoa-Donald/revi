Module 1 — Environnement et types

QuestionQu'affiche type(10/2) ?
Réponse<class 'float'> — / renvoie toujours un float.
QuestionRésultat de 17 % 5 ?
Réponse2 (17 = 3×5 + 2).
QuestionQue renvoie input() ?
RéponseToujours une chaîne str.
QuestionÉcrivez une f-string qui affiche x à 2 décimales.
Réponsef"{x:.2f}"
QuestionDifférence // et % ?
RéponsePour les nombres int et float, // arrondit le quotient vers moins l'infini : -3 // 2 vaut -2 et 7.0 // 2 vaut 3.0. % donne le reste.
QuestionDifférence entre langage compilé et interprété ?
RéponseUn langage compilé (C/C++) est traduit en code machine natif avant exécution ; Python est interprété instruction par instruction (via bytecode).
QuestionComment affecter une valeur à une variable en Python ?
RéponseAvec l'opérateur = (ex. age = 20). L'affectation lie un nom d'identificateur à un objet en mémoire.
QuestionQuels sont les quatre types scalaires fondamentaux en Python ?
Réponseint (entier), float (décimal), str (texte) et bool (booléen True/False).
QuestionComment convertir explicitement une chaîne "42" en entier ?
RéponseAvec int("42"). Pour un décimal, on utilise float() et pour une chaîne, str().
QuestionRôle respectif de print() et input() ?
Réponseprint() affiche des données sur la sortie standard ; input() invite l'utilisateur à saisir une chaîne au clavier.
QuestionComment fonctionne une f-string en Python ?
RéponseEn préfixant la chaîne par f : les expressions entre accolades {expr} sont évaluées et interpolées directement.
QuestionQue calculent les opérateurs //, % et ** ?
Réponse// donne le quotient entier, % le reste modulo, et ** élève à la puissance.
QuestionPourquoi l'indentation est-elle cruciale en Python ?
RéponseElle définit la structure des blocs (fonctions, boucles, conditions). Une indentation erronée lève une IndentationError.

Module 2 — Structures de contrôle

Questionrange(1, 5) génère quoi ?
Réponse1, 2, 3, 4 — la fin est exclue.
QuestionDifférence break / continue ?
Réponsebreak sort de la boucle ; continue passe à l'itération suivante.
Questionfor ou while pour « jusqu'à saisie valide » ?
Réponsewhile : nombre d'itérations inconnu.
QuestionPourquoi if x = 3: est-il invalide ?
Réponse= affecte, on compare avec ==.
QuestionCombien de tours pour une boucle de 3 tours imbriquée dans une boucle de 2 tours ?
Réponse6 (2 × 3).
QuestionQue font les opérateurs logiques and, or et not ?
Réponseand exige les deux opérandes vrais ; or exige au moins un vrai ; not inverse la valeur booléenne.
QuestionComment s'évalue une cascade if / elif / else ?
RéponseDe haut en bas : l'évaluation s'arrête au premier bloc dont la condition est vraie.
QuestionPourquoi l'ordre des conditions if/elif importe-t-il ?
RéponseLe premier test vrai court-circuite les suivants : il faut ordonner du cas le plus restrictif au plus général.
QuestionQuelles sont les bornes produites par range(debut, fin) ?
RéponseLa borne debut est incluse et la borne fin est exclue (intervalle semi-ouvert [debut, fin[).
QuestionComment s'exécutent des boucles imbriquées ?
RéponseÀ chaque itération de la boucle externe, la boucle interne effectue la totalité de ses itérations.

Module 3 — Fonctions

QuestionUne fonction sans return renvoie ?
RéponseNone.
Questionreturn vs print ?
Réponsereturn transmet une valeur réutilisable ; print affiche seulement.
QuestionQue capture def f(*args) ?
RéponseTous les arguments positionnels, dans un tuple.
QuestionOù Python cherche-t-il un nom ?
RéponseRègle LEGB : Local Enclosing Global Built-in.
QuestionPourquoi éviter items=[] par défaut ?
RéponseLa liste est partagée entre les appels (mutable par défaut).
QuestionComment définir une valeur par défaut pour un paramètre de fonction ?
RéponseDans la signature avec def f(x=0):. L'argument devient optionnel lors de l'appel.
QuestionQuel est l'intérêt des arguments nommés lors d'un appel de fonction ?
RéponsePasser les valeurs en nommant le paramètre (ex. f(sep="-")) sans dépendre de leur position dans la signature.
QuestionDifférence de portée entre variable locale et variable globale ?
RéponseUne variable locale est créée dans une fonction et détruite à sa fin. Une variable globale existe au niveau du module.
QuestionComment importer et utiliser un module de la bibliothèque standard ?
RéponseAvec import nom_module (ex. import math) puis math.sqrt(), ou from math import sqrt.
QuestionÀ quoi sert une docstring dans une fonction Python ?
RéponseChaîne littérale ("""...""") placée en début de fonction pour documenter son rôle, accessible via help().

Module 4 — Structures de données

Question[1,2,3,4][1:3] ?
Réponse[2, 3] (fin exclue).
QuestionComment éviter un KeyError ?
Réponsed.get(cle, defaut) au lieu de d[cle].
Questionsort() vs sorted() ?
Réponsesort() trie sur place (renvoie None) ; sorted() renvoie une copie triée.
QuestionQuel type pour des identifiants sans doublon ?
Réponseset (ensemble).
QuestionUn tuple est-il modifiable ?
RéponseNon : immuable.
QuestionQue désigne un indice négatif comme liste[-1] en Python ?
RéponseIl indexe depuis la fin : -1 désigne le dernier élément, -2 l'avant-dernier.
QuestionDifférence entre append(), insert() et pop() sur une liste ?
Réponseappend(x) ajoute à la fin, insert(i, x) insère à l'indice i, et pop(i) retire et renvoie l'élément.
QuestionQu'est-ce qu'un dictionnaire (dict) en Python ?
RéponseUne collection associative associant des clés uniques à des valeurs (ex. {"nom": "Alice", "note": 18}).
QuestionQuelle est la propriété fondamentale d'un ensemble (set) ?
RéponseTous ses éléments sont uniques (dédoublonnage automatique) et l'ensemble n'est pas ordonné.

Module 5 — Fichiers

QuestionModes r, w, a ?
RéponseLire / écrire (écrase) / ajouter à la fin.
QuestionAvantage de with ?
RéponseFermez le fichier automatiquement, même en cas d'erreur.
QuestionFaut-il appliquer strip() avant int() ?
RéponseCe n'est pas nécessaire pour les blancs autour d'un nombre : int(" 15\n") renvoie 15. strip() reste utile pour nettoyer une chaîne avant d'autres traitements.
QuestionException si le fichier n'existe pas ?
RéponseFileNotFoundError.
QuestionDifférence entre mémoire volatile (RAM) et stockage persistant (disque) ?
RéponseLa RAM est effacée à la fermeture du programme ; les fichiers écrits sur disque persistent après l'arrêt.
QuestionQuelle syntaxe garantit la fermeture automatique d'un fichier ouvert ?
RéponseLe gestionnaire de contexte : with open("data.txt", "r", encoding="utf-8") as f:.
QuestionQue produit l'appel chaine.split(",") sur une chaîne ?
RéponseUne liste de sous-chaînes découpées selon le séparateur virgule (ex. ["a", "b"]).
QuestionPourquoi spécifier encoding="utf-8" lors de l'ouverture d'un fichier ?
RéponsePour garantir la bonne restitution des caractères accentués et éviter les erreurs d'encodage selon le système d'exploitation.

Module 6 — Débogage

QuestionTrois types d'erreurs ?
RéponseSyntaxe, exécution, logique.
QuestionQue fait finally ?
RéponseS'exécute toujours (succès ou erreur).
QuestionPourquoi éviter except: nu ?
RéponseIl masque les bugs inattendus.
QuestionComment lever une erreur volontairement ?
Réponseraise (ex. raise ValueError("…")).
QuestionQuand se produit une SyntaxError en Python ?
RéponseAvant l'exécution, lorsque le code viole la grammaire Python (deux-points omis, parenthèse non fermée).
QuestionQu'indique une traceback lors d'un crash en Python ?
RéponseLa pile des appels ayant mené à l'erreur, le fichier, le numéro de ligne et le type d'exception levée.
QuestionQuel est le rôle du bloc try / except ?
RéponseIntercepter une exception susceptible d'intervenir dans try pour éviter l'arrêt brutal du programme.
QuestionPourquoi cibler un type d'exception précis (ex. except ValueError:) ?
RéponsePour ne traiter que les erreurs attendues sans masquer d'autres dysfonctionnements inattendus.
QuestionQu'est-ce que la PEP 8 en Python ?
RéponseLe guide de style officiel recommandant l'indentation de 4 espaces, le snake_case pour les variables et la clarté du code.
