Module 1 — Environnement et types

QuestionQu'affiche type(10/2) ?
Réponse<class 'float'> — / renvoie toujours un float.
QuestionRésultat de 17 % 5 ?
Réponse2 (17 = 3×5 + 2).
QuestionQue renvoie input() ?
RéponseToujours une chaîne str.
QuestionÉcris une f-string qui affiche x à 2 décimales.
Réponsef"{x:.2f}"
QuestionDifférence // et % ?
Réponse// = quotient entier ; % = reste.

Module 2 — Structures de contrôle

Questionrange(1, 5) génère quoi ?
Réponse1, 2, 3, 4 — la fin est exclue.
QuestionDifférence break / continue ?
Réponsebreak sort de la boucle ; continue passe à l'itération suivante.
Questionfor ou while pour « jusqu'à saisie valide » ?
Réponsewhile : nombre d'itérations inconnu.
QuestionPourquoi if x = 3: est-il invalide ?
Réponse= affecte, on compare avec ==.
QuestionCombien de tours pour for i in range(2): for j in range(3): ?
Réponse6 (2 × 3).

Module 3 — Fonctions

QuestionUne fonction sans return renvoie ?
RéponseNone.
Questionreturn vs print ?
Réponsereturn transmet une valeur réutilisable ; print affiche seulement.
QuestionQue capture def f(*args) ?
RéponseTous les arguments positionnels, dans un tuple.
QuestionOù Python cherche-t-il un nom ?
RéponseRègle LEGB : Local Enclosing Global Built-in.
QuestionPourquoi éviter items=[] par défaut ?
RéponseLa liste est partagée entre les appels (mutable par défaut).

Module 4 — Structures de données

Question[1,2,3,4][1:3] ?
Réponse[2, 3] (fin exclue).
QuestionComment éviter un KeyError ?
Réponsed.get(cle, defaut) au lieu de d[cle].
Questionsort() vs sorted() ?
Réponsesort() trie sur place (renvoie None) ; sorted() renvoie une copie triée.
QuestionQuel type pour des identifiants sans doublon ?
Réponseset (ensemble).
QuestionUn tuple est-il modifiable ?
RéponseNon : immuable.

Module 5 — Fichiers

QuestionModes r, w, a ?
RéponseLire / écrire (écrase) / ajouter à la fin.
QuestionAvantage de with ?
RéponseFerme le fichier automatiquement, même en cas d'erreur.
QuestionPourquoi strip() avant int() ?
RéponseLa ligne contient un \n qu'il faut retirer.
QuestionException si le fichier n'existe pas ?
RéponseFileNotFoundError.

Module 6 — Débogage

QuestionTrois types d'erreurs ?
RéponseSyntaxe, exécution, logique.
QuestionQue fait finally ?
RéponseS'exécute toujours (succès ou erreur).
QuestionPourquoi éviter except: nu ?
RéponseIl masque les bugs inattendus.
QuestionComment lever une erreur volontairement ?
Réponseraise (ex. raise ValueError("…")).
