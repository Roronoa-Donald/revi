Chapitre 1 — Environnement, variables et types de données

Module 1 ≈ 2 h de travail Gratuit
Mise en situation

Vous viens d'être recruté comme stagiaire IT. Votre première mission : écrire un petit script qui demande à un utilisateur son nom et son année de naissance, puis affiche « Bonjour <nom>, vous avez environ <âge> ans ». Vous n’avez jamais écrit une ligne de Python. Ce chapitre te donne exactement ce qu'il faut : savoir installer et lancer Python, stocker une information dans une variable, connaître son type, la faire parler avec print() et écouter l'utilisateur avec input().

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. Lancer un script Python et le REPL, et diagnostiquer un problème de PATH ;
  2. déclarer une variable et prédire son type (int, float, str, bool) ;
  3. convertir un type avec int(), float(), str() ;
  4. utiliser les opérateurs arithmétiques, de comparaison et logiques ;
  5. lire une entrée avec input() et la convertir pour calculer ;
  6. reconnaître et corriger une IndentationError et un NameError.

1. Ce que Python est (et pourquoi cela change votre travail)

Définition. Python est un langage de haut niveau, interprété, multi-paradigme (impératif, orienté objet, fonctionnel) et à typage dynamique. Créé par Guido van Rossum en 1989 et publié en 1991, il est aujourd'hui standard en web, data science, automatisation et DevOps.

TermeCe que ça veut dire concrètement
Haut niveauVous écris des concepts (listes, boucles), pas de gestion mémoire manuelle.
InterprétéPas de compilation préalable : l'interpréteur lit et exécute. Cycle d'essai très rapide.
Typage dynamiqueLe type d'une variable est déduit de la valeur, il n'est pas déclaré à l'avance.
Multi-paradigmeVous peux écrire des fonctions, des classes, ou du code fonctionnel dans le même programme.
Niveau 1 — Intuition

Un langage compilé (C++) ressemble à un livre qu'on traduit entièrement avant de le lire. Python ressemble à un traducteur qui lit à voix haute : vous écrivez une phrase, il la dit tout de suite. C'est pour ça que vous testez plus vite… mais que Python est en général plus lent à l'exécution.

Niveau 2 — Technique

Python transforme votre fichier .py en bytecode, exécuté par la machine virtuelle Python (PVM). Le REPL (Read-Eval-Print Loop) applique le même moteur, instruction par instruction. Conséquence pratique : une erreur de syntaxe est détectée au chargement du fichier, mais une erreur de logique n'apparaît qu'à la ligne exécutée.

2. Variables et types de base

Définition. Une variable est un nom qui pointe vers une valeur en mémoire. En Python, la déclaration et l'affectation se font en une seule fois avec =.

nombre_utilisateurs = 150          # int  : entier
prix_ttc = 12.5                    # float: nombre à virgule
nom_application = "GestionStock"   # str  : chaîne de caractères
service_demarre = True             # bool : booléen (True / False)
TypeExemplesÀ retenir
int0, -7, 42Entiers, précision illimitée en Python.
float3.14, -2.0Décimaux ; attention aux arrondis binaires (0.1 + 0.2).
str"a", 'abc'Texte entre guillemets ou apostrophes.
boolTrue, FalseMajuscule obligatoire !
NoneTypeNoneAbsence de valeur.
Erreurs classiques — types
  • true / false en minuscules NameError : Python attend True/False.
  • Oublier les guillemets : nom = Alice cherche une variable Alice, et échoue.
  • Comparer 1 (int) et "1" (str) : 1 == "1" vaut False.
Mnémotechnique

I-F-S-B = « Il Faut Savoir Bien » int, float, str, bool. Les 4 types que 90 % de vos exercices utiliseront.

2.1 Convertir : la fonction qui sauve

age_texte = "21"
age_nombre = int(age_texte)     # "21" -> 21
prix = float("9.99")            # "9.99" -> 9.99
message = str(42)               # 42 -> "42"
Pourquoi convertir ?

input() renvoie toujours du texte. "20" + "5" donne "205" (concaténation), alors que int("20") + 5 donne 25. C'est la source n°1 de bugs chez les débutants.

4. Exemples travaillés

Exemple ATrès simple

Énoncé. Afficher le prix TTC d'un article HT à 12,5 € avec 18 % de TVA.

prix_ht = 12.5
tva = 0.18
prix_ttc = prix_ht * (1 + tva)
print(f"Prix TTC : {prix_ttc:.2f} €")
Prix TTC : 14.75 €

Pourquoi cette méthode ? On écrit la formule avant de l'afficher : la logique de calcul reste testable. Le format :.2f arrondit à 2 décimales à l'affichage.

Erreur classique possible
Écrire prix_ht * 1,18 avec une virgule : Python lit deux arguments et lève TypeError. En code, le séparateur décimal est le point.
Exemple BIntermédiaire

Énoncé. Demander username et année de naissance, afficher un message avec l'âge approximatif.

prenom = input("Quel est ton prénom ? ")
annee = int(input("Année de naissance ? "))   # conversion obligatoire
age = 2026 - annee
print(f"Bonjour {prenom}, tu as environ {age} ans.")
Quel est votre prénom ? Léa Année de naissance ? 2003 Bonjour Léa, vous avez environ 23 ans.

Analyse étape par étape. 1) input() renvoie du texte 2) on le convertit avec int() 3) on calcule 4) on formate avec une f-string. Oublier l'étape 2 donne TypeError: unsupported operand type(s).

Exemple CDifficile

Énoncé. Décomposer un nombre de secondes (ex. 3725) en heures / minutes / secondes.

total = 3725
heures = total // 3600          # 1
reste = total % 3600            # 125
minutes = reste // 60           # 2
secondes = reste % 60           # 5
print(f"{heures}h {minutes}min {secondes}s")
1h 2min 5s

Vérification. 1×3600 + 2×60 + 5 = 3725 . La méthode division entière + modulo est universelle pour décomposer une quantité en unités (secondes, centimes, octets…).

Utilité IT

Les scripts Python sont partout dans l'administration système et le DevOps : convertir des tailles (// et %), formater des rapports (f-strings), valider des entrées utilisateur. Ces trois gestes de base reviennent dans presque tous les scripts de production.

5. Exercices (5 niveaux)

Niveau 1 — Acquisition

1. Quel est le type de resultat ? resultat = 10 / 2

2. Corrige : actif = true.

3. Que vaut 17 % 5 ?

Correction
1. float (car / renvoie toujours un float) 5.0.   2. actif = True (majuscule).   3. 2 (17 = 3×5 + 2).
Niveau 2 — Application

4. Écrivez un script qui demande deux nombres et affiche leur somme, leur produit et leur moyenne.

5. Convertissez 1500 minutes en heures et minutes.

Correction
a = float(input("a ? ")); b = float(input("b ? "))
print("somme", a + b, "produit", a * b, "moyenne", (a + b) / 2)

m = 1500
print(m // 60, "h", m % 60, "min")   # 25 h 0 min
Pour la moyenne, penser aux parenthèses : a + b / 2 ≠ (a + b) / 2.
Niveau 3 — Raisonnement

6. Un énoncé dit : « le programme doit afficher 5 et non 5.0 ». Parmi 10/2, 10//2, int(10/2), lesquels sont acceptables ? Lequel est le plus propre ?

7. Explique pourquoi "3" * 3 ne lève pas d'erreur et vaut "333".

Correction
6. 10//2 et int(10/2) affichent 5. Le plus propre est 10//2 : il exprime directement l'intention « division entière », sans conversion inutile. 7. * sur une chaîne est une répétition : "3"*3 = "3"+"3"+"3" = "333". L'opérateur a un sens différent selon le type des opérandes (surcharge).
Niveau 4 — Examen

8. Écrivez un programme qui demande le prix HT d'un article, la quantité, puis affichez le total TTC (TVA 18 %) arrondi à 2 décimales, sous la forme : « Total : X € pour N articles ».

Correction détaillée
prix_ht = float(input("Prix HT unitaire ? "))
qte = int(input("Quantité ? "))
total = prix_ht * qte * 1.18
print(f"Total : {total:.2f} € pour {qte} articles")
Points de barème : conversion float/int (sinon TypeError ou concaténation), application de la TVA, format :.2f. Erreur fréquente : oublier int() sur la quantité et obtenir une chaîne répétée.
Niveau 5 — Challenge

9. Sans utiliser // ni %, écris une fonction qui convertit un nombre de centimes en euros et centimes. (Indice : int() et la soustraction.)

Piste et correction
centimes = 285
euros = int(centimes / 100)
reste = centimes - euros * 100
print(f"{euros} € et {reste} centimes")   # 2 € et 85 centimes
On reconstruit le reste par soustraction. Cette reformulation prouve qu'on comprend pourquoi le modulo marche : c'est le reste de la division euclidienne.

6. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute le code et la validation fait tourner des jeux de tests indépendants : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire le code de la solution — c’est le principe de l’exercice.

Exercice 1 — Conversion Celsius vers Fahrenheit

Python Niveau 1 — Acquisition

Objectif : Écrire une fonction qui convertit une température, puis l’appeler avec une valeur lue sur l’entrée standard.

Le programme reçoit un entier sur l’entrée standard. Complétez la fonction convertir_temperature pour qu’elle renvoie la valeur en degrés Fahrenheit, puis affichez son résultat.

Formule : F = C × 9/5 + 32.

Entrée du programme
25
Sortie attendue
77.0

25 °C correspondent à 77 °F.

Deux indices, rédigés en mots
  1. Une fonction qui n’a pas de return renvoie None : si None s’affiche, c’est qu’un print a remplacé le return.
  2. Pour obtenir un résultat décimal, la division doit être décimale : en Python, 9 / 5 vaut 1.8 alors que 9 // 5 vaut 1.

Exercice 2 — Moyenne de trois notes, formatée

Python Niveau 2 — Application

Objectif : Lire plusieurs valeurs et présenter un résultat décimal au format demandé.

Le programme reçoit trois lignes, chacune contenant une note entière. Affichez leur moyenne sur une seule ligne, avec exactement deux décimales (par exemple 12.33).

Entrée du programme
12
15
9
Sortie attendue
12.00

12 + 15 + 9 = 36, et 36 / 3 = 12.00.

Deux indices, rédigés en mots
  1. La division entière // tronque le résultat : pour une moyenne, c’est la division décimale / qu’il faut.
  2. L’arrondi se fait au moment de l’affichage, pas dans le calcul : le format d’un f-string permet de fixer le nombre de décimales.

Exercice 3 — Découpage d’une durée

Python Niveau 3 — Raisonnement

Objectif : Utiliser la division entière et le reste pour décomposer une valeur.

Le programme reçoit un nombre entier de secondes. Affichez la durée découpée sous la forme H h M min S s.

Pour 3723 secondes, la sortie attendue est 1 h 2 min 3 s.

Entrée du programme
3723
Sortie attendue
1 h 2 min 3 s

1 h 2 min 3 s : 3600 + 120 + 3.

Deux indices, rédigés en mots
  1. Une heure contient 3600 secondes : la division entière donne le nombre d’heures complètes, le reste ce qui reste à répartir.
  2. Le même raisonnement s’applique une deuxième fois pour extraire les minutes du reste, et le reste final est la réponse en secondes.

7. QCM — niveau examen

Que vaut type(7 // 2) ?

// renvoie un entier (division entière). / aurait renvoyé un float.

Résultat de print("2" + "3") ?

Sur deux chaînes, + concatène. Pour additionner, il faut int("2") + int("3").

Que renvoie input() ?

Toujours str : la conversion (int/float) est à votre charge.

Quelle ligne lève une erreur ?

false minuscule n'existe pas NameError. Python attend False.

Après x = 3; x = x * 2, que vaut x ?

Une variable peut être réaffectée : on évalue d'abord à droite, puis on affecte à gauche.

Qu'affiche print(f"{3.14159:.2f}") ?

Le format .2f demande 2 décimales : 3.14 (arrondi). 3.1 = 1 décimale, 3.1416 = 4 décimales.

Quel opérateur donne le reste d'une division ?

% = modulo. // = quotient entier, / = division réelle.

Pour un total de 100 pièces réparties en boîtes de 12, combien de boîtes pleines et combien de pièces restantes ?

100 // 12 = 8 (boîtes pleines) ; 100 % 12 = 4 (pièces restantes).

Quelle affirmation est FAUSSE ?

Le typage est dynamique : aucune déclaration de type n'est nécessaire avant l'affectation.

Objectif « afficher la note 15 sur 20 au format "15/20" ». Quelle ligne est correcte si n = 15 ?

n + "/20" lève un TypeError (int + str) ; "n/20" affiche le texte littéral. Seule la f-string insère la valeur.

8. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Concaténer au lieu d'additionner : oublier int()/float() sur input().
  • / vs // : un résultat attendu « entier » trahit souvent l'usage de /.
  • True/False en minuscules.
  • Virgule décimale 1,5 au lieu de 1.5.
  • Indentation incohérente (espaces vs tabulations) IndentationError.

9. Méthodologie de résolution

Quand vous voyez un énoncé « entrée calcul sortie »
  1. Lister les entrées et leur type réel (nombre ? texte ?).
  2. Écrire les conversions immédiatement après chaque input().
  3. Écrire la formule sur une ligne séparée, jamais directement dans le print.
  4. Formater la sortie (f-string, :.2f si décimal).
  5. Vérifier avec un jeu de valeurs simple (ex. 10 s, 100 centimes).
