Chapitre 2 — Structures de contrôle : logique et automatisation

Module 2 ≈ 2 h 30 Contenu protégé
Mise en situation

Un client se plaint : la boutique en ligne applique une remise à tout le monde, y compris aux commandes de 5 €. Votre chef te demande une règle précise : remise de 10 % si le panier dépasse 100 €, sinon rien, puis un rappel à l'utilisateur tant qu'il n'a pas saisi un montant valide. Deux problèmes, deux outils : les conditions (if) et les boucles (while, for). Ce chapitre vous apprend à faire « décider » et « répéter » un programme.

Objectifs pédagogiques
  1. Écrire une expression booléenne correcte avec and, or, not ;
  2. choisir entre if, elif et else selon un énoncé ;
  3. écrire une boucle for sur range() et sur une séquence ;
  4. écrire une boucle while avec une condition de sortie garantie ;
  5. contrôler une boucle avec break, continue, pass ;
  6. diagnostiquer une boucle infinie.

1. Expressions booléennes

Définition. Une expression booléenne vaut True ou False. Elle combine des comparaisons avec les opérateurs logiques.

OpérateurVrai si…Exemple
andles DEUX sont vraisage >= 18 and age < 65
orAU MOINS UN est vrairole == "admin" or role == "root"
notl'expression est faussenot est_vide
Niveau 1 — Intuition

and = « il faut tout ». or = « il en suffit d'un ». not = « l'inverse ». Un panier est livrable si stock > 0 and adresse_valide.

Piège classique

En Python on écrit a < b < c (chaîné), mais jamais if x = 3 : = affecte, == compare. if x = 3: lève une SyntaxError.

2. Conditions : if / elif / else

if panier > 100:
    remise = 0.10
elif panier > 50:
    remise = 0.05
else:
    remise = 0.0
Niveau 2 — Technique

Les tests sont évalués de haut en bas et s'arrêtent au premier vrai. L'ordre des elif change donc le résultat : mettre > 50 avant > 100 donnerait une remise de 5 % à une commande de 120 €. C'est le piège d'ordonnancement.

Utilité IT

Validation de formulaires, autorisations d'accès, routage de requêtes : tout système décide avec des conditions. La clarté de l'ordre des elif est une vraie source de bugs en production.

3. Boucle for

La boucle for parcourt une séquence (liste, chaîne, range) :

for i in range(5):          # 0,1,2,3,4
    print(i)

for lettre in "Python":     # P,y,t,h,o,n
    print(lettre)

total = 0
for note in [12, 15, 9]:
    total = total + note
print(total, total / 3)
0 1 2 3 4 P y t h o n 36 12.0
range() — la règle exacte

range(début, fin, pas) va de début inclus à fin exclu. Donc range(1, 4) 1, 2, 3. range(0, 10, 2) 0,2,4,6,8. Retiens : « le dernier n'est jamais dedans ».

4. Boucle while

montant = -1
while montant <= 0:
    montant = float(input("Montant (> 0) ? "))
print("Merci, montant accepté :", montant)
Boucle infinie

Si la condition ne devient jamais fausse, le programme ne s'arrête jamais. Trois causes fréquentes : variable jamais modifiée dans la boucle ; while True: sans break ; comparaison impossible (while x != 0 alors que x augmente).

for ou while ?

for quand vous connaissez la collection à parcourir (ou un nombre de tours fixé). while quand vous répètez jusqu'à ce qu'une condition change (saisie valide, jeu, attente réseau).

5. Contrôle du flux : break, continue, pass

Mot-cléEffet
breakSort immédiatement de la boucle.
continuePassez à l'itération suivante (sans terminer celle-ci).
passNe fait rien — utile comme bouchon temporaire.
for n in range(1, 10):
    if n == 5:
        break          # on arrête à 5
    if n % 2 == 0:
        continue       # on ignore les pairs
    print(n)           # affiche 1, 3
1 3

6. Exemples travaillés

Exemple ATrès simple

Énoncé. Afficher « majeur » si l'âge ≥ 18, sinon « mineur ».

age = 20
if age >= 18:
    print("majeur")
else:
    print("mineur")
majeur
Exemple BIntermédiaire

Énoncé. Calculer la somme des entiers de 1 à n (sans formule).

n = 100
total = 0
for i in range(1, n + 1):     # +1 car la fin est exclue !
    total += i
print(total)
5050

Analyse. La borne n+1 est le piège central : range(1, 100) s'arrête à 99 et donne 4950. Toujours vérifier la borne supérieure.

Exemple CDifficile

Énoncé. Compter les voyelles d'une phrase, en ignorant les majuscules.

phrase = "Bonjour Python"
voyelles = "aeiouy"
compteur = 0
for c in phrase.lower():
    if c in voyelles:
        compteur += 1
print(compteur)
4

Pourquoi lower() ? Sans lui, « Bonjour Python » contient les majuscules 'B' et 'P' — ce ne sont pas des voyelles, mais le 'o' de « Bonjour » reste un 'o' : la conversion uniformise la comparaison. Vérifie : Bonjour Python 4.

7. Exercices (5 niveaux)

Niveau 1 — Acquisition

1. Que vaut True and (5 > 3) ? 2. Combien de tours fait for i in range(3): ? 3. Que fait continue ?

Correction
1. True.   2. 3 tours (0,1,2).   3. Il saute à l'itération suivante sans exécuter le reste du bloc.
Niveau 2 — Application

4. Affichez tous les nombres pairs de 1 à 20. 5. Affichez la table de multiplication de 7.

Correction
for i in range(2, 21, 2):
    print(i)

for i in range(1, 11):
    print(f"7 x {i} = {7 * i}")
Niveau 3 — Raisonnement

6. Ce code boucle-t-il ?

i = 0
while i < 5:
    print(i)

7. Pourquoi for i in range(5, 0, -1) affiche-t-il 5,4,3,2,1 ?

Correction
6. Oui, boucle infinie : i n'est jamais incrémenté (il manque i += 1). 7. Le pas est -1 : on part de 5 inclus jusqu'à 0 exclu en descendant.
Niveau 4 — Examen

8. Écrivez un programme qui demande un mot de passe jusqu'à obtenir « python123 » (mot de passe « correct »), et limite à 3 tentatives.

Correction détaillée
tentatives = 0
succes = False
while tentatives < 3 and not succes:
    saisie = input("Mot de passe ? ")
    tentatives += 1
    if saisie == "python123":
        succes = True
print("Accès autorisé" if succes else "Accès refusé")
Barème : boucle bornée (3), condition double (saisie correcte ET tentatives), message final. Piège : oublier tentatives += 1 boucle infinie.
Niveau 5 — Challenge

9. Sans utiliser min(), trouve le plus petit élément d'une liste en une seule boucle.

Correction
nombres = [42, 7, 19, 3, 88]
plus_petit = nombres[0]
for n in nombres:
    if n < plus_petit:
        plus_petit = n
print(plus_petit)   # 3
L'algorithme « champion en cours » : on initialise avec le premier, puis on remplace à chaque valeur plus petite.

Exercice 1 — Somme des entiers de 1 à n

Python Niveau 2 — Application

Objectif : Écrire une boucle d’accumulation sans utiliser sum().

Le programme reçoit un entier n. Affichez la somme 1 + 2 + … + n en utilisant une boucle, sans sum().

Entrée du programme
10
Sortie attendue
55

1 + 2 + … + 10 = 55.

Deux indices, rédigés en mots
  1. La borne de fin d’un range n’est jamais atteinte : pour aller jusqu’à n, il faut lui demander n + 1.
  2. Un accumulateur s’initialise avant la boucle : s’il est initialisé dedans, il repart de zéro à chaque tour.

Exercice 2 — Décision d’admission

Python Niveau 3 — Raisonnement

Objectif : Enchaîner des conditions dans le bon ordre à l’intérieur d’une boucle.

Le programme reçoit un entier n, puis n notes entières. Pour chaque note, affichez sur une ligne :

  • Admis si elle vaut au moins 10 ;
  • Rattrapage si elle est comprise entre 8 et 9 inclus ;
  • Ajourné sinon.
Entrée du programme
3
12
9
5
Sortie attendue
Admis
Rattrapage
Ajourné

12 est admis, 9 passe en rattrapage, 5 est ajourné.

Deux indices, rédigés en mots
  1. L’ordre des conditions change le résultat : commencez toujours par tester le cas le plus exigeant.
  2. Un enchaînement de conditions s’écrit en cascade : la première branche satisfaite prend la main et les suivantes sont ignorées.

Exercice 3 — Somme des chiffres d’un nombre

Python Niveau 3 — Raisonnement

Objectif : Décomposer un entier chiffre par chiffre et accumuler le résultat.

Le programme reçoit un entier positif. Affichez la somme de ses chiffres.

Entrée du programme
4729
Sortie attendue
22

4 + 7 + 2 + 9 = 22.

Deux indices, rédigés en mots
  1. Un nombre peut se parcourir caractère par caractère une fois converti en texte : chaque morceau redevient un entier pour le calcul.
  2. Autre voie sans conversion : le reste de la division par 10 isole le dernier chiffre, et la division entière par 10 le supprime.

9. QCM — niveau examen

Combien de valeurs contient range(1, 5) ?

1,2,3,4 4 valeurs. La borne de fin est exclue.

Que vaut not (3 > 5) ?

3 > 5 est False, et not False vaut True.

Ce code affiche : for i in range(3): print(i, end=" ")

range(3) démarre à 0 et s'arrête avant 3.

Quel mot-clé sort d'une boucle ?

break sort ; continue saute ; pass ne fait rien.

Que fait ce code ? x = 10; while x > 0: x -= 3

x décroît : 10,7,4,1,-2 la condition devient fausse à -2. Pas de boucle infinie.

Le programme if n % 2 == 0: print("pair") avec n = 7 affiche ?

7 % 2 = 1 ≠ 0, la condition est fausse aucune sortie.

Quel est le résultat de la somme 1+2+…+10 ?

10 × 11 / 2 = 55. Vérifiez avec une boucle range(1, 11) (borne 11 exclue = jusqu'à 10).

Dans if a: … elif b: … else:, que se passe-t-il si a et b sont vrais ?

L'évaluation s'arrête au premier vrai : le elif est ignoré.

Combien de fois "abc" est-il affiché ? for i in range(2): for j in range(3): print("abc")

Boucles imbriquées : 2 × 3 = 6.

Quelle boucle est la plus adaptée pour « répéter jusqu'à ce que l'utilisateur saisisse 'quit' » ?

On ne connaît pas le nombre d'itérations while est le bon outil.

10. Erreurs classiques

À reconnaître en examen
  • Borne de range oubliée (n+1) somme ou comptage faux d'une unité.
  • = au lieu de == dans un test.
  • else if (comme en C) au lieu de elif.
  • Boucle infinie : variable non modifiée dans le while.
  • Ordre des elif qui rend une branche inatteignable.

11. Méthodologie de résolution

« Compter / accumuler » et « répéter jusqu'à »

Accumuler : initialise un accumulateur avant la boucle (total = 0, compteur = 0), puis mets-le à jour dans la boucle. Répéter jusqu'à : identifie la condition de sortie, écris-la en premier, puis le corps.

12. Révision active

Résumé essentiel
  • and/or/not combinent les comparaisons.
  • if/elif/else : évaluation de haut en bas, arrêt au premier vrai.
  • range(début, fin_exclue, pas).
  • for = parcours ; while = répétition conditionnelle.
  • break sort, continue saute, pass ne fait rien.

Checklist de maîtrise

  • Je sais garantir qu'une boucle while se termine.

  • Je sais accorder l'ordre des elif à l'énoncé.
