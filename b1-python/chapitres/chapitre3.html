Chapitre 3 — Fonctions : modularité et réutilisabilité

Module 3 ≈ 2 h 30 Contenu protégé
Mise en situation

Votre script de gestion de notes fonctionne… mais vous avez copié-collé le calcul de moyenne quatre fois. Une règle change ? Vous devez corriger quatre endroits, et vous oubliez le quatrième. Votre chef te dit : « fais-en une fonction ». Une fonction, c'est ce que vous écrivez une fois et appelles partout. Ce chapitre vous apprend à décomposer un problème en fonctions testables — la compétence n°1 attendue en examen et en entreprise.

Objectifs pédagogiques
  1. Définir et appeler une fonction avec def ;
  2. distinguer return et print ;
  3. utiliser paramètres positionnels, par défaut, et *args/**kwargs ;
  4. expliquer la portée locale/globale et l'erreur UnboundLocalError ;
  5. utiliser des fonctions intégrées (len, sum, sorted, max) et un module (math, random) ;
  6. écrire une docstring et une lambda simple.

1. Définir et appeler

def moyenne(notes):
    """Retourne la moyenne d'une liste de notes."""
    return sum(notes) / len(notes)

resultat = moyenne([12, 15, 9])
print(resultat)         # 12.0
Niveau 1 — Intuition

Une fonction est une recette nommée. Les paramètres sont les ingrédients, return est le plat servi. Vous pouvez réutiliser la recette autant de fois que vous voulez, avec d'autres ingrédients.

Niveau 2 — Technique

def crée un objet fonction et lie le nom. L'appel moyenne([12,15,9]) crée une portée locale où notes existe le temps de l'exécution. À la fin, la portée est détruite : notes n'est pas visible à l'extérieur.

2. return vs print

returnprint
RôleRenvoie une valeur au code appelantAffichez du texte à l'écran
Réutilisable ?Oui : x = f()Non : on ne récupère rien
Sans instructionRenvoie None—
Piège d'examen n°1

Une fonction qui affiche au lieu de retourner est un piège classique. Si l'énoncé dit « écrire une fonction qui calcule la moyenne », elle doit return, pas print. x = f() avec f qui fait seulement print donne x = None.

3. Types de paramètres

def saluer(nom, salutation="Bonjour"):   # valeur par défaut
    return f"{salutation}, {nom} !"

saluer("Ali")              # "Bonjour, Ali !"
saluer("Ali", "Salut")     # "Salut, Ali !"   (positionnel)
saluer(salutation="Hey", nom="Ali")  # (nommé)

def total(*args):          # nombre variable d'arguments
    return sum(args)
total(1, 2, 3)             # 6
Valeur par défaut mutable

N'utilise jamais une liste comme valeur par défaut : def f(items=[]) conserve la même liste entre les appels. Écrivez def f(items=None): items = items or [].

4. Portée des variables

x = 10                     # globale

def f():
    x = 3                  # LOCALE : masque la globale
    return x

print(f(), x)              # 3 10
Règle LEGB

Python cherche un nom dans l'ordre : Local Enclosing Global Built-in. Pour modifier une globale depuis une fonction, on utilisait global — à éviter : une fonction qui ne communique que par return est plus testable.

5. Modules standards et fonctions intégrées

import math
import random

print(math.sqrt(16))          # 4.0
print(math.floor(3.7))        # 3
print(random.randint(1, 6))   # un dé 1..6

nombres = [3, 1, 2]
print(len(nombres), sum(nombres), max(nombres), sorted(nombres))
4.0 3 4 3 6 3 [1, 2, 3]
Utilité IT

Ne réinvente pas : statistics.mean, math, random, json font partie de la bibliothèque standard. Un bon développeur connaît l'existant avant d'écrire son propre code.

6. Lambda et docstrings

carre = lambda x: x * x
print(carre(5))               # 25

def tva(prix):
    """Retourne le prix TTC (TVA 18 %)."""
    return prix * 1.18

7. Exemples travaillés

Exemple ATrès simple

Fonction qui retourne le carré.

def carre(n):
    return n * n
print(carre(7))   # 49
Exemple BIntermédiaire

Énoncé. Fonction qui retourne moyenne ET maximum d'une liste.

def stats(notes):
    return sum(notes) / len(notes), max(notes)

moy, top = stats([12, 15, 14, 9, 18])
print("Moyenne :", moy, "Max :", top)
Moyenne : 13.6 Max : 18

Analyse. return a, b renvoie en réalité un tuple, déballé à l'appel. C'est le motif utilisé dans l'exercice 1 du sujet d'examen final.

Exemple CDifficile

Énoncé. Fonction est_premier(n) sans liste ni import.

def est_premier(n):
    if n < 2:
        return False
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False
    return True

print([x for x in range(2, 20) if est_premier(x)])
[2, 3, 5, 7, 11, 13, 17, 19]

Pourquoi s'arrêter à √n ? Si n = a × b, l'un des deux facteurs est ≤ √n. Inutile de tester au-delà. Le return False interne sort dès qu'un diviseur est trouvé (efficacité).

8. Exercices (5 niveaux)

Niveau 1 — Acquisition

1. Quelle valeur retourne une fonction sans return ? 2. Corrige : def f(x) return x+1.

Correction
1. None. 2. Il manque deux-points et indentation : def f(x): puis ligne indentée return x + 1.
Niveau 2 — Application

3. Écrivez convertir_temperature(c) retournant la valeur Fahrenheit (F = C × 9/5 + 32).

Correction
def convertir_temperature(c):
    return c * 9 / 5 + 32
print(convertir_temperature(25))   # 77.0
Niveau 3 — Raisonnement

4. Explique pourquoi x = f() vaut None si f ne contient qu'un print.

5. Que vaut total(1, 2, 3) avec def total(*args): return sum(args) ?

Correction
4. print affiche mais ne renvoie rien : toute fonction sans return renvoie None. 5. args = (1, 2, 3), sum 6.
Niveau 4 — Examen

6. (type sujet final) Complète une fonction calcul_statistiques(liste_notes) qui retourne (moyenne, max_note). Donne aussi le résultat pour [12, 15, 14, 9, 18].

Correction détaillée
def calcul_statistiques(liste_notes):
    total = 0
    for note in liste_notes:
        total += note
    moyenne = total / len(liste_notes)
    max_note = max(liste_notes)
    return moyenne, max_note

# bonus : une seule boucle, sans sum() ni max()
Résultat : moyenne = 13.6, max = 18. Barème : boucle/bon accumulateur, division par len, recherche du max, retour de couple.
Niveau 5 — Challenge

7. Écrivez compte_mots(texte) qui retourne un dictionnaire {mot: fréquence}.

Correction
def compte_mots(texte):
    frequences = {}
    for mot in texte.lower().split():
        frequences[mot] = frequences.get(mot, 0) + 1
    return frequences
print(compte_mots("le chat le chien le rat"))
# {'le': 3, 'chat': 1, 'chien': 1, 'rat': 1}

Exercice 1 — calcul_statistiques — sujet d’examen

Python Niveau 3 — Raisonnement

Objectif : Écrire une fonction qui renvoie plusieurs valeurs et la consommer depuis le programme principal.

Écrivez calcul_statistiques(liste_notes) qui renvoie un couple (moyenne, max_note) en parcourant la liste une seule fois, sans utiliser sum() ni max().

Le programme lit un entier n, puis n notes, et affiche la moyenne avec deux décimales suivie du maximum, séparés par un espace.

Entrée du programme
5
12
15
14
9
18
Sortie attendue
13.60 18

Moyenne 13.60 et maximum 18.

Deux indices, rédigés en mots
  1. Une fonction ne renvoie qu’une seule chose : pour en faire passer deux, il faut les grouper dans un couple, en les séparant par une virgule.
  2. Le maximum se cherche en mémorisant un candidat, puis en le remplaçant dès qu’un élément le dépasse : le premier élément de la liste est un bon point de départ.

Exercice 2 — Division qui ne plante pas

Python Niveau 3 — Raisonnement

Objectif : Empêcher une exception de faire planter le programme.

Écrivez diviser(a, b) qui renvoie le résultat de a / b, ou la chaîne erreur si b vaut 0. Aucune exception ne doit remonter : le programme doit se terminer normalement dans tous les cas.

Entrée du programme
10
2
Sortie attendue
5.0

Division normale : 5.0.

Deux indices, rédigés en mots
  1. Une division par zéro n’est pas une valeur : l’interpréteur interrompt le programme. Il faut donc empêcher l’opération d’être tentée.
  2. Deux stratégies existent : vérifier avant de calculer, ou tenter le calcul et rattraper l’erreur. Dans les deux cas, la valeur renvoyée doit être la même.

Python Niveau 4 — Examen

Objectif : Écrire une fonction booléenne avec sortie anticipée.

Écrivez est_premier(n) qui renvoie True ou False. Le programme lit un entier et affiche oui ou non.

10. QCM — niveau examen

Que renvoie une fonction sans return ?

Toute fonction sans return explicite renvoie None.

Avec def f(x=2): return x*3, que vaut f() ?

La valeur par défaut x=2 s'applique 2 × 3 = 6. Aucune erreur.

Avec la même fonction, que vaut f(4) ?

L'argument fourni remplace le défaut : 4 × 3 = 12.

Que vaut x après def f(): x = 5 puis f(), si x n'existait pas avant ?

x est local à f : il n'existe pas à l'extérieur NameError.

Quelle affirmation est vraie ?

return transmet la valeur au code appelant ; print ne fait qu'afficher.

Résultat de def g(*a): return len(a) puis g(1,2,3,4) ?

*a capture les 4 arguments dans un tuple len = 4.

Que vaut math.floor(3.9) ?

floor arrondit vers le bas 3 (≠ round qui donnerait 4).

Quel code est correct pour une fonction à valeur par défaut ?

Les paramètres avec valeur par défaut doivent venir après ceux sans défaut.

Que vaut stats([2,4,6]) si stats fait return min(l), max(l) ?

L'ordre du return est respecté : d'abord min, puis max.

Quelle est la bonne façon d'obtenir un entier aléatoire entre 1 et 6 ?

random.randint(a, b) inclut les deux bornes. math n'a pas de randint.

Pourquoi éviter def f(items=[]) ?

La valeur par défaut n'est créée qu'une fois : les modifications persistent entre les appels. Préférer None.

11. Erreurs classiques

À reconnaître en examen
  • Confondre return et print (le plus fréquent).
  • Oublier les deux-points ou l'indentation après def.
  • Paramètre avec défaut placé avant un paramètre requis.
  • Vouloir lire une variable locale hors de la fonction (NameError).
  • Défaut mutable items=[].

12. Méthodologie de résolution

Décomposer un énoncé en fonctions
  1. Repère les verbes de l'énoncé : « calculer », « afficher », « vérifier » une fonction chacun.
  2. Une fonction = une responsabilité. Si vous écrivez « et », coupe en deux.
  3. Chaque fonction : entrées (paramètres) traitement sortie (return).
  4. Testez chaque fonction isolément sur un exemple simple avant de les assembler.

13. Révision active

Résumé essentiel

  • return ≠ print ; sans return None.
  • Paramètres : positionnels, nommés, par défaut, *args.
  • Portée : une variable locale n'existe pas dehors (LEGB).
  • Bibliothèque standard : math, random, sum, sorted…
