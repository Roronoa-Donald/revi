Chapitre 5 — Manipulation des fichiers : stocker et récupérer l'information

Module 5 ≈ 2 h 30 Contenu protégé
Mise en situation

Votre programme calcule les moyennes… mais dès qu'il s'arrête, tout est perdu. Le client veut conserver les résultats d'aujourd'hui et les relire demain. Une variable disparaît à la fin du programme : il faut écrire dans un fichier. Ce chapitre vous apprend à lire (donnees.txt), à écrire (resultats.txt), et à gérer proprement les erreurs de fichier — exactement l'exercice 3 du sujet d'examen final.

Objectifs pédagogiques
  1. Distinguer mémoire volatile et stockage persistant ;
  2. ouvrir un fichier avec open() et le fermer proprement avec with ;
  3. lire (r), écrire (w), ajouter (a) ;
  4. parcourir un fichier ligne par ligne et nettoyer chaque ligne (strip) ;
  5. intercepter une erreur de fichier avec try/except ;
  6. traiter un fichier structuré simple (CSV).

1. Volatile vs persistant

Mémoire volatile (RAM / variables)Stockage persistant (fichiers, base)
Durée de vieLe temps d'exécution du programmeJusqu'à suppression
VitesseTrès rapidePlus lent (disque)
UsageTraitement en coursRésultats, configuration, historique

2. open() et le mot-clé with

# Mauvaise pratique : il faut penser à fermer
f = open("donnees.txt", "r", encoding="utf-8")
contenu = f.read()
f.close()

# Bonne pratique : fermeture automatique, même si une erreur survient
with open("donnees.txt", "r", encoding="utf-8") as f:
    contenu = f.read()
Niveau 1 — Intuition

with = « ouvre, fais le travail, referme quoi qu'il arrive ». C'est un garde-fou : jamais de fichier laissé ouvert, même en cas de plantage au milieu.

3. Les modes d'ouverture

ModeEffetSi le fichier existeSi absent
"r"LireOKFileNotFoundError
"w"ÉcrireÉcrase toutCrée
"a"AjouterAjoutez à la finCrée
"r+"Lire + écrireOKErreur
Le piège destructeur du mode « w »

Ouvrir en "w" un fichier qui contient des données le vide immédiatement. Pour ajouter sans perdre, c'est "a". C'est une erreur classique et coûteuse en production.

4. Lire, écrire, ajouter

# Lire ligne par ligne
with open("donnees.txt", "r", encoding="utf-8") as f:
    for ligne in f:
        print(ligne.strip())      # strip() retire le \n

# Écrire (crée/écrase)
with open("resultats.txt", "w", encoding="utf-8") as f:
    f.write("Moyenne : 13.6\n")

# Ajouter
with open("journal.txt", "a", encoding="utf-8") as f:
    f.write("Nouvel enregistrement\n")
Toujours strip() en lisant

Chaque ligne lue contient son caractère de fin de ligne \n. Sans .strip(), "Jean, 15\n" perturbe les comparaisons et l'affichage. Retire-le systématiquement avant de traiter.

5. Gestion des erreurs de fichier

try:
    with open("donnees.txt", "r", encoding="utf-8") as f:
        contenu = f.read()
except FileNotFoundError:
    print("Fichier introuvable.")
except PermissionError:
    print("Accès refusé.")
finally:
    print("Fin de la tentative de lecture.")

6. Formats courants — CSV

# Lire un CSV simple sans bibliothèque
with open("notes.csv", "r", encoding="utf-8") as f:

        nom, note = ligne.strip().split(",")

Utilité IT

Les fichiers sont partout : journaux (logs), exports CSV, configuration JSON, rapports. Savoir lire/écrire un fichier est un prérequis pour l'automatisation système et le traitement de données.

7. Exemples travaillés

Exemple ATrès simple

Écrire puis relire une ligne.

with open("test.txt", "w", encoding="utf-8") as f:
    f.write("Bonjour\n")
with open("test.txt", "r", encoding="utf-8") as f:
    print(f.read().strip())
Bonjour
Exemple BIntermédiaire

Énoncé (sujet type). donnees.txt contient « Jean, 15 », « Marie, 18 », « Paul, 12 ». Lire le fichier et afficher la moyenne des notes.

total = 0
n = 0
with open("donnees.txt", "r", encoding="utf-8") as f:
    for ligne in f:
        nom, note = ligne.strip().split(",")
        total += int(note)
        n += 1
print("Moyenne :", total / n if n else 0)
Moyenne : 15.0

Analyse. 1) strip pour enlever \n ; 2) split(",") pour séparer les champs ; 3) int() car le fichier ne contient que du texte ; 4) compteur pour éviter la division par zéro.

Exemple CDifficile

Énoncé. Calculer les notes puis écrire le résultat dans resultats.txt, en gérant l'absence du fichier source.

try:
    with open("donnees.txt", "r", encoding="utf-8") as f:
        notes = [int(l.strip().split(",")[1]) for l in f if l.strip()]
    moyenne = sum(notes) / len(notes)
    with open("resultats.txt", "w", encoding="utf-8") as out:
        out.write(f"Moyenne : {moyenne:.2f}\n")
    print("Résultat écrit.")
except FileNotFoundError:
    print("Le fichier donnees.txt est introuvable.")

Pourquoi le if l.strip() ? Il ignore les lignes vides (le rythme final) qui feraient échouer int(""). Robustesse = réflexe professionnel.

8. Exercices (5 niveaux)

Niveau 1 — Acquisition

1. Quel mode ouvre en lecture ? 2. Que fait "w" si le fichier existe ? 3. Pourquoi utiliser with ?

Correction
1. "r".   2. Il écrase son contenu. 3. Pour fermer le fichier automatiquement, même en cas d'erreur.
Niveau 2 — Application

4. Écrivez trois lignes dans un fichier, puis relisez-les et comptez-les.

Correction
with open("c.txt", "w", encoding="utf-8") as f:
    f.write("un\ndeux\ntrois\n")
with open("c.txt", "r", encoding="utf-8") as f:

Niveau 3 — Raisonnement

5. Pourquoi int("Jean, 15\n".split(",")[1]) échoue-t-il ?

Correction
Le champ contient " 15\n" (espace + retour ligne). int accepte les espaces mais pas le \n combiné à l'espacement tel quel — il faut strip() avant conversion.
Niveau 4 — Examen

6. (sujet type) Lis donnees.txt, affiche les données ligne par ligne, calcule la moyenne des notes et écris-la dans resultats.txt.

Correction détaillée
total = 0
nombre = 0
with open("donnees.txt", "r", encoding="utf-8") as f:
    for ligne in f:
        if not ligne.strip():
            continue
        nom, note = ligne.strip().split(",")
        print(nom.strip(), "-", note.strip())
        total += int(note)
        nombre += 1

moyenne = total / nombre if nombre else 0
with open("resultats.txt", "w", encoding="utf-8") as out:
    out.write(f"Moyenne : {moyenne:.2f}\n")
print("Moyenne écrite :", moyenne)
Barème : lecture ligne par ligne, nettoyage, conversion, écriture du résultat. Piège : oublier strip ou diviser par zéro.
Niveau 5 — Challenge

7. Compte les occurrences de chaque mot d'un fichier et écris le Top 3 dans top.txt.

Correction
freq = {}
with open("texte.txt", "r", encoding="utf-8") as f:
    for ligne in f:
        for mot in ligne.lower().split():
            freq[mot] = freq.get(mot, 0) + 1

top = sorted(freq.items(), key=lambda kv: kv[1], reverse=True)[:3]
with open("top.txt", "w", encoding="utf-8") as out:
    for mot, n in top:
        out.write(f"{mot} : {n}\n")

10. QCM — niveau examen

Quel mode écrase le contenu existant ?

"w" tronque le fichier ; "a" ajoute.

Que lève open("absent.txt", "r") si le fichier n'existe pas ?

En lecture, un fichier absent lève FileNotFoundError.

Quel est l'avantage principal de with ?

with garantit la fermeture, y compris en cas d'exception.

Que fait ligne.strip() ?

strip() nettoie les blancs autour, dont le saut de ligne de lecture.

Que renvoie f.read() ?

read() renvoie une chaîne ; readlines() renvoie une liste.

Quel mode faut-il pour ne PAS perdre les données existantes en ajoutant ?

"a" (append) ajoute à la fin sans écraser.

Dans for ligne in f:, chaque ligne contient…

L'itération renvoie des lignes complètes (saut de ligne inclus).

Quelle boucle est correcte pour traiter un fichier robustement ?

La gestion d'erreur protège le programme d'un fichier manquant ou d'un accès refusé.

Que fait finally dans un try/except/finally ?

finally s'exécute dans tous les cas (nettoyage, journalisation).

Lire un fichier ligne « Jean, 15 ». Quelle expression donne la note en entier ?

Il faut nettoyer, découper, prendre l'index 1, puis convertir en entier.

11. Erreurs classiques

À reconnaître en examen
  • Utiliser "w" au lieu de "a" et perdre les données.
  • Oublier .strip() int(" 15\n") échoue.
  • Ne pas gérer FileNotFoundError.
  • Oublier encoding="utf-8" accents corrompus.
  • Diviser par zéro quand le fichier est vide.

12. Méthodologie de résolution

Traiter un fichier en 5 étapes
  1. Ouvrir en with avec le bon mode et encoding="utf-8".
  2. Parcourir ligne par ligne ; ignorer les lignes vides.
  3. strip() puis split(sep) pour extraire les champs.
  4. Convertir chaque champ dans le bon type (int/float).
  5. Écrire le résultat dans un fichier de sortie, et gérer l'absence du source.
