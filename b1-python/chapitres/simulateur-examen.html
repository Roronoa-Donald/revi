Le programme suivant est incomplet :

def calcul_statistiques(liste_notes):
    """Calcule la moyenne et la note maximale d'une liste de notes."""
    total = 0
    for note in liste_notes:
        total += note
    # Ajouter le calcul de la moyenne
    moyenne = ______________________
    # Trouver la note maximale
    max_note = ______________________
    return moyenne, max_note

notes = [12, 15, 14, 9, 18]
moyenne, max_note = calcul_statistiques(notes)

Exercice 3/4 — Fichiers

donnees.txt contient « Jean, 15 », « Marie, 18 », « Paul, 12 ». (a) (2 pts) Lis et affiche les données ligne par ligne. (b) (2 pts) Calcule la moyenne des notes et écris-la dans resultats.txt.

Corrigé
total = 0
n = 0
with open("donnees.txt", "r", encoding="utf-8") as f:
    for ligne in f:
        if not ligne.strip():
            continue
        nom, note = ligne.strip().split(",")
        print(nom.strip(), note.strip())
        total += int(note)
        n += 1
with open("resultats.txt", "w", encoding="utf-8") as out:
    out.write(f"Moyenne : {total / n if n else 0:.2f}\n")
Moyenne = 15.0. Points clés : strip, split(","), conversion, division sûre.
Exercice 4/3 — Exceptions

Soit def division(a,b): return a/b puis print(division(10, 0)). (a) (1 pt) Identifie l'erreur. (b) (1 pt) Corrige avec try/except. (c) (1 pt) Ajoute un message d'erreur personnalisé.

Corrigé
(a) ZeroDivisionError. (b/c)

        return a / b
    except ZeroDivisionError:

        return None
Exercice 5/3 — Fonctions

Exercice 1/4 — Boucles

Écrivez un programme qui affiche tous les nombres premiers entre 2 et 50, et comptez-les.

Corrigé
def est_premier(n):
    if n < 2: return False
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0: return False
    return True

premiers = [n for n in range(2, 51) if est_premier(n)]
print(premiers, len(premiers))   # 15 nombres premiers
Exercice 2/4 — Dictionnaires

Écrivez une fonction qui compte la fréquence de chaque mot d'une phrase et retourne un dictionnaire.

Corrigé
def compte_mots(texte):
    freq = {}
    for mot in texte.lower().split():
        freq[mot] = freq.get(mot, 0) + 1
    return freq

Exercice 4/4 — Débogage

Programme censé afficher la somme 1..10, mais affiche 45. Trouve et corrige l'erreur.

s = 0
for i in range(1, 10):
    s += i
print(s)
Corrigé

Exercice 5/4 — Synthèse

Écrivez un programme complet qui lit etudiants.csv (« nom,note1,note2 »), calcule la moyenne de chaque étudiant, affiche ceux qui ont ≥ 10, et écrit le classement (du meilleur au moins bon) dans classement.txt.

Corrigé (synthèse de tout le cours)
resultats = []
try:
    with open("etudiants.csv", "r", encoding="utf-8") as f:
        for ligne in f:
            if not ligne.strip():
                continue
            champs = ligne.strip().split(",")
            nom = champs[0]
            notes = [float(n) for n in champs[1:]]
            moyenne = sum(notes) / len(notes)
            resultats.append((nom, moyenne))
except FileNotFoundError:
    print("Fichier introuvable.")

admis = [r for r in resultats if r[1] >= 10]
print("Admis :", admis)

resultats.sort(key=lambda r: r[1], reverse=True)
with open("classement.txt", "w", encoding="utf-8") as out:
    for nom, moy in resultats:
        out.write(f"{nom} : {moy:.2f}\n")
