Projet intégrateur — « Mini-gestionnaire de notes »

Cahier des charges

Une école veut un petit programme en ligne de commande pour gérer les notes de sa classe. Le programme lit les données depuis etudiants.csv (format nom,note1,note2,...), calcule les moyennes, applique un barème d'admission, affiche un rapport et sauvegarde les résultats.

Fonctionnalités attendues
  1. Lire etudiants.csv (fichiers) et construire une liste d'enregistrements (structures de données).
  2. Calculer la moyenne de chaque étudiant avec une fonction dédiée (fonctions).
  3. Classer du meilleur au moins bon (tri).
  4. Mentionner : « Admis » si moyenne ≥ 10, « Ajourné » sinon (conditions).
  5. Afficher un rapport lisible (f-strings) et écrire resultats.txt.
  6. Gérer les erreurs : fichier absent, ligne vide, note non numérique (try/except).
  7. Bonus : afficher la moyenne de classe, le major et le taux d'admission.

Contraintes : noms explicites, une fonction = une responsabilité, docstrings, aucune ligne dupliquée.

Grille d'auto-évaluation du projet (sur 100)

Tri et rapport lisible 20
Gestion des erreurs / cas limites 20
Lisibilité, noms, docstrings 20

def lire_etudiants(chemin):
    """Retourne [(nom, [notes])] depuis un CSV, en ignorant les lignes invalides."""
    etudiants = []
    try:
        with open(chemin, "r", encoding="utf-8") as f:
            for ligne in f:
                if not ligne.strip():
                    continue
                champs = [c.strip() for c in ligne.split(",")]
                try:
                    notes = [float(n) for n in champs[1:]]
                except ValueError:
                    print(f"Ligne ignorée (note invalide) : {ligne.strip()}")
                    continue
                etudiants.append((champs[0], notes))
    except FileNotFoundError:
        print(f"Fichier {chemin} introuvable.")
    return etudiants

def moyenne(notes):
    """Moyenne d'une liste de notes (0.0 si vide)."""
    return sum(notes) / len(notes) if notes else 0.0

def rapport(etudiants):
    """Retourne une liste (nom, moyenne, mention) triée décroissante."""
    lignes = [(nom, moyenne(notes)) for nom, notes in etudiants]
    lignes.sort(key=lambda t: t[1], reverse=True)
    return [(nom, moy, "Admis" if moy >= 10 else "Ajourne") for nom, moy in lignes]

def ecrire_classement(lignes, chemin="resultats.txt"):
    with open(chemin, "w", encoding="utf-8") as out:
        for nom, moy, mention in lignes:
            out.write(f"{nom} : {moy:.2f} — {mention}\n")

def main():
    etudiants = lire_etudiants("etudiants.csv")
    lignes = rapport(etudiants)
    for nom, moy, mention in lignes:
        print(f"{nom:<10} {moy:6.2f}  {mention}")
    if lignes:
        admis = sum(1 for _, _, m in lignes if m == "Admis")
        print(f"Moyenne de classe : {sum(m for _, m, _ in lignes) / len(lignes):.2f}")
        print(f"Taux d'admission : {admis / len(lignes) * 100:.1f} %")
        print(f"Major : {lignes[0][0]} ({lignes[0][1]:.2f})")
        ecrire_classement(lignes)

if __name__ == "__main__":
    main()
