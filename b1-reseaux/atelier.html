Atelier d’analyse & Bac à sable

Un éditeur interactif dans la page pour résoudre les études de cas. Complétez la grille d’analyse, validez-la et observez le résultat : c'est ici qu'une règle d'adressage devient un calcul automatisé.

Comment fonctionne l'atelier
  • Valider vérifie la conformité de vos réponses dans la grille d’analyse.
  • Données du cas contient les paramètres soumis à l’étude.
  • Expliquer mon erreur demande au tuteur, quand il y a une erreur, pourquoi elle survient et par où chercher. Il explique en mots : il n'écrit jamais de code à votre place.
  • Le raccourci Ctrl + Entrée exécute le script sans quitter l'éditeur.
  • Votre code est conservé dans ce navigateur, par exercice et par cours.

Zone libre — vérificateur d'adresses IP

Grille d’analyse

Objectif : expérimenter sans conséquence. Prenez un mécanisme du cours (classement de classe, masque, handshake, emprunt de bits), programmez-le et testez-le sur des cas limites.

Le script proposé lit des couples « adresse classe » et rappelle le masque par défaut de la classe annoncée. Transforme-le : déduis la classe vous-même à partir du premier octet, calcule le nombre d'hôtes valides, ou remplace tout le script par le mécanisme que vous voulez vérifier.

Dans un vrai réseau, ce contrôle se fera avec un calculateur d'adressage : la structure du script — lire, décider, rapporter — reste exactement la même.

Quatre lignes attendues : déplie « Entrée du programme » et saisis-les avant d’exécuter.

De la page au vrai réseau

La simulation a une limite assumée : aucun paquet n'est émis et aucune interface n'est configurée — le réseau reste du texte structuré. Elle a une force : toute la logique se vérifie sans risque — on peut rejouer un calcul de masque autant de fois que nécessaire. Quand le script reproduit les bons réflexes — lire, décider, rapporter — le passage à la configuration réelle est mécanique.

Les trois erreurs que l'atelier révèle immédiatement
  • Calcul en nombres entiers : l'arithmétique s'effectue sur des entiers — un calcul de masque passe, un 224,5 pas.
  • Découpage d'octet oublié : ${adresse%%.*} prend le premier octet ; sans découpage, la classe se devine mal.
  • Ordre des lectures inversé : l’étude de cas comporte la classe avant l'adresse, et tout décale.
Ce que fait l'atelier, côté technique
  • Votre code est envoyé à ce serveur, qui le transmet à un service d'exécution isolé : rien ne tourne sur votre machine, et aucun accès au système n'est possible.
  • La clé du service reste sur le serveur ; le navigateur ne la voit jamais.
  • Le nombre d'exécutions est limité par jour, pour tout le monde. L'atelier n'exécute donc que sur un clic.

Ensuite

Les 6 chapitres contiennent chacun trois études de cas corrigées automatiquement dans la page. Une fois l'atelier apprivoisé, ils sont la meilleure façon de vérifier que le mécanisme est vraiment acquis.
