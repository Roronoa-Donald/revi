Chapitre 3 — Le modèle OSI

Module 3 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

« Il est difficile de comprendre la technologie des réseaux sans faire référence au modèle OSI » : l'ISO a bâti un modèle générique de sept couches qui ne décrit aucun produit mais cadre toutes les discussions — et le professionnel commence toujours un dépannage par la couche 1.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. nommer les sept couches OSI dans l'ordre, de la physique à l'application ;
  2. associer chaque couche à son rôle (encapsulation, routage, session, format) ;
  3. placer les équipements : câble (1), commutateur (2), routeur (3) ;
  4. appliquer la méthode de dépannage : remonter depuis la couche physique.

1. Les sept couches

L'ISO a élaboré le modèle OSI (Open System Interconnection) : sept couches qui couvrent tous les aspects de la communication entre machines en réseau. Il ne décrit aucun produit, mais sert de référentiel pour corréler les modèles réels et garantir l'interopérabilité.

De bas en haut : 1-Physique (câbles, broches, tensions, radiofréquences) ; 2-Liaison de données (transfert de nœud à nœud, correction d'erreurs, sous-couches MAC et LLC — la plupart des commutateurs vivent ici) ; 3-Réseau (transmission des paquets et routage entre routeurs, les adresses IP) ; 4-Transport (coordination du transfert, TCP et UDP, les numéros de port) ; 5-Session (ouverture, coordination et terminaison des sessions, synchronisation du dialogue) ; 6-Présentation (formatage, chiffrement/déchiffrement, compression) ; 7-Application (la couche la plus proche de l'utilisateur : navigateur, messagerie, FTP, Skype, Outlook).

Mnémotechnique — « Physique-Liaison-Réseau-Transport-Session-Présentation-Application »

De la prise électrique au clic de souris : 1 câble, 2 trame, 3 route, 4 port, 5 dialogue, 6 format, 7 logiciel. En cas de panne, on remonte dans cet ordre.

2. Les équipements et le dépannage

Chaque couche héberge ses équipements : le câble et le connecteur en couche 1, le commutateur (switch) en couche 2, le routeur en couche 3 — « la couche très surveillée par les professionnels », celle des millions de chemins possibles entre Boston et la Californie. Les adresses IP travaillent en couche 3, les ports TCP/UDP en couche 4.

Le dépannage suit le modèle : « en cas de problème de réseau, les professionnels commencent souvent par vérifier la couche physique » — câbles branchés, alimentation branchée — avant de soupçonner la carte réseau (2), le routage (3) ou l'application (7).

Confusions d'examen
  • Le commutateur est de couche 2, le routeur de couche 3 : l'inverse est le piège classique.
  • Les adresses IP vivent en couche 3, les ports TCP/UDP en couche 4.
  • Le chiffrement est de la couche 6 (présentation), pas de la couche 7.
  • La couche session synchronise le dialogue : ouverture, coordination, terminaison.

3. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Les sept couches OSI

Bash Niveau 1 — Acquisition

Objectif : Ranger chaque élément dans sa couche OSI, de la couche 1 physique à la couche 7 application.

Le script lit n lignes « objet couche » : couche vaut c1 à c7. Pour chaque ligne il affiche objet : N-nom, où N est le numéro et nom la couche : 1-physique, 2-liaison, 3-reseau, 4-transport, 5-session, 6-presentation, 7-application. Il termine par routeurs : X/n (les objets de la couche 3).

Entrée du programme
4
cable c1
adresse c3
port c4
navigateur c7
Sortie attendue
cable : 1-physique
adresse : 3-reseau
port : 4-transport
navigateur : 7-application
routeurs : 1/4
Deux indices, rédigés en mots
  1. Un case à sept valeurs, chaque valeur donnant « N-nom ».
  2. La couche 3 (reseau) est celle des routeurs : c'est elle qu'on compte.

Exercice 2 — Où travaille l'équipement

Bash Niveau 2 — Application

Objectif : Placer les équipements dans leurs couches : câble (1), commutateur (2), routeur (3), application (7).

Le script lit n lignes « equipement couche » : couche vaut c1 (câble, connecteur), c2 (commutateur), c3 (routeur) ou c7 (navigateur, messagerie). Pour chaque ligne il affiche equipement : couche N si l'équipement correspond bien à cette couche, equipement : hors couche sinon. Il termine par routeurs : X/n (les équipements placés correctement en couche 3).

Entrée du programme
4
routeur c3
switch c2
cable c1
routeur c2
Sortie attendue
routeur : couche 3
switch : couche 2
cable : couche 1
routeur : hors couche
routeurs : 1/4
Deux indices, rédigés en mots
  1. Un case sur la couche donne l'équipement attendu : c1 cable, c2 commutateur, c3 routeur, c7 application.
  2. La comparaison équipement reçu contre équipement attendu décide du verdict.

Exercice 3 — Le dépannage par couches

Bash Niveau 3 — Raisonnement

Objectif : Appliquer la méthode du professionnel : en cas de panne, remonter les couches OSI depuis la couche physique.

Le script lit n lignes « incident couche » : couche est la couche où se situe la panne — c1 (câble débranché), c2 (carte réseau fautive), c3 (routage absent) ou c7 (application en cause). Pour chaque ligne il affiche : incident : verifier les cables (c1), incident : verifier la carte (c2), incident : verifier le routage (c3), incident : verifier les applications (c7). Il termine par physiques : X/n (les pannes de couche 1, les plus fréquentes).

Entrée du programme
4
pc1 c1
pc2 c2
srv c3
web c7
Sortie attendue
pc1 : verifier les cables
pc2 : verifier la carte
srv : verifier le routage
web : verifier les applications
physiques : 1/4
Deux indices, rédigés en mots
  1. Un case à quatre couches, quatre gestes : cables, carte, routage, applications.
  2. Le compteur suit exactement les incidents de couche 1.

4. QCM — niveau examen

La couche la plus proche de l'utilisateur est…

Navigateur, messagerie, FTP : couche 7.

Le routage des paquets se fait en couche…

Couche réseau : routeurs et adresses IP.

Les commutateurs travaillent surtout en couche…

Liaison de données, sous-couches MAC et LLC.

Les ports TCP et UDP fonctionnent en couche…

Transport ; les adresses IP, elles, sont en couche 3.

Le chiffrement et la compression appartiennent à…

Présentation : formater, chiffrer, compresser.

La couche session assure…

Ouverture, coordination, terminaison des sessions.

Premier réflexe de dépannage :

Câbles et alimentation d'abord — couche 1.

La couche physique décrit…

Caractéristiques électriques, logiques et physiques.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Placer le routeur en couche 2 ou le commutateur en couche 3 : la confusion classique.
  • Chercher le chiffrement en couche 7 : il se fait en couche 6.
  • Oublier les sous-couches MAC et LLC de la couche 2.
  • Commencer le dépannage par les logiciels : la couche 1 d'abord.

6. Méthodologie de résolution

Méthode — dépanner par couches en trois gestes
  1. Vérifier la couche 1 : câbles, connecteurs, alimentation.
  2. Monter d'un cran : carte et commutateur (2), routage et adresses (3).
  3. Terminer par les couches hautes : session (5), format (6), application (7).

7. Révision active

Résumé essentiel
  • Sept couches : physique, liaison, réseau, transport, session, présentation, application.
  • Câble en 1, commutateur en 2, routeur en 3 ; IP en 3, ports en 4.
  • Chiffrement et compression : couche 6 ; sessions : couche 5.
  • Le dépannage remonte les couches depuis la physique.

Checklist de maîtrise

  • Je sais réciter les sept couches dans l'ordre.
  • Je sais associer rôle, équipement et couche.
  • Je sais placer IP (3), ports (4), chiffrement (6).
  • Je sais appliquer la méthode de dépannage par couches.

Les 8 notions à connaître absolument

  1. OSI : modèle générique ISO de sept couches.
  2. Couche 1 : physique — câbles, broches, tensions, radio.
  3. Couche 2 : liaison de données — MAC et LLC, commutateurs.
  4. Couche 3 : réseau — routage, adresses IP, routeurs.
  5. Couche 4 : transport — TCP/UDP, ports, rythme et destination.
  6. Couche 5 : session — ouverture, coordination, terminaison.
  7. Couche 6 : présentation — format, chiffrement, compression.
  8. Couche 7 : application — navigateur, messagerie, FTP.

8. Test de maîtrise

Comment t'auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lis ton pourcentage :

< 50 % — relis la définition des sept couches du support.
50–69 % — refais le classement équipements/objets par couche.

≥ 95 % — niveau de maîtrise recherché.
