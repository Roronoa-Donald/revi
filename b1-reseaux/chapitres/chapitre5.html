Chapitre 5 — L'adressage réseau

Module 5 ≈ 2 h de travail Réservé B1 et plus
Mise en situation

Deux adresses identifient chaque machine : la MAC, numéro de série de la carte réseau, et l'IP, adresse logique routable. Le support les fait collaborer — « l'adresse IP dirige le paquet de réseau en réseau, la MAC de dispositif en dispositif » — puis introduit le masque et les classes A, B, C.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. décrire l'adresse MAC : 48 bits, OUI du fabricant, portée limitée au LAN ;
  2. décomposer l'adresse IPv4 en partie réseau et partie hôte grâce au masque ;
  3. expliquer la coopération ARP (même réseau) et routage (réseaux distants) ;
  4. classifier une adresse par son premier octet : classes A, B, C, D, E.

1. MAC, IP, ARP

L'adresse MAC (Media Access Control) opère en couche 2 : elle identifie unique la carte réseau (NIC). Format : 48 bits, soit 12 chiffres hexadécimaux (00:1A:2B:3C:4D:5E). Les 6 premiers chiffres (24 bits) forment l'OUI (Organizationally Unique Identifier) du fabricant ; les 6 derniers sont le numéro de série du fabricant. Portée : le segment local uniquement — une MAC n'est jamais routée au-delà d'un routeur.

\n

L'adresse IP opère en couche 3 : identité logique et routable. IPv4 : 32 bits en quatre octets décimaux (192.168.1.10), composée d'une partie réseau et d'une partie hôte, séparées par le masque ; dynamique (DHCP) ou statique. IPv6 : 128 bits en huit groupes hexadécimaux, créée contre la pénurie d'IPv4.

\n

La coopération : sur le même réseau, A résout l'IP de B en MAC via ARP (Address Resolution Protocol) et envoie directement. À distance, A encapsule le paquet avec la MAC du routeur local ; le routeur désencapsule, lit l'IP de C, consulte sa table de routage, et réencapsule vers la MAC du routeur suivant — et ainsi de suite.

\n
Mnémotechnique — « IP navigue, MAC rame »

IP traverse les réseaux de routeur en routeur ; MAC ne rame que sur son segment local. ARP est le traducteur entre les deux.

2. Masque et classes

Le masque de sous-réseau répond à la question « où finit le réseau, où commence l'hôte ? ». 32 bits comme l'adresse : les bits à 1 marquent la partie réseau, les bits à 0 la partie hôte. Exemple : 255.255.255.0 — les 24 premiers bits (trois octets) sont réseau, le dernier octet identifie les machines.

\n

Les classes historiques, déterminées par les premiers bits du premier octet : A (1er bit 0, adresses 1 à 126, masque 255.0.0.0, ~16 millions d'hôtes) ; B (10, 128 à 191, 255.255.0.0, ~65 000 hôtes) ; C (110, 192 à 223, 255.255.255.0, 254 hôtes). Les classes D (224-239) servent au multicast, E (240-254) est expérimentale. 127 est la boucle locale.

\n

Ce système, remplacé par le CIDR, reste « essentiel à comprendre » selon le support — et c'est lui qui rend le sous-réseautage lisible au chapitre suivant.

\n
Confusions d'examen
    \n
  • Une MAC n'est jamais routée : elle ne sort pas du LAN, contrairement à l'IP.
    • \n
  • Classe B : 128 à 191 — pas 127 (boucle locale) ni 192 (classe C).
    • \n
  • Bits du masque : 1 = réseau, 0 = hôte — jamais l'inverse.
    • \n
  • ARP traduit IP en MAC sur le segment local ; à distance, c'est la table de routage qui parle.
    • \n

3. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Lire une adresse MAC

Bash Niveau 1 — Acquisition

Objectif : Valider une adresse MAC : 48 bits, soit exactement 12 chiffres hexadécimaux.

Le script lit n lignes « carte mac » : mac est une suite de caractères prétendant être une adresse MAC (sans séparateurs, par exemple aabbccddeeff). Une MAC valide compte exactement 12 chiffres hexadécimaux (0-9, a-f, A-F) : les 6 premiers forment l'OUI du fabricant, les 6 derniers le numéro de série. Pour chaque ligne il affiche carte : mac valide ou carte : mac invalide. Il termine par invalides : X/n.

Entrée du programme
3
pc1 aabbccddeeff
pc2 aabbccdd
pc3 aabbccddeexf
Sortie attendue
pc1 : mac valide
pc2 : mac invalide
pc3 : mac invalide
invalides : 2/3
Deux indices, rédigés en mots
  1. Un case avec douze classes [0-9a-fA-F] de suite valide la forme : le motif doit couvrir tout le mot.
  2. Trop courte, trop longue ou avec un caractère étranger : tout tombe dans le cas invalide.

Exercice 2 — Réseau ou hôte

Bash Niveau 2 — Application

Objectif : Découper une adresse IP selon sa classe : quel octet appartient à la partie réseau, lequel à la partie hôte.

Le script lit n lignes « classe octet » : classe vaut a (1 octet réseau), b (2 octets réseau) ou c (3 octets réseau) ; octet vaut o1, o2, o3 ou o4. Pour chaque ligne il affiche octet : reseau si l'octet appartient à la partie réseau de cette classe, octet : hote sinon. Il termine par reseau : X/n.

Entrée du programme
5
c o1
c o2
c o4
a o2
b o2
Sortie attendue
o1 : reseau
o2 : reseau
o4 : hote
o2 : hote
o2 : reseau
reseau : 3/5
Deux indices, rédigés en mots
  1. Un case sur la classe fixe le nombre d'octets réseau : a 1, b 2, c 3.
  2. Un second case sur l'octet (o1 à o4) compare son rang à ce nombre.

Exercice 3 — La classe de l'adresse

Bash Niveau 3 — Raisonnement

Objectif : Identifier la classe IPv4 par le premier octet : A (1-126), B (128-191), C (192-223), D et E réservées.

Le script lit n lignes « adresse premieroctet » : premieroctet est un entier (0 à 255). Pour chaque ligne il affiche : adresse : classe A (1-126), adresse : classe B (128-191), adresse : classe C (192-223), adresse : classe D (224-239, multicast), adresse : classe E (240-254, expérimentale), adresse : boucle locale (127) ou adresse : reservee (0 et 255). Il termine par speciales : X/n (boucle locale et réservées).

Entrée du programme
4
rc 10
uni 172
pmi 192
groupe 224
Sortie attendue
rc : classe A
uni : classe B
pmi : classe C
groupe : classe D
speciales : 0/4
Deux indices, rédigés en mots
  1. Une suite de if/elif avec -le et -ge évite le case : les tranches sont numériques.
  2. Boucle locale (127), 0 et 255 sont les cas « speciales » à compter.

5. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Router une adresse MAC : elle s'arrête au premier routeur.
  • Ranger 127 en classe B : c'est la boucle locale.
  • Inverser réseau et hôte dans le masque.
  • Oublier l'étape ARP avant l'envoi local : l'IP seule ne suffit pas.

6. Méthodologie de résolution

Méthode — lire une adresse en trois gestes
  1. Regarder le premier octet : 1-126 (A), 128-191 (B), 192-223 (C), 224-239 (D), 240-254 (E).
  2. Appliquer le masque par défaut : /8, /16 ou /24 — séparer réseau et hôte.
  3. Décider du chemin : même réseau (ARP + MAC), réseau distant (MAC du routeur).

7. Révision active

Résumé essentiel
  • MAC : 48 bits, OUI + série, couche 2, jamais routée.
  • IP : 32 bits (IPv4) réseau + hôte ; IPv6 : 128 bits.
  • ARP traduit IP en MAC localement ; le routeur enchaîne à distance.
  • Masque : bits 1 = réseau, 0 = hôte. Classes A (1-126), B (128-191), C (192-223).

Checklist de maîtrise

  • Je sais décomposer une MAC et nommer l'OUI.
  • Je sais séparer réseau et hôte avec un masque par défaut.
  • Je sais dérouler un envoi local (ARP) et distant (routage).
  • Je sais classifier dix adresses par leur premier octet.

Les 8 notions à connaître absolument

  1. MAC : 48 bits hexadécimaux, identité physique de la carte.
  2. OUI : 24 premiers bits, fabricant de la carte.
  3. IPv4 : 32 bits, quatre octets décimaux, réseau + hôte.
  4. IPv6 : 128 bits, huit groupes hexadécimaux.
  5. ARP : traduction IP en MAC sur le segment local.
  6. Masque : 32 bits, 1 = réseau, 0 = hôte.
  7. Classe A : 1-126, /8, 16 millions d'hôtes.
  8. Classe C : 192-223, /24, 254 hôtes.

Comment t'auto-évaluer
