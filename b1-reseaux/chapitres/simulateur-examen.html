Simulateur d'examen

Deux sujets blancs chronométrés, dans l'esprit de l'épreuve (durée 2 h, /20). Réalisez-les sans regarder les corrigés, puis corrigez-vous sévèrement.

Chronomètre d'examen — 2 h

Lancez le chrono quand vous commencez un sujet. Ne consultez le corrigé qu'à la fin. Réservez 15 min de relecture : classes d'adresses, masques, ordre du handshake, comportement en panne, 2^k - 2 hôtes valides.

120:00

Examen blanc n°1

Sujet type épreuve — fondamentaux, topologies, modèle OSI.

Exercice 1/5 — Classer les réseaux

Classer : le réseau d'une salle de TP ; l'interconnexion des agences d'une banque entre deux pays ; le Wi-Fi du campus ; l'iPhone synchronisé au Mac d'un étudiant. Puis : une entreprise de 40 postes peut-elle fonctionner efficacement en réseau poste-à-poste sans serveur dédié ? Justifier en comparant la gestion des comptes.

Corrigé
Salle de TP : LAN (immeuble). Agences entre pays : WAN (plus de 100 km, liaisons d'opérateur). Wi-Fi du campus : WLAN — réseau local sans fil, pas un WAN. iPhone + Mac : PAN. L'entreprise de 40 postes : non — en poste-à-poste (ou workgroup), chaque machine doit gérer ses propres comptes et partages ; dès une dizaine de postes la gestion décentralisée devient chaotique et non sécurisée : il faut passer en architecture client-serveur où un serveur centralise l'authentification et les partages.
Exercice 2/5 — Topologies et supports

Une coupure de câble survient : donner le comportement du réseau en bus, en double anneau, en étoile. Puis conseiller le support : entrepôt très perturbé électromagnétiquement ; liaison entre deux bâtiments distants de 3 km ; poste de comptable standard.

Corrigé
Bus : tout le réseau est affecté — topologie fragile. Double anneau : les données basculent sur l'anneau secondaire le temps de la réparation. Étoile : un seul poste s'isole, le reste continue. Supports : STP blindé pour l'entrepôt perturbé ; fibre optique pour les 3 km (hors norme UTP 100 m) ; UTP catégorie 5e pour le poste standard (1 Gbit/s, moins de 100 m).
Exercice 3/5 — Modèle OSI

Ranger : le chiffrement des données ; la table de routage ; les ports TCP ; le câble RJ45 ; la synchronisation du dialogue. Un utilisateur « n'a plus de réseau » : donner les trois premières vérifications dans l'ordre OSI.

Corrigé
Chiffrement : couche 6 (présentation). Table de routage : couche 3 (réseau). Ports TCP : couche 4 (transport). RJ45 : couche 1 (physique). Synchronisation du dialogue : couche 5 (session). Dépannage : 1) câbles branchés et alimentation (couche 1) ; 2) carte réseau et commutateur (couche 2) ; 3) adresse IP et routage (couche 3) — puis seulement l'application (7).

Examen blanc n°2 — variante

Sujet orienté TCP/IP, adressage et sous-réseautage.

Exercice 1/5 — TCP/IP et handshake

Dérouler le three-way handshake entre un client (séquence A = 1000) et un serveur (séquence B = 5000). Puis choisir TCP ou UDP pour : un courriel ; un appel VoIP ; une requête DNS ; le téléchargement d'un ISO.

Corrigé
1. SYN : client → serveur, séquence 1000. 2. SYN-ACK : serveur → client, ACK = 1001, séquence 5000. 3. ACK : client → serveur, 5001 — communication full-duplex établie. Courriel : TCP (fiabilité). Appel VoIP : UDP (temps réel, pertes tolérables). DNS : UDP (requête courte, rapide). ISO : TCP (aucun octet ne doit manquer).
Exercice 2/5 — MAC, IP, ARP

La machine 192.168.1.10/24 envoie un fichier à 192.168.1.20 puis à 10.0.0.5. Décrire le chemin MAC/IP dans les deux cas. Rappeler pourquoi la MAC n'apparaît jamais au-delà du premier routeur.

Corrigé
Vers 192.168.1.20 (même réseau) : ARP traduit l'IP en MAC locale, envoi direct de station à station. Vers 10.0.0.5 (réseau distant) : l'émetteur encapsule le paquet avec la MAC du routeur ; le routeur désencapsule, lit l'IP de destination, consulte sa table de routage et réencapsule avec la MAC du saut suivant — l'IP reste constante de bout en bout, la MAC change à chaque saut : elle n'est jamais routée.
Exercice 3/5 — Classes et masque

Donner la classe et le masque par défaut de : 10.20.30.40 ; 172.20.1.1 ; 192.168.10.5 ; 127.0.0.1 ; 225.1.1.1. Puis : dans 255.255.255.0, que marquent les bits à 0 ?

Corrigé
10.20.30.40 : classe A (1-126), 255.0.0.0. 172.20.1.1 : classe B (128-191), 255.255.0.0. 192.168.10.5 : classe C (192-223), 255.255.255.0. 127.0.0.1 : boucle locale — pas une classe. 225.1.1.1 : classe D (224-239), multicast. Les bits à 0 du masque marquent la partie hôte — ici le dernier octet.
Exercice 4/5 — Sous-réseautage

À partir d'un /24, on emprunte 3 bits. Donner : le nombre de sous-réseaux, le nombre d'hôtes valides par sous-réseau, le nouveau masque décimal et la notation CIDR. Mêmes questions en empruntant 2 bits. Quel bloc choisir pour une liaison point-à-point ?

Corrigé
3 bits : 2^3 = 8 sous-réseaux ; 5 bits restants : 2^5 - 2 = 30 hôtes valides ; masque 11100000 = 255.255.255.224, soit /27. 2 bits : 4 sous-réseaux ; 2^6 - 2 = 62 hôtes ; masque 255.255.255.192, /26. Liaison point-à-point : /30 — exactement 2 hôtes valides (2^2 - 2), le plus petit bloc.

QCM final — toutes notions

Un réseau limité à un immeuble est…

LAN : salle, classe, campus, PMI.

Dans une étoile, une coupure isole…

Liaisons point à point : le reste continue.

La longueur maximale d'un segment UTP est…

100 mètres ; catégorie 5e pour le gigabit.

Le commutateur travaille en couche…

Liaison de données ; le routeur, lui, est en couche 3.

Le chiffrement OSI se fait en couche…

Présentation : formater, chiffrer, compresser.

Le SYN-ACK du handshake porte…

Acquittement du SYN et nouveau numéro de séquence.

La voix sur IP utilise plutôt…

UDP : rapidité, pertes tolérables.

Une adresse MAC est routée…

Portée : le segment local uniquement.

L'adresse 172.16.0.1 est de classe…

Premier octet 172 : classe B (128-191).

Emprunter 3 bits à un /24 crée…

2^3 = 8 ; /27, 30 hôtes valides chacun.
