Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque session, puis un projet final qui outille le campus entier. Les scripts sont en Bash, comme à l'atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n lignes « reseau portee » (lan/wan/man/pan/wlan) et affiche la description de chaque réseau, puis le compteur LAN.
  2. Lit n lignes « equipement couche » (osil 1 a 7) et affiche le nom de chaque couche, puis le compteur couche 3.
  3. Lit n lignes « protocole famille » (tcp/udp) et affiche fiable ou rapide, puis les deux compteurs.
  4. Lit n adresses MAC (12 caracteres hexa) et vérifie la longueur : 12 chiffres sinon « invalide ».
Corrections
read -r n
lan=0
for ((k=0; k<n; k++)); do
  read -r reseau portee
  case "$portee" in
    lan) echo "$reseau : local (immeuble, campus)" ; lan=$((lan + 1)) ;;
    wan) echo "$reseau : etendu (villes, pays)" ;;
    man) echo "$reseau : metropolitan (ville)" ;;
    wlan) echo "$reseau : local sans fil (802.11)" ;;
    pan) echo "$reseau : personnel (une personne)" ;;
  esac
done
echo "lan : $lan/$n"

read -r n
reseau3=0
for ((k=0; k<n; k++)); do
  read -r equipement couche
  case "$couche" in
    1) echo "$equipement : physique" ;;
    2) echo "$equipement : liaison de donnees" ;;
    3) echo "$equipement : reseau" ; reseau3=$((reseau3 + 1)) ;;
    4) echo "$equipement : transport" ;;
    5) echo "$equipement : session" ;;
    6) echo "$equipement : presentation" ;;
    7) echo "$equipement : application" ;;
  esac
done
echo "couche reseau : $reseau3/$n"

read -r n
tcp=0 ; udp=0
for ((k=0; k<n; k++)); do
  read -r protocole famille
  if [ "$famille" = "tcp" ]; then
    echo "$protocole : fiable (accuses de reception)" ; tcp=$((tcp + 1))
  else
    echo "$protocole : rapide (sans accuse)" ; udp=$((udp + 1))
  fi
done
echo "tcp : $tcp / udp : $udp"

read -r n
invalides=0
for ((k=0; k<n; k++)); do
  read -r mac
  if [ ${#mac} -eq 12 ]; then
    echo "$mac : valide (48 bits)"
  else
    echo "$mac : invalide" ; invalides=$((invalides + 1))
  fi
done
echo "invalides : $invalides/$n"

Application

Application
  1. Lit n lignes « adresse octet » (premier octet + classe annoncee a/b/c/d/e) et valide le classement par le premier octet.
  2. Lit n lignes « ip masque » (a ou b) et dit, pour chaque adresse, si elle est dans le meme reseau que la premiere.
  3. Lit n lignes « objet couche » (osil 1 a 7) et place cable, commutateur, routeur, chiffrement, ports dans leur couche.
  4. Lit n lignes « etape handshake » (syn/synack/ack dans l'ordre) et vérifie la séquence complete.
Corrections
read -r n
justes=0
for ((k=0; k<n; k++)); do
  read -r adresse classe
  premier=${adresse%%.*}
  if [ "$premier" -ge 1 ] && [ "$premier" -le 126 ]; then reelle=a
  elif [ "$premier" -ge 128 ] && [ "$premier" -le 191 ]; then reelle=b
  elif [ "$premier" -ge 192 ] && [ "$premier" -le 223 ]; then reelle=c
  elif [ "$premier" -ge 224 ] && [ "$premier" -le 239 ]; then reelle=d
  else reelle=e
  fi
  if [ "$reelle" = "$classe" ]; then
    echo "$adresse : classe $reelle confirmee" ; justes=$((justes + 1))
  else
    echo "$adresse : classe $reelle, pas $classe"
  fi
done
echo "classements justes : $justes/$n"

read -r n
read -r ipref masque
pref=${ipref%%.*}
for ((k=1; k<n; k++)); do
  read -r ip masque
  p=${ip%%.*}
  if [ "$p" = "$pref" ] && [ "$masque" = "a" ]; then
    echo "$ip : meme reseau /8"
  else
    echo "$ip : reseau different ou masque errone"
  fi
done

read -r n
for ((k=0; k<n; k++)); do
  read -r objet couche
  case "$objet" in
    cable) attendu=1 ;;
    commutateur) attendu=2 ;;
    routeur) attendu=3 ;;
    ports) attendu=4 ;;
    chiffrement) attendu=6 ;;
  esac
  if [ "$couche" = "$attendu" ]; then
    echo "$objet : couche $attendu ok"
  else
    echo "$objet : couche $attendu, pas $couche"
  fi
done

read -r n
etape=0
for ((k=1; k<=n; k++)); do
  read -r paquet
  case "$k:$paquet" in
    1:syn) etape=$((etape + 1)) ;;
    2:synack) etape=$((etape + 1)) ;;
    3:ack) etape=$((etape + 1)) ;;
  esac
done
if [ "$etape" -eq 3 ]; then
  echo "handshake complet : full-duplex"
else
  echo "handshake incomplete : $etape/3"
fi

Raisonnement

Raisonnement
  1. Lit n lignes « poste panne » (bus/anneau/etoile) et simule l'effet d'une coupure : tout tombe, bascule, ou un poste isole.
  2. Lit n lignes « service besoin » (fiable/rapide) et tranche TCP ou UDP, puis signale les incoherences (voix en TCP).
  3. Lit « emprunt » puis calcule : sous-reseaux, hotes valides, dernier octet du masque, prefixe CIDR.
  4. Lit « seuil n » puis n lignes « site hotes » et rend le plus petit bloc /n couvrant chaque site (verdict d'espace perdu).
Corrections
read -r n
graves=0
for ((k=0; k<n; k++)); do
  read -r poste topo
  case "$topo" in
    bus) echo "$poste : tout le reseau tombe" ; graves=$((graves + 1)) ;;
    anneau) echo "$poste : bascule sur l'anneau secondaire" ;;
    etoile) echo "$poste : un seul poste isole" ;;
  esac
done
echo "pannes totales : $graves/$n"

read -r n
incoherences=0
for ((k=0; k<n; k++)); do
  read -r service besoin
  case "$besoin" in
    fiable) echo "$service : TCP" ;;
    rapide) echo "$service : UDP" ;;
  esac
done
echo "regle : contrat manquant = TCP, micro-coupure = UDP"

read -r emprunt
restants=$((8 - emprunt))
sousreseaux=$((1 << emprunt))
hotestheorique=$((1 << restants))
hotes=$((hotestheorique - 2))
declare -A valeurs
valeurs[1]=128 ; valeurs[2]=192 ; valeurs[3]=224 ; valeurs[4]=240
masque=${valeurs[$emprunt]}
prefixe=$((24 + emprunt))
echo "sous-reseaux : $sousreseaux"
echo "hotes valides : $hotes"
echo "masque : 255.255.255.$masque"
echo "prefixe : /$prefixe"

read -r seuil
read -r n
perdu=0
for ((k=0; k<n; k++)); do
  read -r site hotes
  taille=2
  bits=1
  while [ $((taille - 2)) -lt "$hotes" ]; do
    taille=$((taille * 2))
    bits=$((bits + 1))
  done
  prefixe=$((32 - bits))
  capacite=$((taille - 2))
  gaspillage=$((capacite - hotes))
  echo "$site : /$prefixe ($capacite hotes, $gaspillage perdus)"
  perdu=$((perdu + gaspillage))
done
if [ "$perdu" -le "$seuil" ]; then
  echo "plan : acceptable ($perdu adresses perdues)"
else
  echo "plan : a affiner ($perdu adresses perdues)"
fi

Projet intégrateur — « le plan d'adressage du campus »

Cahier des charges

Le script reçoit le recensement du campus : d'abord n_sites sites au format site hotes (nombre de machines à adresser), puis n_tests tests de connectivité au format ip verdict où verdict vaut ok (répond), lent (répond avec perte) ou hs (hors service). Il produit le rapport : pour chaque site, le plus petit bloc couvrant les hôtes (préfixe /n et capacité 2^k - 2) ; puis le diagnostic réseau : chaque hs incrimine la couche 1, chaque lent la couche 3 ; enfin le verdict global : campus prete si tous les tests sont ok et si aucun site ne dépasse 254 hôtes (sinon replanification requise).

Fonctionnalités attendues
  1. Lire les deux blocs sans mélanger sites et tests.
  2. Dimensionner chaque site : plus petit 2^k - 2 couvrant les hôtes.
  3. Diagnostiquer chaque test : hs → couche 1, lent → couche 3.
  4. Agréger le gaspillage d'adresses avec des tableaux associatifs.
  5. Verdict final au format exact du cahier des charges.

Contraintes : arithmétique entière (bash refuse les décimales), boucle de dimensionnement, bilan après lecture complète.

Grille d'auto-évaluation du projet (sur 100)
Lecture des deux blocs et parsing correct 20
Dimensionnement de chaque site (plus petit bloc) 20
Diagnostic par couche des tests 20
Verdict global conforme 20
Rapport lisible et formats exacts 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
read -r n_sites
declare -A blocs
declare -A gaspillages
depasse=0
for ((k=0; k<n_sites; k++)); do
  read -r site hotes
  if [ "$hotes" -gt 254 ]; then depasse=1 ; fi
  taille=2
  bits=1
  while [ $((taille - 2)) -lt "$hotes" ]; do
    taille=$((taille * 2))
    bits=$((bits + 1))
  done
  prefixe=$((32 - bits))
  capacite=$((taille - 2))
  gaspillage=$((capacite - hotes))
  blocs[$site]=$prefixe
  gaspillages[$site]=$gaspillage
  echo "$site : /$prefixe ($capacite hotes, $gaspillage perdus)"
done
read -r n_tests
l1=0 ; l3=0 ; tout_ok=1
for ((k=0; k<n_tests; k++)); do
  read -r ip verdict
  case "$verdict" in
    ok) echo "$ip : repond" ;;
    lent) echo "$ip : perte, couche 3" ; l3=$((l3 + 1)) ; tout_ok=0 ;;
    hs) echo "$ip : hors service, couche 1" ; l1=$((l1 + 1)) ; tout_ok=0 ;;
  esac
done
total=0
for site in "${!blocs[@]}"; do
  total=$((total + ${gaspillages[$site]}))
done
echo "gaspillage total : $total adresses"
if [ "$tout_ok" = "1" ] && [ "$depasse" = "0" ]; then
  echo "verdict : campus prete"
else
  echo "verdict : replanification requise"
fi
Cette solution combine dimensionnement, diagnostic par couche, agrégation du gaspillage et verdict global — les chapitres 1, 3, 5 et 6 en un seul script.
