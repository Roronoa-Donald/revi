Architecture des réseaux B1 — OSI, TCP/IP, adressage, sous-réseaux

L'architecture des réseaux n'est pas de la théorie : c'est une discipline — classer un réseau (LAN, MAN, WAN), prévoir la panne (bus, anneau, étoile), dépanner par couches (OSI), ouvrir une connexion (handshake TCP), découper un plan d'adresses (masque, VLSM). Six chapitres pour ancrer chaque mécanisme. Chacun est d'abord programmé et vérifié dans l'atelier, puis rejoué tel quel sur les exemples des supports.

Ce que tu sauras faire à la fin du cours
  • classer un réseau : LAN contre WAN, workgroup contre client-serveur, PAN à WAN ;
  • prévoir la panne : bus fragile, anneau à jeton et double anneau, étoile qui isole ;
  • dépanner par couches : les sept couches OSI, câble en 1, commutateur en 2, routeur en 3 ;
  • ouvrir une connexion TCP : SYN, SYN-ACK, ACK — et choisir TCP ou UDP selon l'exigence ;
  • lire une adresse : MAC 48 bits non routée, IP réseau + hôte, masque, classes A, B, C ;
  • dimensionner un plan d'adressage : emprunt de bits, nouveau masque, VLSM et CIDR.
Comment ce cours s'articule

Les trois sessions du support « Architecture des réseaux » (Collège de Paris) déroulent les fondamentaux, les topologies et supports, les modèles OSI et TCP/IP, puis l'adressage et le sous-réseautage. Ce cours en garde l'esprit et fait manipuler chaque règle en Bash : un script qui reproduit l'analyse exacte du support — classement, panne, handshake, masque — exécuté dans la page.

Chaque chapitre se termine par trois exercices de code : tu écris vraiment le script, il est réellement exécuté, puis corrigé par des tests que tu ne vois pas. La logique écrite ici se rejoue telle quelle sur les cas des supports (classes d'adresses, emprunt de bits, VLSM).

Programme du cours

1Fondamentaux et architectures
Pourquoi les réseaux ? LAN contre WAN ; groupe de travail contre client-serveur ; les cinq types de réseaux (PAN, LAN, WLAN, MAN, WAN). 2Topologies et supports
Les trois topologies (bus, anneau, étoile) et leur comportement en panne ; les supports de transmission (UTP, STP, fibre, Wi-Fi, CPL). 3Le modèle OSI
Les sept couches du modèle OSI, de la physique à l'application ; les équipements par couche ; la méthode de dépannage par couches. 4Le modèle TCP/IP
Les quatre couches du modèle TCP/IP ; le three-way handshake de TCP ; choisir entre TCP fiable et UDP rapide. 5L'adressage réseau
L'adresse MAC (48 bits, OUI, non routée) ; l'adresse IP (réseau + hôte, IPv4/IPv6) ; ARP et le routage ; le masque ; les classes A, B, C. 6Le sous-réseautage
Emprunter des bits à la partie hôte ; calculer le nouveau masque ; VLSM et CIDR : la fin des classes.
