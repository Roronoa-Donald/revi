Chapitre 6 — Capteurs, seuils et régulation

Module 6 ≈ 3 h de travail Réservé B1 et plus
Mise en situation

Le robot est équipé : afficheur 7 segments pour compter, capteur de distance pour freiner, capteur de température pour alerter. Le matériel se branche en une heure ; le programme qui le pilote demande trois qualités : une table de correspondance claire, des seuils stricts assumés, un bilan qui résume la série. C’est le chapitre où tout le cours se combine.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. associer chaque chiffre à ses segments via un dictionnaire ;
  2. classer des relevés par seuils stricts avec trois états ;
  3. réafficher des nombres sans zéros inutiles ;
  4. agréger une série en minimum et moyenne entière.

1. L’afficheur 7 segments comme table

Sept segments nommés de a à g. Chaque chiffre allume un sous-ensemble : le 0 allume tout sauf g, le 1 seulement b et c, le 8 tout. La correspondance est une donnée, pas un calcul : un dictionnaire la pose une fois pour toutes.

segments = {
    0: "a b c d e f",
    1: "b c",
    2: "a b d e g",
    ...
    8: "a b c d e f g"
}
print(segments[chiffre])

Le programme principal se réduit alors à une lecture et un affichage : toute la complexité est dans la table, lisible et vérifiable chiffre par chiffre. C’est le même réflexe qu’en électronique, où la table de vérité précède le câblage.

Mnémotechnique — « Le dictionnaire est un câblage »

Écrire 7: "a b c" dans un dictionnaire, c’est brancher les segments a, b, c du chiffre 7. Une table de correspondance est plus sûre qu’un calcul : elle ne peut pas se tromper de formule, seulement d’entrée — et ça se voit d’un coup d’œil.

2. Trois états, deux seuils

La station météo du TP classe chaque relevé : alerte chaleur au-dessus de 30, alerte froid en dessous de 15, normal entre les deux. Trois états, deux seuils, une chaîne if / elif / else.

if t > 30:      "ALERTE CHALEUR"
elif t < 15:    "ALERTE FROID"
else:           "normale"

Les seuils sont stricts : 30 exactement est normal, 15 exactement est normal. Les tests vérifient toujours la frontière — le relevé égal au seuil est le cas qui trahit un >= écrit par distraction.

Piège — le relevé à la frontière

Un >= au lieu de > déplace tout le compte d’alertes : 30.0 basculerait en alerte. L’énoncé fixe la frontière ; le code la respecte au caractère près. Si l’énoncé dit « strictement supérieur », le test est >.

3. Afficher sans zéros inutiles

Un relevé de 30.0 doit s’afficher « 30 », un relevé de 12.5 garde sa décimale. Le format :g fait exactement cela : il supprime les zéros de fin.

f"{t:g} C : normale"      →   "30 C : normale"
f"{t:g} C : normale"      →   "12.5 C : normale"
f"{t:.2f} C : normale"    →   "30.00 C : normale"   (à éviter ici)

Les trois formats à connaître : :g nettoie, :.2f arrondit à deux décimales, :<12 aligne à gauche. Choisir le mauvais n’est pas une erreur de style : c’est une sortie différente, et les tests la refusent.

4. Le bilan : minimum et moyenne entière

Après le classement, le régulateur résume la série : le relevé le plus petit (le plus urgent) et la moyenne.

minimum = min(distances)
moyenne = sum(distances) // n        # division entière

print(f"minimum : {minimum}")
print(f"moyenne : {moyenne}")

La division entière // est imposée par l’énoncé : 135 / 6 vaut 22,5 mais 135 // 6 vaut 22. Le min() d’une liste non vide ne plante jamais ; c’est une liste vide qui le ferait — et l’énoncé garantit n ≥ 1.

Suivre le minimum dans la boucle

Deux écoles : min() après coup, ou une variable suivie dans la boucle (« si d est plus petit, il devient le nouveau minimum »). Les deux sont justes ; la seconde est ce qu’on écrit sur une carte qui traite les relevés au fil de l’eau, sans les retenir tous.

Exercice 1 — Décodeur 7 segments

Étude de cas Niveau 2 — Application

Objectif : Associer chaque chiffre à la liste de ses segments allumés, via une table de correspondance.

Un afficheur 7 segments possède sept segments notés de a à g. Analysez les données soumises pour chaque cas. Construire la correspondance dans un dictionnaire : 0 → a b c d e f ; 1 → b c ; 2 → a b d e g ; 3 → a b c d g ; 4 → b c f g ; 5 → a c d f g ; 6 → a c d e f g ; 7 → a b c ; 8 → tous ; 9 → a b c d f g.

Cas d’exemple
2
Résolution attendue
a b d e g

Le 2 allume cinq segments : a, b, d, e et g.

Deux indices, rédigés en mots
  1. Complétez le dictionnaire chiffre par chiffre, puis une seule ligne d’affichage suffit : print(segments[chiffre]).
  2. Le 8 allume tous les segments : c’est la seule entrée qui contient les sept lettres.

6. QCM — niveau examen

Quels segments s’allument pour le chiffre 8 ?

Le 8 allume les sept segments.

t = 30 exactement avec le test t > 30 : quel état ?

Seuil strict : 30 n’est pas strictement supérieur à 30, il reste normal.

Que vaut 135 // 6 ?

La division entière tronque : 22. Le reste serait 3.

Que produit f"{12.5:g}" ?

:g affiche sans zéros inutiles : la décimale utile reste.

Dans if / elif / else, le relevé 20 des seuils 30 et 15 tombe dans…

Ni > 30 ni < 15 : c’est le else qui le classe normal.

min() sur une liste vide…

Il n’y a pas de minimum à une liste vide : l’énoncé garantit n ≥ 1.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Table incomplète : un chiffre absent du dictionnaire lève KeyError à l’affichage.
  • Seuil large au lieu de strict : 30 exactement compte en alerte et le total glisse.
  • :.2f au lieu de :g : « 30.00 » s’affiche là où « 30 » est attendu.
  • Moyenne vraie au lieu d’entière : 22.5 affiché là où // donne 22.
  • min() sur liste vide : impossible ici (n ≥ 1), mais le réflexe de garde reste bon.

8. Méthodologie de résolution

Piloter un capteur en simulation
  1. Poser les données fixes dans une table (dictionnaire) plutôt qu’en calculs ad hoc.
  2. Fixer les seuils et leur strictesse tels que l’énoncé les écrit.
  3. Choisir le format d’affichage : :g pour nettoyer, :.2f pour arrondir, alignement pour les colonnes.
  4. Agréger après la boucle : min, max, somme, moyenne — jamais dans le classement.
  5. Rejouer les frontières : une valeur exactement au seuil, une sous le seuil, une au-dessus.

9. Révision active

Résumé essentiel
  • Une correspondance chiffre → segments est une donnée : le dictionnaire la pose, l’affichage la lit.
  • Trois états, deux seuils : if / elif / else, une seule branche par relevé.
  • Seuils stricts : 30 et 15 exactement restent dans la zone normale.
  • :g affiche sans zéros inutiles ; :.2f arrondit ; le choix du format change la sortie.
  • Bilan : min() pour l’extrême, // pour la moyenne entière imposée par l’énoncé.

Checklist de maîtrise

  • Je construis un dictionnaire de correspondance complet et je le lis proprement.
  • Je classe des relevés avec des seuils stricts en trois états.
  • J’affiche des nombres sans zéros inutiles au bon format.
  • Je produis un bilan minimum et moyenne entière corrects.
