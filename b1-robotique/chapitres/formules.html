Mémo du roboticien

Boucles, décisions, formats et opérateurs du cours sur une page. À garder ouvert pendant les exercices et l’atelier.

La boucle du robot

capter    lire les entrées (input, capteur)

décider   comparer à des seuils ou des règles

agir      commander les sorties (print, digitalWrite)

Sur la carte, la boucle tourne dans loop() ou while True ; en simulation, le programme la déroule puis s’arrête.

Lectures et conversions

ligne de texte        input()

entier                int(input())

décimal               float(input())

n valeurs             [int(input()) for _ in range(n)]

deux entiers (1 ligne)  a, b = (int(x) for x in input().split())

« nom age » (1 ligne)   parties = input().split()

L’ordre des lectures est imposé par l’énoncé : le programme doit le respecter exactement.

Boucles et comptages

k répétitions         for _ in range(k):

sur une série         for valeur in serie:

compteur              initialiser AVANT, incrémenter DANS la bonne branche,

                      exploiter APRÈS la boucle

comparaisons du tri à bulles    n(n − 1) / 2

range(0) ne passe rien : le programme saute au bilan. Le pluriel s’accorde avec {"s" if c > 1 else ""}.

Décisions

test simple           if d < seuil:    ...

deux branches         if / else        exactement une branche

trois états           if / elif / else  la première vraie gagne

fonction de test      def est_pair(x): return x % 2 == 0

primalité             diviseurs de 2 à √x ; 0 et 1 exclus

Strict ou large change la frontière de camp : la valeur exactement au seuil est le cas de test qui trahit l’opérateur.

Logique et chiffrement

ET  a and b   (& bit à bit)

OU  a or b    (| bit à bit)

NON not a     (~ bit à bit)

XOR a != b    (^ bit à bit ; la puissance se note **)

afficher 0/1  int(...)

additionneur  S = a ^ b ^ cin ;  Cout = (a & b) | (cin & (a ^ b))

César         chr((ord(c) - base + k) % 26 + base)

NAND = not(a and b) est universelle : tout circuit se reconstruit avec elle. Les lettres seules se décalent ; chiffres, espaces et ponctuation restent inchangés.

Formats d’affichage

f"{valeur}"        insertion simple

f"{m:.2f}"         deux décimales fixes        13.67

f"{t:g}"           sans zéros inutiles          30.0 → 30

f"{nom:<12}"       aligné à gauche sur 12       "Membre      "

f"{n} cycle{'s' if n > 1 else ''}}"   pluriel conditionnel

Choisir le mauvais format change la sortie : les tests comparent au caractère près.

Erreurs fréquentes à éviter

  • Lire les entrées dans un autre ordre que l’énoncé.
  • Initialiser un compteur dans la boucle, ou afficher le bilan dedans.
  • Confondre / (décimal) et // (quotient entier).
  • Écrire >= là où l’énoncé dit « strictement supérieur ».
  • Décaler une majuscule avec la base des minuscules dans César.
  • Confondre ^ (XOR) et ** (puissance).
