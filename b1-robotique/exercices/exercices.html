Projet intégrateur — « relevé de télémétrie »

Cahier des charges

Le robot revient d’un parcours avec son journal de télémétrie. Le programme lit n, puis n lignes au format capteur valeur — le capteur vaut dist (distance en cm) ou temp (température en °C). Il produit un rapport complet : nombre de relevés par capteur, distance minimale avec son état (STOP/LENT/LIBRE), température maximale avec son état (ALERTE CHALEUR si > 30, ALERTE FROID si < 15, normale), et une recommandation finale.

Fonctionnalités attendues
  1. Lire les relevés en une passe et les ranger par capteur dans deux listes.
  2. Calculer : distance minimale, température maximale, avec des fonctions dédiées.
  3. Classer : états par seuils stricts (distance < 10 STOP, < 30 LENT ; température > 30, < 15).
  4. Recommander : «maintenance» si une alerte existe, «mission nominale» sinon.
  5. Formater : valeurs sans zéros inutiles (:g), libellés exacts.
  6. Gérer les cas limites : aucun relevé d’un capteur (message dédié), un seul relevé.

Contraintes : une fonction = une responsabilité, noms explicites, aucun index hors liste.

Grille d’auto-évaluation du projet (sur 100)
Lecture en une passe et séparation par capteur 20
Fonctions dédiées min/max correctes 20
Seuils stricts et états exacts 20
Recommandation et cas limites 20
Lisibilité, noms, formats 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

def etat_distance(d):
    if d < 10:
        return "STOP"
    if d < 30:
        return "LENT"
    return "LIBRE"

def etat_temperature(t):
    if t > 30:
        return "ALERTE CHALEUR"
    if t < 15:
        return "ALERTE FROID"
    return "normale"

n = int(input())
distances = []
temperatures = []
for _ in range(n):
    parties = input().split()
    if parties[0] == "dist":
        distances.append(float(parties[1]))
    else:
        temperatures.append(float(parties[1]))

print(f"releves distance : {len(distances)}")
print(f"releves temperature : {len(temperatures)}")

if distances:
    mini = min(distances)
    print(f"distance minimale : {mini:g} ({etat_distance(mini)})")
else:
    print("distance minimale : aucun releve")

if temperatures:
    maxi = max(temperatures)
    print(f"temperature maximale : {maxi:g} ({etat_temperature(maxi)})")
else:
    print("temperature maximale : aucun releve")

if any(d < 10 for d in distances) or any(t > 30 or t < 15 for t in temperatures):
    print("recommandation : maintenance")
else:
    print("recommandation : mission nominale")
Cette solution combine lecture structurée, fonctions de test, seuils stricts, formats et cas limites — l’essentiel des six modules en un seul rapport.
