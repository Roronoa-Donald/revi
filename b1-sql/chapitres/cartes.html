Module 2 — Types de données et création de tables

QuestionQuel type pour l’argent et pourquoi ?
RéponseDECIMAL(p, s) : calcul décimal exact, là où FLOAT arrondit.
QuestionDifférence entre CHAR(x) et VARCHAR(x) ?
RéponseCHAR réserve toujours x caractères et complète d’espaces ; VARCHAR stocke jusqu’à x, tel quel.
QuestionFormat d’un littéral DATE en SQL ?
Réponse'AAAA-MM-JJ' — année, mois, jour, toujours dans cet ordre.
QuestionQue devient une colonne absente d’un INSERT ?
RéponseElle reçoit NULL, ou sa valeur par défaut si DEFAULT est déclaré.
QuestionQu’est-ce que « TINYINT » (Ch. 2) ?
RéponseEntiers : TINYINT à BIGINT selon la plage ; INT(x) ne change que l’affichage.
QuestionQu’est-ce que « INT » (Ch. 2) ?
RéponseDeux précisions du support : la notation INT(x) ne change pas la capacité de stockage, seulement l’affichage (avec ZEROFILL , elle complète de zéros). Pour les décimaux, on utilise DECIMAL(p, s) — précision p, s décimale

Module 3 — Interroger : SELECT, WHERE, tri et restrictions

QuestionOrdre fixe des clauses d’un SELECT ?
RéponseSELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT.
QuestionComment teste-t-on NULL ?
RéponseIS NULL ou IS NOT NULL — jamais = NULL.
QuestionQue font % et _ dans LIKE ?
Réponse% remplace toute suite de caractères, _ exactement un caractère.
QuestionQue fait ORDER BY a, b DESC ?
RéponseTriez par a croissant puis, à l’intérieur, par b décroissant.
QuestionQu’est-ce que « DISTINCT » (Ch. 3) ?
Réponseéliminer les doublons avec DISTINCT ;

Module 4 — Jointures : relier les tables

QuestionQue construit une jointure ?
RéponseUne table virtuelle et temporaire, appariée par la condition ON.
QuestionDifférence INNER / LEFT JOIN ?
RéponseINNER ne garde que les correspondances ; LEFT garde toute la table de gauche, complétée de NULL.
QuestionPourquoi COUNT(V.immat) et pas COUNT(*) sur une LEFT JOIN ?
RéponseCOUNT(colonne) ignore les NULL : les marques sans voiture comptent 0, pas 1.
QuestionC’est quoi une colonne ambiguë ?
RéponseUn nom de colonne porté par deux tables jointes et écrit sans préfixe d’alias.
QuestionQu’est-ce que « INNER JOIN » (Ch. 4) ?
Réponsechoisir entre INNER JOIN et LEFT JOIN selon la question ;
QuestionQu’est-ce que « produit cartésien » (Ch. 4) ?
RéponseCondition de jointure oubliée : produit cartésien, des milliers de lignes absurdes.

Module 5 — Agrégation : compter, regrouper, filtrer les groupes

QuestionQue renvoie une fonction d’agrégation ?
RéponseUne valeur unique par table (sans GROUP BY) ou par groupe (avec).
QuestionDifférence COUNT(*) / COUNT(colonne) ?
RéponseCOUNT(*) compte toutes les lignes ; COUNT(colonne) saute les NULL.
QuestionRègle d’or du GROUP BY ?
RéponseToute colonne du SELECT est dans le GROUP BY ou dans un agrégat.
QuestionWHERE ou HAVING ?
RéponseWHERE filtre les lignes avant regroupement ; HAVING filtre les groupes, avec un agrégat.

Module 6 — Modifier les données et gérer les droits

QuestionPourquoi tester par SELECT avant un UPDATE ?
RéponseLe même WHERE ramène exactement les lignes qui seront modifiées : on voit avant de toucher.
QuestionDELETE sans WHERE, effet ?
RéponseLa table est vidée de ses lignes ; la structure reste (contrairement à DROP TABLE).
QuestionComment définit-on un utilisateur MySQL ?
RéponsePar un couple login@hôte, le joker % élargissant l’hôte.
QuestionQue permet GRANT OPTION ?
RéponseDe transmettre à d’autres les privilèges qu’on possède — avec WITH GRANT OPTION dans la clause.
