Module 1 — Bases de données et SGBD

QuestionDéfinissez une base de données.
RéponseUn ensemble d’informations organisé pour être accessible, géré et mis à jour facilement, interrogeable par le contenu.
QuestionRôle du SGBD ?
RéponseLogiciel qui gère la base : insertion, modification, recherche et, selon le système, contrôle des accès et partage.
QuestionClé primaire vs clé étrangère ?
RéponseLa primaire identifie chaque ligne sans ambiguïté ; l’étrangère pointe vers une ligne d’une autre table.
QuestionQue vaut NULL ?
RéponseL’absence d’information — ni 0, ni chaîne vide, ni tiret.
QuestionQu’est-ce que le modèle relationnel ?
RéponseUne manière d’organiser les données en tables (aussi appelées relations), faites de lignes et de colonnes, reliées entre elles par des clés (clé primaire et clé étrangère).
QuestionComment lire une requête SELECT ?
RéponseSELECT dit quoi afficher, FROM dit dans quelle table lire, ORDER BY dit dans quel ordre. Une requête SELECT ne modifie jamais les données.

Module 2 — Types de données et création de tables

QuestionQuel type pour l’argent et pourquoi ?
RéponseEn MySQL, DECIMAL convient aux décimaux exacts ; le parc SQLite stocke les francs entiers en INTEGER.
QuestionDifférence entre CHAR(x) et VARCHAR(x) ?
RéponseEn MySQL, CHAR est fixe et VARCHAR variable ; SQLite leur donne une affinité texte sans imposer cette longueur.
QuestionComment le parc SQLite représente-t-il datecirc ?
RéponseEn TEXT au format 'AAAA-MM-JJ', ou NULL si la date est inconnue.
QuestionQue devient une colonne absente d’un INSERT ?
RéponseEn SQLite, elle reçoit son DEFAULT ou NULL, sauf erreur de contrainte NOT NULL. Dans une table ordinaire, une INTEGER PRIMARY KEY omise peut être générée.
QuestionÀ quoi sert TINYINT en MySQL ?
RéponseÀ stocker un petit entier : de −128 à 127 en version signée. SQLite donne à TINYINT une affinité INTEGER sans imposer cette plage.
QuestionQuelle différence entre DATE et DATETIME en MySQL ?
RéponseDATE représente une date ; DATETIME ajoute l’heure. Dans notre parc SQLite, datecirc est un texte AAAA-MM-JJ.
QuestionÀ quoi sert CREATE TABLE ?
RéponseÀ créer une table en définissant ses colonnes, leurs types et leurs contraintes, par exemple NOT NULL et PRIMARY KEY.

Module 3 — Interroger : SELECT, WHERE, tri et restrictions

QuestionOrdre fixe des clauses d’un SELECT ?
RéponseSELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT.
QuestionComment teste-t-on NULL ?
RéponseIS NULL ou IS NOT NULL — jamais = NULL.
QuestionQue font % et _ dans LIKE ?
Réponse% remplace toute suite de caractères, _ exactement un caractère.
QuestionQue fait ORDER BY a, b DESC ?
RéponseTrie par a croissant puis, à l’intérieur, par b décroissant.
QuestionQue fait DISTINCT dans un SELECT ?
RéponseIl retire les doublons du résultat : SELECT DISTINCT paysmarque FROM Marque; affiche chaque pays une seule fois.

Module 4 — Jointures : relier les tables

QuestionQue produit une jointure ?
RéponseUn résultat combinant des lignes ; ON ou USING peuvent définir les correspondances. CROSS JOIN peut produire toutes les combinaisons.
QuestionDifférence INNER / LEFT JOIN ?
RéponseINNER ne garde que les correspondances ; LEFT garde toute la table de gauche, complétée de NULL.
QuestionPourquoi COUNT(V.immat) et pas COUNT(*) sur une LEFT JOIN ?
RéponseCOUNT(colonne) ignore les NULL : les marques sans voiture comptent 0, pas 1.
QuestionC’est quoi une colonne ambiguë ?
RéponseUn nom de colonne porté par deux tables jointes et écrit sans préfixe d’alias.

Module 5 — Agrégation : compter, regrouper, filtrer les groupes

QuestionQue renvoie une fonction d’agrégation ?
RéponseUne valeur unique par table (sans GROUP BY) ou par groupe (avec).
QuestionDifférence COUNT(*) / COUNT(colonne) ?
RéponseCOUNT(*) compte toutes les lignes ; COUNT(colonne) saute les NULL.
QuestionRègle d’or du GROUP BY ?
RéponsePour un résultat déterministe et portable, sélectionnez les colonnes regroupées et les agrégats ; SQLite accepte aussi des colonnes arbitraires.
QuestionWHERE ou HAVING ?
RéponseWHERE filtre les lignes ; HAVING filtre les groupes et peut aussi filtrer le groupe global d’une requête agrégée SQLite.

Module 6 — Modifier les données et gérer les droits

QuestionPourquoi tester par SELECT avant un UPDATE ?
RéponseLe même WHERE montre les lignes visées si la base ne change pas ; contraintes ou déclencheurs peuvent ensuite modifier le résultat.
QuestionDELETE sans WHERE, effet ?
RéponseLa table est vidée de ses lignes ; la structure reste (contrairement à DROP TABLE).
QuestionComment définit-on un utilisateur MySQL ?
RéponsePar un couple login@hôte ; le joker % élargit l’hôte, mais cet usage est déprécié en MySQL 8.4.
QuestionQue permet GRANT OPTION en MySQL ?
RéponseDe transmettre à d’autres les privilèges qu’on possède — avec WITH GRANT OPTION dans la clause.
