Mémo SQL

Syntaxes, ordre des clauses et types du cours sur une page. À garder ouvert pendant le simulateur et les exercices.

Vocabulaire

TermeSens
Base de donnéesinformations organisées, interrogeables par le contenu
SGBDlogiciel qui gère la base (MySQL, PostgreSQL, SQLite…)
Tablelignes (enregistrements) et colonnes (attributs)
Clé primaireidentifie chaque ligne sans ambiguïté
Clé étrangèrepointe vers une ligne d’une autre table
NULLabsence d’information — ni 0, ni chaîne vide

Types de colonnes

entiers        TINYINT, SMALLINT, MEDIUMINT, INT, BIGINT

décimaux exacts  DECIMAL(p, s)   -- l’argent : toujours DECIMAL

mesures         FLOAT, DOUBLE    -- arrondis possibles

chaînes fixes   CHAR(x)          -- complété d’espaces

chaînes variables  VARCHAR(x)    -- stocké tel quel

temps           DATE 'AAAA-MM-JJ', TIME 'HH:MM:SS', DATETIME, TIMESTAMP, YEAR

INT(x) ne change que l’affichage (avec ZEROFILL), pas le stockage.

Ordre des clauses (et de l’exécution)

SELECT   colonnes, agrégats

FROM     tables (jointures)

WHERE    filtre les LIGNES

GROUP BY découpe en GROUPES

HAVING   filtre les GROUPES (condition avec agrégat)

ORDER BY trie (ASC par défaut, DESC décroissant)

LIMIT    n [OFFSET d]   borne le résultat

L’ordre d’écriture est imposé ; une clause déplacée est une erreur de syntaxe.

Opérateurs de WHERE

=  <>  !=  <  <=  >  >=

BETWEEN a AND b         intervalle inclus

IN (v1, v2, …)          appartient à la liste

LIKE '%ab'              % = toute suite ; _ = un caractère

IS NULL / IS NOT NULL   absence d’information (jamais = NULL)

Les chaînes se quotent avec des apostrophes simples : 'DIESEL'.

Jointures

SELECT V.immat, M.nommarque

FROM Voiture V

INNER JOIN Marque M ON V.marque = M.nommarque   -- correspondances seules



FROM Marque M

LEFT JOIN Voiture V ON …   -- toute la table de gauche, NULL à droite

Sur une LEFT JOIN, compter COUNT(V.colonne) et non COUNT(*) : les NULL ne se comptent pas. Deux tables qui partagent un nom de colonne : toujours préfixer par l’alias.

Agrégation

COUNT(*)              toutes les lignes

COUNT(colonne)        lignes sans NULL

COUNT(DISTINCT col)   valeurs distinctes

MIN(x) / MAX(x)       extrêmes (nombres, textes, dates)

SUM(x) / AVG(x)       somme / moyenne (colonnes numériques)



GROUP BY col          toute colonne du SELECT y figure ou est agrégée

HAVING COUNT(*) > 2   filtre les groupes (jamais WHERE avec un agrégat)

Modification et droits

UPDATE table SET col = val WHERE cond;    -- sans WHERE : toute la table

DELETE FROM table WHERE cond;             -- sans WHERE : la table est vidée

ALTER TABLE t ADD COLUMN c TYPE;          -- évolution de structure

DROP TABLE t;                             -- suppression de la structure



CREATE USER 'login'@'hote' IDENTIFIED BY 'mdp';   -- % = joker d’hôte

GRANT SELECT ON base.table TO 'login'@'hote';

REVOKE SELECT ON base.table FROM 'login'@'hote';

GRANT ALL PRIVILEGES ON base.* TO … WITH GRANT OPTION;   -- ALL seul ; OPTION = délégation

Tester toute modification par le SELECT équivalent avant de l’exécuter.
