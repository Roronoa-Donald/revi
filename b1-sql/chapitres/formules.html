Types de colonnes : MySQL et SQLite

Repères MySQL :

entiers        TINYINT, SMALLINT, MEDIUMINT, INT, BIGINT

décimaux exacts  DECIMAL(p, s)   -- prix avec centimes

mesures         FLOAT, DOUBLE    -- arrondis possibles

chaînes fixes   CHAR(x)          -- complété d’espaces

chaînes variables  VARCHAR(x)    -- stocké tel quel

temps           DATE 'AAAA-MM-JJ', TIME 'HH:MM:SS', DATETIME, TIMESTAMP, YEAR

En MySQL, INT(x) ne change pas la capacité de stockage. Dans SQLite, les noms de types déterminent une affinité : VARCHAR(x) ne limite pas la longueur et DECIMAL ne garantit pas un calcul décimal exact. Le parc utilise TEXT pour les dates et INTEGER pour les prix en francs.

Ordre des clauses

SELECT   colonnes, agrégats

FROM     tables (jointures)

WHERE    filtre les LIGNES

GROUP BY découpe en GROUPES

HAVING   filtre les GROUPES

ORDER BY trie (ASC par défaut, DESC décroissant)

LIMIT    n [OFFSET d]   borne le résultat

Ordre d’écriture : ci-dessus. Ordre logique : FROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY, LIMIT. L’optimiseur peut choisir un autre ordre physique.

Opérateurs de WHERE

=  <>  !=  <  <=  >  >=

BETWEEN a AND b         intervalle inclus

IN (v1, v2, …)          appartient à la liste

LIKE '%ab'              % = toute suite ; _ = un caractère

IS NULL / IS NOT NULL   absence d’information (jamais = NULL)

Les chaînes se quotent avec des apostrophes simples : 'DIESEL'.

Jointures

SELECT V.immat, M.nommarque

FROM Voiture V

INNER JOIN Marque M ON V.codemarque = M.codemarque;



SELECT M.nommarque, V.immat FROM Marque M

LEFT JOIN Voiture V ON V.codemarque = M.codemarque;

Sur une LEFT JOIN, compter COUNT(V.colonne) et non COUNT(*) : les NULL ne se comptent pas. Deux tables qui partagent un nom de colonne : préfixez par l’alias. USING et NATURAL sont d’autres formes ; CROSS JOIN sans condition produit un produit cartésien.

Agrégation

COUNT(*)              toutes les lignes

COUNT(colonne)        lignes sans NULL

COUNT(DISTINCT col)   valeurs distinctes

MIN(x) / MAX(x)       extrêmes (nombres, textes, dates)

SUM(x) / AVG(x)       somme / moyenne (colonnes numériques)



GROUP BY col          privilégier colonnes regroupées et agrégats

HAVING COUNT(*) > 2   filtre les groupes (pas d’agrégat direct du même SELECT dans WHERE)

SQLite peut accepter une colonne non regroupée, choisie sans garantie dans le groupe ; HAVING peut aussi filtrer le groupe global d’une requête agrégée sans GROUP BY.

Modification et droits

UPDATE table SET col = val WHERE cond;    -- sans WHERE : toute la table

DELETE FROM table WHERE cond;             -- sans WHERE : la table est vidée

ALTER TABLE t ADD COLUMN c TYPE;          -- évolution de structure

DROP TABLE t;                             -- suppression de la structure



CREATE USER 'login'@'hote' IDENTIFIED BY 'mdp';   -- % = joker d’hôte

GRANT SELECT ON base.table TO 'login'@'hote';

REVOKE SELECT ON base.table FROM 'login'@'hote';

GRANT ALL PRIVILEGES ON base.* TO … WITH GRANT OPTION;   -- ALL seul ; OPTION = délégation

Les exemples CREATE USER, GRANT et REVOKE ci-dessus concernent MySQL, pas SQLite. Testez toute modification par le SELECT équivalent avant de l’exécuter.
