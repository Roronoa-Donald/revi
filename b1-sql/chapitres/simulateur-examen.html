Examen blanc n°1

Sujet type — requêtes de lecture et analyse, d’après le style des évaluations B1.

Exercice 1/4 — Lecture filtrée

Écrivez la requête qui liste les voitures diesel mises en circulation avant 2015, de la plus ancienne à la plus récente (immatriculation, marque, date).

Corrigé
SELECT immat, marque, datecirc FROM Voiture
WHERE moteur = 'DIESEL' AND datecirc < '2015-01-01'
ORDER BY datecirc;
Résultat : 4 lignes — TG-7854-Z (2000), TG-6733-AB (2002), TG-6733-AC (2012), TG-0020-AL (2014).
Exercice 2/5 — Agrégation

Donnez, par type de moteur, le nombre de voitures et le prix moyen d’achat. Quel moteur compte le plus de voitures ?

Corrigé
SELECT moteur, COUNT(*), AVG(pxachat) FROM Voiture GROUP BY moteur;
ESSENCE domine : 11 voitures (prix moyen ≈ 30,55 M), devant DIESEL (6, ≈ 21,1 M), ELECTRIQUE (4, ≈ 26,55 M) et HYBRIDE (2, 22,5 M).
Exercice 3/5 — Jointure

Listez les voitures japonaises (immatriculation et marque), triées par immatriculation. Combien y en a-t-il ?

Corrigé
SELECT V.immat, V.marque FROM Voiture V
INNER JOIN Marque M ON V.marque = M.nommarque
WHERE M.paysmarque = 'JAPON' ORDER BY V.immat;
10 voitures : les marques TOYOTA (5), SUZUKI (2), MITSUBISHI (1), MAZDA (1), NISSAN (1).
Exercice 4/6 — Analyse complète

Quelles marques ont strictement plus de deux voitures dans le parc ? Donnez leur effectif, du plus grand au plus petit.

Corrigé
SELECT marque, COUNT(*) AS nb FROM Voiture
GROUP BY marque HAVING COUNT(*) > 2
ORDER BY nb DESC;
TOYOTA (5) et MERCEDES BENZ (4). Le filtre porte sur un groupe : HAVING, pas WHERE.

Examen blanc n°2 — variante

Sujet orienté structure, mise à jour et droits.

Exercice 1/5 — Création

Écrivez le CREATE TABLE de la table Marque avec clé primaire, puis l’INSERT de TOYOTA (code TOY, Japon).

Corrigé
CREATE TABLE Marque (
  codemarque CHAR(3) PRIMARY KEY,
  nommarque VARCHAR(20) NOT NULL,
  paysmarque VARCHAR(15) NOT NULL
);
INSERT INTO Marque (codemarque, nommarque, paysmarque) VALUES ('TOY', 'TOYOTA', 'JAPON');
Exercice 2/5 — Modification

Le parc devient 100 % électrique : toutes les voitures de marque TOYOTA passent en moteur ELECTRIQUE. Écrivez l’UPDATE, puis expliquez pourquoi on teste d’abord par SELECT.

Corrigé
UPDATE Voiture SET moteur = 'ELECTRIQUE' WHERE marque = 'TOYOTA';
Le SELECT avec le même WHERE ramène exactement les lignes qui seront modifiées (5 ici) : on voit avant de toucher. Sans WHERE, toute la table passerait en électrique.
Exercice 3/5 — Droits

Créez l’utilisateur gestionnaire se connectant uniquement depuis localhost (mot de passe au choix) et accordez-lui la consultation de toute la base, mais l’écriture seulement sur Voiture.

Corrigé
CREATE USER 'gestionnaire'@'localhost' IDENTIFIED BY '...mdp...';
GRANT SELECT ON parc_auto.* TO 'gestionnaire'@'localhost';
GRANT INSERT, UPDATE, DELETE ON parc_auto.Voiture TO 'gestionnaire'@'localhost';
Principe du moindre privilège : chaque GRANT donne le minimum nécessaire.
Exercice 4/5 — QCM des pièges

Vrai ou faux : (a) COUNT(colonne) compte les NULL ; (b) 'login@hote' se quotte en un bloc ; (c) GRANT ALL, GRANT OPTION est une syntaxe valide ; (d) DELETE FROM Voiture supprime la table.

Corrigé
(a) Faux — COUNT(colonne) ignore les NULL. (b) Faux — login et hôte se quotent séparément : 'login'@'hote'. (c) Faux — ALL s’emploie seul ; la forme est WITH GRANT OPTION. (d) Faux — DELETE vide la table, DROP TABLE la supprime.

QCM final — toutes notions

Que vaut COUNT(immat) sur 34 lignes dont 9 immat NULL ?

COUNT(colonne) ignore les NULL : 34 − 9 = 25.

Comment teste-t-on NULL dans WHERE ?

= NULL ne renvoie jamais vrai.

Une jointure interne retient…

Sans correspondance des deux côtés, la ligne disparaît.

Sur une LEFT JOIN, compter les voitures par marque, c’est…

COUNT(colonne) ignore les NULL des marques sans voiture.

La clause qui filtre les groupes est…

HAVING porte sur le résultat du regroupement, souvent avec un agrégat.

Quel type pour un prix en francs ?

DECIMAL calcule en décimal exact.

Un littéral DATE s’écrit…

Année, mois, jour, quoté.

UPDATE sans WHERE…

La condition limite la modification ; sans elle, toute la table est touchée.

'yeslows'@'%' permet de se connecter…

Le joker % désigne tous les hôtes.

GRANT OPTION sert à…

Le droit de déléguer, jamais inclus dans ALL.
