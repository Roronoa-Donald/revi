Bases de données & SQL — interroger une base

Une base de données ne répond qu’à une seule chose : une question bien écrite. Six chapitres pour apprendre à décrire une base, la remplir, la questionner, relier ses tables, regrouper ses lignes et protéger ses données — chaque chapitre se termine par trois exercices de code corrigés, et chaque requête s’essaie en réel dans le simulateur SQL intégré au cours, sans rien installer.

Ce que tu sauras faire à la fin du cours
  • employer le vocabulaire exact : base, SGBD, modèle relationnel, clés ;
  • choisir les types de données et écrire un CREATE TABLE complet ;
  • interroger une table : SELECT, WHERE, DISTINCT, ORDER BY, LIMIT ;
  • relier les tables : INNER JOIN, LEFT JOIN, alias et colonnes préfixées ;
  • analyser par groupes : COUNT, SUM, AVG, GROUP BY, HAVING ;
  • modifier sous contrôle : UPDATE, DELETE, ALTER, utilisateurs et privilèges.
Comment ce cours s’articule

Chaque chapitre part d’une question concrète sur le parc auto du support (tables Marque et Voiture : 12 marques, 23 voitures), montre la requête et sa lecture, puis se termine par trois exercices de code corrigés et un QCM. La logique des requêtes — filtre, jointure, agrégat, privilège — se programme en Bash dans la page et s’exécute réellement ; les requêtes SQL s’essaient en réel dans le simulateur intégré : rien à installer, la base est déjà chargée.

Le simulateur tourne sous SQLite (WebAssembly) : les requêtes du cours — SELECT, jointures, agrégats — y fonctionnent à l’identique de MySQL. Les commandes d’administration (CREATE USER, GRANT) restent décrites dans le cours et rejouées en Bash, qui sait décider qui a le droit de faire quoi.
