Bases de données & SQL — interroger une base

Une base de données ne répond qu’à une seule chose : une question bien écrite. Six chapitres pour apprendre à décrire une base, la remplir, la questionner, relier ses tables, regrouper ses lignes et protéger ses données — chaque chapitre se termine par trois exercices de code corrigés, et les requêtes compatibles SQLite s’essaient dans le simulateur intégré, sans rien installer.

Ce que vous saurez faire à la fin du cours
  • employer le vocabulaire exact : base, SGBD, modèle relationnel, clés ;
  • choisir les types de données et écrire un CREATE TABLE complet ;
  • interroger une table : SELECT, WHERE, DISTINCT, ORDER BY, LIMIT ;
  • relier les tables : INNER JOIN, LEFT JOIN, alias et colonnes préfixées ;
  • analyser par groupes : COUNT, SUM, AVG, GROUP BY, HAVING ;
  • modifier sous contrôle : UPDATE, DELETE, ALTER, utilisateurs et privilèges.
Comment ce cours s’articule

Chaque chapitre part d’une question concrète sur le parc auto du support (12 marques et 23 voitures, complétées par des équipements fictifs), montre la requête et sa lecture, puis se termine par trois exercices SQL et un QCM. Les exercices utilisent les mêmes définitions de tables, avec des données adaptées ; ceux de création partent d’une base vide. Le simulateur intégré charge également le parc automobile : rien à installer.

Le simulateur utilise SQLite (WebAssembly). Certains comportements diffèrent de MySQL, notamment pour les types et les agrégats. Les commandes d’administration MySQL (CREATE USER, GRANT) sont étudiées, mais ne s’exécutent pas dans ce simulateur SQLite.

Programme du cours

Parcours des 6 chapitres

  1. 1 Bases de données et SGBD Définition d’une base de données, fonctions, types de bases, SGBD et exemples, modèle relationnel. Chapitre
  2. 2 Types de données et création de tables Types numériques, chaînes CHAR et VARCHAR, types temporels, CREATE TABLE, INSERT, clés. Chapitre
  3. 3 Interroger : SELECT, WHERE, tri et restrictions Afficher et sélectionner, filtrer avec WHERE, éliminer les doublons, trier avec ORDER BY, limiter avec LIMIT. Chapitre
  4. 4 Jointures : relier les tables Pourquoi joindre, jointure sans JOIN puis INNER JOIN, LEFT JOIN, alias, lecture du résultat. Chapitre
  5. 5 Agrégation : compter, regrouper, filtrer les groupes COUNT, MIN, MAX, SUM, AVG, GROUP BY, HAVING, ordre complet d’une requête. Chapitre
  6. 6 Modifier les données et gérer les droits UPDATE, DELETE, ALTER, utilisateurs et CREATE USER, privilèges GRANT et REVOKE, GRANT OPTION. Chapitre
