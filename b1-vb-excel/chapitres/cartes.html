Cartes de révision — VBA Excel

Cliquez sur une carte pour révéler la réponse. Objectif : répondre sans hésiter, dans les deux sens. Revenez à J+1, J+3, J+7 pour ancrer durablement la syntaxe VBA.

Module 1 — Introduction à VBA, l’onglet Développeur, l’enregistreur de macros et l’éditeur VBE (Alt+F11)

QuestionRaccourci pour ouvrir l’éditeur VBE ?
RéponseAlt+F11 (et dans VBE : Ctrl+R pour l’Explorateur de projets, F4 pour la fenêtre Propriétés, F2 pour l’Explorateur d’objets).
QuestionDifférence entre Ce classeur et PERSO.XLS ?
RéponseCe classeur limite la macro au fichier courant ; PERSO.XLS (classeur de macros personnelles caché) rend la macro disponible dans tous les classeurs d’Excel.
QuestionRéférence absolue vs référence relative dans l’enregistreur ?
RéponseAbsolue (défaut) : Range("B2").Select cible toujours B2. Relative : ActiveCell.Offset(lig, col) se déplace à partir de la cellule active.
QuestionCode couleur dans l’éditeur VBE ?
RéponseVert = commentaire (commence par ') ; Bleu = mot-clé réservé (Sub, Dim, End Sub) ; Noir = code normal ; Rouge = erreur de syntaxe.
QuestionDifférence entre F5 et F8 dans VBE ?
RéponseF5 exécute toute la macro d’un seul trait ; F8 exécute la macro pas à pas (ligne par ligne) pour le débogage.

Module 2 — Le Modèle Objet Excel (Application → Workbooks → Worksheets → Range / Cells)

QuestionHiérarchie des 4 grands niveaux du Modèle Objet Excel ?
RéponseApplication → Workbooks (classeurs) → Worksheets (feuilles de calcul) → Range / Cells (cellules).
QuestionQuelle cellule désigne Cells(4, 3) ?
RéponseC4 : ligne 4 et colonne 3 (C). Dans Cells(ligne, colonne), la ligne vient toujours en premier.
QuestionDifférence entre ThisWorkbook et ActiveWorkbook ?
RéponseThisWorkbook est le classeur qui contient le code VBA exécuté ; ActiveWorkbook est le classeur actuellement affiché au premier plan.
QuestionPartant de B3, quelle cellule désigne Range("B3").Offset(2, -1) ?
RéponseA5 : +2 lignes fait passer de la ligne 3 à la ligne 5 ; -1 colonne fait reculer de la colonne B à la colonne A.
QuestionComment désigner toutes les cellules d’une feuille ou ajuster la colonne B ?
RéponseCells (sans argument) désigne toutes les cellules de la feuille ; Columns("B") ou Columns(2) désigne la colonne B entière.

Module 3 — Propriétés (Value, Formula, Interior.Color, Font.Bold), Méthodes (Select, ClearContents, Copy, AutoFit) et Événements (Workbook_Open, Worksheet_Change)

QuestionDifférence entre Clear, ClearContents et ClearFormats ?
RéponseClearContents efface uniquement le contenu (garde le style) ; ClearFormats efface uniquement le style (garde les valeurs) ; Clear efface tout.
QuestionComment mettre A1 en gras sur fond jaune en VBA ?
RéponseRange("A1").Font.Bold = True et Range("A1").Interior.ColorIndex = 6 (ou .Interior.Color = RGB(255, 255, 0)).
QuestionOù placer Workbook_Open() et Worksheet_Change() ?
RéponseWorkbook_Open() se place dans le module ThisWorkbook ; Worksheet_Change(ByVal Target As Range) se place dans le module de la feuille concernée (ex. Feuil1).
QuestionQue représente Target dans Worksheet_Change(ByVal Target As Range) ?
RéponseTarget est l’objet Range représentant la cellule (ou la plage) qui vient d’être modifiée par l’utilisateur.
QuestionÀ quoi sert Application.ScreenUpdating = False ?
RéponseÀ désactiver temporairement le rafraîchissement de l’écran pendant qu’une macro s’exécute, ce qui supprime le scintillement et accélère fortement le traitement.

Module 4 — Variables, Types de données (Integer, Long, Double, String, Boolean, Variant, Option Explicit), Opérateurs et Fonctions (Sub vs Function)

QuestionÀ quoi sert Option Explicit en tête de module ?
RéponseÀ rendre obligatoire la déclaration de toutes les variables avec Dim, ce qui détecte immédiatement les fautes de frappe à la compilation.
QuestionPourquoi préférer Long à Integer pour les lignes d’une feuille Excel ?
RéponseInteger plafonne à 32 767 (erreur Overflow au-delà), tandis que Long va jusqu’à 2 147 483 647 et couvre les 1 048 576 lignes d’Excel.
QuestionQuel est le piège de Dim x, y As Integer ?
RéponseSeul y est déclaré en Integer ; x, n’ayant pas de clause As Type, est créé en Variant. Il faut écrire Dim x As Integer, y As Integer.
QuestionComment une Function renvoie-t-elle sa valeur en VBA ?
RéponseEn affectant le résultat au nom même de la fonction avant End Function (ex. CalculTTC = ht * 1.18).
QuestionQuel mot-clé est obligatoire pour affecter un objet Range à une variable ?
RéponseLe mot-clé Set : Set maPlage = Range("A1:B10").

Module 5 — Structures de contrôle (If...Then...ElseIf...End If, Select Case, boucles For...Next, For Each...In, Do While/Until...Loop)

QuestionComment écrire un intervalle et une comparaison dans un Select Case ?
RéponseIntervalle avec To (ex. Case 10 To 20) ; comparaison avec Is (ex. Case Is >= 50) ; défaut avec Case Else.
QuestionPourquoi parcourir avec Step -1 pour supprimer des lignes ?
RéponseParce que Rows(i).Delete fait remonter la ligne i+1 au rang i : en descendant (For i = N To 2 Step -1), on ne saute aucune ligne.
QuestionDifférence entre Do While et Do Until ?
RéponseDo While répète TANT QUE la condition est vraie ; Do Until répète JUSQU’À CE QUE la condition devienne vraie.
QuestionComment parcourir toutes les cellules de A1:A20 sans indice ?
RéponseAvec Dim c As Range puis For Each c In Range("A1:A20") ... Next c.
QuestionComment sortir immédiatement d’une boucle For ou d’une procédure Sub ?
RéponseExit For quitte la boucle For ; Exit Do quitte la boucle Do ; Exit Sub quitte immédiatement la procédure.

Module 6 — Boîtes de dialogue (MsgBox, InputBox), Gestion des erreurs (On Error GoTo) et Formulaires (UserForm)

QuestionQuand met-on des parenthèses autour des arguments de MsgBox ?
RéponseUniquement lorsqu’on récupère la valeur du bouton cliqué dans une variable (rep = MsgBox("Continuer ?", vbYesNo, "Titre")) ou avec Call.
QuestionQuels sont les codes d’erreur VBA les plus fréquents (9, 11, 13, 1004) ?
Réponse9 = Indice en dehors de la plage (feuille introuvable) ; 11 = Division par zéro ; 13 = Incompatibilité de type ; 1004 = Erreur définie par l’application ou par l’objet.
QuestionPourquoi placer Exit Sub juste avant l’étiquette d’un On Error GoTo ?
RéponsePour que la macro s’arrête normalement à la fin du code principal sans exécuter par erreur le bloc de gestion d’erreur.
QuestionOù et comment remplir une ComboBox à l’ouverture d’un UserForm ?
RéponseDans l’événement Private Sub UserForm_Initialize() à l’aide de la méthode ComboBox1.AddItem "Valeur" (ou via la propriété RowSource).
QuestionDifférence entre Me.Hide et Unload Me ?
RéponseMe.Hide masque le formulaire en conservant les valeurs de ses contrôles en mémoire ; Unload Me le ferme et libère toute sa mémoire.
