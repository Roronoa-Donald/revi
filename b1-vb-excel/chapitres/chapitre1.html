Chapitre 1 — Introduction à VBA, l’onglet Développeur, l’enregistreur de macros et l’éditeur VBE (Alt+F11)

Mise en situation

Le support de cours du Dr TCHAZINO Tchamiè (support1.pdf, 47 pages) s’ouvre sur un constat quotidien : dans un service comptable ou financier, répéter chaque matin la même mise en forme de tableau, les mêmes tris et les mêmes calculs sur des dizaines de feuilles fait perdre du temps et multiplie les erreurs humaines. Une macro Excel — programme écrit en langage VBA (Visual Basic for Applications) — permet d’enregistrer ou de coder une fois pour toutes cette séquence d’actions pour l’exécuter d’un simple clic ou d’un raccourci clavier.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. définir une macro et distinguer les deux modes de création : enregistrement automatique et écriture dans VBE ;
  2. activer l’onglet Développeur, configurer la sécurité des macros et choisir l’emplacement d’enregistrement (Ce classeur vs PERSO.XLS / PERSONAL.XLSB) ;
  3. différencier l’enregistrement en références absolues (Range("B2").Select) et en références relatives (ActiveCell.Offset) ;
  4. maîtriser l’environnement VBE (Alt+F11) : Explorateur de projets (Ctrl+R), fenêtre Propriétés (F4), fenêtre de code, exécution (F5) et pas à pas (F8) ;
  5. lire et modifier une procédure Sub...End Sub générée par l’enregistreur et chaîner des macros avec Call.

1. Qu’est-ce qu’une macro VBA et comment activer l’onglet Développeur ?

Une macro est une suite d’instructions regroupées dans une procédure en langage VBA (Visual Basic for Applications) qui s’exécute automatiquement à la demande de l’utilisateur pour accomplir une tâche répétitive dans Excel (mise en forme d’un rapport, import de données, contrôle de saisie, génération de factures). On crée une macro de deux manières complémentaires : soit par l’enregistreur automatique de macros, qui traduit en direct chaque geste (clic, saisie, formatage) en code VBA, soit en écrivant directement les instructions dans l’éditeur Visual Basic (VBE) lorsque l’on a besoin de variables, de boucles, de conditions ou de boîtes de dialogue.

Par défaut, les commandes de programmation sont masquées dans le ruban d’Excel. Il faut d’abord afficher l’onglet Développeur (via Fichier → Options → Personnaliser le ruban → cocher Développeur, ou dans les versions antérieures via les options d’affichage du ruban). Un classeur contenant du code VBA doit impérativement être sauvegardé au format Classeur Excel prenant en charge les macros (.xlsm ou .xls) : enregistrer en .xlsx standard supprime toutes les macros du fichier.

Règle d’or de sécurité et d’enregistrement

Dans Développeur → Sécurité des macros, le niveau recommandé est Désactiver toutes les macros avec notification : Excel bloque l’exécution automatique à l’ouverture d’un fichier inconnu mais affiche un bandeau permettant d’activer le contenu si la source est sûre.

2. L’enregistreur de macros : nom, raccourci, PERSO.XLS et références absolues vs relatives

Pour enregistrer une macro (Développeur → Enregistrer une macro ou Outils → Macro → Nouvelle macro), Excel ouvre une boîte de dialogue demandant quatre paramètres :

  • Nom de la macro : commence obligatoirement par une lettre, sans espace ni caractère spécial (utiliser le souligné _ ou la casse CamelCase, par ex. Format_Entete ou ChangerStyleReference).
  • Touche de raccourci : une combinaison Ctrl + lettre (ou Ctrl + Maj + lettre pour éviter d’écraser un raccourci natif comme Ctrl+C ou Ctrl+Z).
  • Enregistrer la macro dans : trois destinations possibles :
    • Ce classeur : la macro n’est disponible que lorsque ce fichier précis est ouvert ;
    • Nouveau classeur : la macro est créée dans un classeur vierge ;
    • Classeur de macros personnelles (PERSO.XLS / PERSONAL.XLSB) : classeur caché chargé automatiquement au démarrage d’Excel, rendant la macro accessible depuis tous les classeurs du poste.
  • Description : commentaire libre documentant l’auteur, la date et le rôle de la macro.

Dès que l’on clique sur OK, chaque action est traduite en VBA jusqu’au clic sur Arrêter l’enregistrement. Le support insiste sur une distinction fondamentale lors de la sélection des cellules pendant l’enregistrement :

  • Enregistrement en références absolues (par défaut) : si vous cliquez sur la cellule B2, l’enregistreur écrit Range("B2").Select. À chaque exécution future, la macro retournera invariablement sur B2, quelle que soit la cellule sélectionnée au départ.
  • Enregistrement en références relatives (bouton « Utiliser les références relatives » activé) : Excel enregistre le déplacement par rapport à la cellule active au moyen de la propriété Offset. Descendre de 2 lignes et aller 1 colonne à droite génère ActiveCell.Offset(2, 1).Range("A1").Select. La macro peut alors être rejouée à partir de n’importe quelle ligne du tableau.
Pièges fréquents avec l’enregistreur de macros
  • Oublier de cliquer sur Arrêter l’enregistrement : tous vos clics d’exploration suivants continuent d’alourdir la macro.
  • Enregistrer un formatage de ligne en références absolues alors qu’on souhaite l’appliquer sur la ligne courante sélectionnée par l’utilisateur.
  • Remplacer par mégarde Ctrl+C (copier) ou Ctrl+S (enregistrer) comme raccourci clavier de la macro.

3. L’éditeur Visual Basic (VBE — Alt+F11) et l’anatomie d’une procédure Sub

Le raccourci universel Alt+F11 bascule instantanément entre la feuille Excel et l’éditeur Visual Basic (VBE — Visual Basic Editor). L’interface VBE s’articule autour de trois fenêtres essentielles :

  • L’Explorateur de projets (Ctrl+R) : affiche l’arborescence de chaque classeur ouvert (VBAProject) avec ses dossiers : Microsoft Excel Objects (les feuilles Feuil1, Feuil2 et l’objet classeur ThisWorkbook), le dossier Modules (Module1, Module2… où l’enregistreur place le code standard, ou créés via Insertion → Module) et le dossier Feuilles (contenant les formulaires UserForm).
  • La fenêtre Propriétés (F4) : affiche les attributs de l’élément sélectionné dans l’Explorateur (par exemple la propriété (Name) permettant de renommer Module1 en Mod_Facturation).
  • La fenêtre de code (double-clic sur un module ou F7) : zone d’édition dotée d’une coloration syntaxique immédiate — les commentaires (précédés d’une apostrophe ') s’affichent en vert, les mots-clés réservés VBA (Sub, End Sub, Dim, With) en bleu, le code courant en noir et les lignes comportant une erreur de syntaxe en rouge.

Toute macro enregistrée prend la forme d’une procédure délimitée par Sub NomMacro() et End Sub. Par exemple, le premier TP du support bascule le style de référence d’Excel en notation L1C1 :

Sub ChangerStyleReference()
' Macro enregistrée par Dr TCHAZINO Tchamiè
' Bascule la grille Excel en style L1C1 (Ligne / Colonne)
    Application.ReferenceStyle = xlR1C1
End Sub

Sub RetablirStyleA1()
    Application.ReferenceStyle = xlA1
    Call AfficherConfirmation
End Sub

Depuis VBE, la touche F5 (ou le bouton lecture vert) exécute la procédure entière d’un trait, tandis que la touche F8 exécute la macro pas à pas détaillé (ligne par ligne, surlignée en jaune), ce qui permet d’observer en temps réel l’effet de chaque instruction sur la feuille Excel. Enfin, l’instruction Call AutreMacro (ou simplement le nom AutreMacro) permet d’appeler une procédure depuis une autre.

Exercice 2 — Références absolues vs relatives et navigation dans VBE

Objectif : Distinguer le code généré en références absolues et relatives et associer chaque tâche VBE à son raccourci clavier.

Énoncé. Yao a enregistré deux macros sous Excel, puis souhaite les inspecter dans l’éditeur Visual Basic (VBE). Dans la première macro, le bouton « Utiliser les références relatives » était désactivé (mode par défaut) et Yao a cliqué sur B2. Dans la seconde, ce bouton était activé et Yao est descendu de 3 lignes et allé 2 colonnes à droite à partir de la cellule active.

  2. Par défaut (bouton « Utiliser les références relatives » non enfoncé), l’enregistreur travaille-t-il en références absolues ou relatives ?
  3. En références relatives, quelle propriété de ActiveCell traduit le décalage de lignes et de colonnes (ex. ActiveCell.______(3, 2)) ?
  4. Dans VBE, quelle touche de fonction lance l’exécution pas à pas détaillé (ligne par ligne) ?
  5. Dans VBE, quelle touche de fonction exécute la macro entière d’un seul trait ?
Cas d’exemple
Inspection d'un module dans VBE :

- Ouvrir la fenêtre Propriétés : F4
- Exécuter pas à pas : F8

5. QCM — niveau examen

Quel raccourci clavier permet d’ouvrir directement l’éditeur Visual Basic (VBE) depuis Excel ?

Alt+F11 bascule entre Excel et l’éditeur VBE. Alt+F8 ouvre la boîte de dialogue de lancement des macros, Ctrl+R affiche l’Explorateur de projets dans VBE et F4 ouvre la fenêtre Propriétés.

Dans quel emplacement faut-il enregistrer une macro pour qu’elle soit disponible dans tous les classeurs Excel ouverts sur l’ordinateur ?

Le classeur de macros personnelles (PERSO.XLS ou PERSONAL.XLSB) est un classeur masqué chargé automatiquement au démarrage d’Excel, ce qui rend ses macros accessibles depuis n’importe quel classeur.

Lors de l’enregistrement d’une macro en références relatives, quelle instruction VBA traduit un déplacement de 2 lignes vers le bas et 1 colonne vers la droite ?

En références relatives, l’enregistreur utilise ActiveCell.Offset(décalage_lignes, décalage_colonnes) : Offset(2, 1) descend de 2 lignes (+2) et décale d’1 colonne à droite (+1).

Dans la fenêtre de code de l’éditeur VBE, par quel caractère commence un commentaire (affiché en vert et ignoré à l’exécution) ?

En VBA, toute ligne ou fin de ligne précédée d’une apostrophe simple (') ou du mot-clé historique Rem est un commentaire affiché en vert par l’éditeur VBE.

Quelle touche de fonction permet d’exécuter une macro instruction par instruction (pas à pas détaillé) dans VBE pour observer son comportement ?

F8 exécute la procédure ligne par ligne en surlignant en jaune l’instruction courante. F5 exécute toute la macro d’un coup, F2 ouvre l’Explorateur d’objets et F4 ouvre la fenêtre Propriétés.

Où l’enregistreur de macros stocke-t-il le code VBA des macros enregistrées dans un classeur ?

L’enregistreur crée automatiquement un dossier Modules dans le projet VBA du classeur et y place la procédure Sub...End Sub à l’intérieur d’un module standard (Module1).

Parmi les noms suivants, lequel est un nom de macro VBA syntaxiquement valide ?

Un nom de macro VBA doit commencer par une lettre et ne comporter ni espace ni trait d’union (interprété comme le signe moins) ; le caractère souligné (_) est autorisé.

Que fait l’instruction VBA Application.ReferenceStyle = xlR1C1 étudiée dans le support de cours ?

Application.ReferenceStyle = xlR1C1 active l’option « Style de référence L1C1 » d’Excel (et xlA1 rétablit les lettres de colonnes A, B, C).

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Enregistrer un classeur contenant des macros au format .xlsx au lieu de .xlsm : tout le code VBA est perdu à la fermeture.
  • Laisser l’enregistreur en références absolues quand on veut une macro applicable à n’importe quelle ligne sélectionnée.
  • Mettre des espaces ou commencer par un chiffre dans le nom d’une procédure Sub.
  • Confondre F5 (exécution complète immédiate) et F8 (exécution pas à pas ligne par ligne).

7. Méthodologie de résolution

Méthode — réussir sa première macro en 4 étapes
  1. Définir si les déplacements doivent viser des cellules fixes (références absolues) ou partir de la cellule active (références relatives).
  2. Lancer l’enregistreur avec un nom explicite sans espace, choisir Ce classeur ou PERSO.XLS, réaliser les gestes sans clic superflu puis arrêter l’enregistrement.
  3. Ouvrir VBE avec Alt+F11, localiser la procédure dans Modules → Module1 (Ctrl+R) et commenter le code avec une apostrophe '.
  4. Tester la macro en mode pas à pas avec F8 en observant côte à côte la fenêtre VBE et la feuille Excel.

8. Révision active

Résumé essentiel
  • Une macro est une procédure VBA (Sub...End Sub) qui automatise une suite d’actions dans Excel.
  • L’enregistreur traduit les gestes en code VBA dans un module standard (Module1) ; PERSO.XLS rend une macro disponible dans tous les classeurs.
  • En références absolues, VBA cible Range("B2") ; en références relatives, il utilise ActiveCell.Offset(lig, col).
  • VBE (Alt+F11) réunit l’Explorateur de projets (Ctrl+R), la fenêtre Propriétés (F4) et la fenêtre de code (F5 exécuter, F8 pas à pas).

Checklist de maîtrise

  • Je sais activer l’onglet Développeur et enregistrer un classeur en .xlsm.
  • Je sais choisir entre Ce classeur et PERSO.XLS lors de l’enregistrement.
  • Je sais expliquer la différence entre Range("B2").Select et ActiveCell.Offset(2, 1).
  • Je sais ouvrir VBE (Alt+F11), lire un Sub...End Sub et déboguer avec F8.

Les 8 notions à connaître absolument

  1. VBA (Visual Basic for Applications) : langage de programmation intégré aux applications Microsoft Office.
  2. Enregistreur de macros : outil traduisant les actions de l’utilisateur à l’écran en instructions VBA.
  3. PERSO.XLS / PERSONAL.XLSB : classeur de macros personnelles masqué, chargé à chaque ouverture d’Excel.
  4. Références relatives : mode d’enregistrement générant des déplacements ActiveCell.Offset(lignes, colonnes).
  5. VBE (Alt+F11) : environnement de développement intégré (Visual Basic Editor).
  6. Explorateur de projets (Ctrl+R) : arborescence des objets Excel, modules standards et UserForms.
  7. Procédure Sub...End Sub : bloc d’instructions exécutables formant une macro.
  8. Pas à pas détaillé (F8) : exécution ligne par ligne d’une macro pour le débogage.
