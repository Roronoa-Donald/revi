Chapitre 3 — Propriétés (Value, Formula, Interior.Color, Font.Bold), Méthodes (Select, ClearContents, Copy, AutoFit) et Événements (Workbook_Open, Worksheet_Change)

Mise en situation

Maintenant que nous savons désigner précisément un classeur, une feuille ou une plage de cellules, que pouvons-nous faire dessus ? En VBA, on agit sur un objet de trois façons : lire ou modifier ses caractéristiques (ses Propriétés), lui ordonner d’exécuter une action (ses Méthodes), ou programmer une réaction automatique lorsqu’un événement survient sur le classeur ou la feuille (les Événements).

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. distinguer syntaxiquement et conceptuellement une Propriété (attribut affecté avec =) d’une Méthode (action exécutée sur l’objet) ;
  2. manipuler les propriétés clés de Range : Value, Formula, Count, Row, Column, Font (Bold, Size, Color) et Interior (Color, ColorIndex) ;
  3. utiliser les méthodes essentielles : Select, Activate, Clear vs ClearContents vs ClearFormats, Copy, Delete, Insert, AutoFit ;
  4. factoriser le code avec With...End With et appeler les fonctions Excel via Application.WorksheetFunction ;
  5. écrire des procédures événementielles Workbook_Open (dans ThisWorkbook) et Worksheet_Change(ByVal Target As Range) (dans une feuille).

1. Propriétés : lire et modifier les caractéristiques d’un objet (Value, Formula, Font, Interior)

Une propriété est un attribut (une caractéristique) d’un objet que l’on peut lire ou modifier à l’aide de l’opérateur d’affectation = (syntaxe : Objet.Propriete = Valeur). Certaines propriétés sont en lecture/écriture (comme Value ou Name), tandis que d’autres sont en lecture seule (comme Count, Row, Column ou Address).

  • Value : contient la valeur de la cellule (propriété par défaut de Range). Ex. : Range("B2").Value = 15000 ou montant = Range("B2").Value.
  • Formula et FormulaLocal : Formula injecte une formule en syntaxe anglaise avec séparateur virgule (ex. Range("C2").Formula = "=SUM(A2:B2)"), tandis que FormulaLocal utilise les noms de fonctions de la langue d’Excel installée (ex. "=SOMME(A2:B2)").
  • Mise en forme de la police (sous-objet Font) : Range("A1").Font.Bold = True (gras), .Font.Italic = True (italique), .Font.Size = 14 (taille), .Font.Name = "Calibri", .Font.Color = RGB(255, 0, 0) (texte rouge).
  • Couleur de fond de cellule (sous-objet Interior) : Range("A1:D1").Interior.Color = RGB(220, 240, 255) ou via la palette de 56 couleurs d’Excel Range("A1").Interior.ColorIndex = 6 (jaune). Pour retirer la couleur de fond : .Interior.ColorIndex = xlNone.
  • Propriétés de feuille et d’application : Worksheets(1).Name = "Bilan_2026" renomme l’onglet ; Worksheets("Calculs").Visible = False masque la feuille ; Application.ScreenUpdating = False fige le rafraîchissement de l’écran pendant l’exécution d’une macro lourde (ce qui l’accélère considérablement et évite le scintillement).
Écrire directement dans .Value sans passer par .Select

L’enregistreur de macros génère deux lignes : Range("B2").Select puis ActiveCell.FormulaR1C1 = "100". En vrai code VBA professionnel, on écrit directement en une seule ligne Range("B2").Value = 100 sans déplacer le curseur de sélection : le code est 10 fois plus rapide et plus lisible.

2. Méthodes (Select, ClearContents, Copy, AutoFit), bloc With...End With et WorksheetFunction

Une méthode est une action que l’on ordonne à un objet d’accomplir (syntaxe : Objet.Methode [Arguments], sans signe = devant la méthode) :

  • Effacer une plage (la distinction cruciale d’examen) :
    • Range("A2:D20").ClearContents : efface uniquement le contenu (valeurs et formules) tout en conservant la mise en forme (bordures, couleurs, formats numériques) ;
    • Range("A2:D20").ClearFormats : réinitialise uniquement la mise en forme en gardant les valeurs ;
    • Range("A2:D20").Clear : efface absolument tout (contenu, formats et commentaires).
  • Copier, supprimer, ajuster : Range("A1:B10").Copy Destination:=Range("E1") copie la plage vers E1 en une seule instruction ; Rows(5).Delete supprime la ligne 5 ; Columns("A:F").AutoFit ajuste automatiquement la largeur des colonnes A à F à leur contenu.
  • Gérer les classeurs et feuilles : Workbooks.Add (nouveau classeur), Workbooks.Open("C:\Rapports\Mai.xlsx"), ThisWorkbook.Save, Worksheets.Add (nouvelle feuille).

Lorsqu’on modifie plusieurs propriétés ou appelle plusieurs méthodes sur le même objet, le bloc With ... End With évite de répéter le nom de l’objet à chaque ligne. De plus, l’objet Application.WorksheetFunction permet d’utiliser directement les fonctions de calcul d’Excel (Sum, Average, Max, Min, VLookup, CountIf) en VBA :

With Worksheets("Facture").Range("A1:E1")
    .Font.Bold = True
    .Font.Size = 12
    .Interior.Color = RGB(33, 115, 70)
    .Columns.AutoFit
End With

' Calculer la somme de B2:B50 via WorksheetFunction :
Range("B51").Value = Application.WorksheetFunction.Sum(Range("B2:B50"))

3. Les procédures événementielles : Workbook_Open et Worksheet_Change

Jusqu’ici, nos macros étaient lancées manuellement (bouton, raccourci clavier ou menu). Une procédure événementielle s’exécute automatiquement en réponse à un événement déclenché par l’utilisateur ou par Excel. Contrairement aux macros classiques, elle ne se place jamais dans un module standard (Module1), mais dans le module de l’objet surveillé :

  • Dans le module ThisWorkbook (événements du classeur) :
    • Private Sub Workbook_Open() : s’exécute automatiquement dès l’ouverture du classeur (idéal pour afficher un message d’accueil, activer la feuille du menu principal ou initialiser des paramètres).
    • Private Sub Workbook_BeforeClose(Cancel As Boolean) : s’exécute juste avant la fermeture du classeur (mettre Cancel = True annule la fermeture si une vérification échoue).
  • Dans le module d’une feuille Feuil1 (événements de feuille) :
    • Private Sub Worksheet_Change(ByVal Target As Range) : se déclenche dès que l’utilisateur modifie la valeur d’une cellule de cette feuille. Le paramètre automatique Target désigne exactement la cellule (ou la plage) qui vient d’être modifiée !
    • Private Sub Worksheet_SelectionChange(ByVal Target As Range) : se déclenche à chaque fois que l’utilisateur clique sur une autre cellule (Target est la nouvelle sélection).
    • Private Sub Worksheet_Activate() : se déclenche lorsque l’utilisateur clique sur l’onglet de la feuille pour l’afficher.
' Dans le module de la feuille Feuil1 (et non dans Module1) :
Private Sub Worksheet_Change(ByVal Target As Range)
    ' Si la cellule modifiée se trouve dans la colonne B (colonne 2) :
    If Target.Column = 2 And Target.Row >= 2 Then
        Target.Offset(0, 1).Value = Date  ' Inscrit la date de saisie en colonne C
    End If
End Sub
Pièges classiques sur les méthodes et les événements
  • Utiliser .Clear au lieu de .ClearContents pour vider un modèle de facture : toutes les bordures et couleurs du tableau sont détruites !
  • Écrire Sub Workbook_Open() dans Module1 : Excel ne l’exécutera pas automatiquement à l’ouverture (elle doit résider dans ThisWorkbook).
  • Oublier le point initial (.Font.Bold = True) à l’intérieur d’un bloc With Range("A1") ... End With.

Exercice 1 — Distinguer Propriétés et Méthodes sur un modèle de facture

Étude de cas Formative Niveau 1 — Acquisition

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Qualifier chaque membre VBA comme propriété ou méthode et choisir entre Clear, ClearContents et ClearFormats.

Énoncé. Essi prépare un bouton « Nouvelle facture » pour vider la plage de saisie B8:E25 tout en conservant les bordures, les couleurs et le format monétaire du tableau. Elle hésite entre plusieurs instructions VBA :

Instruction VBAEffet sur la feuille
Range("B4").Value = "Facture n° 104"Écrit le titre dans B4
Range("B8:E25").ClearContentsVide les valeurs sans toucher au format
Range("B8:E25").ClearEfface tout (valeurs, bordures et couleurs)
Range("B4").Font.Bold = TrueMet la police de B4 en gras
Columns("B:E").AutoFitAjuste la largeur des colonnes B à E
  1. Dans Range("B4").Value = "Facture n° 104", Value est-il une propriete ou une methode ?
  2. Dans Columns("B:E").AutoFit, AutoFit est-il une propriete ou une methode ?
  3. Quelle méthode Essi doit-elle choisir pour vider les valeurs de B8:E25 tout en conservant ses bordures et couleurs ?
  4. Quel sous-objet de Range permet de modifier la couleur de fond (remplissage) d’une cellule : Font ou Interior ?
  5. Quelle propriété booléenne de Application met-on à False en début de macro pour figer le rafraîchissement d’écran et accélérer l’exécution ?
Cas d’exemple
Mise en forme d'une cellule :
- Range("A1").Font.Size = 14 -> propriété (affectation avec =)
- Range("A1:B5").Copy -> méthode (action de copie)
Trois indices, rédigés en mots
  1. Ce à quoi on affecte une valeur avec le signe = est une propriété ; ce qui déclenche une action sans signe = est une méthode.
  2. Pour effacer seulement le contenu (contents en anglais) sans détruire le cadre du tableau, évitez Clear tout court.
  3. Étapes : classer Value comme propriete et AutoFit comme methode ; retenir ClearContents ; choisir Interior pour la couleur de fond ; citer ScreenUpdating (Application.ScreenUpdating = False).

Exercice 2 — Factoriser avec With...End With et calculer avec WorksheetFunction

Étude de cas Formative Niveau 2 — Application

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Compléter un bloc With...End With et utiliser Application.WorksheetFunction pour appeler les fonctions Excel en VBA.

Énoncé. Pour éviter de répéter cinq fois Worksheets("Bilan").Range("A1:F1"), Mawuli utilise un bloc de factorisation et calcule ensuite la somme de la plage D2:D100 :

With Worksheets("Bilan").Range("A1:F1")
    .Font.Bold = True
    .Font.Size = 12
    .Interior.ColorIndex = 6
End With

Range("D101").Value = Application.WorksheetFunction.Sum(Range("D2:D100"))
  1. Par quel mot-clé s’ouvre un bloc qui factorise les accès à un même objet ?
  2. Par quels deux mots se ferme obligatoirement ce bloc ?
  3. Par quel signe de ponctuation commence chacune des lignes à l’intérieur du bloc (devant Font et Interior) ? (écrivez le nom du signe, ex. point, ou le caractère .)
  4. Quel sous-objet de Application permet d’appeler les fonctions de feuille de calcul d’Excel (comme Sum, Average, VLookup) depuis VBA ?
  5. Dans WorksheetFunction.Sum(...), les noms des fonctions Excel s’écrivent-ils en anglais ou en francais ?
Cas d’exemple
Calcul de la moyenne de B2:B30 en VBA :
moy = Application.WorksheetFunction.Average(Range("B2:B30"))
Trois indices, rédigés en mots
  1. Le bloc de factorisation porte le nom anglais signifiant « Avec ».
  2. À l’intérieur du bloc, chaque propriété est rattachée à l’objet de l’en-tête par son point d’accès.
  3. Étapes : noter With à l’ouverture et End With à la fermeture ; indiquer le point (.) devant les propriétés internes ; relever WorksheetFunction ; préciser anglais (Sum, Average, VLookup).

Exercice 3 — Procédures événementielles : Workbook_Open et Worksheet_Change

Étude de cas Formative Niveau 3 — Raisonnement

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Placer chaque procédure événementielle dans le bon module VBE et exploiter le paramètre Target.

Énoncé. Le directeur financier souhaite deux automatisations sans bouton :

  • Automatisation 1 : dès l’ouverture du classeur, afficher automatiquement la feuille "Accueil" via l’événement Workbook_Open().
  • Automatisation 2 : sur la feuille Feuil1, dès qu’un comptable modifie un montant dans la colonne B (colonne 2), inscrire automatiquement la date du jour dans la colonne C située juste à droite, grâce au code suivant :
Private Sub Worksheet_Change(ByVal Target As Range)
    If Target.Column = 2 Then
        Target.Offset(0, 1).Value = Date
    End If
End Sub
  1. Dans quel module de l’Explorateur de projets faut-il écrire Workbook_Open() pour qu’elle se déclenche à l’ouverture du classeur ?
  2. Dans quel module faut-il écrire Worksheet_Change : dans Module1 ou dans le module de la feuille (Feuil1) ?
  3. Comment s’appelle le paramètre de type Range qui désigne la cellule qui vient d’être modifiée dans Worksheet_Change ?
  4. Quelle propriété de Target renvoie le numéro de la colonne modifiée (testée à 2 dans le code) ?
  5. Si le comptable modifie la cellule B10, dans quelle cellule (en notation A1) l’instruction Target.Offset(0, 1).Value = Date écrit-elle la date ?
Cas d’exemple
L'utilisateur clique sur la cellule D4 de Feuil2 :
- Événement déclenché : Worksheet_SelectionChange dans Feuil2
- Target.Address -> "$D$4"
- Target.Row -> 4, Target.Column -> 4
Trois indices, rédigés en mots
  1. Un événement qui concerne le classeur entier vit dans l’objet classeur ; un événement qui concerne une feuille vit dans l’objet feuille.
  2. Dans la signature Private Sub Worksheet_Change(ByVal Target As Range), lisez le nom de l’argument avant As Range.
  3. Étapes : placer Workbook_Open dans ThisWorkbook ; placer Worksheet_Change dans Feuil1 ; nommer le paramètre Target ; relever la propriété Column ; décaler B10 de Offset(0, 1) vers C10.

5. QCM — niveau examen

Quelle méthode de l’objet Range permet d’effacer uniquement les valeurs et formules d’une plage tout en conservant ses bordures et couleurs ?

ClearContents vide uniquement le contenu des cellules en préservant toute la mise en forme. Clear efface tout (contenu + formats), ClearFormats n’efface que le style et Delete supprime physiquement les cellules en décalant la feuille.

Parmi les écritures suivantes appliquées à Range("A1"), laquelle met correctement le texte en gras et illustre la modification d’une propriété ?

Bold est une propriété booléenne du sous-objet Font de Range : on lui affecte la valeur True avec le signe = (Range("A1").Font.Bold = True).

Dans quel module de l’Explorateur de projets faut-il placer la procédure Private Sub Workbook_Open() pour qu’elle s’exécute automatiquement à l’ouverture du fichier ?

Les événements liés au classeur entier (Workbook_Open, Workbook_BeforeClose, Workbook_BeforeSave) doivent obligatoirement être écrits dans le module de l’objet ThisWorkbook.

Dans la procédure événementielle Private Sub Worksheet_Change(ByVal Target As Range), que représente le paramètre Target ?

Excel transmet automatiquement dans l’argument Target (de type Range) la référence exacte de la cellule ou de la plage dont la valeur vient de changer.

Quelle propriété permet de modifier la couleur de remplissage (fond) de la cellule A1 en VBA ?

Le sous-objet Interior gère le remplissage intérieur de la cellule via ses propriétés Color (avec RGB) ou ColorIndex (palette de 1 à 56). Font.Color modifie uniquement la couleur des caractères.

Quel est l’intérêt principal d’un bloc With Range("A1:F1") ... End With ?

With...End With factorise la référence à l’objet : à l’intérieur du bloc, chaque ligne commençant par un point (.Font.Bold = True, .Interior.ColorIndex = 6) s’applique directement à cet objet.

Comment appeler la fonction SOMME d’Excel sur la plage B2:B20 depuis du code VBA pour stocker le résultat dans une variable ?

L’objet Application.WorksheetFunction expose les fonctions de feuille de calcul d’Excel (en anglais, comme Sum, Average, Max, VLookup) pour les évaluer directement en VBA.

Quelle méthode ajuste automatiquement la largeur des colonnes A à D à la longueur de leur contenu ?

La méthode AutoFit appliquée à un objet Columns (ou Rows) ajuste automatiquement la largeur des colonnes (ou la hauteur des lignes) au contenu le plus long.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Confondre Clear (efface contenu ET mise en forme) avec ClearContents (efface uniquement les valeurs/formules).
  • Placer une procédure événementielle (Workbook_Open ou Worksheet_Change) dans un module standard Module1 où elle restera inactive.
  • Oublier le point devant les propriétés (.Font.Bold) à l’intérieur d’un bloc With...End With.
  • Abuser de .Select et .Activate alors qu’on peut modifier directement Range("...").Value.

7. Méthodologie de résolution

Méthode — agir proprement sur une plage Excel en VBA
  1. Se demander s’il s’agit de modifier un attribut (Propriété avec =) ou de déclencher une action (Méthode sans =).
  2. Regrouper les modifications portant sur un même objet dans un bloc With ... End With en commençant chaque ligne par un point.
  3. Préférer ClearContents à Clear pour réinitialiser les zones de saisie d’un modèle sans détruire ses bordures.
  4. Pour automatiser une réaction sur saisie ou ouverture, placer le code dans Feuil1 (Worksheet_Change) ou ThisWorkbook (Workbook_Open).

8. Révision active

Résumé essentiel
  • Une propriété (Value, Formula, Font.Bold, Interior.Color, Name, Row, Column) se lit ou se modifie avec =.
  • Une méthode (Select, ClearContents, Clear, Copy, Delete, AutoFit, Open, Save) exécute une action sur l’objet.
  • With...End With factorise les accès à un même objet ; Application.WorksheetFunction appelle les fonctions natives d’Excel.
  • Workbook_Open (dans ThisWorkbook) et Worksheet_Change(ByVal Target As Range) (dans une feuille) réagissent automatiquement aux événements.

Checklist de maîtrise

  • Je sais distinguer une propriété d’une méthode dans n’importe quelle ligne de code VBA.
  • Je sais choisir entre Clear, ClearContents et ClearFormats selon le besoin.
  • Je sais écrire un bloc With...End With pour formater un en-tête de tableau.
  • Je sais utiliser Target dans Worksheet_Change(ByVal Target As Range).

Les 8 notions à connaître absolument

  1. Propriété : caractéristique d’un objet lue ou modifiée avec = (Value, Formula, Name).
  2. Méthode : action exécutée par un objet (Select, Copy, ClearContents, AutoFit).
  3. ClearContents vs Clear : effacer uniquement les valeurs/formules vs effacer valeurs et mise en forme.
  4. Font & Interior : sous-objets de Range gérant la police et la couleur de fond.
  5. With ... End With : structure appliquant une série d’instructions au même objet sans le répéter.
  6. Application.WorksheetFunction : passerelle permettant d’appeler les fonctions Excel (Sum, VLookup) en VBA.
  7. Workbook_Open() : procédure événementielle de ThisWorkbook exécutée à l’ouverture du fichier.
  8. Worksheet_Change(ByVal Target As Range) : événement de feuille déclenché à chaque modification de cellule (Target).
