Chapitre 4 — Variables, Types de données (Integer, Long, Double, String, Boolean, Variant, Option Explicit), Opérateurs et Fonctions (Sub vs Function)

Mise en situation

Lire et écrire directement dans les cellules de la feuille à chaque étape d’un calcul ralentit les macros et rend le code illisible. Le support du Dr TCHAZINO Tchamiè introduit alors les variables — zones nommées en mémoire vive (RAM) dotées d’un type précis — ainsi que les fonctions personnalisées (Function) capables d’enrichir Excel avec vos propres formules métier.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. déclarer des variables typées avec Dim ... As Type et comprendre pourquoi Option Explicit est indispensable ;
  2. choisir le bon type de données (Integer vs Long pour les lignes Excel, Double/Currency, String, Boolean, Date, Object avec Set, Variant) ;
  3. distinguer la portée locale (Dim dans une procédure), module (Private/Dim en tête de module), publique (Public) et les constantes (Const) ;
  4. utiliser les opérateurs arithmétiques (dont \ et Mod), de concaténation (&), de comparaison (<>) et logiques (And, Or, Not, Xor) ;
  5. différencier une procédure Sub d’une fonction Function et écrire une fonction personnalisable utilisable dans une cellule Excel.

1. Déclaration des variables (Dim), règles de nommage et Option Explicit

Une variable est un emplacement de la mémoire vive désigné par un identifiant (son nom) qui conserve une valeur modifiable au cours de l’exécution de la macro. En VBA, un nom de variable doit commencer par une lettre, compter au maximum 255 caractères, ne contenir ni espace, ni point, ni opérateur (le caractère souligné _ est permis) et ne pas être un mot réservé (Sub, Dim, For, Then…). VBA ne distingue pas les majuscules des minuscules dans les noms.

On déclare une variable avec le mot-clé Dim suivi de son type : Dim compteur As Long. Si l’on n’impose rien, VBA autorise l’utilisation de variables non déclarées en leur attribuant automatiquement le type universel Variant. C’est un piège redoutable : la moindre faute de frappe dans un nom de variable (par ex. tauxTva puis tauxTav) crée silencieusement une seconde variable vide valant 0 ! Pour l’interdire, on place toujours en première ligne du module l’directive :

Option Explicit

Avec Option Explicit (activable automatiquement dans VBE via Outils → Options → onglet Éditeur → cocher Déclaration des variables obligatoire), toute variable non déclarée déclenche immédiatement une erreur de compilation signalée avant même l’exécution.

Le piège de la déclaration multiple sur une seule ligne

En VBA, écrire Dim a, b As Integer ne déclare que b en Integer : a (sans As Type explicite) devient un Variant ! Il faut toujours préciser le type de chaque variable : Dim a As Integer, b As Integer.

La portée (visibilité) d’une variable dépend de l’endroit où elle est déclarée : déclarée avec Dim à l’intérieur d’une procédure Sub ou Function, elle est locale (créée à l’entrée de la procédure et détruite à sa sortie) ; déclarée avec Dim ou Private tout en haut d’un module (avant la première procédure), elle est partagée par toutes les procédures de ce module ; déclarée avec Public en tête d’un module standard, elle est accessible depuis tous les modules du projet. Enfin, une valeur fixe se déclare avec Const (ex. Const TAUX_TVA As Double = 0.18).

3. Opérateurs (&, Mod, logiques) et distinction Procédure Sub vs Fonction Function

En VBA, les nombres décimaux s’écrivent toujours avec un point (.) comme séparateur décimal (0.18), jamais avec une virgule. Les opérateurs se répartissent en quatre familles :

  • Arithmétiques : +, -, *, / (division décimale), \ (division entière : 7 \ 2 vaut 3), Mod (reste de la division entière : 7 Mod 2 vaut 1) et ^ (puissance).
  • Concaténation de texte : l’esperluette & assemble deux chaînes ou du texte et un nombre (ex. "Client " & code & " : " & montant & " FCFA"). Toujours entourer & d’espaces et l’utiliser de préférence à +.
  • Comparaison : =, <> (différent de), <, >, <=, >=.
  • Logiques : And (ET), Or (OU), Not (NON), Xor (OU exclusif).

Le support établit enfin la distinction fondamentale entre une procédure Sub et une fonction Function :

  • Une procédure Sub réalise des actions (modifier des cellules, colorier, afficher un message) et ne renvoie pas de valeur.
  • Une fonction Function reçoit des arguments entre parenthèses, effectue un calcul et renvoie une valeur typée. En VBA, pour renvoyer le résultat, on l’affecte au nom même de la fonction (NomFonction = resultat) avant End Function.
Option Explicit

' Fonction personnalisée (UDF) utilisable en VBA ET comme formule dans Excel :
Function MontantTTC(prixHT As Double, tauxTVA As Double) As Double
    MontantTTC = prixHT * (1 + tauxTVA)
End Function

Sub TesterCalcul()
    Dim ht As Double, ttc As Double
    ht = Range("B2").Value
    ttc = MontantTTC(ht, 0.18)  ' En VBA : séparateur virgule (,) et point décimal (.)
    Range("C2").Value = ttc
End Sub
Utiliser sa Function directement dans une cellule Excel

Toute Function publique placée dans un module standard (Module1) apparaît dans la catégorie Fonctions personnalisées d’Excel. Dans une feuille Excel francophone, on l’appelle avec le point-virgule et la virgule décimale : =MontantTTC(B2; 0,18), tandis que dans le code VBA on écrit MontantTTC(ht, 0.18).

Exercice 1 — Typage des variables et Option Explicit au service comptable

Étude de cas Formative Niveau 1 — Acquisition

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Choisir les bons types VBA (Long, Double, String, Boolean, Variant, Object avec Set) et appliquer Option Explicit.

Énoncé. Akouvi révise une macro qui plante avec l’erreur « Dépassement de capacité (Overflow) » lorsqu’elle parcourt un grand fichier de 50 000 lignes clients. En tête du module, elle examine les déclarations suivantes :

Option Explicit

Sub AnalyserClients()
    Dim numLigne As Long
    Dim ancienCompteur As Integer
    Dim codeClient, nomClient As String
    Dim estActif As Boolean
    Dim plageClients As Range
    Set plageClients = Range("A2:D50000")
End Sub
  1. Quelle directive de deux mots placée en première ligne oblige à déclarer toutes les variables du module ?
  2. Pourquoi ancienCompteur As Integer plante-t-il sur 50 000 lignes : quelle est la valeur maximale d’un Integer en VBA ?
  3. Quel type entier sur 4 octets (utilisé pour numLigne) faut-il toujours privilégier pour les numéros de lignes Excel ?
  4. Dans la ligne Dim codeClient, nomClient As String, quel est le type réel attribué par VBA à codeClient ?
  5. Quel mot-clé de 3 lettres est obligatoire au début de la ligne qui affecte la référence d’objet à plageClients ?
Cas d’exemple
Déclaration correcte de deux entiers longs et d'une feuille :
Dim i As Long, j As Long
Dim f As Worksheet
Set f = ThisWorkbook.Worksheets("Ventes")
Trois indices, rédigés en mots
  1. La directive figure tout en haut du code ; un Integer signé sur 2 octets va de -32 768 à +32 767.
  2. En VBA, toute variable qui n’est pas immédiatement suivie de sa propre clause As Type reçoit le type générique par défaut.
  3. Étapes : relever Option Explicit ; indiquer 32767 (32 767) comme plafond d’Integer ; citer Long pour les lignes Excel ; répondre Variant pour codeClient ; noter le mot-clé Set pour l’objet Range.

Exercice 2 — Opérateurs VBA (&, \, Mod) et portée des variables

Étude de cas Formative Niveau 2 — Application

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Évaluer les opérateurs VBA de division entière, de reste (Mod) et de concaténation (&) ainsi que la portée des déclarations.

Énoncé. Un entrepôt conditionne ses articles par cartons de 10 unités. Pour 47 articles en stock, la macro exécute les calculs suivants :

Public Const TAILLE_CARTON As Long = 10

Sub CalculerColisage()
    Dim stock As Long, cartons As Long, reste As Long
    Dim message As String
    stock = 47
    cartons = stock \ TAILLE_CARTON
    reste = stock Mod TAILLE_CARTON
    message = "Cartons : " & cartons & " / Reste : " & reste
End Sub
  1. Que vaut la variable cartons après la division entière 47 \ 10 ?
  2. Que vaut la variable reste après l’opération modulo 47 Mod 10 ?
  3. Quel symbole d’opérateur est utilisé à la dernière ligne pour concaténer le texte et les nombres dans message ?
  4. La variable stock, déclarée avec Dim à l’intérieur de Sub CalculerColisage(), a-t-elle une portée locale ou publique ?
  5. Quel mot-clé placé devant TAILLE_CARTON garantit que la valeur 10 ne pourra jamais être modifiée par le programme ?
Cas d’exemple
Conversion de 135 minutes en heures et minutes :
- heures = 135 \ 60 -> 2
- minutes = 135 Mod 60 -> 15
- texte = heures & "h" & minutes -> "2h15"
Trois indices, rédigés en mots
  1. L’antislash \ donne le quotient entier (combien de fois 10 rentre dans 47) et Mod donne le reste de cette division.
  2. Une variable déclarée à l’intérieur d’un Sub n’existe que pendant l’exécution de ce Sub.
  3. Étapes : calculer 47 \ 10 = 4 ; calculer 47 Mod 10 = 7 ; relever l’esperluette & pour la concaténation ; qualifier la portée de locale ; noter le mot-clé Const.

Exercice 3 — Créer et appeler une fonction personnalisée Function (UDF)

Étude de cas Formative Niveau 3 — Raisonnement

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Comprendre la syntaxe d’une Function VBA, son mécanisme de retour et les différences de séparateurs entre VBA et Excel.

Énoncé. Le responsable commercial veut disposer dans Excel d’une fonction personnalisée PrixNet(montantHT, tauxRemise) utilisable comme une formule native. Vous écrivez dans Module1 :

Option Explicit

Function PrixNet(montantHT As Double, tauxRemise As Double) As Double
    PrixNet = montantHT * (1 - tauxRemise)
End Function
  1. Quel mot-clé déclare une procédure qui calcule et renvoie une valeur (par opposition à Sub) ?
  2. À quelle cible affecte-t-on le résultat montantHT * (1 - tauxRemise) pour que la fonction le renvoie ? (écrivez l’identifiant placé à gauche du signe =)
  3. Que renvoie l’appel VBA PrixNet(20000, 0.1) ?
  4. Dans le code VBA, quel caractère sépare le chiffre des unités des décimales dans 0.1 : le point ou la virgule ?
  5. Dans une feuille de calcul Excel en français, quel caractère sépare les deux arguments lorsqu’on tape la formule =PrixNet(A2 ; 0,1) : le point-virgule ou la virgule ?
Cas d’exemple
Function DoubleValeur(x As Double) As Double
    DoubleValeur = x * 2
End Function
- En VBA : y = DoubleValeur(12.5) -> 25
- Dans une cellule Excel : =DoubleValeur(A1)
Trois indices, rédigés en mots
  1. En VBA, il n’y a pas de mot-clé return : regardez ce qui se trouve à gauche du signe = à l’intérieur de la fonction.
  2. Une remise de 0.1 correspond à 10 % de 20 000 FCFA (soit 2 000 FCFA déduits).
  3. Étapes : noter Function ; indiquer PrixNet (le nom de la fonction) ; calculer 20000 * 0.9 = 18000 ; répondre point pour le décimal en VBA ; répondre point-virgule (;) pour séparer les arguments dans Excel français.

5. QCM — niveau examen

Quelle instruction placée tout en haut d’un module VBA oblige le programmeur à déclarer explicitement toutes ses variables avec Dim ?

Option Explicit impose la déclaration préalable de chaque variable et bloque à la compilation toute variable non déclarée ou mal orthographiée.

Quel type de données VBA prend automatiquement une variable déclarée sans précision de type (par exemple Dim x) ?

En l’absence de clause As Type, VBA attribue par défaut le type générique Variant (au moins 16 octets en mémoire).

Pourquoi recommande-t-on le type Long plutôt que Integer pour une variable stockant un numéro de ligne Excel ?

Le type Integer (2 octets) plafonne à 32 767, alors qu’une feuille Excel comporte jusqu’à 1 048 576 lignes. Le type Long (4 octets, jusqu’à plus de 2 milliards) évite l’erreur d’exécution 6 (Dépassement de capacité).

Comment affecte-t-on une référence d’objet (comme Range("A1:B10")) à une variable objet déclarée par Dim maPlage As Range ?

En VBA, toute affectation d’une référence d’objet (Range, Worksheet, Workbook, Object) exige obligatoirement le mot-clé Set devant le nom de la variable.

Comment une fonction personnalisée Function CalculPrime(ca As Double) As Double renvoie-t-elle son résultat en VBA ?

VBA n’utilise pas return pour renvoyer la valeur d’une Function : on affecte la valeur de retour directement à l’identifiant de la fonction (CalculPrime = ca * 0.05).

Quel opérateur est recommandé en VBA pour concaténer (assembler) deux chaînes de caractères ou une chaîne et un nombre ?

L’opérateur & (entouré d’espaces) convertit automatiquement les nombres en texte et concatène sans risque d’ambiguïté avec l’addition arithmétique +.

Dans la déclaration VBA Dim montantHT, montantTTC As Double, quel est le type réel de la variable montantHT ?

En VBA, chaque variable doit avoir son propre As Type. Dans Dim montantHT, montantTTC As Double, seule montantTTC est de type Double ; montantHT est de type Variant.

Quel mot-clé permet de déclarer en tête d’un module standard une variable globale accessible depuis tous les modules du projet VBA ?

Le mot-clé Public placé en tête d’un module standard rend la variable visible dans l’ensemble des modules du projet VBA.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Oublier Option Explicit et perdre une heure sur une variable mal orthographiée valant 0.
  • Écrire Dim i, j As Long en croyant que i est de type Long (i est en réalité Variant !).
  • Oublier le mot-clé Set lors de l’affectation d’une variable objet (Set f = Worksheets("Ventes")).
  • Écrire un nombre décimal avec une virgule (0,18) dans l’éditeur VBE au lieu du point (0.18).

7. Méthodologie de résolution

Méthode — choisir ses variables et structurer ses fonctions
  1. Activer systématiquement Option Explicit en première ligne de chaque module.
  2. Déclarer les compteurs de lignes en Long, les montants en Double ou Currency, les textes en String et les plages en Range (avec Set).
  3. Utiliser une Function dès qu’un calcul doit renvoyer une valeur (ou être appelé comme formule dans une cellule Excel) et une Sub pour les actions sur l’interface.
  4. Tester la Function dans la feuille Excel avec le séparateur point-virgule (;).

8. Révision active

Résumé essentiel
  • Option Explicit oblige à déclarer toutes les variables (Dim nom As Type) et élimine les bugs de faute de frappe.
  • Types clés : Long (lignes Excel), Integer (≤ 32 767), Double/Currency (décimaux), String (texte), Boolean (True/False), Date, Object (affecté avec Set), Variant (défaut).
  • L’opérateur & concatène les chaînes ; Mod donne le reste entier ; le point . est le séparateur décimal en code VBA.
  • Une Sub exécute des actions sans retour ; une Function renvoie un résultat en l’affectant à son propre nom (NomFonction = resultat).

Checklist de maîtrise

  • Je sais pourquoi Option Explicit et le type Long (au lieu de Integer) protègent mes macros.
  • Je sais déclarer correctement plusieurs variables typées et utiliser Set pour les objets.
  • Je sais écrire une Function VBA et l’appeler aussi bien dans un Sub que dans une cellule Excel.
  • Je maîtrise la différence de portée entre Dim (procédure), Private (module) et Public (projet).

Les 8 notions à connaître absolument

  1. Option Explicit : directive imposant la déclaration préalable de toutes les variables.
  2. Dim ... As Type : instruction de déclaration d’une variable typée en mémoire.
  3. Long vs Integer : entier 4 octets (±2 milliards, adapté aux lignes Excel) vs 2 octets (±32 767).
  4. Double & Currency : nombres décimaux en virgule flottante double précision et en virgule fixe monétaire.
  5. Variant : type générique par défaut (16 octets min.) attribué aux variables non typées.
  6. Set : mot-clé obligatoire pour affecter une référence à une variable objet (Range, Worksheet).
  7. Opérateur & : opérateur de concaténation de chaînes de caractères en VBA.
  8. Function (UDF) : procédure renvoyant une valeur par affectation à son nom, utilisable dans les formules Excel.
