Chapitre 5 — Structures de contrôle (If...Then...ElseIf...End If, Select Case, boucles For...Next, For Each...In, Do While/Until...Loop)

Mise en situation

Une macro enregistrée est purement linéaire : elle répète toujours les mêmes lignes du début à la fin. Pour traiter un tableau de 500 factures où seules les factures impayées doivent être relancées, ou pour s’arrêter automatiquement dès qu’une cellule vide est rencontrée, il faut doter notre programme des structures de contrôle du chapitre 5 du support : les conditions et les boucles.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. écrire des tests conditionnels complets avec If...Then...ElseIf...Else...End If en ordonnant correctement les seuils ;
  2. remplacer une cascade de tests sur une même expression par un bloc Select Case (valeurs multiples, plage To, comparaison Is >=, Case Else) ;
  3. parcourir une plage de lignes avec For i = début To fin [Step pas]...Next i et utiliser Step -1 pour supprimer des lignes sans décalage ;
  4. parcourir une collection d’objets (cellules d’un Range ou feuilles d’un classeur) avec For Each élément In collection...Next ;
  5. maîtriser les boucles Do While...Loop et Do Until...Loop (test en entrée vs test en sortie) et éviter les boucles infinies.

1. Les structures conditionnelles : If...Then...ElseIf...End If et Select Case

Le test If ... Then ... ElseIf ... Else ... End If permet d’exécuter des blocs d’instructions différents selon qu’une condition booléenne est vraie (True) ou fausse (False). Dès qu’une branche est vérifiée, VBA exécute ses instructions puis saute directement à End If : comme avec la fonction SI d’Excel, il faut donc toujours tester les paliers du plus strict au plus large.

If montant >= 50000 Then
    tauxRemise = 0.15
ElseIf montant >= 10000 Then
    tauxRemise = 0.08
Else
    tauxRemise = 0
End If

Lorsqu’on évalue une même variable par rapport à plusieurs valeurs, intervalles ou seuils, la structure Select Case est beaucoup plus lisible qu’une suite de ElseIf. Le support détaille ses trois syntaxes de cas : liste de valeurs séparées par des virgules (Case 1, 3, 5), intervalle borné avec le mot-clé To (Case 10 To 14), comparaison ouverte avec le mot-clé Is (Case Is >= 15), et cas par défaut Case Else :

Select Case note
    Case Is >= 16
        mention = "Très Bien"
    Case 14 To 15.99
        mention = "Bien"
    Case 12 To 13.99
        mention = "Assez Bien"
    Case 10 To 11.99
        mention = "Passable"
    Case Else
        mention = "Ajourné"
End Select

2. Les boucles à compteur (For...Next, Step) et de collection (For Each...In)

Lorsque le nombre d’itérations est connu, on utilise la boucle For compteur = début To fin [Step pas] ... Next compteur. Par défaut, le pas d’incrémentation (Step) vaut +1. On peut préciser un pas de 2 (Step 2 pour traiter une ligne sur deux) ou un pas négatif (Step -1) pour parcourir un tableau de bas en haut :

Dim i As Long
' Parcourir les lignes 2 à 20 pour calculer le montant TTC en colonne C :
For i = 2 To 20
    Cells(i, 3).Value = Cells(i, 2).Value * 1.18
Next i
Pourquoi supprimer des lignes exige toujours For i = fin To début Step -1

Si vous supprimez la ligne i (Rows(i).Delete) dans une boucle croissante For i = 2 To 20, l’ancienne ligne i + 1 remonte immédiatement au numéro i, tandis que le compteur passe à i + 1 : la ligne qui vient de remonter est sautée et jamais contrôlée ! Pour supprimer des lignes sous condition, on parcourt toujours du bas vers le haut : For i = 20 To 2 Step -1.

Pour parcourir tous les objets d’une collection (toutes les cellules d’une plage ou toutes les feuilles d’un classeur) sans gérer de numéro d’indice, VBA offre la boucle For Each élément In collection ... Next élément :

Dim cel As Range
For Each cel In Range("B2:B50")
    If cel.Value < 0 Then
        cel.Interior.Color = RGB(255, 200, 200) ' Surligne les négatifs en rouge clair
    End If
Next cel

3. Les boucles conditionnelles Do While / Do Until et les sorties anticipées (Exit)

Lorsque le nombre de lignes du tableau est inconnu à l’avance (par exemple : lire une colonne jusqu’à la première cellule vide), on utilise une boucle conditionnelle Do ... Loop, qui se décline selon deux critères :

  • While (tant que) vs Until (jusqu’à ce que) : Do While Cells(i, 1).Value <> "" continue tant que la cellule n’est pas vide ; Do Until Cells(i, 1).Value = "" continue jusqu’à ce que la cellule soit vide. Ces deux écritures sont logiquement équivalentes.
  • Condition en tête (Do While...Loop) vs condition en pied (Do...Loop While) : placée après Do, la condition est vérifiée avant la première itération (si la première cellule est déjà vide, le corps s’exécute 0 fois). Placée après Loop, la condition est vérifiée à la fin : le corps de la boucle s’exécute donc au moins une fois.
Dim lig As Long
lig = 2
Do While Cells(lig, 1).Value <> ""
    Cells(lig, 4).Value = "Vérifié"
    lig = lig + 1  ' INDISPENSABLE pour éviter une boucle infinie !
Loop

Enfin, VBA permet de quitter prématurément une boucle ou une procédure dès qu’un objectif est atteint (par exemple, dès que le client recherché a été trouvé) grâce aux instructions de sortie anticipée : Exit For (sort de la boucle For ou For Each), Exit Do (sort de la boucle Do...Loop), Exit Sub et Exit Function (quitte immédiatement la procédure ou la fonction).

Exercice 1 — Barème de remises avec If...Then...ElseIf et Select Case

Étude de cas Formative Niveau 1 — Acquisition

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Évaluer l’exécution d’un bloc If...ElseIf...Else et maîtriser les mots-clés To, Is et Case Else d’un Select Case.

Énoncé. Une coopérative agricole applique une prime de fidélité selon le tonnage annuel livré par chaque producteur, codée en VBA de deux façons équivalentes :

' Version 1 : If...Then...ElseIf
If tonnage >= 50 Then
    prime = 100000
ElseIf tonnage >= 20 Then
    prime = 40000
Else
    prime = 10000
End If

' Version 2 : Select Case
Select Case tonnage
    Case Is >= 50 : prime = 100000
    Case 20 To 49.99 : prime = 40000
    Case Else : prime = 10000
End Select
  1. Quelle est la valeur de prime pour un producteur qui a livré tonnage = 35 ?
  2. Quelle est la valeur de prime pour un producteur qui a livré exactement tonnage = 50 ?
  3. Dans Select Case, quel mot-clé de 2 lettres précède l’opérateur de comparaison dans Case ___ >= 50 ?
  4. Quel mot-clé de 2 lettres exprime l’intervalle fermé dans Case 20 ___ 49.99 ?
  5. Quelle clause du Select Case récupère tous les cas qui n’ont correspondu à aucun des cas précédents ?
Cas d’exemple
Test de tonnage = 12 :
- tonnage >= 50 (faux)
- tonnage >= 20 (faux)
- Branche Else / Case Else -> prime = 10000
Trois indices, rédigés en mots
  1. Suivez les tests dans l’ordre : pour 35, le premier test (>= 50) est faux, mais le second (>= 20) est vrai.
  2. Pour 50, le signe >= signifie « supérieur ou égal » : la borne 50 est donc incluse dans le premier palier.
  3. Étapes : trouver 40000 pour tonnage = 35 ; trouver 100000 pour tonnage = 50 ; relever le mot-clé Is devant >= ; relever le mot-clé To entre 20 et 49.99 ; noter Case Else pour le cas par défaut.

Exercice 2 — Boucles For...Next, Step -1 et For Each sur une feuille de stock

Étude de cas Formative Niveau 2 — Application

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Tracer l’exécution d’une boucle For...Next, appliquer Step -1 pour la suppression de lignes et utiliser For Each.

Énoncé. Le gestionnaire de stock souhaite d’abord compter les articles en rupture sur la plage C2:C6, puis supprimer les lignes correspondantes :

Ligne ExcelArticle (Colonne B)Quantité en stock (Colonne C)
Ligne 2Clavier USB15

  2. Quelle est la somme totale des quantités en stock sur les lignes 2 à 6 ?
  3. Pour supprimer les lignes où le stock vaut 0 avec For i = 6 To 2 Step -1, quelle est la première valeur prise par le compteur i ?
  4. Dans cette boucle de suppression à rebours, quel est le pas précisé après le mot-clé Step ?

Exercice 3 — Parcours conditionnel Do While...Loop et arrêt sur cellule vide

Étude de cas Formative Niveau 3 — Raisonnement

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Suivre l’évolution des variables dans une boucle Do While...Loop et utiliser Exit Do.

Énoncé. Une macro parcourt la colonne A à partir de la ligne 2 jusqu’à rencontrer une cellule vide :

Dim lig As Long, cumul As Long
lig = 2
cumul = 0
Do While Cells(lig, 1).Value <> ""
    cumul = cumul + Cells(lig, 1).Value
    lig = lig + 1
Loop

Les valeurs de la colonne A sont : A2 = 100, A3 = 250, A4 = 150, et A5 est vide ("").

  1. Combien de fois le corps de la boucle Do While est-il exécuté avant de s’arrêter ?
  2. Quelle est la valeur finale de la variable cumul à la sortie de la boucle ?
  3. Quelle est la valeur finale de la variable lig au moment où la condition Cells(lig, 1).Value <> "" devient fausse ?
  4. Si l’on remplaçait Do While Cells(lig, 1).Value <> "" par Do _____ Cells(lig, 1).Value = "", quel mot-clé (signifiant « jusqu’à ce que ») faudrait-il écrire ?
  5. Quelle instruction de deux mots permettrait de quitter immédiatement la boucle Do si cumul dépassait un plafond d’alerte ?
Cas d’exemple
Si A2 est déjà vide au départ (lig = 2) :
- Do While Cells(2, 1).Value <> "" est faux dès le premier test
- Nombre de passages : 0, cumul = 0, lig reste à 2.
Trois indices, rédigés en mots
  1. Suivez lig tour par tour : lig=2 (A2=100, cumul=100, lig passe à 3) ; lig=3 (A3=250, cumul=350, lig passe à 4) ; lig=4 (A4=150, cumul=500, lig passe à 5).
  2. Au test suivant, lig vaut 5 et A5 est vide : la condition <> "" est fausse et on sort de la boucle.
  3. Étapes : compter 3 tours (lignes 2, 3, 4) ; additionner 100 + 250 + 150 = 500 ; noter lig = 5 à la sortie ; écrire Until pour « jusqu’à ce que » ; citer Exit Do pour la sortie anticipée.

5. QCM — niveau examen

Dans un bloc If...Then...ElseIf...Else multi-lignes en VBA, quelle instruction est obligatoire pour fermer la structure ?

Tout bloc If...Then écrit sur plusieurs lignes doit impérativement se terminer par End If (seul le If condensé sur une seule ligne ne prend pas de End If).

Dans une structure Select Case, quelle syntaxe permet de tester si la variable est supérieure ou égale à 100 ?

Avec un opérateur de comparaison (<, >, <=, >=, <>) dans un Select Case, VBA utilise le mot-clé Is : Case Is >= 100 (et le mot-clé To pour un intervalle fermé comme Case 50 To 99).

Pourquoi utilise-t-on For i = 50 To 2 Step -1 plutôt que For i = 2 To 50 lorsqu’une macro supprime des lignes avec Rows(i).Delete ?

Quand la ligne i est supprimée, l’ancienne ligne i+1 prend immédiatement le numéro i. Si le compteur monte à i+1, cette ligne n’est jamais examinée. En descendant avec Step -1, le décalage n’affecte que les lignes déjà traitées.

Quelle boucle est la plus adaptée pour parcourir directement chaque feuille de calcul d’un classeur sans gérer de compteur numérique ?

La boucle For Each élément In collection ... Next parcourt automatiquement tous les objets d’une collection (ici chaque objet Worksheet f de ThisWorkbook.Worksheets).

Quelle est la différence entre Do While condition ... Loop et Do ... Loop While condition ?

Lorsque le test est placé en tête (Do While condition), le corps ne s’exécute jamais si la condition est fausse d’emblée. Placé en pied (Loop While condition), le corps est exécuté une première fois avant le test.

Que se passe-t-il dans une boucle Do While Cells(i, 1).Value <> "" ... Loop si le programmeur oublie l’instruction i = i + 1 ?

Contrairement à For...Next qui incrémente son compteur automatiquement, Do While...Loop exige que le programmeur fasse avancer la variable de parcours (i = i + 1), faute de quoi la condition reste éternellement vraie sur la même cellule.

Quelle instruction permet de quitter immédiatement une boucle For...Next dès que la valeur recherchée a été trouvée, sans attendre la fin du compteur ?

En VBA, Exit For interrompt immédiatement la boucle For (ou For Each) en cours et poursuit l’exécution après le Next (de même, Exit Do quitte une boucle Do...Loop).

Combien de fois le corps de la boucle For k = 2 To 10 Step 2 ... Next k est-il exécuté ?

Avec un départ à 2, une fin à 10 incluse et un pas Step 2, la variable k prend successivement les 5 valeurs : 2, 4, 6, 8 et 10.

6. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Oublier d’incrémenter le compteur (i = i + 1) dans une boucle Do While / Do Until, provoquant une boucle infinie.
  • Supprimer des lignes dans une boucle croissante For i = 2 To N au lieu de décroître avec Step -1.
  • Oublier le mot-clé Is devant un opérateur de comparaison dans un Select Case (écrire Case Is >= 10 et non Case >= 10).
  • Confondre Do While (continue tant que c’est vrai) et Do Until (continue jusqu’à ce que cela devienne vrai).

7. Méthodologie de résolution

Méthode — choisir la bonne boucle pour chaque tâche Excel
  1. Nombre de lignes connu et fixe (ex. lignes 2 à 100) : utiliser For i = 2 To 100 ... Next i.
  2. Suppression de lignes sous condition : utiliser impérativement For i = derniereLigne To 2 Step -1.
  3. Traitement de chaque cellule d’une plage ou de chaque feuille d’un classeur : utiliser For Each obj In collection.
  4. Parcours jusqu’à la première cellule vide (longueur inconnue) : utiliser Do While Cells(i, 1).Value <> "" avec i = i + 1.

8. Révision active

Résumé essentiel
  • If...Then...ElseIf...Else...End If et Select Case (To, Is, Case Else) dirigent le flux selon des conditions.
  • For i = début To fin [Step pas]...Next i répète à compteur ; Step -1 parcourt à l’envers (indispensable pour supprimer des lignes).
  • For Each élément In collection...Next parcourt chaque objet d’un Range ou de Worksheets.
  • Do While / Do Until...Loop boucle selon une condition (en entrée ou en sortie) ; Exit For / Exit Do / Exit Sub permettent de sortir immédiatement.

Checklist de maîtrise

  • Je sais écrire un Select Case utilisant des valeurs multiples, To, Is >= et Case Else.
  • Je sais expliquer pourquoi la suppression de lignes requiert Step -1.
  • Je sais parcourir une plage avec For Each cel In Range("...").
  • Je sais écrire une boucle Do While qui s’arrête à la première cellule vide sans boucler à l’infini.

Les 8 notions à connaître absolument

  1. If ... Then ... ElseIf ... Else ... End If : structure conditionnelle à branchements multiples.
  2. Select Case ... End Select : aiguillage multi-cas utilisant To (intervalle), Is (comparaison) et Case Else.
  3. For ... To ... [Step pas] ... Next : boucle à compteur automatique (croissant ou décroissant avec Step -1).
  4. For Each ... In ... Next : boucle parcourant tous les objets d’une collection (cellules, feuilles, classeurs).
  5. Do While ... Loop : boucle répétée tant que la condition est vraie.
  6. Do Until ... Loop : boucle répétée jusqu’à ce que la condition devienne vraie.
  7. Exit For / Exit Do : sortie anticipée immédiate de la boucle en cours.
  8. Boucle infinie : erreur logique où la condition d’arrêt d’un Do...Loop n’est jamais atteinte (oubli de i = i + 1).
