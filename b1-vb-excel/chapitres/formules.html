Mémo VBA sous Excel

Toutes les syntaxes, propriétés, méthodes et structures du support du Dr TCHAZINO Tchamiè résumées sur une seule page de référence.

1. Environnement VBE & Enregistreur de macros

Alt+F11  : Basculer entre Excel et l'editeur VBE

Ctrl+R   : Explorateur de projets (Modules, Feuil1, ThisWorkbook, UserForm)

F4       : Fenetre Proprietes         F2 : Explorateur d'objets

F5       : Executer la macro          F8 : Pas a pas detaille (ligne par ligne)

PERSO.XLS / PERSONAL.XLSB : Classeur de macros personnelles (tous classeurs)

Absolue  : Range("B2").Select         Relative : ActiveCell.Offset(lig, col)

Style    : Application.ReferenceStyle = xlR1C1  (ou xlA1)

2. Le Modèle Objet Excel

Hierarchie : Application -> Workbooks -> Worksheets -> Range / Cells

Classeurs  : ThisWorkbook (contient la macro) != ActiveWorkbook (au 1er plan)

Feuilles   : Worksheets("Ventes") ou Worksheets(1) (1er onglet a gauche)

             Sheets inclut aussi les feuilles graphiques (Charts)

Cellules   : Range("A1:B10")   Range("A1:A5,C1:C5") (union avec virgule)

             Cells(ligne, colonne)  -> Cells(4, 2) = B4

             Rows(3) / Columns("B:D")

Decalage   : Range("C4").Offset(-1, 2) -> E3 (+ bas/droite, - haut/gauche)

3. Propriétés, Méthodes & Événements

Proprietes (=) : .Value  .Formula  .Font.Bold = True  .Font.Size = 12

                 .Interior.Color = RGB(r,v,b)  .Interior.ColorIndex = 6

                 .Count  .Row  .Column  .Name  Application.ScreenUpdating = False

Methodes       : .Select  .Activate  .Copy Destination:=Range("E1")

                 .ClearContents (garde le format) != .Clear (efface tout)

                 .ClearFormats  .Delete  .Insert  Columns("A:D").AutoFit

Fonctions Excel: Application.WorksheetFunction.Sum(Range("B2:B20"))

Evenements     : Workbook_Open() -> dans ThisWorkbook

                 Worksheet_Change(ByVal Target As Range) -> dans Feuil1

4. Variables, Types, Opérateurs & Function

Option Explicit : Oblige a declarer toutes les variables avec Dim

Types entiers   : Byte (0..255), Integer (-32768..32767), Long (+-2 milliards)

Types decimaux  : Single, Double (8 octets), Currency (monetaire fixe)

Autres types    : String, Boolean (True/False), Date, Variant (defaut)

Variable objet  : Dim plg As Range  ->  Set plg = Range("A1:A10")

Operateurs      : & (concatenation), \ (div. entiere), Mod (reste), <> (diff.)

Function (UDF)  : Function CalculTTC(ht As Double) As Double

                      CalculTTC = ht * 1.18   ' Retour par le nom de la fonction

                  End Function

5. Structures de contrôle (Conditions & Boucles)

If cond Then ... ElseIf cond2 Then ... Else ... End If

Select Case note : Case Is >= 16 / Case 12 To 15.99 / Case Else / End Select

Boucle compteur  : For i = 2 To 50 ... Next i

Suppression      : For i = 50 To 2 Step -1 -> Rows(i).Delete -> Next i

Collection       : For Each cel In Range("A1:A20") ... Next cel

Boucle cond.     : Do While Cells(i, 1).Value <> "" ... i = i + 1 ... Loop

                   Do Until Cells(i, 1).Value = ""  ... i = i + 1 ... Loop

Sorties          : Exit For / Exit Do / Exit Sub / Exit Function

6. Boîtes de dialogue, Erreurs & UserForms

MsgBox   : rep = MsgBox("Confirmer ?", vbYesNo + vbQuestion, "Titre")

           If rep = vbYes Then ...   (Arguments nommes : Prompt:="...", Title:="...")

InputBox : texte = InputBox("Nom :", "Saisie")   (renvoie "" si Annuler)

Erreurs  : On Error GoTo Etiquette  ...  Exit Sub  ...  Etiquette: Err.Number

UserForm : Label, TextBox, ComboBox (.AddItem dans UserForm_Initialize), CommandButton

           Frm.Show (affiche) / Frm.Hide (masque en memoire) / Unload Me (decharge)
