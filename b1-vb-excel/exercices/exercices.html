Exercices supplémentaires & projet d’automatisation VBA

En complément des 18 exercices interactifs répartis dans les 6 chapitres (et accessibles depuis l’atelier d’exercices), voici des exercices d’entraînement gradués et un dossier complet de conception d’application Excel/VBA.

Entraînement rapide (acquisition)

Échauffement
  1. Enregistrer une macro qui bascule Excel en style de référence L1C1 (Application.ReferenceStyle = xlR1C1), puis écrire la procédure inverse qui rétablit le style A1.
  2. Traduire en notation A1 les références Cells(1, 4), Cells(8, 2) et Range("C5").Offset(3, -2).
  3. Écrire une instruction VBA qui vide les cellules de saisie B4:B15 de la feuille "Devis" sans effacer leurs bordures ni leur format monétaire.
  4. Corriger la déclaration fautive Dim ligne, derniereLigne As Long pour que les deux variables soient bien de type Long.
Corrections & procédures VBA

1. Style L1C1 / A1 : Application.ReferenceStyle = xlR1C1 puis Application.ReferenceStyle = xlA1.

2. Adressage : Cells(1, 4) = D1 ; Cells(8, 2) = B8 ; Range("C5").Offset(3, -2) = ligne 8, colonne A soit A8.

3. Réinitialisation propre : Worksheets("Devis").Range("B4:B15").ClearContents.

4. Déclaration typée : Dim ligne As Long, derniereLigne As Long (avec Option Explicit en tête de module).

Application

Application
  1. Écrire une fonction personnalisée Function MentionJury(moyenne As Double) As String utilisant Select Case pour renvoyer "Très Bien" (≥ 16), "Bien" (14 à 15,99), "Assez Bien" (12 à 13,99), "Passable" (10 à 11,99) ou "Ajourné" (< 10).
  2. Écrire une boucle For Each qui parcourt la plage C2:C100 et colorie en jaune (ColorIndex = 6) toutes les cellules dont le montant dépasse 500 000.
  3. Écrire une boucle Do While qui part de la ligne 2 et numérote automatiquement la colonne A jusqu’à la première ligne où la colonne B (nom du client) est vide.
  4. Écrire une procédure événementielle Worksheet_Change qui inscrit automatiquement en colonne E le nom de l’utilisateur (Application.UserName) dès qu’un montant est modifié en colonne D.
Corrections & procédures VBA

1. Fonction MentionJury : Utiliser Select Case moyenne avec Case Is >= 16, Case 14 To 15.99, …, Case Else et affecter le texte à MentionJury = ....

2. Boucle For Each : For Each cel In Range("C2:C100") : If cel.Value > 500000 Then cel.Interior.ColorIndex = 6 : Next cel.

3. Boucle Do While : i = 2 : Do While Cells(i, 2).Value <> "" : Cells(i, 1).Value = i - 1 : i = i + 1 : Loop.

4. Événement Worksheet_Change : Dans le module de la feuille : If Target.Column = 4 And Target.Row >= 2 Then Target.Offset(0, 1).Value = Application.UserName.

Raisonnement

Raisonnement
  1. Écrire une procédure de purge qui supprime toutes les lignes entre la ligne 2 et la ligne 200 dont le statut en colonne F vaut "Annulé", sans sauter aucune ligne consécutive.
  2. Concevoir un formulaire UserForm d’enregistrement de commande comprenant un TextBoxClient, une ComboBoxModePaiement ("Espèces", "Virement", "Mobile Money") et un bouton ButtonValider qui ajoute la saisie sur la première ligne vide de la feuille.
  3. Sécuriser une procédure d’export avec On Error GoTo pour afficher le numéro (Err.Number) et la description (Err.Description) de l’erreur en cas de feuille ou de fichier manquant.
Corrections & procédures VBA

1. Purge à rebours : For i = 200 To 2 Step -1 : If Cells(i, 6).Value = "Annulé" Then Rows(i).Delete : Next i.

2. UserForm : Remplir la liste dans UserForm_Initialize() avec .AddItem ; dans ButtonValider_Click(), contrôler que les champs ne sont pas vides, trouver la première ligne vide avec une boucle Do While, écrire les valeurs puis appeler Unload Me.

3. Gestion d’erreurs : Placer On Error GoTo GestionErr en début de Sub, terminer le flux normal par Exit Sub, puis sous GestionErr: afficher MsgBox Err.Number & " : " & Err.Description, vbCritical.
