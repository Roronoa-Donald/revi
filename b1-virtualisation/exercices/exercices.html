Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque chapitre, puis un projet final : le réveil d’un parc entier. Les scripts sont en Bash, comme à l’atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lit n lignes « heure inactif » et classe les heures perdues au seuil 48, puis le bilan d’inactivité.
  2. Lit n lignes « ressource partage » et valide les ressources partagées de l’histoire, puis le compteur.
  3. Lit n lignes « service categorie » et valide les quatre services de l’histoire, puis le compteur.
  4. Lit n lignes « concept role » (partage/avantage/risque) et valide chaque question technique, puis le compteur.
Corrections
read -r n
perdues=0
total=0
for ((k=0; k<n; k++)); do

Application

Application
  1. Lit n lignes « serveur services cout » et classe fainéants/équilibrés/saturés avec le gaspillage.
  2. Lit la capacité puis n demandes « vm ram disque » et alloue sans dépasser, avec les restes.
  3. Lit n lignes « vm service » et produit l’inventaire par service dans l’ordre d’apparition.
  4. Lit n lignes « serveur avant apres » et compte les réveillés (avant < 30, apres ≥ 80).
Corrections
read -r n
f=0
gaspillage=0
for ((k=0; k<n; k++)); do
  read -r serveur services cout
  if [ "$services" -lt 2 ]; then
    echo "$serveur : faineant"
    f=$((f + 1))
    gaspillage=$((gaspillage + cout * 80 / 100))
  elif [ "$services" -gt 4 ]; then
    echo "$serveur : sature"
  else
    echo "$serveur : equilibre"
  fi
done
echo "faineants : $f"
echo "gaspillage : $gaspillage FCFA"

read -r n
read -r ram disque
reste_r=$ram
reste_d=$disque
ok=0
for ((k=0; k<n; k++)); do
  read -r vm r d
  if [ "$r" -le "$reste_r" ] && [ "$d" -le "$reste_d" ]; then
    echo "$vm : allouee"
    reste_r=$((reste_r - r))
    reste_d=$((reste_d - d))
    ok=$((ok + 1))
  else
    echo "$vm : refusee"
  fi
done
echo "allouees : $ok/$n"
echo "reste : $reste_r ram $reste_d disque"

read -r n
declare -A compte
declare -A ordre
g=0
for ((k=0; k<n; k++)); do
  read -r vm service
  echo "$vm : $service"
  if [ -z "\${compte[$service]+x}" ]; then
    ordre[$g]=$service
    g=$((g + 1))
  fi
  compte[$service]=$((\${compte[$service]:-0} + 1))
done
for ((k=0; k<g; k++)); do
  service=\${ordre[$k]}
  echo "$service : \${compte[$service]} vm"
done
echo "services : $g"

read -r n

for ((k=0; k<n; k++)); do

    reveilles=$((reveilles + 1))

Raisonnement

Raisonnement
  1. Lit la capacité puis n charges « vm charge » et refuse tout dépassement, avec le verdict de saturation exacte.
  2. Lit n lignes « serveur cpu ram reponses » et détecte les symptômes 90/90/500 avec l’action de déplacement.
  3. Lit le parc puis le coût d’une VM et calcule la consolidation au plafond avec l’économie.
  4. Lit m hôtes puis n VM « vm besoin » et place chaque VM au premier hôte suffisant, avec les restes.
Corrections
read -r capacite
[ "$capacite" = "-" ] && capacite=100
read -r n
ok=0
total=0
for ((k=0; k<n; k++)); do
  read -r vm charge

  fi
done
echo "charge : $total/$capacite"
echo "hebergees : $ok/$n"

read -r n
x=0
for ((k=0; k<n; k++)); do
  read -r serveur cpu ram reponses
  c=0
  symptome=""
  if [ "$cpu" -gt 90 ]; then c=$((c + 1)) ; symptome="cpu" ; fi
  if [ "$ram" -gt 90 ]; then c=$((c + 1)) ; symptome="ram" ; fi
  if [ "$reponses" -gt 500 ]; then c=$((c + 1)) ; symptome="reponses" ; fi
  if [ "$c" -eq 0 ]; then
    echo "$serveur : sain"
  else

    x=$((x + 1))
  fi
done

echo "deplacements : $x"

read -r n
total=0
for ((k=0; k<n; k++)); do
  read -r serveur cout
  total=$((total + cout))
done
read -r cout_vm
vm=$((total / cout_vm))
[ $((total % cout_vm)) -ne 0 ] && vm=$((vm + 1))
apres=$((vm * cout_vm))
eco=$((total - apres))
pct=$((eco * 100 / total))
echo "parc actuel : $n serveurs — $total FCFA"

read -r m
declare -A capacite
declare -A ordre
for ((k=0; k<m; k++)); do
  read -r hote c
  capacite[$hote]=$c
  ordre[$k]=$hote
done
read -r n
non=0
for ((k=0; k<n; k++)); do
  read -r vm besoin
  place=0
  for ((j=0; j<m; j++)); do
    hote=\${ordre[$j]}
    if [ "$place" = "0" ] && [ "\${capacite[$hote]}" -ge "$besoin" ]; then
      echo "$vm : $hote"
      capacite[$hote]=$((\${capacite[$hote]} - besoin))
      place=1
    fi
  done
  if [ "$place" = "0" ]; then
    echo "$vm : sans-place"
    non=$((non + 1))
  fi
done
for ((j=0; j<m; j++)); do
  hote=\${ordre[$j]}
  echo "$hote : \${capacite[$hote]}"
done
echo "non-placees : $non/$n"

Projet intégrateur — « le réveil d’un parc entier »

Cahier des charges

Le script reçoit le dossier de réveil d’un parc. D’abord n lignes serveur config où config est une suite de lettres sans espace — f = fainéant confirmé (moins de 30 % d’utilisation), c = compatible virtualisation, s = sauvegardes existantes, le tiret - = aucune information. Puis m lignes vm charge de la charge des VM prévues. Il affiche pour chaque serveur serveur : a virtualiser si les trois lettres sont présentes, sinon serveur : a etudier (manque X) avec la première lettre manquante dans l’ordre f, c, s ; pour chaque VM vm : charge=X ; enfin le verdict : parc reveille si tous les serveurs sont virtualisables ET que la charge totale des VM est de 300 au plus, parc a ajuster si les serveurs sont prêts sans ce volume, parc bloque sinon.

Fonctionnalités attendues
  1. Lire les deux blocs sans mélanger serveurs et VM.
  2. Auditer chaque serveur : première lettre manquante dans l’ordre f, c, s.
  3. Chiffrer la charge totale des VM prévues.
  4. Verdict final au format exact du cahier des charges.

Contraintes : parsing lettre à lettre, premier manque dans l’ordre, bilan après lecture complète.

Grille d’auto-évaluation du projet (sur 100)
Lecture des deux blocs et parsing correct 20
Audit des serveurs (premier manque) 20
Charge totale des VM 20
Verdict global conforme 20
Rapport lisible et formats exacts 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
read -r n
tous_ok=1
for ((k=0; k<n; k++)); do
  read -r serveur config
  f=0 ; c=0 ; s=0
  if [ "$config" != "-" ]; then
    for ((j=0; j<${#config}; j++)); do
      lettre=${config:$j:1}
      case "$lettre" in
        f) f=1 ;;
        c) c=1 ;;
        s) s=1 ;;
      esac
    done
  fi
  if [ "$f" = "1" ] && [ "$c" = "1" ] && [ "$s" = "1" ]; then
    echo "$serveur : a virtualiser"
  elif [ "$f" = "0" ]; then
    echo "$serveur : a etudier (manque f)" ; tous_ok=0
  elif [ "$c" = "0" ]; then
    echo "$serveur : a etudier (manque c)" ; tous_ok=0
  else
    echo "$serveur : a etudier (manque s)" ; tous_ok=0
  fi
done
read -r m
total=0
for ((k=0; k<m; k++)); do
  read -r vm charge
  total=$((total + charge))
  echo "$vm : charge=$charge"
done
if [ "$tous_ok" = "1" ] && [ "$total" -le 300 ]; then
  echo "verdict : parc reveille"
elif [ "$tous_ok" = "1" ]; then
  echo "verdict : parc a ajuster"
else
  echo "verdict : parc bloque"
fi
Cette solution combine parsing lettre à lettre, premier manque dans l’ordre, chiffrage de la charge et verdict global — les chapitres 1, 5 et 6 en un seul script.
