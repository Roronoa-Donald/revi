Chapitre 2

📐 Espaces Vectoriels

Axiomes, sous-espaces, familles libres, bases et dimension — la structure de l'algèbre linéaire.

Objectifs du chapitre

  • Connaître les 8 axiomes d'un espace vectoriel
  • Vérifier si un sous-ensemble est un sous-espace vectoriel (SEV)
  • Distinguer famille libre, liée, génératrice et base
  • Calculer la dimension d'un espace et appliquer la formule de Grassmann

C'est quoi un espace vectoriel ?

🏫 Analogie de la boîte à outils

Un espace vectoriel, c'est une boîte à outils mathématique : un ensemble de « vecteurs » munis de deux opérations (addition + multiplication par un scalaire) qui respectent 8 règles strictes.

Exemples classiques : \(\mathbb{R}^2\), \(\mathbb{R}^3\), \(\mathbb{R}_n[X]\) (polynômes de degré ≤ n), \(\mathcal{M}_{n,p}(\mathbb{R})\).

Les 8 axiomes — Structure \((E, +, \cdot)\)

🧠 Mnémonique : 4 + 4 = 8 — « A.C.N.I. × 2 »

Associativité · Commutativité · élément Neutre · élément Inverse

4 axiomes pour l'addition (+)

#AxiomeFormule
A1Associativité\((u+v)+w = u+(v+w)\)
A2Commutativité\(u+v = v+u\)
A3Élément neutre\(\exists\, 0_E : u + 0_E = u\)
A4Opposé\(\forall u,\ \exists\, (-u) : u + (-u) = 0_E\)

4 axiomes pour la loi externe (·)

#AxiomeFormule
M1Associativité mixte\(\lambda(\mu\, u) = (\lambda\mu)\, u\)
M2Élément neutre scalaire\(1 \cdot u = u\)
D1Distributivité / vecteurs\(\lambda(u+v) = \lambda u + \lambda v\)
D2Distributivité / scalaires\((\lambda+\mu)\, u = \lambda u + \mu u\)

Sous-espaces vectoriels (SEV)

🧠 3 Tests pour un SEV — « N.A.M. » (Non-vide, Addition, Multiplication)

Un sous-ensemble \(F \subset E\) est un SEV ssi :

  • Non-vide : \(0_E \in F\) (ou montrer que \(F \neq \varnothing\))
  • Addition stable : \(\forall u, v \in F,\ u+v \in F\)
  • Multiplication stable : \(\forall \lambda \in \mathbb{R},\ \forall u \in F,\ \lambda u \in F\)
💡 Test 2-en-1 : On peut regrouper A + M : \(\forall \lambda, \mu \in \mathbb{R},\ \forall u, v \in F : \lambda u + \mu v \in F\)
⚠️ Piège : \(F = \{(x, y) \in \mathbb{R}^2 \mid x + y = 1\}\) n'est pas un SEV car \((0,0) \notin F\).

✏️ Exercice guidé — Vérifier si un ensemble est un SEV

Énoncé : L'ensemble \(F = \{(x, y, z) \in \mathbb{R}^3 \mid x - 2y + z = 0\}\) est-il un SEV de \(\mathbb{R}^3\) ?

Étape 1 — Test N (non-vide) :

\((0,0,0) \in F\) ? → \(0 - 2(0) + 0 = 0\) ✓ Le vecteur nul est dans \(F\).

Étape 2 — Test A (stabilité par addition) :

Soient \(u = (x_1, y_1, z_1)\) et \(v = (x_2, y_2, z_2)\) dans \(F\), donc \(x_1 - 2y_1 + z_1 = 0\) et \(x_2 - 2y_2 + z_2 = 0\).

\[(x_1+x_2) - 2(y_1+y_2) + (z_1+z_2) = \underbrace{(x_1-2y_1+z_1)}_{=0} + \underbrace{(x_2-2y_2+z_2)}_{=0} = 0 \quad ✓\]

Étape 3 — Test M (stabilité par multiplication scalaire) :

\[\lambda x_1 - 2(\lambda y_1) + \lambda z_1 = \lambda\underbrace{(x_1 - 2y_1 + z_1)}_{=0} = 0 \quad ✓\]

Conclusion : \(F\) est un SEV de \(\mathbb{R}^3\). C'est le plan d'équation \(x - 2y + z = 0\) passant par l'origine.

💡 Règle générale : Tout ensemble défini par une équation linéaire homogène (= 0) est un SEV !

✏️ Exercice guidé — Contre-exemple : ce n'est PAS un SEV

Énoncé : \(G = \{(x, y) \in \mathbb{R}^2 \mid xy \geq 0\}\) est-il un SEV ?

Test N : \((0,0) \in G\) car \(0 \times 0 = 0 \geq 0\) ✓

Test A : Prenons \(u = (1,1)\) et \(v = (-1,2)\). On a \(1 \times 1 = 1 \geq 0\) ✓ et \((-1)(2) = -2 \not\geq 0\) ✗

En fait, \(v \notin G\). Prenons \(u=(1, -1)\) (xy = -1 < 0) → \(u \notin G\) non plus. Essayons \(u = (1, 0)\) et \(v = (0, -1)\) :

\(u + v = (1, -1)\) et \(1 \times (-1) = -1 < 0\), donc \(u+v \notin G\). Le test A échoue !

Conclusion : \(G\) n'est pas un SEV (il suffit d'UN contre-exemple !).

Exemple : \(F = \{(x, y) \in \mathbb{R}^2 \mid 2x - y = 0\}\) est un SEV de \(\mathbb{R}^2\) :

  • \((0,0)\) vérifie \(2(0)-0=0\) ✓ (non-vide)
  • Si \((x_1,y_1), (x_2,y_2) \in F\) → \(2(x_1+x_2)-(y_1+y_2) = (2x_1-y_1)+(2x_2-y_2) = 0\) ✓
  • \(\lambda(x,y) = (\lambda x, \lambda y)\) et \(2\lambda x - \lambda y = \lambda(2x-y) = 0\) ✓

Combinaisons linéaires & Vect

Une combinaison linéaire (CL) de \(v_1, \ldots, v_k\) :

\[\lambda_1 v_1 + \lambda_2 v_2 + \cdots + \lambda_k v_k \quad (\lambda_i \in \mathbb{R})\]

L'ensemble de toutes les CL possibles forme le sous-espace engendré :

\[\text{Vect}(v_1, \ldots, v_k) = \{\lambda_1 v_1 + \cdots + \lambda_k v_k \mid \lambda_i \in \mathbb{R}\}\]

C'est toujours un SEV de \(E\).

Familles libres et liées

🧠 Mnémonique : « Libre = Aucune redondance »

  • Famille libre : la seule CL donnant \(0_E\) est la triviale (\(\lambda_1 = \cdots = \lambda_k = 0\))
  • Famille liée : il existe une CL non triviale qui donne \(0_E\) (il y a de la redondance !)
💡 Règles rapides :
  • Plus de vecteurs que \(\dim(E)\) → automatiquement liée
  • Si un vecteur est CL des autres → liée
  • \(\{0_E, \ldots\}\) → toujours liée (car \(1 \cdot 0_E = 0_E\))

Exemple 1 : \(\{(1,0), (0,1)\}\) dans \(\mathbb{R}^2\) :

\(\lambda_1(1,0) + \lambda_2(0,1) = (0,0) \Rightarrow \lambda_1 = \lambda_2 = 0\) → libre ✓

Exemple 2 : \(\{(1,0), (0,1), (1,1)\}\) dans \(\mathbb{R}^2\) : 3 vecteurs pour \(\dim = 2\) → liée ✓

En effet : \(1 \cdot (1,0) + 1 \cdot (0,1) - 1 \cdot (1,1) = (0,0)\) avec des coefficients non tous nuls.

✏️ Exercice guidé — Déterminer si une famille est libre ou liée

Énoncé : La famille \(\{v_1 = (1,2,1),\ v_2 = (0,1,-1),\ v_3 = (2,5,1)\}\) est-elle libre dans \(\mathbb{R}^3\) ?

Étape 1 — Poser l'équation :

\[\lambda_1(1,2,1) + \lambda_2(0,1,-1) + \lambda_3(2,5,1) = (0,0,0)\]

Étape 2 — Former le système :

\[\begin{cases} \lambda_1 + 0 + 2\lambda_3 = 0 \\ 2\lambda_1 + \lambda_2 + 5\lambda_3 = 0 \\ \lambda_1 - \lambda_2 + \lambda_3 = 0 \end{cases}\]

Étape 3 — Résoudre par échelonnement :

De \(L_1\) : \(\lambda_1 = -2\lambda_3\)

\(L_2 : 2(-2\lambda_3) + \lambda_2 + 5\lambda_3 = 0 \Rightarrow \lambda_2 + \lambda_3 = 0 \Rightarrow \lambda_2 = -\lambda_3\)

\(L_3 : (-2\lambda_3) - (-\lambda_3) + \lambda_3 = -2\lambda_3 + \lambda_3 + \lambda_3 = 0\) ✓ (automatiquement satisfaite)

Étape 4 — Conclure :

Pour \(\lambda_3 = 1\) : \(\lambda_1 = -2\), \(\lambda_2 = -1\), \(\lambda_3 = 1\). Tous non nuls → CL non triviale !

\[-2(1,2,1) - 1(0,1,-1) + 1(2,5,1) = (-2+0+2,\ -4-1+5,\ -2+1+1) = (0,0,0) ✓\]

Conclusion : La famille est liée. On a \(v_3 = 2v_1 + v_2\).

Base et dimension

🧠 Base = Libre + Génératrice = « Le juste nécessaire »

Une base de \(E\) est une famille à la fois libre et génératrice.

La dimension de \(E\) = nombre de vecteurs dans n'importe quelle base.

EspaceBase canoniqueDimension
\(\mathbb{R}^n\)\(\{e_1, \ldots, e_n\}\)\(n\)
\(\mathbb{R}_n[X]\) (deg ≤ n)\(\{1, X, X^2, \ldots, X^n\}\)\(n+1\)
\(\mathcal{M}_{n,p}(\mathbb{R})\)\(\{E_{ij}\}\) (matrices élémentaires)\(n \times p\)
ℹ️ Propriétés utiles :
  • Famille libre dans \(E\) → au plus \(\dim(E)\) vecteurs
  • Famille libre de \(\dim(E)\) vecteurs → c'est une base !
  • Famille génératrice de \(\dim(E)\) vecteurs → c'est une base !

Formule de Grassmann & Somme directe

Pour deux sous-espaces \(F_1\) et \(F_2\) de \(E\) :

\[\boxed{\dim(F_1 + F_2) = \dim(F_1) + \dim(F_2) - \dim(F_1 \cap F_2)}\]
ℹ️ Somme directe : Si \(F_1 \cap F_2 = \{0_E\}\), on écrit \(F_1 \oplus F_2\) et alors \(\dim(F_1 \oplus F_2) = \dim(F_1) + \dim(F_2)\).

Exemple : Soit \(F_1 = \text{Vect}((1,0,0), (0,1,0))\) et \(F_2 = \text{Vect}((0,1,0), (0,0,1))\) dans \(\mathbb{R}^3\).

  • \(\dim(F_1) = 2\), \(\dim(F_2) = 2\)
  • \(F_1 \cap F_2 = \text{Vect}((0,1,0))\) → \(\dim(F_1 \cap F_2) = 1\)
  • \(\dim(F_1 + F_2) = 2 + 2 - 1 = 3\), donc \(F_1 + F_2 = \mathbb{R}^3\).

✏️ Exercice guidé — Formule de Grassmann pas à pas

Énoncé : Dans \(\mathbb{R}^4\), on donne :

\[F = \text{Vect}((1,0,1,0),\ (0,1,0,1)) \qquad G = \text{Vect}((1,1,1,1),\ (0,1,1,0))\]

Calculer \(\dim(F+G)\) et déterminer si \(F + G\) est une somme directe.

Étape 1 — Dimensions de \(F\) et \(G\) :

\(\dim(F) = 2\) (les deux vecteurs ne sont pas proportionnels → libre).

\(\dim(G) = 2\) (idem).

Étape 2 — Trouver \(F \cap G\) :

Un vecteur \(w \in F \cap G\) s'écrit \(w = \alpha(1,0,1,0) + \beta(0,1,0,1) = \gamma(1,1,1,1) + \delta(0,1,1,0)\).

\[\begin{cases} \alpha = \gamma \\ \beta = \gamma + \delta \\ \alpha = \gamma + \delta \\ \beta = \gamma \end{cases} \Rightarrow \begin{cases} \alpha = \gamma \\ \delta = \beta - \gamma \\ \delta = \alpha - \gamma = 0 \\ \beta = \gamma = \alpha \end{cases}\]

Donc \(\delta = 0\) et \(\alpha = \beta = \gamma\) → \(w = \alpha(1,1,1,1)\), donc \(F \cap G = \text{Vect}((1,1,1,1))\) et \(\dim(F \cap G) = 1\).

Étape 3 — Appliquer Grassmann :

\[\dim(F+G) = 2 + 2 - 1 = \boxed{3}\]

Conclusion : \(F \cap G \neq \{0\}\), donc la somme n'est pas directe. \(F + G\) est un sous-espace de dimension 3 de \(\mathbb{R}^4\).

Pièges classiques à l'examen

⚠️ Piège n°1 : Confondre « libre » et « génératrice ». Ce sont deux notions indépendantes : libre = pas de redondance, génératrice = couvre tout.
⚠️ Piège n°2 : Oublier de vérifier \(0_E \in F\) pour un SEV. C'est le test le plus rapide pour éliminer.
⚠️ Piège n°3 : Dire que \(\dim(\mathbb{R}_n[X]) = n\) au lieu de \(\mathbf{n+1}\). La base est \(\{1, X, \ldots, X^n\}\), soit \(n+1\) éléments !

Récapitulatif

📝 L'essentiel du Chapitre 2

  • 8 axiomes : 4 pour \(+\), 4 pour \(\cdot\) (A.C.N.I. × 2)
  • SEV : tester N.A.M. (Non-vide, Addition, Multiplication)
  • Libre = seule CL nulle est triviale · Liée = redondance
  • Base = Libre + Génératrice · \(\dim\) = taille de la base
  • Grassmann : \(\dim(F_1{+}F_2) = \dim(F_1) + \dim(F_2) - \dim(F_1 \cap F_2)\)
