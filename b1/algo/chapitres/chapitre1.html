Chapitre 1 — Algorithmique

Variables & Types de Données

Les fondations de tout programme : comprendre les variables, les types de données, l'affectation et les entrées/sorties.

Objectifs du chapitre

  • Comprendre ce qu'est un algorithme et son utilité
  • Connaître les structures de base : entrée, sortie, traitement
  • Écrire un premier pseudo-code simple

1.1 — Qu'est-ce qu'un algorithme ?

📋 Définition

Un algorithme est une suite finie d'instructions précises qui, à partir de données d'entrée, produit un résultat de sortie après un nombre fini d'étapes.

🍳
Analogie — La recette de cuisine : Un algorithme, c'est comme une recette. Les ingrédients sont les entrées, les instructions sont les étapes, et le plat fini est la sortie. Si tu suis les étapes dans l'ordre, tu obtiens toujours le même résultat !

Les 3 parties d'un algorithme

1 Entrées — Les données que l'algorithme reçoit (ex : deux nombres à additionner).
2 Traitement — Les opérations effectuées sur les données (ex : addition).
3 Sorties — Le résultat produit (ex : la somme).
🧠
Mnémo — ETS : Entrée → Traitement → Sortie. Comme « Entrée en scène, Travail, Sortie de scène » — tout algorithme suit ce schéma !

1.2 — Les variables

📦 Définition

Une variable est un espace de stockage en mémoire identifié par un nom (identifiant) et qui contient une valeur d'un certain type.

🗄️
Analogie — Le casier : Imagine un casier dans un vestiaire. Le numéro du casier c'est le nom de la variable, le contenu c'est la valeur, et le type de casier (petit/grand/avec crochet) c'est le type de données.

Règles de nommage

  • Commence par une lettre (pas un chiffre)
  • Contient uniquement lettres, chiffres et _ (underscore)
  • Pas d'espaces ni de caractères spéciaux
  • Pas de mots réservés du langage (si, alors, pour…)
  • Choisir des noms explicites : age plutôt que a
💡
Bonne pratique : Utilise le camelCase (nombreEleves) ou le snake_case (nombre_eleves) pour les noms composés. Sois cohérent dans tout ton programme !

Déclaration en pseudocode

Variable age : Entier Variable nom : Chaîne Variable moyenne : Réel Variable estInscrit : Booléen

Traduction en Pascal

var age : integer; nom : string; moyenne : real; estInscrit : boolean;

1.3 — Les types de données

Chaque variable a un type qui détermine les valeurs possibles et les opérations autorisées.

TypeDescriptionExemplesPascal
Entier Nombre sans virgule 0, 42, -7 integer
Réel Nombre avec virgule 3.14, -0.5 real
Caractère Un seul symbole 'A', '3', '@' char
Chaîne Suite de caractères "Bonjour", "B1" string
Booléen Vrai ou Faux VRAI, FAUX boolean
🧠
Mnémo — ERCBC : Entier, Réel, Caractère, Booléen, Chaîne — retiens « Elle Rit Car Bob Chante » pour les 5 types fondamentaux.
⚠️
Attention : '3' (caractère) ≠ 3 (entier). Le caractère '3' est un symbole, le nombre 3 peut être utilisé pour calculer. On ne peut pas additionner '3' + '2' pour obtenir 5 !

1.4 — L'affectation

⬅️ Définition

L'affectation consiste à stocker une valeur dans une variable. En pseudocode, on utilise la flèche ←. En Pascal, on utilise :=.

📬
Analogie — La boîte aux lettres : L'affectation, c'est comme mettre une lettre dans une boîte aux lettres. La boîte (variable) reçoit le courrier (valeur). Si tu mets un nouveau courrier, l'ancien est remplacé.

Syntaxe

// Affectation d'une constante age ← 20 nom ← "Alice" pi ← 3.14159 // Affectation avec expression somme ← a + b double ← nombre * 2
age := 20; nom := 'Alice'; pi := 3.14159; somme := a + b; double := nombre * 2;
⚠️
Piège classique : a ← b copie la valeur de b dans a. La variable b garde sa valeur ! Ce n'est pas un échange.

Exemple trace — Échange de deux variables

Pour échanger les valeurs de a et b, on a besoin d'une variable temporaire :

// Échange de a et b temp ← a // Sauvegarder a a ← b // Écraser a avec b b ← temp // Restaurer l'ancien a dans b
🧠
Mnémo — Le verre d'eau : Pour échanger le contenu de deux verres (🥤↔️🧃), il faut un troisième verre vide (la variable temp). Verse le premier dans le vide, puis remplis le premier avec le second, et le second avec le troisième.

1.5 — Entrées et Sorties

📥📤 Communication avec l'utilisateur

Les entrées permettent à l'utilisateur de fournir des données au programme. Les sorties affichent des résultats à l'écran.

En pseudocode

Écrire("Quel est votre âge ?") // Sortie : afficher un message Lire(age) // Entrée : l'utilisateur tape sa réponse Écrire("Vous avez ", age, " ans.") // Sortie : afficher le résultat

En Pascal

writeln('Quel est votre age ?'); readln(age); writeln('Vous avez ', age, ' ans.');
ℹ️
Différence writeln / write : writeln ajoute un retour à la ligne après l'affichage. write reste sur la même ligne. Pareil pour readln (lire avec saut de ligne) et read.

1.6 — Opérations et Expressions

Opérateurs arithmétiques

OpérateurSignificationExempleRésultat
+Addition7 + 310
-Soustraction7 - 34
*Multiplication7 * 321
/Division réelle7 / 23.5
DIVDivision entière7 DIV 23
MODReste (modulo)7 MOD 21
🧠
Mnémo — DIV et MOD : Pense à la division posée de l'école primaire : 7 ÷ 2 = 3 reste 1.
DIV donne le quotient (3), MOD donne le reste (1).
Astuce : si nombre MOD 2 = 0, le nombre est pair ! 🎯

Priorité des opérations

Comme en maths : parenthèses d'abord, puis */DIV/MOD, puis +-.

📝
Exemple : 3 + 4 * 2 = 3 + 8 = 11 (pas 14 !)
Pour forcer l'addition en premier : (3 + 4) * 2 = 7 * 2 = 14

1.7 — Les constantes

🔒 Définition

Une constante est une variable dont la valeur est fixée une fois pour toutes et ne peut pas être modifiée pendant l'exécution du programme.

Constante PI ← 3.14159 Constante TVA ← 0.20 Constante MAX_ELEVES ← 35
const PI = 3.14159; TVA = 0.20; MAX_ELEVES = 35;
💡
Convention : Les constantes s'écrivent souvent en MAJUSCULES pour les distinguer des variables. Utilise-les dès qu'une valeur ne doit jamais changer (π, taux de TVA…).

1.8 — Premier programme complet

Créons un programme qui calcule l'aire d'un cercle à partir de son rayon :

En pseudocode

Algorithme AireCercle Constante PI ← 3.14159 Variable rayon : Réel Variable aire : Réel Début Écrire("Entrez le rayon du cercle :") Lire(rayon) aire ← PI * rayon * rayon Écrire("L'aire du cercle est : ", aire) Fin

En Pascal

program AireCercle; const PI = 3.14159; var rayon, aire : real; begin writeln('Entrez le rayon du cercle :'); readln(rayon); aire := PI * rayon * rayon; writeln('L''aire du cercle est : ', aire:0:2); end.
ℹ️
Notation Pascal :0:2 : Le premier chiffre est la largeur totale (0 = automatique), le second est le nombre de décimales affichées. aire:0:2 affiche l'aire avec 2 chiffres après la virgule.

Exercice guidé — Conversion de types

🎯 Convertir une durée en secondes → heures, minutes, secondes

Énoncé : On dispose d'une variable duree_sec ← 7384. Calculer les heures, minutes et secondes correspondantes.

Étape 1 — Déclarer les variables
Variables :
    duree_sec : ENTIER ← 7384
    heures    : ENTIER
    minutes   : ENTIER
    secondes  : ENTIER
Étape 2 — Calculer les heures
heures ← duree_sec DIV 3600
// 7384 DIV 3600 = 2
Étape 3 — Calculer le reste après les heures
reste ← duree_sec MOD 3600
// 7384 MOD 3600 = 184
Étape 4 — Calculer minutes et secondes
minutes ← reste DIV 60       // 184 DIV 60 = 3
secondes ← reste MOD 60      // 184 MOD 60 = 4
Résultat
Afficher heures, "h", minutes, "min", secondes, "s"
→ 2h 3min 4s ✓

1.9 — Résumé du chapitre

🎯 Ce qu'il faut retenir

  • Algorithme = Entrée → Traitement → Sortie
  • Variable = espace mémoire nommé contenant une valeur typée
  • 5 types fondamentaux : Entier, Réel, Caractère, Booléen, Chaîne
  • Affectation (←) remplace l'ancienne valeur
  • Écrire = afficher, Lire = saisir
  • DIV = quotient, MOD = reste
  • Constante = variable non modifiable
🧠
Résumé mnémo complet :
🍳 Algorithme = recette (ETS : Entrée → Traitement → Sortie)
