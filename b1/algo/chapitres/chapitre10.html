Chapitre 10

La Complexité algorithmique

Mesurer l'efficacité : notation Grand O, complexité temporelle vs spatiale, analyser un algorithme.

Objectifs du chapitre

  • Lire et écrire dans des fichiers texte
  • Connaître les modes d'ouverture (lecture, écriture, ajout)
  • Traiter un fichier ligne par ligne

10.1 — Pourquoi mesurer la complexité ?

🏎️
Analogie — Les voitures : Deux voitures vont de Paris à Lyon. L'une prend l'autoroute (rapide mais péage), l'autre les routes nationales (lent mais gratuit). La complexité mesure le « coût » d'un algorithme : combien de temps (temporel) et combien de mémoire (spatial).

🎯 Ce qu'on mesure

  • Complexité temporelle : combien d'opérations en fonction de n ?
  • Complexité spatiale : combien de mémoire en fonction de n ?
  • On s'intéresse au pire cas (garantie de performance)

10.2 — La notation Grand O

📐 Définition

O(f(n)) décrit le comportement asymptotique : comment le nombre d'opérations évolue quand n grandit. On ignore les constantes et les termes de moindre importance.

📝
Simplification :
3n² + 5n + 10 → on garde le terme dominant → O(n²)
100n + 2000 → O(n)
7 → O(1) (constant)
🧠
Mnémo — Règles de simplification :
1️⃣ Ignorer les constantes : O(3n) = O(n)
2️⃣ Garder le terme dominant : O(n² + n) = O(n²)
3️⃣ Pire cas par défaut
« Constantes dehors, Dominant dedans » = CD

10.4 — Comment analyser un algorithme

Règles pratiques

StructureComplexité
Instruction simple (affectation, comparaison)O(1)
Boucle Pour de 1 à nO(n)
Deux boucles imbriquées (n × n)O(n²)
Division par 2 à chaque étapeO(log n)
Séquence (l'une après l'autre)Max des deux
📝
Exemple — Analyse : 
somme ← 0              // O(1)
Pour i de 1 à n Faire   // O(n) ×
    somme ← somme + T[i] //   O(1)
FinPour
Pour i de 1 à n Faire   // O(n) ×
    Pour j de 1 à n Faire //   O(n)
        ...              //     O(1)
    FinPour
FinPour
Total : O(1) + O(n) + O(n²) = O(n²) (terme dominant)

10.5 — Complexité spatiale

💾 Mémoire utilisée

La complexité spatiale mesure la mémoire supplémentaire utilisée par l'algorithme (hors données d'entrée).

AlgorithmeComplexité spatiale
Recherche séquentielleO(1) — juste i et trouvé
Tri par sélectionO(1) — en place
Récursion profondeur nO(n) — pile d'appels
💡
En place : Un tri « en place » ne crée pas de nouveau tableau. Il réarrange les éléments dans le tableau d'origine → O(1) en espace.

Méthode : Analyser la Complexité d'un Algorithme

Étape 1 : Identifier les boucles

  • Pas de boucle → O(1)
  • 1 boucle de 1 à N → O(n)
  • 2 boucles imbriquées de 1 à N → O(n²)
  • Boucle qui divise par 2 → O(log n)

Étape 2 : Appliquer les règles de combinaison

  • Séquentiel : O(f) puis O(g) → O(max(f,g))
  • Imbriqué : O(f) dans O(g) → O(f × g)
  • Ignorer les constantes : O(3n) = O(n)
  • Garder le terme dominant : O(n² + n) = O(n²)

Étape 3 : Cas courants à reconnaître

Accès direct (tableau[i])O(1)
Recherche dichotomiqueO(log n)
Parcours simpleO(n)
Tri efficace (fusion)O(n log n)
Tri basique (sélection, bulles)O(n²)
Fibonacci naïfO(2ⁿ) ⚠️

Étape 4 : Vérifier avec un exemple concret

  • Pour n = 1000 : O(n²) = 1 000 000 opérations
  • Pour n = 1000 : O(log n) = ~10 opérations seulement !
