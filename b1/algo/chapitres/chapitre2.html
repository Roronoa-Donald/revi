Chapitre 2 — Algorithmique

Structures Conditionnelles

Apprendre à faire des choix dans un programme : Si/Sinon, Selon/Cas, conditions imbriquées et opérateurs logiques.

Objectifs du chapitre

  • Déclarer et utiliser des variables de différents types
  • Maîtriser l'affectation et les opérations arithmétiques
  • Utiliser les instructions de lecture et d'écriture

2.1 — La structure Si / Alors / Sinon

🚦 Définition

La structure Si permet d'exécuter des instructions uniquement si une condition est vraie. Le bloc Sinon s'exécute quand la condition est fausse.

🚦
Analogie — Le feu rouge : Si le feu est vert → tu passes. Sinon (rouge) → tu t'arrêtes. Le programme fait exactement la même chose : il teste une condition et choisit un chemin.

Syntaxe pseudocode

Si condition Alors instructions si vrai Sinon instructions si faux FinSi

Exemple : Majeur ou mineur ?

Écrire("Quel est votre âge ?") Lire(age) Si age >= 18 Alors Écrire("Vous êtes majeur.") Sinon Écrire("Vous êtes mineur.") FinSi
readln(age); if age >= 18 then writeln('Vous êtes majeur.') else writeln('Vous êtes mineur.');
⚠️
Piège Pascal : Pas de ; avant le else ! Le ; termine l'instruction complète, pas le bloc then. Si tu mets un ; avant else, erreur de compilation.

2.3 — Opérateurs logiques : ET, OU, NON

🔗 Combiner des conditions

Les opérateurs logiques permettent de combiner plusieurs conditions en une seule expression.

OpérateurSignificationVrai quand…Pascal
ETConjonctionLes DEUX conditions sont vraiesand
OUDisjonctionAu moins UNE condition est vraieor
NONNégationLa condition est fausse (inverse)not
🧠
Mnémo — ET/OU :
🎭 ET = exigeant → il faut TOUT. Comme un professeur strict : « devoir rendu ET présent en cours ».
🎉 OU = généreux → il suffit d'UN. Comme un buffet : « gâteau OU tarte ».

Tables de vérité

VRAI ET VRAI = VRAI VRAI ET FAUX = FAUX FAUX ET VRAI = FAUX FAUX ET FAUX = FAUX
VRAI OU VRAI = VRAI VRAI OU FAUX = VRAI FAUX OU VRAI = VRAI FAUX OU FAUX = FAUX
📝
Exemple : Un élève est admis si sa note est ≥ 10 ET il n'a pas d'absence injustifiée :
Si (note >= 10) ET (absences = 0) Alors Écrire("Admis")

2.4 — Conditions imbriquées (Si / SinonSi)

Quand il y a plus de 2 cas, on imbrique les conditions :

Si note >= 16 Alors Écrire("Très bien") SinonSi note >= 14 Alors Écrire("Bien") SinonSi note >= 12 Alors Écrire("Assez bien") SinonSi note >= 10 Alors Écrire("Passable") Sinon Écrire("Insuffisant") FinSi
if note >= 16 then writeln('Très bien') else if note >= 14 then writeln('Bien') else if note >= 12 then writeln('Assez bien') else if note >= 10 then writeln('Passable') else writeln('Insuffisant');
💡
Ordre important : Teste toujours du plus grand au plus petit (ou l'inverse, mais sois cohérent). Si tu testes note >= 10 en premier, un 18 serait « Passable » !

2.5 — La structure Selon / Cas

🎯 Quand utiliser Selon ?

La structure Selon (ou Case) est idéale quand on teste la valeur exacte d'une variable parmi plusieurs possibilités. Plus lisible que des Si/SinonSi répétitifs.

Écrire("Entrez un numéro de jour (1-7) :") Lire(jour) Selon jour Faire 1 : Écrire("Lundi") 2 : Écrire("Mardi") 3 : Écrire("Mercredi") 4 : Écrire("Jeudi") 5 : Écrire("Vendredi") 6, 7 : Écrire("Weekend !") Défaut : Écrire("Numéro invalide") FinSelon
case jour of 1: writeln('Lundi'); 2: writeln('Mardi'); 3: writeln('Mercredi'); 4: writeln('Jeudi'); 5: writeln('Vendredi'); 6, 7: writeln('Weekend !'); else writeln('Numéro invalide'); end;
🧠
Mnémo — Si vs Selon :
📊 Selon = valeurs exactes (1, 2, 3…) → comme un menu à choix multiples
🔍 Si = intervalles et conditions complexes (>= 10, ET, OU) → comme un détecteur

Exercice guidé — Classification d'un triangle

🎯 Déterminer le type d'un triangle à partir de ses 3 côtés

Énoncé : Étant donnés 3 côtés a=5, b=5, c=8, déterminer si le triangle est équilatéral, isocèle ou scalène.

Étape 1 — Vérifier si c'est un triangle valide
SI (a + b > c) ET (a + c > b) ET (b + c > a) ALORS
    // 5+5=10 > 8 ✓  |  5+8=13 > 5 ✓  |  5+8=13 > 5 ✓
    // C'est bien un triangle
Étape 2 — Classifier avec conditions imbriquées
    SI (a = b) ET (b = c) ALORS
        Afficher "Équilatéral"       // 5≠8, donc NON
    SINON SI (a = b) OU (a = c) OU (b = c) ALORS
        Afficher "Isocèle"           // a=b=5, donc OUI ✓
    SINON
        Afficher "Scalène"
    FIN SI
Résultat
→ "Isocèle" ✓
Le triangle (5, 5, 8) a deux côtés égaux.

2.6 — Résumé du chapitre

🎯 Ce qu'il faut retenir

  • Si/Alors/Sinon : exécution conditionnelle simple ou double
  • SinonSi : enchaîner plusieurs conditions (ordre important !)
  • Selon/Cas : tester des valeurs exactes d'une variable
  • ET = les deux vraies, OU = au moins une vraie, NON = inverse
  • En Pascal : if/then/else, case/of, and/or/not
  • Pas de ; avant else en Pascal !
