Chapitre 4

Les Tableaux

Stocker et manipuler des collections de données : tableaux 1D, 2D, parcours et recherche séquentielle.

Objectifs du chapitre

  • Maîtriser les boucles Pour, TantQue et Répéter
  • Savoir choisir la bonne boucle selon le contexte
  • Éviter les boucles infinies

4.1 — Tableaux à une dimension

📦 Définition

Un tableau est une structure qui permet de stocker plusieurs valeurs du même type sous un même nom. Chaque valeur est identifiée par un indice (numéro de position).

🏨
Analogie — L'hôtel : Un tableau = un étage d'hôtel. Chaque chambre a un numéro (indice). Toutes les chambres sont identiques (même type). Pour trouver un client, on dit « chambre 3 » → T[3].

Déclaration

// Pseudocode Variable notes : Tableau[1..10] de Réel
var notes : array[1..10] of real;

Accès et affectation

notes[1] ← 15.5 // Affecter la valeur 15.5 à la case 1 notes[3] ← notes[1] + 2 // Case 3 = 17.5
⚠️
Indices : En pseudocode on commence souvent à l'indice 1. En Pascal aussi. Mais en C/Java/Python, on commence à 0 ! Attention quand tu traduis.
🧠
Mnémo — T.I.P. : Un tableau c'est Type identique, Indice pour accéder, Plusieurs valeurs.

4.2 — Parcourir un tableau

Pour traiter toutes les cases d'un tableau, on utilise une boucle Pour :

Remplissage par l'utilisateur

Pour i de 1 à N Faire Écrire("Entrez la note n°", i, " : ") Lire(notes[i]) FinPour

Affichage

Pour i de 1 à N Faire Écrire("Note ", i, " = ", notes[i]) FinPour

Calcul de la somme et de la moyenne

somme ← 0 Pour i de 1 à N Faire somme ← somme + notes[i] FinPour moyenne ← somme / N

Recherche du maximum

max ← notes[1] Pour i de 2 à N Faire Si notes[i] > max Alors max ← notes[i] FinSi FinPour
💡
Initialisation du max : On initialise avec le premier élément du tableau (pas 0 !). Puis on compare à partir du 2ème.

4.3 — Tableaux à deux dimensions (matrices)

📊 Définition

Un tableau 2D = un tableau de tableaux. On accède à un élément par deux indices : la ligne et la colonne.

🎬
Analogie — Le cinéma : La rangée = 1er indice (ligne). Le siège dans la rangée = 2ème indice (colonne). cinema[3][5] = rangée 3, siège 5.
Variable grille : Tableau[1..3][1..4] de Entier // Parcours complet avec 2 boucles imbriquées Pour i de 1 à 3 Faire Pour j de 1 à 4 Faire Écrire(grille[i][j], " ") FinPour Écrire() // Retour à la ligne FinPour
var grille : array[1..3, 1..4] of integer;

4.4 — Recherche séquentielle

On parcourt le tableau case par case pour trouver une valeur :

trouvé ← FAUX i ← 1 TantQue (i ≤ N) ET (trouvé = FAUX) Faire Si T[i] = valeurCherchée Alors trouvé ← VRAI position ← i Sinon i ← i + 1 FinSi FinTantQue
🧠
Mnémo — FLAG : On utilise un drapeau (booléen trouvé) pour savoir si on a trouvé et on s'arrête dès que c'est trouvé — on ne continue pas inutilement.

Exercices guidés — Les Tableaux

🎯 Trouver le maximum et sa position dans un tableau

Énoncé : T = [14, 7, 23, 9, 18]. Trouver la valeur maximale et son indice.

Étape 1 — Initialiser avec le premier élément
max_val ← T[0]    // max_val = 14
max_pos ← 0
Étape 2 — Parcourir le tableau
POUR i DE 1 À 4 FAIRE
    SI T[i] > max_val ALORS
        max_val ← T[i]
        max_pos ← i
    FIN SI
FIN POUR
Étape 3 — Trace
iT[i]T[i] > max ?max_valmax_pos
177 > 14 ? Non140
22323 > 14 ? Oui232
399 > 23 ? Non232
41818 > 23 ? Non232
Résultat
→ Maximum = 23 à l'indice 2 ✓

🎯 Inverser un tableau en place

Énoncé : Inverser T = [3, 8, 1, 6, 2] sans tableau auxiliaire.

Principe — Échanger les éléments symétriques
POUR i DE 0 À (n DIV 2 - 1) FAIRE
    temp ← T[i]
    T[i] ← T[n - 1 - i]
    T[n - 1 - i] ← temp
FIN POUR
Trace (n=5, boucle de 0 à 1)
iÉchangeTableau
Init—[3, 8, 1, 6, 2]
0T[0] ↔ T[4][2, 8, 1, 6, 3]
1T[1] ↔ T[3][2, 6, 1, 8, 3]
 
→ Résultat : [2, 6, 1, 8, 3] ✓
L'élément central (indice 2) ne bouge pas.

4.5 — Résumé

🎯 Aide-mémoire

  • Tableau 1D : une seule ligne de cases, accès par T[i]
  • Tableau 2D : lignes × colonnes, accès par T[i][j]
  • Parcours : toujours avec boucle Pour
  • Somme : accumulateur initialisé à 0
  • Max : initialisé au 1er élément, boucle à partir du 2ème
  • Recherche : drapeau trouvé + arrêt dès trouvé
  • T.I.P. : Type identique, Indice, Plusieurs valeurs
