Chapitre 5

Fonctions & Procédures

Découper un programme en sous-programmes réutilisables : paramètres, retour de valeur, portée des variables.

Objectifs du chapitre

  • Déclarer et parcourir des tableaux à une dimension
  • Rechercher un élément dans un tableau
  • Comprendre les tableaux à deux dimensions

5.1 — Pourquoi découper un programme ?

🍕
Analogie — La pizzeria : Au lieu qu'une seule personne fasse tout (pâte, sauce, garniture, cuisson), on découpe en postes spécialisés. Chaque poste = un sous-programme. Résultat : plus clair, plus rapide, réutilisable.

🎯 Avantages

  • Lisibilité : code plus court et organisé
  • Réutilisation : on appelle la même fonction plusieurs fois
  • Maintenabilité : on corrige une seule fois à un seul endroit
  • Travail en équipe : chacun code un sous-programme
🧠
Mnémo — L.R.M.T. : Lisibilité, Réutilisation, Maintenabilité, Travail d'équipe = les 4 raisons de découper.

5.2 — Les procédures

🔧 Définition

Une procédure est un sous-programme qui exécute une action mais ne retourne pas de valeur.

📣
Analogie : Une procédure = un ordre. « Va nettoyer la chambre ! » → l'action est faite, mais personne ne te rend de résultat.
Procédure AfficherBonjour(nom : Chaîne) Début Écrire("Bonjour ", nom, " !") Fin // Appel AfficherBonjour("Alice") // Affiche : Bonjour Alice !
procedure AfficherBonjour(nom: string); begin writeln('Bonjour ', nom, ' !'); end; { Appel } AfficherBonjour('Alice');

5.3 — Les fonctions

📤 Définition

Une fonction est un sous-programme qui retourne une valeur grâce au mot-clé Retourner.

🧮
Analogie — La machine à café : Tu mets une pièce (paramètre), elle te rend un café (valeur retournée). La machine est la fonction, le café est le résultat.
Fonction Carre(n : Entier) : Entier Début Retourner n * n Fin // Appel résultat ← Carre(5) // résultat = 25
function Carre(n: integer): integer; begin Carre := n * n; { En Pascal, on assigne au nom de la fonction } end;
🧠
Mnémo — F vs P :
Fonction = Fournit un résultat (retourne une valeur)
Procédure = Pas de résultat (exécute une action)
« La Fonction est Fertile, la Procédure est Pratique. »

5.4 — Passage de paramètres

ModePseudocodePascalEffet
Par valeurparam : Typeparam: TypeCopie — l'original ne change pas
Par référenceparam : Type (E/S)var param: TypeL'original est modifié
📋
Analogie : Par valeur = tu donnes une photocopie de ton document. La fonction peut gribouiller dessus, l'original est intact. Par référence = tu donnes l'original. Attention, il peut être modifié !
Procédure Doubler(n : Entier E/S) Début n ← n * 2 Fin x ← 5 Doubler(x) Écrire(x) // Affiche 10 (x a été modifié)
procedure Doubler(var n: integer); begin n := n * 2; end;

5.5 — Portée des variables

TypeDéclarée où ?Visible où ?
LocaleDans le sous-programmeUniquement dans ce sous-programme
GlobaleDans le programme principalPartout
🏠
Analogie : Variable locale = affaires dans ta chambre (personne d'autre n'y touche). Variable globale = affaires dans le salon (tout le monde peut les utiliser).
⚠️
Bonne pratique : Évite les variables globales ! Passe les données en paramètres. Les globales rendent le code difficile à déboguer.

Exercices guidés — Fonctions & Procédures

🎯 Fonction : Vérifier si un nombre est premier

Énoncé : Écrire une fonction estPremier(n) et tester avec n=17 et n=15.

Étape 1 — Écrire la fonction
FONCTION estPremier(n : ENTIER) : BOOLÉEN
    SI n < 2 ALORS
        RETOURNER FAUX
    FIN SI
    POUR i DE 2 À √n FAIRE
        SI n MOD i = 0 ALORS
            RETOURNER FAUX    // Divisible → pas premier
        FIN SI
    FIN POUR
    RETOURNER VRAI            // Aucun diviseur trouvé
FIN FONCTION
Étape 2 — Trace pour n = 17 (√17 ≈ 4.12, boucle de 2 à 4)
i17 MOD i= 0 ?
217 MOD 2 = 1Non
317 MOD 3 = 2Non
417 MOD 4 = 1Non
 
→ estPremier(17) = VRAI ✓
Trace pour n = 15 (√15 ≈ 3.87, boucle de 2 à 3)
i=2 : 15 MOD 2 = 1 → Non
i=3 : 15 MOD 3 = 0 → RETOURNER FAUX
→ estPremier(15) = FAUX ✓ (divisible par 3)

🎯 Procédure vs Fonction : Afficher vs Retourner

Énoncé : Comparer une procédure et une fonction pour calculer la moyenne de 3 notes.

Version Procédure (ne retourne rien)
PROCÉDURE afficherMoyenne(a, b, c : RÉEL)
    m ← (a + b + c) / 3
    Afficher "Moyenne =", m
FIN PROCÉDURE

// Appel :
afficherMoyenne(12, 15, 9)
→ Affiche "Moyenne = 12.0"
// On ne peut PAS stocker le résultat
Version Fonction (retourne une valeur)
FONCTION calculerMoyenne(a, b, c : RÉEL) : RÉEL
    RETOURNER (a + b + c) / 3
FIN FONCTION

// Appel :
resultat ← calculerMoyenne(12, 15, 9)
// resultat = 12.0, on peut le réutiliser
SI resultat >= 10 ALORS
    Afficher "Admis"    → "Admis" ✓
FIN SI

5.6 — Résumé

🎯 Aide-mémoire

  • Procédure : action sans retour
  • Fonction : calcul avec retour (Retourner)
  • Par valeur : copie (original intact)
  • Par référence (E/S) : original modifié
  • Variable locale : visible seulement dans son sous-programme
  • L.R.M.T. : Lisibilité, Réutilisation, Maintenabilité, Travail d'équipe
  • F = Fournit, P = Pas de résultat
