Chapitre 9

Structures de Données

Piles, files, listes chaînées et enregistrements : organiser les données au-delà des tableaux.

Objectifs du chapitre

  • Maîtriser les piles (LIFO) et files (FIFO)
  • Comprendre les listes chaînées et leurs opérations
  • Savoir choisir la bonne structure de données

9.1 — Les enregistrements (records)

📋 Définition

Un enregistrement regroupe plusieurs données de types différents sous un même nom. Chaque donnée est un champ.

🪪
Analogie — La carte d'identité : Une seule carte, mais plusieurs informations : nom (chaîne), prénom (chaîne), âge (entier), taille (réel). C'est un enregistrement !
Type Etudiant = Enregistrement nom : Chaîne prenom : Chaîne age : Entier moyenne : Réel FinEnregistrement Variable e1 : Etudiant e1.nom ← "Dupont" e1.age ← 20
type Etudiant = record nom: string; prenom: string; age: integer; moyenne: real; end; var e1: Etudiant;
🧠
Mnémo — Tableau vs Enregistrement :
📦 Tableau = plusieurs valeurs du même type (boîte d'œufs)
🪪 Enregistrement = plusieurs valeurs de types différents (carte d'identité)

9.2 — Les piles (stacks)

📚 Principe LIFO

Une pile = Last In, First Out. Le dernier élément ajouté est le premier retiré. Deux opérations de base : Empiler (push) et Dépiler (pop).

🥞
Analogie — La pile d'assiettes : Tu empiles les assiettes les unes sur les autres. Pour en prendre une, tu prends celle du dessus (la dernière posée). Tu ne peux pas prendre celle du milieu !
OpérationDescriptionComplexité
Empiler(x)Ajoute x au sommetO(1)
Dépiler()Retire et retourne le sommetO(1)
Sommet()Consulte le sommet sans retirerO(1)
EstVide()Vérifie si la pile est videO(1)
📝
Cas d'utilisation : Pile d'appels (récursivité !), bouton « Annuler » (Ctrl+Z), historique de navigation (bouton Retour).

9.3 — Les files (queues)

🚶 Principe FIFO

Une file = First In, First Out. Le premier élément ajouté est le premier retiré. Deux opérations : Enfiler (enqueue) et Défiler (dequeue).

🎫
Analogie — La file d'attente : Au cinéma, le premier arrivé est le premier servi. Pas de doublage ! Les nouveaux arrivent à la fin, les premiers partent de devant.
OpérationDescriptionComplexité
Enfiler(x)Ajoute x à la finO(1)
Défiler()Retire et retourne le premierO(1)
Premier()Consulte le premier sans retirerO(1)
EstVide()Vérifie si la file est videO(1)
🧠
Mnémo — LIFO vs FIFO :
🥞 PiLe = LIFO = Last In First Out (assiettes, Ctrl+Z)
🎫 FiFe = FIFO = First In First Out (file d'attente, imprimante)

9.4 — Les listes chaînées

🔗 Principe

Chaque élément (nœud) contient une valeur et un pointeur vers l'élément suivant. Le dernier pointe vers NIL (rien).

🚂
Analogie — Le train : Chaque wagon = un nœud. Il transporte des passagers (valeur) et est accroché au wagon suivant (pointeur). Le dernier wagon n'est accroché à rien (NIL).
Type Noeud = Enregistrement valeur : Entier suivant : ↑Noeud // Pointeur vers le noeud suivant FinEnregistrement
AvantageInconvénient
Insertion/suppression rapide (O(1))Accès par indice lent (O(n))
Taille dynamiquePlus de mémoire (pointeurs)

Pièges classiques à l'examen

⚠️ Piège n°1 — LIFO vs FIFO : Pile = LIFO (Last In, First Out) : on dépile le dernier empilé. File = FIFO (First In, First Out) : on défile le premier enfilé. Ne les confondez pas !
⚠️ Piège n°2 — Terminologie : Pile → Empiler/Dépiler. File → Enfiler/Défiler. Penser aussi à push/pop pour la pile et enqueue/dequeue pour la file.
⚠️ Piège n°3 — Accès par indice : Une liste chaînée ne permet pas l'accès direct par indice (pas de tab[i]). Il faut parcourir la liste depuis la tête — c'est O(n), pas O(1) comme un tableau !

9.6 — Résumé

🎯 Aide-mémoire

  • Enregistrement : types différents sous un nom (carte d'identité)
  • Pile LIFO : Empiler/Dépiler, dernier entré = premier sorti
  • File FIFO : Enfiler/Défiler, premier entré = premier sorti
  • Liste chaînée : nœuds liés par pointeurs (train)
  • Pile → Ctrl+Z, récursion | File → imprimante, messages
