Chapitre 4 — ATO

Architecture d'un Ordinateur

Modèle de Von Neumann, CPU, mémoire hiérarchique, bus système et entrées/sorties.

Objectifs du chapitre

  • Comprendre le modèle de Von Neumann (5 composants)
  • Connaître le fonctionnement du CPU et ses registres
  • Expliquer le cycle Fetch-Decode-Execute
  • Décrire la hiérarchie mémoire (registres → cache → RAM → disque)
  • Comprendre le rôle des 3 bus système

4.1 — Le modèle de Von Neumann

📋 L'idée révolutionnaire

Avant 1945, chaque « ordinateur » était câblé pour une seule tâche. Pour changer le programme, il fallait physiquement recâbler la machine !

En 1945, John Von Neumann propose une idée géniale : stocker le programme dans la même mémoire que les données. Ainsi, pour changer de programme, il suffit de charger un nouveau fichier en mémoire — plus besoin de toucher au câblage.

C'est le modèle que suivent TOUS les ordinateurs modernes.

📋
Analogie — Le bureau : Imagine un employé à son bureau. Sur le bureau (= mémoire), il y a à la fois les données (dossiers, chiffres) et les instructions (procédures à suivre). L'employé (= CPU) lit les instructions une par une et traite les dossiers. Les dossiers arrivent par la porte d'entrée (= entrées) et les résultats sont envoyés par la porte de sortie (= sorties).

Les 5 composants du modèle

ComposantRôleAnalogie humaine
Unité de Commande (UC)Cherche, décode et ordonne l'exécution des instructionsLe chef d'orchestre
Unité Arithmétique et Logique (UAL)Effectue calculs (+, −, ×, ÷) et opérations logiques (AND, OR…)Le calculateur
Mémoire centraleStocke programmes et données en cours d'utilisationLe bureau de travail
EntréesReçoit les données de l'extérieur (clavier, souris, capteur…)Les yeux et les oreilles
SortiesEnvoie les résultats (écran, imprimante, haut-parleur…)La bouche et les mains
⚠️
Architecture Harvard : Variante avec mémoire programme et mémoire données séparées. Utilisée dans les microcontrôleurs (Arduino, PIC). Avantage : accès simultané aux données et instructions.
🧠
Mnémo Von Neumann — « MUCES » : Mémoire, UC, Calculateur (UAL), Entrées, Sorties.

4.2 — Le processeur (CPU)

📋 Structure du CPU

Le CPU (Central Processing Unit) est le « cerveau » de l'ordinateur. Il contient :

  • UAL — effectue les calculs
  • UC (Unité de Commande) — pilote le séquencement
  • Registres — mémoires ultra-rapides internes
  • Horloge — cadence le CPU (en GHz)

Les registres principaux

RegistreNom completRôle
PC (CO)Program Counter / Compteur OrdinalAdresse de la prochaine instruction
IR (RI)Instruction RegisterContient l'instruction en cours
MAR (RA)Memory Address RegisterAdresse mémoire à lire/écrire
MBR (RD)Memory Buffer RegisterDonnée lue/à écrire en mémoire
ACCAccumulateurStocke les résultats intermédiaires de l'UAL
SPStack PointerPointe vers le sommet de la pile
SR / FLAGSStatus RegisterDrapeaux : Z (zéro), C (carry), N (négatif), V (overflow)

Le cycle d'instruction (Fetch-Decode-Execute)

⚡ Les 3 étapes fondamentales

  1. FETCH (Recherche) — L'UC copie PC → MAR, lit la mémoire[MAR] → MBR → IR, incrémente PC
  2. DECODE (Décodage) — L'UC analyse IR : identifie l'opcode (opération) et les opérandes (données)
  3. EXECUTE (Exécution) — L'UAL effectue l'opération, le résultat va dans ACC ou en mémoire

Ce cycle se répète des milliards de fois par seconde (1 GHz = 10⁹ cycles/s).

🍳
Analogie — Cuisiner :
FETCH = aller chercher la recette dans le livre (mémoire).
DECODE = lire et comprendre l'étape « battre 2 œufs ».
EXECUTE = casser les œufs et battre. Puis on passe à l'étape suivante (PC++).

4.3 — La hiérarchie mémoire

📋 Principe

Plus une mémoire est rapide, plus elle est petite et chère. On organise les mémoires en pyramide : en haut le plus rapide, en bas le plus volumineux.

Registres
~1 ns, ~Ko
Cache L1/L2/L3
~2-20 ns, ~Mo
RAM (DRAM)
~50-100 ns, ~Go
SSD / Disque dur
~μs-ms, ~To
Stockage distant (Cloud)
~ms-s, ~∞

Types de mémoire

TypeVolatile ?AccèsUsage
SRAMOuiTrès rapide (~1-2 ns)Cache CPU
DRAMOuiRapide (~50-100 ns)RAM principale (DDR4, DDR5)
ROMNonLentBIOS/UEFI, firmware
EEPROM/FlashNonMoyenSSD, clés USB, cartes SD
HDDNonLent (mécanique)Stockage de masse
🧠
Mnémo : La pyramide mémoire c'est comme un bureau : Les registres = ce que tu tiens en main (ultra-rapide, très peu). Le cache = les post-it sur l'écran. La RAM = le bureau devant toi. Le disque dur = les tiroirs du bureau. Le cloud = les archives au sous-sol.
💡
Cache : Le cache exploite le principe de localité — temporelle (si on accède à une donnée, on y accédera bientôt à nouveau) et spatiale (les données voisines seront probablement accédées aussi).

4.4 — Les bus système

📋 Définition

Un bus est un ensemble de lignes (fils) qui transporte des signaux entre les composants de l'ordinateur. Il y a 3 types de bus :

Bus de données
32/64 bits
Bus d'adresses
32/64 bits
Bus de contrôle
R/W, IRQ…
BusDirectionTransporteDétails
Bus de donnéesBidirectionnelLes donnéesLargeur = nombre de bits traités (32/64 bits)
Bus d'adressesUnidirectionnel (CPU→mémoire)Les adresses mémoiren bits → 2ⁿ adresses possibles (32 bits = 4 Go max)
Bus de contrôleBidirectionnelLes signaux de commandeR/W (lecture/écriture), IRQ (interruption), CLK (horloge)
🚌
Analogie — L'autoroute :
Le bus de données = les voies de circulation (plus il y en a, plus de débit).
Le bus d'adresses = les panneaux de sortie (indique la destination).
Le bus de contrôle = les feux et la signalisation (commande le trafic).

📝 Calcul : mémoire adressable

Bus d'adresses de 32 bits : 2³² = 4 294 967 296 octets = 4 Go (max RAM en 32 bits)

Bus d'adresses de 64 bits : 2⁶⁴ = 16 Eio ≈ 18,4 × 10¹⁸ octets (en théorie !)

4.5 — Les entrées/sorties (E/S)

📋 Modes de gestion des E/S

ModePrincipeAvantageInconvénient
Polling (scrutation)Le CPU interroge régulièrement le périphériqueSimpleGaspille du temps CPU
InterruptionLe périphérique signale au CPU quand il est prêtCPU libre entre-tempsPlus complexe
DMA (Direct Memory Access)Le périphérique transfère directement en RAM sans passer par le CPUTrès performantNécessite un contrôleur DMA
📬
Analogie — Le courrier :
Polling = aller vérifier la boîte aux lettres toutes les 5 minutes.
Interruption = la sonnette retentit quand le facteur arrive.
DMA = le facteur dépose le courrier directement sur votre bureau.

4.6 — Performances du processeur

📋 Facteurs de performance

  • Fréquence d'horloge — Plus de GHz = plus de cycles/seconde
  • Nombre de cœurs — Traitement parallèle (dual, quad, octa…)
  • Pipeline — Découpe le cycle Fetch-Decode-Execute en étapes parallélisées
  • Taille du cache — Plus de cache = moins d'accès lents à la RAM
  • Largeur du bus — 64 bits transfère 2× plus que 32 bits par cycle

📝 Pipeline — le principe de la chaîne de montage

Sans pipeline : une instruction doit finir avant que la suivante commence (3 cycles par instruction).

Avec pipeline (3 étages) :

CycleÉtage 1 (Fetch)Étage 2 (Decode)Étage 3 (Execute)
1Instr. 1——
2Instr. 2Instr. 1—
3Instr. 3Instr. 2Instr. 1
4Instr. 4Instr. 3Instr. 2

Résultat : après le remplissage initial, 1 instruction terminée par cycle au lieu d'1 tous les 3 cycles !

💡
Hyper-Threading (Intel) / SMT (AMD) : Chaque cœur physique simule 2 cœurs logiques pour mieux utiliser les ressources du pipeline inutilisées.

Résumé du chapitre

🔑 Points clés

  • Von Neumann : 5 composants — UC, UAL, Mémoire, Entrées, Sorties
  • CPU : UAL + UC + Registres + Horloge
  • Cycle : Fetch → Decode → Execute (milliards/seconde)
  • Registres clés : PC, IR, MAR, MBR, ACC, SP, FLAGS
  • Hiérarchie mémoire : Registres > Cache > RAM > SSD/HDD > Cloud
  • 3 bus : Données (bidirectionnel), Adresses (unidirectionnel), Contrôle
  • E/S : Polling < Interruption < DMA (en performance)
  • Pipeline : exécution chevauche fetch de l'instruction suivante
  • CISC vs RISC : complexe/flexible vs simple/rapide

Exercice guidé

Le cycle d'exécution d'une instruction

Instruction : ADD R1, R2 (additionner R1 et R2, résultat dans R1)

Phase 1 — FETCH (Recherche)
1. Le PC (Program Counter) contient l'adresse : 0x0040
2. L'adresse est envoyée sur le bus d'adresses
3. La mémoire envoie l'instruction via le bus de données
4. L'instruction est stockée dans le registre RI
5. PC est incrémenté : PC = 0x0044 (instruction suivante)
Phase 2 — DECODE (Décodage)
L'unité de contrôle décode l'instruction :
  - Opération : ADD (addition)
  - Opérande 1 : R1 (contient 15)
  - Opérande 2 : R2 (contient 27)
Phase 3 — EXECUTE (Exécution)
L'UAL (Unité Arithmétique et Logique) effectue :
  R1 + R2 = 15 + 27 = 42
  Résultat stocké dans R1

→ R1 = 42 ✓

Registre d'état mis à jour :
  Z (Zero) = 0 (résultat ≠ 0)
  N (Negative) = 0 (résultat positif)
  C (Carry) = 0 (pas de retenue)
