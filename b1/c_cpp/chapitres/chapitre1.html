Chapitre 1

⚡ Bases du Langage C

Bienvenue dans le monde du C ! Votre premier programme, les variables, les types et les opérateurs — tout pour démarrer solidement.

Objectifs du chapitre

  • Installer l'environnement de développement C
  • Comprendre le cycle compilation → exécution
  • Écrire un premier programme avec printf et scanf

1.1 — Pourquoi apprendre le C ?

🏗️ Le C, fondation de tout

Le langage C a été créé en 1972 par Dennis Ritchie aux laboratoires Bell. Aujourd'hui, il est partout :

  • Systèmes d'exploitation — Linux, Windows, macOS sont écrits en C
  • Embarqué — voitures, robots, microcontrôleurs
  • Langages — Python, PHP, Java sont eux-mêmes écrits en C
Analogie — Le C est l'alphabet

Imaginez que tous les langages de programmation sont des langues (français, anglais, espagnol…). Le C est l'alphabet latin : ils l'utilisent presque tous. Maîtriser le C, c'est maîtriser les fondations de tous les autres.

Compilation vs Interprétation : Le C est un langage compilé. Votre code source (.c) est traduit en langage machine par un compilateur (gcc) avant d'être exécuté. C'est comme traduire un livre entièrement avant de le lire, plutôt que de traduire phrase par phrase.
Cycle de compilation
Code source (.c)  →  Compilateur (gcc)  →  Exécutable (.exe)

$ gcc mon_programme.c -o mon_programme
$ ./mon_programme

1.2 — Premier programme : Hello World

hello.c
#include <stdio.h>    // Bibliothèque d'entrées/sorties

int main() {          // Point d'entrée du programme
    printf("Hello, World!\n");  // Affiche un message
    return 0;         // Fin normale (0 = tout va bien)
}
Mnémonique — I.M.P.R.

Tout programme C contient ces 4 parties obligatoires :

  • I — #include (les bibliothèques)
  • M — main() (la fonction principale)
  • P — printf() (afficher quelque chose)
  • R — return 0; (fin du programme)
Analogie — La recette de cuisine

#include = les ingrédients dont vous avez besoin. main() = la recette elle-même. printf() = servir le plat. return 0 = dire "le repas est prêt !".

⚠️ Erreurs fréquentes : Oublier le ; en fin de ligne, oublier #include <stdio.h>, écrire Main au lieu de main (le C est sensible à la casse !).

1.3 — Variables et types de données

Analogie — Les boîtes étiquetées

Une variable est une boîte dans la mémoire de l'ordinateur. La boîte a :

  • Un nom (l'étiquette) — ex: age
  • Un type (la taille de la boîte) — ex: int
  • Une valeur (ce qu'il y a dedans) — ex: 20
TypeTaillePlageUsageExemple
int4 octets−2³¹ à 2³¹−1Entiersint age = 20;
float4 octets±3.4×10³⁸Décimaux (6 chiffres)float pi = 3.14f;
double8 octets±1.7×10³⁰⁸Décimaux précis (15 ch.)double e = 2.71828;
char1 octet−128 à 127Caractère uniquechar lettre = 'A';
Mnémonique — I.F.D.C. (Il Fait Du Chaud)
  • Int — Entiers
  • Float — Flottants simples
  • Double — Double précision
  • Char — Caractère unique
Déclaration et initialisation
// Déclaration
int age;
float note;

// Déclaration + initialisation (recommandé !)
int score = 100;
char grade = 'A';
double moyenne = 15.75;

// Constante : valeur qui ne change jamais
const float PI = 3.14159f;
#define TVA 0.20  // Autre façon (macro préprocesseur)
Conseil : Toujours initialiser vos variables ! En C, une variable non initialisée contient une valeur aléatoire (poubelle en mémoire). C'est une source de bugs très fréquente.

1.4 — Entrées/Sorties : printf et scanf

📤 printf — Afficher à l'écran

printf() utilise des spécificateurs de format pour insérer des valeurs dans du texte :

SpécificateurTypeExemple
%dintprintf("%d", 42); → 42
%ffloat/doubleprintf("%.2f", 3.14); → 3.14
%ccharprintf("%c", 'A'); → A
%schaîneprintf("%s", "Bonjour");
\nsaut de ligneprintf("Ligne1\nLigne2");
Mnémonique — %D.F.C.S. (Des Frites Chaudes, Svp !)
  • %d — Décimal (entier)
  • %f — Flottant
  • %c — Caractère
  • %s — String (chaîne)
Exemples printf
int age = 20;
float note = 15.5f;
char initiale = 'D';

printf("J'ai %d ans\n", age);
printf("Ma note : %.1f/20\n", note);
printf("Initiale : %c\n", initiale);
printf("Nom : %s, Age : %d\n", "Alice", 21);

📥 scanf — Lire au clavier

scanf() lit la saisie de l'utilisateur. Attention : il faut le & devant la variable !

Exemples scanf
int age;
float taille;

printf("Entrez votre âge : ");
scanf("%d", &age);       // & = adresse de la variable

printf("Entrez votre taille : ");
scanf("%f", &taille);

printf("Vous avez %d ans et mesurez %.2f m\n", age, taille);
⚠️ Le piège du & : Oublier le & dans scanf est l'erreur n°1 des débutants ! Sans &, le programme peut planter. Pensez : « scanf a besoin de l'adresse → le & est comme un GPS qui donne l'adresse de la boîte en mémoire ».

⚠️ La division entière : 7 / 2 = 3 (pas 3.5 !) en C, quand les deux opérandes sont des int. Pour avoir 3.5, écrivez 7.0 / 2 ou faites un cast : (float)7 / 2.

Raccourcis d'affectation

Opérateurs raccourcis
int x = 10;
x += 5;   // x = x + 5  → 15
x -= 3;   // x = x - 3  → 12
x *= 2;   // x = x * 2  → 24
x /= 4;   // x = x / 4  → 6
x %= 5;   // x = x % 5  → 1

// Incrémentation / Décrémentation
x++;      // x = x + 1
x--;      // x = x - 1
Astuce : x++ et ++x font la même chose dans une instruction seule. Mais dans une expression, x++ renvoie l'ancienne valeur puis incrémente, alors que ++x incrémente puis renvoie la nouvelle valeur.

1.6 — Conversion de types (Casting)

Analogie — Le convertisseur de devises

Le casting, c'est comme convertir des euros en dollars : la valeur change de « format » mais représente la même chose. Attention cependant : convertir un billet de 10.50€ en pièces entières perd les centimes !

Types de cast
// Cast implicite (automatique)
int a = 5;
float b = a;        // b = 5.000000 (int → float, pas de perte)

// Cast explicite (vous décidez)
float pi = 3.14159;
int arrondi = (int)pi;  // arrondi = 3 (perte des décimales !)

// Piège classique de la division
int x = 7, y = 2;
float result1 = x / y;        // result1 = 3.0 (division entière !)
float result2 = (float)x / y; // result2 = 3.5 (correct !)
Mnémonique — « Grand accueille Petit »

La conversion sans perte va du petit type vers le grand :
char → int → float → double
L'inverse (double → int) perd de l'information !

✏️ Exercice guidé — Convertir des secondes en h:m:s

Objectif : Convertir un nombre de secondes en heures, minutes, secondes.

Étape 1 — Lire les secondes totales :

int total, heures, minutes, secondes;
printf("Nombre de secondes : ");
scanf("%d", &total);

Étape 2 — Calculer avec / et % :

heures   = total / 3600;          // Division entière
minutes  = (total % 3600) / 60;   // Reste après les heures
secondes = total % 60;            // Reste après les minutes
💡 L'opérateur % (modulo) donne le reste de la division entière — essentiel pour les conversions !

Résultat : 3725 secondes → 1h 2m 5s
