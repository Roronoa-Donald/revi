Chapitre 3

⚡ Les Fonctions

Découpez votre code en blocs réutilisables : prototypes, paramètres, retour de valeur et portée des variables.

Objectifs du chapitre

  • Utiliser if/else et switch/case
  • Maîtriser les boucles while, for et do-while
  • Combiner les conditions avec les opérateurs logiques

3.1 — Pourquoi utiliser des fonctions ?

Analogie — La cuisine modulaire

Imaginez un restaurant. Au lieu qu'un seul cuisinier fasse tout (entrée + plat + dessert + service), on divise le travail : un chef pour les entrées, un pour les plats, un pâtissier. Chacun est spécialisé, et on peut les réutiliser pour différents menus. Les fonctions, c'est pareil !

🎯 Les 3 avantages des fonctions

  • Réutilisabilité — Écrire le code une fois, l'utiliser partout
  • Lisibilité — Un programme découpé est plus facile à comprendre
  • Maintenabilité — Un bug ? On ne corrige qu'à un seul endroit
Mnémonique — R.L.M. (Réutiliser, Lire, Maintenir)

Les 3 raisons de créer des fonctions : Réutiliser le code, Lire plus facilement, Maintenir sans douleur.

3.2 — Syntaxe d'une fonction

Structure générale
type_retour nom_fonction(type param1, type param2) {
    // Corps de la fonction
    return valeur;  // Si type_retour != void
}

// Exemple concret
int addition(int a, int b) {
    int somme = a + b;
    return somme;
}

// Appel
int resultat = addition(5, 3);  // resultat = 8
Mnémonique — T.N.P.C.R. (Tout Nouveau Programme Commence par Réfléchir)

Les 5 éléments d'une fonction :

  • Type de retour — ce que la fonction renvoie
  • Nom — identifiant de la fonction
  • Paramètres — les entrées entre ()
  • Corps — les instructions entre { }
  • Return — la valeur renvoyée

🔀 void : quand la fonction ne renvoie rien

Si la fonction fait une action sans renvoyer de valeur (afficher, modifier), on utilise void :

Fonction void (procédure)
void afficherBonjour(char nom[]) {
    printf("Bonjour %s !\n", nom);
    // Pas de return nécessaire
}

afficherBonjour("Alice");  // Affiche: Bonjour Alice !

3.3 — Prototypes (déclaration anticipée)

Analogie — Le sommaire d'un livre

Le prototype est comme le sommaire d'un livre : il annonce ce qui existe sans donner les détails. Le compilateur a besoin de connaître l'existence d'une fonction avant de la voir utilisée.

Organisation avec prototypes
#include <stdio.h>

// Prototypes (déclarations) — en haut du fichier
int carre(int n);
void saluer(char nom[]);

// Fonction main — utilise les fonctions
int main() {
    saluer("Bob");
    printf("5² = %d\n", carre(5));
    return 0;
}

// Définitions — après main
int carre(int n) {
    return n * n;
}

void saluer(char nom[]) {
    printf("Salut %s !\n", nom);
}
⚠️ Erreur fréquente : Utiliser une fonction sans prototype et sans la définir avant main. Le compilateur ne la connaît pas encore et génère une erreur « implicit declaration ».

3.4 — Passage par valeur

Analogie — La photocopie

Quand vous passez un paramètre par valeur, c'est comme donner une photocopie de votre document. La fonction peut gribouiller sur la copie : l'original reste intact !

Passage par valeur = copie
void doubler(int x) {
    x = x * 2;    // Modifie la COPIE locale
    printf("Dans la fonction : %d\n", x);  // 20
}

int main() {
    int a = 10;
    doubler(a);
    printf("Après appel : %d\n", a);  // 10 ← Inchangé !
    return 0;
}
En C, tout est par valeur par défaut. La variable originale n'est jamais modifiée par la fonction. Pour modifier l'original, il faut passer un pointeur (chapitre 5).

3.5 — Passage par adresse (pointeur)

Analogie — Le document original

Au lieu de donner une photocopie, vous donnez l'adresse du coffre-fort où se trouve le document. La fonction peut alors modifier directement l'original !

Passage par adresse avec *
void doubler(int *px) {     // Reçoit l'ADRESSE
    *px = *px * 2;           // Modifie l'ORIGINAL via *
    printf("Dans la fonction : %d\n", *px);  // 20
}

int main() {
    int a = 10;
    doubler(&a);             // Passe l'ADRESSE avec &
    printf("Après appel : %d\n", a);  // 20 ← Modifié !
    return 0;
}
Mnémonique — & = Adresse, * = Accéder
  • &a → « Donne-moi l'Adresse de a » (GPS)
  • *px → « Accéder à ce qui est à cette adresse » (ouvrir le coffre)

🔄 Exemple classique : échanger deux variables

Swap — échange de deux valeurs
void echanger(int *pa, int *pb) {
    int temp = *pa;    // Sauvegarde la valeur de a
    *pa = *pb;         // a prend la valeur de b
    *pb = temp;        // b prend l'ancienne valeur de a
}

int main() {
    int x = 5, y = 10;
    printf("Avant: x=%d, y=%d\n", x, y);   // x=5, y=10
    echanger(&x, &y);
    printf("Après: x=%d, y=%d\n", x, y);   // x=10, y=5
    return 0;
}

3.6 — Portée des variables

Analogie — Chambres d'hôtel

Les variables locales sont comme les objets dans une chambre d'hôtel : visibles uniquement dans cette chambre. Les variables globales sont comme les objets dans le hall : tout le monde peut les voir.

Locale vs Globale
int compteur = 0;  // Globale — visible partout (ÉVITER !)

void incrementer() {
    compteur++;  // Accède à la globale
    int local = 42;  // Locale — visible SEULEMENT ici
}

int main() {
    incrementer();
    printf("compteur = %d\n", compteur);  // 1
    // printf("%d", local);  // ❌ ERREUR : local n'existe pas ici !
    return 0;
}

🏷️ Variables static (mémoire persistante)

Une variable static conserve sa valeur entre les appels de fonction :

Variable static
void compterAppels() {
    static int nb = 0;  // Initialisée UNE SEULE FOIS
    nb++;
    printf("Appel n°%d\n", nb);
}

int main() {
    compterAppels();  // Appel n°1
    compterAppels();  // Appel n°2
    compterAppels();  // Appel n°3
    return 0;
}
⚠️ Bonnes pratiques : Évitez les variables globales ! Elles créent des dépendances invisibles et rendent le débugage difficile. Préférez passer les données en paramètres.

Exercices guidés pas à pas

✏️ Exercice guidé — Fonction puissance récursive

Objectif : Calculer x^n avec une fonction récursive.

Étape 1 — Prototype et cas de base :

double puissance(double x, int n);  // Prototype

double puissance(double x, int n) {
    if (n == 0) return 1;        // Cas de base : x^0 = 1
    return x * puissance(x, n-1); // Appel récursif
}

Étape 2 — Utiliser la fonction :

printf("2^10 = %.0f\n", puissance(2, 10));  // 1024
printf("3^4  = %.0f\n", puissance(3, 4));   // 81
💡 La récursion s'arrête grâce au cas de base (n == 0). Sans lui → boucle infinie !

✏️ Exercice guidé — Échanger deux variables (passage par adresse)

Objectif : Comprendre la différence entre passage par valeur et par adresse.

Étape 1 — Version qui NE MARCHE PAS (par valeur) :

void echanger_valeur(int a, int b) {
    int temp = a; a = b; b = temp;
    // Échange uniquement les copies locales !
}

Étape 2 — Version correcte (par adresse) :

void echanger(int *a, int *b) {
    int temp = *a;
    *a = *b;       // Modifie la valeur pointée
    *b = temp;
}

int x = 5, y = 10;
echanger(&x, &y);  // Passer les adresses avec &
printf("x=%d, y=%d\n", x, y);  // x=10, y=5 ✓
⚠️ Le * devant le paramètre = pointeur (adresse). Le & à l'appel = "donne-moi l'adresse de".
