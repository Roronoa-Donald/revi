Chapitre 5

⚡ Les Pointeurs

Le concept le plus puissant (et le plus redouté) du C : comprendre les adresses mémoire, le déréférencement et l'allocation dynamique.

Objectifs du chapitre

  • Déclarer et appeler des fonctions
  • Comprendre prototypes, passage par valeur et par référence
  • Maîtriser la portée et la durée de vie des variables

5.1 — Qu'est-ce qu'un pointeur ?

Analogie — L'adresse postale

Imaginez que chaque variable est une maison dans une rue. La maison contient une valeur (son habitant). Un pointeur n'est pas une maison, c'est un Post-it sur lequel est écrit l'adresse de la maison. Avec le Post-it (pointeur), vous pouvez aller à la maison et voir/modifier son habitant (la valeur).

🔑 Définition formelle

Un pointeur est une variable qui stocke l'adresse mémoire d'une autre variable.

Les deux opérateurs clés
int a = 42;       // Variable normale (la maison)
int *p = &a;      // Pointeur vers a (le Post-it avec l'adresse)

// & = "adresse de"  → &a donne l'adresse de a
// *  = "valeur à"    → *p donne la valeur à l'adresse stockée dans p

printf("Valeur de a   : %d\n", a);    // 42
printf("Adresse de a  : %p\n", &a);   // 0x7ffc... (adresse hex)
printf("Valeur de p   : %p\n", p);    // Même adresse
printf("Valeur via *p : %d\n", *p);   // 42 (déréférencement)
Mnémonique — & → Adresse · * → Accéder
  • & commence par un A → Adresse (« où habites-tu ? »)
  • * ressemble à une étoile → elle ouvre la porte (« montre-moi ce qu'il y a dedans ! »)
Visualisation mémoire :
a est à l'adresse 0x100 et contient 42.
p est à l'adresse 0x200 et contient 0x100 (l'adresse de a).
*p suit le « lien » 0x100 → trouve 42.

5.2 — Modifier une valeur via un pointeur

Modification via pointeur
int x = 10;
int *p = &x;

printf("Avant : x = %d\n", x);  // 10

*p = 99;  // Modifie la valeur à l'adresse de x → x vaut 99

printf("Après : x = %d\n", x);  // 99 ← Modifié via le pointeur !

// C'est EXACTEMENT le même mécanisme que le passage par adresse
// dans les fonctions (chapitre 3)
⚠️ Pointeur non initialisé = DANGER !
❌ Ne faites JAMAIS ça
int *p;          // p pointe vers... n'importe où !
*p = 42;         // CRASH ! Écriture à une adresse inconnue

// ✅ Toujours initialiser :
int *p = NULL;   // Pointeur nul (sûr, testable)
// OU
int x;
int *p = &x;     // Pointe vers x (valide)

5.3 — Pointeurs et tableaux

🔗 Le lien secret

En C, le nom d'un tableau EST un pointeur vers son premier élément. tab est équivalent à &tab[0].

Relation tableau ↔ pointeur
int tab[] = {10, 20, 30, 40, 50};
int *p = tab;  // Pas besoin de & : tab EST déjà une adresse !

// Deux façons d'accéder aux éléments :
printf("%d\n", tab[2]);     // 30 (notation tableau)
printf("%d\n", *(p + 2));   // 30 (arithmétique de pointeur)
printf("%d\n", *(tab + 2)); // 30 (même chose !)

// tab[i]  est IDENTIQUE à  *(tab + i)

// Parcours avec pointeur
for (int *ptr = tab; ptr < tab + 5; ptr++) {
    printf("%d ", *ptr);  // 10 20 30 40 50
}
Analogie — Le GPS qui avance

Le pointeur p est un GPS positionné au début du tableau. p+1 avance d'une case, p+2 de deux cases. *p = « qu'est-ce qu'il y a ICI ? ».

Arithmétique de pointeur : p + 1 n'ajoute pas 1 octet mais la taille d'un élément. Si p pointe sur un int (4 octets), p+1 avance de 4 octets.

5.4 — Allocation dynamique : malloc et free

Analogie — Réserver une chambre d'hôtel

malloc = réserver une chambre (de la mémoire) à la demande. free = libérer la chambre quand vous avez fini. Si vous ne libérez pas, c'est une fuite mémoire (comme payer une chambre vide).

malloc, calloc, realloc, free
#include <stdlib.h>  // Pour malloc, free, etc.

// malloc : alloue n octets (NON initialisés)
int *tab = (int*)malloc(5 * sizeof(int));

// calloc : alloue et initialise à 0
int *tab2 = (int*)calloc(5, sizeof(int));

// Vérifier que l'allocation a réussi !
if (tab == NULL) {
    printf("Erreur d'allocation !\n");
    return 1;
}

// Utiliser comme un tableau normal
for (int i = 0; i < 5; i++) {
    tab[i] = i * 10;
}

// Agrandir : realloc
tab = (int*)realloc(tab, 10 * sizeof(int));

// LIBÉRER quand on n'en a plus besoin
free(tab);
tab = NULL;  // Bonne pratique : mettre à NULL après free
Mnémonique — M.C.R.F. (Mon Chat Ronronne Fort)
  • Malloc — alloue (non initialisé)
  • Calloc — alloue + initialise à 0
  • Realloc — redimensionne
  • Free — libère !
⚠️ Les 3 erreurs mortelles de l'allocation :
  1. Oublier free → fuite mémoire (programme consomme de plus en plus)
  2. Double free → crash (libérer deux fois la même zone)
  3. Utiliser après free → comportement imprévisible (dangling pointer)

5.5 — Pointeurs et fonctions (rappel enrichi)

Fonction qui renvoie un tableau dynamique
// Créer un tableau dynamique et le retourner
int* creerTableau(int n) {
    int *t = (int*)calloc(n, sizeof(int));
    for (int i = 0; i < n; i++) t[i] = i + 1;
    return t;  // OK car alloué dynamiquement !
}

int main() {
    int *tab = creerTableau(5);
    for (int i = 0; i < 5; i++)
        printf("%d ", tab[i]);  // 1 2 3 4 5
    free(tab);  // INDISPENSABLE !
    return 0;
}
⚠️ JAMAIS retourner l'adresse d'une variable locale !
❌ Erreur grave
int* mauvais() {
    int x = 42;
    return &x;  // ❌ x est détruite à la sortie de la fonction !
}
// Le pointeur retourné pointe vers une zone détruite (dangling pointer)

Exercices guidés pas à pas

✏️ Exercice guidé — Tableau dynamique avec malloc

Objectif : Allouer un tableau dont la taille est choisie à l'exécution.

Étape 1 — Allouer :

int n;
printf("Combien de notes ? ");
scanf("%d", &n);

int *notes = (int *)malloc(n * sizeof(int));
if (notes == NULL) {
    printf("Erreur d'allocation !\n");
    return 1;
}
⚠️ Toujours vérifier que malloc ne retourne pas NULL !

Étape 2 — Utiliser comme un tableau normal :

for (int i = 0; i < n; i++) {
    printf("Note %d : ", i + 1);
    scanf("%d", &notes[i]);  // notes[i] = *(notes + i)
}

Étape 3 — Libérer la mémoire :

free(notes);    // Toujours libérer !
notes = NULL;   // Bonne pratique : évite les pointeurs pendants
💡 Règle d'or : chaque malloc doit avoir son free.

✏️ Exercice guidé — Pointeurs et arithmétique

Objectif : Comprendre l'arithmétique des pointeurs.

int tab[] = {10, 20, 30, 40, 50};
int *p = tab;  // p pointe sur tab[0]

printf("*p     = %d\n", *p);       // 10 (valeur pointée)
printf("*(p+2) = %d\n", *(p+2));   // 30 (avance de 2 cases)
printf("p[3]   = %d\n", p[3]);     // 40 (notation tableau)
p++;                                // p pointe maintenant sur tab[1]
printf("*p     = %d\n", *p);       // 20
💡 p+1 avance de sizeof(int) octets (4 octets), pas de 1 octet ! C ajuste automatiquement.
