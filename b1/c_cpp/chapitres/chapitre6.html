Chapitre 6

⚡ Les Structures

Regrouper des données de types différents dans un seul « paquet » : struct, typedef, tableaux de structures.

Objectifs du chapitre

  • Comprendre les adresses mémoire et les pointeurs
  • Utiliser les opérateurs * (déréférencement) et & (adresse)
  • Lier pointeurs et tableaux

6.1 — Qu'est-ce qu'une structure ?

Analogie — La carte d'identité

Une carte d'identité regroupe des informations de types différents : nom (texte), date de naissance (date), numéro (entier), photo (image). Un struct fait la même chose en C : il regroupe plusieurs variables de types différents sous un seul nom.

📦 Définition

Une structure (struct) est un type de donnée personnalisé qui regroupe plusieurs variables (appelées champs ou membres) de types éventuellement différents.

Déclaration d'une structure
// Définition du modèle (type)
struct Etudiant {
    char nom[50];
    int age;
    float moyenne;
};

// Déclaration d'une variable de type struct Etudiant
struct Etudiant e1;

// Initialisation directe
struct Etudiant e2 = {"Alice", 20, 15.5};

// Accès aux champs avec le point .
strcpy(e1.nom, "Bob");
e1.age = 19;
e1.moyenne = 12.75;

printf("%s a %d ans (moy: %.2f)\n", e1.nom, e1.age, e1.moyenne);
// Bob a 19 ans (moy: 12.75)
Mnémonique — « Le point ouvre le champ »

Pour accéder à un champ : variable.champ. Le point (.) est comme une clé qui ouvre le bon tiroir de la boîte.

6.2 — typedef : simplifier les noms

Analogie — Le surnom

typedef donne un surnom à un type. Au lieu d'écrire « Monsieur Jean-Pierre Dupont-Martin » à chaque fois, on dit juste « Jean ». Pareil : au lieu de struct Etudiant, on peut écrire juste Etudiant.

typedef struct
// Sans typedef : répéter "struct" partout
struct Etudiant e1;  // struct obligatoire

// Avec typedef : le surnom suffit
typedef struct {
    char nom[50];
    int age;
    float moyenne;
} Etudiant;  // ← Le surnom !

Etudiant e1 = {"Alice", 20, 15.5};  // Plus besoin de "struct" !
Etudiant e2;  // Beaucoup plus propre
Convention : En C, on nomme les types créés avec typedef en PascalCase (première lettre majuscule) : Etudiant, Point, Voiture.

6.3 — Tableaux de structures

Analogie — Le registre scolaire

Un tableau de structures est comme un registre scolaire : chaque ligne est un élève (une structure) avec son nom, son âge, ses notes. Le registre = le tableau, chaque fiche = une structure.

Tableau de structures
typedef struct {
    char nom[30];
    float note;
} Etudiant;

#define N 3
Etudiant promo[N] = {
    {"Alice", 16.5},
    {"Bob", 12.0},
    {"Charlie", 14.75}
};

// Afficher toute la promo
for (int i = 0; i < N; i++) {
    printf("%s : %.2f\n", promo[i].nom, promo[i].note);
}

// Trouver le meilleur élève
int best = 0;
for (int i = 1; i < N; i++) {
    if (promo[i].note > promo[best].note)
        best = i;
}
printf("Meilleur : %s (%.2f)\n", promo[best].nom, promo[best].note);

6.4 — Passer une structure à une fonction

Par valeur vs par pointeur
typedef struct {
    char nom[50];
    int age;
} Personne;

// Par VALEUR : copie la structure (ne modifie pas l'original)
void afficher(Personne p) {
    printf("%s (%d ans)\n", p.nom, p.age);
}

// Par POINTEUR : modifie l'original (plus efficace)
void vieillir(Personne *p) {
    p->age++;  // ← Notation FLÈCHE pour pointeur de structure !
}

int main() {
    Personne alice = {"Alice", 20};
    afficher(alice);        // Alice (20 ans)
    vieillir(&alice);
    afficher(alice);        // Alice (21 ans) ← Modifié !
    return 0;
}
Mnémonique — Point vs Flèche
  • objet.champ → variable directe (le point est simple comme l'accès direct)
  • pointeur->champ → via pointeur (la flèche suit le chemin vers l'adresse)

En fait, p->age est un raccourci pour (*p).age.

6.5 — Structures imbriquées

Structure dans une structure
typedef struct {
    int jour, mois, annee;
} Date;

typedef struct {
    char nom[50];
    Date naissance;   // Structure imbriquée !
    float moyenne;
} Etudiant;

Etudiant e = {"Alice", {15, 3, 2004}, 15.5};

printf("%s, née le %02d/%02d/%d\n", 
       e.nom, 
       e.naissance.jour,    // Deux points successifs
       e.naissance.mois, 
       e.naissance.annee);
// Alice, née le 15/03/2004
Conseil : Utilisez les structures imbriquées pour modéliser des données complexes. C'est un premier pas vers la programmation orientée objet que vous verrez en C++ (chapitre 8).

6.6 — Complément : Énumérations (enum)

enum — des constantes nommées
// Définir des valeurs symboliques
typedef enum {
    LUNDI, MARDI, MERCREDI, JEUDI,   // 0, 1, 2, 3
    VENDREDI, SAMEDI, DIMANCHE        // 4, 5, 6
} Jour;

typedef enum {
    ROUGE = 1,    // Valeur personnalisée
    VERT = 2,
    BLEU = 4
} Couleur;

Jour today = MERCREDI;
if (today == SAMEDI || today == DIMANCHE)
    printf("Week-end !\n");
else
    printf("Jour de cours !\n");  // ← Exécuté
Utilité de enum : Au lieu d'écrire if (jour == 3) (que veut dire 3 ?), on écrit if (jour == MERCREDI) — beaucoup plus lisible !

Exercices guidés pas à pas

✏️ Exercice guidé — Gestion d'étudiants avec structures

Objectif : Créer un tableau de structures et trouver le meilleur étudiant.

Étape 1 — Définir la structure :

typedef struct {
    char nom[50];
    int note;
} Etudiant;

Étape 2 — Créer et remplir le tableau :

Etudiant classe[3] = {
    {"Alice", 15},
    {"Bob", 18},
    {"Clara", 12}
};

Étape 3 — Trouver le meilleur :

int meilleur_idx = 0;
for (int i = 1; i < 3; i++) {
    if (classe[i].note > classe[meilleur_idx].note)
        meilleur_idx = i;
}
printf("Meilleur : %s (%d/20)\n", classe[meilleur_idx].nom,
       classe[meilleur_idx].note);
// Meilleur : Bob (18/20)

✏️ Exercice guidé — Structure avec typedef et fonction

Objectif : Passer une structure à une fonction.

typedef struct {
    float x, y;
} Point;

float distance(Point a, Point b) {
    float dx = b.x - a.x;
    float dy = b.y - a.y;
    return sqrt(dx*dx + dy*dy);  // #include <math.h>
}

Point p1 = {0, 0}, p2 = {3, 4};
printf("Distance = %.1f\n", distance(p1, p2));  // 5.0
💡 Pour modifier la structure originale dans la fonction, passez un pointeur : void deplacer(Point *p) et utilisez p->x.
