8.1 — Du C au C++ : quoi de neuf ?

Analogie — La maison rénovée

Le C est une maison solide mais basique. Le C++ est cette même maison rénovée et agrandie : mêmes fondations, mais avec une cuisine équipée (classes), un système domotique (héritage), et un ascenseur (polymorphisme). Tout le C valide fonctionne en C++ !

CC++
printf / scanfcout / cin
#include <stdio.h>#include <iostream>
struct (données)class (données + méthodes)
Passage par pointeurPassage par référence (&)
malloc / freenew / delete
Fichier .cFichier .cpp
Premier programme C++
#include <iostream>   // Remplace stdio.h
using namespace std;   // Pour éviter std:: partout

int main() {
    cout << "Hello, C++ !" << endl;
    return 0;
}

// Compilation : g++ hello.cpp -o hello
Mnémonique — cout = C Output, cin = C Input
  • cout << → les flèches « poussent » les données vers la sortie (écran)
  • cin >> → les flèches « aspirent » les données depuis l'entrée (clavier)

8.2 — cout et cin : entrées/sorties modernes

cout et cin
#include <iostream>
#include <string>     // Pour std::string
using namespace std;

int main() {
    // Affichage avec cout
    int age = 20;
    double note = 15.5;
    cout << "Age: " << age << ", Note: " << note << endl;
    
    // Pas besoin de %d, %f, %s ! cout détecte le type automatiquement

    // Lecture avec cin
    string nom;    // string au lieu de char[] !
    cout << "Votre nom : ";
    cin >> nom;
    
    int annee;
    cout << "Année de naissance : ";
    cin >> annee;
    
    cout << "Bonjour " << nom << " (" << (2024-annee) << " ans)" << endl;
    
    // Lire une ligne complète (avec espaces)
    string ville;
    cout << "Ville : ";
    getline(cin, ville);  // Remplace fgets
    
    return 0;
}

🎉 L'avantage de string en C++

En C++, string remplace les char[]. Plus besoin de strlen, strcpy, strcmp !

string vs char[]
string a = "Hello";
string b = " World";

string c = a + b;        // Concaténation avec + !
int len = c.length();    // Longueur (remplace strlen)
if (a == "Hello") { }    // Comparaison avec == (remplace strcmp)

// Plus besoin de se soucier de la taille !
// string gère la mémoire automatiquement

8.3 — Les références (&)

Analogie — Le surnom

En C, pour modifier une variable dans une fonction, on passe un pointeur (*p). En C++, la référence est un alias (surnom) : un deuxième nom pour la même variable. Plus simple, plus propre, pas besoin de * et & partout.

Référence vs Pointeur
// EN C : pointeur (lourd)
void doublerC(int *p) {
    *p = *p * 2;
}
int x = 5;
doublerC(&x);  // x = 10

// EN C++ : référence (élégant)
void doublerCpp(int &n) {   // & dans la déclaration = référence
    n = n * 2;              // Pas de * nécessaire !
}
int y = 5;
doublerCpp(y);  // y = 10  — pas de & à l'appel !

// Swap en C++ avec références
void swap(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}
Mnémonique — Pointeur vs Référence
  • Pointeur (C) : déclaration *p, passer &x, utiliser *p → 3 symboles !
  • Référence (C++) : déclaration &n, passer x, utiliser n → 1 seul symbole

8.4 — Classes et objets

Analogie — Le moule à gâteau

Une classe est un moule (plan, modèle). Un objet est un gâteau fait avec ce moule. Un moule peut produire autant de gâteaux que vous voulez, chacun avec ses propres garnitures (valeurs).

📦 Classe = struct + fonctions + protection

En C, un struct ne contient que des données. En C++, une class contient des données (attributs) ET des fonctions (méthodes), avec un contrôle d'accès (public/private).

Première classe C++
class Etudiant {
private:           // Attributs cachés (encapsulation)
    string nom;
    float note;

public:            // Accessible de l'extérieur
    // Constructeur (appelé à la création)
    Etudiant(string n, float no) {
        nom = n;
        note = no;
    }

    // Méthodes (fonctions de la classe)
    void afficher() {
        cout << nom << " : " << note << "/20" << endl;
    }

    float getNote() { return note; }        // Getter
    void setNote(float n) { note = n; }     // Setter

    bool estAdmis() { return note >= 10; }
};

int main() {
    // Créer des objets (instances)
    Etudiant alice("Alice", 15.5);
    Etudiant bob("Bob", 8.0);

    alice.afficher();  // Alice : 15.5/20
    bob.afficher();    // Bob : 8/20

    cout << "Alice admise ? " << (alice.estAdmis() ? "Oui" : "Non") << endl;

    bob.setNote(12.0);
    bob.afficher();    // Bob : 12/20
    return 0;
}
Mnémonique — P.A.M.C. (les 4 éléments d'une classe)
  • Private — attributs cachés (protection)
  • Attributs — les données (variables)
  • Méthodes — les fonctions
  • Constructeur — initialise l'objet à la création

8.5 — Encapsulation (public/private)

Analogie — Le distributeur de billets

Un distributeur (GAB) : vous accédez au public (écran, clavier, fente). Le mécanisme interne (compteur de billets, coffre) est private — vous n'y touchez pas directement ! C'est la protection des données.

AccèsDepuis la classeDepuis l'extérieur
public✅ Oui✅ Oui
private✅ Oui❌ Non
protected✅ Oui❌ Non (mais oui pour les classes filles)
Getters et Setters
class CompteBancaire {
private:
    float solde;   // Personne ne peut modifier directement !

public:
    CompteBancaire(float s) : solde(s) {}  // Constructeur avec liste d'init.

    float getSolde() { return solde; }     // Lecture autorisée
    
    void deposer(float montant) {
        if (montant > 0) solde += montant; // Validation !
    }
    
    bool retirer(float montant) {
        if (montant > 0 && montant <= solde) {
            solde -= montant;
            return true;
        }
        return false;  // Refusé !
    }
};

int main() {
    CompteBancaire c(1000);
    // c.solde = -999;  // ❌ ERREUR : private !
    c.deposer(500);     // ✅ Via la méthode publique
    cout << c.getSolde() << endl;  // 1500
    return 0;
}

8.6 — Aperçu de l'héritage

Analogie — L'arbre généalogique

L'héritage est comme la génétique : un enfant hérite des caractéristiques de son parent (yeux, taille) mais peut avoir ses propres traits. La classe fille récupère tout de la classe mère et ajoute ses spécificités.

Héritage simple
// Classe mère (base)
class Animal {
protected:
    string nom;
public:
    Animal(string n) : nom(n) {}
    void manger() { cout << nom << " mange." << endl; }
};

// Classe fille (dérivée) — hérite de Animal
class Chien : public Animal {
public:
    Chien(string n) : Animal(n) {}   // Appelle le constructeur parent
    void aboyer() { cout << nom << " : Wouf !" << endl; }
};

class Chat : public Animal {
public:
    Chat(string n) : Animal(n) {}
    void miauler() { cout << nom << " : Miaou !" << endl; }
};

int main() {
    Chien rex("Rex");
    rex.manger();   // Hérité de Animal !
    rex.aboyer();   // Propre à Chien

    Chat mimi("Mimi");
    mimi.manger();  // Hérité
    mimi.miauler(); // Propre à Chat
    return 0;
}
L'héritage en un mot : class Fille : public Mere signifie « Fille possède tout ce que Mere a, plus ses propres ajouts ». C'est le pilier de la Programmation Orientée Objet (POO).

Exercices guidés pas à pas

✏️ Exercice guidé — Classe Rectangleavec encapsulation

Objectif : Créer une classe C++ avec attributs privés et méthodes.

Étape 1 — Déclarer la classe :

class Rectangle {
private:
    double largeur, hauteur;  // Attributs privés

public:
    // Constructeur
    Rectangle(double l, double h) : largeur(l), hauteur(h) {}

    // Méthodes
    double aire() const { return largeur * hauteur; }
    double perimetre() const { return 2 * (largeur + hauteur); }

    void afficher() const {
        cout << largeur << "x" << hauteur
             << " → Aire=" << aire()
             << ", Périmètre=" << perimetre() << endl;
    }
};

Étape 2 — Utiliser :

Rectangle r1(5, 3);
r1.afficher();  // 5x3 → Aire=15, Périmètre=16

Rectangle r2(10, 2);
r2.afficher();  // 10x2 → Aire=20, Périmètre=24
💡 const après une méthode signifie qu'elle ne modifie pas l'objet — bonne pratique C++ !

✏️ Exercice guidé — Héritage : Forme → Cercle

Objectif : Comprendre l'héritage en C++.

class Forme {
protected:
    string nom;
public:
    Forme(string n) : nom(n) {}
    virtual double aire() const = 0;  // Méthode abstraite
    void afficher() const {
        cout << nom << " → Aire = " << aire() << endl;
    }
};

class Cercle : public Forme {
    double rayon;
public:
    Cercle(double r) : Forme("Cercle"), rayon(r) {}
    double aire() const override { return 3.14159 * rayon * rayon; }
};

Cercle c(5);
c.afficher();  // Cercle → Aire = 78.5398
💡 virtual + = 0 rend la méthode abstraite. override vérifie à la compilation que l'on redéfinit bien une méthode du parent.
