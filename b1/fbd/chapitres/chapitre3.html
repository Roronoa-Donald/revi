Chapitre 3

💻 SQL — Fondamentaux

CREATE, SELECT, INSERT, UPDATE, DELETE — les commandes de base pour manipuler une base de données.

Objectifs du chapitre

  • Écrire des requêtes SELECT avec WHERE et ORDER BY
  • Utiliser les fonctions d'agrégation (COUNT, SUM, AVG, MAX, MIN)
  • Maîtriser GROUP BY et HAVING

Qu'est-ce que SQL ?

🔧 Analogie AutoBot : SQL est le langage universel pour parler aux bases de données. Comme l'anglais est la langue internationale des affaires, SQL est la langue internationale des données.

SQL = Structured Query Language (Langage de Requête Structuré). Inventé dans les années 1970, il est compris par TOUS les SGBD relationnels.

🧠 Mnémonique D.M.C.

DDL — ML — CL

DDL = Data Definition Language (CREATE, ALTER, DROP) — structure
DML = Data Manipulation Language (SELECT, INSERT, UPDATE, DELETE) — données
DCL = Data Control Language (GRANT, REVOKE) — droits

DDL — Créer et modifier

CREATE TABLE

SQL — CREATE TABLE
CREATE TABLE etudiants (
    id        SERIAL PRIMARY KEY,
    nom       VARCHAR(50) NOT NULL,
    prenom    VARCHAR(50) NOT NULL,
    email     VARCHAR(100) UNIQUE,
    age       INTEGER CHECK (age >= 16),
    date_insc DATE DEFAULT CURRENT_DATE
);

ALTER TABLE & DROP TABLE

SQL — ALTER & DROP
-- Ajouter une colonne
ALTER TABLE etudiants ADD COLUMN telephone VARCHAR(15);

-- Supprimer une colonne
ALTER TABLE etudiants DROP COLUMN telephone;

-- Renommer
ALTER TABLE etudiants RENAME COLUMN nom TO last_name;

-- Supprimer une table (⚠️ irréversible !)
DROP TABLE etudiants;
⚠️ DROP TABLE supprime la table ET toutes ses données. Pas de Ctrl+Z ! En production, on ajoute IF EXISTS pour éviter les erreurs.

INSERT — Insérer des données

SQL — INSERT
-- Insertion complète (tous les attributs sauf SERIAL)
INSERT INTO etudiants (nom, prenom, email, age)
VALUES ('Dupont', 'Marie', 'marie@univ.fr', 19);

-- Insertion multiple
INSERT INTO etudiants (nom, prenom, email, age) VALUES
    ('Ali', 'Ben', 'ali@univ.fr', 20),
    ('Chen', 'Wei', 'wei@univ.fr', 21),
    ('Diallo', 'Ami', 'ami@univ.fr', 18);
💡 Bonne pratique : Toujours lister les colonnes dans INSERT — ça protège contre les changements de structure et rend le code plus lisible.

SELECT — Interroger

🧠 Mnémonique S.F.W.O.L.

SELECT — FROM — WHERE — ORDER BY — LIMIT

L'ordre des clauses dans une requête SELECT simple.

SQL — SELECT
-- Tout sélectionner
SELECT * FROM etudiants;

-- Colonnes spécifiques
SELECT nom, prenom, age FROM etudiants;

-- Avec filtre
SELECT nom, prenom FROM etudiants WHERE age >= 20;

-- Tri
SELECT nom, age FROM etudiants ORDER BY age DESC;

-- Limiter les résultats
SELECT * FROM etudiants ORDER BY nom LIMIT 10;

-- Alias
SELECT nom AS "Nom de famille", age AS "Âge" FROM etudiants;

-- Valeurs distinctes
SELECT DISTINCT ville FROM etudiants;

Opérateurs WHERE

OpérateurSignificationExemple
=, !=Égal, différentWHERE age = 20
<, >, <=, >=ComparaisonWHERE age >= 18
AND, OR, NOTLogiqueWHERE age > 18 AND ville = 'Paris'
BETWEENIntervalle inclusWHERE age BETWEEN 18 AND 25
INListe de valeursWHERE ville IN ('Paris','Lyon')
LIKEMotif (% = n car., _ = 1 car.)WHERE nom LIKE 'D%'
IS NULLTeste NULL (≠ de = NULL !)WHERE email IS NULL
⚠️ Piège classique : WHERE email = NULL ne fonctionne PAS. Il faut WHERE email IS NULL. Rien n'est égal à NULL, même pas NULL !

UPDATE — Modifier

SQL — UPDATE
-- Modifier un enregistrement
UPDATE etudiants SET age = 21 WHERE id = 1;

-- Modifier plusieurs colonnes
UPDATE etudiants SET email = 'new@univ.fr', age = 22 WHERE id = 1;

-- Modifier plusieurs lignes
UPDATE etudiants SET age = age + 1;  -- ⚠️ TOUTES les lignes !
⚠️ DANGER : Un UPDATE sans WHERE modifie TOUTES les lignes ! Toujours vérifier la clause WHERE avant d'exécuter.

DELETE — Supprimer

SQL — DELETE
-- Supprimer un enregistrement
DELETE FROM etudiants WHERE id = 3;

-- Supprimer avec condition
DELETE FROM etudiants WHERE age < 16;

-- Vider toute la table (⚠️)
DELETE FROM etudiants;

-- Alternative plus rapide pour vider
TRUNCATE TABLE etudiants;  -- remet aussi l'auto-increment

DELETE vs TRUNCATE vs DROP

CommandeEffetWHERE ?Annulable ?

TRUNCATEVide la table entièreNonNon

Exercices guidés

CRUD complet sur une table

Contexte : Gérer une table PRODUIT(id, nom, prix, stock).

CREATE — Créer la table
CREATE TABLE PRODUIT (
    id    INT PRIMARY KEY AUTO_INCREMENT,
    nom   VARCHAR(50) NOT NULL,
    prix  DECIMAL(8,2),
    stock INT DEFAULT 0
);
INSERT — Ajouter des données
INSERT INTO PRODUIT (nom, prix, stock) VALUES
    ('Clavier', 29.99, 150),
    ('Souris', 19.99, 200),
    ('Écran', 249.99, 45);
-- 3 lignes insérées ✓
SELECT — Lire les données
SELECT nom, prix FROM PRODUIT WHERE stock > 100;
-- Résultat :
-- | Clavier | 29.99 |
-- | Souris  | 19.99 |
UPDATE — Modifier
UPDATE PRODUIT SET prix = prix * 0.9 WHERE stock > 100;
-- Clavier : 29.99 → 26.99
-- Souris  : 19.99 → 17.99
-- 2 lignes modifiées ✓
DELETE — Supprimer
DELETE FROM PRODUIT WHERE stock = 0;
-- 0 lignes supprimées (aucun stock à 0)

Requêtes avec WHERE, ORDER BY et LIKE

-- Table EMPLOYE(id, nom, poste, salaire, ville)
-- Trouver les développeurs triés par salaire décroissant
SELECT nom, salaire
FROM EMPLOYE
WHERE poste = 'Développeur'
ORDER BY salaire DESC;

-- Résultat :
-- | Martin  | 3800 |
-- | Dupont  | 3200 |
-- | Leroy   | 2900 |
-- Chercher les noms commençant par 'D'
SELECT nom FROM EMPLOYE WHERE nom LIKE 'D%';
-- Résultat : Dupont, Durand

-- Chercher les noms contenant 'ar'
SELECT nom FROM EMPLOYE WHERE nom LIKE '%ar%';
-- Résultat : Martin, Durand
