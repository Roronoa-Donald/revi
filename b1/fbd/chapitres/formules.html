Formules & Règles essentielles

🗃️ Ch.1 — Modèle relationnel

Schéma :

TABLE(PK, attribut1, #FK, …)

souligné = PK | # = FK

Relations : 1:1 → FK UNIQUE | 1:N → FK côté N | M:N → table de jonction

σ Ch.2 — Algèbre relationnelle

Unaires :

σ_condition (R) → filtre lignes
π_colonnes (R) → filtre colonnes

Jointure :

R1 ⋈_θ R2 = σ_θ (R1 × R2)

💻 Ch.3 — SQL Fondamentaux

SELECT cols FROM table WHERE cond ORDER BY col LIMIT n;
INSERT INTO t (cols) VALUES (vals);
UPDATE t SET col=val WHERE cond;
DELETE FROM t WHERE cond;

🔗 Ch.4 — SQL Avancé

Ordre exécution :

FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY→LIMIT

WHERE = avant groupement | HAVING = après groupement

🧹 Ch.5 — Normalisation

La clé, toute la clé, rien que la clé :

1NF = atomique | 2NF = pas partiel | 3NF = pas transitif

DF transitive : A → B → C → séparer

🏗️ Ch.6 — Conception

Processus :

Analyse → MCD → MLD → MPD → Normaliser

Contraintes : Entité (PK) + Référentielle (FK) + Domaine (CHECK) + Utilisateur (TRIGGER)
