Chapitre 1

🐍 Variables & Types

Les bases absolues de Python : afficher, stocker des données, comprendre les types.

Objectifs du chapitre

  • Installer Python et configurer l'environnement
  • Comprendre la syntaxe de base : print, input, commentaires
  • Manipuler les types de base : int, float, str, bool

Pourquoi Python ?

🐍 Le langage couteau-suisse

Python est comme un couteau suisse : simple à utiliser mais incroyablement puissant. Il est utilisé partout : web, IA, data science, automatisation, cybersécurité…

Contrairement au C, Python n'a pas besoin de compilateur. Vous écrivez, vous exécutez. C'est un langage interprété.

Analogie : Si le C est une voiture manuelle (précise mais complexe), Python est une voiture automatique : facile au départ, très efficace au quotidien.
Mon premier programme
print("Hello, World!")   # C'est tout ! Pas de main(), pas de ;
# En C il fallait : #include, int main(), printf, return 0...

Variables — des boîtes étiquetées

📦 Analogie de la boîte

Une variable est une boîte avec une étiquette. L'étiquette est le nom, le contenu est la valeur. En Python, pas besoin de dire quel type sera dans la boîte — Python le devine tout seul !

Déclaration de variables
nom = "Alice"        # str (texte)
age = 20             # int (entier)
taille = 1.75        # float (décimal)
etudiant = True      # bool (vrai/faux)

# Pas de int, float, char... Python devine !
# C'est le TYPAGE DYNAMIQUE
⚠️ Règles de nommage :
  • Commence par une lettre ou _ (pas un chiffre !)
  • Pas d'espaces ni caractères spéciaux
  • Convention : snake_case (mon_age, pas monAge)
  • Python est sensible à la casse : age ≠ Age ≠ AGE

Les 4 types de base — I.F.S.B.

🧠 Mnémonique I.F.S.B.

Int · Float · Str · Bool — les 4 types fondamentaux de Python, comme les 4 éléments de la programmation !

TypeDescriptionExempleVérifier
intEntier42, -7type(42) → <class 'int'>
floatDécimal3.14, -0.5type(3.14) → <class 'float'>
strTexte (chaîne)"Hello", 'Oui'type("Hi") → <class 'str'>

💡 Astuce : La fonction type(x) vous dit TOUJOURS le type d'une variable. Utilisez-la quand vous avez un doute !

Afficher et Lire — print() & input()

print() — afficher
# Basique
print("Bonjour !")

# Plusieurs valeurs
nom = "Alice"
age = 20
print("Je suis", nom, "j'ai", age, "ans")

# f-string (⭐ LA méthode moderne)
print(f"Je suis {nom}, j'ai {age} ans")
# Accolades = trou à remplir automatiquement

🎯 f-strings — la méthode moderne

Pensez aux f-strings comme un texte à trous : vous mettez un f devant les guillemets, puis chaque {variable} est automatiquement remplacée par sa valeur. C'est comme Mad Libs en programmation !

input() — lire une saisie
# input() retourne TOUJOURS un str !
nom = input("Votre nom : ")      # "Alice" → str
age = input("Votre âge : ")      # "20" → str (pas int !)

# ⚠️ PIÈGE CLASSIQUE :
# age + 1 → ERREUR ! "20" + 1 = impossible

# Solution : convertir !
age = int(input("Votre âge : "))   # "20" → 20 (int)
taille = float(input("Taille : ")) # "1.75" → 1.75 (float)
⚠️ Piège n°1 du débutant : input() retourne TOUJOURS un str ! Pour calculer, convertissez avec int() ou float().

Opérateurs

🐍 vs C : En Python, 7 / 2 = 3.5 (division réelle). En C, 7 / 2 = 3 (division entière). Python a // pour la division entière et ** pour la puissance (pas besoin de pow()).
Opérateurs sur les strings
# Concaténation
prenom = "Alice"
message = "Bonjour " + prenom    # "Bonjour Alice"

# Répétition
ligne = "-" * 30                  # "------------------------------"

# ⚠️ Interdit : "Age: " + 20     → TypeError !
# Solution : "Age: " + str(20)   ou f"Age: {20}"

Conversions de types

Casting en Python
# str → int
age = int("20")          # 20

# str → float
prix = float("19.99")    # 19.99

# int/float → str
texte = str(42)           # "42"

# Vérification
type(age)                 # <class 'int'>
isinstance(age, int)      # True

🔄 Règle simple

Le nom du type sert de fonction de conversion : int(), float(), str(), bool(). C'est plus intuitif qu'en C !

ConversionRésultatPiège ?
int("42")42✅ OK
int("3.14")❌ ValueErrorPasser par float d'abord !
int(3.9)3Tronque (ne pas arrondir) !
bool(0)False0, "", [], None → False
bool(42)TrueTout le reste → True

Exercices guidés pas à pas

✏️ Exercice guidé — Calculer l'âge dans 10 ans

Objectif : Demander l'âge à l'utilisateur et afficher son âge dans 10 ans.

Étape 1 — Lire l'entrée :

age_texte = input("Quel est votre âge ? ")
print(type(age_texte))  # <class 'str'> ← ATTENTION !
⚠️ Piège : input() retourne TOUJOURS un str, même si on tape un nombre !

Étape 2 — Convertir en entier :

age = int(age_texte)  # Conversion str → int

Étape 3 — Calculer et afficher :

futur = age + 10
print(f"Dans 10 ans, vous aurez {futur} ans.")

Code complet :

age = int(input("Quel est votre âge ? "))
futur = age + 10
print(f"Dans 10 ans, vous aurez {futur} ans.")

Exécution : Quel est votre âge ? 20 → Dans 10 ans, vous aurez 30 ans.

✏️ Exercice guidé — Convertisseur °C → °F

Objectif : Convertir des degrés Celsius en Fahrenheit.

Étape 1 — Lire un nombre décimal :

celsius = float(input("Température en °C : "))
💡 On utilise float() car la température peut être décimale (ex: 36.5).

Étape 2 — Appliquer la formule F = C × 9/5 + 32 :

fahrenheit = celsius * 9 / 5 + 32

Étape 3 — Afficher avec arrondi :

print(f"{celsius}°C = {round(fahrenheit, 1)}°F")

Exécution : 100 → 100.0°C = 212.0°F ✓
