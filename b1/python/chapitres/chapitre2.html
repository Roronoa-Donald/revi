Chapitre 2

🐍 Les Conditions

Apprendre à votre programme à prendre des décisions : if, elif, else et opérateurs logiques.

Objectifs du chapitre

  • Déclarer des variables et comprendre le typage dynamique
  • Maîtriser les opérations sur les chaînes et les f-strings
  • Effectuer des conversions de types

Prendre des décisions

🚦 Analogie du feu tricolore

Un programme sans conditions est une route en ligne droite. Les conditions sont les feux tricolores : selon la situation, on va à gauche, à droite ou tout droit.

if / else — la base
age = int(input("Votre âge : "))

if age >= 18:
    print("Vous êtes majeur ✅")
else:
    print("Vous êtes mineur ❌")

# ⚠️ INDENTATION OBLIGATOIRE !
# Python utilise l'indentation (4 espaces) au lieu des { }
⚠️ Règle d'or Python : L'indentation remplace les accolades { }. Si le code n'est pas correctement indenté → IndentationError. Utilisez 4 espaces (ou Tab configuré à 4).

elif — plusieurs chemins

🔀 Analogie du menu

Imaginez un menu de restaurant : si plat 1 disponible → le prendre, sinon si plat 2 → sinon si plat 3 → sinon "rien ne convient". C'est exactement if / elif / else.

if / elif / else
note = float(input("Note /20 : "))

if note >= 16:
    mention = "Très Bien"
elif note >= 14:
    mention = "Bien"
elif note >= 12:
    mention = "Assez Bien"
elif note >= 10:
    mention = "Passable"
else:
    mention = "Recalé(e)"

print(f"Mention : {mention}")

# ⚠️ L'ordre compte ! Testez du plus grand au plus petit
# car Python s'arrête au PREMIER elif vrai
💡 Astuce : elif = "else if" en abrégé. Vous pouvez en mettre autant que nécessaire. Le else final est optionnel mais recommandé.

Opérateurs logiques — and, or, not

Combiner des conditions
age = 20
permis = True

# and : les DEUX doivent être vraies
if age >= 18 and permis:
    print("Vous pouvez conduire")

# or : au moins UNE doit être vraie
if age < 12 or age > 65:
    print("Tarif réduit")

# not : inverse la condition
if not permis:
    print("Pas de permis !")

# 🐍 Python vs C :
# Python : and, or, not (mots anglais !)
# C      : &&, ||, !    (symboles)
PythonC/C++Signification
and&&ET logique
or||OU logique
not!NON logique

Expression conditionnelle (ternaire)

Ternaire Python vs C
# Python : valeur_si_vrai if condition else valeur_si_faux
statut = "majeur" if age >= 18 else "mineur"

# C : condition ? vrai : faux
# Python inverse l'ordre : valeur PUIS condition !
Mnémonique : En Python, on écrit comme on parle : « majeur si age >= 18, sinon mineur ».

Astuces Python uniques

in et chaînes de comparaison
# 'in' : tester l'appartenance (super utile !)
fruit = "pomme"
if fruit in ["pomme", "banane", "orange"]:
    print("C'est un fruit connu !")

# Chaîne de comparaison (exclusif à Python !)
note = 15
if 10 <= note <= 20:
    print("Note valide")
# En C il faudrait : if (note >= 10 && note <= 20)
💡 Super-pouvoir Python : L'opérateur in cherche un élément dans une liste, un tuple ou une chaîne. "a" in "chat" → True

match-case (Python 3.10+)

Le switch de Python
commande = input("Commande : ")

match commande:
    case "aide":
        print("Liste des commandes...")
    case "quitter":
        print("Au revoir !")
    case "version":
        print("v1.0")
    case _:
        print("Commande inconnue")
        # _ = default (comme en C avec switch/default)
Note : match-case existe depuis Python 3.10. Avant, on utilisait des chaînes de if/elif. Pas de break nécessaire contrairement au switch C !

Exercices guidés pas à pas

✏️ Exercice guidé — Calculatrice de tarif cinéma

Objectif : Afficher le tarif selon l'âge : enfant (<12), adulte (12-64), senior (65+).

Étape 1 — Lire l'âge :

age = int(input("Votre âge : "))

Étape 2 — Enchaîner les conditions avec elif :

if age < 12:
    tarif = 5
    categorie = "Enfant"
elif age < 65:
    tarif = 10
    categorie = "Adulte"
else:
    tarif = 7
    categorie = "Senior"
💡 L'ordre des elif est important ! Python s'arrête à la première condition vraie.

Étape 3 — Afficher :

print(f"Catégorie : {categorie} → Tarif : {tarif}€")

Exécutions :

  • 8 ans → Enfant → 5€
  • 30 ans → Adulte → 10€
  • 70 ans → Senior → 7€

✏️ Exercice guidé — Vérificateur de mot de passe

Objectif : Vérifier qu'un mot de passe respecte 3 critères.

Étape 1 — Définir les critères :

mdp = input("Mot de passe : ")

assez_long = len(mdp) >= 8
a_chiffre = any(c.isdigit() for c in mdp)
a_majuscule = any(c.isupper() for c in mdp)

Étape 2 — Vérifier avec des opérateurs logiques :

if assez_long and a_chiffre and a_majuscule:
    print("✅ Mot de passe valide !")
else:
    print("❌ Mot de passe invalide :")
    if not assez_long:
        print("  - Au moins 8 caractères requis")
    if not a_chiffre:
        print("  - Au moins un chiffre requis")
    if not a_majuscule:
        print("  - Au moins une majuscule requise")

Exécution : abc → ❌ (3 erreurs). MonPass1 → ✅

Récapitulatif

📝 L'essentiel du Chapitre 2

  • if / elif / else — structure de décision (indentation !)
  • Comparaison : == != < > <= >=

  • Ternaire : valeur if condition else autre
  • in : vérifier l'appartenance
  • Python permet 10 <= x <= 20 directement
  • match-case : switch Python (3.10+), pas de break
