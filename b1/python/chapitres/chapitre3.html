🐍 Les Boucles

Répéter automatiquement des actions : for, while, range et compréhensions de listes.

La boucle for — parcourir

🎠 Analogie du manège

La boucle for est comme un manège : on sait à l'avance combien de tours on va faire. Chaque tour, on prend l'élément suivant.

for … in — la star de Python
# Parcourir une séquence
for fruit in ["pomme", "banane", "orange"]:
    print(fruit)

# Parcourir une chaîne
for lettre in "Python":
    print(lettre, end=" ")  # P y t h o n

# for en Python ≠ for en C
# Python : for élément in collection
# C      : for (i=0; i<n; i++)  → plus complexe !
range() — générer des nombres
# range(stop) → 0, 1, 2, ..., stop-1
for i in range(5):
    print(i)              # 0 1 2 3 4 (PAS 5 !)

# range(start, stop)
for i in range(1, 6):
    print(i)              # 1 2 3 4 5

# range(start, stop, step)
for i in range(0, 10, 2):
    print(i)              # 0 2 4 6 8

# Compte à rebours
for i in range(5, 0, -1):
    print(i)              # 5 4 3 2 1

🧠 Mnémonique R.D.F. — range(Début, Fin, Pas)

Range prend jusqu'à 3 arguments : Début (inclus, défaut 0), Fin (exclu !), Pas (défaut 1). Retenir : la Fin est toujours exclue, comme une porte fermée 🚪.

La boucle while — tant que

⏳ Analogie du réveil

while c'est comme un réveil qui sonne tant qu'on ne l'a pas éteint. On ne sait pas combien de fois il va sonner — ça dépend de quand on appuie sur le bouton.

while — quand on ne sait pas combien de tours
# Demander jusqu'à obtenir la bonne réponse
reponse = ""
while reponse != "Python":
    reponse = input("Quel langage ? ")
print("Bravo ! 🎉")

# Attention à la boucle infinie !
# while True:
#     print("Je ne m'arrête jamais !")  # ❌ Ctrl+C !
UtiliserQuandExemple
forOn connaît le nombre de toursParcourir une liste, range(n)
whileOn ne sait pas quand arrêterAttendre une saisie correcte

break & continue

Contrôler la boucle
# break = SORTIR immédiatement
for n in range(1, 100):
    if n == 5:
        break           # Sort de la boucle
    print(n)            # Affiche 1 2 3 4

# continue = PASSER au tour suivant
for n in range(1, 6):
    if n == 3:
        continue        # Saute le 3
    print(n)            # Affiche 1 2 4 5

# 🎯 Résumé :
# break    = "J'en ai assez, je sors !"
# continue = "Je saute celui-ci, au suivant !"

enumerate() et zip()

Outils pro pour les boucles
# enumerate : indice + valeur (au lieu de range(len(..)))
fruits = ["pomme", "banane", "orange"]
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
# 0: pomme   1: banane   2: orange

# zip : parcourir 2 listes en parallèle
noms = ["Alice", "Bob", "Clara"]
notes = [15, 17, 12]
for nom, note in zip(noms, notes):
    print(f"{nom} : {note}/20")
💡 Règle d'or : Si vous écrivez for i in range(len(liste)) puis liste[i], utilisez plutôt enumerate(). C'est plus Pythonic !

Compréhensions de listes

⚡ Le super-pouvoir de Python

Les compréhensions de listes sont un raccourci magique pour créer des listes en une seule ligne. C'est comme une recette de cuisine compressée !

List comprehension
# Méthode classique (3 lignes)
carres = []
for x in range(1, 6):
    carres.append(x ** 2)

# Compréhension de liste (1 ligne !)
carres = [x ** 2 for x in range(1, 6)]
# [1, 4, 9, 16, 25]

# Avec condition (filtre)
pairs = [x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]

# 📝 Formule : [expression for var in iterable if condition]

🧠 Lire une compréhension

Lisez-la comme une phrase : [x**2 for x in range(5) if x > 0] → « Prends x², pour chaque x de 0 à 4, si x > 0 ».

Boucles imbriquées

Boucle dans une boucle
# Table de multiplication
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} × {j} = {i*j}", end="\t")
    print()  # Saut de ligne

# 1 × 1 = 1   1 × 2 = 2   1 × 3 = 3
# 2 × 1 = 2   2 × 2 = 4   2 × 3 = 6
# 3 × 1 = 3   3 × 2 = 6   3 × 3 = 9

# Analogie : l'aiguille des minutes fait 60 tours
# pour CHAQUE tour de l'aiguille des heures

Exercices guidés pas à pas

✏️ Exercice guidé — Jeu "Deviner le nombre"

Objectif : L'ordinateur choisit un nombre entre 1 et 100, le joueur doit le deviner.

Étape 1 — Générer le nombre secret :

import random
secret = random.randint(1, 100)
tentatives = 0

Étape 2 — Boucle while avec break :

while True:
    proposition = int(input("Votre nombre : "))
    tentatives += 1

    if proposition < secret:
        print("⬆️ Plus grand !")
    elif proposition > secret:
        print("⬇️ Plus petit !")
    else:
        print(f"🎉 Bravo ! Trouvé en {tentatives} tentatives !")
        break  # Sort de la boucle
💡 while True + break est un patron courant pour les boucles dont on ne connaît pas le nombre d'itérations.

✏️ Exercice guidé — Table de multiplication avec for

Objectif : Afficher la table de multiplication d'un nombre choisi.

Étape 1 — Lire le nombre :

n = int(input("Table de : "))

Étape 2 — Boucle for avec range :

for i in range(1, 11):
    resultat = n * i
    print(f"{n} × {i} = {resultat}")

Exécution pour n = 7 :

7 × 1 = 7
7 × 2 = 14
...
7 × 10 = 70

Bonus — Avec compréhension de liste :

resultats = [n * i for i in range(1, 11)]
for i, val in enumerate(resultats, start=1):
    print(f"{n} × {i} = {val}")
