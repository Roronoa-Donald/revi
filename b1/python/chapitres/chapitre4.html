Chapitre 4

🐍 Les Fonctions

Découper votre code en blocs réutilisables : def, return, paramètres, lambda.

Objectifs du chapitre

  • Maîtriser les boucles for et while
  • Utiliser range(), break, continue
  • Créer des compréhensions de listes

Pourquoi des fonctions ?

🧩 Analogie des recettes de cuisine

Imaginez que vous faites souvent des crêpes. Plutôt que de réécrire la recette à chaque fois, vous la notez UNE FOIS et vous dites simplement « faire des crêpes ». Une fonction, c'est exactement ça : une recette nommée que vous pouvez appeler quand vous voulez.

🧠 Mnémonique R.L.T. — 3 raisons

Réutiliser (écrire une seule fois, appeler plusieurs fois) · Lire (code plus clair et organisé) · Tester (chaque fonction se teste séparément)

Créer une fonction — def

Syntaxe de base
# Définir une fonction
def dire_bonjour():
    print("Bonjour ! 👋")

# Appeler la fonction
dire_bonjour()      # Affiche "Bonjour ! 👋"
dire_bonjour()      # On peut l'appeler autant de fois qu'on veut

# Avec paramètre
def dire_bonjour(nom):
    print(f"Bonjour {nom} !")

dire_bonjour("Alice")   # Bonjour Alice !
dire_bonjour("Bob")     # Bonjour Bob !
return — renvoyer un résultat
# Sans return → la fonction FAIT quelque chose (affiche, etc.)
def afficher_carre(n):
    print(n ** 2)

# Avec return → la fonction CALCULE et RENVOIE un résultat
def carre(n):
    return n ** 2

resultat = carre(5)     # resultat = 25
print(carre(3) + carre(4))  # 9 + 16 = 25

# ⚠️ Différence fondamentale :
# print() → affiche à l'écran (pas réutilisable)
# return  → renvoie une valeur (réutilisable dans des calculs)
⚠️ Piège n°1 : print() ≠ return. Si vous faites print() au lieu de return, la fonction ne renvoie rien (None) et vous ne pourrez pas réutiliser le résultat dans un calcul.

Paramètres avancés

Valeurs par défaut et nommés
# Paramètre avec valeur par défaut
def saluer(nom, lang="fr"):
    if lang == "fr":
        print(f"Bonjour {nom} !")
    else:
        print(f"Hello {nom}!")

saluer("Alice")          # Bonjour Alice ! (fr par défaut)
saluer("Bob", "en")      # Hello Bob!

# Arguments nommés (keyword arguments)
saluer(lang="en", nom="Clara")  # Ordre libre !

# Retour multiple (tuple)
def min_max(liste):
    return min(liste), max(liste)

petit, grand = min_max([3, 1, 7, 2])
print(petit, grand)  # 1 7
🐍 Super-pouvoir Python : Une fonction peut retourner plusieurs valeurs grâce au tuple. return a, b et on récupère avec x, y = f().

*args et **kwargs

Nombre variable d'arguments
# *args : nombre variable d'arguments positionnels
def somme(*args):
    total = 0
    for n in args:
        total += n
    return total

print(somme(1, 2))         # 3
print(somme(1, 2, 3, 4))   # 10

# **kwargs : arguments nommés variables
def fiche(**kwargs):
    for cle, valeur in kwargs.items():
        print(f"{cle} : {valeur}")

fiche(nom="Alice", age=20, ville="Paris")
# nom : Alice
# age : 20
# ville : Paris

📦 Analogie de la valise

*args = une valise ouverte : on peut y mettre autant d'objets qu'on veut, sans les nommer.
**kwargs = une valise avec des étiquettes : chaque objet a un nom.

Portée des variables

Local vs Global
x = 10  # Variable GLOBALE

def f():
    x = 5    # Variable LOCALE (différente !)
    print(x) # 5

f()
print(x)     # 10 (le global n'a pas changé)

# Pour modifier le global depuis une fonction :
def g():
    global x
    x = 99

g()
print(x)     # 99

# ⚠️ Évitez global autant que possible !
# Préférez passer en paramètre et return

🏠 Analogie des pièces

Variable locale = un objet dans une pièce (visible uniquement dans cette pièce).
Variable globale = un objet dans le couloir (visible partout, mais on préfère ne pas y toucher).

Fonctions lambda (anonymes)

Mini-fonctions en une ligne
# Fonction classique
def double(x):
    return x * 2

# Même chose en lambda
double = lambda x: x * 2
print(double(5))  # 10

# Utile pour sort, map, filter
noms = ["Clara", "alice", "Bob"]
noms.sort(key=lambda s: s.lower())
print(noms)  # ['alice', 'Bob', 'Clara']

# Formule : lambda paramètres: expression
carre = lambda x: x ** 2
somme = lambda a, b: a + b
Quand utiliser lambda : Pour des fonctions simples d'une seule expression, souvent passées en argument (sort, map, filter). Pour le reste, utilisez def classique.

Documenter — docstrings

Bonne pratique
def moyenne(notes):
    """
    Calcule la moyenne d'une liste de notes.
    
    Args:
        notes (list): Liste de nombres
    
    Returns:
        float: La moyenne des notes
    """
    return sum(notes) / len(notes)

# Accéder à la doc
help(moyenne)
print(moyenne.__doc__)
💡 Règle pro : Documentez vos fonctions avec des docstrings (triple guillemets). Ça aide les autres (et vous dans 6 mois !).

Exercices guidés pas à pas

✏️ Exercice guidé — Mini-calculatrice avec fonctions

Objectif : Créer 4 fonctions arithmétiques et les appeler.

Étape 1 — Définir les fonctions :

def additionner(a, b):
    # Retourne la somme de a et b
    return a + b

def diviser(a, b):
    # Retourne a/b avec protection
    if b == 0:
        return "Erreur : division par zéro !"
    return a / b

Étape 2 — Menu interactif :

a = float(input("Premier nombre : "))
b = float(input("Deuxième nombre : "))
op = input("Opération (+, -, *, /) : ")

if op == "+":
    print(f"Résultat : {additionner(a, b)}")
elif op == "/":
    print(f"Résultat : {diviser(a, b)}")

Exécution : 10 / 0 → Erreur : division par zéro !

✏️ Exercice guidé — Fonction statistiques avec *args

Objectif : Une fonction qui accepte un nombre variable de notes.

Étape 1 — Définir avec *args :

def stats(*notes):
    # Retourne (min, max, moyenne) des notes
    if len(notes) == 0:
        return None
    return min(notes), max(notes), sum(notes) / len(notes)

Étape 2 — Appeler et unpacker :

minimum, maximum, moyenne = stats(12, 15, 8, 19, 14)
print(f"Min: {minimum}, Max: {maximum}, Moyenne: {moyenne}")
# Min: 8, Max: 19, Moyenne: 13.6

Bonus — Avec une liste existante :

mes_notes = [12, 15, 8, 19, 14]
resultat = stats(*mes_notes)  # * "déballe" la liste
💡 L'opérateur * devant une liste la "déballe" en arguments individuels.

Récapitulatif

📝 L'essentiel du Chapitre 4

  • def nom(params): — définir une fonction
  • return renvoie une valeur (≠ print qui affiche)
  • Valeurs par défaut : def f(x, y=10)
  • Retour multiple : return a, b
  • *args = arguments illimités, **kwargs = nommés
  • Local vs Global — évitez global
  • lambda x: expr — fonction anonyme en une ligne
  • Docstrings pour documenter vos fonctions
