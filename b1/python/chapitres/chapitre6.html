Chapitre 6

🐍 Dictionnaires & Sets

Stocker des données en paires clé:valeur et manipuler des ensembles uniques.

Objectifs du chapitre

  • Maîtriser listes, tuples, dictionnaires et ensembles
  • Choisir la bonne structure selon le besoin
  • Utiliser les méthodes principales de chaque type

Dictionnaire — clé : valeur

📖 Analogie du vrai dictionnaire

Un dictionnaire Python fonctionne comme un vrai dictionnaire : vous cherchez un mot (la clé) pour trouver sa définition (la valeur). Pas besoin de feuilleter page par page — accès instantané !

Créer et accéder
# Créer un dictionnaire
etudiant = {
    "nom": "Alice",
    "age": 20,
    "notes": [15, 17, 12]
}

# Accéder par la clé (PAS par indice !)
print(etudiant["nom"])      # "Alice"
print(etudiant["age"])      # 20

# ⚠️ Clé inexistante → KeyError !
# print(etudiant["ville"])  # ❌ KeyError

# Solution sûre : .get()
print(etudiant.get("ville", "Inconnue"))  # "Inconnue" (défaut)

# Modifier / Ajouter
etudiant["age"] = 21            # Modifier
etudiant["ville"] = "Paris"     # Ajouter (si clé n'existe pas)

# Supprimer
del etudiant["ville"]           # Supprime la clé
note = etudiant.pop("age")      # Supprime et retourne la valeur

Méthodes du dictionnaire — K.V.I.

🧠 Mnémonique K.V.I.

Keys · Values · Items — les 3 vues essentielles d'un dictionnaire.

Les 3 vues
d = {"nom": "Alice", "age": 20, "note": 15}

d.keys()       # dict_keys(["nom", "age", "note"])
d.values()     # dict_values(["Alice", 20, 15])
d.items()      # dict_items([("nom","Alice"), ("age",20), ("note",15)])

# Parcourir un dictionnaire
for cle in d:               # Parcourt les CLÉS par défaut
    print(cle)

for cle, val in d.items():  # Clé ET valeur
    print(f"{cle} : {val}")

# Vérifier qu'une clé existe
if "nom" in d:
    print("La clé 'nom' existe !")

# Nombre de paires
len(d)  # 3
MéthodeRetourne
.keys()Toutes les clés
.values()Toutes les valeurs
.items()Paires (clé, valeur)
.get(clé, défaut)Valeur ou défaut si absente
.update(autre_dict)Fusionne deux dicts
.pop(clé)Supprime et retourne

Dict comprehension

Créer un dict en une ligne
# Classique
carres = {}
for x in range(1, 6):
    carres[x] = x ** 2

# Compréhension de dictionnaire (1 ligne !)
carres = {x: x**2 for x in range(1, 6)}
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Avec condition
pairs = {x: x**2 for x in range(10) if x % 2 == 0}
# {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}

Les sets — ensembles uniques

🎨 Analogie du sac de billes

Un set est un sac de billes sans doublons : chaque élément est unique. Si vous essayez de mettre deux billes rouges, il n'en gardera qu'une. Et l'ordre n'est pas garanti !

Sets
# Créer un set
fruits = {"pomme", "banane", "orange", "pomme"}
print(fruits)  # {"pomme", "banane", "orange"} — pas de doublon !

# Set vide (⚠️ pas {}, c'est un dict vide !)
vide = set()

# Ajouter / Supprimer
fruits.add("kiwi")
fruits.discard("banane")  # Pas d'erreur si absent

# Supprimer les doublons d'une liste !
nombres = [1, 2, 2, 3, 3, 3]
uniques = list(set(nombres))  # [1, 2, 3]
Opérations ensemblistes
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a | b    # Union : {1,2,3,4,5,6}
a & b    # Intersection : {3,4}
a - b    # Différence : {1,2}
a ^ b    # Symétrique : {1,2,5,6}

# Sous-ensemble
{1, 2} <= {1, 2, 3}  # True (sous-ensemble)
OpérationSymboleMéthode
Uniona | ba.union(b)
Intersectiona & ba.intersection(b)
Différencea - ba.difference(b)
Symétriquea ^ ba.symmetric_difference(b)

Exercices guidés pas à pas

✏️ Exercice guidé — Compteur de mots dans une phrase

Objectif : Compter l'occurrence de chaque mot avec un dictionnaire.

Étape 1 — Découper la phrase :

phrase = "le chat mange le poisson et le chat dort"
mots = phrase.split()

Étape 2 — Construire le compteur :

compteur = {}
for mot in mots:
    compteur[mot] = compteur.get(mot, 0) + 1
💡 .get(mot, 0) retourne 0 si la clé n'existe pas (évite le KeyError !).

Étape 3 — Afficher trié par fréquence :

for mot, count in sorted(compteur.items(), key=lambda x: x[1], reverse=True):
    print(f"  '{mot}' → {count} fois")

Résultat : 'le' → 3 fois, 'chat' → 2 fois, 'mange' → 1 fois...

✏️ Exercice guidé — Amis communs avec les sets

Objectif : Utiliser les opérations ensemblistes.

Étape 1 — Définir les ensembles :

amis_alice = {"Bob", "Clara", "David", "Emma"}
amis_bob   = {"Alice", "Clara", "Frank", "Emma"}

Étape 2 — Opérations ensemblistes :

communs   = amis_alice & amis_bob    # Intersection → {'Clara', 'Emma'}
tous      = amis_alice | amis_bob    # Union
exclusifs = amis_alice - amis_bob    # Différence → {'Bob', 'David'}
symetrique = amis_alice ^ amis_bob   # Différence symétrique

Résultat : Amis communs : {'Clara', 'Emma'}

Récapitulatif

📝 L'essentiel du Chapitre 6

  • Dict {"clé": valeur} — accès par clé, pas par indice
  • .get(clé, défaut) évite les KeyError
  • K.V.I. : .keys(), .values(), .items()
  • Parcours : for k, v in d.items()
  • Set {} : pas de doublons, pas d'ordre
  • Opérations : | union, & intersection, - différence
  • Supprimer les doublons : list(set(liste))
