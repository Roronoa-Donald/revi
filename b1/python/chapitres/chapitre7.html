Chapitre 7

🐍 Fichiers & Exceptions

Lire et écrire dans des fichiers, gérer les erreurs proprement avec try/except.

Objectifs du chapitre

  • Lire et écrire des fichiers avec open() et with
  • Gérer les erreurs avec try / except / finally
  • Comprendre les types d'exceptions courants

Ouvrir un fichier — with open()

📓 Analogie du cahier

Un fichier c'est comme un cahier : vous devez l'ouvrir, le lire ou écrire, puis le refermer. En Python, with le referme automatiquement (pas de fclose() à oublier !).

La syntaxe magique : with
# ⭐ LA bonne façon (fermeture automatique)
with open("fichier.txt", "r") as f:
    contenu = f.read()
# Le fichier est automatiquement fermé ici !

# Modes d'ouverture
# "r"  → Read (lire, défaut)
# "w"  → Write (écrire, ÉCRASE !)
# "a"  → Append (ajouter à la fin)
# "r+" → Read + Write

🧠 Mnémonique R.W.A. (comme en C !)

Read · Write (écrase !) · Append — les mêmes modes qu'en C mais avec with en bonus pour la fermeture auto.

Lire un fichier

3 façons de lire
# 1. Tout lire d'un coup
with open("notes.txt", "r") as f:
    contenu = f.read()          # Tout en une string
    print(contenu)

# 2. Lire ligne par ligne (mémoire OK)
with open("notes.txt", "r") as f:
    for ligne in f:             # ⭐ Meilleure méthode !
        print(ligne.strip())    # .strip() enlève le \n

# 3. Toutes les lignes en liste
with open("notes.txt", "r") as f:
    lignes = f.readlines()      # Liste de strings
    print(lignes[0])            # Première ligne
💡 Bonnes pratiques : Utilisez for ligne in f: pour les gros fichiers (lit une ligne à la fois, économise la mémoire). .strip() supprime les espaces et \n en début/fin.

Écrire dans un fichier

Écrire et ajouter
# Écrire (écrase le fichier !)
with open("resultats.txt", "w") as f:
    f.write("Alice : 15/20\n")
    f.write("Bob : 17/20\n")

# Ajouter à la fin
with open("resultats.txt", "a") as f:
    f.write("Clara : 12/20\n")

# Écrire plusieurs lignes
lignes = ["Ligne 1\n", "Ligne 2\n", "Ligne 3\n"]
with open("multi.txt", "w") as f:
    f.writelines(lignes)

# ⚠️ f.write() n'ajoute PAS de \n automatiquement !
# Contrairement à print(), il faut les mettre soi-même
⚠️ Piège : Le mode "w" écrase tout le contenu existant ! Pour ajouter sans écraser, utilisez "a" (append).

Fichiers CSV et JSON

CSV (valeurs séparées par des virgules)
import csv

# Écrire du CSV
with open("etudiants.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["Nom", "Note"])  # En-tête
    writer.writerow(["Alice", 15])
    writer.writerow(["Bob", 17])

# Lire du CSV
with open("etudiants.csv", "r") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)  # ["Nom", "Note"], ["Alice", "15"]...
JSON (format universel)
import json

# Sauvegarder un dict en JSON
data = {"nom": "Alice", "notes": [15, 17, 12]}
with open("data.json", "w") as f:
    json.dump(data, f, indent=2)  # indent = joli format

# Charger depuis JSON
with open("data.json", "r") as f:
    data = json.load(f)
    print(data["nom"])  # "Alice"

# 🐍 json.dump() = sauvegarder, json.load() = charger
# dump = écrire, load = lire

Exceptions — try/except

🛡️ Analogie du filet de sécurité

try/except est un filet de sécurité sous un trapéziste : si une erreur se produit (chute), le programme ne crash pas — le filet la rattrape et vous décidez quoi faire.

Gérer les erreurs
# Sans try/except → crash !
# n = int(input("Nombre : "))  # Si on tape "abc" → ValueError

# Avec try/except → sécurisé
try:
    n = int(input("Nombre : "))
    print(f"Vous avez saisi : {n}")
except ValueError:
    print("❌ Ce n'est pas un nombre !")

# Plusieurs types d'erreurs
try:
    f = open("inexistant.txt", "r")
    contenu = f.read()
except FileNotFoundError:
    print("Fichier introuvable !")
except PermissionError:
    print("Accès refusé !")
except Exception as e:
    print(f"Erreur inattendue : {e}")
finally:
    print("Ce bloc s'exécute TOUJOURS")
    # Idéal pour fermer des ressources
ExceptionCause
ValueErrorValeur invalide (int("abc"))
TypeErrorType incompatible ("a" + 1)
ZeroDivisionErrorDivision par zéro
FileNotFoundErrorFichier introuvable
KeyErrorClé absente dans un dict
IndexErrorIndice hors limites

Lever ses propres exceptions — raise

raise
def diviser(a, b):
    if b == 0:
        raise ValueError("Division par zéro interdite !")
    return a / b

try:
    print(diviser(10, 0))
except ValueError as e:
    print(f"Erreur : {e}")
# Erreur : Division par zéro interdite !

Exercices guidés pas à pas

✏️ Exercice guidé — Mini carnet de contacts JSON

Objectif : Sauvegarder et charger un carnet de contacts.

Étape 1 — Créer et sauvegarder :

import json

contacts = {
    "Alice": {"tel": "0612345678", "email": "alice@mail.com"},
    "Bob":   {"tel": "0698765432", "email": "bob@mail.com"}
}

with open("contacts.json", "w") as f:
    json.dump(contacts, f, indent=4, ensure_ascii=False)

Étape 2 — Charger et modifier :

try:
    with open("contacts.json", "r") as f:
        contacts = json.load(f)
except FileNotFoundError:
    contacts = {}

contacts["Clara"] = {"tel": "0611111111", "email": "clara@mail.com"}
💡 Toujours utiliser try/except quand on ouvre un fichier — il pourrait ne pas exister !

Étape 3 — Re-sauvegarder :

with open("contacts.json", "w") as f:
    json.dump(contacts, f, indent=4, ensure_ascii=False)
print(f"{len(contacts)} contacts sauvegardés.")  # 3

✏️ Exercice guidé — Lire un CSV de notes

Objectif : Lire un fichier CSV, parser les notes et calculer la moyenne.

Étape 1 — Lire et parser avec gestion d'erreurs :

import csv

notes = []
with open("notes.csv", "r") as f:
    lecteur = csv.reader(f)
    next(lecteur)  # Sauter l'en-tête
    for ligne in lecteur:
        try:
            notes.append(float(ligne[1]))
        except ValueError:
            print(f"⚠️ Note invalide pour {ligne[0]}")

Étape 2 — Calculer :

if notes:
    print(f"Moyenne : {sum(notes)/len(notes):.1f}/20")
else:
    print("Aucune note valide.")

Sortie : ⚠️ Note invalide pour David puis Moyenne : 14.8/20

Récapitulatif

📝 L'essentiel du Chapitre 7

  • with open("f", "r") as f: — ouvre et ferme auto
  • Modes R.W.A. : Read, Write (écrase !), Append
  • Lire : f.read(), for ligne in f, f.readlines()
  • Écrire : f.write("...") (pas de \n auto)
  • csv : csv.reader/writer pour les tableaux
  • json : json.dump/load pour les dicts
  • try/except : attrape les erreurs sans crash
  • finally : s'exécute toujours
  • raise : lever ses propres erreurs
