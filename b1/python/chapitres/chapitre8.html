Modules — import

📦 Analogie de la boîte à outils

Un module est une boîte à outils déjà prête. Au lieu de fabriquer chaque outil, vous importez la boîte (import math) et utilisez ses outils (math.sqrt()). Python est livré avec des centaines de boîtes !

Importer un module
# 1. Importer tout le module
import math
print(math.sqrt(16))   # 4.0
print(math.pi)         # 3.141592653589793

# 2. Importer une fonction spécifique
from math import sqrt, pi
print(sqrt(16))        # 4.0 — pas besoin de "math."

# 3. Renommer un module (alias)
import random as rd
print(rd.randint(1, 6))  # Dé à 6 faces

# 4. Tout importer (⚠️ déconseillé)
from math import *       # Pollution du namespace

🧠 Mnémonique I.F.A. (Import)

Import complet · From (sélectif) · Alias (renommer) — les 3 façons d'importer un module.

Créer ses propres modules

mon_module.py
# mon_module.py — C'est juste un fichier .py !
def saluer(nom):
    return f"Bonjour, {nom} !"

def carre(n):
    return n ** 2

PI = 3.14159
main.py — utiliser le module
# main.py (même dossier que mon_module.py)
import mon_module

print(mon_module.saluer("Alice"))  # "Bonjour, Alice !"
print(mon_module.carre(5))        # 25

# ou plus sélectif :
from mon_module import saluer, PI
print(saluer("Bob"))  # "Bonjour, Bob !"
💡 Règle : Un module = un fichier .py. Le nom du module = le nom du fichier (sans .py). C'est aussi simple que ça !

Introduction à la POO — Classes

🏠 Analogie du plan de maison

Une classe est un plan d'architecte. Un objet est une maison construite à partir de ce plan. Avec un même plan, on peut construire plusieurs maisons, chacune avec ses propres couleurs (attributs) et fonctionnalités (méthodes).

Première classe
class Etudiant:
    def __init__(self, nom, age):  # Constructeur
        self.nom = nom             # Attribut
        self.age = age             # Attribut
    
    def se_presenter(self):        # Méthode
        return f"Je suis {self.nom}, {self.age} ans"
    
    def est_majeur(self):
        return self.age >= 18

# Créer des objets (instances)
alice = Etudiant("Alice", 20)
bob = Etudiant("Bob", 17)

print(alice.se_presenter())  # "Je suis Alice, 20 ans"
print(bob.est_majeur())      # False
print(alice.nom)              # "Alice"

🧠 Mnémonique C.I.A.M. (Classe)

Classe (le plan) → Init (le constructeur) → Attributs (les données) → Méthodes (les actions). Et self = « moi-même » — chaque objet se réfère à lui-même.

self — la clé de la POO

Comprendre self
class Compteur:
    def __init__(self):
        self.valeur = 0   # Chaque compteur a SA propre valeur
    
    def incrementer(self):
        self.valeur += 1   # self = "moi-même" (cet objet)
    
    def afficher(self):
        print(f"Compteur : {self.valeur}")

c1 = Compteur()
c2 = Compteur()

c1.incrementer()  # c1.valeur = 1
c1.incrementer()  # c1.valeur = 2
c2.incrementer()  # c2.valeur = 1

c1.afficher()  # "Compteur : 2"
c2.afficher()  # "Compteur : 1"
# Chaque objet a ses propres données !
⚠️ Piège : self est le premier paramètre de chaque méthode de classe. Oubliez-le et Python lèvera une erreur ! Mais quand vous appelez la méthode, vous ne le passez pas — Python le fait automatiquement.

Héritage — spécialiser une classe

🧬 Analogie de l'arbre généalogique

Un enfant hérite des caractéristiques de ses parents mais peut avoir des traits propres. En POO, une classe enfant hérite des attributs et méthodes de la classe parent et peut les modifier ou en ajouter.

Héritage simple
class Animal:  # Classe parent
    def __init__(self, nom):
        self.nom = nom
    
    def parler(self):
        return "..."

class Chien(Animal):  # Hérite de Animal
    def parler(self):  # Redéfinition (override)
        return f"{self.nom} dit Wouf !"

class Chat(Animal):
    def parler(self):
        return f"{self.nom} dit Miaou !"
    
    def ronronner(self):  # Méthode propre
        return "Rrrrrr..."

rex = Chien("Rex")
mimi = Chat("Mimi")

print(rex.parler())      # "Rex dit Wouf !"
print(mimi.parler())     # "Mimi dit Miaou !"
print(mimi.ronronner())  # "Rrrrrr..."
print(rex.nom)           # "Rex" — hérité de Animal

Exercices guidés pas à pas

✏️ Exercice guidé — Système de personnages (POO)

Objectif : Créer une hiérarchie de classes avec héritage.

Étape 1 — Classe de base :

class Personnage:
    def __init__(self, nom, pv=100, attaque=10):
        self.nom = nom
        self.pv = pv
        self.attaque = attaque

    def attaquer(self, cible):
        cible.pv -= self.attaque
        print(f"{self.nom} attaque {cible.nom} ! (-{self.attaque} PV)")

Étape 2 — Classe Mage (héritage) :

class Mage(Personnage):
    def __init__(self, nom, pv=80, attaque=8, mana=50):
        super().__init__(nom, pv, attaque)
        self.mana = mana

    def lancer_sort(self, cible, degats=25):
        if self.mana >= 10:
            self.mana -= 10
            cible.pv -= degats
            print(f"🔮 {self.nom} lance un sort ! (-{degats} PV)")
        else:
            print(f"{self.nom} n'a plus de mana !")
💡 super().__init__(...) appelle le constructeur parent pour initialiser les attributs communs.

Étape 3 — Simuler un combat :

guerrier = Personnage("Aragorn", pv=120, attaque=15)
mage = Mage("Gandalf")

mage.lancer_sort(guerrier)  # 🔮 Gandalf lance un sort ! (-25 PV)
guerrier.attaquer(mage)     # Aragorn attaque Gandalf ! (-15 PV)
# Aragorn: 95 PV | Gandalf: 65 PV, 40 mana

✏️ Exercice guidé — Créer et importer un module

Objectif : Créer un module et l'importer de 3 façons.

Étape 1 — Créer outils.py :

# outils.py
def moyenne(*notes):
    return sum(notes) / len(notes) if notes else 0

def est_premier(n):
    if n < 2: return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0: return False
    return True

Étape 2 — 3 styles d'import :

# Style 1 : import module
import outils
print(outils.moyenne(12, 15, 18))  # 15.0

# Style 2 : from ... import ...
from outils import est_premier
print(est_premier(17))  # True

# Style 3 : alias
import outils as o
print(o.moyenne(10, 20))  # 15.0
⚠️ Évitez from outils import * — ça importe tout et peut créer des conflits de noms !
