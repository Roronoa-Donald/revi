Chapitre 3

🌐 Adressage IPv4

Comprendre les adresses IP, les classes, les masques, et les adresses privées.

Objectifs du chapitre

  • Comprendre le rôle de la couche liaison et les adresses MAC
  • Maîtriser le fonctionnement des trames et du switch
  • Configurer des VLAN et comprendre STP

Qu'est-ce qu'une adresse IP ?

📮 Analogie de l'adresse postale

Chaque maison a une adresse postale unique. De la même façon, chaque appareil sur un réseau a une adresse IP unique. Elle permet d'identifier qui envoie et qui reçoit les données.

Format IPv4
192.168.1.100

4 octets séparés par des points
Chaque octet = 0 à 255
Total = 32 bits

En binaire : 11000000.10101000.00000001.01100100

Classes d'adresses IP

Classe1er octetMasque par défautUsage
A1 – 126255.0.0.0 (/8)Très grands réseaux
B128 – 191255.255.0.0 (/16)Grands réseaux
C192 – 223255.255.255.0 (/24)Petits réseaux
D224 – 239—Multicast
E240 – 255—Réservé/Expérimental

🧠 Mnémonique pour les plages

Classe A : commence par 1 (1-126)
Classe B : 128-191 (après 127 = loopback)
Classe C : 192-223 (le plus courant en LAN !)

⚠️ 127.x.x.x est réservé pour le loopback (boucle locale). 127.0.0.1 = « moi-même » (localhost).

Le masque de sous-réseau

🏘️ Analogie du code postal

Dans « 75001 Paris », le 75 = département (partie réseau), le 001 = arrondissement (partie hôte). Le masque fait pareil : il sépare la partie réseau de la partie hôte dans l'adresse IP.

Exemple avec /24
IP :     192.168.1.100
Masque : 255.255.255.0  (= /24)

Partie réseau : 192.168.1  (les 24 premiers bits)
Partie hôte :   .100       (les 8 derniers bits)

→ Réseau : 192.168.1.0
→ Broadcast : 192.168.1.255
→ Hôtes utilisables : .1 à .254 (254 hôtes)
💡 Formule : Nombre d'hôtes = 2n – 2 (où n = bits pour la partie hôte). On retire 2 : l'adresse réseau et le broadcast.

Adresses privées vs publiques

ClassePlage privéeCIDR

🧠 Mnémonique « 10, 172, 192 »

Les 3 plages privées : 10.x.x.x · 172.16-31.x.x · 192.168.x.x
Votre box utilise probablement 192.168.x.x !

ℹ️ Privé = pas routable sur Internet. Pour sortir sur Internet, un routeur fait du NAT (Network Address Translation) : il remplace l'IP privée par l'IP publique.

Conversion binaire ↔ décimale

Comprendre le binaire est essentiel pour maîtriser les masques et le subnetting. Chaque octet = 8 bits, chaque bit a une valeur positionnelle :

Table des puissances de 2 (à connaître par cœur !)
Position :   7     6     5     4     3    2    1    0
Valeur :   128    64    32    16     8    4    2    1

Exemple : convertir 192 en binaire
  192 = 128 + 64 = 11000000

Exemple : convertir 10101100 en décimal
  10101100 = 128 + 32 + 8 + 4 = 172

🧠 Les sous-réseaux « magiques »

Les valeurs de masque possibles pour un octet sont toujours :
0 · 128 · 192 · 224 · 240 · 248 · 252 · 254 · 255
Ce sont 256 − 2ⁿ pour n = 0 à 8. Retenez cette série !

L'opération AND (ET logique)

Pour trouver l'adresse réseau à partir d'une IP et son masque, on applique un ET logique bit à bit :

AND logique – Exemple : 192.168.1.130 / 255.255.255.192
Règle AND :  1 AND 1 = 1  |  1 AND 0 = 0  |  0 AND 1 = 0  |  0 AND 0 = 0

IP :     192.168.1.  10000010   (130 en binaire)
Masque : 255.255.255.11000000   (192 = /26)
                    ──────────
AND :    192.168.1.  10000000   = 192.168.1.128  ← adresse réseau !

→ L'hôte 192.168.1.130/26 appartient au réseau 192.168.1.128/26
💡 Raccourci sans binaire : 256 − masque = taille du bloc. 256 − 192 = 64. Quel multiple de 64 ≤ 130 ? → 128. Donc réseau = 192.168.1.128.

Pièges classiques

⚠️ Piège 1 – Classe ≠ masque par défaut en CIDR : En adressage classique, une adresse 10.x.x.x a un masque /8. Mais en CIDR (sans classe), on peut avoir 10.0.0.0/24 ! Ne pas supposer le masque à partir de l'adresse.
⚠️ Piège 2 – Broadcast ≠ dernière adresse du masque : Le broadcast est la dernière adresse de chaque sous-réseau, pas forcément x.x.x.255. Ex: dans /26, le broadcast de 192.168.1.0/26 est 192.168.1.63.
⚠️ Piège 3 – Nombre d'hôtes = 2ⁿ − 2, pas 2ⁿ : On retire toujours 2 adresses : l'adresse réseau (tous les bits hôte à 0) et le broadcast (tous les bits hôte à 1). Un /24 → 2⁸ − 2 = 254 hôtes, pas 256.

Identifier la classe et le réseau

Énoncé : Pour 172.16.254.1/16, trouver la classe, l'adresse réseau et le broadcast.

Étape 1 — Identifier la classe
172 → en binaire : 10101100
Premier bit = 1, deuxième = 0 → Classe B
Classe B : 128.0.0.0 à 191.255.255.255 ✓
Étape 2 — Masque /16
/16 = 255.255.0.0
Les 16 premiers bits = réseau, les 16 derniers = hôte
Étape 3 — Adresse réseau (AND logique)
172.16.254.1    = 10101100.00010000.11111110.00000001
255.255.0.0     = 11111111.11111111.00000000.00000000
AND             = 10101100.00010000.00000000.00000000
→ Réseau = 172.16.0.0
Étape 4 — Broadcast (bits hôte à 1)
Réseau :    172.16.0.0
Broadcast : 172.16.255.255
Plage :     172.16.0.1 à 172.16.255.254
Nb hôtes :  2^16 - 2 = 65 534

Récapitulatif

📝 L'essentiel du Chapitre 3

  • IPv4 = 4 octets, 32 bits (ex: 192.168.1.100)
  • Classes A/B/C pour les réseaux courants
  • Masque = sépare partie réseau et partie hôte
  • Hôtes = 2n – 2 (réseau + broadcast exclus)
  • Privé : 10.x · 172.16-31.x · 192.168.x → NAT pour Internet
  • 127.0.0.1 = localhost
