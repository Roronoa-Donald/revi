Fiches de révision par chapitre

Ch.1 — Modèle OSI

PLRTSPA
  • 7 couches : Physique → Liaison → Réseau → Transport → Session → Présentation → Application
  • Données encapsulées couche par couche (poupées russes)
  • LAN = local, WAN = étendu, MAN = métropolitain

Ch.2 — TCP/IP

ATIA
  • 4 couches : Application, Transport, Internet, Accès réseau
  • TCP = fiable, connexion (3-way handshake : SYN → SYN-ACK → ACK)
  • UDP = rapide, sans connexion (streaming, jeux)
  • Ports clés : 80 (HTTP), 443 (HTTPS), 22 (SSH), 53 (DNS), 25 (SMTP)

Ch.3 — Adressage IPv4

4 octets · 32 bits
  • Classe A : 1.0.0.0 → 126.x.x.x (masque /8)
  • Classe B : 128.0.0.0 → 191.x.x.x (masque /16)
  • Classe C : 192.0.0.0 → 223.x.x.x (masque /24)
  • Privé : 10.x.x.x, 172.16-31.x.x, 192.168.x.x
  • Formule hôtes : 2n − 2 (n = bits hôtes)

Ch.4 — Subnetting

2ⁿ − 2 hôtes
  • CIDR : /24 = 255.255.255.0 = 254 hôtes
  • /25 = 128 − 2 = 126 hôtes
  • /26 = 64 − 2 = 62 hôtes
  • /27 = 32 − 2 = 30 hôtes
  • /28 = 16 − 2 = 14 hôtes
  • /30 = 4 − 2 = 2 hôtes (lien point-à-point)
  • Étapes : bits empruntés → taille bloc → @réseau → @broadcast → plage

Ch.5 — Protocoles

DORA
  • HTTP : requête/réponse, codes 200/301/404/500
  • DNS : nom → IP (records A, AAAA, CNAME, MX, NS)
  • DHCP : attribution auto d'IP (Discover → Offer → Request → Ack)
  • ARP : IP → MAC (broadcast « Qui a cette IP ? »)
  • ICMP : ping, traceroute (diagnostic)

Ch.6 — Équipements

HSR = 1-2-3
  • Hub = couche 1 (broadcast tout, mégaphone)
  • Switch = couche 2 (table MAC, facteur intelligent)
  • Routeur = couche 3 (table de routage, GPS)
  • Pare-feu = filtrage (videur)
  • Point d'accès Wi-Fi, Modem (signal numérique ↔ analogique)

Ch.7 — Sécurité

C.I.D.
  • Symétrique (AES, 1 clé, rapide) vs Asymétrique (RSA, 2 clés)
  • HTTPS = asymétrique + symétrique (hybride)
  • VPN = tunnel chiffré (IPSec, OpenVPN, WireGuard)
  • Attaques : Phishing, DDoS, MitM, ARP Spoofing, Brute Force
  • Protection : HTTPS, 2FA, mots de passe forts, VLAN

Ch.8 — Wi-Fi & Outils

PINTA
  • Normes : b(11Mb) → g(54Mb) → n/Wi-Fi4 → ac/Wi-Fi5 → ax/Wi-Fi6
  • 2.4 GHz (portée) vs 5 GHz (débit)
  • Sécurité : WEP ⛔ → WPA ⚠️ → WPA2 ✅ → WPA3 ✅✅
  • Commandes : ping, ipconfig, nslookup, tracert, arp, netstat
  • Diagnostic bottom-up : câble → IP → passerelle → 8.8.8.8 → DNS
