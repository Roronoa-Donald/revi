Chapitre 2

📊 Tableaux de fréquences

Effectifs, fréquences, fréquences cumulées et regroupement en classes.

Objectifs du chapitre

  • Calculer les effectifs et fréquences cumulés
  • Construire et interpréter un diagramme cumulatif
  • Lire des quartiles et la médiane sur une courbe

Tableau de distribution

📦 Analogie du tri de bonbons

Vous avez un sac de 20 bonbons de 4 couleurs. Trier et compter chaque couleur = construire un tableau de distribution. Le tableau répond à « combien de chaque ? » et « quelle proportion ? ».

Exemple : Notes obtenues à un test (sur 5) par 20 élèves :

Note (xᵢ)Effectif (nᵢ)Fréquence (fᵢ)Fréq. cumulée (Fᵢ)
122/20 = 0.100.10
233/20 = 0.150.25
377/20 = 0.350.60
455/20 = 0.250.85
533/20 = 0.151.00
Total201.00—

Les formules clés

🧠 Mnémonique E.F.C. — Effectif, Fréquence, Cumulée

Effectif : nᵢ = combien d'individus ont la valeur xᵢ
Fréquence : fᵢ = nᵢ / N (proportion)
Cumulée : Fᵢ = f₁ + f₂ + … + fᵢ (cumul progressif)

Formules de base
Effectif total :      N = Σ nᵢ = n₁ + n₂ + ... + nₖ

Fréquence :           fᵢ = nᵢ / N

Fréquence en % :      fᵢ% = (nᵢ / N) × 100

Fréquence cumulée :   Fᵢ = f₁ + f₂ + ... + fᵢ

Effectif cumulé :     Nᵢ = n₁ + n₂ + ... + nᵢ

Vérifications :       Σ nᵢ = N
                      Σ fᵢ = 1
                      Fₖ = 1 (dernière cumulée)
ℹ️ Vérifications : Σnᵢ = N (somme des effectifs = total). Σfᵢ = 1 (somme des fréquences = 1). La dernière fréquence cumulée = 1.

💡 Centre de classe : cᵢ = (borne inf + borne sup) / 2. Exemple : (150 + 160) / 2 = 155. On utilise le centre pour les calculs de moyenne.
⚠️ Notation [a ; b[ : Le crochet [ inclut la valeur, le crochet [ l'exclut. Donc [160 ; 170[ inclut 160 mais pas 170.

Choisir le nombre et la largeur des classes

Règle de Sturges
Nombre de classes k :   k ≈ 1 + 3.322 × log₁₀(N)

Amplitude de classe h : h = (max − min) / k

Exemples :
  N = 20  → k ≈ 1 + 3.322 × 1.30 ≈ 5.3 → ~5 classes
  N = 50  → k ≈ 1 + 3.322 × 1.70 ≈ 6.6 → ~7 classes
  N = 100 → k ≈ 1 + 3.322 × 2.00 ≈ 7.6 → ~8 classes
💡 Astuce pratique : Si les données vont de 150 à 190 cm et qu'on veut ~4 classes : h = (190 − 150) / 4 = 10 cm. Classes : [150;160[, [160;170[, [170;180[, [180;190].
ℹ️ Règle de bon sens : Pas trop de classes (sinon tableau illisible), pas trop peu (sinon perte d'information). En général, entre 5 et 15 classes convient.

Pièges classiques à l'examen

⚠️ Piège n°1 — Oublier que Σfᵢ = 1 : Si la somme de vos fréquences ne fait pas 1 (arrondi près), c'est qu'il y a une erreur de calcul. Vérifiez TOUJOURS !
⚠️ Piège n°2 — Confondre fréquence et effectif : fᵢ = 0.30 ≠ 30 individus. C'est 30% du total. Si N = 50, alors nᵢ = 0.30 × 50 = 15 individus.
⚠️ Piège n°3 — Classes d'amplitudes inégales : Si les classes ont des largeurs différentes, on ne peut pas comparer les effectifs directement. Il faut utiliser la densité = fᵢ / amplitude. C'est essentiel pour les histogrammes !

Récapitulatif

📝 L'essentiel du Chapitre 2

  • E.F.C. : Effectif (nᵢ), Fréquence (nᵢ/N), Cumulée (somme progressive)
  • Σnᵢ = N, Σfᵢ = 1, dernière Fᵢ = 1
  • Classes pour données continues : [a ; b[
  • Centre de classe = (a + b) / 2

Méthode : Construire un Tableau de Fréquences Complet

Données brutes : une liste de N valeurs

Étape 1 : Trier et lister les modalités/classes

  • Données discrètes → lister chaque valeur distincte (xᵢ)
  • Données continues → découper en classes [a ; b[
  • Nombre de classes recommandé ≈ √N (règle de Sturges)

Étape 2 : Compter les effectifs (nᵢ)

  • Bâtonner : |||| pour compter sans se tromper
  • Vérification : Σnᵢ = N (total obligatoire)

Étape 3 : Calculer les fréquences relatives

  • fᵢ = nᵢ / N
  • Vérification : Σfᵢ = 1 (arrondir si nécessaire)

Étape 4 : Fréquences cumulées

  • Nᵢ = n₁ + n₂ + … + nᵢ (effectifs cumulés)
  • Fᵢ = f₁ + f₂ + … + fᵢ (fréquences cumulées)
  • Dernière valeur : Nₖ = N et Fₖ = 1

Étape 5 : Données groupées en classes

  • Centre de classe cᵢ = (borne inf + borne sup) / 2
  • Amplitude = borne sup − borne inf
  • Pour les calculs de moyenne/variance : utiliser les centres de classes

Checklist finale : Σnᵢ = N ? Σfᵢ = 1 ? Dernière cumul = N ?
