Chapitre 6

📊 Corrélation & régression

Nuage de points, coefficient de corrélation et droite de régression.

Nuage de points

📍 Analogie de la carte des étoiles

On a 2 variables (X et Y) mesurées sur les mêmes individus. On place chaque individu comme un point sur un graphique (X en abscisse, Y en ordonnée). L'ensemble forme un nuage de points qui montre la relation entre X et Y.

ℹ️ Exemples : Taille vs poids, heures d'étude vs note, température vs ventes de glaces.

Corrélation

🧠 Mnémonique C.D.P. — Covariance, Droite, Prédiction

Covariance = mesure la liaison entre X et Y
Droite de régression = modèle Y = aX + b
Prédiction = utiliser la droite pour estimer Y à partir de X

🧠 Mnémonique secondaire — Corrélation en 3 mots

Positive = X ↑ Y ↑ (les deux montent ensemble)
Négative = X ↑ Y ↓ (l'une monte, l'autre descend)
Nulle = aucun lien visible (nuage circulaire)

Coefficient de corrélation linéaire (r)

r = Cov(X,Y) / (σₓ × σᵧ)

Où :
Cov(X,Y) = Σ(xᵢ − x̄)(yᵢ − ȳ) / N = [Σ(xᵢ×yᵢ)/N] − x̄×ȳ
σₓ = écart-type de X
σᵧ = écart-type de Y

Propriétés de r :
• -1 ≤ r ≤ +1  (toujours entre -1 et 1)
• |r| proche de 1 → forte corrélation
• |r| proche de 0 → faible ou pas de corrélation
• r > 0 → positive, r < 0 → négative
|r|Interprétation
0.8 – 1.0Corrélation forte
0.5 – 0.8Corrélation modérée
0.2 – 0.5Corrélation faible
0.0 – 0.2Corrélation très faible ou nulle
⚠️ Corrélation ≠ Causalité ! Le nombre de noyades et les ventes de glaces sont corrélés (les deux augmentent en été), mais les glaces ne causent pas les noyades. La cause commune est la chaleur.

Droite de régression (moindres carrés)

📏 Analogie de la tendance

La droite de régression est la « meilleure ligne droite » qui traverse le nuage de points. Elle minimise la somme des distances verticales au carré entre les points et la droite.

Droite Y = aX + b

Pente :     a = Cov(X,Y) / Var(X) = [Σ(xᵢyᵢ)/N − x̄ȳ] / σₓ²
Ordonnée :  b = ȳ − a × x̄

La droite passe TOUJOURS par le point moyen (x̄, ȳ).
💡 Utilité : La droite de régression permet de prédire Y pour une nouvelle valeur de X. Mais attention : ne prédisez pas en dehors de la plage des données (extrapolation risquée) !

Coefficient de détermination R²

Qualité de l'ajustement
R² = r² = (coefficient de corrélation)²

Interprétation :
R² représente la proportion de la variance de Y
expliquée par la relation linéaire avec X.

Exemple : r = 0.90 → R² = 0.81 = 81%
→ 81% de la variation de Y est expliquée par X.
→ 19% reste inexpliqué (autres facteurs).

R² = 1   → ajustement parfait (tous les points sur la droite)
R² = 0   → aucun pouvoir explicatif
R² > 0.7 → bon modèle en général

Pièges classiques à l'examen

⚠️ Piège n°1 — Corrélation ≠ Causalité : Même si r = 0.99, on ne peut pas conclure que X cause Y. Il peut y avoir une variable cachée (confondante). Exemples célèbres : glaces et noyades, cignognes et natalité.
⚠️ Piège n°2 — Extrapolation : La droite est fiable entre les valeurs observées. Prédire Y pour X = 100 si vos données vont de 2 à 8 est très risqué (la relation peut changer).
⚠️ Piège n°3 — Relation non linéaire : r mesure la corrélation linéaire. Si la relation est courbe (parabolique, exponentielle), r peut être faible même si la relation est forte. Toujours regarder le nuage de points d'abord !

Avec les données précédentes, trouver l'équation.

a = Somme[(xi-x̄)(yi-ȳ)] / Somme[(xi-x̄)²]

b = ȳ - a×x̄

Récapitulatif

📝 L'essentiel du Chapitre 6

  • Nuage de points = visualiser la relation entre 2 variables
  • r = Cov(X,Y) / (σₓ × σᵧ), toujours entre -1 et +1
  • |r| proche de 1 = forte corrélation, proche de 0 = faible
  • ⚠️ Corrélation ≠ Causalité
  • Droite Y = aX + b, a = Cov/Var(X), b = ȳ − ax̄
  • La droite passe par (x̄, ȳ)

Méthode : Calculer r et la Droite de Régression

Données : n couples (xᵢ, yᵢ)

Étape 1 : Calculer les moyennes

  • x̄ = Σxᵢ / n et ȳ = Σyᵢ / n

Étape 2 : Remplir le tableau

  • Colonnes : xᵢ, yᵢ, xᵢ², yᵢ², xᵢ·yᵢ
  • Calculer toutes les sommes Σ

Étape 3 : Covariance

  • Cov(X,Y) = (Σxᵢyᵢ / n) − x̄·ȳ

Étape 4 : Écarts-types

  • σₓ = √(Σxᵢ²/n − x̄²) et σᵧ = √(Σyᵢ²/n − ȳ²)

Étape 5 : Coefficient de corrélation

  • r = Cov(X,Y) / (σₓ · σᵧ)
  • |r| proche de 1 → forte corrélation ; proche de 0 → faible

Étape 6 : Droite de régression y = ax + b

  • a = Cov(X,Y) / σₓ² = Cov(X,Y) / Var(X)
  • b = ȳ − a·x̄
  • Vérification : la droite passe par (x̄, ȳ)

Étape 7 : Interpréter

  • R² = r² → % de variance expliquée (ex: R²=0.81 → 81%)
  • a > 0 → relation croissante ; a < 0 → décroissante
