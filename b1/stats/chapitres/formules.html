Fiches par chapitre

Ch.1 — Séries

P.E.I. · Q.Q.
  • Population = tout, Échantillon = sous-groupe, Individu = 1 élément
  • Qualitatif (nominal/ordinal) vs Quantitatif (discret/continu)
  • Effectif (nᵢ), Effectif total (N), Fréquence (fᵢ = nᵢ/N)

Ch.2 — Fréquences

E.F.C.
  • fᵢ = nᵢ / N | Σfᵢ = 1
  • Fᵢ (cumulée) = f₁ + f₂ + … + fᵢ
  • Centre de classe = (a + b) / 2
  • Notation [a ; b[ → a inclus, b exclus

Ch.3 — Tendance centrale

M.M.M.
  • Moyenne : x̄ = Σxᵢ/N = Σ(xᵢ×fᵢ)
  • Moyenne pondérée : Σ(xᵢ×pᵢ) / Σpᵢ
  • Médiane : N impair → rang (N+1)/2. N pair → moyenne des 2 centraux
  • Mode : valeur la plus fréquente

Ch.4 — Dispersion

V.É.R.
  • Étendue : max − min
  • Variance : σ² = Σ(xᵢ−x̄)²/N
  • König : σ² = (Σxᵢ²/N) − x̄²
  • Écart-type : σ = √σ²
  • IQR : Q3 − Q1
  • Outlier : hors [Q1−1.5×IQR ; Q3+1.5×IQR]

Ch.5 — Graphiques

B.C.H.P.
  • Barres (séparées) → discret / qualitatif
  • Circulaire → angle = fᵢ × 360°
  • Histogramme (collé) → continu en classes
  • Polygone → centres reliés
  • Ogive → Fᵢ cumulées, lire médiane à 0.5

Ch.6 — Corrélation

r · Y=aX+b
  • Cov(X,Y) : Σ(xᵢyᵢ)/N − x̄ȳ
  • r : Cov(X,Y) / (σₓ × σᵧ), −1 ≤ r ≤ 1
  • Pente : a = Cov(X,Y) / Var(X)
  • Ordonnée : b = ȳ − a×x̄
  • Droite passe par (x̄, ȳ)
  • ⚠️ Corrélation ≠ Causalité
