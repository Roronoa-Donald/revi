Cartes de Révision & Mémorisation Active — Services Cloud AWS B3

36 fiches synthétiques pour ancrer les concepts fondamentaux de l'architecture et de l'ingénierie Amazon Web Services : Infrastructure globale (Régions, AZs, Edge Locations), Modèle de responsabilité partagée, IAM et politiques JSON, Rôles et gouvernance AWS Organizations/SCPs, Instances EC2 et modèles d'achat (On-Demand/Reserved/Spot), Volumes EBS gp3/io2, Auto Scaling Groups et ALB, Réseau Amazon VPC et 5 IPs réservées, Security Groups avec état et Network ACLs sans état, Classes de stockage S3 et cycle de vie, Bases de données relationnelles RDS multi-AZ et Aurora, NoSQL DynamoDB avec RCU/WCU, Fonctions serverless AWS Lambda, Files d'attente SQS et DLQ, et supervision avec Amazon CloudWatch et CloudTrail.

Module 1 — Fondements & Infrastructure AWS

QuestionQu'est-ce qu'une Région AWS ?
RéponseUn emplacement géographique autonome mondial regroupant au moins 3 Availability Zones isolées reliées par fibre privée.
QuestionQu'est-ce qu'une Availability Zone (AZ) ?
RéponseUn ou plusieurs centres de données discrets au sein d'une région, dotés d'alimentations et de réseaux physiques redondants.
QuestionQuelle est la règle du modèle de responsabilité partagée ?
RéponseAWS est responsable de la sécurité DU cloud (matériel, hyperviseurs) ; le client est responsable de la sécurité DANS le cloud (données, IAM, OS EC2).
QuestionQuels sont les six piliers du Well-Architected Framework ?
RéponseExcellence opérationnelle, Sécurité, Fiabilité, Efficacité des performances, Optimisation des coûts, et Durabilité.
QuestionÀ quoi servent les Edge Locations dans AWS ?
RéponseCe sont des points de présence locaux (PoP) pour mettre en cache du contenu CDN (CloudFront) et accélérer les requêtes DNS (Route 53).
QuestionQuelle commande initialise les identifiants de l'AWS CLI v2 ?
Réponse« aws configure » (stocke les clés dans ~/.aws/credentials et la région par défaut dans ~/.aws/config).

Module 2 — Sécurité IAM & Gouvernance

QuestionQuelle est la différence entre un utilisateur IAM et un rôle IAM ?
RéponseL'utilisateur a des identifiants permanents (mot de passe/clés) ; le rôle utilise des jetons temporaires STS sans mot de passe persistant.
QuestionQuel est l'ordre d'évaluation du moteur d'autorisation IAM ?
Réponse1. Default Deny ; 2. Explicit Deny (priorité absolue) ; 3. Explicit Allow ; 4. Default Deny final si aucun Allow.
QuestionQuels sont les composants clés d'une politique IAM JSON ?
RéponseVersion, Statement : [ { Effect (Allow/Deny), Action, Resource, Condition } ].
QuestionÀ quoi sert une Service Control Policy (SCP) ?
RéponseÀ définir les permissions maximales autorisées (garde-fous) sur les comptes d'une organisation AWS sans accorder de droits directs.
QuestionQu'est-ce qu'un Instance Profile dans EC2 ?
RéponseUn conteneur transmettant un rôle IAM temporaire à une instance EC2 pour éviter de stocker des clés d'accès en dur sur la machine.
QuestionQuelle est la fréquence de rotation recommandée pour les clés IAM ?
Réponse90 jours au maximum pour les clés statiques selon le CIS AWS Benchmark (ou privilégier les rôles sans clé).

Module 3 — Calcul & Conteneurs AWS

QuestionQu'est-ce qu'une instance Spot dans Amazon EC2 ?
RéponseUne instance utilisant la capacité inutilisée d'AWS avec jusqu'à 90% de remise, interruptible avec 2 minutes de préavis.
QuestionQuelles sont les performances de base incluses d'un volume EBS gp3 ?
Réponse3 000 IOPS et 125 MB/s de débit inclus sans surcoût, modulables indépendamment de la taille de stockage.
QuestionQuelle est la différence majeure entre un ALB et un NLB ?
RéponseALB opère en couche 7 (HTTP/HTTPS, routage par URL) ; NLB opère en couche 4 (TCP/UDP, latence ultra-faible, IP statique).
QuestionQuel est le rôle d'un Launch Template pour un Auto Scaling Group ?
RéponseDéfinir la configuration de lancement des instances : AMI, type d'instance, Security Group, rôle IAM et script User Data.
QuestionComment un Auto Scaling Group équilibre-t-il les instances entre les AZs ?
RéponseIl lance les nouvelles instances dans l'Availability Zone qui compte le moins d'instances actives pour éviter tout SPOF.
QuestionQu'est-ce qu'AWS Fargate ?
RéponseUn moteur de calcul serverless pour conteneurs (ECS/EKS) exécutant des applications Docker sans aucune machine virtuelle à gérer.

Module 4 — Réseau Amazon VPC & Sécurité

QuestionCombien d'adresses IP AWS réserve-t-il dans chaque sous-réseau VPC ?
Réponse5 adresses : .0 (réseau), .1 (routeur VPC), .2 (DNS Amazon), .3 (réservé futur), et .255 (broadcast).
QuestionQuelle est la différence fondamentale entre Security Group et Network ACL ?
RéponseSecurity Group = avec état (stateful) au niveau de l'instance ; Network ACL = sans état (stateless) au niveau du sous-réseau.
QuestionQuelle route qualifie un sous-réseau de public ?
RéponseUne route par défaut 0.0.0.0/0 pointant vers une Internet Gateway (igw-xxxx).
QuestionÀ quoi sert une NAT Gateway dans un Amazon VPC ?
RéponseÀ permettre aux instances des sous-réseaux privés d'accéder à Internet en sortie sans accepter de connexions entrantes.
QuestionQu'est-ce que la non-transitivité du VPC Peering ?
RéponseSi A est appairé à B et B à C, A ne peut pas communiquer avec C via B sans établir un lien direct ou utiliser une Transit Gateway.
QuestionPourquoi une NACL sortante doit-elle autoriser les ports éphémères (1024-65535) ?
RéponseCar étant sans état (stateless), la NACL ne mémorise pas la connexion entrante et doit explicitement autoriser le paquet réponse.

Module 5 — Stockage S3, Bases RDS & DynamoDB

QuestionQuelle est la durabilité garantie par Amazon S3 Standard ?
Réponse99.999999999% (11 neuf) par an grâce à la réplication multi-centres de données.
QuestionQuelle est la différence fondamentale entre EBS et EFS ?
RéponseEBS est un stockage bloc lié à une seule instance dans une seule AZ ; EFS est un stockage fichier NFS partagé multi-AZ.
QuestionÀ quoi sert le déploiement RDS Multi-AZ ?
RéponseÀ assurer la haute disponibilité via une réplique synchrone passive Standby avec basculement automatique en cas de panne.
QuestionQuelle est la différence entre RDS Multi-AZ et Read Replicas ?
RéponseMulti-AZ = réplication synchrone pour la résilience ; Read Replica = réplication asynchrone pour la scalabilité des lectures.
QuestionComment se calcule 1 RCU dans Amazon DynamoDB ?
Réponse1 RCU = 1 lecture fortement cohérente par seconde pour un élément jusqu'à 4 KB (ou 2 lectures éventuellement cohérentes).
QuestionQuel est le rôle de S3 Block Public Access ?
RéponseBloquer de manière centralisée toute tentative d'accorder des permissions publiques anonymes sur un bucket ou un objet.

Module 6 — Serverless, Observabilité & IaC

QuestionQuelle est la durée maximale d'exécution d'une fonction AWS Lambda ?
Réponse15 minutes (900 secondes) par invocation au maximum.
QuestionÀ quoi sert une Dead-Letter Queue (DLQ) dans Amazon SQS ?
RéponseÀ isoler automatiquement les messages ayant échoué après un nombre maximal de tentatives (MaxReceiveCount) pour analyse.
QuestionQuelle est la différence clé entre Amazon SQS et Amazon SNS ?
RéponseSQS fonctionne en mode pull (file d'attente consommée par des workers) ; SNS fonctionne en mode push (diffusion Pub/Sub multi-abonnés).
QuestionQuelle est la différence fondamentale entre CloudWatch et CloudTrail ?
RéponseCloudWatch surveille les métriques et les performances des ressources ; CloudTrail audite les appels d'API (qui a fait quoi).
QuestionQu'est-ce que le patron d'architecture Fan-out ?
RéponseLa publication d'un événement dans un topic SNS qui le duplique automatiquement vers plusieurs files SQS abonnées en parallèle.
QuestionComment fonctionne la tarification d'AWS Lambda ?
RéponseFacturation à l'usage combinant le nombre de requêtes (0.20 $/million) et le temps de calcul en Go-secondes.
