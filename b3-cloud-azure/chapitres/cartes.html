Cartes de Révision & Mémorisation Active — Cloud Microsoft Azure B3

36 fiches synthétiques pour ancrer les concepts clés de l'administration Cloud Azure : Hiérarchie ARM, Cloud Adoption Framework, Microsoft Entra ID, Azure RBAC, Azure Policy, Séries de VM, VMSS, VNet, Adresses Réservées, NSG, Blob Storage Lifecycle, SAS Tokens, Azure SQL vs Cosmos DB, Log Analytics KQL et Cost Management.

Module 1 — Architecture, Régions & ARM

QuestionQu'est-ce qu'une Zone de Disponibilité (Availability Zone) Azure et quel SLA garantit-elle ?
RéponseUn datacenter physiquement distinct au sein d'une région, doté d'une alimentation, d'un refroidissement et d'un réseau indépendants. Déployer sur au moins 2 AZs garantit un SLA de 99.99%.
QuestionQuelle est la distance minimale séparant deux régions d'une Paire Régionale (Paired Region) ?
RéponseAu moins 480 kilomètres (300 miles), pour garantir qu'une catastrophe naturelle n'affecte pas simultanément le site de production et le site de reprise (DR).
QuestionQuels sont les 4 niveaux hiérarchiques de gestion organisationnelle sous Azure ARM ?
Réponse1. Root Management Group -> 2. Management Groups (MG) -> 3. Subscriptions (Abonnements) -> 4. Resource Groups (Groupes de ressources).
QuestionQuel est le gabarit de nommage standard CAF pour un groupe de ressources Azure ?
Réponserg---- (exemple : rg-erp-prod-we-01).
QuestionQuelle est la différence fondamentale entre la réplication LRS et ZRS pour Azure Storage ?
RéponseLRS conserve 3 copies dans un seul datacenter (vulnérable à la panne du bâtiment), tandis que ZRS réplique de manière synchrone sur 3 Availability Zones distinctes de la région.
QuestionQu'est-ce que le principe d'Instances Réservées (RI) et quel est son impact financier ?
RéponseUn engagement sur 1 an ou 3 ans sur des capacités de calcul VM prévisibles, offrant entre 35% (1 an) et 60% (3 ans) d'économie sur la part calcul par rapport au Pay-As-You-Go.

Module 2 — Entra ID, RBAC & Gouvernance

QuestionQu'est-ce qu'une Managed Identity Azure et quel problème de sécurité résout-elle ?
RéponseUne identité gérée automatiquement dans Entra ID pour une ressource Azure. Elle supprime le besoin d'enregistrer des clés ou mots de passe en clair dans le code applicatif.
QuestionQuelle est la formule d'évaluation d'une autorisation Azure RBAC ?
RéponseL'action doit correspondre à une règle dans Actions (avec wildcards) et ne correspondre à AUCUNE règle dans NotActions.
QuestionQuelle est la différence fondamentale entre le rôle Owner et le rôle Contributor ?
RéponseOwner peut déléguer des droits et assigner des rôles RBAC à d'autres identités (Microsoft.Authorization/*), tandis que Contributor en est expressément exclu.
QuestionQuelle est la distinction clé entre Azure RBAC et Azure Policy ?
RéponseRBAC gère QUI (les identités autorisées à agir), tandis qu'Azure Policy gère QUOI (les règles de configuration imposées aux ressources déployées).
QuestionQuelles sont les différences entre les verrous CanNotDelete et ReadOnly ?
RéponseCanNotDelete autorise les modifications mais bloque la suppression ; ReadOnly interdit à la fois toute modification et toute suppression.
QuestionComment s'articulent Soft-Delete et Purge Protection dans Azure Key Vault ?
RéponseSoft-Delete place les secrets supprimés en corbeille temporaire (7 à 90 jours) ; Purge Protection interdit à quiconque de vider cette corbeille avant le terme légal.

Module 3 — Calcul, VMSS & PaaS

QuestionQuelles sont les caractéristiques clés des séries B, D, E et F de machines virtuelles Azure ?
RéponseB : burstable économique ; D : équilibré usage général (ratio 1:4) ; E : mémoire intensive (ratio 1:8) ; F : calcul intensif (ratio 1:2).
QuestionQuelle est la différence entre un Fault Domain et un Update Domain dans un Availability Set ?
RéponseFault Domain : isolation matérielle contre les pannes physiques (racks/alimentations) ; Update Domain : isolation logique pour les redémarrages séquentiels lors des maintenances de l'hôte.
QuestionQuels sont les SLAs respectifs d'une Single VM Premium SSD, d'un Availability Set et d'Availability Zones ?
RéponseSingle VM Premium : 99.9% (≈ 8.76 h/an) ; Availability Set : 99.95% (≈ 4.38 h/an) ; Availability Zones : 99.99% (≈ 52.6 min/an).
QuestionComment calcule-t-on le SLA composite d'une architecture multi-tiers en série ?
RéponseEn multipliant les probabilités de disponibilité de chaque niveau unitaire : SLA_composite = SLA_1 * SLA_2 * ... * SLA_n.
QuestionPourquoi le paramètre de Cooldown est-il vital dans l'auto-scaling d'un Azure VMSS ?
RéponseIl temporise les nouvelles décisions d'échelle après un ajout ou retrait pour laisser le temps aux instances de booter et traiter le trafic sans déclencher de battement (flapping).
QuestionQu'est-ce que le Slot Swap sur Azure App Service et quel est son atout ?
RéponseC'est l'échange instantané des adresses IP virtuelles entre les slots Staging et Production, permettant des mises en ligne zéro-downtime et un rollback immédiat.

Module 4 — Réseau Virtuel VNet & Sécurité

QuestionQuelles sont les 5 adresses IP réservées par Azure dans chaque sous-réseau ?
Réponse.0 (Réseau), .1 (Passerelle par défaut), .2 (DNS primaire Azure), .3 (DNS secondaire Azure) et .dernière (Broadcast).
QuestionCombien d'adresses utilisables offre un sous-réseau Azure /28 (16 adresses) ?
Réponse16 - 5 = 11 adresses IP exploitables pour les machines virtuelles (de .4 à .14).
QuestionDans quel ordre sont traitées les règles d'un Network Security Group (NSG) ?
RéponsePar ordre croissant de priorité (de 100 à 4096). La première règle qui matche le paquet est appliquée immédiatement.
QuestionQuel risque critique Azure Bastion élimine-t-il sur les serveurs d'entreprise ?
RéponseL'exposition des ports RDP (3389) et SSH (22) sur Internet et les attaques par force brute associées, en encapsulant l'administration dans du flux HTTPS (443).
QuestionPourquoi deux réseaux virtuels ayant des plages IP qui se chevauchent ne peuvent-ils pas être appairés ?
RéponseParce que les routeurs logiciels SDN d'Azure ne pourraient pas déterminer vers quel réseau acheminer les paquets sans ambiguïté.
QuestionComment fonctionne le transit de passerelle dans une topologie Hub-and-Spoke ?
RéponseLe Hub active "Allow Gateway Transit" et chaque Spoke active "Use Remote Gateways", permettant aux Spokes d'utiliser la passerelle VPN centrale sans duplication.

Module 5 — Stockage & Données Managées

QuestionQuels sont les quatre services inclus dans un compte de stockage Azure Storage standard v2 ?
RéponseAzure Blob (objets), Azure Files (fichiers partagés SMB/NFS), Azure Queue (files de messages) et Azure Table (NoSQL simple).
QuestionQuels sont les quatre paliers d'accès d'Azure Blob Storage et leurs cas d'usage ?
RéponseHot (accès fréquent), Cool (fichiers stables >30j), Cold (accès rare >90j) et Archive (archivage légal >180j avec réhydratation).
QuestionQu'est-ce que la réhydratation d'un blob archivé ?
RéponseLe processus asynchrone (pouvant prendre de 1 à 15 heures) permettant de restaurer un blob du palier Archive vers un palier en ligne (Hot ou Cool) afin de pouvoir le lire.
QuestionQuels sont les quatre composants essentiels d'un jeton de sécurité SAS (Shared Access Signature) ?
Réponse1. Permissions (sp) ; 2. Fenêtre temporelle (st/se) ; 3. Protocole imposé (spr=https) ; 4. Ressource cible autorisée.
QuestionQuelle est la différence fondamentale entre Azure SQL Database et Azure Cosmos DB ?
RéponseAzure SQL est un moteur relationnel T-SQL transactionnel ACID avec schémas fixes ; Cosmos DB est une base NoSQL multi-modèle distribuée mondialement à latence sub-10ms.
QuestionQuelle est la différence entre GRS et GZRS ?
RéponseGRS fait du LRS dans la région source puis réplique dans la région jumelée ; GZRS fait du ZRS (3 Availability Zones) dans la région source avant de répliquer dans la région jumelée.

Module 6 — Surveillance, FinOps & IaC

QuestionQuelle est la différence fondamentale entre les métriques et les logs dans Azure Monitor ?
RéponseLes métriques sont des valeurs numériques légères en temps quasi réel idéales pour l'alerte immédiate ; les logs sont des événements textuels détaillés analysés dans Log Analytics.
QuestionQuels sont les opérateurs de base de la structure d'une requête KQL ?
RéponseTable | where | project | summarize by | order by | take .
QuestionQu'est-ce que le Secure Score dans Microsoft Defender for Cloud ?
RéponseUne note en pourcentage mesurant la posture de sécurité d'un abonnement Azure en fonction du respect des bonnes pratiques et recommandations de sécurité.
QuestionÀ quoi sert un Action Group dans Azure Monitor ?
RéponseÀ définir les cibles et moyens de notification (emails, SMS, webhooks, Azure Functions) activés lors du déclenchement d'une règle d'alerte.
QuestionQuel est l'intérêt d'une alerte de budget "Forecasted" par rapport à "Actual" dans Cost Management ?
RéponseElle alerte par anticipation dès que la tendance de consommation prédit un dépassement du budget d'ici la fin du mois, avant même que l'argent ne soit dépensé.
QuestionQu'est-ce que Bicep dans l'écosystème Azure ?
RéponseUn langage déclaratif d'Infrastructure as Code (DSL) concis et modulaire qui simplifie la création de gabarits Azure et se compile en templates JSON ARM.
