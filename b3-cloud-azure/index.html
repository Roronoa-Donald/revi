Cloud Azure B3

Maîtrisez l’architecture, la sécurité, le réseau et l’automatisation du Cloud Microsoft Azure : gouvernance ARM, Entra ID, RBAC, VMSS, sous-réseaux VNet, Blob Lifecycle, requêtes analytiques KQL et Infrastructure as Code Bicep. L’Ingénierie Cloud Microsoft Azure en Bachelor 3

De l'Administration des Ressources IaaS à la Gouvernance d'Entreprise & FinOps

En troisième année de Bachelor en Ingénierie Réseaux et Systèmes d’Information, le Cloud Computing ne se résume plus à déployer une machine virtuelle isolée depuis une interface graphique. Il constitue la plateforme d'infrastructure fondamentale où convergent l'orchestration réseau, la sécurité des identités hybrides, le stockage distribué hautement disponible et la gestion automatisée des coûts.

Conçu selon les exigences des certifications professionnelles Microsoft Azure (AZ-104 / AZ-305) et les enseignements magistraux de M. AGOUTOCO-POKO Caleb Benaja, ce cours couvre l'ensemble des compétences d'ingénieur Cloud : la structure globale des datacenters Azure (régions, zones de disponibilité indépendantes, paires géographiques, hiérarchie de gestion des groupes et abonnements selon le Cloud Adoption Framework), la sécurité des accès et identités (Microsoft Entra ID / Azure AD, contrôle d'accès granulaire RBAC, politiques de conformité Azure Policy et coffre-fort Azure Key Vault), les solutions de calcul (machines virtuelles, dimensionnement des séries B, D, E, F, ensembles et zones de disponibilité pour des SLAs de 99.95% à 99.99%, virtual machine scale sets VMSS avec règles d'auto-scaling et PaaS Azure App Service), le réseau virtuel Azure VNet (sous-réseaux, les 5 adresses IP réservées par Azure, Network Security Groups NSG avec priorités de règles et règles par défaut, VNet Peering Hub-and-Spoke et passerelles VPN), le stockage de données (Blob Storage avec gestion automatique du cycle de vie Hot/Cool/Cold/Archive, partages de fichiers SMB Azure Files, bases managées Azure SQL et Cosmos DB, jetons SAS d'accès sécurisé), et enfin la supervision opérationnelle et l'automatisation (Azure Monitor, requêtes analytiques en langage KQL Kusto, Microsoft Defender for Cloud avec Secure Score, budgets Cost Management FinOps et templates Infrastructure as Code Bicep / ARM).
