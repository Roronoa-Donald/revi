Sommaire Général — Cloud Azure B3

Programme complet en 6 modules : de l'architecture globale ARM aux réseaux virtuels VNet, du calcul VMSS au stockage distribué et à l'observabilité analytique KQL.

  1. 1

    Architecture Globale, Régions, Souscriptions & Hiérarchie ARM

    Structure mondiale des datacenters Azure, Régions et Zones de Disponibilité (AZs 1, 2, 3), Paires Régionales, hiérarchie de gestion organisationnelle (Root Management Group, Abonnements, Resource Groups), conventions de nommage du Cloud Adoption Framework (CAF) et optimisation financière TCO / FinOps.

    ≈ 2 h 45 de travail 3 exercices de code lab QCM & Cartes mémo
  2. 2

    Identité Microsoft Entra ID (Azure AD), RBAC & Gouvernance

    Gestion centralisée des identités avec Microsoft Entra ID (utilisateurs, groupes, Managed Identities pour ressources Azure), contrôle d’accès basé sur les rôles (Azure RBAC, Actions / NotActions, wildcards, rôles intégrés Owner/Contributor/Reader et rôles personnalisés), gouvernance déclarative par Azure Policy, verrous de ressources (Resource Locks) et sécurisation des secrets via Azure Key Vault.

    ≈ 2 h 45 de travail 3 exercices de code lab QCM & Cartes mémo
  3. 3

    Calcul & Virtualisation Azure (Azure Compute, VMSS & PaaS)

    Machines virtuelles Azure IaaS, dimensionnement par familles et séries (B, D, E, F), disques managés (Standard HDD/SSD, Premium SSD, Ultra Disk), architectures de haute disponibilité (Availability Sets avec domaines de panne et de mise à jour, Availability Zones), calcul de SLA composite, groupes de machines identiques (VMSS) avec auto-scaling et cooldown, et hébergement PaaS managé Azure App Service avec slots de déploiement et swap zéro-downtime.

    ≈ 2 h 45 de travail 3 exercices de code lab QCM & Cartes mémo
  4. 4

    Réseau Virtuel Azure (Azure Virtual Network - VNet & Sécurité)

    Architecture réseau logiciel (SDN) sous Azure : Virtual Networks (VNet), découpage CIDR en sous-réseaux (Subnets), les 5 adresses IP réservées par Azure dans chaque subnet, groupes de sécurité réseau (NSG), priorité de filtrage des flux et règles par défaut, accès distant sécurisé sans IP publique avec Azure Bastion, interconnexion privée par VNet Peering, topologie d’entreprise Hub-and-Spoke et passerelles VPN / ExpressRoute.

    ≈ 2 h 45 de travail 3 exercices de code lab QCM & Cartes mémo
  5. 5

    Stockage Azure (Blob, Files, Disques) et Données Managées

    Comptes de stockage Azure (Storage Accounts standard v2), services de stockage de données (Blob Storage non structuré, partages de fichiers SMB/NFS Azure Files, Azure Queues et Tables), gestion automatique du cycle de vie des objets (Lifecycle Management : Hot, Cool, Cold, Archive), politiques de réplication des données (LRS, ZRS, GRS, GZRS), sécurité par signatures d’accès partagé (SAS Tokens) et comparatif des bases de données managées (Azure SQL Database vs Azure Cosmos DB).

    ≈ 2 h 45 de travail 3 exercices de code lab QCM & Cartes mémo
  6. 6

    Surveillance, Gestion des Coûts & Automatisation (IaC & KQL)

    Observabilité de bout en bout avec Azure Monitor, collecte de métriques et alertes automatisées (Action Groups), analyse des journaux dans un espace Log Analytics Workspace avec le langage de requête KQL (Kusto Query Language), évaluation de la posture de sécurité avec Microsoft Defender for Cloud et le Secure Score, gouvernance financière FinOps avec Azure Cost Management et budgets d’alerte, et automatisation déclarative par Infrastructure as Code (IaC Bicep et templates ARM).

    ≈ 2 h 45 de travail 3 exercices de code lab QCM & Cartes mémo
