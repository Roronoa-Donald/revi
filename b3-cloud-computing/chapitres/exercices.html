Catalogue des 18 Exercices de Code en Cloud Computing B3

Tous les ateliers pratiques d’études de cas intégrés au cours, classés par niveau de difficulté progressive (Niveau 1 Fondamental, Niveau 2 Intermédiaire, Niveau 3 Avancé).

Module 1 — Modèles NIST, Typologies de Services & Caractéristiques Fondamentales

cc3-c1-e1 N1

Classificateur de modèles de service (IaaS, PaaS, SaaS) et responsabilités

Déterminer la répartition des responsabilités opérationnelles (INFRA, OS, RUNTIME, APP, DATA) entre le fournisseur (CSP) et le client selon le modèle de service.

Résoudre dans le cours
cc3-c1-e2 N2

Auditeur des 5 caractéristiques essentielles NIST (SP 800-145)

Vérifier la conformité d’une offre d’infrastructure aux 5 critères obligatoires de la définition NIST du Cloud Computing.

Résoudre dans le cours
cc3-c1-e3 N3

Évaluateur de modèles de déploiement Cloud (Public, Privé, Hybride, Communautaire)

Qualifier automatiquement le modèle de déploiement Cloud cible d’une organisation selon ses contraintes de colocation, connectivité et criticité des données.

Résoudre dans le cours

Module 2 — Plateformes Cloud, Hyperscalers & Architectures Haute Disponibilité

cc3-c2-e1 N1

Cartographe d’équivalences de services CSP (AWS, Azure, GCP)

Associer les dénominations commerciales des services entre les trois géants hyperscalers selon leur catégorie fonctionnelle.

Résoudre dans le cours
cc3-c2-e2 N2

Calculateur de SLA composé et budget d’erreur annuel

Calculer la disponibilité globale résultante d’une chaîne de services Cloud (série) ou de composants redondés (parallèle) et son indisponibilité annuelle.

Résoudre dans le cours
cc3-c2-e3 N3

Simulateur de passerelle multi-cloud et routage dynamique

Aiguiller dynamiquement les flux applicatifs vers le meilleur point de terminaison Cloud sain selon la stratégie opérationnelle choisie.

Résoudre dans le cours

Module 3 — Technologies de Virtualisation, Hyperviseurs & Dimensionnement

cc3-c3-e1 N1

Classificateur d’hyperviseurs (Bare-Metal vs Hosted, HVM vs PV)

Identifier le type architectural d’hyperviseur et le mode d’émulation matérielle pour qualifier son overhead et son adéquation Cloud.

Résoudre dans le cours
cc3-c3-e2 N2

Calculateur de consolidation et sur-allocation (Overcommitment)

Vérifier la faisabilité d’hébergement d’un lot de machines virtuelles sur un hôte physique selon les plafonds de sur-allocation vCPU et RAM.

Résoudre dans le cours
cc3-c3-e3 N3

Dimensionnement d’instances face à une charge crête transactionnelle

Calculer le nombre minimal d’instances Cloud nécessaires pour absorber un pic de transactions par seconde (TPS) selon les limites CPU, RAM et IOPS.

Résoudre dans le cours

Module 4 — Green IT, Efficacité Énergétique & Métriques Environnementales

cc3-c4-e1 N1

Calculateur d’indicateur d’efficacité énergétique PUE et DCiE

Mesurer la proportion d’énergie gaspillée dans le refroidissement et la distribution électrique d’un datacenter face à l’énergie utile consommée par les serveurs IT.

Résoudre dans le cours
cc3-c4-e2 N2

Simulateur d’empreinte carbone et réduction CO2 par migration Cloud

Quantifier les émissions de gaz à effet de serre (tCO2e) et l’économie carbone permise par la mutualisation Cloud et l’efficacité énergétique.

Résoudre dans le cours
cc3-c4-e3 N3

Optimiseur d’extinction automatique d’instances (Auto-Shutdown FinOps)

Calculer les économies financières et énergétiques générées par l’extinction automatique des environnements de dev/test hors des heures ouvrées.

Résoudre dans le cours

Module 5 — Responsabilité Partagée, Sécurité & Conformité Réglementaire

cc3-c5-e1 N1

Matrice du modèle de responsabilité partagée (Shared Responsibility)

Identifier sans ambiguïté qui, du client ou du fournisseur Cloud (CSP), assume la responsabilité d’un périmètre opérationnel et sécuritaire.

Résoudre dans le cours
cc3-c5-e2 N2

Auditeur de posture de sécurité du stockage Cloud (CSPM)

Détecter les erreurs courantes de configuration sur un espace de stockage objet Cloud (S3, Blob) et évaluer son score de sécurité.

Résoudre dans le cours
cc3-c5-e3 N3

Évaluateur de souveraineté des données (RGPD, Cloud Act, SecNumCloud)

Analyser l’exposition légale d’une infrastructure Cloud aux lois extraterritoriales et vérifier la conformité aux exigences de souveraineté européennes.

Résoudre dans le cours

Module 6 — Stratégies de Migration 6R, FinOps & Optimisation Économique

cc3-c6-e1 N1

Arbre de décision des 6 R de la migration applicative Cloud

Appliquer l’arbre de décision méthodologique (Gartner / AWS 6R) pour choisir la trajectoire de migration adaptée à chaque application.

Résoudre dans le cours
cc3-c6-e2 N2

Calculateur comparatif de TCO : CAPEX sur site vs OPEX Cloud sur 3 ans

Comparer le coût total de possession (Total Cost of Ownership) sur un cycle d’investissement de 3 ans et calculer le retour sur investissement (ROI).

Résoudre dans le cours
cc3-c6-e3 N3

Analyseur FinOps d’arbitrage de tarification (On-Demand, Réservé, Spot)

Segmenter les types de charges de travail et appliquer les leviers tarifaires Cloud optimaux (Instances Réservées, Spot et À la Demande) pour réduire la facture.

Résoudre dans le cours
