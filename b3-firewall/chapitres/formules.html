Mémento Technique & Aide-Mémoire Pare-feu & Sécurité Périmétrique

Guide de référence opérationnelle : états conntrack, matrice des flux de sécurité DMZ, syntaxe comparée iptables vs nftables, signatures d’attaques et paramètres de durcissement.

1. Machine à États TCP & Table de Suivi Netfilter Conntrack

État conntrackDrapeaux TCP (Flags)Rôle & Comportement Pare-feuDélai Timeout défaut
NEWSYN (ou premier paquet)Initie la session. Alloue une entrée dans la table conntrack.60 secondes (SYN_SENT)
ESTABLISHEDACK après SYN-ACK, DATASession bilatérale validée par le handshake à 3 voies. Trafic légitime.3600 à 432000 s
RELATEDPaquets secondaires liésConnexion associée à une session existante (ex: canal de données FTP, erreurs ICMP).Selon protocole maître
INVALIDCombinaison anormalePaquet orphelin, hors session ou flags contradictoires (SYN+FIN, Null). À DROP impérativement.Immédiat (aucun stockage)

2. Matrice d’Or de Sécurité des Flux Inter-Zones (Architecture DMZ)

Flux Source -> DestinationStatut de ConformitéPorts & Services TypiquesJustification Sécuritaire
WAN -> DMZAutorisé et strictement filtré80, 443 (Web), 25 (Mail), 53 (DNS)Exposition contrôlée des services publics. Tout le reste est DROP.
LAN -> DMZAutorisé pour administration80, 443 (HTTP), 22 (SSH admin), 3306 (BDD)Permet aux postes internes de consommer les serveurs et aux admins de gérer.
LAN -> WANAutorisé avec SNAT/Proxy80, 443, 53 via passerelle NATNavigation des employés, masquage de l’adressage IP privé interne.
DMZ -> WANRestreint au strict nécessaire80, 443 (mises à jour système), 53Empêche la DMZ de servir de relais d’attaque ou de botnet vers Internet.
DMZ -> LANSTRICTEMENT INTERDIT (Règle d’Or)AUCUN port initiéEn cas de compromission d’un serveur DMZ, le pirate ne peut pas pivoter vers le réseau interne.
WAN -> LANSTRICTEMENT INTERDITAUCUN flux directLe réseau d’entreprise interne ne doit jamais être exposé directement sur le Net.

3. Syntaxe Comparée des Règles : iptables vs nftables

Action de SécuritéSyntaxe Linux héritée (iptables)Syntaxe moderne Linux (nftables)
Politique par défaut DROPiptables -P INPUT DROPnft add chain inet filter input { type filter hook input priority 0; policy drop; }
Autoriser trafic déjà établiiptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPTnft add rule inet filter input ct state established,related accept
Autoriser HTTP/HTTPS entrantiptables -A INPUT -p tcp -m multiport --dports 80,443 -j ACCEPTnft add rule inet filter input tcp dport { 80, 443 } accept
Masquage SNAT sortantiptables -t nat -A POSTROUTING -o eth0 -j MASQUERADEnft add rule ip nat postrouting oifname "eth0" masquerade
Redirection DNAT (Port Forward)iptables -t nat -A PREROUTING -p tcp --dport 80 -j DNAT --to 10.0.0.10:8080nft add rule ip nat prerouting tcp dport 80 dnat to 10.0.0.10:8080
Blocage dynamique liste noireiptables -A INPUT -s 198.51.100.5 -j DROPnft add element inet filter blacklist { 198.51.100.5 }
