Laboratoire Interactif & Bac à Sable Git & GitHub

Expérimentez et automatisez vos outils de plomberie Git en Python 3 : hachage d’objets, parcours de graphes DAG, résolution de conflits et validation de workflows CI/CD.

Suggestions d’expérimentations pratiques

Génération de pointeurs Git LFS

Calculez le hash SHA-256 de fichiers binaires volumineux et assemblez le texte formel du pointeur LFS selon la spécification v1.

Analyseur de workflows GitHub Actions

Construisez un parseur YAML détectant les failles d’injection de code dans les blocs run: manipulant les contextes d’événements.
