Sommaire & Plan d’Études — Git & GitHub B3

Programme détaillé des 6 modules de spécialisation en interne Git, topologies de fusion, reflog, workflows d’entreprise, GitHub Actions et sécurité des dépôts.

Module Titre du cours Programme & Notions clés Statut
Module 1 Modèle Objet Git & Arborescence Interne Anatomie du dossier .git, modèle objet immuable (blobs, trees, commits, tags), hachage SHA-1/SHA-256, adressage par contenu et commandes de plomberie. Accès libre
Module 2 Stratégies de Fusion Avancées & Rebase Interactif Fast-Forward vs 3-Way Merge, calcul du Lowest Common Ancestor (LCA), stratégies recursive et ort, rebase interactif, squash et arbitrage formel des conflits. Réservé B3 et plus
Module 3 Diagnostic, Reflog & Sauvetage de Données Journal de références git reflog, sauvetage de commits orphelins (dangling), recherche dichotomique de régressions avec git bisect, gestion de la pile LIFO git stash et intégrité avec git fsck. Réservé B3 et plus
Module 4 Workflows d’Équipe, Gouvernance & Protection de Branches Modèles de collaboration (Git Flow, GitHub Flow, Trunk-Based Development), règles de protection de branches (Branch Protection Rules / Rulesets), signature cryptographique GPG et norme Conventional Commits 1.0.0. Réservé B3 et plus
Module 5 Automatisation & CI/CD avec GitHub Actions Syntaxe déclarative YAML, événements déclencheurs, runners, stratégie matricielle multi-plateforme (strategy.matrix), gestion des secrets et durcissement contre les injections de commandes. Réservé B3 et plus
Module 6 Administration Avancée, LFS, Hooks & Purge d’Historique Gestion des gros fichiers binaires avec Git LFS, automatisation avec les hooks client et serveur, hygiène de dépôt, réécriture complète du DAG et purge de secrets compromis avec git-filter-repo. Réservé B3 et plus
