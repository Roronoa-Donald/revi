Cartes de Révision & Mémorisation Active — Google Cloud Platform B3

47 fiches synthétiques pour ancrer les concepts fondamentaux de l'architecture et de l'ingénierie Google Cloud : Hiérarchie des ressources, SDK gcloud CLI, IAM et moindre privilège, Comptes de service et Workload Identity, Compute Engine et Managed Instance Groups (MIG), GKE et Cloud Run, Réseau VPC et adresses réservées, Règles de pare-feu et Cloud Load Balancing, Classes Cloud Storage et cycle de vie, Cloud SQL et Spanner, Cloud Pub/Sub, Operations Suite (Monitoring/Logging), FinOps (CUD/SUD) et Terraform pour GCP.

Module 1 — Architecture, Hiérarchie & gcloud

QuestionQu’est-ce que « La hiérarchie des ressources suit l'ordre strict » ?
RéponseOrganisation > Dossiers > Projets > Ressources : les autorisations allow sont héritées, mais un deny applicable peut refuser des permissions prises en charge.
QuestionComment distinguer Project ID, Project Name et Project Number dans Google Cloud ?
RéponseL'ID est mondial et immuable, de 6 à 30 caractères avec une syntaxe de type RFC 1035 ; le nom est modifiable et le numéro est attribué par Google.
QuestionComment les groupes d'instances gérés (MIG) améliorent-ils l'élasticité et la disponibilité ?
RéponseL'autoscaling ajuste le nombre de VM ; l'autohealing configuré utilise une sonde de santé pour recréer une instance défaillante.
QuestionQue prend en charge GKE Autopilot et comment sont facturées ses ressources ?
RéponseGoogle gère les nœuds ; la facturation porte généralement sur les ressources demandées par les Pods, parfois sur les nœuds, avec d'éventuels frais de cluster.
QuestionQuelles adresses IPv4 une plage principale de sous-réseau Google Cloud réserve-t-elle ?
RéponseLes deux premières et les deux dernières : en /24, .0, .1, .254 et .255. Il reste 2^(32-p) - 4 adresses utilisables pour un préfixe /p autorisé ; la plage comporte au moins huit adresses.
QuestionComment Public Cloud NAT donne-t-il un accès sortant aux VM sans IP publique ?
RéponseIl traduit leur adresse privée en une adresse IP publique du NAT pour les connexions sortantes, sans exposer directement les VM.
QuestionQue peut automatiser Object Lifecycle Management dans Cloud Storage ?
RéponseSelon des règles comme l'âge, il peut changer la classe de stockage ou supprimer des objets.
QuestionComment Cloud Logging peut-il conserver ou analyser durablement des journaux ?
RéponseIl collecte les journaux configurés et des sinks peuvent les router vers Cloud Storage ou BigQuery.
QuestionComment Cloud Trace et Cloud Profiler aident-ils à diagnostiquer les performances ?
RéponseTrace mesure la latence des requêtes ; Profiler échantillonne notamment l'utilisation du processeur et de la mémoire par le code.
QuestionQuels sont les 4 niveaux de la hiérarchie Google Cloud ?
Réponse1. Organisation (racine liée au domaine) ; 2. Dossiers (Folders) ; 3. Projets ; 4. Ressources.
QuestionQuelles sont les caractéristiques d'un Project ID Google Cloud ?
RéponseUnique au monde, immuable, 6 à 30 caractères, minuscules/chiffres/tirets, commence par une lettre et ne finit pas par un tiret (RFC 1035).
QuestionQuelle est la différence entre Project Name, Project ID et Project Number ?
RéponseName = affichage modifiable ; ID = identifiant permanent unique mondial ; Number = entier système généré par Google.
QuestionQu'est-ce que Cloud Shell dans Google Cloud ?
RéponseUne machine virtuelle Linux gratuite dans le navigateur avec 5 Go d'espace persistant et le SDK gcloud préconfiguré.
QuestionComment s'applique l'héritage des autorisations IAM dans la hiérarchie ?
RéponseUne liaison allow est héritée par les descendants. Une règle deny applicable peut refuser des permissions prises en charge pour le principal, sous réserve de ses conditions et exceptions.
QuestionQuelle est la différence entre le niveau réseau Premium Tier et Standard Tier dans GCP ?
RéponsePremium Tier utilise le réseau privé mondial en fibre de Google dès le PoP edge le plus proche ; Standard Tier utilise l'Internet public.

Module 2 — IAM, Rôles & Comptes de Service

QuestionQu'est-ce que le principe du moindre privilège dans Google Cloud IAM ?
RéponseLa règle accordant à chaque utilisateur ou application uniquement les permissions strictement nécessaires à sa mission.
QuestionPourquoi les rôles primitifs (Viewer, Editor, Owner) sont-ils déconseillés ?
RéponseCar ils s'appliquent globalement à tous les services du projet sans granularité, octroyant des droits excessifs.
QuestionQuelle est la structure d'un nom de compte de service dans Google Cloud ?
Réponse[nom]@[projet-id].iam.gserviceaccount.com.
QuestionQuel est le risque majeur des clés privées JSON de comptes de service ?
RéponseLe risque de fuite accidentelle (Git, postes) offrant un accès permanent non contrôlé à l'infrastructure.
QuestionComment Workload Identity améliore-t-il la sécurité des conteneurs ?
RéponseIl remplace les clés JSON statiques par des jetons temporaires éphémères négociés automatiquement.
QuestionQuel est le délai de rotation recommandé par le CIS Benchmark pour les clés de comptes de service ?
RéponseTous les 90 jours au maximum.

Module 3 — Calcul, GKE & Cloud Run

QuestionQuel est le taux de SLA d'une VM Compute Engine mono-zone vs multi-zones ?
Réponse99.5% en mono-zone (216 min/mois d'arrêt max) vs 99.99% en multi-zones (4.32 min/mois d'arrêt max).
QuestionQu'est-ce qu'un groupe d'instances géré (MIG) régional ?
RéponseUn groupe de VMs identiques réparties sur plusieurs zones assurant auto-scaling et auto-healing automatique.
QuestionPourquoi GKE Autopilot est-il privilégié pour la majorité des projets ?
RéponseGoogle gère entièrement les nœuds, applique le durcissement de sécurité et facture uniquement les Pods actifs.
QuestionQuelle est la particularité de la concurrence dans Google Cloud Run ?
RéponseUne seule instance de conteneur peut traiter jusqu'à 1 000 requêtes en parallèle, optimisant les coûts d'exécution.
QuestionPour quel type de charge de travail les instances Spot sont-elles adaptées ?
RéponseLes traitements par lots, calculs asynchrones et environnements de test tolérants aux arrêts inopinés.
QuestionQu'est-ce que le Traffic Splitting sur Cloud Run ?
RéponseLa capacité de répartir les pourcentages de trafic HTTP entre plusieurs révisions pour tester des versions Canary.

Module 4 — Réseau VPC & Load Balancing

QuestionQuelle est la portée géographique d'un réseau VPC Google Cloud ?
RéponseUn VPC Google Cloud est mondial, composé de sous-réseaux régionaux indépendants.
QuestionCombien d'adresses IP sont réservées dans un sous-réseau VPC GCP et lesquelles ?
Réponse4 adresses : .0 (réseau), .1 (passerelle), .2 (DNS Google), .255 (diffusion).
QuestionQuel est le rôle de Cloud NAT ?
RéponsePermettre aux VMs privées sans IP publique d'émettre vers Internet de façon sécurisée.
QuestionComment sont ordonnées les règles de pare-feu VPC dans Google Cloud ?
RéponsePar priorité de 0 à 65535 ; la règle avec le nombre le plus petit s'applique en premier.
QuestionQu'est-ce que le routage Anycast dans Cloud Load Balancing ?
RéponseUne seule IP publique mondiale annoncée sur tous les PoP edge pour terminer les connexions au plus près de l'utilisateur.
QuestionQuelle est la limitation majeure du VPC Network Peering ?
RéponseIl est strictement non transitif : l'appairage de A avec B et de B avec C ne connecte pas A à C.

Module 5 — Stockage, Bases de Données & Pub/Sub

QuestionQuelle durabilité annuelle Google indique-t-il pour Cloud Storage ?
Réponse99.999999999% (11 9s) ; la durabilité est distincte du SLA de disponibilité et la redondance dépend de l'emplacement.
QuestionQuelles sont les durées minimales des classes Nearline, Coldline et Archive ?
RéponseNearline = 30 jours, Coldline = 90 jours, Archive = 365 jours.
QuestionQuels objectifs SLA mensuels Spanner publie-t-il selon la configuration ?
RéponseAu 30 octobre 2026 : 99.999 % en multi- ou birégional, 99.99 % en régional hors Stockholm et 99.95 % en régional à Stockholm, sous les conditions et exclusions du SLA.
QuestionÀ quelles conditions utiliser la classe Cloud Storage Rapid ?
RéponseRapid exige un bucket zonal dans une zone prise en charge, avec Rapid Bucket, espace de noms hiérarchique et accès uniforme ; quotas et compatibilités sont à vérifier.
QuestionQuels objectifs SLA mensuels Cloud SQL publie-t-il en HA ?
RéponseAu 30 octobre 2026 : 99.95 % pour Enterprise HA et 99.99 % pour Enterprise Plus HA, par instance et mois calendaire, sous les conditions et exclusions du SLA.
QuestionQuel cas d'usage correspond le mieux à Cloud Bigtable ?
RéponseLa télémétrie IoT, les séries temporelles et l'analytique à latence sub-milliseconde sur de grands volumes.
QuestionQuelle est la différence entre les modes Pull et Push dans Cloud Pub/Sub ?
RéponsePull : le consommateur interroge Pub/Sub ; Push : Pub/Sub déclenche un webhook HTTPS vers le consommateur.
QuestionQu'est-ce qu'une URL signée (Signed URL) dans Cloud Storage ?
RéponseUne URL temporaire cryptographiquement signée autorisant l'accès à un objet sans identifiant Google Cloud.

Module 6 — Observabilité, FinOps & Terraform

QuestionQu'est-ce que Cloud Monitoring dans Google Cloud ?
RéponseLe service de collecte de métriques d'infrastructure et applicatives, de tableaux de bord et de gestion d'alertes.
QuestionQuel est le rôle d'un Log Sink dans Cloud Logging ?
RéponseFiltrer et exporter des flux de journaux en continu vers BigQuery, Cloud Storage ou Pub/Sub.
QuestionQuelle est la différence entre Cloud Trace et Cloud Profiler ?
RéponseTrace mesure la latence des requêtes entre microservices ; Profiler analyse la consommation CPU et mémoire du code.
QuestionQu'est-ce qu'une remise Sustained Use Discount (SUD) ?
RéponseUne remise automatique appliquée par Google sur les VMs qui s'exécutent pendant une large portion du mois civil.
QuestionQuel est le gain moyen d'un engagement CUD de 1 an vs 3 ans ?
RéponseEnviron 37% de remise pour 1 an d'engagement, et environ 55% de remise pour 3 ans.
QuestionPourquoi stocker l'état Terraform sur Google Cloud Storage (GCS) ?
RéponsePour centraliser l'état, permettre la collaboration d'équipe et assurer le verrouillage d'état automatique (State Locking).
