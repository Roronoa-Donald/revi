4. Règles Réseau VPC, Adressage & Load Balancing

Adresses Réservées dans un Sous-Réseau VPC

Chaque sous-réseau VPC réserve obligatoirement 4 adresses IP :

  • .0 : Adresse réseau (Network)
  • .1 : Passerelle par défaut (Default Gateway)
  • .2 : Réservé par Google (DNS interne)
  • .255 (dernière) : Réservé par Google (Broadcast)

Nombre d'adresses assignables à des VMs = 2^(32 - prefix) - 4.

Architecture Global External HTTP(S) Load Balancer

  • Global Forwarding Rule : Adresse IP Anycast mondiale publique sur ports 80/443.
  • Target HTTP(S) Proxy : Terminaison TLS avec certificats gérés par Google.
  • URL Map : Routage par hôte et préfixes d'URL vers les services backend.
  • Backend Service : Groupe de backends (MIG de VMs ou NEG Cloud Run) supervisé par Health Check.
