2. Élection et Coûts du Spanning Tree Protocol (STP / RSTP)

Structure du Bridge ID (BID) & Départage

Le Bridge ID est encodé sur 8 octets selon la spécification IEEE 802.1t / 802.1w :

  • Bridge Priority (4 bits) : Multiples stricts de 4096 (de 0 à 61440, valeur par défaut : 32768).
  • Extended System ID (12 bits) : Identifiant du VLAN (de 1 à 4094).
  • Adresse MAC du commutateur (48 bits) : Utilisée pour départager deux commutateurs ayant la même priorité totale.

Règle d'or : Le commutateur ayant le plus petit BID devient le Root Bridge (commence par la priorité totale la plus basse, puis la plus petite adresse MAC).

5. Formules et Métriques OSPFv2 (RFC 2328)

Calcul du Coût d'Interface OSPF & États d'Adjacence

La formule standard de calcul de coût pour chaque interface OSPF est :

Coût OSPF = Bande_Passante_de_Référence / Bande_Passante_Interface

Par défaut, la bande passante de référence Cisco est 100 Mbps (10^8 bps). Sur les réseaux modernes 1G/10G/40G, il est obligatoire d'ajuster la référence : auto-cost reference-bandwidth 100000 (100 Gbps).

Cycle de vie d'une adjacence OSPF : Down → Init → 2-Way (élection DR/BDR) → ExStart → Exchange (échange de DBD) → Loading (LSR / LSU) → Full (base LSDB synchronisée).
