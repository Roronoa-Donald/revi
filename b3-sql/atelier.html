Éditeur SQL libre

Rédigez une requête SQL. Le bouton Exécuter utilise un service externe, s'il est configuré ; sa disponibilité et son dialecte dépendent du service. Cet éditeur ne fournit pas une base PostgreSQL de production. La correction automatique des exercices du cours est temporairement suspendue.

La requête initiale est un exemple autonome compatible avec SQLite. Utilisez une base de test adaptée pour les commandes propres à PostgreSQL.

Pistes de travail sur une base de test adaptée

Ces pistes nécessitent vos propres données et outils ; aucun simulateur spécialisé n’est fourni dans cet éditeur.

Index B-Tree

Étudiez les divisions de pages lors d'insertions et l'effet du paramètre Fill Factor sur une base de test.

Plans d'exécution

Sur PostgreSQL, comparez les coûts estimés de plans selon les données et la sélectivité.
