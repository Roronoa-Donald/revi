3. Modèle de Coût de l'Optimiseur CBO PostgreSQL

Paramètres de Coût Unitaire de Référence

L'optimiseur CBO estime le coût d'un plan selon la formule de pondération matérielle :

Coût = (N_pages_seq * seq_page_cost) + (N_pages_rand * random_page_cost) + (N_tuples * cpu_tuple_cost) + (N_operateurs * cpu_operator_cost)
  • seq_page_cost = 1.0 : coût de référence pour la lecture séquentielle d'une page disque de 8 Ko.
  • random_page_cost = 4.0 (sur disque HDD rotatif) / 1.1 (sur stockage SSD NVMe moderne).
  • cpu_tuple_cost = 0.01 : coût de traitement d'un tuple en mémoire CPU.
  • cpu_operator_cost = 0.0025 : coût d'évaluation d'un opérateur ou d'une clause WHERE.
