Cartes de Révision & Mémorisation Active — Windows Server B3

36 fiches synthétiques pour ancrer les concepts fondamentaux : Architecture Système NT, Rôles DHCP/DNS, Forêt Active Directory, Rôles FSMO, Modèle AGDLP, Ordre LSDOU des GPOs, Droits NTFS/SMB, Hyper-V et Clustering de Haute Disponibilité.

Module 1 — Architecture, DHCP, DNS & Licences

QuestionQuels sont les deux modes d’exécution de l’architecture Windows NT ?
RéponseLe Mode Noyau (Ring 0, accès matériel total, HAL/VMM) et le Mode Utilisateur (Ring 3, mémoire protégée, sous-système Win32).
QuestionPourquoi privilégier Server Core en production ?
RéponsePour sa sécurité maximale (surface d’attaque minimale), sa légèreté en RAM/disque et la réduction des redémarrages de maintenance.
QuestionQuelles sont les deux règles de plancher de licence par cœur Microsoft ?
RéponseMinimum 8 cœurs physiques par socket CPU, et minimum 16 cœurs physiques par serveur physique au total.
QuestionCombien de VMs sont couvertes par l’édition Datacenter ?
RéponseUn nombre illimité de machines virtuelles sur l’hôte physique licencié.
QuestionÀ quoi sert un enregistrement DNS de type SRV ?
RéponseÀ spécifier l’emplacement réseau (serveur cible et port) d’un service applicatif, comme LDAP ou Kerberos pour Active Directory.
QuestionQu’est-ce qu’une réservation DHCP ?
RéponseL’attribution permanente et déterministe d’une même adresse IP à une machine spécifique identifiée par son adresse MAC.

Module 2 — Active Directory, AGDLP & FSMO

QuestionQuels sont les 5 rôles FSMO d’Active Directory ?
RéponseSchema Master et Domain Naming (forêt) ; PDC Emulator, RID Master et Infrastructure Master (domaine).
QuestionQuelle est la signification de l’acronyme AGDLP ?
RéponseAccounts (comptes) -> Global Groups (métier) -> Domain Local Groups (ressource) -> Permissions (ACLs).
QuestionPourquoi le rôle PDC Emulator est-il le plus critique du domaine ?
RéponseCar il synchronise l’horloge NTP pour Kerberos, traite les échecs et modifications de mots de passe, et sert de cible pour les GPOs.
QuestionQuelle est la différence entre un transfert de rôle et une saisie forcée (seize) ?
RéponseLe transfert est coopératif et planifié entre deux DCs en ligne ; la saisie est une appropriation d’urgence après le crash définitif d’un DC.
QuestionÀ quoi sert le rôle RID Master ?
RéponseÀ allouer des blocs d’identifiants relatifs (RIDs) à chaque contrôleur pour forger des SIDs uniques lors de la création d’objets.
QuestionQuel est l’Event ID signalant l’ajout d’un membre dans un groupe de sécurité ?
RéponseL’Event ID 4728 dans le journal de sécurité Windows (Security log).

Module 3 — Stratégies de Groupe (GPO) & LSDOU

QuestionQuel est l’ordre de traitement officiel du modèle LSDOU ?
RéponseLocal, Site, Domaine, puis Unité Organisationnelle (LSDOU).
QuestionQuelle est la différence entre le GPC et le GPT d’une GPO ?
RéponseLe GPC stocke les métadonnées dans Active Directory ; le GPT stocke les fichiers réels de configuration dans le partage SYSVOL.
QuestionQue fait l’option Enforced (application forcée) ?
RéponseElle traverse obligatoirement tous les blocages d’héritage et interdit tout écrasement par une GPO descendante.
QuestionQue fait l’option Block Inheritance sur une OU ?
RéponseElle bloque l’héritage des GPOs parentes (Site, Domaine), sauf celles qui sont marquées Enforced.
QuestionAu sein d’une même OU, quelle GPO gagne en cas de conflit ?
RéponseLa GPO possédant le Link Order le plus bas (Link Order = 1 a la plus haute priorité).
QuestionComment fonctionne le filtrage de sécurité (Security Filtering) ?
RéponseEn accordant ou refusant le droit « Appliquer la stratégie de groupe » à des groupes d’ordinateurs ou d’utilisateurs spécifiques.

Module 4 — Fichiers, Partage SMB, NTFS & Stockage

QuestionQu’est-ce que la règle du plus restrictif ?
RéponseLe droit d’accès effectif via le réseau est l’intersection la plus restrictive entre les droits de partage SMB et les permissions NTFS.
QuestionQuel est l’ordre de priorité des ACEs dans une DACL NTFS ?
Réponse1. Explicit Deny, 2. Explicit Allow, 3. Inherited Deny, 4. Inherited Allow.
QuestionPourquoi utiliser ReFS plutôt que NTFS pour les VMs Hyper-V ?
RéponsePour sa résilience contre les corruptions de données et sa fonctionnalité Block Cloning qui accélère la manipulation des disques VHDX.
QuestionCombien de disques physiques au minimum requiert le mode Storage Spaces Parity ?
RéponseMinimum 3 disques physiques (tolérance de panne de 1 disque).
QuestionQuelle est la capacité utile d’un pool Storage Spaces en Two-Way Mirror ?
Réponse50 % de la capacité brute totale du pool de disques.
QuestionComment fonctionne la déduplication de données ?
RéponseEn identifiant les blocs dupliqués pour n’en conserver qu’une copie unique dans le Chunk Store avec des pointeurs de réanalyse.

Module 5 — Virtualisation Hyper-V & Réseau

QuestionQuelles sont les deux partitions fondamentales de l’architecture Hyper-V ?
RéponseLa partition parente d’administration (Root Partition) et les partitions invitées isolées (Child Partitions).
QuestionQuels sont les atouts des VMs de Génération 2 ?
RéponseMicroprogramme UEFI x64, Secure Boot, contrôleurs SCSI natifs et démarrage réseau PXE performant sans matériel émulé.
QuestionQuels sont les trois types de commutateurs virtuels Hyper-V ?
RéponseExternal (accès LAN/Internet), Internal (VMs + hôte), Private (strictement inter-VMs).
QuestionComment s’évalue la mémoire dynamique d’une VM ?
RéponseTarget = Demande x (1 + Buffer%) bornée par les valeurs de mémoire minimale et maximale configurées.
QuestionQuelle est la différence entre checkpoints Standard et de Production ?
RéponseLes checkpoints Standard capturent l’état mémoire vive ; les checkpoints de Production utilisent VSS pour garantir la cohérence applicative.
QuestionQue réalise l’opération de fusion (Merge) d’un checkpoint ?
RéponseElle réintègre les blocs du disque différentiel .avhdx dans le disque VHDX parent puis supprime le différentiel.

Module 6 — PowerShell, Sauvegardes & Clustering

QuestionSur quels ports écoute le service WinRM pour PowerShell Remoting ?
RéponsePort TCP 5985 (HTTP sécurisé par Kerberos) et port TCP 5986 (HTTPS avec certificat SSL/TLS).
QuestionQuelle est la différence entre Enter-PSSession et Invoke-Command ?
RéponseEnter-PSSession ouvre une session interactive unitaire (1:1), tandis qu’Invoke-Command exécute des scripts distribués en parallèle (1:N).
QuestionQuels sont les trois composants de l’architecture de sauvegarde VSS ?
RéponseLe VSS Requestor (logiciel demandeur), le VSS Writer (application gelée) et le VSS Provider (moteur de cliché).
QuestionComment calcule-t-on la majorité absolue de quorum d’un cluster ?
RéponseMajorité requise = (Total des voix // 2) + 1.
QuestionQu’est-ce que le phénomène de Split-Brain dans un cluster ?
RéponseLa scission d’un cluster en sous-groupes isolés écrivant simultanément sur le même stockage partagé et corrompant les données.
QuestionQuels sont les avantages d’un Cloud Witness (témoin Cloud) ?
RéponseIl arbitre le quorum via un simple compte Blob Azure, évitant l’achat d’un troisième site physique ou d’une baie SAN dédiée.
