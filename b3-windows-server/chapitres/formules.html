2. Le Modèle Microsoft AGDLP / AGUDLP d’Organisation des Groupes

Chaîne Canonique d’Attribution des Droits

Pour garantir la maintenabilité et éviter l’explosion des listes de contrôle d’accès (ACL) :

  1. A (Accounts) : Les utilisateurs individuels ou comptes de service.
  2. G (Global Groups) : Groupes globaux représentant un rôle métier ou une fonction (ex. GG_Comptables). Membres de DL ou UG.
  3. U (Universal Groups) : Groupes universels utilisés dans les forêts multi-domaines pour consolider les groupes globaux de plusieurs arbres.
  4. DL (Domain Local Groups) : Groupes locaux de domaine représentant une ressource et un niveau d’accès (ex. DL_Factures_Lecture, DL_DossierRH_Modif).
  5. P (Permissions) : L’ACL NTFS ou le droit de partage est attribué exclusivement au groupe DL.

4. Règles Officielles de Licence Microsoft par Cœur Physique

Règles de Calcul & Virtualisation Windows Server

  • Règle du Socket : Minimum 8 cœurs physiques par socket processeur (si $\\le 8$, compter 8).
  • Règle du Serveur : Minimum 16 cœurs physiques par serveur complet.
  • Packs de vente : Vendus par packs de 2 cœurs. $\\text{Packs de base} = lceil \\text{Cœurs totaux} / 2 ceil$.
  • Édition Standard : Chaque couverture complète de l’hôte physique octroie le droit d’exécuter 2 machines virtuelles Windows Server. Pour $V$ VMs : $\\text{Packs requis} = \\text{Packs base} \\times lceil V / 2 ceil$.
  • Édition Datacenter : Une seule couverture de l’hôte physique octroie des VMs illimitées.
