Examens Blancs & Épreuves Corrigées de C# B2

Deux sujets d’entraînement intensif conformes aux épreuves de licence informatique B2, accompagnés de leurs corrigés types et barèmes détaillés.

Épreuve 1 : Contrôle Continu (CC) — Durée 1 h 30 (Barème sur 20 points)

Sujet du Contrôle Continu — Fondamentaux CLR, Encapsulation & Polymorphisme

Partie 1 : Questions de cours & Architecture CLR (6 points)

  1. Définissez précisément les opérations de boxing et d’unboxing en C#. Pourquoi constituent-elles un goulot d’étranglement de performance sur des boucles intensives ? (3 pts)
  2. Quelle est la différence fondamentale entre les mots-clés override et new lorsqu’une classe dérivée redéfinit une méthode présente dans sa classe parente ? (3 pts)

Partie 2 : Conception orientée objet & Immuabilité (8 points)

On souhaite modéliser un système de gestion de transactions financières immuables :

  1. Déclarez un record C# Transaction comportant un identifiant de type chaîne, un montant décimal (decimal) et une date d’opération (DateTime). (2 pts)
  2. Expliquez le fonctionnement de l’égalité par valeur sur les records et écrivez une ligne de code utilisant l’expression with pour créer une nouvelle transaction avec un statut ajusté à « Valide ». (3 pts)
  3. Concevez une classe CompteBancaire avec une propriété Solde accessible en lecture publique et écriture privée, ainsi qu’une méthode Crediter(decimal montant) levant une ArgumentException si le montant est inférieur ou égal à zéro. (3 pts)

Partie 3 : Interfaces multiples & Implémentation explicite (6 points)

Soit deux interfaces ILogger et IAuditor possédant toutes deux la méthode void Log(string message). Implémentez une classe ServicePaiement qui fournit deux comportements distincts pour chacune de ces interfaces en utilisant l’implémentation explicite d’interface. Montrez comment l’appelant consomme ces deux méthodes. (6 pts)

Corrigé Partie 1 (6 points)

  • Boxing / Unboxing (3 pts) : Le boxing consiste à encapsuler une variable de type valeur (sur la pile) à l’intérieur d’une boîte objet allouée sur le tas managé (Heap). L’unboxing extrait explicitement la valeur de cette boîte vers la pile. Dans une boucle intensive, le boxing répété provoque des milliers d’allocations sur le tas et sature le Garbage Collector (GC), entraînant des pauses d’exécution et une chute de débit.
  • override vs new (3 pts) : override modifie l’entrée correspondante dans la table des méthodes virtuelles (vtable) : l’appel résout dynamiquement vers la classe dérivée, même si la variable est typée avec la classe de base. new masque simplement la méthode de base sans modifier la vtable : l’appel est résolu statiquement à la compilation en fonction du type déclaré de la variable.

Corrigé Partie 2 (8 points)

  • Déclaration de record (2 pts) :
    public record Transaction(string Id, decimal Montant, DateTime DateOperation);
  • Égalité et mutabilité non destructive (3 pts) : Deux records sont égaux si toutes leurs propriétés sont égales en valeur (pas seulement la référence mémoire). Copie avec with :
    var t2 = t1 with { Montant = 150.00m };
  • Classe CompteBancaire (3 pts) :
    public class CompteBancaire {
      public decimal Solde { get; private set; }
      public void Crediter(decimal m) {
        if (m <= 0) throw new ArgumentException("Montant invalide");
        Solde += m;
      }
    }

Corrigé Partie 3 (6 points)

  • Implémentation explicite :
    public class ServicePaiement : ILogger, IAuditor {
      void ILogger.Log(string msg) => Console.WriteLine($"[LOG] {msg}");
      void IAuditor.Log(string msg) => Console.WriteLine($"[AUDIT CONFORME] {msg}");
    }
    Consommation par cast :
    var s = new ServicePaiement();
    ((ILogger)s).Log("Paiement initié");
    ((IAuditor)s).Log("Paiement initié");

Épreuve 2 : Examen Terminal (ET) — Durée 2 h 00 (Barème sur 20 points)

Sujet de l’Examen Terminal — LINQ Avancé, Asynchronisme TAP & IDisposable

Partie 1 : Requêtes LINQ & Traitement de collections (7 points)

Soit une liste List<Commande> où chaque commande possède Client, Categorie et Total.

  1. Écrivez une requête LINQ (méthodes d’extension) qui regroupe les commandes par Categorie, calcule le chiffre d’affaires total par catégorie, filtre les catégories dont le chiffre d’affaires dépasse 10 000 €, et ordonne le résultat par chiffre d’affaires décroissant. (4 pts)
  2. Expliquez ce qu’est l’exécution différée (deferred execution) en LINQ et citez deux méthodes provoquant l’évaluation immédiate de la requête. (3 pts)

Partie 2 : Programmation Asynchrone (async/await) & Tâches concurrentes (7 points)

  1. Expliquez comment le compilateur Roslyn transforme une méthode async Task en une machine à états et quel est le rôle précis de l’opérateur await vis-à-vis du thread appelant. (3 pts)
  2. Écrivez une méthode public async Task SynchroniserServeursAsync(List<string> urls) qui télécharge le contenu de toutes les URLs en parallèle via Task.WhenAll et gère l’agrégation d’erreurs dans une AggregateException. (4 pts)

Partie 3 : Gestion déterministe des ressources (6 points)

Expliquez pourquoi le Garbage Collector de .NET ne suffit pas pour libérer les ressources système non managées (handles de fichiers, sockets, verrous réseau). Décrivez le pattern IDisposable et l’instruction using en montrant le code équivalent généré par le compilateur. (6 pts)
