Chapitre 2 — Données personnelles et données sensibles

Mise en situation

Chaque clic, chaque formulaire, chaque achat produit de la donnée. Décider si une information est une donnée personnelle — et si elle est sensible — commande toutes les obligations de l’entreprise.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. distinguer donnée personnelle directe, indirecte et non personnelle ;
  2. identifier les données sensibles ;
  3. définir un traitement de données personnelles ;
  4. citer les opérations qui constituent un traitement.

1. Qu’est-ce qu’une donnée personnelle

Une donnée personnelle est toute information relative à une personne physique identifiée ou identifiable. L’identification peut être :

  • directe : nom, prénom, empreinte digitale, biométrie ;
  • indirecte : numéro de téléphone, plaque d’immatriculation, adresse postale, courriel ;
  • à partir d’une seule donnée : ADN, numéro de matricule ;
  • par croisement de plusieurs données : un homme vivant à telle adresse, né tel jour et membre de telle organisation.
Les coordonnées d’entreprise

Les coordonnées d’une entreprise (adresse, téléphone, courriel générique de service) ne sont pas, en principe, des données personnelles. Dès qu’elles rattachent une personne physique, elles le redeviennent.

2. Les données sensibles

Les données sensibles sont des données à caractère personnel relatives à :

  • l’origine raciale ou ethnique ;
  • les opinions ou activités religieuses, philosophiques, politiques, syndicales ;
  • la vie sexuelle, la santé ;
  • les mesures d’ordre social ;
  • les poursuites, sanctions pénales ou administratives.

Leur traitement est soumis à des formalités renforcées : consentement exprès et encadrement strict. Leur violation est plus sévèrement punie (voir le chapitre 6).

3. Le traitement des données personnelles

Un traitement est une opération ou une suite d’opérations portant sur des données personnelles. Une entreprise réalise un traitement dès qu’elle effectue des opérations de :

  • collecte et enregistrement ;
  • organisation et conservation ;
  • adaptation et modification ;
  • utilisation et cession de données.
Le traitement, c’est le cycle de vie de la donnée

Collecter, ranger, garder, transformer, utiliser, transmettre : toute étape du parcours d’une donnée est un traitement. Dès la première opération, le RGPD s’applique.

4. Pourquoi protéger les données

Les données personnelles sont au cœur de l’économie numérique. Elles sont partout, mais à l’origine elles appartiennent à chaque citoyen : une personne qui livre ses données doit pouvoir contrôler leur sort.

La protection est d’autant plus nécessaire que le volume de données — et le nombre de cyberattaques — croît. L’indice mondial de protection des données de Dell EMC relevait une croissance exponentielle des volumes, de l’ordre de +569 %, et +701 % pour la seule France.

Le réflexe à acquérir

Avant tout traitement : identifier la donnée (personnelle ? sensible ?), nommer l’opération, vérifier la base légale, et garantir les droits des personnes.

5. Études de cas & applications pratiques

Ces trois études de cas se réalisent directement dans la page. Complétez chaque grille d’analyse à partir des données du cas, puis lancez la validation pour vérifier vos réponses critère par critère.

La validation compare vos réponses aux attendus des cas affichés ; elle ne vérifie pas votre capacité à traiter toutes les situations.

En cas d’hésitation, le bouton Obtenir une aide formative générale fournit un conseil identique pour toutes les grilles, sans transmettre de réponse attendue ni utiliser le tuteur IA.

Exercice 1 — Le formulaire d'inscription du site Kiféco

Étude de cas Formative Niveau 1 — Acquisition

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Repérer les données personnelles d'un formulaire réel et distinguer identification directe et indirecte.

Énoncé. Kiféco, boutique en ligne de kits solaires établie à Lomé, fait remplir à ses clients un formulaire d'inscription de huit champs :

N°Champ
1Nom du client
2Prénom du client
3Numéro de téléphone
4Adresse de livraison
5Courriel personnel
6Numéro de client attribué par Kiféco
7Raison sociale de l'entreprise (commandes professionnelles)
8Courriel générique de l'entreprise (contact@)

Rappel du cours : une donnée personnelle est toute information relative à une personne physique identifiée ou identifiable ; l'identification peut être directe (nom) ou indirecte (numéro, adresse). Les coordonnées d'une entreprise, rattachant une personne morale, ne sont pas en principe des données personnelles.

Répondez par le nombre seul pour la question 1 ; par le mot exact attendu pour les autres questions.

  1. Combien de ces huit champs recueillent-ils une donnée personnelle ?
  2. L'identification par le nom et le prénom est-elle directe ou indirecte ?
  3. Le numéro de téléphone, sans le nom, permet-il d'identifier une personne ?
  4. Le courriel générique de l'entreprise (contact@) est-il une donnée personnelle ?
  5. Quelle donnée de ce formulaire permet une identification indirecte : le numéro de client ou la raison sociale ?
Cas d’exemple
La plateforme LivraisonRapide recueille cinq champs : nom, prénom, numéro de téléphone, courriel générique du service client (contact@), matricule interne du livreur.

1) Données personnelles : nom, prénom, téléphone, matricule = 4.
2) Nom et prénom : identification directe.
3) Le téléphone sans le nom : oui, identification indirecte.
4) Le courriel générique : non.
5) L'identification indirecte : le matricule.
Trois indices, rédigés en mots
  1. Une donnée personnelle rattache une personne physique : dès qu'un champ désigne un être humain identifié ou identifiable, il en est une ; les coordonnées d'une société n'y suffisent pas.
  2. L'identification est directe quand le champ nomme la personne ; elle est indirecte quand il faut recouper ou interroger un fichier pour remonter jusqu'à elle.
  3. 1. Parcourez les huit champs et écartez ceux qui désignent la société. 2. Le nom et le prénom désignent la personne. 3. Un numéro suffit à joindre une personne identifiée dans un fichier. 4. Un courriel générique de service rattache une personne morale. 5. Comparez le numéro de client et la raison sociale.

Exercice 2 — La fiche d'adhésion du club Athlé Santé

Étude de cas Formative Niveau 1 — Acquisition

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Isoler les données sensibles d'une fiche réelle et rappeler la formalité exigée pour leur traitement.

Énoncé. Le club de remise en forme Athlé Santé, ouvert à Lomé, fait remplir à chaque nouvel adhérent une fiche de dix champs :

N°Champ
1Nom
2Prénom
3Courriel
4Adresse
5Tension artérielle relevée au premier cours
6Régime alimentaire demandé au snack, motif religieux
7Appartenance à un syndicat (réduction « adhérents syndiqués »)
8Traitement médical en cours, noté par l'entraîneur
9Origine ethnique renseignée « pour des statistiques d'audience »
10Créneau horaire préféré

Rappel du cours : les données sensibles touchent l'origine, les opinions (religieuses, syndicales, politiques), la santé et la vie sexuelle ; leur traitement exige le consentement exprès et un encadrement strict.

Répondez par le nombre seul pour la question 1 ; par le mot exact attendu pour les autres questions.

  1. Combien de champs portent-ils sur des données sensibles ?
  2. La tension artérielle relève de quelle catégorie de données sensibles ?
  3. L'appartenance syndicale est-elle une donnée sensible ?
  4. Le courriel est-il une donnée sensible ?
  5. Quelle formalité renforcée le traitement de ces données exige-t-il ?
Cas d’exemple
La mutuelle Solidarité collecte : nom, courriel, état de santé déclaré, opinions politiques d'un adhérent élu, régime alimentaire prescrit pour raisons de santé.

1) Données sensibles : état de santé, opinions politiques, régime prescrit (santé) = 3.
2) L'état de santé : catégorie santé.
3) Les opinions politiques : oui, sensibles.
4) Le courriel : non (personnelle, mais pas intime).
5) Formalité : le consentement exprès.
Trois indices, rédigés en mots
  1. Les données sensibles touchent l'intimité de la personne : origine, opinions, santé, vie sexuelle. Un simple moyen de contact n'en est pas une.
  2. Comptez les champs qui révèlent l'état de santé, une conviction ou une origine ; ne retenez pas les coordonnées de contact.
  3. 1. Passez les dix champs en revue et retenez ceux de l'intimité. 2. La tension est une donnée du corps. 3. Une opinion est sensible même si elle est déclarée volontairement. 4. Un courriel est une donnée personnelle, pas intime. 5. Relisez la formalité attachée aux données sensibles dans le rappel du cours.

Exercice 3 — Le fichier clients de l'imprimeure Mosaïque

Étude de cas Formative Niveau 2 — Application

Cette vérification est une aide à l’apprentissage : elle ne donne pas de note et ne valide pas les acquis.

Objectif : Nommer chaque opération constitutive d'un traitement au fil de la vie d'un fichier réel.

Énoncé. Mosaïque, imprimerie de Kara, gère son fichier clients de la façon suivante : Léa, la gérante, réceptionne les bons de commande papier au comptoir ; elle les saisit dans le logiciel de gestion ; elle classe les fiches par quartier de livraison ; elle archive les fiches pendant trois ans ; elle corrige les adresses quand un client déménage ; chaque samedi, elle transmet la liste des livraisons à la société de transport partenaire ; au bout de trois ans, elle broie les papiers.

Rappel du cours : un traitement est toute opération portant sur des données personnelles — collecte et enregistrement, organisation et conservation, adaptation et modification, utilisation et cession. Dès la première opération, le régime de protection s'applique.

Répondez par le mot exact attendu, en deux mots au plus (par exemple « collecte »).

  1. La réception des bons au comptoir correspond à quelle opération ?
  2. La saisie dans le logiciel correspond à quelle opération ?
  3. La transmission hebdomadaire au transporteur correspond à quelle opération ?
  4. L'archivage pendant trois ans correspond à quelle opération ?
  5. Dès la première opération (la réception des bons), le régime de protection s'applique-t-il ?
Cas d’exemple
Le garage AutoPropre gère son fichier : réception des fiches au comptoir, saisie dans le logiciel, tri des fiches par marque de véhicule, garde des fiches deux ans, envoi des plaques au loueur partenaire.

1) Comptoir : collecte.
2) Logiciel : enregistrement.
3) Envoi au loueur : cession.
4) Garde deux ans : conservation.
5) Dès la collecte : oui, le régime s'applique.
Trois indices, rédigés en mots
  1. Le traitement est le cycle de vie de la donnée : collecter, ranger, garder, transformer, transmettre — chaque étape a son nom dans le cours.
  2. Chaque geste de Léa correspond à un terme de la liste : réceptionner, saisir, transmettre, archiver.
  3. 1. La réception des papiers est le premier geste du cycle. 2. La saisie inscrit la donnée dans un fichier. 3. La transmission fait sortir la donnée vers un tiers. 4. L'archivage maintient la donnée dans le temps. 5. Relisez la dernière phrase du rappel.

6. QCM — niveau examen

Une donnée personnelle est…

Une donnée personnelle est une information sur une personne identifiée ou identifiable, directement ou non. Ni un fichier de musique ni un brevet : ce ne sont pas des informations sur une personne.

Un exemple de donnée personnelle directe ?

Le nom et le prénom identifient la personne directement, sans déduction. La plaque et le courriel exigent un rapprochement : ils sont indirects.

Un exemple de donnée indirecte ?

Le numéro de téléphone est une donnée indirecte : il faut le rapprocher d’un annuaire pour identifier la personne. Empreinte et nom sont directs.

Une donnée sensible ?

Origine, opinions, santé, vie sexuelle, sanctions.

Les coordonnées d’entreprise sont…

Elles ne visent pas une personne physique en principe.

Un traitement de données, c’est…

Un traitement est une opération ou une suite d’opérations sur des données : collecte, enregistrement, conservation, diffusion. Ni un antivirus ni un contrat de travail.

La conservation est-elle un traitement ?

Conserver est une opération de traitement.

La cession de données est…

Transmettre des données est un traitement.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Traiter la donnée personnelle et la donnée sensible comme équivalentes.
  • Oublier qu’une donnée indirecte peut identifier une personne.
  • Croire qu’un traitement suppose une action spectaculaire : même la conservation en est un.
  • Négliger le consentement exprès pour les données sensibles.
  • Penser qu’un courriel générique d’entreprise est une donnée personnelle.

8. Méthodologie de résolution

Qualifier une donnée et son traitement
  1. Identifier la personne visée par l’information.
  2. Tester l’identification : directe, indirecte, par croisement ?
  3. Repérer un caractère sensible (origine, opinions, santé, sanctions).
  4. Nommer l’opération : collecte, conservation, cession…
  5. En déduire les obligations : base légale et droits des personnes.

9. Révision active

Résumé essentiel
  • Donnée personnelle : information sur une personne identifiée ou identifiable.
  • Identification directe, indirecte, par une seule donnée ou par croisement.
  • Données sensibles : origine, opinions, santé, vie sexuelle, mesures et sanctions.
  • Traitement : toute opération sur des données personnelles.
  • Le RGPD s’applique dès la première opération de traitement.

Checklist de maîtrise

  • Je classe une donnée en personnelle directe, indirecte ou non.
  • Je reconnais une donnée sensible.
  • Je définis un traitement.
  • Je cite les opérations constitutives d’un traitement.

10. Test de maîtrise

Comment vous auto-évaluer

Le QCM ci-dessus est un test de maîtrise. Lisez votre pourcentage :

< 50 % — Reprenez la définition de la donnée personnelle.
50–69 % — Entraînez-vous sur les données sensibles.
70–94 % — Solide : vous qualifiez données et traitements.
≥ 95 % — Maîtrise : passez aux défis du numérique, chapitre 3.
