Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque module, puis un projet final qui outille un registre de conformité. Les scripts sont en Bash, comme à l’atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lis n lignes « code libelle » (p personnelle, s sensible, autre) et affiche la catégorie, puis le nombre de données sensibles.
  2. Lis un chiffre d’affaires et affiche 4 % de ce montant (entier).
  3. Lis n numéros d’article (55, 68, 79, 86, 87, 93) et affiche l’objet de chacun, ou inconnu.
Corrections
read -r n
sensibles=0
for ((k=0; k<n; k++)); do
  read -r code libelle
  case "$code" in
    p) echo "$libelle : personnelle" ;;
    s) echo "$libelle : sensible" ; sensibles=$((sensibles + 1)) ;;
    *) echo "$libelle : autre" ;;
  esac
done
echo "sensibles : $sensibles"

read -r chiffre
echo "4 pourcent : $((chiffre * 4 / 100))"

read -r n
for ((k=0; k<n; k++)); do
  read -r article
  case "$article" in
    55) echo "55 : creation de l IPDCP" ;;
    68) echo "68 : mission de controle" ;;
    79) echo "79 : traitements sans formalites" ;;
    86) echo "86 : donnees sensibles" ;;
    87) echo "87 : condamnations" ;;
    93) echo "93 : entrave au controle" ;;
    *) echo "$article : inconnu" ;;
  esac
done

Application

Application
  1. Lis n traitements « nom consentement » (oui ou non) et affiche conforme ou non conforme, puis le bilan.
  2. Lis n entreprises « nom chiffre_affaires » et affiche la sanction RGPD de chacune (20 M€ minimum, sinon 4 %), puis le total.
  3. Lis n articles et affiche la peine d’emprisonnement maximale de chacun (79, 86, 87 : 5 ans ; 93 : 2 ans), puis la somme des maxima.
Corrections
read -r n
conformes=0
for ((k=0; k<n; k++)); do
  read -r nom consentement
  if [ "$consentement" = "oui" ]; then
    echo "$nom : conforme"
    conformes=$((conformes + 1))
  else
    echo "$nom : non conforme"
  fi
done
echo "conformes : $conformes/$n"

read -r n
total=0
for ((k=0; k<n; k++)); do
  read -r nom ca
  sanction=$((ca * 4 / 100))
  if [ "$sanction" -lt 20000000 ]; then sanction=20000000; fi
  echo "$nom : $sanction"
  total=$((total + sanction))
done
echo "total : $total"

read -r n
total=0
for ((k=0; k<n; k++)); do
  read -r article
  case "$article" in
    79|86|87) ans=5 ;;
    93) ans=2 ;;
    *) ans=0 ;;
  esac
  echo "article $article : $ans ans maximum"
  total=$((total + ans))
done
echo "somme des maxima : $total ans"

Raisonnement

Raisonnement
  1. Lis le type (intentionnel ou negligence) puis n faits « code libelle » (formalites, sensible, condamnation, entrave) et affiche l’article et la peine.
  2. Lis n opérations (collecte, enregistrement, organisation, conservation, adaptation, modification, utilisation, cession ou autre) et distingue traitement et hors traitement.
  3. Lis n traitements « nom consentement finalite minimisation » et affiche conforme ou le nombre de principes manquants, puis le taux de conformité en pourcentage.
Corrections
read -r type
read -r n
for ((k=0; k<n; k++)); do
  read -r code libelle
  case "$code" in
    formalites)
      if [ "$type" = "negligence" ]; then
        echo "$libelle : article 79 (1 a 3 ans)"
      else
        echo "$libelle : article 79 (1 a 5 ans)"
      fi ;;
    sensible) echo "$libelle : article 86 (1 a 5 ans)" ;;
    condamnation) echo "$libelle : article 87 (1 a 5 ans)" ;;
    entrave) echo "$libelle : article 93 (6 mois a 2 ans)" ;;
    *) echo "$libelle : aucune qualification" ;;
  esac
done

read -r n
traitements=0
for ((k=0; k<n; k++)); do
  read -r operation
  case "$operation" in
    collecte|enregistrement|organisation|conservation|adaptation|modification|utilisation|cession)
      echo "$operation : traitement"
      traitements=$((traitements + 1)) ;;
    *) echo "$operation : hors traitement" ;;
  esac
done
echo "traitements : $traitements/$n"

read -r n
conformes=0
for ((k=0; k<n; k++)); do
  read -r nom c f m
  manquants=0
  for v in "$c" "$f" "$m"; do
    [ "$v" = "non" ] && manquants=$((manquants + 1))
  done
  if [ "$manquants" -eq 0 ]; then
    echo "$nom : conforme"
    conformes=$((conformes + 1))
  else
    echo "$nom : $manquants principe(s) manquant(s)"
  fi
done
echo "conformes : $conformes/$n"
echo "taux : $((conformes * 100 / n)) %"

Projet intégrateur : registre de conformité

Cahier des charges

Le script reçoit le registre d’une entreprise : d’abord n, le nombre de traitements, puis n lignes au format nom consentement finalite minimisation sensible, chaque valeur valant oui ou non. Il contrôle les trois principes du RGPD pour chaque traitement, signale les données sensibles conservées sans consentement (article 86 de la loi togolaise), puis produit le bilan.

Fonctionnalités attendues
  1. Lire d’abord le nombre de traitements, puis une ligne par traitement.
  2. Contrôler consentement, finalité et minimisation : conforme seulement si les trois valent oui.
  3. Signaler un risque pénal article 86 si le traitement est sensible et sans consentement.
  4. Bilan : conformes, non conformes, risques article 86, formats exacts.

Contraintes : une boucle de lecture, trois compteurs, aucun bilan à l’intérieur de la boucle.

Grille d’auto-évaluation du projet (sur 100)
Lecture des lignes sans mélange 20
Contrôle des trois principes exact 25
Signalement du risque article 86 correct 25
Compteurs fiables 15
Bilan final lisible et complet 15

Objectif : ≥ 95/100 avant de considérer le projet terminé.

read -r n
conformes=0
non_conformes=0
risques=0
for ((k=0; k<n; k++)); do
  read -r nom consentement finalite minimisation sensible
  manquants=0
  for v in "$consentement" "$finalite" "$minimisation"; do
    [ "$v" = "non" ] && manquants=$((manquants + 1))
  done
  if [ "$manquants" -eq 0 ]; then
    echo "$nom : conforme"
    conformes=$((conformes + 1))
  else
    echo "$nom : non conforme"
    non_conformes=$((non_conformes + 1))
  fi
  if [ "$sensible" = "oui" ] && [ "$consentement" = "non" ]; then
    echo "$nom : risque penal article 86"
    risques=$((risques + 1))
  fi
done
echo "conformes : $conformes"
echo "non conformes : $non_conformes"
echo "risques article 86 : $risques"
Cette solution combine la lecture ligne à ligne, le contrôle des principes du chapitre 5 et la qualification pénale du chapitre 6 en un seul script.
