Mémo synthétique ERP & Systèmes d’Information

Toutes les formules de gestion, règles comptables, notations BPMN et équations clés réunies sur une seule page de référence.

1. Composantes du SI & Modélisation du TCO

// Les 5 composantes interdépendantes du SI
SI = Matériel (Hardware) + Logiciel (Software) + Données (Data) + Processus (Workflows) + Humains (Acteurs)

// Calcul du TCO (Total Cost of Ownership) sur 5 ans
TCO_OnPremise = Capex_initial + 5 * (Maintenance_licences_18% + Admin_sys + Energie + Sauvegardes)
TCO_SaaS      = Integration_initiale + 5 * (Abonnement_mensuel * 12 + Support_Cloud)

2. Modélisation de Processus BPMN 2.0

// Événements (Cercles)
[O] Fin fin cercle épais  |  (o) Intermédiaire double cercle  |  ( ) Début cercle simple

// Passerelles (Losanges - Gateways)
[X]  Exclusive (XOR) : un seul chemin conditionnel possible
[+]  Parallèle (AND) : tous les chemins s’exécutent simultanément
[O]  Inclusive (OR)  : un ou plusieurs chemins selon conditions

// Organisation des responsabilités
Pool : organisation ou entité juridique externe
Lane : rôle métier, service ou département au sein de l’organisation

3. Intégration Applicative & Formats Pivots

// Comparatif des topologies d’intégration
Point-à-point : N * (N - 1) / 2 interfaces  -> Complexité spaghetti ingérable
ESB (Hub)     : N interfaces vers le bus   -> Découplage, routage et médiation

// Paradigmes d’intégration de données
ETL (Extract - Transform - Load) : transformation avant chargement (DWH classique)
ELT (Extract - Load - Transform) : chargement brut puis transformation dans le Cloud Data Warehouse

4. Cycles Métiers & Calcul des Besoins Nets (MRP)

// Cycle Procure-to-Pay (P2P - Fournisseurs)
Demande d’Achat (DA) -> Bon de Commande (PO) -> Bon de Réception (GR) -> Three-Way Matching -> Règlement

// Cycle Order-to-Cash (O2C - Clients)
Devis -> Bon de Commande client -> Bon de Livraison (Décrémentation stock) -> Facture -> Encaissement

// Équation fondamentale du Besoin Net en MRP
Besoin_Net = max(0, Besoin_Brut - Stock_Initial - Receptions_Prevues + Stock_Securite)

5. Règles Comptables & Formules de Stock

// Comptabilité en partie double
Σ Débits = Σ Crédits (Égalité absolue)
Bilan : Actif (Emplois) = Passif (Ressources)

// Valorisation des stocks au CMUP (après chaque nouvelle entrée)
CMUP_nouveau = ((Stock_ancien * CMUP_ancien) + (Quantite_recue * Prix_achat_unitaire)) / (Stock_ancien + Quantite_recue)

// Modèle de Wilson (Quantité économique de commande - EOQ)
Q* = √( (2 * D * C_s) / C_p )
avec D = Demande annuelle, C_s = Coût de passation de commande, C_p = Coût unitaire de possession

6. Conduite de Projet ERP & Criticité des Risques

// Évaluation matricielle de la criticité d’un risque
Criticité (C) = Probabilité d’occurrence (P) * Gravité de l’impact (G)

// Niveaux de criticité
C < 6   : Risque faible (surveillance de routine)
6 ≤ C ≤ 12 : Risque modéré (plan d’action préventif obligatoire)
C > 12  : Risque critique (revue hebdomadaire en comité de direction, plan de contingence)
