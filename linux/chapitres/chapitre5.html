Chapitre 5 — Scripts Bash : lire, décider, rapporter

Module 5 ≈ 2 h 30 de travail Réservé B2 et plus
Mise en situation

Répéter à la main une suite de commandes est une source d’erreur. L’administrateur automatise : un script lit les données, décide selon la règle métier et produit un rapport. C’est le squelette lire → décider → rapporter que l’on retrouve dans tous les exercices.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. déclarer et utiliser des variables, y compris les paramètres positionnels ;
  2. lire l’entrée standard avec read dans une boucle ;
  3. décider avec if, test et case ;
  4. écrire une fonction et interpréter son code de retour.

1. Variables et paramètres

Une variable s’assigne sans espace autour du = et s’utilise avec un $. Les paramètres positionnels arrivent automatiquement : $0 est le nom du script, $1, $2… les arguments, $# leur nombre, $@ la liste complète.

#!/bin/bash
compteur=0            # PAS de$compteur=0 (espace interdit)
echo "arguments : $#"
for argument in "$@"; do echo "$argument"; done
total=$((a + b))       # arithmétique entière
Le shebang

La première ligne #!/bin/bash désigne l’interpréteur. Sans elle, le script est exécuté par le shell courant, dont les extensions (boucles C, tableaux) peuvent manquer.

2. Lire l’entrée : read

read lit une ligne de l’entrée standard et la range dans une ou plusieurs variables. Le grand classique est le compteur n lu en premier, puis une boucle qui lit les lignes.

read -r n                 # premier : le nombre de lignes
for ((i=0; i<n; i++)); do
  read -r nom type         # une lecture par ligne
  # … traiter
done
Piège — la dernière ligne sans retour à la ligne

Si l’entrée ne se termine pas par un retour à la ligne, le dernier read touche la fin de fichier et échoue : la dernière donnée est perdue. Toujours terminer l’entrée par une ligne vide finale.

3. Décider : if et case

if compare avec test ; case aiguille selon un motif — idéal pour classer des chaînes (un type, une extension, une classe de droits).

if [ "$taille" -ge 1024 ]; then echo "gros"; else echo "petit"; fi
case "$fichier" in
  *.sh) echo "script" ;;
  *.log) echo "journal" ;;
  *) echo "autre" ;;
esac
Comparer proprement

Nombres : -eq -ne -lt -le -gt -ge. Chaînes : = et !=. Toujours entre guillemets : [ "$v" = "OK" ], sinon une variable vide casse le test.

4. Fonctions et code de retour

Une fonction regroupe du code réutilisable et renvoie un code de retour : 0 signifie succès, toute valeur non nulle un échec. C’est ce code qu’utilisent if et les enchaînements && / ||.

est_gros() {
  [ "$1" -ge 1024 ]
}
if est_gros 2048; then echo "gros"; fi
commande && echo "reussi" || echo "echoue"
Le squelette du cours

Tout exercice suit le même plan : lire les données, décider selon la règle, puis rapporter une seule fois après la boucle. Séparer le traitement du bilan évite le bug classique du compteur affiché à chaque passage.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute le code et la validation fait tourner des jeux de tests indépendants : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire le code de la solution — c’est le principe de l’exercice.

Exercice 1 — Additionner une série de valeurs

Bash Niveau 1 — Acquisition

Objectif : Cumuler les entiers lus et afficher le total.

Le script lit n, puis n lignes contenant chacune un entier (éventuellement négatif). Il calcule la somme et affiche somme : X.

Entrée du programme
3
4
6
10
Sortie attendue
somme : 20
Deux indices, rédigés en mots
  1. L’addition arithmétique s’écrit s=$((s + v)).
  2. La somme s’affiche une seule fois, après la boucle.

Exercice 2 — Trouver le maximum

Bash Niveau 2 — Application

Objectif : Parcourir une série et garder la plus grande valeur.

Le script lit n, puis n lignes contenant chacune un entier. Il affiche max : X où X est la plus grande valeur rencontrée.

Entrée du programme
3
5
9
2
Sortie attendue
max : 9
Deux indices, rédigés en mots
  1. La première valeur sert de maximum initial.
  2. On compare ensuite chaque nouvelle valeur à max avec [ "$v" -gt "$max" ].

Exercice 3 — Classer des fichiers par taille

Bash Niveau 2 — Application

Objectif : Écrire une règle de diagnostic et compter les gros fichiers.

Le script lit n lignes « nom taille » où taille est un nombre d’octets. Il affiche nom : gros si la taille est supérieure ou égale à 1024, nom : petit sinon, puis termine par gros : X.

Entrée du programme
2
log.txt 2048
notes 512
Sortie attendue
log.txt : gros
notes : petit
gros : 1
Deux indices, rédigés en mots
  1. La comparaison se fait avec [ "$taille" -ge 1024 ].
  2. Le seuil est inclusif : 1024 est déjà « gros ».

6. QCM — niveau examen

Que vaut $# dans un script ?

$# contient le nombre de paramètres positionnels ; $0 est le nom du script.

Quel paramètre est le premier argument ?

$1 est le premier argument ; $0 est le nom du script.

Une boucle for ((i=0; i

bash supporte la syntaxe arithmétique dite « style C ».

Comparaison numérique pour « supérieur ou égal » ?

-ge = greater or equal ; -gt = strictement supérieur.

Que signifie un code de retour 0 ?

En shell, 0 = succès, toute autre valeur = échec.

Que fait read -r n ?

-r empêche l’interprétation des barres obliques inverses ; la ligne est rangée dans n.

Le bilan d’un compteur s’affiche…

Affiché après la boucle, il sort une seule fois, avec le total final.

Que vaut $@ ?

$@ déroule tous les paramètres positionnels.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Mettre des espaces autour du = lors d’une affectation.
  • Oublier les guillemets dans un test : [ $v = OK ] casse si v est vide.
  • Afficher le bilan dans la boucle au lieu d’après.
  • Terminer l’entrée sans retour à la ligne et perdre la dernière donnée.
  • Confondre > (strict) et >= (-ge) dans une comparaison.

8. Méthodologie de résolution

Écrire un script robuste
  1. Lire d’abord le compteur, puis chaque ligne dans la boucle.
  2. Initialiser les compteurs et le maximum avant la boucle.
  3. Décider avec if ou case selon la nature de la donnée.
  4. Rapporter une seule fois, après la boucle.
  5. Tester sur trois jeux : cas courant, cas limite, cas vide (n = 0).

9. Révision active

Résumé essentiel
  • Variables sans espaces autour du = ; $1… les arguments, $# leur nombre, $@ la liste.
  • read lit une ligne ; le compteur n se lit avant la boucle.
  • if/test compare, case aiguille selon un motif (*.sh, type…).
  • Une fonction renvoie un code : 0 succès, non nul échec.
  • Le squelette lire → décider → rapporter structure tous les scripts du cours.

Checklist de maîtrise

  • J’écris une boucle qui lit n puis n lignes.
  • J’utilise les bons opérateurs de comparaison.
  • J’écris un case pour classer des chaînes.
  • J’affiche le bilan après la boucle, une seule fois.
