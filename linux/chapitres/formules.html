Mémo de l’administrateur

Arborescence, commandes, droits, réseau, services et squelettes de scripts du cours sur une page. À garder ouvert pendant les exercices et l’atelier.

L’arborescence en une image

/          racine : origine de tout

etc        configuration (à sauvegarder)      home   répertoires des utilisateurs

tmp        temporaires, vidés au reboot        var    journaux, spools, bases

root       maison du super-utilisateur         dev    fichiers des périphériques

usr        programmes et bibliothèques         bin/sbin  binaires essentiels

boot       noyau et démarrage                  proc   arborescence virtuelle du noyau

Tout chemin absolu commence par / ; /root n’est pas /.

Commandes de base

où suis-je        pwd            changer      cd chemin

lister            ls [-a -l]      créer rep    mkdir -p

créer fichier     touch          copier      cp [-r] source cible

renommer/déplacer mv             supprimer   rm [-r] (danger : -f)

afficher          cat, head, tail            manuel      man cmd

écrire            echo "x" > f (écrase) ; echo "x" >> f (ajoute)

Syntaxe immuable : COMMANDE OPTIONS ARGUMENTS — ls -l /home.

Chercher : find et grep

find /tmp -name "fich*"     -type f|d    -size +10M   -user root

find / -perm -4000 -type f  # audit setuid

grep "ERROR" /var/log/syslog   -c (compte)   -i (casse)   -v (inverse)

journalctl -u service   -p err -b   tail -f /var/log/syslog

Toujours des guillemets autour du motif de find, sinon le shell le développe.

Droits d’accès

-rwxr-x---     type(-,d,l) + u:rwx  g:r-x  o:---

poids          r=4  w=2  x=1  →  rwx=7  r-x=5  rw-=6  ---=0

octal          rwxr-x--- = 750 ; rw-r--r-- = 644 ; rw-r----- = 640

chmod          symbolique (u/g/o/a + - = lettres) ou octal ; -R récursif

chown          propriétaire (utilisateur:groupe) ; chgrp groupe

vérifier       ls -l, id utilisateur

+ ajoute, - retire, = fixe exactement : ug=rwx efface ce qui dépassait rwx.

Comptes et groupes

/etc/passwd  login:mot-de-passe:UID:GID:info:maison:shell

             x ou ! = mot de passe dans shadow ; * interdit ; !! désactive

/etc/shadow  mots de passe chiffrés (root seul)

/etc/group   groupe:*:GID:utilisateurs

commandes    useradd, usermod, userdel -r, passwd, groupadd, groupdel

UID          root = 0 ; < 1000 = système ; ≥ 1000 = humains

id utilisateur affiche UID, GID et groupes secondaires.

Réseau et SSH

ip a ; ip route          adresses et passerelle (default via)

privées  10.0.0.0/8 ; 172.16–172.31 ; 192.168.0.0/16

statique /etc/network/interfaces : address / gateway / dns-nameservers

ssh user@hote:port       port 22 par défaut

ssh-keygen -t ed25519 ; ssh-copy-id user@hote ; scp f user@hote:/tmp/

Adresse IPv4 valide : exactement quatre octets de 0 à 255.

Services, processus, planification

systemctl status|start|restart|enable service

active → rien ; inactive → start ; failed → restart

ps aux ; top ; kill PID (propre) ; kill -9 PID (dernier recours)

cron : minute heure jour mois jour-semaine  commande

journalctl -u service   journalctl -p err -b

Un zombie est un processus terminé non récupéré par son parent.

Squelette d’un script Bash

#!/bin/bash

read -r n                    # premier : le compteur d’entrées

compteur=0                   # initialisation AVANT la boucle

for ((i=0; i<n; i++)); do

  read -r valeur             # une lecture par ligne d’entrée

  case "$valeur" in OK) compteur=$((compteur + 1)) ;; esac

done

echo "compteur : $compteur"  # bilan APRÈS la boucle

Comparer des nombres : -eq -ne -lt -le -gt -ge. Toujours entre guillemets dans [ ].

Erreurs fréquentes à éviter

  • Confondre / (racine) et /root (maison de root).
  • Écrire les journaux dans /etc au lieu de /var.
  • Un seul chevron > qui écrase un fichier de configuration.
  • Ouvrir un fichier en 777 au lieu d’accorder le droit à la bonne classe.
  • Redémarrer un service sans lire son status ni son journal.
  • Lire le seuil après n, ou oublier le retour à la ligne final du dernier read.
