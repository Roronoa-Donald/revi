Chapitre 1 — Objets et classes

Module 1 ≈ 2 h de travail Accès libre
Mise en situation

En procédural, on range les données dans des tableaux et on les fait circuler de fonction en fonction : personne ne garantit qu’un « client » a bien un nom, un solde et un historique. La programmation orientée objet réunit les données et les opérations qui les concernent dans une même entité : la classe.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. expliquer l’intérêt d’une classe par rapport à un tableau associatif ;
  2. déclarer une classe avec propriétés, constructeur et méthodes ;
  3. utiliser $this pour atteindre l’état de l’objet courant ;
  4. instancier un objet et appeler ses méthodes.

1. Pourquoi passer à l’objet

Un tableau associatif (["nom" => "Ada", "solde" => 100]) transporte bien des données, mais rien ne l’empêche d’oublier une clé ou d’accepter un solde négatif. Une classe décrit la forme d’une donnée : quelles propriétés elle possède et quelles opérations ont le droit de la modifier.

La classe est le moule, l’objet est la pièce produite. Un objet de la classe CompteBancaire connaît son titulaire et son solde, et sait se décrire ou retirer de l’argent. Deux objets différents ont chacun leur propre état.

Une classe = données + comportements

Les propriétés (variables) décrivent l’état ; les méthodes (fonctions) décrivent les actions. En les réunissant, on peut raisonner sur le « client » ou le « compte » comme sur une entité complète plutôt que sur une série de tableaux.

2. Déclarer une classe et son constructeur

On déclare une classe avec le mot-clé class. Le constructeur __construct() est appelé automatiquement à la création de l’objet : c’est l’endroit naturel pour ranger les valeurs reçues.

<?php
class Point {
    private $x;
    private $y;

    public function __construct(int $x, int $y) {
        $this->x = $x;
        $this->y = $y;
    }
}

$this représente l’objet en cours de construction ou d’utilisation. Écrire $this->x = $x range l’argument dans la propriété x de cet objet — pas dans une variable globale.

Piège — la flèche, pas le point

En PHP, on atteint un membre avec -> ($this->x), jamais avec le point qui reste la concaténation de chaînes. Confondre $this.x et $this->x est l’erreur numéro un des débutants venus de JavaScript ou de Python.

3. Méthodes et état

Une méthode lit et modifie l’état de l’objet. Elle accède aux propriétés via $this et peut renvoyer un résultat avec return.

public function afficher(): string {
    return "(" . $this->x . ", " . $this->y . ")";
}

Le type de retour (: string) documente le contrat : la méthode promet une chaîne. PHP vérifie cette promesse à l’exécution et lève une erreur si le contrat n’est pas tenu.

4. Instancier et utiliser un objet

On crée un objet avec new, ce qui déclenche le constructeur. On appelle ensuite ses méthodes avec la même flèche.

$p = new Point(3, 4);
echo $p->afficher();     // (3, 4)
echo $p->x;              // interdit : x est privé

Une propriété privée n’est accessible que depuis l’intérieur de la classe : c’est le chapitre 2 qui explique comment l’ouvrir proprement avec des getters et des setters.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Premier objet

PHP Niveau 1 — Acquisition

Objectif : Créer une classe, un constructeur et une méthode, puis instancier.

Le programme reçoit deux lignes : x puis y (entiers). Écris une classe Point avec un constructeur qui range les deux coordonnées et une méthode afficher() qui renvoie la chaîne (x, y). Instancie le point et affiche le résultat.

Entrée du programme
3
4
Sortie attendue
(3, 4)

Deux entiers lus, un couple affiché.

Deux indices, rédigés en mots
  1. Le constructeur s’écrit __construct(int $x, int $y) et affecte $this->x et $this->y.
  2. Deux valeurs se concatènent avec le point : '(' . $this->x . ', ' . $this->y . ')'.

Exercice 2 — Enchaîner les appels

PHP Niveau 2 — Application

Objectif : Faire renvoyer $this par une méthode pour enchaîner les appels.

Le programme reçoit n, puis n prix (entiers). Écris une classe Panier dont la méthode ajouter(int $prix) cumule le prix et renvoie $this, et dont la méthode total() renvoie le total. Ajoute les prix, puis affiche total : X.

Entrée du programme
3
10
20
30
Sortie attendue
total : 60

Trois prix cumulés.

Deux indices, rédigés en mots
  1. Une méthode qui renvoie $this permet d’enchaîner : $panier->ajouter(10)->ajouter(20).
  2. Le type de retour d’une méthode renvoyant l’objet courant s’écrit : self.

Exercice 3 — Constructeur qui valide

PHP Niveau 2 — Application

Objectif : Assainir une valeur dans le constructeur.

Le programme reçoit un âge (entier, éventuellement négatif). Écris une classe Age dont le constructeur ramène toute valeur négative à 0, et une méthode valeur() qui renvoie l’âge. Affiche age : X.

Entrée du programme
25
Sortie attendue
age : 25

Valeur positive conservée.

Deux indices, rédigés en mots
  1. Une expression ternaire choisit la valeur : $age < 0 ? 0 : $age.
  2. L’objet s’instancie directement dans l’affichage : (new Age($age))->valeur().

6. QCM — niveau examen

Quelle est la différence entre classe et objet ?

La classe décrit la forme ; new en produit des objets (instances) distincts.

Quand le constructeur est-il exécuté ?

__construct() s’exécute à chaque new, pour initialiser l’objet.

Que représente $this ?

$this est l’instance en cours d’utilisation.

Comment atteint-on une propriété en PHP ?

La flèche -> atteint membres et méthodes : $this->x.

Que fait le point en PHP ?

Le point est l’opérateur de concaténation, pas d’accès aux membres.

Une propriété private est accessible…

private réserve l’accès au code de la classe elle-même.

Que promet `: string` après un nom de méthode ?

C’est la déclaration du type renvoyé : le contrat est vérifié.

Deux objets d’une même classe partagent-ils leur état ?

Chaque instance porte ses propres valeurs de propriétés.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Confondre . (concaténation) et -> (accès aux membres).
  • Oublier $this-> et écrire une variable locale au lieu d’une propriété.
  • Déclarer une propriété sans visibilité ni valeur et la lire avant toute affectation.
  • Croire que le constructeur retourne une valeur : il initialise, il ne renvoie rien.
  • Oublier qu’une propriété privée est inaccessible depuis l’extérieur de la classe.

8. Méthodologie de résolution

Écrire une classe propre
  1. Nommer l’entité métier en pensant à l’objet, pas à la table de données.
  2. Lister l’état : quelles propriétés décrivent un objet complet ?
  3. Écrire le constructeur qui range ces propriétés à partir d’arguments typés.
  4. Définir les méthodes qui lisent ou transforment l’état via $this.
  5. Tester en petit : instancier deux objets et vérifier qu’ils sont indépendants.

9. Révision active

Résumé essentiel
  • Une classe réunit des propriétés (état) et des méthodes (comportements).
  • new crée un objet et déclenche __construct().
  • $this désigne l’objet courant ; on atteint ses membres avec ->.
  • Le point . concatène des chaînes, il n’accède pas aux membres.
  • La visibilité private réserve l’accès au code de la classe.

Checklist de maîtrise

  • Je distingue classe, objet et instance.
  • Je déclare une classe avec propriétés, constructeur et méthodes.
  • J’utilise $this et -> sans les confondre avec le point.
  • J’instancie deux objets et je vérifie qu’ils sont indépendants.
