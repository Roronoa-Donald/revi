Chapitre 2 — Encapsulation, constantes et membres statiques

Module 2 ≈ 2 h de travail Réservé B2 et plus
Mise en situation

Un objet dont on peut modifier l’état librement de l’extérieur est un tableau déguisé. Protéger l’état derrière des méthodes qui vérifient ce qu’on leur donne, c’est la différence entre du code qui tient et du code qui casse au premier solde négatif.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. choisir la bonne visibilité pour chaque propriété et méthode ;
  2. exposer l’état par des getters et le modifier par des setters qui valident ;
  3. déclarer une constante de classe et la lire avec self:: ;
  4. utiliser un membre statique partagé par tous les objets.

1. Encapsulation et visibilité

La visibilité décide qui peut toucher un membre. public l’ouvre à tout le monde, private le réserve à la classe, protected l’ouvre aussi aux classes filles (chapitre 3). Le principe d’encapsulation : propriétés en private, méthodes publiques qui contrôlent l’accès.

class Compte {
    private $solde;

    public function solde(): float {
        return $this->solde;
    }
}
Le soupirail, pas la porte ouverte

Une propriété publique se modifie de partout : n’importe quel bout de code peut écrire $compte->solde = -500. Avec un private et un setter, on ne peut passer que par une porte qui trie : c’est là qu’on refuse une valeur absurde.

2. Getters et setters qui valident

Un getter (getX() ou x()) lit l’état ; un setter (setX()) l’écrit et en profite pour valider. Une valeur invalide déclenche une exception plutôt que de corrompre l’objet.

public function setSolde(float $solde): void {
    if ($solde < 0) {
        throw new InvalidArgumentException("solde négatif");
    }
    $this->solde = $solde;
}

Le setter peut aussi renvoyer $this pour permettre l’enchaînement ($compte->setNom(...)->setSolde(...)), une convention dite interface fluide.

3. Constantes de classe

Une constante de classe const appartient à la classe, pas aux objets : elle est fixée à la déclaration et ne change jamais. On la lit avec self:: à l’intérieur et Classe:: à l’extérieur.

class Facture {
    const TVA = 18.0;

    public function ttc(float $ht): float {
        return $ht * (1 + self::TVA / 100);
    }
}
Piège — un $ de trop

Une constante s’écrit const TVA = 18; et se lit self::TVA : pas de $, ni à la déclaration, ni à l’usage. Y ajouter un $ transforme la constante en propriété.

4. Membres statiques

Un membre static appartient à la classe elle-même, non à un objet : il est partagé par toutes les instances. Utile pour un compteur d’objets ou une méthode outil qui n’a pas besoin d’état.

class Utilisateur {
    private static $nombre = 0;

    public function __construct() {
        self::$nombre++;
    }

    public static function nombre(): int {
        return self::$nombre;
    }
}

On appelle une méthode statique sans instance : Utilisateur::nombre(). À l’intérieur, $this n’existe pas — on parle de la classe avec self.

Exercice 1 — Propriété privée et setter

PHP Niveau 2 — Application

Objectif : Protéger une propriété derrière un setter qui valide.

Le programme reçoit n puis n montants (entiers). Écrivez une classe Compte avec une propriété privée $solde valant 0 et une méthode deposer(int $montant) qui n’ajoute que les montants strictement positifs. Affichez solde : X.

Entrée du programme
3
50
-10
20
Sortie attendue
solde : 70

Le montant négatif est ignoré.

Deux indices, rédigés en mots
  1. Le mot-clé private interdit l’accès direct : seule la méthode de la classe peut modifier $solde.
  2. Un montant n’est déposé que si $montant > 0.

Exercice 2 — Constante de classe

PHP Niveau 2 — Application

Objectif : Utiliser une constante et une méthode statique.

Le programme reçoit un prix hors taxe (entier). Écrivez une classe Config avec la constante TVA = 18 (pour cent) et une méthode statique ttc(int $ht) qui renvoie le prix TTC arrondi à l’entier inférieur. Affichez ttc : X.

Entrée du programme
100
Sortie attendue
ttc : 118

100 + 18 % = 118.

Deux indices, rédigés en mots
  1. Une constante de classe se lit self::TVA à l’intérieur de la classe.
  2. intdiv($ht * self::TVA, 100) donne la part de TVA entière.

Exercice 3 — Méthode statique

PHP Niveau 1 — Acquisition

Objectif : Appeler une méthode sans instancier la classe.

Le programme reçoit un entier. Écrivez une classe Maths avec une méthode statique estPair(int $n) qui renvoie vrai si le nombre est pair. Affichez pair : oui ou pair : non.

Entrée du programme
4
Sortie attendue
pair : oui

4 est pair.

Deux indices, rédigés en mots
  1. Une méthode statique s’appelle avec ClassName::méthode(), sans new.
  2. Un nombre est pair si le reste de sa division par 2 vaut 0.

6. QCM — niveau examen

Quelle visibilité réserve un membre à la classe ?

private limite l’accès au code de la classe.

Une propriété publique se modifie…

public ouvre l’accès à tout code disposant de l’objet.

À quoi sert un setter ?

Le setter contrôle la valeur avant de l’affecter.

Comment lit-on une constante à l’intérieur de la classe ?

self::TVA atteint la constante de classe.

Une constante s’écrit…

Pas de $ pour une constante : const TVA = 18.

Un membre static appartient…

static est partagé par la classe et toutes ses instances.

Que vaut $this dans une méthode statique ?

Une méthode statique n’a pas d’instance : on utilise self.

Que fait `return $this` dans un setter ?

Renvoyer $this autorise $obj->a()->b(), une interface fluide.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Laisser une propriété public alors qu’elle devrait être contrôlée.
  • Écrire self->$MACHIN (flèche) au lieu de self::$MACHIN (double deux-points).
  • Mettre un $ devant le nom d’une constante.
  • Oublier que $this est indisponible dans une méthode statique.
  • Valider après avoir affecté au lieu de valider avant.

8. Méthodologie de résolution

Protéger l’état d’un objet
  1. Fermer : passer toutes les propriétés en private.
  2. Ouvrir un getter par propriété réellement utile à l’extérieur.
  3. Contrôler chaque écriture dans un setter, avec une exception si besoin.
  4. Constanteniser les valeurs fixes (taux, limites) avec const.
  5. Choisir static seulement pour un état partagé ou un outil sans instance.

9. Révision active

Résumé essentiel
  • public, private, protected décident qui accède à un membre.
  • L’encapsulation = propriétés privées + méthodes publiques de contrôle.
  • Les setters valident avant d’affecter ; un setter peut renvoyer $this pour l’enchaînement.
  • const fixe une valeur de classe, lue avec self::TVA (aucun $).
  • static partage un membre entre toutes les instances ; $this y est indisponible.

Checklist de maîtrise

  • Je sais justifier la visibilité de chaque membre.
  • J’écris un setter qui refuse une valeur invalide.
  • Je lis une constante avec self:: sans y mettre de $.
  • J’utilise static et self là où $this n’a pas de sens.
