Mémo PHP

Syntaxe des classes, visibilité, héritage, exceptions et PDO sur une page. À garder ouvert pendant les exercices et l’atelier.

Une classe, un objet

class Point {

    private $x;                       // état

    public function __construct(int $x) { $this->x = $x; }

    public function afficher(): string { return "(" . $this->x . ")"; }

}

$p = new Point(3);      // new déclenche le constructeur

$p->afficher();          // flèche pour un membre

Le point . concatène ; la flèche -> atteint un membre.

Visibilité, constantes, statique

public     ouvert à tous        protected  classe + filles

private    réservé à la classe  const      const TVA = 18;   self::TVA

static     partagé par la classe           self::$compteur (pas $this)

fluent     return $this;         permet   $obj->a()->b()

Encapsulation : propriétés en private, accès par getters et setters qui valident.

Héritage, abstrait, interfaces

class Chien extends Animal { ... }        parent::__construct($nom)

abstract class Forme { abstract public function aire(): float; }

interface Affichable { public function afficher(): string; }

class Cercle extends Forme implements Affichable { ... }

polymorphisme : $forme->aire() exécute la version du type réel

Interface = contrat de signatures ; classe abstraite = squelette réutilisable.

Traits et namespaces

trait Salutation { public function saluer(): string { ... } }

class Accueil { use Salutation; }        // importe les méthodes

conflit : use A, B { A::demarrer insteadof B; B::demarrer as demarrerB; }

namespace App;                             // tout en haut, après

Le namespace fait partie du nom complet : App\Utilisateur.

Erreurs et exceptions

throw new Exception("message");            // lance

try { ... } catch (Exception $e) { $e->getMessage(); }

class SoldeInsuffisant extends Exception {}    // personnalisée

catch (InvalidArgumentException | RangeException $e) { ... }  // multi

finally { ... }                            // exécuté dans tous les cas

Attraper précis plutôt que catch (Exception $e) : un type fils avant le parent.

PDO et architecture

$pdo = new PDO("sqlite::memory:");

$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

$stmt = $pdo->prepare("INSERT INTO t (n) VALUES (:n)");

$stmt->execute([":n" => $valeur]);        // jamais de concaténation SQL

class Depot { public function __construct(PDO $pdo) { ... } }

Couches : entités → dépôt → service → affichage. Chaque couche ne connaît que la suivante.

Lire l’entrée en CLI

$ligne   = trim(fgets(STDIN));      // une valeur par ligne, débarrassée du \n

$nombre  = (int) $ligne;            // cast explicite

echo "resultat : " . $nombre . "\n";

Toujours trim() une entrée : elle conserve sinon le saut de ligne final.

Erreurs fréquentes à éviter

  • Écrire $this.x au lieu de $this->x.
  • Mettre un $ devant une constante.
  • Oublier parent::__construct() dans une classe fille.
  • Tenter new sur une classe abstraite ou une interface.
  • Concaténer une entrée utilisateur dans une requête SQL.
  • Oublier trim() sur fgets(STDIN).
