Examen blanc n°1 — objets et héritage

Sujet type examen — classes, encapsulation et hiérarchie.

Exercice 1/5 — Classe

Écrire la classe Compte avec une propriété privée solde, un constructeur qui l’initialise et une méthode solde() qui la renvoie. Pourquoi la propriété est-elle privée ?

Corrigé
class Compte { private $solde; public function __construct(float $s) { $this->solde = $s; } public function solde(): float { return $this->solde; } }.
Privée pour interdire une écriture directe depuis l’extérieur : l’état ne se modifie que par des méthodes contrôlées.
Exercice 2/5 — Setter

Ajouter setSolde() qui refuse un solde négatif. Quelle construction utiliser pour signaler le refus, et pourquoi ne pas simplement ne rien faire ?

Corrigé
On lève une exception : if ($s < 0) throw new InvalidArgumentException("solde négatif");.
Ne rien faire cacherait l’erreur : le setter n’applique pas la valeur et l’appelant doit le savoir.
Exercice 3/5 — Héritage

Écrire une classe fille ComptePro qui étend Compte, possède une propriété privee et son propre constructeur. Que doit faire ce constructeur ?

Corrigé
class ComptePro extends Compte { private $plafond; public function __construct(float $s, float $p) { parent::__construct($s); $this->plafond = $p; } }.
Il appelle parent::__construct($s) pour ne pas oublier l’initialisation héritée.
Exercice 4/5 — Abstrait

Soit une classe abstraite Forme avec la méthode abstraite aire(). Pourquoi ne peut-on pas écrire « new Forme() » ? Que doit faire une classe fille ?

Corrigé
Une classe abstraite décrit un squelette, pas un objet complet : new est interdit.
Chaque fille doit implémenter aire(), sinon elle reste abstraite.

Examen blanc n°2 — namespaces, exceptions, PDO

Sujet orienté organisation du code, erreurs et base de données.

Exercice 1/5 — Namespace

Déclarer deux classes Utilisateur sans collision de noms, puis en importer une sous l’alias U. Où se place la déclaration namespace ?

Corrigé
Les placer dans des namespaces distincts : namespace App; et namespace Auth;, soit App\Utilisateur et Auth\Utilisateur.
Import : use Auth\Utilisateur as U;. Le namespace se déclare tout en haut, juste après <?php.
Exercice 2/5 — Exception

Écrire une exception SoldeInsuffisant, la lancer depuis retirer(), et intercepter uniquement ce type. Quel est l’intérêt par rapport à catch (Exception $e) ?

Corrigé
class SoldeInsuffisant extends Exception {} ; on la lance et on fait catch (SoldeInsuffisant $e).
Intercepter un type précis distingue un problème métier d’une erreur technique inattendue.
Exercice 3/5 — PDO

Pourquoi ne jamais écrire "SELECT * FROM t WHERE nom = '" . $nom . "'" ? Réécrire cette requête correctement.

Corrigé
La concaténation ouvre la porte à l’injection SQL.
Correct : $stmt = $pdo->prepare("SELECT * FROM t WHERE nom = :nom"); $stmt->execute([":nom" => $nom]);.
Exercice 4/5 — Architecture

Quel est le rôle d’un dépôt (repository) ? Citer les quatre couches d’une application et l’ordre de leurs dépendances.

Corrigé
Le dépôt isole l’accès aux données d’une entité derrière des méthodes claires.
Couches : entités → dépôt → service → affichage ; chaque couche ne connaît que la suivante.

QCM final — toutes notions

Quel opérateur atteint un membre ?

La flèche -> atteint une propriété ou une méthode d’un objet.

Quelle visibilité réserve l’accès à la classe ?

private limite l’accès au code de la classe.

Comment appelle-t-on le constructeur parent ?

parent::__construct() exécute l’initialisation héritée.

Une interface contient…

C’est un contrat de signatures, sans implémentation.

À quoi sert un namespace ?

Il préfixe les classes pour les distinguer.

Quand s’exécute finally ?

finally s’exécute après le try ou le catch, dans tous les cas.

Que protège une requête préparée ?

Elle sépare le SQL des valeurs, empêchant l’injection.

Que fait static ?

Un membre static appartient à la classe, pas aux instances.

Que fait insteadof entre deux traits ?

insteadof tranche un conflit de méthodes de traits.

Comment lire une constante de classe ?

self::TVA, sans le $, à l’intérieur de la classe.
