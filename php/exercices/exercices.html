Entraînement rapide (acquisition)

Échauffement
  1. Lire un prénom et afficher « Bonjour prénom ».
  2. Lire deux entiers et afficher leur somme et leur produit.
  3. Créer une classe Voiture avec une propriété marque et afficher la marque lue.
  4. Lire un entier et dire s’il est pair (« pair : oui/non »).

Application

Application
  1. Écrire une classe Rectangle (largeur, hauteur) avec aire() et perimetre().
  2. Écrire un setter d’âge qui refuse une valeur négative (exception).
  3. Créer une classe facture utilisant une constante TVA et calculer un TTC.
  4. Compter les instances créées avec un membre statique.
Corrections
class Rectangle {
    private $l; private $h;
    public function __construct(float $l, float $h) { $this->l = $l; $this->h = $h; }
    public function aire(): float { return $this->l * $this->h; }
    public function perimetre(): float { return 2 * ($this->l + $this->h); }
}

class Personne {
    private $age;
    public function setAge(int $age): void {
        if ($age < 0) { throw new InvalidArgumentException("age négatif"); }
        $this->age = $age;
    }
}

class Facture {
    const TVA = 18.0;
    public function ttc(float $ht): float { return $ht * (1 + self::TVA / 100); }
}

class Compteur {
    private static $n = 0;
    public function __construct() { self::$n++; }
    public static function total(): int { return self::$n; }
}

Raisonnement
  1. Hiérarchie Forme → Cercle, Carre avec aire() redéfinie : afficher l’aire de chaque forme.
  2. Résoudre un conflit entre deux traits avec insteadof et as.
  3. Simuler un journal : intercepter une exception d’entrée et compter les erreurs.

Corrections
abstract class Forme { abstract public function aire(): float; }
class Carre extends Forme {
    private $c;
    public function __construct(float $c) { $this->c = $c; }
    public function aire(): float { return $this->c * $this->c; }
}

trait A { public function demarrer(): string { return "A"; } }
trait B { public function demarrer(): string { return "B"; } }
class Service {
    use A, B { A::demarrer insteadof B; B::demarrer as demarrerB; }
}

$erreurs = 0;
try {
    $v = trim(fgets(STDIN));
    if (!is_numeric($v)) { throw new InvalidArgumentException("non numérique"); }
} catch (InvalidArgumentException $e) {
    $erreurs++;
}
echo "erreurs : $erreurs
";

class Depot {

    public function somme(): int { return array_sum($this->valeurs); }

Projet intégrateur — « liste de tâches »

Cahier des charges

On te confie une petite application ToDo List. Le programme lit n, puis n lignes de tâches. Il les range dans une classe TodoList (ajout + lecture), les affiche numérotées de 1 à n au format 1. tâche, puis compte les tâches contenant le mot « urgent ».

Fonctionnalités attendues
  1. Lire les tâches dans l’ordre : n d’abord, puis une par ligne.
  2. Encapsuler le tableau dans une classe TodoList (propriété privée).
  3. Exposer ajouter() et lister() comme seules méthodes d’accès.
  4. Numéroter les tâches à partir de 1 et respecter le format « 1. tâche ».
  5. Compter les tâches « urgent » et afficher le total.
  6. Gérer le cas limite n = 0 (rapport vide mais propre).

Contraintes : aucune propriété publique, méthodes nommées clairement, bilan après la boucle.

Grille d’auto-évaluation du projet (sur 100)
Lecture ordonnée et gestion de n = 0 20
Encapsulation correcte (propriété privée) 20
Numérotation et format exacts 20
Comptage des tâches « urgent » 20
Lisibilité, noms, méthodes 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
class TodoList {
    private $taches = [];

    public function ajouter(string $tache): void {
        $this->taches[] = $tache;
    }

    public function lister(): array {
        return $this->taches;
    }
}

$n = (int) trim(fgets(STDIN));
$todo = new TodoList();
for ($i = 0; $i < $n; $i++) {
    $todo->ajouter(trim(fgets(STDIN)));
}
$urgents = 0;
foreach ($todo->lister() as $i => $tache) {
    echo ($i + 1) . ". " . $tache . "
";
    if (str_contains($tache, "urgent")) {
        $urgents++;
    }
}
echo "urgents : $urgents
";
Cette solution combine lecture ordonnée, encapsulation dans une classe, numérotation et comptage — l’essentiel des six modules en un seul programme.
