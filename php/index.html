PHP POO B2 — objets, architecture et base de données

Passer du PHP procédural au PHP objet, c’est apprendre à modéliser. Six chapitres pour créer des classes, protéger l’état avec l’encapsulation, factoriser par héritage et interfaces, organiser le code avec traits et namespaces, traiter les erreurs par exceptions, puis dialoguer avec une base via PDO — chaque mécanisme étant d’abord écrit et vérifié dans l’atelier, comme dans une vraie application.

Ce que vous saurez faire à la fin du cours
  • créer des classes, des objets et des constructeurs propres ;
  • protéger l’état d’un objet par l’encapsulation et des setters qui valident ;
  • factoriser par héritage, classes abstraites et interfaces ;
  • organiser le code avec traits, namespaces et chargement automatique ;
  • signaler les situations anormales par des exceptions et les intercepter ;
  • dialoguer avec une base de données via PDO sans jamais s’exposer à l’injection ;
  • assembler un petit service (liste de tâches) en couches.
Comment ce cours s’articule

Le cours historique de PHP objet couvre les classes, l’encapsulation, l’héritage, les namespaces, les exceptions et PDO. Ce cours en garde le plan et fait manipuler chaque mécanisme en PHP 8 : le même langage qu’un serveur réel, exécuté dans la page.

Chaque chapitre se termine par trois exercices de code : vous écrivez vraiment la classe, elle est réellement exécutée, puis corrigée par des tests que vous ne voyez pas. La logique écrite ici se rejoue telle quelle dans une application.

Programme du cours

1Objets et classes
Pourquoi modéliser, déclarer une classe, le constructeur, $this, méthodes et instanciation. 2Encapsulation, constantes et membres statiques
Visibilité, getters et setters avec validation, constantes de classe et membres statiques. 3Héritage, classes abstraites et interfaces
Étendre une classe, appeler parent, classes abstraites, polymorphisme et contrats d’interface. 4Traits, namespaces et chargement des classes
Réutiliser des méthodes avec un trait, organiser le code en namespaces, importer et charger les classes. 5Erreurs et exceptions
Erreurs PHP, lancer et attraper une exception, exceptions personnalisées, finally et multi-catch. 6PDO, dépôt de données et architecture
Se connecter avec PDO, requêtes préparées contre l’injection, patron repository, projet ToDo List.
