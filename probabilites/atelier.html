Atelier de code

Un éditeur dans la page, un vrai interpréteur Python derrière. Écris un calcul, exécute-le et lis ce qu’il affiche : c’est ici qu’une formule devient un résultat vérifié.

Comment fonctionne l’atelier
  • Exécuter fait tourner votre programme Python tel quel et affiche sa sortie, ses erreurs et son code de sortie.
  • Entrée du programme contient ce que input() lira, une valeur par ligne.
  • Expliquer mon erreur demande au tuteur, quand il y a une erreur, pourquoi elle survient et par où chercher. Il explique en mots : il n’écrit jamais de code à votre place.
  • Le raccourci Ctrl + Entrée exécute le programme sans quitter l’éditeur.
  • Votre code est conservé dans ce navigateur, par exercice et par cours.

Zone libre

Zone libre — probabilité élémentaire

Python

Objectif : expérimenter sans conséquence. Prends une formule du cours (probabilité, espérance, variance, loi binomiale, Φ) et calcule-la sur des cas limites.

Le programme proposé calcule une probabilité à partir d’un entier lu en entrée. Modifie la formule, change le nombre de cas favorables, ajoute une boucle de simulation, ou remplace tout le programme par la formule que tu veux vérifier — une espérance, une variance, une loi binomiale.

Dans une vraie analyse, ce sera un tableur ou un script statistique : la structure — lire, calculer, afficher — reste exactement la même.

Entrée du programme
8
Sortie attendue
3/8

Déplie « Entrée du programme » et saisis la taille de l’univers avant d’exécuter.

De la page à la vraie analyse

La simulation a une limite assumée : rien n’est envoyé ni stocké durablement. Elle a une force : toute la formule se vérifie sans serveur. Quand le programme calcule les bons résultats sur tes cas limites, le portage est mécanique : la même formule, le même arrondi.

Les trois erreurs que l’atelier révèle immédiatement
  • Division entière : ir/2.0 renvoie un décimal, pas une fraction affichée.
  • Entrée mal lue : comparer une chaîne issue de input() avec un nombre sans convertir.
  • Arrondi implicite : afficher un flottant brut au lieu de le formater (f"{x:.4f}").
Ce que fait l’atelier, côté technique
  • Votre code est envoyé à ce serveur, qui le transmet à un service d’exécution isolé : rien ne tourne sur votre machine, et aucun accès au système n’est possible.
  • La clé du service reste sur le serveur ; le navigateur ne la voit jamais.
  • Le nombre d’exécutions est limité par jour, pour tout le monde. L’atelier n’exécute donc que sur un clic.

Les 6 chapitres contiennent chacun trois exercices Python corrigés automatiquement dans la page. Une fois l’atelier apprivoisé, ils sont la meilleure façon de vérifier que la formule est vraiment acquise.
