Chapitre 5 — Variables aléatoires continues

Module 5 ≈ 3 h de travail Réservé B2 et plus
Mise en situation

Une durée de vie, une taille, une erreur de mesure prennent une infinité de valeurs : on ne peut plus parler de la probabilité d’une valeur exacte. On décrit alors la variable par une densité, et l’on calcule des probabilités d’intervalles par une aire.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. passer de la loi ponctuelle discrète à la densité continue ;
  2. utiliser la loi uniforme et la loi exponentielle ;
  3. calculer une probabilité avec la loi normale centrée réduite ;
  4. lire et interpréter une table de la loi normale.

1. Densité et fonction de répartition

Une variable continue X est décrite par une densité f positive, d’intégrale totale 1 : ∫ f(x) dx = 1. La probabilité d’un intervalle est l’aire sous la courbe : P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx. La fonction de répartition est F(x) = P(X ≤ x) = ∫₋∞ˣ f(t) dt.

Piège — P(X = x) = 0 pour une loi continue

Pour une variable continue, la probabilité d’une valeur exacte est nulle : P(X = x) = 0. Seules les probabilités d’intervalles ont un sens, et P(a ≤ X ≤ b) = P(a < X ≤ b) = P(a ≤ X < b) : les bornes n’importent pas.

2. Loi uniforme et loi exponentielle

La loi uniforme sur [a, b] répartit la probabilité également : F(x) = (x − a)/(b − a). La loi exponentielle de paramètre λ > 0, souvent utilisée pour une durée de vie, a pour répartition P(X ≥ x) = e^(−λx).

from math import exp

# Uniforme : P(X ≤ milieu).
a, b, x = 1.0, 5.0, 3.0
print(f"{(x - a) / (b - a):.4f}")   # 0.5000

# Exponentielle : P(X >= x).
print(f"{exp(-2 * 3):.4f}")          # 0.0025
Sans mémoire

La loi exponentielle est sans mémoire : savoir que l’événement n’est pas encore arrivé ne change rien à la loi des temps restants. C’est le pendant continu de la loi de Poisson, qui compte les événements.

3. Loi normale et standardisation

La loi normale N(μ, σ) est en cloche, centrée en μ et d’écart-type σ. On se ramène à la normale centrée réduite N(0, 1) par la standardisation Z = (X − μ)/σ.

from math import erf, sqrt

def phi(z):
    return 0.5 * (1 + erf(z / sqrt(2)))

print(f"{phi(0):.4f}")      # 0.5000
print(f"{phi(1.96):.4f}")   # 0.9750
Repères à connaître

Autour de la moyenne : P(μ−σ ≤ X ≤ μ+σ) ≈ 0,68, ≈ 0,95 pour ±2σ, ≈ 0,997 pour ±3σ. Le quantile 1,96 coupe 97,5 % de la masse à sa gauche.

4. Lire une table de la loi normale

La table donne Φ(z) = P(Z ≤ z) pour z ≥ 0. Pour z < 0, on utilise la symétrie : Φ(−z) = 1 − Φ(z). Pour une probabilité d’intervalle : P(a ≤ Z ≤ b) = Φ(b) − Φ(a).

from math import erf, sqrt

def phi(z):
    return 0.5 * (1 + erf(z / sqrt(2)))

# P(-1 <= Z <= 2) = Φ(2) - Φ(-1) = Φ(2) - (1 - Φ(1))
print(f"{phi(2) - (1 - phi(1)):.4f}")   # 0.8186

La calculatrice ou erf remplacent la table : le principe reste la standardisation puis la lecture de Φ.

Exercice 1 — Loi uniforme continue

Python Niveau 2 — Application

Objectif : Calculer P(X ≤ x) pour X uniforme sur [a, b].

Le programme reçoit trois décimaux : a, b (bornes, avec a < b) puis x. Pour une loi uniforme continue sur [a, b], la fonction de répartition vaut F(x) = (x−a)/(b−a), ramenée à 0 si x < a et à 1 si x > b. Affiche F(x) avec 4 décimales.

Entrée du programme
0
2
1
Sortie attendue
0.5000

Le point 1 est le milieu de [0, 2].

Deux indices, rédigés en mots
  1. Commence par « ramener » x dans l’intervalle : si x est sous a, le résultat vaut 0 ; au-dessus de b, il vaut 1.
  2. Au milieu, la répartition vaut (x - a) / (b - a).

Python Niveau 2 — Application

Objectif : Calculer P(X ≥ x) = e^(−λx) pour une loi exponentielle.

Le programme reçoit un décimal lambda (λ > 0) puis un décimal x (positif). Affiche la probabilité de dépassement P(X ≥ x) = e^(−λx) avec 4 décimales.

Entrée du programme
1
1
Sortie attendue
0.3679

e⁻¹ ≈ 0,3679.

Deux indices, rédigés en mots
  1. La probabilité de dépassement de la loi exponentielle est exp(-lam * x).
  2. Une seule ligne suffit : le produit λ·x se calcule avant l’exponentielle.

Exercice 3 — Loi normale centrée réduite

Python Niveau 3 — Raisonnement

Objectif : Calculer Φ(z) = P(Z ≤ z) pour la loi normale centrée réduite.

Le programme reçoit un décimal z. Affiche la probabilité Φ(z) = P(Z ≤ z) de la loi normale centrée réduite, arrondie à 4 décimales. On la calcule par la fonction d’erreur : Φ(z) = 0,5 · (1 + erf(z/√2)).

Entrée du programme
0
Sortie attendue
0.5000

Φ(0) = 0,5 par symétrie.

Deux indices, rédigés en mots
  1. La fonction erf du module math donne la fonction d’erreur ; divise z par sqrt(2).
  2. La formule complète est 0.5 * (1 + erf(z / sqrt(2))).

6. QCM — niveau examen

Pour une loi continue, P(X = x) vaut…

La probabilité d’une valeur exacte est nulle.

La densité vérifie…

L’aire totale sous la densité vaut 1.

F(x) pour une uniforme sur [a, b] ?

La répartition croît linéairement de a à b.

P(X ≥ x) pour une exponentielle de paramètre λ ?

La probabilité de dépasser x est e^(−λx).

Comment standardise-t-on X ?

Z = (X−μ)/σ suit N(0,1).

Que vaut Φ(0) ?

La courbe est symétrique : la moitié de la masse est à gauche de 0.

Φ(−z) vaut…

La symétrie de la normale donne Φ(−z) = 1 − Φ(z).

P(a ≤ Z ≤ b) vaut…

On soustrait les répartitions aux deux bornes.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Chercher P(X = x) pour une variable continue (valeur toujours nulle).
  • Oublier de standardiser avant de lire la table.
  • Mal traiter z < 0 : utiliser Φ(−z) = 1 − Φ(z).
  • Inverser les bornes dans P(a ≤ Z ≤ b) = Φ(b) − Φ(a).
  • Confondre P(X ≤ x) et P(X ≥ x) dans l’exponentielle.

8. Méthodologie de résolution

Traiter une loi continue
  1. Identifier la loi (uniforme, exponentielle, normale) et ses paramètres.
  2. Si normale, standardiser avec Z = (X − μ)/σ.
  3. Écrire la probabilité comme une aire (intervalle, complément).
  4. Évaluer Φ avec erf ou la table, en gérant les z négatifs.
  5. Interpréter le résultat comme une proportion.

9. Révision active

Résumé essentiel
  • Une variable continue est décrite par une densité d’aire totale 1.
  • P(X = x) = 0 ; seules les probabilités d’intervalles comptent.
  • Uniforme : F(x) = (x−a)/(b−a). Exponentielle : P(X ≥ x) = e^(−λx).
  • Normale : standardiser Z = (X−μ)/σ, puis lire Φ.
  • Φ(−z) = 1 − Φ(z) et P(a ≤ Z ≤ b) = Φ(b) − Φ(a).

Checklist de maîtrise

  • Je sais qu’une probabilité ponctuelle continue vaut 0.
  • J’applique la répartition d’une uniforme et d’une exponentielle.
  • Je standardise avant d’utiliser la loi normale.
  • Je gère les z négatifs par symétrie.
