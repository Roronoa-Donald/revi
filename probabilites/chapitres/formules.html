Formulaire de probabilités

Toutes les formules du cours sur une page. À garder ouvert pendant les exercices et l’atelier.

Événements et probabilité

P(Ω) = 1       0 ≤ P(A) ≤ 1       P(Ā) = 1 − P(A)

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)     (formule de la réunion)

univers équiprobable : P(A) = card(A) / card(Ω)

P(A|B) = P(A ∩ B) / P(B)              (probabilité conditionnelle)

indépendance : P(A ∩ B) = P(A) · P(B)

« Incompatibles » ne veut pas dire « indépendants » : incompatibles = intersection vide.

Dénombrement

principe multiplicatif : m × n × …

arrangement A(n,k) = n! / (n−k)!         (l’ordre compte)

combinaison C(n,k) = n! / (k!(n−k)!)     (l’ordre ne compte pas)

permutations avec répétition : n! / (r₁! r₂! …)

binôme : (a+b)ⁿ = Σ C(n,k) aᵏ bⁿ⁻ᵏ

Variable aléatoire discrète

loi : Σ pᵢ = 1

espérance : E(X) = Σ xᵢ pᵢ        linéarité : E(aX+b) = aE(X)+b

variance : V(X) = E(X²) − E(X)²   écart-type : σ(X) = √V(X)

répartition : F(x) = P(X ≤ x) = Σ_{xᵢ ≤ x} pᵢ

P(X ≥ x) = 1 − P(X < x)

Lois discrètes usuelles

Bernoulli B(p)      E = p            V = p(1−p)

Binomiale B(n,p)    P(X=k) = C(n,k) pᵏ (1−p)ⁿ⁻ᵏ

                    E = n p          V = n p (1−p)

Poisson P(λ)        P(X=k) = λᵏ e^(−λ) / k!

                    E = λ            V = λ

Variables continues

densité : ∫ f(x) dx = 1        P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx

P(X = x) = 0                    (valeur exacte)

uniforme [a,b] : F(x) = (x−a)/(b−a)

exponentielle λ : P(X ≥ x) = e^(−λx)

normale N(μ,σ) : standardiser Z = (X − μ)/σ

Loi normale : repères

Φ(z) = 0,5 (1 + erf(z/√2))        Φ(0) = 0,5

Φ(−z) = 1 − Φ(z)                  P(a ≤ Z ≤ b) = Φ(b) − Φ(a)

P(μ−σ ≤ X ≤ μ+σ) ≈ 0,68     ±2σ ≈ 0,95     ±3σ ≈ 0,997

quantile 1,96 : Φ(1,96) ≈ 0,975

Convergence et théorèmes limites

Markov (X ≥ 0)            P(X ≥ a) ≤ E(X)/a

Tchebychev                 P(|X−E(X)| ≥ ε) ≤ V(X)/ε²

moyenne de n variables    E = μ,  V = σ²/n  → μ

somme Sₙ = X₁+…+Xₙ         E = nμ,  σ = σ√n

TCL : Z = (Sₙ − nμ)/(σ√n) ≈ N(0, 1)

Erreurs fréquentes à éviter

  • Oublier de retirer P(A ∩ B) dans la réunion.
  • Confondre P(A|B) et P(B|A).
  • Compter l’ordre (arrangement) là où il ne compte pas (combinaison).
  • Confondre E(X²) et E(X)² dans la variance.
  • Oublier C(n,k) dans P(X = k) de la binomiale.
  • Chercher P(X = x) pour une variable continue (vaut 0).
  • Ne pas standardiser avant d’utiliser la loi normale.
