Module 1 — Bases du langage Java

QuestionQuel est le point d’entrée d’un programme Java ?
RéponseLa méthode public static void main(String[] args).
QuestionCite quatre types primitifs.
Réponseint, double, boolean, char.
QuestionQue vaut 7 / 2 ? Et 7 / 2.0 ?
Réponse3 (division entière) et 3.5 (avec un double).
QuestionQue fait + entre une chaîne et un nombre ?
RéponseIl concatène, sans additionner.
QuestionComment lire un entier au clavier ?
RéponseAvec sc.nextInt() sur un Scanner(System.in).
QuestionComment afficher un décimal avec le point ?
RéponseString.format(Locale.US, "%.2f", valeur).

Module 2 — Conditions et boucles

QuestionQue renvoie une comparaison ?
RéponseUn boolean (true ou false).
QuestionSyntaxe de l’opérateur ternaire ?
Réponsecondition ? valeurSiVrai : valeurSinon.
QuestionPourquoi break dans un switch ?
RéponsePour empêcher le fall-through vers le cas suivant.
QuestionDifférence entre for et while ?
Réponsefor pour un nombre connu d’itérations, while tant qu’une condition tient.
QuestionDifférence entre break et continue ?
Réponsebreak sort de la boucle ; continue passe au tour suivant.
QuestionQue fait i++ ?
RéponseIl incrémente i de 1.

Module 3 — Tableaux, ArrayList et méthodes

QuestionQuelle est la taille d’un tableau ?
RéponseFixe, déterminée à la création (new int[n]).
QuestionQuel est le premier indice ?
Réponse0 ; le dernier vaut length − 1.
QuestionQuand utiliser ArrayList ?
RéponseQuand le nombre d’éléments varie.
QuestionQuel type dans une ArrayList d’entiers ?
RéponseInteger (classe enveloppe de int).
QuestionÀ quoi sert return ?
RéponseÀ renvoyer une valeur à l’appelant de la méthode.
QuestionComment initialiser un maximum ?
RéponseAvec la première valeur, pas avec 0.

Module 4 — Classes, objets et encapsulation

QuestionDifférence entre classe et objet ?
RéponseLa classe est le moule ; l’objet est une instance créée par new.
QuestionComment s’appelle le constructeur ?
RéponseComme la classe ; il initialise l’objet.
QuestionQue désigne this ?
RéponseL’objet courant.
QuestionQue réserve private ?
RéponseL’accès au code de la classe seule.
QuestionRôle d’un setter ?
RéponseÉcrire l’état en validant la valeur avant l’affectation.
QuestionPourquoi redéfinir toString() ?
RéponsePour afficher un objet de façon lisible au lieu d’une adresse.

Module 5 — Collections, héritage et polymorphisme

QuestionQuelle collection pour des valeurs uniques ?
RéponseUn Set, qui élimine les doublons.
QuestionQuelle collection associe clé et valeur ?
RéponseUne Map (par exemple HashMap).
QuestionQue fait extends ?
RéponseIl fait hériter une classe d’une autre.
QuestionÀ quoi sert super(...) ?
RéponseÀ appeler le constructeur de la classe mère.
QuestionQue fait @Override ?
RéponseIl redéfinit une méthode héritée.
QuestionQue permet le polymorphisme ?
RéponseD’appeler la version du type réel de l’objet.

Module 6 — Exceptions et robustesse

QuestionStructure de capture ?
Réponsetry { … } catch (Type e) { … } finally { … }.
QuestionQuand s’exécute finally ?
RéponseDans tous les cas, après le try ou le catch.
QuestionException d’une division entière par zéro ?
RéponseArithmeticException.
QuestionException d’un parseInt invalide ?
RéponseNumberFormatException.
QuestionComment créer une exception métier ?
RéponseEn étendant Exception et en appelant super(message).
QuestionDifférence entre throw et throws ?
Réponsethrow lance l’exception ; throws la déclare dans la signature.
