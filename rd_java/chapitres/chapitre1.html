Chapitre 1 — Bases du langage Java

Module 1 ≈ 2 h 30 de travail Accès libre
Mise en situation

Un programme Java ne s’improvise pas : il vit dans une classe, démarre par une méthode précise et manipule des valeurs d’un type déterminé. Poser ces fondations évite les surprises de compilation — car en Java, une déclaration floue ne passe pas.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. reconnaître la structure d’une classe et la méthode main ;
  2. déclarer des variables des types primitifs et connaître leurs opérateurs ;
  3. afficher avec System.out.print/println et formatter un décimal ;
  4. lire une saisie au clavier avec Scanner.

1. Un programme Java, de l’intérieur

Un programme Java s’écrit dans une classe. L’exécution démarre toujours à la méthode public static void main(String[] args) : le point d’entrée fixe par la machine virtuelle.

public class Main {
    public static void main(String[] args) {
        System.out.println("Bonjour");
    }
}
Tout tourne autour de la classe

Les accolades délimitent la classe, puis la méthode. L’instruction se termine par un point-virgule : l’oublier est l’erreur de compilation numéro un des débutants.

2. Types primitifs et variables

Chaque variable a un type connu à la compilation. Les types primitifs couvrent les besoins courants : int (entier), double (décimal), boolean (vrai/faux), char (un caractère).

int age = 20;
double prix = 9.99;
boolean actif = true;
char initiale = 'A';
Piège — la division entière

7 / 2 donne 3 en Java : deux entiers produisent un entier. Pour un résultat décimal, il faut au moins un opérande double : 7 / 2.0 ou 7.0 / 2.

3. Opérateurs et concaténation

Les opérateurs arithmétiques (+ − * / %) s’appliquent aux nombres. Le signe + sert aussi à concaténer des chaînes : c’est le contexte qui décide.

int a = 3;
int b = 4;
System.out.println("somme : " + (a + b));   // sommes d'abord, texte ensuite

Les parenthèses autour de (a + b) sont capitales : sans elles, a serait concaténé au texte avant l’addition.

4. Lire au clavier avec Scanner

Scanner lit l’entrée standard. On crée l’objet une fois, puis on appelle nextInt(), nextDouble() ou next() selon le type attendu.

import java.util.Scanner;

Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
double x = sc.nextDouble();

Pour formater un décimal avec le point (et non la virgule de la locale française), utilisez String.format(Locale.US, "%.2f", valeur) : le format reste identique d’une machine à l’autre.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Somme de deux entiers

Java Niveau 1 — Acquisition

Objectif : Lire deux entiers et afficher leur somme : premier programme Java complet.

Le programme reçoit deux entiers, un par ligne. Lisez-les avec un Scanner et affichez somme : X où X est leur somme.

Entrée du programme
3
4
Sortie attendue
somme : 7

Trois plus quatre.

Deux indices, rédigés en mots
  1. La somme s’écrit simplement a + b ; System.out.println affiche une ligne.
  2. Pour mélanger texte et valeur, concatène : "somme : " + (a + b).

Exercice 2 — Moyenne d’une série

Java Niveau 1 — Acquisition

Objectif : Parcourir une entrée avec une boucle et produire un résultat décimal formaté.

Le programme reçoit un entier n, puis n entiers. Calculez leur moyenne et affichez moyenne : X.XX avec exactement deux décimales (séparateur point).

Entrée du programme
4
1
2
3
4
Sortie attendue
moyenne : 2.50

Somme 10 sur 4 valeurs.

Deux indices, rédigés en mots
  1. Une boucle for de 0 à n lit chaque valeur avec sc.nextInt() et l’ajoute à somme.
  2. Pour forcer le point décimal, formate avec String.format(Locale.US, "%.2f", moyenne).

Exercice 3 — Conversion Celsius → Fahrenheit

Java Niveau 2 — Application

Objectif : Manipuler des nombres décimaux, des constantes et un format à une décimale.

Le programme reçoit un nombre décimal, une température en degrés Celsius. Convertissez-la en Fahrenheit avec la formule F = C × 9 / 5 + 32 et affichez le résultat avec une décimale.

Entrée du programme
25
Sortie attendue
77.0

25 °C font 77 °F.

Deux indices, rédigés en mots
  1. Utilise des littéraux décimaux (9.0 / 5.0) pour éviter la division entière.
  2. Formate avec String.format(Locale.US, "%.1f", fahrenheit).

6. QCM — niveau examen

Par où démarre un programme Java ?

La machine virtuelle cherche public static void main(String[] args).

Quel type pour un décimal ?

double représente les nombres à virgule flottante.

Que vaut 7 / 2 en Java ?

Deux entiers donnent une division entière : 3.

Comment obtenir un décimal ?

Un opérande double suffit à produire un résultat décimal.

Que fait le signe + entre une chaîne et un nombre ?

Dès qu’un opérande est une chaîne, + concatène.

Quel objet lit le clavier ?

Scanner(System.in) lit l’entrée standard.

Que fait System.out.println ?

println affiche, puis passe à la ligne suivante.

Pourquoi formater avec Locale.US ?

La locale française utiliserait la virgule comme séparateur.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Oublier le point-virgule en fin d’instruction.
  • Attendre un résultat décimal d’une division entre deux int.
  • Oublier les parenthèses dans "somme : " + (a + b).
  • Formater un décimal sans fixer la locale : le séparateur peut varier.
  • Lire un entier avec nextDouble() ou inversement.

8. Méthodologie de résolution

Écrire un premier programme Java
  1. Déclarer une classe et sa méthode main.
  2. Importer ce qui est nécessaire (Scanner, Locale).
  3. Déclarer chaque variable avec son type avant de l’utiliser.
  4. Lire l’entrée avec la bonne méthode de Scanner.
  5. Afficher un résultat formaté et relire la sortie attendue.

9. Révision active

Résumé essentiel
  • Un programme Java vit dans une classe et démarre à main.
  • Chaque variable a un type primitif (int, double, boolean, char).
  • Deux entiers divisés donnent un entier ; un double force le décimal.
  • Le + concatène dès qu’un opérande est une chaîne.
  • Scanner lit l’entrée ; String.format(Locale.US, …) fige le format.

Checklist de maîtrise

  • Je sais structurer une classe avec main.
  • Je choisis le bon type pour chaque variable.
  • Je prévois le résultat entier ou décimal d’une division.
  • Je lis l’entrée avec Scanner et je formate mes sorties.
