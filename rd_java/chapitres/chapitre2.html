Chapitre 2 — Conditions et boucles

Module 2 ≈ 2 h 30 de travail Réservé B2 et plus
Mise en situation

Un programme doit prendre des décisions et répéter des traitements. Conditions et boucles forment le squelette de tout algorithme : sans elles, le code se contente d’exécuter des instructions en ligne.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. écrire des conditions avec if/else et l’opérateur ternaire ;
  2. choisir entre plusieurs cas avec switch ;
  3. répéter un traitement avec for et while ;
  4. contrôler une boucle avec break et continue.

1. Conditions et opérateur ternaire

if exécute un bloc quand une condition est vraie ; else prend le relais sinon. L’opérateur ternaire condition ? valeurSiVrai : valeurSinon condense une expression en une ligne.

int n = 7;
boolean pair = n % 2 == 0;
System.out.println(pair ? "pair" : "impair");

Les opérateurs de comparaison (== != < > <= >=) renvoient un boolean, que l’on combine avec && (et) et || (ou).

2. Plusieurs cas avec switch

Quand une même valeur est comparée à plusieurs constantes, switch est plus lisible qu’une cascade de else if. Le mot-clé break évite d’enchaîner sur le cas suivant.

switch (jour) {
    case 1:
        System.out.println("Lundi");
        break;
    default:
        System.out.println("Autre");
}
Piège — le break oublié

Sans break, l’exécution « tombe » dans le cas suivant (fall-through) et exécute du code qu’on ne voulait pas. Chaque case se termine normalement par break.

3. Boucles for et while

for s’utilise quand on connaît le nombre d’itérations ; while répète tant qu’une condition reste vraie.

int somme = 0;
for (int i = 1; i <= 5; i++) {
    somme += i;
}

int k = 0;
while (k < 3) {
    k++;
}

Une boucle for se lit en trois parties : initialisation, condition, incrément. L’incrément i++ équivaut à i = i + 1.

4. break, continue et imbrication

break sort immédiatement de la boucle ; continue passe à l’itération suivante. On construit aussi des suites en gardant deux variables (par exemple Fibonacci).

int a = 0;
int b = 1;
StringBuilder sb = new StringBuilder();
for (int i = 0; i < n; i++) {
    if (i > 0) sb.append(' ');
    sb.append(a);
    int suivant = a + b;
    a = b;
    b = suivant;
}
Garde l’état dans des variables

Beaucoup de suites se calculent sans tableau : il suffit de retenir les derniers termes dans des variables et de les décaler à chaque tour. C’est plus économe et tout aussi clair.

Exercice 1 — Pair ou impair

Java Niveau 1 — Acquisition

Objectif : Utiliser une condition et l’opérateur modulo.

Le programme reçoit un entier n. Affichez pair si n est divisible par 2, sinon impair.

Entrée du programme
7
Sortie attendue
impair

7 est impair.

Deux indices, rédigés en mots
  1. Le reste de la division par 2 s’obtient avec n % 2.
  2. Une condition n % 2 == 0 signifie que le nombre est pair.

Exercice 2 — Somme des entiers de 1 à n

Java Niveau 1 — Acquisition

Objectif : Accumuler dans une boucle.

Le programme reçoit un entier n. Calculez la somme 1 + 2 + … + n avec une boucle et affichez somme : X.

Entrée du programme
5
Sortie attendue
somme : 15

1+2+3+4+5 = 15.

Deux indices, rédigés en mots
  1. Une boucle for (int i = 1; i <= n; i++) parcourt les entiers de 1 à n.
  2. Ajoute chaque i à la variable somme, puis affiche le total à la fin.

6. QCM — niveau examen

Que renvoie une comparaison en Java ?

Les comparaisons produisent un boolean (true/false).

Que fait l’opérateur ternaire ?

condition ? a : b choisit a ou b.

Quand préférer switch ?

switch évite une longue cascade de else if.

À quoi sert break dans un switch ?

break empêche le fall-through vers le cas suivant.

Quelle boucle pour un nombre d’itérations connu ?

for exprime directement initialisation, condition et incrément.

Que fait continue ?

continue saute le reste du corps et repart au tour suivant.

Que fait i++ ?

L’opérateur ++ incrémente la variable de 1.

Comment calcule-t-on une suite sans tableau ?

On retient deux valeurs et on les décale à chaque itération.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Oublier le break dans un switch.
  • Écrire if (x = 1) au lieu de if (x == 1).
  • Créer une boucle dont la condition ne devient jamais fausse.
  • Confondre break (sort) et continue (tour suivant).
  • Se tromper de borne dans for (<= contre <).

8. Méthodologie de résolution

Construire un contrôle de flux
  1. Déterminer la condition qui gouverne la décision.
  2. Choisir if/else, ternaire ou switch selon le nombre de cas.
  3. Fixer les bornes de la boucle (initialisation, condition, incrément).
  4. Contrôler la sortie avec break/continue seulement si c’est nécessaire.
  5. Tester les cas limites : zéro, négatif, borne atteinte.

9. Révision active

Résumé essentiel
  • Les comparaisons produisent des boolean, combinés par && et ||.
  • L’opérateur ternaire condense une condition en expression.
  • switch compare une valeur à plusieurs cas ; chaque case finit par break.
  • for répète un nombre connu de fois, while tant qu’une condition tient.
  • break sort d’une boucle, continue passe au tour suivant.

Checklist de maîtrise

  • J’écris une condition claire et sans affectation accidentelle.
  • Je choisis entre ternaire, if/else et switch.
  • Je maîtrise les bornes de mes boucles.
  • J’utilise break et continue à bon escient.
