Chapitre 3 — Tableaux, ArrayList et méthodes

Module 3 ≈ 2 h 30 de travail Réservé B2 et plus
Mise en situation

Dès qu’il y a plusieurs valeurs, il faut une structure pour les ranger et un moyen de les parcourir. Tableaux et listes stockent les données ; les méthodes les traitent par blocs nommés et réutilisables.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. déclarer et parcourir un tableau de taille fixe ;
  2. utiliser une ArrayList quand la taille varie ;
  3. extraire une portion de logique dans une méthode ;
  4. passer des paramètres et renvoyer un résultat.

1. Tableaux à taille fixe

Un tableau range un nombre fixe de valeurs du même type, indexées de 0 à n-1. On le déclare avec sa taille puis on remplit chaque case.

int[] valeurs = new int[3];
valeurs[0] = 10;
valeurs[1] = 20;
valeurs[2] = 30;

for (int i = 0; i < valeurs.length; i++) {
    System.out.println(valeurs[i]);
}
Piège — dépasser la taille

Accéder à valeurs[3] d’un tableau de trois cases lève une ArrayIndexOutOfBoundsException. La boucle s’arrête donc à i < valeurs.length, jamais à i <= valeurs.length.

2. ArrayList quand la taille varie

Une ArrayList s’agrandit toute seule. Elle ne stocke que des objets : les entiers passent par la classe enveloppe Integer, et Java fait la conversion automatiquement.

import java.util.ArrayList;

ArrayList<Integer> notes = new ArrayList<>();
notes.add(15);
notes.add(12);
System.out.println(notes.size());   // 2
System.out.println(notes.get(0));   // 15

On parcourt une liste avec une boucle indexée ou un for-each : for (int note : notes) { … }.

3. Extraire une méthode

Une méthode regroupe un traitement sous un nom. Elle reçoit des paramètres et peut renvoyer une valeur avec return.

static int somme(int[] valeurs) {
    int total = 0;
    for (int v : valeurs) {
        total += v;
    }
    return total;
}

Le type de retour (int ici) fait partie du contrat. Une méthode qui ne renvoie rien se déclare void.

4. Algorithmes simples sur les tableaux

Deux algorithmes reviennent sans cesse : le maximum et le parcours inversé. Pour le maximum, on initialise avec la première valeur — surtout pas avec 0, sinon des valeurs négatives seraient ignorées.

int max = valeurs[0];
for (int i = 1; i < valeurs.length; i++) {
    if (valeurs[i] > max) {
        max = valeurs[i];
    }
}
Un seul passage suffit

La plupart de ces traitements se font en un seul parcours, en gardant l’information utile dans une variable (le maximum vu, le total, l’état précédent). Pas besoin de trier ni de mémoriser tout.

Exercice 1 — Maximum d’un tableau

Java Niveau 1 — Acquisition

Objectif : Parcourir un tableau pour en extraire le maximum.

Le programme reçoit un entier n, puis n entiers. Affichez max : X où X est la plus grande valeur du tableau.

Entrée du programme
5
3
9
2
7
4
Sortie attendue
max : 9

La plus grande valeur est 9.

Deux indices, rédigés en mots
  1. Initialise le maximum avec la première valeur (valeurs[0]), pas avec 0 : des valeurs négatives seraient mal comparées.
  2. Boucle à partir de l’indice 1 et remplace le maximum dès qu’une valeur est plus grande.

Exercice 2 — Inverser un tableau

Java Niveau 2 — Application

Objectif : Parcourir un tableau dans le sens inverse et assembler une sortie.

Le programme reçoit un entier n, puis n entiers. Affichez-les dans l’ordre inverse, séparés par des espaces, sur une seule ligne.

Entrée du programme
3
1
2
3
Sortie attendue
3 2 1

Ordre inversé.

Deux indices, rédigés en mots
  1. Parcours le tableau de n-1 à 0 avec une boucle décrémentée.
  2. Un StringBuilder accumule la sortie ; n’ajoute l’espace qu’après le premier élément écrit.

Exercice 3 — Nombre premier

Java Niveau 3 — Raisonnement

Objectif : Écrire une méthode et tester un nombre premier.

Le programme reçoit un entier n. Affichez premier si n est un nombre premier, sinon non premier. Rappel : 1 n’est pas premier.

Entrée du programme
17
Sortie attendue
premier

17 n’a aucun diviseur autre que 1 et lui-même.

Deux indices, rédigés en mots
  1. Un nombre est premier s’il est supérieur ou égal à 2 et n’a aucun diviseur jusqu’à sa racine.
  2. Une boucle d = 2 ; d * d <= n teste les diviseurs ; si n % d == 0, le nombre n’est pas premier.

6. QCM — niveau examen

Un tableau a…

new int[n] alloue exactement n cases.

Premier indice d’un tableau ?

Les indices vont de 0 à length−1.

Que fait valeurs.length ?

length donne le nombre de cases du tableau.

Quand préférer ArrayList ?

ArrayList s’agrandit dynamiquement.

Quel type stocke une ArrayList de nombres ?

Les collections stockent des objets : Integer pour les entiers.

Comment renvoyer un résultat ?

return transmet la valeur à l’appelant.

Que vaut le type d’une méthode qui ne renvoie rien ?

void signifie « aucune valeur renvoyée ».

Comment initialiser un maximum ?

La première valeur évite d’ignorer des valeurs négatives.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Dépasser la taille d’un tableau (ArrayIndexOutOfBoundsException).
  • Initialiser un maximum à 0 au lieu de la première valeur.
  • Oublier d’importer ArrayList.
  • Utiliser == pour comparer deux chaînes au lieu de .equals().
  • Écrire une méthode avec un type de retour et oublier le return.

8. Méthodologie de résolution

Travailler avec des collections de valeurs
  1. Choisir la structure : tableau si la taille est fixe, ArrayList sinon.
  2. Parcourir avec une boucle indexée ou un for-each.
  3. Extraire le traitement répété dans une méthode nommée.
  4. Renvoyer le résultat avec le bon type.
  5. Tester les cas limites : tableau vide, valeurs négatives, un seul élément.

9. Révision active

Résumé essentiel
  • Un tableau a une taille fixe, indexée de 0 à length−1.
  • ArrayList s’agrandit ; elle stocke des objets (Integer pour les entiers).
  • Une méthode regroupe un traitement, reçoit des paramètres et renvoie une valeur.
  • void signifie qu’aucune valeur n’est renvoyée.
  • Maximum et inversion se calculent en un seul passage.

Checklist de maîtrise

  • J’écris une méthode avec paramètres et type de retour.
