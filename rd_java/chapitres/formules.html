Mémo Java

Syntaxe, classes, collections et exceptions sur une page. À garder ouvert pendant les exercices et l’atelier.

Structure et types

public class Main {

    public static void main(String[] args) { ... }

}

int n = 7;        double x = 9.99;      boolean ok = true;

System.out.println("texte " + valeur);   // concaténation

String.format(Locale.US, "%.2f", x)      // format à point

Chaque instruction se termine par un point-virgule ; le + concatène dès qu’un opérande est une chaîne.

Conditions et boucles

if (n % 2 == 0) { ... } else { ... }

String r = (n % 2 == 0) ? "pair" : "impair";

switch (n) { case 1: ... break; default: ... }

for (int i = 1; i <= n; i++) { ... }

while (condition) { ... }      break;   continue;

Le break du switch empêche le fall-through ; for sert quand le nombre d’itérations est connu.

Tableaux, ArrayList et méthodes

int[] t = new int[3];        t.length

ArrayList<Integer> liste = new ArrayList<>();

liste.add(15);   liste.size();   liste.get(0);

for (int v : t) { ... }                      // for-each

static int somme(int[] v) { ... return total; }

Indices de 0 à length−1 ; une ArrayList stocke des objets (Integer pour int).

Classes et encapsulation

class Rectangle {

    private final int largeur;

    Rectangle(int largeur) { this.largeur = largeur; }

    int aire() { return largeur * largeur; }

    @Override public String toString() { return "(" + largeur + ")"; }

}

Rectangle r = new Rectangle(4);    r.aire();

private protège l’état ; getters/setters contrôlent l’accès ; final fige une valeur.

Collections et héritage

class Chien extends Animal {

    Chien(String nom) { super(nom); }

    @Override String crier() { return "Wouf"; }

abstract class Forme { abstract double aire(); }

Le polymorphisme exécute la version du type réel de l’objet.

Exceptions

try {

    int v = Integer.parseInt(saisie);

} catch (NumberFormatException e) {

    System.out.println("saisie invalide");

} finally { ... }

class SoldeInsuffisant extends Exception {

    SoldeInsuffisant(String m) { super(m); }

}

void retirer(int m) throws SoldeInsuffisant { ... }

throw lance ; throws déclare ; finally s’exécute dans tous les cas.

Lire l’entrée

import java.util.Scanner;

Scanner sc = new Scanner(System.in);

int n = sc.nextInt();     double x = sc.nextDouble();

String mot = sc.next();   String ligne = sc.nextLine();

next() lit un mot, nextLine() lit la ligne entière ; ne mélange pas les deux sans précaution.

Erreurs fréquentes à éviter

  • Oublier le point-virgule ou une accolade.
  • Attendre un décimal d’une division entre deux int.
  • Dépasser la taille d’un tableau (i < length, jamais <=).
  • Comparer deux chaînes avec == au lieu de .equals().
  • Oublier super(...) dans le constructeur d’une classe fille.
  • Confondre throw (lancer) et throws (déclarer).
