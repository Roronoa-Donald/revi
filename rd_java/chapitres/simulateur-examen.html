Examen blanc n°1 — langage et contrôle du flux

Sujet type examen — types, opérateurs, conditions, boucles, tableaux.

Exercice 1/5 — Types

Que vaut 7 / 2 ? Et 7 / 2.0 ? Comment obtenir 3.5 de la première expression ?

Corrigé
7 / 2 donne 3 (division entière) ; 7 / 2.0 donne 3.5.
Pour forcer le décimal, un opérande doit l’être : 7.0 / 2 ou un cast.
Exercice 2/5 — Boucles

Écrire une boucle qui calcule la somme des entiers de 1 à n. Quel type de boucle choisir ?

Corrigé
int somme = 0; for (int i = 1; i <= n; i++) somme += i;.
Le nombre d’itérations est connu : une boucle for est la plus directe.
Exercice 3/5 — Conditions

Écrire une condition qui affiche « majeur » si l’âge est supérieur ou égal à 18, sinon « mineur ».

Corrigé
System.out.println(age >= 18 ? "majeur" : "mineur");
L’opérateur ternaire convient à une décision unique en une expression.
Exercice 4/5 — Tableaux

Pourquoi écrire for (int i = 1; i < t.length; i++) pour trouver le maximum de t ?

Corrigé
On initialise max = t[0] puis on parcourt à partir de 1.
Initialiser à 0 ignorerait des valeurs négatives ; la borne i < t.length évite le dépassement.

Examen blanc n°2 — objets, collections et exceptions

Sujet orienté modélisation, collections, héritage et robustesse.

Exercice 1/5 — Encapsulation

Écrire une classe Compte avec un solde privé, un getter, et un retirer() qui refuse un montant supérieur au solde. Quelle exception utiliser ?

Corrigé
private int solde; avec getSolde().
Dans retirer(), lancer une exception : InvalidArgumentException, IllegalStateException ou une exception métier dédiée.
Exercice 2/5 — Collections

Quelle collection choisir pour compter les valeurs distinctes d’une liste ? Pour associer un nom à un âge ?

Corrigé
Un Set (par exemple HashSet) élimine les doublons : size() donne le nombre de valeurs distinctes.
Une Map<String,Integer> associe chaque nom à un âge.
Exercice 3/5 — Héritage

Écrire une classe fille Chien qui hérite d’Animal, appelle son constructeur et redéfinit crier(). Que permet le polymorphisme ?

Corrigé
class Chien extends Animal { Chien(String nom) { super(nom); } @Override String crier() { return "Wouf"; } }.
Une variable Animal a = new Chien(...) appelle la version du type réel.
Exercice 4/5 — Exceptions

Pourquoi encadrer Integer.parseInt d’un try/catch ? Quelle exception attraper précisément ?

Corrigé
Une saisie non numérique lève une NumberFormatException.
La capturer permet d’afficher un message clair au lieu de laisser le programme s’arrêter.

QCM final — toutes notions

Que vaut 7 / 2 ?

Deux int donnent une division entière.

Que fait i++ ?

++ ajoute 1 à la variable.

Quelle boucle pour un nombre connu d’itérations ?

for exprime directement les trois parties.

Premier indice d’un tableau ?

Les indices vont de 0 à length−1.

Que protège private ?

private réserve l’accès à la classe elle-même.

Quelle collection élimine les doublons ?

Un Set ne garde qu’une copie par valeur.

Que fait @Override ?

Il redéfinit la version de la classe mère.

Quand s’exécute finally ?

finally s’exécute après le try ou le catch.

Quelle exception pour parseInt invalide ?

La conversion d’un texte non numérique échoue ainsi.

Que déclare throws ?

L’appelant doit capturer ou propager.
