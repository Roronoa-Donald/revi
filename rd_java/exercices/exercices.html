Projet intégrateur — « gestion d’étudiants »

Cahier des charges

On te confie une petite application de gestion d’étudiants. Le programme lit un entier n, puis n lignes au format nom note. Il range chaque étudiant dans une classe Etudiant (nom, note), calcule la moyenne de la promotion, puis affiche la moyenne et les étudiants ayant une note supérieure ou égale à 10.

Fonctionnalités attendues
  1. Modéliser un étudiant par une classe (attributs privés, getters).
  2. Lire les données dans l’ordre : n, puis n lignes « nom note ».
  3. Calculer la moyenne de la promotion.
  4. Filtrer les étudiants ayant au moins 10 et les afficher.
  5. Formater la moyenne sur deux décimales (Locale.US).
  6. Gérer le cas limite n = 0 sans erreur.

Contraintes : attributs privés, méthodes nommées clairement, aucune fuite d’état.

Grille d’auto-évaluation du projet (sur 100)
< 50 % — Lecture ordonnée et gestion de n = 0 20
50–69 % — Encapsulation correcte de la classe Etudiant 20
70–94 % — Filtrage et affichage des étudiants ≥ 10 20
≥ 95 % — Lisibilité, noms, formatage 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
import java.util.*;

class Etudiant {
    private final String nom;
    private final int note;

    Etudiant(String nom, int note) {
        this.nom = nom;
        this.note = note;
    }

    String getNom() { return nom; }
    int getNote() { return note; }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        ArrayList<Etudiant> etudiants = new ArrayList<>();
        int somme = 0;
        for (int i = 0; i < n; i++) {
            String nom = sc.next();
            int note = sc.nextInt();
            etudiants.add(new Etudiant(nom, note));
            somme += note;
        }
        double moyenne = n == 0 ? 0.0 : (double) somme / n;
        System.out.println("moyenne : " + String.format(Locale.US, "%.2f", moyenne));
        for (Etudiant e : etudiants) {
            if (e.getNote() >= 10) {
                System.out.println(e.getNom() + " : " + e.getNote());
            }
        }
    }
}
Cette solution combine modélisation, lecture ordonnée, moyenne, filtrage et formatage — l’essentiel des six chapitres en un seul programme.
