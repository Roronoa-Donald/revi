Exercices supplémentaires & projet intégrateur

De la pratique graduée pour consolider chaque module, puis un projet final qui assemble un tableau de bord d’infrastructure. Les scripts sont en PowerShell, comme à l’atelier.

Entraînement rapide (acquisition)

Échauffement
  1. Lire deux entiers et afficher leur somme.
  2. Lire un âge de snapshot et dire s’il faut le purger (> 7 jours).
  3. Lire une température et classer normal / chaud / danger / critique.
  4. Compter le nombre d’échecs parmi n mises à jour.
Corrections
$a = [int][Console]::In.ReadLine()
$b = [int][Console]::In.ReadLine()
Write-Output ("somme : " + ($a + $b))

$age = [int][Console]::In.ReadLine()
if ($age -gt 7) { Write-Output "snapshot : a purger" } else { Write-Output "snapshot : conserve" }

$temp = [int][Console]::In.ReadLine()
if ($temp -ge 85) { Write-Output "danger" } elseif ($temp -ge 60) { Write-Output "chaud" } else { Write-Output "normal" }

$n = [int][Console]::In.ReadLine()
$echecs = 0
for ($i = 0; $i -lt $n; $i++) {
    if ([Console]::In.ReadLine() -eq "echec") { $echecs++ }
}
Write-Output ("echecs : " + $echecs)

Application

Application
  1. Valider la stratégie 3-2-1 à partir de trois valeurs.
  2. Calculer la charge par serveur et le reste non réparti.
  3. Détecter une surallocation de vCPU.
  4. Totaliser un volume de VM et le comparer à la capacité d’une cible.
Corrections
$copies = [int][Console]::In.ReadLine()

if (($copies -ge 3) -and ($supports -ge 2) -and ($horsSite -eq "oui")) {

$par = [int]([math]::Floor($requetes / $serveurs))
Write-Output ("par serveur : " + $par)
Write-Output ("non reparties : " + ($requetes % $serveurs))

$vcpu = [int][Console]::In.ReadLine()
$coeurs = [int][Console]::In.ReadLine()

Raisonnement

Raisonnement
  1. Classifier un mode réseau (NAT / Bridge / Host-Only) selon l’accès Internet et l’accès LAN.
  2. Déterminer si un clone survit à la suppression de sa source.
  3. Vérifier le quorum d’un cluster à partir du nombre de nœuds en ligne.
  4. Établir un plan de maintenance à partir d’une fréquence (switch).
Corrections
$mode = [Console]::In.ReadLine()
switch ($mode) {
    "nat" { Write-Output "internet : oui"; Write-Output "lan : non" }
    "bridge" { Write-Output "internet : oui"; Write-Output "lan : oui" }
    "host-only" { Write-Output "internet : non"; Write-Output "lan : non" }
    default { Write-Output "internet : non"; Write-Output "lan : non" }
}

$sourceSupprimee = [Console]::In.ReadLine()

Projet intégrateur — « audit d’une infrastructure »

Cahier des charges

On te confie un script d’audit. Le script lit d’abord un entier n : le nombre de VM. Puis, pour chaque VM, une ligne nom vcpu coeurs. Il affiche, VM par VM, si elle est en surallocation. À la fin, il affiche le nombre total de VM en surallocation, puis un verdict : infrastructure : a surveiller si au moins une VM est en surallocation, sinon infrastructure : saine.

Fonctionnalités attendues
  1. Lire n, puis n lignes « nom vcpu coeurs ».
  2. Tester la surallocation (vcpu > coeurs) pour chaque VM.
  3. Afficher une ligne par VM : NOM : surallocation oui/non.
  4. Compter les VM en surallocation.
  5. Afficher le total puis le verdict global.
  6. Gérer le cas n = 0 sans erreur.

Contraintes : comparaisons avec -gt, switch ou if, et une seule boucle de lecture.

Grille d’auto-évaluation du projet (sur 100)
Lecture ordonnée et gestion de n = 0 20
Test correct de la surallocation 20
Affichage par VM au bon format 20
Comptage et verdict global 20
Lisibilité, noms, cohérence 20

Objectif : ≥ 95/100 avant de considérer le projet terminé.

Voir une solution de référence (après avoir essayé !) 
$n = [int][Console]::In.ReadLine()
$enSurallocation = 0
for ($i = 0; $i -lt $n; $i++) {
    $nom = [Console]::In.ReadLine()
    $vcpu = [int][Console]::In.ReadLine()
    $coeurs = [int][Console]::In.ReadLine()
    if ($vcpu -gt $coeurs) {
        Write-Output ($nom + " : surallocation oui")
        $enSurallocation++
    } else {
        Write-Output ($nom + " : surallocation non")
    }
}
Write-Output ("surallocation : " + $enSurallocation)
if ($enSurallocation -gt 0) {
    Write-Output "infrastructure : a surveiller"
} else {
    Write-Output "infrastructure : saine"
}
Cette solution combine lecture ordonnée, test de surallocation, comptage et verdict — l’essentiel des premiers chapitres en un seul script.
