Cartes de révision

Clique sur une carte pour révéler la réponse. Objectif : répondre sans hésiter dans les deux sens pour ancrer durablement les concepts clés de React.

Module 1 — Penser en composants & l’écosystème JSX / Vite

QuestionQu’est-ce que React ?
RéponseUne bibliothèque JavaScript déclarative et basée sur des composants pour créer des interfaces utilisateur.
QuestionQue signifie UI = f(state) ?
RéponseL’interface visuelle est le résultat prédictible d’une fonction pure recevant les données d’état.
QuestionEn quoi JSX est-il compilé ?
RéponseEn appels à React.createElement(type, props, children).
QuestionPourquoi utilise-t-on className au lieu de class ?
RéponseParce que class est un mot réservé en JavaScript pour la déclaration de classes.
QuestionÀ quoi sert un Fragment (<>...</>) ?
RéponseÀ regrouper plusieurs éléments enfants sans ajouter de nœud div inutile dans le DOM.
QuestionQuelle méthode monte l’application dans le DOM ?
RéponsecreateRoot(document.getElementById('root')).render(<App />).

Module 2 — Composants fonctionnels & transmission de props

QuestionPourquoi les props sont-elles immuables ?
RéponsePour garantir que les composants restent prévisibles et purs vis-à-vis de leurs données d’entrée.
QuestionÀ quoi sert la déstructuration des props ?
RéponseÀ extraire directement les propriétés utiles dans la signature de la fonction sans répéter props.x.
QuestionQue contient props.children ?
RéponseLes éléments JSX insérés entre la balise ouvrante et fermante du composant conteneur.
QuestionComment passer une fonction comme prop ?
RéponseExemple : <Bouton onAction={() => alert('Clic')} />.
QuestionQu’est-ce que le flux de données unidirectionnel ?
RéponseLe fait que les données transitent toujours de haut en bas, des composants parents vers les enfants.
QuestionComment éviter le prop drilling excessif ?
RéponsePar la composition de composants avec children ou par l’utilisation de la Context API.

Module 3 — État local (useState) & formulaires contrôlés

QuestionQue fait le setter retourné par useState ?
RéponseIl met à jour la valeur en mémoire et planifie un nouveau rendu du composant.
QuestionPourquoi privilégier setX(prev => prev + 1) ?
RéponsePour éviter de calculer sur un état obsolète lorsque plusieurs mises à jour sont regroupées par lot.
QuestionQu’est-ce qu’un SyntheticEvent ?
RéponseUne enveloppe multi-navigateurs autour des événements natifs du DOM standard.
QuestionComment vider un champ contrôlé ?
RéponseEn appelant son setter avec une chaîne vide : setNom('').
QuestionComment supprimer un élément d’un tableau d’état ?
RéponseAvec la méthode filter : setListe(prev => prev.filter(item => item.id !== cible)).
QuestionPourquoi ne faut-il pas muter directement l’état ?
RéponseParce que React compare les références : sans nouvelle référence, il ne déclenche pas de réaffichage.

Module 4 — Rendu conditionnel, listes & clés dynamiques

QuestionPourquoi map() est-il préféré à forEach() en JSX ?
RéponseParce que map() retourne un nouveau tableau exploitable par React, alors que forEach() ne renvoie rien (undefined).
QuestionQue risque-t-on à utiliser key={index} ?
RéponseDes désynchronisations d’état des enfants lors de suppressions, insertions ou tris dans la liste.
QuestionComment corriger {count && <Badge />} ?
RéponseÉcrire {count > 0 && <Badge />} ou {Boolean(count) && <Badge />} pour éviter d’afficher 0.
QuestionOù place-t-on la prop key ?
RéponseSur le premier élément JSX renvoyé par la fonction de rappel de map().
QuestionComment trier un tableau en React sans muter la source ?
RéponseAvec [...tableau].sort(...) pour trier une copie superficielle.
QuestionQu’est-ce qu’un retour anticipé (early return) ?
RéponseVérifier une condition dès le début du composant (ex. if (loading) return <Spinner />) pour simplifier le JSX final.

Module 5 — Effets de bord (useEffect) & requêtes asynchrones

QuestionPourquoi useEffect est-il exécuté après le rendu ?
RéponsePour ne pas bloquer l’affichage visuel de l’interface pendant les opérations lentes comme les requêtes réseau.
QuestionQue signifie useEffect(() => {}, []) ?
RéponseL’effet ne s’exécute qu’une seule fois au montage initial du composant.
QuestionÀ quel moment la fonction de nettoyage est-elle appelée ?
RéponseAvant que l’effet ne se réexécute, ainsi qu’au démontage final du composant.
QuestionComment exécuter une fonction async dans useEffect ?
RéponseEn déclarant la fonction async à l’intérieur du callback et en l’appelant immédiatement.
QuestionQue se passe-t-il si une dépendance manque dans le tableau ?
RéponseL’effet peut capturer des valeurs obsolètes (stale closure) et générer des incohérences.
QuestionComment annuler une requête fetch en cours ?
RéponseEn passant un signal AbortController.signal et en appelant controller.abort() dans le cleanup.

Module 6 — Navigation avec React Router & architecture globale

QuestionPourquoi une SPA est-elle plus fluide qu’un site classique ?
RéponseCar elle ne recharge jamais l’intégralité de la page HTML : seul le contenu ciblé est re-rendu.
QuestionQue fait le composant <Link to="..."> ?
RéponseIl modifie l’URL via window.history sans déclencher de rechargement réseau de la page.
QuestionÀ quoi sert useParams() ?
RéponseÀ récupérer les paramètres dynamiques d’URL déclarés avec la notation :nom dans la Route.
QuestionQuel est le rôle de <Outlet /> ?
RéponseC’est le point d’insertion où le composant de la sous-route active est affiché à l’intérieur d’un layout parent.
QuestionComment rediriger un utilisateur non connecté ?
RéponseEn renvoyant <Navigate to="/login" replace /> si la condition d’authentification est fausse.
QuestionQu’est-ce qu’une fonction réductrice (reducer) ?
RéponseUne fonction pure (state, action) => newState calculant le prochain état de manière immuable.
