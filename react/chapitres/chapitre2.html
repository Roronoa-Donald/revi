Chapitre 2 — Composants fonctionnels & transmission de props

Module 2 ≈ 2 h 45 de travail Réservé B2 et plus
Mise en situation

Une fois le découpage d’une interface compris, il faut faire communiquer les composants entre eux. React privilégie des fonctions pures recevant des données en entrée (les props) pour garantir la réutilisabilité et la prévisibilité de l’application.

Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  1. créer des composants fonctionnels modernes respectant les conventions de nommage ;
  2. passer des props de tout type (chaînes, nombres, objets, fonctions) ;
  3. déstructurer les props et définir des valeurs par défaut robustes ;
  4. maîtriser la prop children pour concevoir des conteneurs réutilisables ;
  5. comprendre le flux de données unidirectionnel descendant.

1. Anatomie d’un composant fonctionnel

En React moderne, un composant fonctionnel est une simple fonction JavaScript qui reçoit un objet de données appelé props et renvoie une description de l’UI en JSX.

// Composant simple avec déstructuration
function CarteUtilisateur({ nom, role = 'lecteur' }) {
  return (
    <div className="carte">
      <h3>{nom}</h3>
      <span className="badge">{role}</span>
    </div>
  );
}
Convention stricte de casse

Le nom d’un composant React doit impérativement commencer par une majuscule (ex. CarteUtilisateur). Une balise en minuscule (ex. <div>, <span>) est traitée par React comme un élément HTML natif du DOM.

2. Transmission et lecture des props

Les props (diminutif de properties) constituent le mécanisme par lequel un composant parent transmet des informations à un composant enfant. Elles sont en lecture seule (immuables) : un composant ne doit jamais modifier ses propres props.

// Passage de différents types de props
<Profil
  nom="Alexandre"
  age={24}
  isAdmin={true}
  competences={['React', 'Vite', 'Node']}
  onSelect={() => console.log('Sélectionné')}
/>
Les expressions JavaScript entre accolades

Dans du JSX, tout ce qui se trouve entre accolades {...} est évalué comme une expression JavaScript : variables, calculs arithmétiques, appels de fonctions ou chaînes littérales.

3. Composition et la prop spéciale children

React favorise la composition plutôt que l’héritage. Lorsqu’un composant agit comme une boîte générique (panneau, carte, boîte de dialogue), il ne sait pas à l’avance ce qu’il va contenir. Il utilise alors la prop réservée children :

function Card({ titre, children }) {
  return (
    <div className="card-box">
      <h2>{titre}</h2>
      <div className="card-body">
        {children}
      </div>
    </div>
  );
}

// Utilisation avec imbrication de contenu arbitraire :
<Card titre="Mon Compte">
  <p>Bienvenue sur votre espace personnel.</p>
  <button>Modifier profil</button>
</Card>

4. Flux unidirectionnel et prop drilling

Les données descendent toujours du parent vers les enfants dans un flux unidirectionnel. Lorsqu’une donnée doit traverser plusieurs composants intermédiaires qui n’en ont pas l’usage direct, on parle de prop drilling.

Dans les applications de taille intermédiaire à grande, on résout ce problème par la composition de composants ou par l’utilisation de l’API Context de React.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute le code et la validation fait tourner des jeux de tests indépendants : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

Exercice 1 — Valeurs par défaut des props

JavaScript Niveau 1 — Acquisition

Objectif : Appliquer un rôle par défaut si la prop transmise est omise ou indéfinie.

Les composants React utilisent des valeurs par défaut pour leurs props optionnelles. Le programme lit une ligne nom role. Si le rôle vaut - ou est absent, la valeur par défaut est invite. Affichez Utilisateur : nom | Role : role.

Entrée du programme
Sophie admin
Sortie attendue
Utilisateur : Sophie | Role : admin

Rôle explicite admin.

Deux indices, rédigés en mots
  1. Vérifiez si role est falsy ou égal à "-" avec une ternaire ou l'opérateur ||.
  2. Affichez la chaîne formatée avec un gabarit littéral.

Exercice 2 — Composition et prop children

JavaScript Niveau 1 — Acquisition

Objectif : Encapsuler un contenu arbitraire dans un composant Card réutilisable.

La prop spéciale children permet d'imbriquer du contenu. Le programme lit deux lignes : la variante CSS sur la ligne 1 (ex. info, danger), et le texte enfant sur la ligne 2. Affichez la balise générée : <div class="card card-VARIANTE"><p>TEXTE</p></div>.

Entrée du programme
info
Mise a jour disponible
Sortie attendue
<div class="card card-info"><p>Mise a jour disponible</p></div>

Carte de notification info.

Deux indices, rédigés en mots
  1. Nettoyez les éventuels espaces avec trim().
  2. Injectez la variante dans la classe et le texte enfant dans le paragraphe interne.

Exercice 3 — Déstructuration et filtrage de props

JavaScript Niveau 2 — Application

Objectif : Extraire les props pertinentes pour éviter de transmettre des attributs parasites aux balises HTML.

En React moderne, on déstructure les props d'un composant pour isoler celles dont il a besoin. Le script reçoit sur une ligne des paires cle=valeur séparées par des espaces. Isolez les props id, theme et active, et affichez-les au format : Props filtrees : id=ID theme=THEME active=ACTIVE (si une clé manque, affichez none).

Entrée du programme
id=btn1 theme=dark active=true onClick=handleClick
Sortie attendue
Props filtrees : id=btn1 theme=dark active=true

Extraction de 3 props en ignorant onClick.

Deux indices, rédigés en mots
  1. Stockez les paires dans un objet ou une Map en découpant chaque terme au signe =.
  2. Assignez la valeur par défaut "none" pour les trois propriétés attendues.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Tenter de modifier directement les props (ex. props.titre = "Nouveau").
  • Oublier les accolades pour passer un booléen, un nombre ou un objet (ex. age="20" au lieu de age={20}).
  • Nommer un composant en minuscule (ex. function button() au lieu de Button()).
  • Multiplier le prop drilling sans envisager la composition avec children.
  • Confondre props (reçues de l’extérieur, immuables) et state (géré localement, modifiable).

8. Méthodologie de résolution

Concevoir et paramétrer un composant réutilisable
  1. Identifier les données variables nécessaires au composant.
  2. Déclarer la fonction avec un nom explicite en PascalCase.
  3. Déstructurer l’objet props en argument avec des valeurs par défaut pour les champs optionnels.
  4. Utiliser la prop children si le composant sert de conteneur d’éléments arbitraires.
  5. Tester le composant avec différents jeux de props pour vérifier sa robustesse.

9. Révision active

Résumé essentiel
  • Un composant fonctionnel est une fonction pure retournant du JSX.
  • Les props permettent aux parents de transmettre des paramètres en lecture seule.
  • La déstructuration ES6 ({ prop1, prop2 = defaut }) améliore la lisibilité du code.
  • La prop children permet de concevoir des conteneurs réutilisables (Card, Dialog, Layout).
  • Les données s’écoulent selon un flux unidirectionnel descendant prévisible.

Checklist de maîtrise

  • Je sais nommer mes composants en PascalCase.
  • Je transmets des données de tout type avec la syntaxe {expression}.
  • Je déstructure mes props et prévois des valeurs de repli.
  • J’utilise la prop children pour créer des conteneurs.
  • Je ne modifie jamais directement les props reçues.
