Chapitre 4 — Rendu conditionnel, listes & clés dynamiques

Module 4 ≈ 2 h 45 de travail Réservé B2 et plus
Mise en situation

La plupart des applications manipulent des collections d’éléments : catalogues de produits, fils d’actualités ou listes de messages. Afficher ces données de manière ordonnée et conditionnelle exige de maîtriser la méthode map() et le rôle critique de la prop key.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. maîtriser les différentes techniques de rendu conditionnel (if, ternaire, court-circuit) ;
  2. éviter les pièges du court-circuit avec la valeur 0 ;
  3. transformer un tableau de données en éléments JSX avec Array.prototype.map() ;
  4. comprendre le rôle fondamental de la prop key pour l’algorithme de réconciliation ;
  5. calculer des listes filtrées ou triées sans dupliquer l’état.

1. Techniques de rendu conditionnel

En React, il n’existe pas de directive spéciale comme v-if ou *ngIf : on utilise les structures de contrôle natives de JavaScript.

// 1. Retour anticipé (Early return)
if (isLoading) {
  return <p>Chargement en cours...</p>;
}

// 2. Opérateur ternaire
return (
  <div>
    {isLogged ? <Profil /> : <BoutonConnexion />}
  </div>
);

// 3. Court-circuit logique (&&)
return (
  <div>
    <h1>Boîte de réception</h1>
    {hasUnreadMessages && <span className="pastille">Nouveau !</span>}
  </div>
);
Le piège classique de {count && <Composant />}

En JavaScript, 0 && "texte" s’évalue à 0 (et non à false). Si votre variable vaut 0, React affichera le chiffre 0 dans la page au lieu de ne rien rendre ! Écrivez toujours : {count > 0 && <Badge />} ou {Boolean(count) && <Badge />}.

2. Rendu de listes avec map()

Pour afficher une liste dynamique, on transforme un tableau de données en un tableau d’éléments JSX à l’aide de la méthode fonctionnelle map() :

const fruits = [
  { id: 'f1', nom: 'Pomme', prix: 1.2 },
  { id: 'f2', nom: 'Banane', prix: 0.9 },
  { id: 'f3', nom: 'Orange', prix: 1.5 }
];

function ListeFruits() {
  return (
    <ul>
      {fruits.map(fruit => (
        <li key={fruit.id}>
          {fruit.nom} — {fruit.prix} €
        </li>
      ))}
    </ul>
  );
}

3. Le rôle fondamental de la prop key

La prop key est une chaîne ou un identifiant unique qui indique à React l’identité de chaque élément d’une liste entre deux rendus. Elle permet au réconciliateur de savoir précisément quel élément a été ajouté, déplacé ou supprimé, sans devoir redessiner toute la liste.

Pourquoi éviter l’index de boucle comme clé ?

Utiliser l’index de boucle (key={index}) fonctionne si la liste est statique. Mais en cas d’ajout en tête, de suppression ou de tri, les index changent : React confond alors l’état interne des composants enfants (comme le contenu de champs de saisie ou des cases cochées). Utilisez toujours un identifiant stable et unique issu des données (ex. id de base de données).

4. Calcul de données dérivées sans redondance d’état

Si une liste doit être filtrée par un champ de recherche ou triée, ne stockez pas la liste filtrée dans un second state. Calculez-la simplement à la volée pendant le rendu :

const [recherche, setRecherche] = useState('');

// Calcul dérivé à chaque rendu :
const produitsFiltres = produits.filter(p =>
  p.nom.toLowerCase().includes(recherche.toLowerCase())
);

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Oublier la prop key lors de l’utilisation de map().
  • Utiliser l’index de boucle comme clé sur une liste sujette aux ajouts ou aux tris.
  • Utiliser {count && <Composant />} quand count peut valoir 0 (affiche "0").
  • Créer un state dupliqué pour une liste filtrée au lieu de la calculer à la volée.
  • Modifier directement le tableau d’origine avec sort() ou reverse() dans le corps du composant.

8. Méthodologie de résolution

Afficher et filtrer une collection de données en React
  1. Définir la structure des données avec un identifiant unique stable (id).
  2. Filtrer ou trier les données à la volée en créant une copie non mutante.
  3. Itérer sur la collection avec .map() pour produire les balises JSX.
  4. Assigner key={item.id} sur la balise parente de chaque élément de la boucle.
  5. Prévoir un affichage alternatif si la collection est vide (empty state).

9. Révision active

Résumé essentiel
  • Le JSX utilise les structures de contrôle JavaScript pures (ternaires, court-circuit, map).
  • La méthode map() est l’outil de référence pour transformer des données en listes de composants.
  • La prop key est indispensable pour permettre au réconciliateur de traquer les nœuds du DOM.
  • L’index de tableau doit être évité comme clé sur les listes dynamiques.
  • Les données dérivées (filtres, compteurs) doivent être calculées au vol sans état redondant.

Checklist de maîtrise

  • Je maîtrise l’opérateur ternaire et le court-circuit && en JSX.
  • J’évite le piège du 0 numérique dans les expressions conditionnelles.
  • J’itère sur mes tableaux avec map() en retournant du JSX.
  • Je fournis une clé unique et stable (key) à chaque élément de liste.
  • Je ne duplique pas mon state pour les données filtrées ou triées.
