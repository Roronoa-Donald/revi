Chapitre 6 — Navigation avec React Router & architecture globale

Module 6 ≈ 3 h 15 de travail Réservé B2 et plus
Mise en situation

Une application web d’envergure ne se résume pas à un écran unique : elle comprend des pages de profil, un tableau de bord, des formulaires et des vues détaillées. React Router permet de créer une navigation fluide sans rechargement de page tout en conservant les URLs et l’historique du navigateur.

Objectifs pédagogiques

À la fin de ce chapitre, tu seras capable de :

  1. comprendre le fonctionnement d’une Single Page Application (SPA) et l’API History du navigateur ;
  2. configurer React Router v6 (BrowserRouter, Routes, Route, Link) ;
  3. extraire des paramètres dynamiques d’URL avec le Hook useParams ;
  4. concevoir des routes imbriquées à l’aide du composant Outlet ;
  5. gérer des flux d’état globaux avec useReducer et structurer une base de code professionnelle.

1. Le concept de Single Page Application (SPA)

Dans une application web traditionnelle, chaque clic sur un lien <a href="..."> envoie une requête au serveur qui renvoie une nouvelle page HTML complète, provoquant un clignotement blanc.

Dans une SPA (Single Page Application), une seule page HTML est chargée au départ. Le routeur intercepte les clics sur les liens, modifie l’URL dans la barre d’adresse avec l’API window.history.pushState(), et met à jour uniquement les composants correspondant à la nouvelle route.

Navigation instantanée

La navigation devient instantanée car le navigateur n’a plus besoin de re-télécharger ni de re-parser les feuilles de style et les bundles JavaScript à chaque changement de page.

2. Configuration de React Router v6

Pour intégrer le routage dans un projet React, on installe react-router-dom :

import { BrowserRouter, Routes, Route, Link, NavLink } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <nav>
        <NavLink to="/" end>Accueil</NavLink>
        <NavLink to="/cours">Cours</NavLink>
        <NavLink to="/contact">Contact</NavLink>
      </nav>

      <Routes>
        <Route path="/" element={<Accueil />} />
        <Route path="/cours" element={<ListeCours />} />
        <Route path="/cours/:slug" element={<DetailCours />} />
        <Route path="*" element={<PageIntrouvable />} />
      </Routes>
    </BrowserRouter>
  );
}
Link vs balise a standard

N’utilisez jamais <a href="..."> pour la navigation interne : cela recharge la page entière et réinitialise tout le state React ! Utilisez systématiquement <Link to="..."> ou <NavLink to="...">.

3. Paramètres dynamiques et useParams

Pour créer des pages dynamiques (ex. /cours/react ou /utilisateurs/42), on déclare un paramètre préfixé par : dans le chemin de la route. Dans le composant cible, le Hook useParams() récupère ces valeurs :

import { useParams } from 'react-router-dom';

function DetailCours() {
  const { slug } = useParams();
  return <h1>Consultation du cours : {slug}</h1>;
}

4. Architecture professionnelle et gestion d’état par Reducer

Lorsque la complexité augmente, regrouper les données dans de multiples useState devient confus. Le Hook useReducer offre une architecture prédictible inspirée du pattern Redux :

function panierReducer(state, action) {
  switch (action.type) {
    case 'AJOUT':
      return { ...state, total: state.total + action.prix };
    case 'REMISE':
      return { ...state, total: Math.max(0, state.total - action.valeur) };
    default:
      return state;
  }
}
Organisation recommandée d’un projet React
  • src/components/ : composants UI réutilisables (boutons, cartes, modales).
  • src/pages/ : composants représentant les pages de l’application.
  • src/hooks/ : Hooks personnalisés (ex. useAuth, useFetch).
  • src/services/ : fonctions d’appel aux APIs backend.

5. Exercices de code

Ces trois exercices se font dans la page. L’éditeur du navigateur exécute votre code sur un service distant, puis la validation fait tourner des tests que vous ne voyez pas : réussir l’exemple affiché ne suffit donc pas, il faut traiter le cas général.

En cas d’erreur, le bouton Expliquer mon erreur interroge le tuteur : il décrit ce qui s’est passé et par où chercher, sans jamais écrire de code à votre place — c’est le principe de l’exercice.

Exercice 1 — Paramètres de route dynamiques (useParams)

JavaScript Niveau 1 — Acquisition

Objectif : Extraire les paramètres d'URL définis avec la notation :param de React Router.

Le hook useParams extrait les paramètres dynamiques de l'URL. Le script lit sur la ligne 1 le modèle de route (ex. /users/:id/profile) et sur la ligne 2 l'URL courante (ex. /users/42/profile). Affichez les paramètres extraits au format JSON : {"id":"42"}. Si les segments ne correspondent pas en nombre, affichez {}.

Entrée du programme
/users/:id/profile
/users/42/profile
Sortie attendue
{"id":"42"}

Paramètre id extrait avec succès.

Deux indices, rédigés en mots
  1. Comparez pattern.length et url.length.
  2. Si un segment de pattern commence par ":", stockez url[i] avec la clé sans le deux-points.

Exercice 2 — Route protégée et composant Navigate

JavaScript Niveau 1 — Acquisition

Objectif : Rediriger un utilisateur non connecté avec le composant Navigate de React Router.

Pour sécuriser une route privée, on teste l'authentification : si l'utilisateur est connecté, le composant enfant s'affiche ; sinon, une redirection s'opère. Le script lit une ligne auth composant où auth vaut 1 ou 0. Si 1, affichez <COMPOSANT /> ; si 0, affichez <Navigate to="/login" replace />.

Entrée du programme
1 Dashboard
Sortie attendue
<Dashboard />

Accès autorisé au tableau de bord.

Deux indices, rédigés en mots
  1. Si auth === "1", affichez le composant cible avec des balises auto-fermantes.
  2. Si auth === "0", affichez la balise Navigate avec to="/login" et replace.

Exercice 3 — Architecture d'état par Reducer (useReducer)

JavaScript Niveau 2 — Application

Objectif : Implémenter une fonction réductrice pure (state, action) => newState pour gérer un panier d'achats.

Pour des états complexes, le hook useReducer découple les transitions dans une fonction pure. Le script lit sur la ligne 1 le total initial (entier), et sur la ligne 2 une suite d'actions séparées par des espaces : AJOUT:X (ajoute X) ou REMISE:X (retire X, minimum 0). Affichez Total panier : TOTAL.

Entrée du programme
50
AJOUT:20 REMISE:10
Sortie attendue
Total panier : 60

50 + 20 - 10 = 60

Deux indices, rédigés en mots
  1. Découpez chaque action sur le deux-points pour séparer le type et le montant.
  2. Utilisez Math.max(0, total - val) pour éviter un panier négatif.

7. Erreurs classiques — récapitulatif

À reconnaître en examen
  • Utiliser des balises <a> au lieu de <Link> dans une SPA React.
  • Oublier d’envelopper l’arborescence des routes dans un <BrowserRouter>.
  • Omettre le composant <Outlet /> dans un composant de Layout contenant des sous-routes.
  • Muter l’état à l’intérieur d’un reducer au lieu de renvoyer un nouvel objet { ...state }.
  • Mélanger les responsabilités en plaçant des requêtes HTTP directes dans des composants UI de bas niveau.

8. Méthodologie de résolution

Structurer et sécuriser la navigation d’une application React
  1. Définir l’arborescence des URLs (publiques, privées, introuvables).
  2. Configurer le BrowserRouter au niveau le plus haut de l’application.
  3. Organiser les composants dans des dossiers dédiés (pages, components, services).
  4. Protéger les routes sensibles à l’aide d’un composant PrivateRoute vérifiant la session.
  5. Gérer les paramètres d’URL avec useParams pour les vues de détail dynamiques.

9. Révision active

Résumé essentiel
  • React Router transforme une application React en Single Page Application navigable et rapide.
  • BrowserRouter synchronise l’UI avec l’URL du navigateur via l’History API.
  • Les composants Link et NavLink évitent le rechargement de page natif.
  • useParams et Outlet permettent des routes dynamiques et des layouts imbriqués modulaires.
  • useReducer apporte une architecture prévisible pour les états complexes et volumineux.

Checklist de maîtrise

  • Je sais configurer BrowserRouter, Routes et Route.
  • J’utilise Link ou NavLink pour tous mes liens internes.
  • J’extrais des identifiants dynamiques avec useParams.
  • J’utilise Outlet pour composer des pages avec barre de navigation ou sidebar.
  • Je structure mes projets React selon les standards professionnels de l’industrie.
