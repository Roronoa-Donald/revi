Exercices pratiques & projet fil conducteur

18 ateliers de programmation répartis sur les six chapitres du cours, complétés par le développement guidé d’une application complète : la Todo App réactive.

Le catalogue des 18 exercices
  • Chapitre 1 : Création d’éléments virtuels, rendu conditionnel JSX, arborescence de composants.
  • Chapitre 2 : Valeurs par défaut des props, composition avec children, déstructuration de props.
  • Chapitre 3 : Simulateur useState, validation d’inputs contrôlés, immutabilité de tableaux d’état.
  • Chapitre 4 : Listes avec prop key, filtrage insensible à la casse, court-circuit logique.
  • Chapitre 5 : Détection de dépendances useEffect, machine d’états API, nettoyage de timers.
  • Chapitre 6 : Paramètres dynamiques useParams, route protégée Navigate, architecture par reducer.

Projet fil conducteur : La Todo App réactive complète

Ce projet intègre l’ensemble des notions du cours dans une application professionnelle organisée en modules modulaires.

Étape 1 : Découpage et composants fonctionnels

Créer l’arborescence des composants :

  • App.jsx : orchestrateur principal et gestion du state global des tâches.
  • Header.jsx : affichage du titre et du compteur de tâches restantes.
  • TodoForm.jsx : formulaire contrôlé avec champ de saisie et bouton d’ajout.
  • TodoList.jsx : rendu de la collection via map() et attribution de clés uniques.
  • TodoItem.jsx : ligne individuelle avec case à cocher et bouton de suppression.
Étape 2 : Gestion réactive de l’état (useState)

Implémenter les actions fondamentales de manière strictement immuable :

// Ajout d’une tâche
setTodos(prev => [...prev, { id: crypto.randomUUID(), texte, fait: false }]);

// Bascule de statut
setTodos(prev => prev.map(t => t.id === id ? { ...t, fait: !t.fait } : t));

// Suppression
setTodos(prev => prev.filter(t => t.id !== id));
Étape 3 : Filtrage dynamique sans état redondant

Calculer les tâches affichées selon le filtre actif (toutes, en cours, terminées) sans dupliquer le tableau dans un second state :

const [filtre, setFiltre] = useState('toutes');

const tachesVisibles = todos.filter(t => {
  if (filtre === 'actives') return !t.fait;
  if (filtre === 'terminees') return t.fait;
  return true;
});
Étape 4 : Persistance locale avec useEffect

Synchroniser les données avec le localStorage du navigateur pour conserver les tâches après rechargement :

// Chargement initial
const [todos, setTodos] = useState(() => {
  const saved = localStorage.getItem('todos_app');
  return saved ? JSON.parse(saved) : [];
});

// Sauvegarde automatique à chaque modification
useEffect(() => {
  localStorage.setItem('todos_app', JSON.stringify(todos));
}, [todos]);
Étape 5 : Navigation avec React Router

Ajouter une barre de navigation pour séparer les vues de l’application :

  • / : liste interactive des tâches courantes.
  • /statistiques : indicateurs de productivité et graphiques d’avancement.
  • /a-propos : crédits et technologies employées.
