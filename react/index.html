React B2 — composants, JSX, hooks, state, effets et React Router

React est la bibliothèque incontournable du développement frontend moderne. Six chapitres pour maîtriser le paradigme déclaratif, composer des interfaces réutilisables, manipuler l’état et les effets, et architecturer des applications complètes et performantes.

Ce que vous saurez faire à la fin du cours
  • penser en composants autonomes et maîtriser le modèle mental déclaratif de React ;
  • écrire du JSX propre et manipuler les props avec déstructuration et children ;
  • gérer des états réactifs complexes et des formulaires contrôlés avec useState ;
  • rendre des listes dynamiques performantes grâce à map() et la prop key ;
  • synchroniser des composants avec des APIs distantes via useEffect sans fuite mémoire ;
  • architecturer une Single Page Application complète avec React Router v6.
Comment ce cours s’articule

Ce cours aborde React de manière progressive en six chapitres : des fondations du JSX jusqu’au routage multipage et aux architectures globales. Le chapitre 1 est en accès libre.

Chaque chapitre se termine par trois exercices de code interactifs en JavaScript : vous écrivez la logique de composants, d’état et d’algorithmes réactifs, exécutée directement dans la page et validée par une batterie de tests cachés.

Programme du cours
