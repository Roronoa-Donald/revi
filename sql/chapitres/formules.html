Mémento & Syntaxe de Référence SQL ANSI

Synthèse opérationnelle des commandes DDL/DML, expressions conditionnelles, fonctions de fenêtrage et niveaux d’isolation transactionnels.

1. Définition de Données (DDL) & Contraintes

Commande / ClauseSyntaxe typeRôle & Comportement
CREATE TABLECREATE TABLE t (id INT PRIMARY KEY, nom VARCHAR(50) NOT NULL);Création d’une nouvelle table avec clé primaire et contrainte de présence.
FOREIGN KEYFOREIGN KEY (parent_id) REFERENCES parent(id) ON DELETE CASCADEMaintien de l’intégrité référentielle avec suppression en cascade.
CHECKCHECK (prix > 0 AND stock ≥ 0)Validation de domaine sur les colonnes lors des insertions et mises à jour.
ALTER TABLEALTER TABLE t ADD COLUMN date_creation DATE DEFAULT CURRENT_DATE;Modification de la structure d’une table existante sans perte de données.

Fonction / OpérateurExempleRésultat & Particularité

3. Jointures & Algèbre Relationnelle

Type de JointureOpération mathématiqueTraitement des lignes sans correspondance
INNER JOINIntersection (A ∩ B)Seules les lignes ayant une clé commune sont conservées.
LEFT JOINA ∪ (A ∩ B)Toutes les lignes de la table gauche sont conservées, complétées par NULL à droite.
FULL OUTER JOINUnion complète (A ∪ B)Toutes les lignes des deux tables sont conservées avec NULL pour les manques.
CROSS JOINProduit cartésien (A × B)Associe chaque ligne de A à toutes les lignes de B (taille = |A| * |B|).

4. Fonctions de Fenêtrage (Window Functions)

Fonction analytiqueClause OVERDescription de l’effet
ROW_NUMBER()OVER (PARTITION BY dept ORDER BY score DESC)Attribution d’un numéro séquentiel unique (1, 2, 3...) par partition.
RANK()OVER (ORDER BY note DESC)Classement avec ex aequo générant des sauts dans la numérotation (1, 2, 2, 4).
DENSE_RANK()OVER (ORDER BY note DESC)Classement avec ex aequo sans saut dans la séquence (1, 2, 2, 3).
LAG(col, n)OVER (ORDER BY date_op ASC)Accès à la valeur située n lignes en amont dans la partition ordonnée.
