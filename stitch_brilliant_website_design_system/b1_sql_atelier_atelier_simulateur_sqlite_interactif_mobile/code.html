SELECT m.nom AS marque, COUNT(v.id) AS stock, ROUND(AVG(v.prix), 2) AS prix_moyen FROM marque m JOIN voiture v ON m.id = v.marque_id GROUP BY m.nom HAVING COUNT(v.id) >= 2 ORDER BY prix_moyen DESC;

Comment exploiter l'atelier

  • check_circle Persistance en mémoire : Vos modifications (INSERT/UPDATE) restent actives tant que l'onglet demeure ouvert.
  • check_circle Transactions temporaires : Utilisez BEGIN TRANSACTION et ROLLBACK pour éprouver des requêtes destructives.
  • check_circle Exportation instantanée : Téléchargez vos jeux de données au format CSV ou dump SQL d'un simple clic.
warning

Piège fréquent sous SQLite

Typage dynamique & affinités : Contrairement à PostgreSQL ou Oracle, SQLite accepte par défaut d'insérer du texte dans une colonne déclarée INTEGER sans lever d'exception de type strict. Pensez à activer le mode STRICT sur vos créations de tables.
