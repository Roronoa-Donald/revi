Q

Quelle est la différence fondamentale entre WHERE et HAVING dans une requête d'agrégation ?

// EXEMPLE DE REQUÊTE
SELECT dept, AVG(salaire)
FROM employes
WHERE actif = 1
GROUP BY dept
HAVING AVG(salaire) > 45000;
👆 Toucher pour voir la réponse (Flip)
verified Réponse & Explication

WHERE filtre les lignes individuelles avant tout regroupement.
HAVING filtre les groupes formés après l’évaluation des fonctions d’agrégation (SUM, AVG, COUNT...).
