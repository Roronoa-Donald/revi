Ex. 07 — Jointure interne INNER JOIN entre Voiture et Marque

parc_auto.sqlite
assignment Objectif & Consigne de l'exercice :
Rédigez la requête SQL permettant d'afficher pour chaque véhicule son immatriculation, son modele, son prix et le nom de sa marque d'origine (marque_nom).
Critère de tri : Triez les résultats par ordre alphabétique de marque, puis par prix décroissant pour les véhicules d'une même marque.
schema Relations impliquées 1:N
Voiture Table gauche
PK immat FK marque_id ──┐ modele annee prix
ON Voiture.marque_id = Marque.id
Marque Table droite
PK id ◄─────────┘ nom pays
query.sql SQLite dialect
1 2 3 4 5
SELECT v.immat, v.modele, v.prix, m.nom AS marque_nom
FROM Voiture v
INNER JOIN Marque m ON v.marque_id = m.id
ORDER BY m.nom ASC, v.prix DESC;

warning

Erreurs fréquentes lors de la soumission

  • • Oubli des alias de table : Dans une jointure, préfixez systématiquement vos colonnes ambiguës (v.immat, m.nom).
  • • Inversion des clauses ON : Bien que relationnellement symétrique, l'évaluation de test attend la clé étrangère liée à la clé primaire.
  • • Confusion WHERE vs HAVING : HAVING s'applique exclusivement après agrégation par GROUP BY.
