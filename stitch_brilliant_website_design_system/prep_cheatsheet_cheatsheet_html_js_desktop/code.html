html Structure HTML

Base

Le squelette normalisé d'un document HTML5 avec balises structurantes sémantiques.

<!DOCTYPE html>

Informe le navigateur de la version HTML5 standard.

<html lang="fr">, <head>, <body>

Enveloppe racine, métadonnées techniques, puis contenu visible.

<meta charset="UTF-8">, <title>

Encodage universel des caractères et nom de l'onglet.

<header>, <nav>, <main>, <section>, <article>, <footer>

Zones sémantiques pour l'accessibilité et les robots.

Standard W3C HTML5 Sémantique

perm_media Textes et medias

Contenu

Hiérarchisation textuelle, ancrages hypertextes et incorporation média.

<h1> à <h6>, <p>

Titre unique de page (h1), sous-titres ordonnés, paragraphes de texte.

<strong>, <em>

Emphase forte (gras sémantique) et emphase simple (italique).

<a href="url" target="_blank">

Lien externe ou ancre interne vers une section de l'atelier.

<img src="..." alt="...">, <figure>, <video>, <audio controls>

alt est obligatoire pour l'accessibilité écran.

Accessibilité Media & Typography

format_list_bulleted Listes

Énumérations

Trois modèles d'organisation séquentielle et dictionnaires de données.

<ul> <li>Élément</li> </ul> À puces

Liste non ordonnée pour menus, collections d'items interchangeables.

<ol> <li>Étape 1</li> </ol> Numérotée

Liste ordonnée indispensable aux tutoriels pas à pas et classements.

<dl>, <dt>, <dd> Définition

dt = terme / label clé, dd = explication ou valeur associée.

Imbrication permise <li> inside <ul>/<ol>

edit_note Formulaires

Inputs

Conteneurs d'interaction, liaison étiquettes/champs et envoi de données.

<form action="/api" method="POST">

Encadre les requêtes. GET pour recherche, POST pour mutation.

<label for="monId"> + <input id="monId">

Relie le texte au champ pour le clic et les lecteurs d'écran.

<textarea rows="4"></textarea>

Zone de saisie de texte multiligne avec balise de fermeture explicite.

<select> <option value="1">Choix</option> </select>

Menu déroulant compact. L'attribut value est transmis au serveur.

<button type="submit">Valider</button>

Déclenche l'événement submit sur le formulaire parent.

Accessibilité prioritaire label for === input id

Ciblage

Identification des nœuds, transfert d'état et pont d'accessibilité ARIA.

Identifiant multiple et réutilisable pour CSS et sélecteurs de groupe.

id="uniqueId"

Identifiant strictement unique dans tout le DOM du document.

Attribut personnalisé accessible en JS via el.dataset.userId.

Logique

Variables de scope moderne, fonctions fléchées et manipulation d'arrays.

const (immuable par défaut), let (réassignable)

Bannir var pour éviter les fuites de scope de fonction.

const calc = (a, b) => a * b;

Fonction fléchée concise préservant le contexte lexical du this.

condition ? ifTrue : ifFalse

Opérateur ternaire pour assignations conditionnelles en une ligne.

.map(), .filter(), .find(), .reduce()

Méthodes fonctionnelles pures sans mutation du tableau originel.

Arbre DOM

Sélection d'éléments, gestion d'événements et injection de nœuds dynamiques.

document.querySelector('.classe / #id')

Retourne le 1er nœud correspondant ou null.

element.addEventListener('click', (e) => {})

Écoute non destructive d'événements (click, input, submit, change).

element.textContent vs .innerHTML

textContent est sécurisé contre les failles d'injection XSS.

element.classList.add / toggle / remove

Active ou désactive des règles CSS sans écraser les classes existantes.

app.js — Écouteur, validation, toggle de classe et micro-retour 
// Attente du chargement complet du DOM
document.addEventListener('DOMContentLoaded', () => {
  const form = document.querySelector('#registrationForm');
  const emailInput = document.querySelector('#userEmail');
  const errorFeedback = document.querySelector('#emailError');

  // Garde réflexe : sortie immédiate si l'élément n'existe pas sur la page
  if (!form || !emailInput) {
    console.warn("Éléments du formulaire introuvables sur ce document.");
    return;
  }

  // Écoute de l'événement de soumission
  form.addEventListener('submit', (event) => {
    event.preventDefault(); // Stoppe le rechargement HTTP classique
    
    const emailValue = emailInput.value.trim();
    const isValidEmail = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(emailValue);

    if (!isValidEmail) {
      // Diagnostic visuel d'erreur
      emailInput.classList.add('border-feedback-error');
      errorFeedback.textContent = "Format de courriel invalide. Vérifiez l'arobase (@).";
      emailInput.focus();
      return;
    }

    // Réinitialisation et succès tactile
    emailInput.classList.remove('border-feedback-error');
    emailInput.classList.add('border-feedback-correct');
    errorFeedback.textContent = "";

    console.log("Données transmises avec succès :", {
      email: emailValue,
      horodatage: new Date().toISOString()
    });
  });
});
