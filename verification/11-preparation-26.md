# K13 — qualification pédagogique des 26 candidats historiques

**Périmètre :** lecture des 26 énoncés locaux, de leurs amorces et indices, et des sections précédant les premiers ateliers, le 29 octobre 2026. Les identifiants proviennent du relevé historique ; les constats et rapprochements ci-dessous sont indépendants. Une notion présente n'est pas la preuve qu'elle est comprise. Un prérequis disponible dans un autre cours n'est pas nécessairement maîtrisé ou effectivement suivi. Les exemples cités sont des points d'entrée, pas un graphe exhaustif.

**Résultat :** une inversion claire sur `py-c1-e1` (F222) et une préparation Bash insuffisamment explicite sur les trois exercices Git B1 (F223). Pour les autres, les concepts du domaine sont généralement introduits avant l'atelier ou dans son énoncé ; la maîtrise des outils de programmation reste à établir. Pour les neuf exercices de GitHub B3, Linux B3 et Docker, les mots signalés dans les corrigés mémorisés ne prouvent pas que ces mots sont imposés aux élèves (F204/F211). Un objectif Python contradictoire avec les ateliers est aussi présent dans 17 chapitres de GitHub B3, Linux B3 et SQL B3 (F225).
